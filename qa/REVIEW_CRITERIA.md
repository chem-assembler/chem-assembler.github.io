### 検収の指摘で直したこと（2026-08-13・ユーザーレビュー）

上の通読の成果をユーザーに見せたところ、4点の指摘があった。**3点はこちらの誤り。**

1. **不斉炭素原子でない理由の説明**（`org.bio.glucose-structure`）。
   「ホルミル基の炭素は二重結合をもつので**結合する相手が3つしかなく**」と書いていたが、
   「**二重結合は2つの結合に同じ基が結合している**」と説明したほうが分かりやすい、との指摘。
   そのとおりで、こう書けば**両端の炭素を1つの理由で説明できる**
   （ホルミル基の炭素は酸素が2つ分を占め、−CH₂OH は水素が2個 ＝ どちらも「同じ基が2つ」）。
   こちらの書き方は端ごとに別の理由を立てていた。→ 統一した言い方に直した。
2. **`org.poly.sbr-copolymer` の補足が浮いていた**。
   誤答肢「スチレンだけを共重合させてつくる」は**共重合の定義に反する語**なので誤答肢に向かない
   ——これは v72 で差し替え済みだったが、**その肢に対応していた補足の一文
   「単量体が1種類では共重合にならない」を消し忘れていた**（対応する肢がないまま残っていた）。
   → 残っている誤答肢（スチレンだけを付加重合）に対応する説明に差し替えた。
3. **アルコールの級は教科書表記に合わせる**（v69 の判断を反転）。
   v69 では**アプリ内の多数派**だった「1級」形にそろえたが、
   **教科書は「第一級」形36回・「1級」形0回**（R5 化学 4〜7編の実測）で完全に一方的だった。
   生徒が教科書・問題集で目にする語と一致していないと照合できないので、**教科書側が正**。
   → 11項目72か所を「第一級／第二級／第三級」に置換し、`tests.js` の検査も反転させた。
   略記のほうは `org.alcohol.class` の補足で「同じものを指す」と伝える（J-7 と同じ形）。

## 原則（なぜこの基準か）
一問一答は「暗記の土台」。ただし **丸暗記ではなく、判断できる形で覚えさせる**。
そのために「問だけ／選択肢だけ」を切り出しても**文として意味が通り、真偽が判定できる**ことを最優先にする。

---

## 評価基準

### C1. 問＋選択肢1つで文が完結する（複数選択）
選択肢は単独の断片にせず、**問（主語・文脈）と1つの選択肢を組み合わせて真偽を判定できる完全な文**にする。
1つの操作・事実を細切れの複数選択肢に割らない（重複を作らない）。
- ✗ 問「炭素の検出について正しいものを選べ」＋選択肢「石灰水を用いて確認する」「二酸化炭素で石灰水が白濁する」「白色沈殿は炭酸カルシウムである」（同じ1手順の断片が3つ）
- ✓ 問「有機化合物中の炭素を確認する操作と結果について正しいものを選べ」＋選択肢「生じた二酸化炭素を石灰水に通すと白濁する」

### C2. 問題文に操作・状況の文脈を書く
「**何をしたときの話か**」を問題文に明示する（特に実験・計算）。前提が抜けると答えが一意に決まらない。
- ✗ 「吸収管の順番について正しいものを選べ」
- ✓ 「元素分析で、燃焼で生じた水と二酸化炭素を吸収管で別々に量るとき、つなぐ順番について正しいものを選べ」

### C3. 囮（誤選択肢）も完全な文・条件を明記
囮も「何をして生じたか／どの条件か」を書き、浮いた断片にしない。**誤りが明確に判定できる**形にする。
- ✗ 「石灰水が赤くなる」（何をした結果かが不明）
- ✓ 「完全燃焼で生じた二酸化炭素で石灰水は赤くなる」（操作つき・明確な誤り）

### C4. 暗記対象と与件を区別する
問題で**与えられる値（原子量・分子量・定数など）は「与件」**として扱い、暗記対象にしない。
覚えるのは**手順・考え方**（例：質量 × 割合）。「原子量が与えられないと解けない」ことも明示してよい。
- ✗ 覚えるべき知識として「CO₂の分子量44のうち炭素は12」だけを提示
- ✓ 「CO₂の質量 ×(12/44)。原子量は問題で与えられるので、覚えるのは『CO₂の質量に炭素の割合をかける』こと」

### C5. 補足（解説）は理由まで書く
「定番」「よく出る」で終わらせない。**なぜそうするのか**を書く。
- ✗ 補足「よく問われる定番。水を先に取る。」
- ✓ 補足「先にソーダ石灰管を置くと水もCO₂も吸ってしまい別々に量れない。だから水だけを吸う塩化カルシウム管を先に置く」

### C6. 定義は厳密な言い回しで
用語の定義は曖昧にせず正確に。
- ✗ 「分子式は原子の数」
- ✓ 「分子式は1分子中の原子の数（を表す）／組成式はその最も簡単な整数比」

### C7. 化学的に正確（事実・条件の漏れなし）
事実誤り、条件（液性・触媒・温度・単位）の欠落、成立範囲の未記載がない。
成立に前提がある場合は明示（例：酸素の差し引きは試料が C・H・O のみのとき）。

### C8. 難易度・範囲がメタと一致
`difficulty` と `group`、対象課程（化学基礎/化学）が内容に合う。範囲外の要求をしない。

### C9. 単元内で一貫
表記（下付き `CO₂`・`H₂O`、イオン式）、用語、モードの役割（**めくり＝再生／複数選択＝弁別**）を単元内で統一。

### C10. 原子・単体・分子・イオンを区別
原子を指すなら「炭素原子」「酸素原子」と明記する（「炭素」「酸素」のままにしない）。
ただし単体・分子は別語で正しい（例：「水素が発生する」は単体 H₂ の意味で正しく、「水素原子」ではない）。文脈で判断する。
- ✗ 「水素が少ない炭素から H がとれる」　✓ 「水素が少ない炭素原子から H がとれる」

### C11. 正解肢を偏らせない／「値」を問う設問は誤り値を囮に
正解数は **2〜4 で分散**（毎回同数・4以上への偏りを避ける）。色・価数・温度など**値をもつ属性**は、別の値（別の色・別の価数・別の温度対応）を囮に置く。
※単純否定の対（「する／しない」「高い／低い」）を両方並べると自明化するので不可。だが **多値属性（2価/3価、各色など）は補集合があり自明化しない**ので並列してよい（例「グリセリンは2価」「グリセリンは3価」）。

### C12. 包括ルールの丸暗記文を選択肢にしない
「0〜1個=1級・2個=2級・3個=3級」のような包括ルールは**補足**へ回す。選択肢は**具体例**（「2-プロパノールは2級」）や**少し迷う判断**（「ヒドロキシ基が付いた炭素原子に炭素原子が0個なら1級」）を問う。

### C13. 数値の目安と例外は選択肢にも入れる
実用的な目安（例：水に溶けやすいのは炭素数およそ4以下）と例外（多価アルコールは-OHが多く溶けやすい）は、めくりだけでなく**選択肢にも**置き、補足で補う。

### C14. なじみの薄い用語は暗記を強制せず補足で説明
専門用語（脱離反応 など）は、語を覚えなくても解ける作りにし、**意味は補足で説明**する。

### C15. 発展の補足は「めくり」と「複数選択」の両方に揃える
発展事項の補足（リン酸触媒・チマーゼ など）は片方のモードだけに書かない。両 variant で揃える。

### C16. 設問テーマ（題意）と選択肢・問い方を一致させる
囮も**題意の範囲内**で作る（製法の設問に反応の是非を混ぜない等）。めくりの問い方もテーマ準拠にする（「最もよく登場する〜」より「〜の性質は？」）。
