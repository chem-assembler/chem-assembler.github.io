# Gemini 依頼パック: エタノールの分子間脱水の反応機構を作る（reactions.json）

## これは何の作業か

Chem-Assembler の反応機構ビューア（巻矢印アニメーション）に、
**エタノールの分子間脱水（ジエチルエーテルの生成）** を1本追加する。

すでに「エタノールの分子内脱水（160〜170℃・エテン生成）」は入っている（id: `ethanol_e1`）。
分子間脱水（130〜140℃・ジエチルエーテル生成）は**温度条件の違いで生成物が変わる**という
教科書の定番の対比なのに、機構が無いため片方しか見せられない。ここを埋める。

**この作業がGeminiに向いている理由**: 出来上がりを機械で検査できる。
座標・添字・電荷・巻矢印の指し先が1つでも狂えば `tools/verify-reactions.js` が落ちる。

## 作るもの

`assembler/reactions.json` の配列に、次の1件を**末尾に追加**する。

- `id`: `ethanol_ether`
- `name`: `エタノールの分子間脱水（ジエチルエーテル生成）`
- `series`: `脱離反応`（既存の `ethanol_e1` と同じ。**この文字列以外は使わない**）
- `desc`: 130〜140℃という条件と、160〜170℃では分子内脱水になる対比に触れる1〜2文

### 機構（3手順・4状態）

エタノール2分子と触媒の H⁺ から始める。

| 手順 | 変化 | 巻矢印 |
|---|---|---|
| 0→1 | 一方のエタノールの O が H⁺ を受け取り、オキソニウムイオン **-OH₂⁺** になる | その O の非共有電子対 → O と H⁺ の中点（`mid`） |
| 1→2 | **もう1分子のエタノールの O が、-OH₂⁺ のついた炭素を攻撃**し、水が脱離する（S<sub>N</sub>2） | ①攻撃する O → 相手の炭素（`atom`）②C–O 結合 → 脱離する O（`bond`→`atom`）の2本 |
| 2→3 | プロトン化されたエーテルから H⁺ が外れ、ジエチルエーテルが完成（触媒 H⁺ は再生） | O–H 結合 → その O（`bond`→`atom`）※または O の電子対 → 外れる H |

**注意（化学）**: 攻撃されるのは -OH₂⁺ が**ついている**炭素です。
隣の炭素ではありません（隣を攻撃すると別の物質になります）。

## データの書き方

**既存の `ethanol_e1` のエントリを読んで、その書式をそのまま踏襲してください。**
それが唯一の正しいひな形です。要点だけ再掲します。

```
{
  "id": "...", "name": "...", "series": "...", "desc": "...",
  "states": [ { "atoms": [ {"element":"C","x":358,"y":300}, ... ],
                "bonds": [ {"atom1Index":0,"atom2Index":1,"type":1}, ... ] }, ... ],
  "steps":  [ { "from":0, "to":1, "caption":"...",
                "arrows":[ {"source":{...},"target":{...},"style":"pair"} ] }, ... ]
}
```

- **原子は水素まで全部明示する**（省略しない）。
- **原子の並び順（添字）は全状態で同じにする**。結合と巻矢印は添字で指すので、
  途中で並べ替えると全部狂う。**状態は前の状態をコピーして必要な所だけ直す**のが安全。
- 電荷は `"charge": 1` / `"charge": -1`。中性の原子には書かない。
- 巻矢印の指し先は3種類:
  - `{"type":"atom","index":7}` … 原子そのもの（非共有電子対の出発点・電子の行き先）
  - `{"type":"bond","atoms":[1,7]}` … 結合（**その状態に実在する結合でなければ不合格**）
  - `{"type":"mid","atoms":[7,9]}` … 2原子の中点（新しく結合ができる位置を指すとき）
  - `"style"` は `"pair"`（電子対＝両羽）か `"single"`（単電子＝片羽）。今回はすべて `pair`
- `arrows` の `source` / `target` は **`from` 側の状態**の添字で書く。
- 座標は 42px 刻みのグリッドに合わせる（既存データと同じ）。**原子どうしは20px以上離す**。
  2分子を並べるので、上下または左右に十分な間隔（3グリッド＝126px 程度）を取ること。

## 検査（これが合格の定義）

リポジトリのルートで:

```bash
node tools/verify-reactions.js
```

- 終了コード 0 で `✅ 不合格の問題はありません` なら合格。
- `△ 警告` に「状態Nはどの手順にも出てきません」が出たら、その状態は画面に出ない＝
  手順のつなぎ方が間違っているので直すこと。
- よく出るエラーと意味:
  - `状態0 と 状態N で ◯ の数が違います` … 原子を足した/消した。機構では原子は保存される。
    **水が脱離しても原子は消さない**（離れた位置に移動させるだけ）
  - `電荷の合計が違います` … H⁺ を消した、または `charge` の付け替えを忘れた。
    全状態で合計 +1 になるはず（触媒の H⁺ が1個ある）
  - `原子N(C+) の結合が 4 本（上限 3）` … 電荷と結合数が矛盾している
  - `矢印Nの source が「状態Mに無い結合」を指しています` … `bond` で指した結合が
    その状態に無い。`from` 側の状態を見て添字を確認する
  - `原子N と 原子M が近すぎます` … 2分子の間隔が足りない

## 守ってほしいこと

- **`assembler/reactions.json` 以外のファイルは触らない。**
- **ファイルは UTF-8（BOMなし）で保存する。** 過去に文字化け事故がある。
  保存後に `縺` `繧` `繝` `蜊` `荳` `邨` が混ざっていないか確認すること。
- **改行コードとインデントの流儀を既存に合わせる**（ファイル全体が書き換わると差分が読めない）。
- `git commit` / `git push` は**しない**。差分を残したまま報告してよい。
- 迷ったら**手順を増やさず3手順で作る**。細かすぎる機構は教材として読みにくい。

## 報告してほしいこと

1. `node tools/verify-reactions.js` の出力（全文）
2. 各手順の caption（解説文）をそのまま貼る ← 化学の説明として妥当かをこちらで見ます
3. 判断に迷った点
