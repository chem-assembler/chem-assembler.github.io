# 高校化学が正面から扱わない知識の目録（作問時の注意台帳）

高校の教科書が **意図的に単純化している／出題を避けている／説明を省いている** 事項を集める。
一問一答の作問では、ここに載っている事項を**うっかり「正しい断定」として書かない**ようにする。

## なぜ要るか

教科書の単純化には理由がある（初学者には機械的な規則のほうが速い）。だが作問する側が
単純化を**事実だと思い込む**と、知っている学習者ほど落とす設問ができる。実際に起きた事故:

- 「エーテルは無極性」… 教科書の言い回しをそのまま書いたが誤り（→ [C-1](#c-1)）
- 「臭素水の脱色は不飽和結合の検出だから、アルデヒドは脱色しない」… 誤り（→ [A-2](#a-2)）

**扱い方の分類**（各項目の「一問一答での扱い」欄で使う）:

| 記号 | 意味 |
|---|---|
| **避ける** | 出題そのものを作らない。触れると初学者を混乱させ、正確に書くと範囲外になる |
| **機械的に教える** | 教科書どおりの単純な規則で出題してよい。ただし**断定の言い回しに気をつける** |
| **補足で触れる** | 選択肢では問わず、`supplement` で一言だけ添える |
| **条件を明記** | 出題してよいが、成立条件（炭素数・液性・温度など）を必ず書く |

## A. 検出反応の「陽性・陰性」が実は単純でないもの

### A-1. キサントプロテイン反応とフェニルアラニン

- **教科書の言い方**: 「ベンゼン環をもつアミノ酸（フェニルアラニン・チロシン・トリプトファン）は
  キサントプロテイン反応で黄色を呈する」
- **実際**: キサントプロテイン反応はベンゼン環の**ニトロ化**なので、環が活性化されているかで
  反応性が大きく違う。**チロシン**（ヒドロキシ基あり）と**トリプトファン**（インドール環）は
  よく反応するが、**フェニルアラニン**の環は活性化基をもたず、通常の条件ではほとんど呈色しない
- **なぜ教科書がぼかすか**: 置換基効果（配向性・活性化）はニトロ化の理解が要り、
  タンパク質の単元では扱えないため
- **一問一答での扱い**: **避ける**（個々のアミノ酸名を挙げて陽性・陰性を問わない）。
  設問は「タンパク質にベンゼン環をもつアミノ酸が含まれていると呈色する」までにとどめ、
  **フェニルアラニンを正解肢にも誤答肢にも使わない**。名前を挙げるならチロシン・トリプトファン
- **点検は flip と choice の両方を見る**。実際に choice だけ直して**めくりの答えに
  「チロシン・フェニルアラニンなど」が残っていた**（2026-08-05 修正）
- 関連コード: `org.bio.xanthoproteic`

### A-2. 臭素水の脱色は「不飽和結合の検出」だけではない

- **教科書の言い方**: 「臭素水を脱色する＝二重結合・三重結合をもつ」
- **実際**: **アルデヒドも臭素水を脱色する**（臭素に酸化されてカルボン酸になる。
  $\text{CH}_3\text{CHO} + \text{Br}_2 + \text{H}_2\text{O} \to \text{CH}_3\text{COOH} + 2\text{HBr}$）。フェノールも臭素水と置換反応して脱色し、
  さらに白色沈殿を生じる
- **一問一答での扱い**: **条件を明記**。「アルケンとアルカンの区別」のように**飽和炭化水素との
  対比**で使う。**アルデヒドやフェノールを選択肢に混ぜた「脱色するのはどれか」は作らない**
- 実際に事故になった: `org.carbonyl.ketone-no-reduce` で「臭素水ではアセトンとアセトアルデヒドを
  区別できない」と書いたが、実際は区別できてしまう（2026-08-05 修正済み）

### A-3. 塩化鉄(III) の呈色は化合物ごとに色が違う

- **教科書の言い方**: 「フェノール類は塩化鉄(III)水溶液で青紫〜赤紫に呈色する」
- **実際**: 色は化合物で大きく違う（フェノール＝紫、クレゾール＝青、サリチル酸＝赤紫、
  カテコール＝緑）。濃度や pH でも変わる
- **なぜ教科書がぼかすか**: 錯体の構造の話になり範囲外。検出としては「色がつくか」だけが要点
- **一問一答での扱い**: **条件を明記**。個々の色を正解肢に置くのは教科書に載る対
  （フェノール＝紫、サリチル酸＝赤紫）にとどめ、**色そのものを正誤の判定点にしない**
- 関連コード: `org.phenol.fecl3` / `org.aroN.salicylic`

### A-4. フェーリング液は塩基性でないとはたらかない

- **教科書の言い方**: 「フェーリング液を加えて加熱すると赤色沈殿」
- **落とし穴**: **希硫酸で加水分解した直後の液は酸性**なので、そのまま加えても沈殿しない。
  **中和してから**加える必要がある。二糖の加水分解 → 還元性の確認、という流れで問われる定番
- **一問一答での扱い**: **条件を明記**（2026-08-05 修正済み: `org.bio.invert-sugar`）

### A-5. フェーリング液の還元はアルデヒドだけではない（およびギ酸での陰性事故）

- **教科書の言い方**: 「フェーリング液を還元する＝アルデヒド（ホルミル基をもつ）」
- **実際**: 
  1. $\alpha$-ヒドロキシケトン（フルクトースなど）も塩基性下で異性化して陽性になる。
  2. **ギ酸 HCOOH は教科書上還元性ありとされるが、通常のフェーリング反応は陰性（沈殿が出ない）になる**。強塩基性のフェーリング液中でギ酸イオン $\text{HCOO}^-$ が $\text{Cu}^{2+}$ と安定なキレート錯体を形成し還元が阻害されるため。
- **一問一答での扱い**: **補足で触れる / 条件を明記**。
  アルデヒドの単元では「ホルミル基をもつものは陽性」と書き、「陽性なら必ずホルミル基」という逆は書かない。
  また**「フェーリング陽性の物質」の正解肢としてギ酸を選ばない**（銀鏡反応陽性の例として使用する）。
- 関連コード: `org.bio.fructose` / `org.carbonyl.formic-reducing`

## B. 還元性の「何に変わるか」が説明されないもの

### B-1. ギ酸の還元性

- **教科書の言い方**: 「ギ酸は分子中にホルミル基の構造をもつので還元性を示す」
- **説明されないこと**: **還元性を示した結果ギ酸が何になるか**。答えは**二酸化炭素 $\text{CO}_2$**
  （$\text{HCOOH} \to \text{CO}_2 + 2\text{H}^+ + 2e^-$）。ふつうのアルデヒドは酸化されてカルボン酸になるが、
  ギ酸はすでにカルボキシ基なので、酸化されると炭素が最高酸化数（+4）になり $\text{CO}_2$ として抜ける
- **入試での扱い**: 生成物を問う出題は**避けられている**。「還元性を示す」ことだけが問われる
- **一問一答での扱い**: **機械的に教える**（初学者には「ギ酸は還元性あり」で十分）。
  生成物は**補足で触れる**にとどめ、選択肢では問わない。なおフェーリング反応は上記の通り錯体形成のため実質陰性となる。
- 関連コード: `org.carbonyl.formic-reducing`

### B-2. ギ酸エステルの還元性

- **教科書の言い方**: 触れない
- **実際**: ギ酸エステル $\text{HCOOR}$ も $\text{H-C(=O)-}$ の構造をもつので還元性を示す
  （銀鏡反応陽性）。ギ酸メチル・ギ酸エチルが該当する
- **なぜ落とし穴か**: 「エステルは還元性を示さない」と機械的に覚えていると誤る。
  また構造決定で「銀鏡反応陽性 → アルデヒドかギ酸」と絞ると、ギ酸エステルを落とす
- **一問一答での扱い**: **補足で触れる**。エステルの単元で「ギ酸エステルだけは例外」と
  一言添える。難関向けに独立項目にするかは要検討（Lv4 候補）
- 関連コード: `org.carbonyl.ester-bond`（補足追記の候補）／`org.carbonyl.formic-reducing`

## C. 「無極性」「極性」の雑な使い方

<a id="c-1"></a>
### C-1. エーテルは無極性ではない

- **教科書の言い方**: 「エーテルは無極性で水に溶けにくく、沸点が低い」
- **実際**: エーテルの $\text{C-O-C}$ は折れ線なので双極子が打ち消されず、**ジエチルエーテルの
  双極子モーメントは約 1.15 D**（エタノールは約 1.69 D）。無極性ではない
- **正しい理由づけ**: 沸点が低いのも水に溶けにくいのも、**分子間で水素結合をつくらない**
  （$\text{O-H}$ をもたない）ことによる
- **一問一答での扱い**: **「無極性」と書かない**。理由は水素結合で説明する
- 2026-08-05 修正済み: `org.alcohol.ether-props` / `ether-diethyl` / `org.bio.monosaccharide`
- なお **アルカン・メタン・ベンゼンを「無極性」と書くのは正しい**（対称性で打ち消される）

## D. 成立条件が落ちやすい規則

### D-1. アルコールの沸点「1級＞2級＞3級」

- **成立条件**: **炭素数が同じとき**の比較。炭素数が違えば分子量の効果が上回る
  （メタノール 64.7℃ ＜ 2-メチル-2-プロパノール 82.4℃）
- **一問一答での扱い**: **条件を明記**（2026-08-05 修正済み: `org.alcohol.bp`）

### D-2. アルコールとエーテルは「互いに構造異性体」

- **成立条件**: **炭素数が同じとき**。メタノール $\text{CH}_4\text{O}$ とジエチルエーテル $\text{C}_4\text{H}_{10}\text{O}$ は異性体ではない。
  また一般式 $\text{C}_n\text{H}_{2n+2}\text{O}$ が当てはまるのは**鎖状飽和**のもの（シクロヘキサノールは $\text{C}_n\text{H}_{2n}\text{O}$）
- **一問一答での扱い**: **条件を明記**（2026-08-05 修正済み: `org.alcohol.formula`）

### D-3. アルカンの状態「C5以上は液体」

- **成立条件**: **C18 以上は固体**。「C5 以上は液体」と書くと C18 以上と矛盾する
- **一問一答での扱い**: **条件を明記**（2026-08-05 修正済み: `org.ali.alkane-state`）

### D-4. 「フェノール類は炭酸より弱い酸」— ピクリン酸やサリチル酸は例外

- **教科書の言い方**: 「酸の強さは カルボン酸 ＞ 炭酸 ＞ フェノール類」
- **実際**: 
  - **ピクリン酸（2,4,6-トリニトロフェノール）は $pKa \approx 0.38$ の強酸**で、炭酸どころか多くのカルボン酸より強い（硝酸並み）。ニトロ基の強い電子求引性と共鳴効果による。
  - **サリチル酸（$pKa \approx 2.97$）** はフェノール性水酸基とカルボキシ基を併せ持ち、アニオンの分子内水素結合により安息香酸よりも強酸である。
- **一問一答での扱い**: **条件を明記**。序列を書くときは主語をフェノール・クレゾール・ナフトールのように具体化する。**ピクリン酸やサリチル酸を「炭酸水素ナトリウムと反応しない物質」として混入させない**
- 関連コード: `org.phenol.acidity` / `org.phenol.weaker-than-carbonic` / `org.phenol.picric`

### D-5. フェノールのニトロ化は濃硝酸だけでは進まない

- **教科書の言い方**: 「フェノールを濃硝酸でニトロ化するとピクリン酸が得られる」と書く本がある
- **実際**: 濃硝酸だけだとフェノールが酸化されてタール化し、トリニトロ化まで進まない。
  **濃硝酸と濃硫酸の混合物（混酸）**を使う
- **一問一答での扱い**: **条件を明記**（2026-08-05 修正済み: `org.phenol.picric`）

### D-6. 不飽和脂肪酸が「折れ曲がる」のはシス型のとき

- **教科書の言い方**: 「不飽和脂肪酸は二重結合のところで折れ曲がるので分子が密に並べず融点が低い」
- **実際**: 折れ曲がるのは**シス型**のとき。トランス型（トランス脂肪酸）は直鎖に近く融点も高い。
  天然の油脂はほぼシス型なので結論は正しいが、「二重結合があれば折れ曲がる」という因果は成り立たない
- **一問一答での扱い**: **補足で触れる**（「天然の油脂の二重結合はシス型」と一言）。
  シス・トランスの区別を選択肢では問わない
- 関連コード: `org.fat.solid-liquid` / `org.fat.hardening`

### D-7. アセチレンの製法

- **教科書の言い方**: 実験室では炭化カルシウム＋水。**工業的にはメタンの熱分解**（約1500℃）
- **落とし穴**: 設問で「製法」とだけ書くと、工業的製法を知っている学習者には
  「メタンを加熱して生じる」も正しくなる
- **一問一答での扱い**: **条件を明記**（設問に「実験室的製法」と書く。2026-08-05 修正済み:
  `org.ali.acetylene-prep`）

## E. 仕組みの説明が範囲外のもの（結論だけ教える）

<a id="e-2"></a>

これらは**結論を機械的に覚えるのが正しい**。理由を問う設問を作らない。

| 事項 | 教科書が省く理由 | 一問一答での扱い |
|---|---|---|
| マルコフニコフ則（H は水素の多い炭素へ） | カルボカチオンの安定性が範囲外 | **機械的に教える**。理由は問わない |
| ザイツェフ則（水素の少ない炭素から H がとれる） | 同上 | **機械的に教える** |
| フェノールがアルコールより酸性が強い理由 | 共鳴による陰イオンの安定化が範囲外 | **機械的に教える**。序列だけ覚える |
| ベンゼンの結合がすべて同等な理由 | 共鳴・非局在化が範囲外 | 「単結合と二重結合の中間」で止める |
| ヨウ素デンプン反応の呈色の仕組み | らせん内部への包接が範囲外 | 色と条件（加熱で消え冷やすと戻る）だけ |
| フェノールが臭素水と触媒なしで反応する理由 | ヒドロキシ基の活性化・配向性が範囲外 | **機械的に教える**。「置換されやすい」で止める |

## F. 名前が実態とずれているもの

| 事項 | ずれ | 扱い |
|---|---|---|
| ニトログリセリン | 名前は「ニトロ」だが**ニトロ化合物ではなく硝酸エステル**（$\text{C-O-NO}_2$ 結合） | **補足で触れる**（`org.carbonyl.inorganic-ester` で対応済み） |
| ニトロセルロース | 同上。ヒドロキシ基の硝酸エステル化であってニトロ化ではない | **補足で触れる**（`org.bio.nitrocellulose` で対応済み） |
| 無水酢酸 | 「無水」は水を含まない意味ではなく**水がとれた形**。酸性を示さない | **補足で触れる**（`org.carbonyl.acetic-anhydride-props` で対応済み） |
| 氷酢酸 | 水溶液ではなく**純度の高い酢酸そのもの** | 誤答肢として活用（`org.carbonyl.acetic` で対応済み） |
| 高級脂肪酸の「高級」 | 品質ではなく**炭素数が多い**こと | 誤答肢として活用（`org.carbonyl.fatty-acid` で対応済み） |

## G. 理論化学分野での意図的単純化・隠された前提

### G-1. 新課程における「エンタルピー変化 ($\Delta H$)」表記への移行と符号の逆転

- **教科書の言い方**: 旧課程では「熱化学方程式」として $C(\text{固}) + O_2(\text{気}) = CO_2(\text{気}) + 394\text{ kJ}$ （右辺プラスが発熱）と表記していた
- **実際**: 2022年度新学習指導要領より、国際標準の化学反応式＋エンタルピー変化表記へ全面的に移行した。
  $$C(\text{固}) + O_2(\text{気}) \to CO_2(\text{気}) \quad \Delta H = -394\text{ kJ/mol}$$
  **発熱反応では $\Delta H < 0$（系のエネルギー減少）、吸熱反応では $\Delta H > 0$** となり、旧記法と符号が逆になる
- **なぜ教科書が変わったか**: 旧来の「熱化学方程式（等号 $=$ で結び熱を右辺に書く）」は日本独自のガラパゴス記法であり、大学化学や国際標準（IUPAC）と矛盾していたため
- **一問一答での扱い**: **条件を明記 / 記法統一**。旧過去問の移植時に「発熱＝プラス」と誤記しないよう徹底チェックする

### G-2. 強酸の無限希釈（極稀薄溶液）での pH

- **教科書の言い方**: $pH = -\log_{10}[H^+]$。例えば $10^{-5}\text{ mol/L}$ の塩酸を水で1000倍に薄めると $10^{-8}\text{ mol/L}$ になり $pH = 8$ になる
- **実際**: **酸をどれだけ薄めても塩基性（$pH > 7$）になることは絶対にない**。
  $10^{-8}\text{ mol/L}$ のような極稀薄溶液では、水の自動電離 $\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-$ による $\text{H}^+$（約 $10^{-7}\text{ mol/L}$）を無視できず、厳密な電離平衡計算を行うと $pH \approx 6.98$ となる
- **一問一答での扱い**: **避ける**。極稀薄溶液での pH 計算を出題しない。通常濃度範囲（$10^{-1} \sim 10^{-5}\text{ mol/L}$）に限定する

### G-3. 弱酸の電離度 $\alpha$ とオストワルト希釈律の限界

- **教科書の言い方**: 「弱酸の電離度 $\alpha = \sqrt{\frac{K_a}{c}}$。濃度 $c$ が小さいほど電離度 $\alpha$ は大きくなる」
- **実際**: $\alpha = \sqrt{\frac{K_a}{c}}$ は $\alpha \ll 1$ のときのみ成り立つ近似式である。濃度 $c \to 0$ の極限では、弱酸であっても電離度 $\alpha \to 1$（完全電離）に近づくため、この近似式を極稀薄溶液に適用すると $\alpha > 1$ になってしまい破綻する
- **一問一答での扱い**: **条件を明記**。「$\alpha \ll 1$ とみなせる場合」などの但し書きを設問または解説に付記する

### G-4. 12族元素（Zn, Cd, Hg）の分類

- **教科書の言い方**: 昔の参考書・教科書では3〜12族を「遷移元素」とまとめることがあった
- **実際**: 現代の IUPAC および新課程教科書では、**12族（Zn, Cd, Hg）は「典型元素」**に分類される。12族元素は d軌道が完全に満たされており（$d^{10}$）、遷移元素に特徴的な「不完全な d軌道による多様な酸化数や呈色錯イオン」を示さず、最外殻の s電子のみが化学性質を支配するため
- **一問一答での扱い**: **条件を明記**。「遷移元素は3〜11族」として出題し、亜鉛 Zn を遷移元素の例として扱わない

### G-5. 王水が金を溶かす真の理由（単なる強酸ではない）

- **教科書の言い方**: 「王水（濃硝酸と濃塩酸を 1:3 で混合した液体）は強い酸化力と酸性をもつため金や白金を溶かす」
- **実際**: 金 $\text{Au}$ は濃硝酸の酸化力だけではほとんど溶けない。濃塩酸から供給される高濃度の塩化物イオン $\text{Cl}^-$ が金(III)イオンと非常に安定な錯イオン **テトラクロリド金(III)酸イオン $[\text{AuCl}_4]^-$** を形成するため、水酸化・イオン化平衡が右に強く偏り、酸化還元電位が下がって溶解が進行する。
  $$\text{Au} + \text{HNO}_3 + 4\text{HCl} \to \text{H}[\text{AuCl}_4] + \text{NO} + 2\text{H}_2\text{O}$$
- **一問一答での扱い**: **補足で触れる**。王水の組成（濃硝酸:濃塩酸 = 1:3、「一硝三塩」）を問う設問を中心とし、「強酸だから溶ける」という表現は避け、錯イオン形成が本質であることを補足に書く

### G-6. ボルタ電池の分極（起電力低下）の真の理由

- **教科書の言い方**: 「正極の銅板表面に発生した水素ガスの気泡が銅板を覆い、電流の流れを物理的に邪魔する（分極）」
- **実際**: 水素気泡による物理的遮断は主因ではない。銅極上で $\text{H}^+$ が還元されて $\text{H}_2$ になる反応には大きな**過電圧（overpotential）**が必要であり、発生した $\text{H}_2$ による逆電位（逆起電力）の発生や正極付近の $\text{H}^+$ 濃度の低下によって、銅極の電位が極化（低下）することが主因である。減極剤（酸化剤：$\text{H}_2\text{O}_2$ や $\text{K}_2\text{Cr}_2\text{O}_7$）を加えるのは過電圧を抑えて $\text{H}_2$ を酸化消滅させるため
- **一問一答での扱い**: **機械的に教える**。高校レベルの表現「水素の発生による分極（起電力低下）」に沿って出題するが、「気泡が絶縁体になるから」という誤った物理的断定を避ける

### G-7. ヘンリーの法則の適用限界

- **教科書の言い方**: 「一定温度で一定量の液体に溶ける気体の質量は、その気体の分圧に比例する」
- **実際**: ヘンリーの法則が成り立つの：**水に溶けにくい気体（$\text{O}_2, \text{N}_2, \text{H}_2, \text{CO}_2$ など）**かつ**高圧すぎない条件**に限られる。
  アンモニア $\text{NH}_3$ や塩化水素 $\text{HCl}$ のように、水と化学反応して電離する気体にはヘンリーの法則は直接適用できない（水酸化物イオンやヒドロニウムイオンになって大量に溶けるため）
- **一問一答での扱い**: **条件を明記**。ヘンリーの法則の計算問題で対象とする気体を酸素や窒素にし、アンモニアや塩化水素を計算対象に混ぜない

## H. 無機化学分野での意図的単純化・隠された前提

### H-1. クロム酸イオンと二クロム酸イオンの液性平衡（酸化還元との混同）

- **教科書の言い方**: 「クロム酸カリウム（黄色）水溶液に酸を加えると二クロム酸カリウム（橙赤色）に変わる」
- **実際**: この反応 $2\text{CrO}_4^{2-} + 2\text{H}^+ \rightleftharpoons \text{Cr}_2\text{O}_7^{2-} + \text{H}_2\text{O}$ は**酸化還元反応ではない**。
  $\text{CrO}_4^{2-}$ においても $\text{Cr}_2\text{O}_7^{2-}$ においても、クロムの酸化数はどちらも **$+6$** のままであり、単なる酸塩基・脱水縮合平衡である
- **一問一答での扱い**: **条件を明記**。「酸化還元反応の例」としてこの色変化を選ばせない。「液性（pH）による平衡移動」として問う

### H-2. 濃硫酸の作用（「熱濃硫酸」と「冷濃硫酸」）

- **教科書の言い方**: 「濃硫酸は酸化作用をもつ」
- **実際**: 濃硫酸が酸化作用を示すのは**加熱したとき（熱濃硫酸）**のみである。
  例：$\text{Cu} + 2\text{H}_2\text{SO}_4(\text{熱濃}) \to \text{CuSO}_4 + 2\text{H}_2\text{O} + \text{SO}_2 \uparrow$
  常温の濃硫酸（冷濃硫酸）は酸化力が極めて弱く、またアルミニウム $\text{Al}$ や鉄 $\text{Fe}$、ニッケル $\text{Ni}$ などとは不動態を形成して反応が止まる
- **一問一答での扱い**: **条件を明記**。銅や銀と反応させて $\text{SO}_2$ を発生させる反応では、必ず「加熱した濃硫酸（熱濃硫酸）」と明記する

### H-3. 過酸化水素 $\text{H}_2\text{O}_2$ の還元剤としての反応相手

- **教科書の言い方**: 「過酸化水素は通常酸化剤として働くが、強い酸化剤に対しては還元剤として働く」
- **実際**: 還元剤として働く相手は極めて限定的である。高校化学で出題される相手は実質的に **過マンガン酸カリウム $\text{KMnO}_4$** と **オゾン $\text{O}_3$**（および二クロム酸カリウムの一部条件）のみである。相手の酸化剤の標準電位が $\text{H}_2\text{O}_2 \to \text{O}_2 + 2\text{H}^+ + 2e^-$ （$+0.695\text{ V}$）より高い場合のみ還元剤となる
- **一問一答での扱い**: **機械的に教える / 条件を明記**。「過酸化水素が還元剤として働く例」として過マンガン酸カリウム以外の一般的な酸化剤を安易に選択肢に混ぜない

## I. 有機化学・高分子化学分野での追加・隠された前提

### I-1. ヨードホルム反応を示す構造の厳密な条件（酢酸やエステルが陰性の理由）

- **教科書の言い方**: 「$\text{CH}_3-\text{CO}-\text{R}$ または $\text{CH}_3-\text{CH(OH)}-\text{R}$ の構造をもつ化合物がヨードホルム反応を示す」
- **実際**: $\text{R}$ が $-\text{OH}$（酢酸）や $-\text{O-R'}$（酢酸エステル）、$-\text{NH}_2$（アセトアミド）などの場合、ヨードホルム反応条件の強塩基（$\text{NaOH}$）により即座に酸塩基中和が起こりカルボキシラートアニオン（$\text{CH}_3\text{COO}^-$）となる。アニオン状態では負電荷がカルボニル酸素に非局在化して安定化するため、α位の炭素からさらに水素を引き抜いてエノラートアニオン（$\text{^-CH}_2\text{COO}^-$）を生成することが電気的に不可能となり、反応が全く進行しない
- **一問一答での扱い**: **条件を明記**。構造の定義として「$\text{R}$ は $\text{H}$ または炭化水素基」であることを明確にし、酢酸や酢酸エチルをヨードホルム反応陽性の選択肢に絶対に入れない

### I-2. セルロースのヒドロキシ基と反応性（硝酸エステル化・酢酸エステル化）

- **教科書の記述**: 「セルロースの分子中には無水グルコース単位あたり3個のヒドロキシ基があり、これをエステル化できる」
- **実際**: セルロースは分子間・分子内で非常に強固な**水素結合**を形成しており、結晶領域（ミセル領域）では試薬が侵入できずヒドロキシ基が反応しない。そのため、硝酸エステル化（ニトロセルロース合成）やアセチル化（トリアセチルセルロース合成）を行う際は、まず膨潤させたり非晶領域から不均一系で反応を進めたりする必要がある。完全なトリアセチル化は困難であり、一度ジアセチル化状態へ加水分解調整（アセテートレーヨン）される
- **一問一答での扱い**: **補足で触れる**。一問一答では「グルコース単位あたり3個の $-\text{OH}$」という計算モデルで出題してよいが、反応性の高さについては補足で触れるにとどめる

### I-3. アミノ酸の等電点と緩衝作用の平易化

- **教科書の記述**: 「等電点ではアミノ酸分子全体が双性イオン（両性イオン）となり、電荷が 0 になる」
- **実際**: 等電点（$\text{pI}$）とは、**溶液中に存在する 陽イオン・双性イオン・陰イオン の全体の平均電荷が 0 になる pH** のことであり、すべての分子が $100\%$ 双性イオンになっているわけではない（水酸化物イオンや水素イオンの電離平衡に従い、わずかに陽イオンや陰イオンも平衡存在している）
- **一問一答での扱い**: **機械的に教える**。一問一答では「分子全体として電荷が 0 になる pH」と定義し、ミリ単位の平衡組成までは問わない
