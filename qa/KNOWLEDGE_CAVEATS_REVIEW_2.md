## 1. 未調査2件の決着（優先対応）

### 1-1. 「エーテルは反応しない」（C章追記候補）

- **教科書の言い方**: 「エーテルは化学的に極めて安定で、反応性が低く、金属ナトリウムとも反応しない」
- **実際**: 
  1. **強酸によるC−O結合の切断（エーテル開裂）**: 濃ヒドヨウ酸（HI）や濃臭素酸（HBr）と加熱すると、C−O結合が切れアルキルハロゲン化物とアルコール（またはフェノール）が生じる。
     例: $\text{R-O-R'} + \text{HI} \to \text{R-I} + \text{R'-OH}$
  2. **空気酸化による過酸化物の生成**: エーテル（特にジエチルエーテルやテトラヒドロフラン）を空気・光に晒しておくと、α位のC−H結合がラジカル酸化されて危険な有機過酸化物（Peroxide）が生成し、蒸留濃縮時に爆発事故を起こす。
- **なぜ教科書がぼかすか**: 酸による親核置換反応（$S_N1, S_N2$機構）や自由ラジカル自動酸化の機構が高校範囲を超えているため。
- **一問一答での扱い**: **条件を明記 / 補足で触れる**。
  - 出題では「アルコールと異なり金属ナトリウムと反応して水素を発生しない」「化学的に安定で有機溶媒として用いられる」という高校範囲の文脈で出題してよい。
  - ただし「いかなる試薬とも絶対に反応しない」という絶対的断定の選択肢は作らない。
  - 保存上の注意（褐色瓶での保存、空気に触れさせない等）は補足（`supplement`）で触れる。
- **参考資料の記載**: 『化学新研究』のコラム「エーテルの反応性と危険性・保存法」
- **関連コード**: `org.alcohol.ether-props` / `org.alcohol.ether-diethyl`

### 1-2. ケトン・アルデヒドの還元（E章追記候補）

- **教科書の言い方**: 入試では具体名のない「還元剤」または「還元」という語のみが示され、アルデヒドを還元すると1級アルコール、ケトンを還元すると2級アルコールになり、**必ず酸化前の化合物に素直に戻るパターン**しか登場しない。
- **実際**: 
  1. **酸化前のアルコールに戻る還元**: 白金・ニッケル触媒による水素化（$\text{H}_2/\text{Ni}$）や、水素化ホウ素ナトリウム（$\text{NaBH}_4$）、水素化アルミニウムリチウム（$\text{LiAlH}_4$）等のヒドリド還元剤を用いる場合、カルボニル基が還元されて対応するアルコールに戻る。
  2. **カルボニル基が完全に消滅する還元**: 強酸性下の亜鉛アマルガム（クレメンゼン還元）や塩基性下のヒドラジン（ウォルフ・キシュナー還元）を用いると、カルボニル基 $\text{C=O}$ はメチレン基 $\text{-CH}_2\text{-}$ まで完全還元される。
  3. **カルボン酸やエステルの還元**: 高校では「カルボン酸やエステルは還元されない」ように扱われるが、$\text{LiAlH}_4$ を用いるとエステルやカルボン酸も1級アルコールへ還元できる。
- **なぜ教科書がぼかすか**: 還元試薬の化学選択性（$\text{NaBH}_4$ はエステルを還元しないがアルデヒド/ケトンは還元するなど）や反応機構が未履修範囲のため。
- **一問一答での扱い**: **機械的に教える**。
  - 一問一答では「アルデヒドの還元→1級アルコール」「ケトンの還元→2級アルコール」として機械的に教え・問うてよい（初学者への導入として正しい）。
  - ただし「カルボン酸は化学的に絶対に還元できない」といった誤った断定を選択肢に混ぜない。
- **参考資料の記載**: 『化学新研究』のコラム「カルボニル化合物の還元と還元剤の種類」 / 『ハート有機化学』
- **関連コード**: `org.alcohol.oxidation` / `org.carbonyl.aldehyde-oxidation` / `org.carbonyl.ketone-no-reduce`

## 2. 新規追記項目（高校参考書のコラム・大学教科書の比較より）

### 2-1. フルクトースがケトンでありながらフェーリング液・銀鏡反応を示す理由（A章追記）

- **教科書の言い方**: 「フルクトースはケトン基（カルボニル基）をもつが、還元性を示す」
- **実際**: フルクトースは $\alpha$-ヒドロキシケトン構造をもつ。弱塩基性のフェーリング液やアンモニア性硝酸銀水溶液中では、塩基の作用によってエンジオール中間体を経由する異性化平衡（ロブリー・ドブリュイン＝ファン エケンシュタイン転位）が起こり、一部がグルコースやマンノースなどのアルデヒド構造に変化するため還元性を示す。中性〜酸性溶液中ではこの転位が起こらないため還元性を示さない。
- **なぜ教科書がぼかすか**: ケト-エノール転位およびエンジオール経由の異性化平衡の機構が高校化学の範囲外であるため。
- **一問一答での扱い**: **補足で触れる / 条件を明記**。
  - 「フルクトースは還元性を示す」ことは事実として出題してよい。
  - 「フルクトースが直接フェーリング液を還元する」のではなく「塩基性下でアルデヒドに構造変化するため」であることを補足に書く。
- **参考資料の記載**: 『化学新研究』コラム「フルクトースの還元性の謎」 / 『総合的研究化学』
- **関連コード**: `org.bio.fructose` / `org.carbonyl.fehling`

### 2-2. アニリンがアンモニアより弱塩基である理由（E章追記）

- **教科書の言い方**: 「アニリンは水に少し溶けてごく弱い塩基性を示す（アンモニアより弱い塩基）」
- **実際**: アンモニアの $pK_b \approx 4.75$ に対し、アニリンの $pK_b \approx 9.37$ であり、アニリンの塩基性はアンモニアより約1万倍弱い。これは、アミノ基の非共有電子対がベンゼン環の $\pi$ 電子系と共鳴・非局在化するため、プロトン（$\text{H}^+$）を受け取る能力（塩基性）が著しく低下することによる。
- **なぜ教科書がぼかすか**: アニリンの共鳴構造および $\pi$ 電子非局在化の説明が高校範囲外のため。
- **一問一答での扱い**: **機械的に教える**。
  - 塩基性の強さの序列「脂肪族アミン ＞ アンモニア ＞ 芳香族アミン（アニリン）」は暗記事項として扱ってよいが、電子論的な共鳴の理由までは問わない。
- **参考資料の記載**: 『化学新研究』コラム「芳香族アミンの塩基性が弱い理由」
- **関連コード**: `org.aroN.aniline-base`

### 2-3. サリチル酸のアセチル化に無水酢酸を用い、酢酸を用いない理由（D章追記）

- **教科書の言い方**: 「サリチル酸に無水酢酸を作用させると、フェノール性ヒドロキシ基がアセチル化されてアセチルサリチル酸ができる」
- **実際**: フェノール類のヒドロキシ基は、アルコールのヒドロキシ基に比べて求核性が低く（ベンゼン環との共鳴のため）、普通のカルボン酸（酢酸）とのエステル化反応は平衡が極度に左に偏り実質的に進行しない。そのため、より反応性の高い酸無水物（無水酢酸）や酸塩化物（塩化アセチル）を用いる必要がある。
- **なぜ教科書がぼかすか**: 芳香族ヒドロキシ基の求核性の低さと酸無水物の高いアシル化能力の差が未履修のため。
- **一問一答での扱い**: **条件を明記**。
  - サリチル酸からアスピリンをつくる試薬として「無水酢酸」を正解とし、「酢酸との反応」を選択肢として混入させない。
- **参考資料の記載**: 『入試化学要点&盲点』 / 『化学新研究』コラム「フェノールのエステル化と無水酢酸」
- **関連コード**: `org.aroN.aspirin` / `org.carbonyl.acid-anhydride`

### 2-4. 側鎖をもつアルキルベンゼンの酸化（過マンガン酸カリウムによる酸化の条件）（D章追記）

- **教科書の言い方**: 「トルエンやエチルベンゼンなどの側鎖をもつアルキルベンゼンを $\text{KMnO}_4$ で酸化すると、安息香酸が生じる」
- **実際**: 側鎖の炭素鎖がどれだけ長くても（例: プロピルベンゼン）、ベンゼン環に直結した炭素（$\alpha$炭素）に水素原子が1つ以上結合していれば、側鎖は切断されてすべて安息香酸 $\text{C}_6\text{H}_5\text{COOH}$ になる。ただし、$\alpha$炭素に水素がない *tert*-ブチルベンゼン $\text{C}_6\text{H}_5\text{-C(CH}_3)_3$ は $\text{KMnO}_4$ で酸化されず安息香酸にならない。
- **なぜ教科書がぼかすか**: 側鎖酸化のラジカル引き抜き機構（ベンジル位ラジカルの安定性）が範囲外のため。
- **一問一答での扱い**: **条件を明記**。
  - 通常のアルキル基（メチル基・エチル基）で安息香酸ができる例を出題するが、「すべてのアルキルベンゼンが安息香酸になる」という極端な一般化は避ける。
- **参考資料の記載**: 『化学新研究』コラム「側鎖アルキル基の酸化と安息香酸」
- **関連コード**: `org.aro.sidechain-oxidation`

### 2-5. シス-トランス異性体（マレイン酸・フマル酸等）の融点と沸点の差（D章追記）

- **教科書の言い方**: 「マレイン酸（シス形）は融点が 130℃、フマル酸（トランス形）は融点が 287℃ である」
- **実際**: 
  1. **融点**: トランス形（フマル酸）は分子の対称性が良く結晶格子中に密にパッキングできるため、シス形（マレイン酸）よりも著しく融点が高い。またマレイン酸は分子内水素結合を形成するため、分子間水素結合が弱まり融点が下がる。
  2. **沸点 / 水への溶解度**: シス形は極性が大きく（双極子モーメントをもつ）、水に対する溶解度が大きく沸点も高い。トランス形は極性が相殺されるため水に溶けにくい。
- **なぜ教科書がぼかすか**: 分子の対称性と結晶格子のパッキング、および分子内 vs 分子間水素結合の複合概念が必要なため。
- **一問一答での扱い**: **条件を明記**。
  - マレイン酸（シス）とフマル酸（トランス）の融点・水への溶解度の違いを事実メタデータとして問うのは良いが、単純な「シス型のほうが常に融点が高い」といった誤った解釈を作らない。
- **参考資料の記載**: 『総合的研究化学』 / 『化学新研究』
- **関連コード**: `org.carbonyl.maleic-fumaric` / `org.ali.cis-trans-def`

### 2-6. ヨウ素価の測定でヨウ素 $\text{I}_2$ は直接付加しない（D章追記）

- **教科書の言い方**: 「ヨウ素価＝油脂 100 g に付加するヨウ素 $\text{I}_2$ のグラム数」
- **実際**: 実際には二重結合に対するヨウ素単体 $\text{I}_2$ の付加反応は平衡が著しく左に偏っており、ほとんど進行しない。実験的にはヨウ素よりも反応性の高い一塩化ヨウ素 $\text{ICl}$（ウィイス試薬）または一臭化ヨウ素 $\text{IBr}$ を付加させ、未反応の試薬をヨウ素化カリウムでヨウ素 $\text{I}_2$ として遊離させてチオ硫酸ナトリウムで滴定し、ヨウ素相当量に換算している。
- **なぜ教科書がぼかすか**: 付加反応の可逆性・平衡論および滴定計算の複雑化を防ぐため「ヨウ素が付加する」という計算モデルとして単純化している。
- **一問一答での扱い**: **機械的に教える**。
  - 「ヨウ素 $\text{I}_2$ が付加する」という定義・計算モデルで問うてよい。
- **参考資料の記載**: 『化学新研究』コラム「ヨウ素価の実際の測定法（ウィイス法）」
- **関連コード**: `org.fat.iodine-value`

### 2-7. アミノ酸のニンヒドリン反応でプロリンだけが黄色を呈する理由（A章追記）

- **教科書の言い方**: 「アミノ酸にニンヒドリン水溶液を加えて加熱すると青紫〜赤紫色に呈色する」
- **実際**: 通常の primary アミノ酸（1級アミノ基 $-\text{NH}_2$ をもつもの）はニンヒドリン2分子と反応して「ルーエマン紫（Ruhemann's purple）」と呼ばれる青紫色の色素を形成する。しかし、**プロリン**は環状イミノ酸（2級アミン構造）であるため、異なる色素構造を形成し、**黄色**に呈色する。
- **なぜ教科書がぼかすか**: 1級アミノ酸とイミノ酸の構造の違い、および色素形成反応機構が範囲外のため。
- **一問一答での扱い**: **補足で触れる / 避ける**。
  - 「アミノ酸の検出＝ニンヒドリン反応（青紫〜赤紫）」で統一して出題する。
  - プロリンの黄色呈色を正誤の判定点として出題することは避ける。
- **参考資料の記載**: 『総合的研究化学』 / 『化学新研究』コラム「ニンヒドリン反応とプロリンの例外」
- **関連コード**: `org.bio.ninhydrin` (該当コード無しの場合は `org.bio.amino-acid-def`)

### 2-8. ビスコースレーヨン製造時のセルロースの化学変化（F章追記）

- **教科書の言い方**: 「セルロースを水酸化ナトリウムと二硫化炭素で処理してビスコースとし、希硫酸中に押し出すと再生セルロース（レーヨン）が得られる」
- **実際**: セルロースは単に物理的に溶けて再沈殿しているのではない。水酸化ナトリウムと二硫化炭素によりヒドロキシ基がエステル化（キサントゲン酸エステル化）されて水溶性の**セルロースキサントゲン酸ナトリウム**となり、希硫酸中で加水分解されて元のセルロース構造に戻る（化学再生）。
- **なぜ教科書がぼかすか**: キサントゲン酸エステルの構造と加水分解再生の化学式が複雑なため。
- **一問一答での扱い**: **補足で触れる**。
  - 一問一答では「再生繊維（再生セルロース）」としての分類を中心に問い、化学変化の詳細は補足で触れる。
- **参考資料の記載**: 『化学新研究』コラム「ビスコースレーヨン合成の化学反応」
- **関連コード**: `org.bio.cellulose` / `org.poly.rayon`
