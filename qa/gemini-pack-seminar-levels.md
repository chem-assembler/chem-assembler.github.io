# Gemini 依頼パック: 傍用問題集セミナーの難易度区分を283の知識項目に対応づける

## これは何の作業か

一問一答アプリ `/qa/` の283項目には難易度 **Lv1〜4** が付いているが、**根拠が私の主観**しかない。
これを **傍用問題集『セミナー化学＋化学基礎』のレベル区分**（基本例題／基本問題／発展例題／発展問題）で
客観化する。設計は `qa/DESIGN_difficulty_frequency.md` にある。

**なぜセミナーか**: 難易度を「難しさ」ではなく**受験での位置づけ**で決めたいので、
傍用問題集のレベル区分が直接対応する。重要問題集や新演習は上位層に寄っていて、
Lv1〜2（生存・標準）の線引きに使えない。

**この作業が Gemini に向いている理由**: **有機90ページを通しで読む必要があり、判断は1問ずつ機械的**。
PDF はテキスト抽出が効くことを確認済み（画像PDFではない）。

## 絶対の制約（著作権）

- **問題文・解説文を一切転記しない。** 要約もしない
- 記録するのは「**どのレベル区分に、この知識項目を問う問題があるか**」という**事実メタデータ**だけ
- **問題番号は記録してよい**（事実）。**設問の中身は書かない**
- 出力に問題文の断片が混じっていたら、その行は使えない

> この規則は既存の `化学/問題集/_解析/SCHEMA_問題DB.md` と同じ。統計は著作物の複製ではない、
> という線引きで運用している。**この線を越えないことが受け入れ条件**。

## 作るもの

`qa/data/seminar_map.jsonl` に入れる **1行1問** の JSON。**問題の側から書く**（コードの側からではない）。

```json
{"item": 412, "level": "基本問題", "chapter": 22, "codes": ["org.carbonyl.silver-mirror", "org.carbonyl.fehling"]}
{"item": "基本例題42", "level": "基本例題", "chapter": 22, "codes": ["org.carbonyl.aldehyde-oxidation"]}
```

| フィールド | 中身 |
|---|---|
| `item` | 問題番号。例題は `"基本例題42"` のように区分ごと通し番号のまま文字列で |
| `level` | `基本例題` / `基本問題` / `発展例題` / `発展問題` の**いずれか1つ**（この4語以外を使わない） |
| `chapter` | セミナーの章番号（20〜27） |
| `codes` | **その問題が問うている知識項目コードの配列**。`qa/data/codes_index.md` から選ぶ |

### `codes` の選び方 —— ここが作業の本体

**1問が複数の知識項目にまたがる**のが普通なので、多対多になる。

- **その問題を解くのに必要な知識**を挙げる。**問題文に出てくる語をすべて拾うのではない**
  （例: 酢酸エチルのけん化を問う問題に「エステル」という語が出るが、
  `org.carbonyl.ester-def`（エステルの定義）まで挙げると水増しになる）
- **計算問題は、計算手順の知識項目を挙げる**（元素分析なら `org.anal.*`）
- **どのコードにも当てはまらない問題は `"codes": []` で残す。** 空配列は情報である ＝
  **一問一答に抜けている知識項目**を示している（後で拾う）
- 迷ったら `"note"` フィールドに日本語で理由を書く（任意）

### コード一覧の場所

`qa/data/codes_index.md`（283項目・単元ごとの表）。**この一覧のコードだけを使う**。
無いコードを勝手に作らない（作りたくなったら `codes: []` ＋ `note` に書く）。

## 章ごとに刻んで納品してほしい

90ページを一度に出すと検証できないので、**1章＝1ファイル**で出す。

```
seminar_map_ch20.jsonl
seminar_map_ch21.jsonl
…
seminar_map_ch27.jsonl
```

**まず 21章（脂肪族炭化水素・p257〜）だけを出して止めてください。**
こちらで機械検査（コードが実在するか・level が4語のどれか・問題番号の重複）にかけて、
`codes` の粒度が合っているかを確認してから残りを進めます。**やり直しが8章ぶんになるのを避けたい。**

## あわせて答えてほしい2つの問い（設計の未決事項）

対応表とは別に、**短い所見**として書いてください。

### 問1: 「基本例題」は Lv1（生存）でよいか

例題は解法の提示なので、**知識としては Lv2 相当かもしれない**という疑いがある。
基本例題に出てくる知識が「落とせない最低限」なのか「教科書標準」なのか、
実際に読んだ印象を書いてください。

初期案の対応は次のとおり（**これも検証の対象**）:

| セミナーの区分 | 対応する Lv |
|---|:--:|
| 基本例題 | 1 生存 |
| 基本問題 | 2 標準 |
| 発展例題 | 3 受験標準 |
| 発展問題 | 3〜4（頻度で分ける） |
| どこにも出ない | 4 難関 または 範囲外 |

### 問2: セミナーに出てこない知識項目はどう扱うべきか

283項目のうち、有機8章を読み終えて**一度も出てこなかったコード**の一覧を出してください。
これは2つの意味のどちらかになります。

- **傍用に無いのに入試に出る** → Lv4（難関）が妥当
- **入試にも出ない** → 範囲外（`beyond: true`）の候補

どちらかの判断はこちらでやります（入試側のデータは別にあります）。
**一覧を出すところまで**でお願いします。
