# 選択肢の主語（目的語）の省略 — 洗い出しと直す候補

対象: `qa/questions.json` の `patterns[].variants[]` のうち `mode: "choice"`（**316 問**）。
発端はユーザーの実機報告2件（`org.ali.chirality-def` / `org.ali.isomer-classification`）。

## 判定の基準

**直す**
1. 設問に主語（目的語）の候補が2つ以上あるのに、選択肢がそれを落としている
2. 選択肢が文になっていない（体言止め・言いさし）**かつ**、そのせいで何の話か決まらない
3. **選択肢が他の選択肢を指している**（「〜だから起こる」「この違い」「この反応」）
   — ⚠ `qa/app.js` の `renderChoice` は毎回 `shuffle(v.options...)` で並べ替えるので、
   **指示先の選択肢が上にあるとは限らない**。設問を指す「この実験」は安全、選択肢を指すものは壊れる

**直さない**
- 主語があって読める短文（「鏡像異性体は立体異性体である」）
- 「生成物はエタノール」型の体言止め（主語がある。日本語として自然で、直すと全体で数百件になる）
- 設問が「〜に当てはまるものをすべて選べ」で、選択肢が化合物名のもの（体言が正しい形）

## 迷ったが直さなかったもの

- **`org.ali.unsatur-detection` #2「アセチレンでも起こる」** — 「起こる」は設問の「脱色」を指すので読める。
  ただし**設問（「ものをすべて選べ」＝体言を求める）と選択肢（文）がかみ合っていない**のは別の欠点。今回は触らない
- **`org.ali.homolog` #3「分子式が同じ」** — 設問の主語は「同族体」1つ。読める
- **`org.clue.nitrogen-parity`** — 「分子量が奇数なら窒素の数は奇数」型が5つ並ぶ。
  主語はあり、揃っているので言いさしでも読める
- **`org.bio.amino-acid-polyprotic` #2「…はたらく部分があるため」** — 「段階が増えるのは」と
  主語を先に置いてあるので読める。末尾が「ため」で止まるだけ
- **`org.clue.order` #4「沸点や融点から先に当てにいくのが定石」** — 「である」の省略。読める

## 機械の検査

### 入れたもの

`qa/tests.js`「選択肢: 理由だけを言って結果を言わない肢がない（並べ替えで指し先が消える）」。
文末が `だから起こる|ために起こる|によって起こる|して起こる|ためである|からである` の形なのに、
主題を表す **「は」が1つも無い**肢を赤くする。上の D 型7件すべてを検出することを実測で確かめた
（直す前の文言に戻すと赤くなる）。誤検出は現データで 0 件。

### ⚠ できなかったもの

**「設問に主語が2つ以上あるのに肢が落としている」の一般判定は機械化できなかった。**
案（設問が「A・B について」の形なら全肢が A か B を含む）を実データで走らせたところ、
**12件のうち7件が誤検出**だった。中黒が主語の並びではなかったため:

| 設問 | 中黒が並べているもの |
|---|---|
| C・H・O・N だけからなる化合物について | 元素 |
| 酵素の反応速度と温度・pH の関係について | 観点 |
| 小さな環（三・四員環）のシクロアルカンについて | 数詞 |
| 芳香族炭化水素の側鎖の酸化について（アルケン・アルキンの命名について） | 同じ規則が当てはまる2つ（主語を繰り返すとくどい） |
| 酵素とその基質・生成物の組み合わせについて | 観点 |
| ビニル基・ビニル化合物について | 主語だが、肢が上位語で受けている |
| エノール型・ケト型について | 主語だが、肢が具体例（ビニルアルコール）で答えている |

「中黒が主語を並べているのか観点を並べているのか」を機械で分けられない、というのが理由。
**日本語の「文になっているか」も同様に機械では見られない。** 人の目で読むしかない。
