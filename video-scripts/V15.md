## 1. 画面の流れ（demos.json の5ステップと一致）

| # | 画面（操作） | テロップ（字幕） | ねらい |
|---|---|---|---|
| 1 | 学習タブ → 🎓 クイズに挑戦 → ⏱ 立体タイムアタック。お題（左）と操作する図（右）が出て**タイマーが動き出す** | 左と同じ立体異性体を作れ | ルール提示。タイマーで「見続ける理由」を作る |
| 2 | 🔄 180°回す | まず、図を回してみる | 素朴な発想を先にやらせる |
| 3 | ⟳ 90°回す＋左右入れ替え。**アプリが「回転・巡回では分子は変わりません」と表示** | 回しても分子は変わらない（鏡像のまま） | ここが山。回す＝無駄手だと分かる |
| 4 | ⇄ 枝の入れ替え（中心の立体を反転） | ⇄ 枝を入れ替えると立体が反転する | 奇置換だけが立体を変える |
| 5 | 🏁 完成！ タイムと手数が出る | 完成！ タイムと手数が出る | 達成の絵。自己ベスト更新の表示も出る |

- **お題の分子は毎回ランダム**（出題範囲は既定の「入門（不斉炭素1個）」）。
  入門では**必要な入れ替えはちょうど1回**なので、台本の手数は毎回同じになる
- 収録では回す操作を2回入れているので、**完成は3手**になる。
  「最短は1手」であることは動画では言わない（次回作の引きとして残す）

## 2. ナレーション全文（ずんだもん版・VOICEVOX）

正は [narration/V15.json](narration/V15.json)。

> 左と同じ立体異性体を、右の図を操作して作るのだ。何秒でできる？
> まずは回してみる。百八十度、それから九十度。
> でも、回しても分子は変わらないのだ。ずっと鏡像のまま。
> 立体を変えられるのは、枝の入れ替えだけ。ここでひっくり返るのだ。
> 回すと同じ、入れ替えると鏡像。これがフィッシャー投影のきまりなのだ。
> 無料、インストール不要。リンクはプロフィールなのだ。

- **`narrate.py` の出す読み仮名を必ず確認する**。特に「鏡像（きょうぞう）」「立体異性体」「不斉」。
  角度は算用数字だと読みが揺れるため**漢数字で書いている**（百八十度・九十度）
- 「フィッシャー投影」は固有名詞。人名部分がカタカナのまま読まれるか確認する

## 3. 化学の裏取り

- フィッシャー投影の4つのスロットの入れ替えは、**偶置換なら同じ分子・奇置換なら鏡像**。
  180°回転＝転置2回（偶）、90°回転は4巡回（奇）なので、アプリは**縦横の入れ替えを同時に行って偶に戻している**
  （ボタン名が「90°回す**＋左右入れ替え**」なのはこのため）。だから**回す操作では絶対に正解にならない**
- 「⇄ 枝の入れ替え」は転置1回＝奇置換で、その中心の立体だけが反転する
- 判定は `canonicalStereoCode` の一致。**図の向きや並びが違っても、分子が同じなら完成**
  （アプリも画面にそう書く）。動画でもここは言い切ってよい

## 4. 収録メモ

```
node tools/record/record.mjs --demo=stereo-time-attack --format=short --speed=1.0
node tools/record/mux.mjs --video=video-scripts/out/stereo-time-attack-short.webm \
  --audio=video-scripts/audio/V15/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --se=video-scripts/audio/se/tap.wav \
  --events=video-scripts/out/stereo-time-attack-short.events.json \
  --meta=video-scripts/meta/V15.json --trim=auto --size=1080x1920 \
  --out=video-scripts/out/V15-final.mp4
```

- **速度は 1.0 で固定**。最初 1.2 で撮ったところ映像が音声より18秒短く、mux が末尾を静止で埋めた。
  デモの `wait` を各ナレーション行の長さ（6.6 / 4.8 / 5.2 / 5.5 / 6.1＋4.6 秒）に合わせ直して撮り直した結果、
  末尾の余りは1秒に収まった。**台本の間を変えたら必ず収録からやり直す**
- 実測（2026-07-31 の収録）: お題は「システイン」、**18.2秒・3手**で完成し「🥇 自己ベスト更新！」が出た。
  お題の分子は毎回変わるので、この数字は台本の固定値ではない
- 収録は**まっさらなブラウザ**で行われるので、完成時に「🥇 自己ベスト更新！」が出る
  （手元のブラウザで試すと過去の記録が出てしまうので、画の確認は収録側を正とする）
- モーダル主体の画なので、**短辺 810px の縦画面でお題と操作図が横に並ぶ**構図になる。
  キャンバスの `frame` アクションは効かない（構図は modal の CSS 側で決まる）
