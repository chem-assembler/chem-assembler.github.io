## A. 練習中の画面からヒントに手が届かない

### 症状（ユーザー報告 → 実機で原因を特定）

> ヒントボタンが見当たりません

**バグではなく置き場所の抜け。** 練習を始めると **📚学習のモーダルが閉じてキャンバスに戻る**
（答案を描くためなので、これ自体は正しい）。このとき画面下に出る作業帯 `#ws-practice` の中身は：

```
お題 C₃H₈O の異性体 全 3 種 ／ いま 0個 描いてあります
[🔍 答え合わせ] [🔎 確認] [やめる]
```

**ヒントだけ作業帯に無く、📚学習 の中（`#isomer-practice-card`）に取り残されている。**
押すには学習タブを開き直すしかなく、**そのあいだ答案（キャンバス）はモーダルに隠れる**
——「行き詰まったときに見るもの」なのに、行き詰まっている画面からは押せない。

### 設計はどう言っているか

`DESIGN_isomer_practice.md` §13-1 の表は **「💡ヒントはここに置く」＝確認モード
（`openReview('progress')`）** と書いている。つまり**設計の置き場所は確認モードの中**で、
いまの実装（学習パネルのカード）は設計と食い違っている。

### 提案

どちらでもユーザーの困りごとは消える。**②を勧める**（設計の記述と一致し、面が増えない）。

1. 作業帯 `#ws-practice-actions` に `💡 次のヒント（あと N段・−1点）` を足し、
   学習パネル側のボタンと状態を同期する
2. **`🔎 確認` の中にヒントを置く**（設計どおり）。作業帯からは `🔎 確認` 1手で届く

### 受け入れ条件

**②で実装した（v1368・`feat/hint-reach`）。** 設計 §13-1a に到達手段を書き足した。

- [x] **📚学習 を開き直さずに**ヒントの段を1つ進められる

## B. 炭素番号が自動水素と重なる

### 症状（ユーザー報告）

> 炭素番号表示を、Cの真下ではなく、右下or左下に（通常は右下？）現状H原子と重なる

### 実測（v1365・2026-08-15）

**2-メチル-1-プロパノール**を呼び出して `🔢 主鎖と番号を見る` を押し、
番号の文字と自動水素の中心間距離を測った：

| 番号 | 最寄りの自動水素までの距離 |
|---:|---:|
| **1** | **13px** ← 重なる |
| 2 | 28px |
| 3 | 18px |

水素の丸も番号の文字もこれより大きいので、**1 は確実に重なる**。

### 原因

`game.js` の `_iupacOutward()` は10°刻み×半径16〜26px で置き場所を探して採点しているが、
**足切り（`continue`）が重原子にしか無い**：

```js
if (ch < R + 14) continue;   // ★ 足切り: どの炭素の番号か読めない
```

自動水素（`obstacles.light`）は**採点に少し効くだけ**なので、「重原子から遠くて外向き」
なら水素の上でも勝ってしまう。コメントには「四方が埋まった炭素では自動水素の真上になる
（実測で重なった）」と**すでに書いてあり、その対策として探索を入れたが足切りは入れていない**。

### 提案

1. **自動水素にも足切りを入れる**（`cl` が閾値未満なら `continue`）。閾値は 14〜15px
   （重原子側の 14 と揃える。実測の 13px はこれで落ちる）
2. **同点なら右下を優先する重みを足す**（ユーザー指定。`dx > 0 && dy > 0` に小さな加点）。
   **外向きの重み（×4）より弱くする**——右下の優先で外向きが崩れると、
   「どの炭素の番号か読めない」という既存の足切りの趣旨に反する
3. 足切りを通る置き場所が1つも無いときは、いまと同じく `bestAny` に落とす（出さないよりまし）

### 受け入れ条件

- [x] 2-メチル-1-プロパノールの番号1が、最寄りの自動水素から **14px 以上**離れる
      → **13.5px → 16.5px**（実機の画面で測っても 16.2px）
- [x] 直鎖（ヘキサン）・環（シクロヘキサン）・四方が埋まった炭素（ネオペンタン）でも
      **番号がどの炭素のものか読める**（既存の「2番目より14px以上近い」を崩さない）
      → 実機実測: ヘキサン 最小 15.7px・ネオペンタン 最小 23.0px・シクロヘキサンは番号を出さない（門番）。
      「2番目の重原子との差」は全件で **15.5px 以上**（直しの前後で変わらず）
- [x] 回帰テストが全合格 → **399/399**（IN7・IN8 を追加）

### 直した内容（v1369）

`_iupacOutward` に**自動水素の足切り**（`cl < 15` なら `continue`）を足し、探索半径を
16〜26px → **16〜32px** に広げた（自動水素は 16px にいるので、その先へ抜けるには 31px 以上が要る）。
同点なら**右下**を選ぶ弱い加点（+0.8。外向きの ×4 より弱い）も入れた。
落とし方は3段（両方の足切り → 重原子の足切りだけ → 無条件）——
水素を避けたつもりで「どちらの炭素の番号か読めない」に戻らないため。
番号が 6px ぶん外へ出たので、図の上の字幕の逃がしも 26 → 36px に合わせた。

**ライブラリ全体の実測（compounds.json の 95 件・番号 425 個）**

| 最寄りの自動水素まで | 直す前 | 直した後 |
|---|---:|---:|
| 14px 未満（重なる） | **184 個（43%）** | **0 個** |
| 最小 | 13.5px | 16.5px |

＝ 2-メチル-1-プロパノールだけの話ではなく、**直鎖の中ほどの炭素はほぼ全部重なっていた**。

## C. 答え合わせを「正解｜自分の答え」の2列対応表にする

### 要望（ユーザー・2026-08-15）

> 答え合わせは、正解と自分の図を縦に並べる方がよい
> 正解を左列、自分のこたえを右列で対応関係をわかりやすくする

### いまの形（実測）

**縦に2ブロック**で、対応は読み手が目で突き合わせるしかない：

```
あなたの書き出し
  ① 1-プロパノール ／ ② 2-プロパノール ／ ③ C₂H₆O
標準の書き方と答え（主鎖に番号・系統順）
  1-プロパノール ✓ ／ 2-プロパノール ✓ ／ エチルメチルエーテル（未発見）
```

### 提案

**行＝1つの異性体**の2列表にする。左が正解、右が自分の答え。

| 正解（標準の書き方・系統順） | あなたの答え |
|---|---|
| 1-プロパノール | ① |
| 2-プロパノール | ② |
| エチルメチルエーテル | **（未発見）** |

**⚠ 2列に収まらないものが2種類ある。ここが設計の勘所**：

- **未発見**（正解はあるが自分の図が無い）→ 右セルを「未発見」で空ける。上の表のとおり
- **ダブり**（同じ正解に自分の図が2つ）→ 右セルに **①④** と並べる（既存の「①と④は同じ」を行の中で言う）
- **お題に数えなかった図**（自分の図に対応する正解が無い）→ **表の下に別枠**で残す。
  左列が空の行を作ると「正解が無い正解」に見える。
  いまの `・③ は C₂H₆O です（お題は C₃H₈O）` の文言はそのまま使える

### 受け入れ条件

**実装した（v1370・`feat/answer-grid`）。** 設計 §12-7 に「答え合わせは2列表」を書き足した。

- [x] 1行＝1つの異性体で、左に正解・右に自分の図が**同じ高さで**並ぶ
      → 行の flex（`align-items:stretch`）で**左右の高さの差は全行 0.00px**（実測・小/中/大とも）
- [x] 未発見・ダブり・お題外の3つが、上の方針どおりに表現されている
      → C₄H₁₀O で**同時に**作って確認: 未発見4行が「未発見」の枠・ダブりの行は右に **①④**・
      お題外の ⑤（C₂H₆O）は**表の下の別枠**に `・⑤ は C₂H₆O です（お題は C₄H₁₀O）`
- [x] 既存の `図の大きさ: 小/中/大` と `表示: 確認／答え合わせ` の切替がこわれない
      → 実機でボタンを押して確認。確認モードは2列表を出さず（名前・未発見も出ない）、
      ギャラリーの図サイズも従来どおり 92/128/182px
- [x] 縦に長くなるので、**1行の高さ**を「小」で詰められること（C₄H₁₀O は7行になる）
      → `IP_REVIEW_SCALES` に `rowH` を足してギャラリー用と分けた（小 56/中 104/大 168px）。
      **1行 84px**（小）で、1280×800 では **7行中4行が画面に入る**（残りはスクロール）

**検査**: `IW10`（3つの例外を同時に含む答案）＋ **`IW11`（★否定対照 ＝ 行がずれる）**。
対応づけを正準コードから**添字**に戻すと、`IW10`「エチルメチルエーテルの行に ④」・
`IW11`「1-プロパノールの行に ①、2-プロパノールの行に ②」で赤くなることを実測。回帰テスト **402/402**。

## D. 自分の図にも名称・主鎖・炭素番号を出す

### 要望（ユーザー・2026-08-15）

> 自分の書いた図に、名称・主鎖の表示（色ペンで明示・複数が主鎖となりうる場合の対応検討・
> 炭素番号の表示）なぜその名称になるのかをわかるようにする

### いま

- **自分の図**（`あなたの書き出し`）… 名前だけ（`① 1-プロパノール`）。帯も番号も無い
- **正解の図**（`標準の書き方と答え（主鎖に番号・系統順）`）… **番号は付いている**（`1 2 3`）

つまり**「正解の書き方」には番号があるのに、自分の書き方には無い**。
「自分の図のどこを主鎖と読んだ結果その名前になったのか」が分からない。

### 既存資産（新規のアルゴリズムは要らないはず）

| 資産 | 何ができるか |
|---|---|
| `game.renderIupacNumbering()` | **主鎖の帯（半透明の太線）＋炭素番号**をキャンバスに描く。エーテルは番号でなく**両側のアルキル基を2色**で塗る |

### 決めてほしいこと（**未決。ユーザー自身が「対応検討」と書いている**）

**複数が主鎖となりうる場合をどう見せるか。**

⚠ **例が間違っていた**（ユーザー指摘・2026-08-20）。**正しい例は 3-エチルペンタン**。

| | 5個の鎖の取り方 | 何が2通りか |
|---|---|---|
| **3-メチルペンタン**（当初の例） | **1通りだけ**（両側のエチルを通る鎖しかない） | 主鎖ではなく**番号の向き**（左右どちらから振っても 3-メチル） |

⚠ **ユーザーの整理**（2026-08-20）: 「**主鎖の選択は、どちらでもよい等価な場合と、
他方ではだめな場合がある**」「疑問に答えるという観点であった方がよいとは思うが、
**インターフェースが複雑になりそうだと懸念**している」。

### 方向づけ（ユーザー・2026-08-20）

> **等価な命名は、切り替えできるようにすればよいかと思います。**
>
> **命名練習モードを追加し、そちらに飛ばすのも手ですね。
> 主鎖の始点と終点を選択、パーツごとに名称を選択、など**

**同点を2種類に分けて、扱いを変える。**

| | 例 | 扱い |
|---|---|---|
| **等価な同点**（自己同型で入れ替わるだけ） | 3-エチルペンタン | **説明しない。切り替えられるようにする** ＝ 押すともう1本の取り方で帯が描き直る。「どちらでも同じ」は**文で言うより、切り替わって名前が変わらないことを見せるほうが早い** |
| **等価でない同点**（規則で一方が選ばれる） | ~~実測待ち（下記）~~ → **ライブラリに 0件・標準6問に 0件**（実測。下記） | **ここに「なぜ？」が実在する。**1行の文か、命名練習モードへの入口 |

⚠ **この分け方だと、常設の UI が1つも増えない。**等価な同点では切り替えの小さな押しものが1つ、
等価でない同点は**そもそも稀**（実測で決まる）。ユーザーの「複雑になりそう」への答えがこれ。

⚠ **命名練習モードは、この項目より大きい話**（主鎖の始点・終点を選ばせ、部品ごとに名前を選ばせる
＝ 命名の手順そのものを練習させるモード）。ここで決めるのは「**説明の行き先として使えるか**」まで。
既存の `🔢 主鎖と番号を見る`（§7 の名前を4つの部品に割る画面）と**役割が重なる**ので、
作るなら**その画面を練習に作り替える**のか、**別に建てる**のかを先に決める必要がある。

#### 測ったあとの方向づけ（2026-08-20・調査レーン。数の根拠は下の「先に測ること」）

**1. 等価な同点の「切り替え」に値打ちがあるか —— 該当 18件（ライブラリ）／9件（標準6問）**

切り替えたときに**何が変わって何が変わらないか**は、実測でこう決まっている:

| | 切り替えると |
|---|---|
| 帯の位置 | **変わる**（3-エチルペンタンなら 3本のエチルのうち別の2本に移る） |
| 炭素番号の付く相手 | **変わる**（`C₁` が別の原子に移る） |
| **名前** | ★ **1文字も変わらない**（3本とも `3-エチルペンタン`。等価な同点の定義そのもの） |
| `nameParts`・`dirReason` | 変わらない |
| 図そのもの（分子の形） | 変わらない |

★ **「変わらないことを見せる」ことに値打ちはある。ただし今の面ではない、というのが調査レーンの読み。**

- **値打ちがある側**: 生徒がつまずくのは「自分は左のエチルを主鎖にしたが、模範解答は右だった。
  間違いか？」で、これは**実際に起きる**（9件は標準6問の中にある ＝ 主力問題で起きる）。
  そこに「押すと帯が移るが名前は変わらない」を1回見せられるなら、**文で説明するより短い**
- **いまの面（`🔢` の帯）では弱い側**: `🔢` は**自分が描いた1つの分子を見ている**画面で、
  そこには**比べる相手がいない**。「変わらない」は2つ並べて初めて読める。
