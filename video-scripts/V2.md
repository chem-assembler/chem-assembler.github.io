## 3. 操作手順（実演の詳細）

**正は [assembler/demos.json](../assembler/demos.json) の `isomer-c2h6o`**。以下はその意図。

1. 自由モード・空キャンバスから開始
2. `frame`（cx=462 / cy=294 / width=240）で構図を固定。**被写体が画面中央・幅の約54%**になる
3. C(420,294) → C(462,294) → O(504,294) の順に置く。エタノール（C-C-O）が完成し名称チップが出る
4. 全消去 → **`frame` を置き直す**（`#btn-clear-all` は視野をお題基準に戻すため）
5. C(420,294) → O(462,294) → C(504,294) の順に置く。**酸素だけが真ん中**のジメチルエーテル
6. 完成図と名称チップを静止で見せて終わり

- **`#btn-reset-view`（全体表示）は使わない**。お題基準に視野を戻すボタンなので構図が壊れる
- 座標はすべて SVG 論理座標（tutorials.json と同じ規約）

## 4. 収録メモ

```
node tools/record/record.mjs --demo=isomer-c2h6o --format=short --speed=1
node tools/record/mux.mjs --video=video-scripts/out/isomer-c2h6o-short.webm \
  --audio=video-scripts/audio/V2/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --se=video-scripts/audio/se/tap.wav \
  --events=video-scripts/out/isomer-c2h6o-short.events.json \
  --meta=video-scripts/meta/V2.json --size=1080x1920 \
  --out=video-scripts/out/V2-final.mp4
```

- 事前にリポジトリルートで `python -m http.server 8125` が要る
- 出力は **動画（.mp4）と投稿文（.txt）が同じ場所に並ぶ**。投稿は .txt をコピペするだけ
- **収録の尺は同じ台本でも ±3秒ぶれる**（実測 33.1〜40.5秒。マシンの負荷次第）。
  `--speed` で追い込むより、**音声より少し短く撮って mux の静止延長で埋める**のが安全
  （mux は映像が音声より短いと最終フレームを複製して伸ばす。この動画は 34.2秒 → 37.6秒）
- BGM: のんきな日常 / Regu（DOVA-SYNDROME。規約上クレジット不要）
- 効果音は events.json の操作時刻に自動で置かれる（13箇所）
- **クレジットは映像へ自動で焼き込まれる**（meta の `credits` を読む。右下・パレットのすぐ上）。
  文言を変えるときは `--credit=`、フォント・大きさは `--creditfont=` `--creditsize=`
