### 枝どうしの自動結合は「消す」で解ける

**42px の直交格子では、隣り合う炭素に付けた枝どうしが自動で結合し、意図しない環ができる。**
⑨を素直に置くと **7原子7結合＝C₇H₁₄**（名前も出ない）。

当初これを「格子では描けない」と判断しかけたが、**余分な結合を右クリックで消せば済む**（ユーザー指摘）。
実機で確認: 消すと 7原子6結合・**2,2,3-トリメチルブタン C₇H₁₆**。
デモでは `cutBond`（内部は contextmenu イベント）を使う。**消しゴムツールへの切り替えは不要**。
⑤⑥は枝どうしが斜め・2マス離れなので環はできない（③④⑦⑧も同様）。

- 化学の裏取り: **9つすべて実機の名称チップで検算済み**（①〜⑧はキャンバスに直接置いて確認、
  ⑨は cutBond 後に確認。いずれも C₇H₁₆）。
  内訳は 主鎖7が1／主鎖6が2／主鎖5が5／主鎖4が1
- **動画のフレームだけで名前を確かめようとすると中間状態を拾う**（描き途中は C₆H₁₄ などになる）。
  検算はキャンバスに置いて名称チップを読む方法で行うこと

## 4. 収録メモ

```
node tools/record/record.mjs --demo=isomer-c7h16 --format=short --speed=3.0
node tools/record/mux.mjs --video=video-scripts/out/isomer-c7h16-short.webm \
  --audio=video-scripts/audio/V17/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --se=video-scripts/audio/se/tap.wav \
  --events=video-scripts/out/isomer-c7h16-short.events.json \
  --meta=video-scripts/meta/V17.json --trim=auto --size=1080x1920 \
  --out=video-scripts/out/V17-final.mp4
```

- **速度 3.0 は「作図の総時間 ÷ ナレーション尺」から逆算した**。2.3 では映像が13秒余り、
  mux が末尾を切る＝答えのテロップが出る前に喋り終わってしまう。
  **`wait` も速度で割られる**ので、静止させたい秒数 × 速度 を ms で書く
  （例: 最後の答えを5.7秒見せる → 17000ms ÷ 3.0）
