## 4. 収録メモ

```
node tools/record/record.mjs --demo=isomer-c5h12 --format=short --speed=1.7
node tools/record/mux.mjs --video=video-scripts/out/isomer-c5h12-short.webm \
  --audio=video-scripts/audio/V4/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --se=video-scripts/audio/se/tap.wav \
  --events=video-scripts/out/isomer-c5h12-short.events.json \
  --meta=video-scripts/meta/V4.json --trim=auto --size=1080x1920 \
  --out=video-scripts/out/V4-final.mp4
```

- **`--speed=1.7`**。操作が15回あるので等速だと 48秒かかり、ナレーション（37.4秒）に対して間延びする
- **`--trim=auto` を必ず付ける**。アプリのロードで「演技が始まるまで」が収録ごとに3〜4秒ぶれるため、
  最初の操作の1.5秒前まで映像の頭を自動で落として音と合わせる（尻の無音は `--tail`＝既定1秒で切る）
- クレジット（VOICEVOX:ずんだもん）は meta から自動で焼き込まれる
