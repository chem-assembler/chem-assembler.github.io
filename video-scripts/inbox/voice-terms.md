# 合成音声の利用規約（調査結果）
調査日: 2026-07-28

日本の主要な音声合成ソフト・キャラクターについて、YouTube・TikTok・Instagramでの動画公開に関する利用規約を調査・確認しました。

---

## 1. VOICEROID2「結月ゆかり」（AHS / VOCALOMAKETS）

* **広告収益の可否**: 
  - 個人が自身のYouTube等のアカウントで公開し、広告収益（パートナープログラム）を得ることは「商用利用（個人）」の許諾範囲内、または非商用範囲として認められており**可能**です。
* **法人・団体・ブランド名義の扱い**: 
  - 個人が運営する「ブランド名義（@SchoolLenz）」のアカウントであっても、実質的に個人運営であれば個人利用ガイドラインが適用されます。ただし、法人化した場合や法人名義での運用は別途「法人ライセンス」契約が必要となります。
* **クレジット表記**: 
  - 表記は任意ですが、トラブル防止およびガイドライン遵守のため**推奨**されています。
  - **正確な表記例**: `音声：VOICEROID2 結月ゆかり` または `Voice: VOICEROID2 結月ゆかり (VOCALOMAKETS)`
* **教育目的・学習教材での利用**: 
  - 特別な追加料金や条件はありません。個人制作の解説・教育動画として自由に利用可能です。
* **企業案件・スポンサー動画**: 
  - 企業から金銭等の対価を得て商品・サービスをPRする動画（企業案件）での使用は「業務としての商用利用」に該当するため、**別途商用ライセンスが必要**となります。

**出典URL**: 
- AHS 個人向け商用利用ガイドライン: https://www.ah-soft.com/licensee/voice_character.html
- VOCALOMAKETS 利用ガイドライン: https://vocalomakets.com/guideline

---

## 2. VOICEROID2「東北ずん子」（AHS / SSS合同会社）

* **広告収益の可否**: 
  - 個人動画投稿者によるYouTube / TikTok等での広告収益化は、SSS合同会社の「キャラクターガイドライン」およびAHS規約にて非商用・個人利用の範囲として**認められています**。
* **法人・団体・ブランド名義の扱い**: 
  - 個人が「SchoolLenz」というブランド・チャンネル名で発信すること自体は個人利用として認められます。東北企業以外の「法人」名義での利用にはライセンス契約が必要です。
* **クレジット表記**: 
  - 表記は任意ですが、認知と権利保護のため**推奨**されています。
  - **正確な表記例**: `音声：VOICEROID2 東北ずん子` または `キャラ・音声：東北ずん子 (©SSS合同会社)`
* **教育目的・学習教材での利用**: 
  - 高校生・受験生向けの非営利・教育目的コンテンツでの利用に対して非常に寛容であり、制限や追加条件はありません。
* **企業案件・スポンサー動画**: 
  - タイアップや企業案件動画への使用は商用利用に該当するため、事前にSSS合同会社への問い合わせ・ライセンス購入が必要です。

**出典URL**: 
- 東北ずん子プロジェクト キャラクターガイドライン: https://zunko.jp/guideline.html
- AHS ライセンス案内: https://www.ah-soft.com/licensee/

## 3. VOICEVOX「ずんだもん」（無料ソフト）

* **広告収益の可否**: 
  - 無料ソフトでありながら、個人・法人問わずYouTube・TikTok等の動画広告収益化が**認められています**（完全無料）。
* **法人・団体・ブランド名義の扱い**: 
  - 個人運営のブランド名義（@SchoolLenz）はもちろん、法人アカウントからの投稿であっても商用ライセンス費用なしで利用可能です。
* **クレジット表記**: 
  - **必須**です。動画の概要欄や画面内など、確認できる場所に必ず記載しなければなりません。
  - **正確な表記例**: `VOICEVOX:ずんだもん`
* **教育目的・学習教材での利用**: 
  - 特別な制限はありません。解説動画・教育動画での利用実績が非常に多く、相性が抜群です。
* **企業案件・スポンサー動画**: 
  - クレジット表記を行えば、企業案件やプロモーション動画であっても**無料で利用可能**です（ずんだもんキャラクターガイドラインの公序良俗・反社禁止項目等を守る必要あり）。

**出典URL**: 
- VOICEVOX 利用規約: https://voicevox.hiroshiba.jp/
- 東北ずん子・ずんだもんプロジェクト: https://zunko.jp/

## 4. 推薦と結論

**最も適しているソフト**: **VOICEVOX「ずんだもん」**

### 【推薦理由】
1. **費用ゼロ・規約リスクの低さ**: ソフト自体が完全無料であり、広告収益化や将来的なタイアップ動画（企業案件・アプリ紹介等）であっても商用ライセンスの追加購入が不要です。
2. **ブランド名義（SchoolLenz）での運用との親和性**: 個人が「学習ブランド」名義で運用する場合でもライセンス違反の境界線を心配する必要がありません。
3. **SNS（TikTok / YouTube Shorts）での圧倒的な認知度**: 中高生・受験生の間で「ずんだもん解説」のフォーマットは既に定番化しており、テンポの良い対話・解説系ショート動画において最も親しみやすく、スクロールを止めるフックになります。
4. **必要な対応**: 動画概要欄に `VOICEVOX:ずんだもん` （および立ち絵を使用する場合は作者クレジット `立ち絵: 坂本アヒル様` 等）と記載するだけで運用可能です。
