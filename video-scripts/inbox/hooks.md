# ショート動画のフック文案
作成日: 2026-07-28

既存企画7本（V2〜V8）について、動画冒頭3秒でスクロールを止めさせる「フック文案」各5案（計35案）です。
すべて20字以内・発話2秒以内の長さで、型（疑問・断定・数字・共感）を散らして作成しています。

---

## V2: C₂H₆Oで全く違う2つの物質ができる（エタノールとジメチルエーテル）

1. **お酒の成分とガス、同じ分子式ってマジ？**（19字）
   - *型*: 疑問・インパクト / *心理*: 好奇心（身近な物質とのギャップ）
2. **C₂H₆Oの組み合わせ、実は2パターンある**（18字）
   - *型*: 事実提示 / *心理*: 納得・知識欲（テスト知識の確認）
3. **並べ替えるだけでお酒が気体に変身！？**（18字）
   - *型*: 変化強調 / *心理*: 意外性（手品のような驚き）
4. **構造式を描き間違えると危険な理由**（16字）
   - *型*: 危機感提示 / *心理*: 不安・関心（間違いへの警戒）
5. **分子式だけじゃ正体が分からない物質**（17字）
   - *型*: 提示・問いかけ / *心理*: 共感（異性体の本質理解）
