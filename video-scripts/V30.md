## 1. この回の芯: 炭素は1個も動かさない

**同じ4個の炭素を置いたまま、酸素を1マスずらすだけ**でブタナールがブタノンになる。
作図の差分が「O の位置ひとつ」しかないので、**画面の変化が最小なのに結論が最大**になる。

さらに、**名称チップが ブタナール → ブタノン と変わるあいだ、分子式は C₄H₈O のまま動かない**。
「同じ分子式・違う官能基」を、テロップで主張せずに画面の事実として見せられる。

## 4. 操作手順（座標の根拠）

**正は [assembler/demos-fg.json](../assembler/demos-fg.json) の `fg-aldehyde-ketone`**。

| 対象 | 座標 |
|---|---|
| 炭素4個（全編を通して不動） | (378,294) (420,294) (462,294) (504,294) |
| ブタナールの O | (378,252) ＝ 端の炭素の真上 |
| ブタノンの O | (420,252) ＝ 2番目の炭素の真上 |
| frame（通常） | `cx 441, cy 273, width 300` |
| frame（C=O に寄る） | `cx 420, cy 273, width 220` |

### 二重結合の作り方

原子ツールで O を隣接マスに置くと**自動で単結合**になる（＝この時点ではアルコール）。
そこから **結合ツール（`#btn-tool-bond`）＋ 二重結合（`#btn-bond-double`）で C→O へ `drag`** すると、
既存結合の次数が繰り上がって C=O になる。実機で確認:

- O を (378,252) に置いた直後 … **1-ブタノール C₄H₁₀O** → 二重結合へ … **ブタナール C₄H₈O**
- O を (420,252) に置いた直後 … **2-ブタノール C₄H₁₀O** → 二重結合へ … **ブタノン C₄H₈O**

### 途中で 2-ブタノール が約2.5秒映る（意図した仕様）

O を置き直してから二重結合にするまでのあいだ、名称チップは **2-ブタノール** を出す。
消せない（単結合を経由せずに C=O は作れない）ので、**テロップと音声の側で辻褄を合わせてある**:

- その2.5秒のうち 2.1秒は テロップ「② O を1マスとなりへ」＝ **操作の途中だと言っている**
- 音声もちょうど「二重結合にすると、ブタノン」と、**これから変える**ことを喋っている

**最初の版はここで事故っていた**。結合ツールへの切り替え2つを step5 に置いていたため、
テロップ「ブタノン ＝ ケトン」が出てから名称チップが実際に変わるまで **1.3秒ずれ**、
その間テロップが画面の事実と食い違っていた。
**ツール切り替えを step4 の末尾に移して、step5 を `drag` から始める**ことで 0.4秒まで詰めた。

### 2分子を並べる構図は採らなかった

`summon` でブタナールを呼び出すと ①② と番号付きで並び（V11 型）、比較としては強い。
**が、その状態では式バッジが2分子の合計 C₈H₁₆O₂ になる**。
この回の結論は「分子式はどちらも C₄H₈O」なので、**画面が結論と矛盾する**。
1分子のまま通せば、バッジはブタナールでもブタノンでも C₄H₈O から動かない。**単分子構成が正解**。

**2行目以降を触らないのが正しい。** step1 の `wait` を伸ばすと後続のステップは相対位置を保ったまま
