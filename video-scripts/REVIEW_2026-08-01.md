# 検品レビュー（2026-08-01・ユーザー）

在庫を通して見たときの指摘。**台本の直し**と**アプリの改修**が混ざっているので分けて整理する。
アプリ側は「動画レーンでは直せない」＝別セッション（アプリ改修レーン）の仕事。

## A. 化学の誤り（最優先）

### A-1. V19 けん化の生成物が違う

**ナレーションが「水酸化ナトリウムを加える」と言いながら、生成物を「酢酸とエタノール」と言っている。**
NaOH を加えるのがけん化なら、できるのは**酢酸ナトリウム**（カルボン酸の塩）。油脂も同じで、
**脂肪酸ではなく脂肪酸ナトリウム（＝石けん）**が出る。

- アプリの反応ルールは **`hydrolysis_ester`＝「けん化・加水分解（エステル + H₂O）」**で、
  実際に出る生成物は**酢酸（酸のまま）**。つまり**アプリは加水分解を計算していて、けん化ではない**
- 直し方は2つ。**どちらを採るか要判断**
  - **(a) 台本だけ直す**: NaOH を出さず「水を加えて分解＝加水分解」に統一し、
    石けんの話は「塩基でやると塩になり、それが石けん」と言葉で補う
  - **(b) アプリに塩を持たせる**: 反応ルールを分け、けん化は `R-COONa` を生成する。
    ただしアプリはイオン・対イオンを持たないので**設計判断が要る**（P12-4 の範囲）
- **V19 は再収録が必要**。現状は保留中なので投稿には影響していない

### A-2. V30 の問いが不正確

冒頭「炭素が4つと、酸素が1つ」。**この条件だけではアルコールもエーテルも当てはまる**（C₄H₁₀O）。
アルデヒド／ケトンに絞るには**分子式 C₄H₈O を言う**か「C=O をもつ」と条件を足す必要がある。

- **V30 は再収録が必要**。まだ投稿していない

## B. 見せ方の改善（台本・データ側で直せる）

### B-1. V31 の題材を変える

**バリン・セリンは高校化学ではあまり出ない。グリシン・アラニン・グルタミン酸にしたい。**

- 収録状況を確認した: **グリシン ○／グルタミン酸 ○／アラニンは `D-アラニン` と `L-アラニン` のみで
  「アラニン」単体が無い**
- fg レーンがバリン・セリンを選んだのは、**7種が同じ座標で作図されているのに対し
  L-/D-アラニンは縦置きで骨格の向きが違う**ため（V31.md §4）。
  題材を変えるには **compounds.json に「アラニン」を横置きで追加する**のが前提

### B-2. V10 の初期配置

「重ならない」を見せる回なのに、重なって見えてしまう。**配置か見せる順を変える**。

### B-3. V20 の「2-」が聞き取りにくい

## C. アプリの仕様確認・改修（別セッション）

### C-1. 反応の操作フロー（V18 の指摘から。**いちばん大きい要望**）

やりたい形:

1. **1つの分子を選ぶ → 反応の種類と相手を選ぶ → 2つの分子が並ぶ（選んだ分子が左）→ 反応する**
2. **2つの分子を選ぶ → 反応を選ぶ → 2つの分子が整列して反応する**

いまは呼び出した順に置かれるだけで、**反応の前に整列しない**。
`CH₃COOH + HOCH₂CH₃ → CH₃COOCH₂CH₃` のように**式の並びと画面の並びを一致させたい**。

### C-2. 生成物の配置

- **V18**: 生成したエステルを**横一線**にしたい
- **V6**: アルデヒドは **R-C(O)-H**、カルボン酸は **R-C(O)-OH** の並びが見やすい

いまは v341 で「母体と同じ刻み」に置くようになったが、**向きまでは整えていない**。

### C-3. 変化箇所のハイライトが水素と重なる

オレンジの点線円は **半径17** で描かれ、**自動水素の円と重なって読みにくい**。
**円を大きくして H まで含める**か、別の示し方にする。

### C-4. 結合角（V11）

**直交（90°）ではなく 120° にしたい。**
ただし **CLAUDE.md は「直交作図は意図された仕様（手書き感覚のコンセプト）」と明記**している。
**方針の変更にあたるので、アプリ全体の設計判断が要る**（部分的に 120° にすると作図と食い違う）。

### C-4b. バリン等の構造式（V31）

**主鎖を一直線に伸ばす形を基本にしたい。** compounds.json の座標データの問題。

### C-5. 立体タイムアタックの回転ボタン（V15）

**「90度回転で分子が変形しないボタンがない」**という指摘。
実装されているボタンは次のとおり:

```
btn-ta-rot90cw / btn-ta-rot90ccw / btn-ta-rot180 / btn-ta-swap
btn-ta-cycle-cw / btn-ta-cycle-ccw / btn-ta-reset / btn-ta-next
```

**`rot90` が何を変えるのかを実機で確認する必要がある**（フィッシャー投影では 90°回転で
立体が反転するのが正しい挙動なので、**仕様どおりなのか不具合なのかの切り分けから**）。
