台本は `video-scripts/V<N>.md`、投稿メタは `video-scripts/meta/V<N>.json`（既存と同じ）。

## 0. なぜこれか

**残り在庫13本のうち11本が「化合物作ってみた」**で、そのシリーズは初回（V68 カフェイン 1,271）と
DNA 回（V73 アデニン 1,154）以外が **134〜251** に落ちている。同じ型を2週間流し続けても
その帯のままになる——これが見直しの発端（2026-08-15）。

**「回るもの」と「届けたい相手」が、この機能では一致する**のが選んだ理由。
手筋シリーズはまだ練れていないうえ、視聴者層（25〜34歳 44%・13〜17歳 10.7%）を考えると
受験生向けは視聴を落とす。絞り込みは**数字が減る絵**で回りつつ、題材は入試の構造決定そのもの。

## 1. 実測（v1374・2026-08-15 に実機で全部押した）

### 場所

**📚学習 タブ → 「🔍 実験の結果から絞り込む」のアコーディオン → `🔍 実験カードで絞り込む`**
（⚠ アコーディオンは既定で閉じている。異性体の練習と同じ罠）

### 中身

- 上部に**モード切替**: `構造を数える` / `部品を割り振る（芳香族）` / `断片に割る` / `元素分析から` /
  **`入試問題から`** / `（自分で組む）`
- `入試問題から` に **実在の入試19問**（すべて2021年。大学名つき）
- 分子式のプリセット12種・不斉炭素・エノール除外・環の有無
- **実験カード 20種以上**（ナトリウム／酸化／ヨードホルム／銀鏡／臭素水／水素付加／IR／
  光学異性体／環／オゾン分解 …）。どれも**「実験の文」と「＝ 何が分かるか」が対で書いてある**
- 列（化合物）を複数追える（`＋ 化合物`）。東大の問題は最初から **B・B′ の2列**

### 東京大1Ⅰ（2021）を「▶ 全部積む」で流した実測

```
C₆H₁₂O の全構造異性体 211 → エノール18種を除いて 193 → 制約（不斉炭素1個ほか）で 55

① 赤外吸収でカルボニル基が見られなかった  ＝ C=O をもたない          −4   → 51
② ナトリウムを加えると水素が発生した      ＝ −OH をもつ             −25  → 26
③ 臭素水を脱色しなかった                ＝ 炭素間二重結合をもたない  −18  → 8
④ 酸化するとケトンが得られた             ＝ 第二級アルコール         −3   → 5
⑤ ヨウ素と水酸化ナトリウムで黄色の沈殿     ＝ ヨードホルム陽性        −2   → 3

残り 3 通り（3員環＋第二級−OH が 2／4員環＋第二級−OH が 1）
```

**そのあと画面が自分で答え合わせをする**——ここがこのシリーズの芯：

```
他にも解き方があります。3通りに届く最小の組み合わせが 3 通り（いま5手、最短は 3手）
  ルート1（3手）ヨードホルム陽性 → 11 ／ 二重結合なし → 4 ／ C=O なし → 3

積んだカードの性質
  ヨードホルム陽性     必須   単独で 11 通り
  炭素間二重結合なし   必須   単独で 30 通り
  第二級アルコール     冗長   単独で 17 通り
  −OH をもつ          冗長   単独で 26 通り
  C=O をもたない       冗長   単独で 51 通り
```

**ヨードホルム陽性を1枚目に置くと 55 → 11**。最後に置くと −2 しか効かない。
**同じ実験でも、置く順で効きが10倍以上変わる**——設計書が言っていた
「紙の上では絶対に見えない数字」がそのまま画面に出る。

⚠ **C₄H₁₀O（7通り）でも同じ形が出る**（実測: 5手積んで1通り → 最短1手・情報ゼロが2枚）。
**短い題材でも落ちが成立する**ので、30秒に収めやすいのはこちら。

## 5. 作るときの注意

- ⚠ **`tools/videos.js` の `SERIES` に「構造決定シリーズ」を足す**。足さないと
  `node tools/videos.js` が「表記ゆれ？」で赤くなる（ロング L1 のときと同じ）
- ⚠ **アコーディオンを開く1手が要る**（📚学習 → 🔍 実験の結果から絞り込む）。
  異性体の練習と同じで、既定は閉じている
- ⚠ **`▶ 全部積む` は一気に積む**。動画では**1枚ずつ押す**（カウンタが落ちるのが芯なので、
  まとめて積むと絵が飛ぶ）。ただし尺が足りなければ後半だけ `▶ 全部積む` に頼れる
- **demo（自動収録）はまだ無い。** `assembler/demos-*.json` に `narrowing-*` を新規に書く必要がある。
  モーダル内のセレクタは `#nw-problem`（問題の select）ほか。**ここが次の一手**
- 手動キャプチャ（`?rec=live`）でも撮れる。ロングと違いショートは縦なので、
  **カウンタと内訳が縦構図に入るか**を先に確かめること

## このシリーズの背骨: **アルキル基の書き出しに帰着させる**（2026-08-17・ユーザー）

> アルゴリズムでは総数が書き出せますが、**人間のアプローチとは異なります**。
> **アルキル基の書き出しに帰着させるのが最も再現性と効率性が高い**と考えています。

V99 の題材（東大2021前期1I）を手で解くと、こうなる:

条件は「エノールを除く・不斉炭素1個」。手で数えるなら、アルキル基の書き出しに帰着させるのが速いです。

アルコールは C4H7-CH(OH)-CH3。2位の C は C4H7- の形にかかわらず不斉炭素になるので、
**C4H7- の中に2個目の不斉炭素を作らないように**書き出します。
・鎖式 … ブチル基に二重結合を入れる位置が8通り。うち1つは2個目の不斉炭素ができるので除いて7
・環式 … 4員環が1通り、3員環が3通り。3員環のうち1つは同じ理由で除いて2 → 合わせて3
ケトンは C4H9-CO-CH3。ブチル基で不斉炭素ができるのは sec-ブチルだけなので1

7 + 3 + 1 = 11 通り。アプリは総当たりで数えますが、人が解くならこの帰着のほうが再現できます。

**アプリと人で、道具が違う。** アプリは総当たりで数え、人は「決まっている部分を外して、
残りをアルキル基として書き出す」。**数が合うことより、この帰着が見えることのほうが学習では効く。**

### この回のシリーズ設計に効くこと

- **動画は数字が落ちる絵**、**固定コメントは帰着の道筋**。役割を分ける
  （縦画面に derivation は入らない。V99 の固定コメントがその初出）
- **アルキル基の書き出し練習（V105 の題材）とここでつながる**。
  「C₄H₉– は4種類」を知っていることが、構造決定の速度に直結する
  ＝ V105 は構造決定シリーズの**前提回**として置き直せる
- **手で数えるときに落ちるのは「置換基の内側の2個目の不斉炭素」**。
  実際、公開前の検算でここが2件抜けた（アプリのほうが正しかった）。
  **この落とし穴そのものが1本になる**（「不斉炭素は R の中にも隠れている」）
