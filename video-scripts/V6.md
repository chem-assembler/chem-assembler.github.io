## 3. 前後比較オーバーレイは使わない（2026-08-01 の判断）

反応シリーズは「反応実行モードで**前後を見せる**」枠なので、当初は各反応のあとに
**「🔍 反応の前後を見る」**（P12-5 の比較オーバーレイ）を開く構成にした。**作り直してやめた**。理由:

- **縦画面ではテロップと重なって読めない**。オーバーレイはキャンバス上端から始まるのに対し、
  ショートのテロップは `top: 9%`・名称チップは `top: 23%` に固定されている（`.rec-short`）。
  実収録のフレームで、反応前／反応後の2つの構造式の**真ん中の帯をテロップが覆う**ことを確認した
- 代わりに**実行時モーフィング＋変化箇所のオレンジ点線**で前後を見せる。
  これは分子そのものの上に出るので中央に来る＝縦画面と相性がよい
- ハイライトは「次のプレビュー更新まで残る」仕様なので、**静止ステップを1つ足せばそのまま見せ場にできる**（ステップ4）

将来 `.rec-short #rx-compare-overlay` の位置を下げる CSS を入れれば解禁できる。**アプリ側の改修待ち**。

### 待ち時間の決め方（この回で確立した実測値）

作図回と違って**アクション自体が重い**（シートの開閉・カーソル移動・モーフィング）。
最初は見積もりで組んで**テロップがナレーションから最大8.3秒も遅れた**。
`--events` の出力（各アクションの実時刻）から実測して引き直したのが下の値:

| アクション | 実測コスト |
|---|---|
| `button`（右パネル内＝シートを開く） | 1.34s |
| `summon`（シートが開いている状態から） | 1.01s |
| `reactionButton`（シート開＋クリック＋モーフィング） | 1.52s |
| `frame`（シートを閉じる＋構図） | 0.67s |
| **ステップ間の固定オーバーヘッド** | **1.13s** |

→ **`wait` = （その行のナレーション秒数＋0.6）−（アクションの実測コスト合計＋1.13）**。
これで**全7ステップのテロップがナレーションの 0.3〜0.5秒後**に出る（声が先・字が後で自然）。

- **`--lead=0.3` を付ける**。既定の 1.5 だと最初のテロップが 1.5秒遅れて始まり、フックの3秒を捨てることになる
- 引き直したら**必ず `--events` の時刻で答え合わせをする**（`(at − trim)` とナレーションの累積秒を並べる）
