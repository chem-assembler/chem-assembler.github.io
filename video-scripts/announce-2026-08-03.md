## 2本目 — 有機・立体化学

```
フィッシャー投影は「縦が奥・横が手前」という約束で描く図です。

だから、たまたま十字に見えるだけの図と、フィッシャー投影として描いた図は別物。
アプリはこの2つを区別して、後者だけ D／L を名前に出すようにしました。

約束を守った図にだけ、立体の名前がつきます。
```

**画像**: 乳酸の縦置き（D-乳酸の表示あり）と、横置き（表示なし）を並べる。
**根拠**: `fix(stereo): 立体を名前に出すのは縦置きの図だけにする（v446）`

## 4本目 — 有機・付加反応

```
プロペンに HBr を加えると、Br はどちらの炭素につくか。

答えは「H の多い炭素に H がつく」＝ マルコフニコフ則。

アプリは水素を丸で描くので、反応の前後で数が変わるのが見えます。
左の炭素は H が2つ → 3つ。覚える前に、数えられます。
```

**画像**: プロペン（反応前）と 2-ブロモプロパン（反応後）を並べ、左端の炭素の H を強調。
**根拠**: `reactor.js` の `addAcrossMultipleBond()`（V42 の題材）

## 5本目 — 比例式でみる化学計算

```
気体どうしの反応で、体積を求めるだけなら mol は要りません。

同温・同圧なら体積比＝物質量比なので、L のまま比例式で解けます。
「とりあえず mol にする」と手数が増えて、どこで間違えたか分からなくなる。

必要になるまで mol を出さない。そういう作りにしました。
```

**画像**: 同じ問題を「mol 経由」と「L のまま」で並べた比較。
**根拠**: `feat(ratio): mol を使わなくてよいときは使わない（気体同士は L のまま）（v14）`

## 6本目 — 比例式・中和滴定

```
中和滴定は公式を覚える単元だと思われがちです。

でも本当は「H⁺ と OH⁻ が同じ数だけ結びつく」だけの話。
公式はその結果であって、入口ではありません。

だから公式から入らない作りにしました。数が合う様子を見てから、式にします。
```

**画像**: 中和滴定モードで、H⁺ と OH⁻ のブロックが同数で対になっている図。
**根拠**: `feat(ratio): 中和滴定を追加する（公式を入口にしない）（v17）`

## 7本目 — アプリ横断

```
「係数はどう決まる？」と「その量は何 g？」は、教科書では別の場所にあります。

でも解いている最中に行き来したいのはこの2つ。
```
