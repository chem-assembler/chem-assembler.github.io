## なぜこのネタか（2026-08-01 の判断）

V20 は ⑧で シス-2-ブテン を出して「曲げると名前が変わる → 次回」で終わっている。
その回収がこの回。あわせて **V20 の「5種類」に立体異性体を1つ足して「6種類」にする**回でもある
（V20 は §0 で問いを「構造異性体は何種類？」に直したので、**2本セットで数え方の話が閉じる**）。

**立体は stereo レーン（V50番台）と守備範囲が重なる**が、住み分けは次のとおり:

- stereo レーン … 鏡像異性体・不斉炭素・フィッシャー投影・ハース投影（**立体そのものの道具立て**）
- 異性体シリーズ … **「同じ分子式で何種類？」の数え上げの延長**として、幾何異性体を1つ足す

だから本作では R/S も鏡像も出さない。**メチルが同じ側か反対側か、それだけ**に絞ってある。

## 3. 操作手順（座標の根拠）

**正は [assembler/demos-isomer.json](../assembler/demos-isomer.json) の `isomer-cistrans`**。
V20 と同じく y=294 の横一列・格子 42px を基準にする。

| # | 構造 | 座標・操作 |
|---|---|---|
| ① | 2-ブテン（一直線） | (294〜420,294) の4個 ＋ `clickBond(357,294)` |
| ② | トランス-2-ブテン | `#btn-cistrans-reshape` ＋ `click(350,294)` → (315,330)(336,294)(378,294)(399,258) |
| ③ | シス-2-ブテン | 同じ `click(350,294)`（再タップ＝反転）→ (315,**258**)(336,294)(378,294)(399,258) |
| ⑥ | トランス-2-ブテン | 3回目の `click(350,294)` で ② の配置に戻る |

### タップは C=C の中点（357）ではなく **350** を指す

`flipCisTrans` は**タップ位置に近いほうの炭素**の置換基だけを鏡映する。中点 (357,294) は
両方の sp2 炭素からちょうど 21px で、`dA <= dB` の判定が浮動小数の誤差で決まる
＝ **収録のたびにシスの向き（メチルが上／下）が変わる**。実際に2回撮って両方が出た。

**x=350 にすると左の炭素 (336) に 14px と確実に近くなり、毎回同じ絵になる**
（メチルが2本とも上＝compounds.json のシス-2-ブテンと同じ描き方）。
整形の初回タップ（②）は座標を使わないので、3回とも同じ 350 でよい。

### 二重結合の描き分けは「作図支援」であって反応ではない

`reshapeDoubleBond` / `flipCisTrans` は**座標だけを動かす**（game.js のコメントにも明記されている）。
だからナレーションでは「回して変えられる」とは言わず、**「描き分ける」「入れかわらない」**で通してある。
テロップ⑤「C＝C は回転できない ＝ 入れかわらない」も同じ理由。
**シスがトランスに変化する反応を見せている、と誤読させないこと。**

- 化学の裏取り: **一直線の 2-ブテン／整形後のトランス／反転後のシス／再反転のトランス**の
  4状態すべてを実機のキャンバスに出し、名称チップと分子式を読んだ。
  4状態とも **C₄H₈**、名前は 2-ブテン → トランス-2-ブテン → シス-2-ブテン → トランス-2-ブテン
- LANES.md §4 の**貫通チェック（重原子が結合線に乗っていないか）を4状態すべてで実行し、すべて空配列**
- ±120° 整形は非環の C=C にしか効かない（`_isNonRingCC`）。2-ブテンは非環なので対象

- **`frame` は次のステップにも残る**（`updateDrawing` は viewBox を触らない。実機で確認）。
  だから寄り引きは変えたいステップにだけ `frame` を置けばよく、V20 のように毎回
  `#btn-reset-view` を叩く必要がない。**整形モード中に `#btn-tool-select` 系を押すと
  `reshapeMode` が解除される**ので、②〜⑥のあいだはツールボタンに触らないこと
- 寄りは **width 180 が下限**。150 まで寄せるとメチルの H（x=273）が左端で切れる
- `wait` は計算で置いたあと3回撮って詰めた。**同じ台本でも収録のたびに 0.1〜0.2秒ずれる**ので、
  `--events` の実測とナレーションの累積秒を毎回突き合わせる
- **ffmpeg が PATH にない環境では `FFMPEG=<...>/imageio_ffmpeg/binaries/ffmpeg-*.exe` を
  環境変数で渡す**（mux.mjs / frames.js とも `process.env.FFMPEG` を最優先で見る）
- `?v=` は据え置き（LANES.md §6。`demos-*.json` は `rec.js` が `cache:'no-cache'` で読む）
