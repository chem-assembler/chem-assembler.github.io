# Gemini 委託パッケージ（SNS展開の外注可能タスク）

Claude の枠が枯渇したときに Gemini へ投げるための、**コピペで完結する依頼文集**。
Gemini はこのリポジトリを見られないので、各依頼は単体で成立するよう前提を含めてある。

## 使い方

1. 下の「共通プリアンブル」を毎回コピー
2. 続けて、やらせたいタスクの依頼文をコピーして送る
3. 返ってきた Markdown コードブロックを丸ごとコピーし、**その1行目に書かれたファイル名**
   （例 `<!-- save as: video-scripts/inbox/quiz-ideas.md -->`）でリポジトリに保存する。
   保存先の指示は各依頼文に組み込んであるので、Gemini の出力を見れば置き場所が分かる
4. 次回セッションで Claude がそれを検証し、台本・実装・方針に反映する

**ファイルは UTF-8（BOMなし）で保存すること**（このリポジトリの絶対ルール。メモ帳ではなく
VS Code 等で保存する。文字化けは `node tools/verify-release.js` が検出する）。

## 委託してよい／いけない仕事

| 委託OK | 委託NG（Claude 側でやる） |
|---|---|
| 台本ネタ出し・クイズ案の量産 | アプリのコード修正（rec.js・demos.json・tests.js） |
| 規約・市場のリサーチ | git 操作・バージョンバンプ・テスト実行 |
| 投稿文・ハッシュタグのバリエーション | 化学的正しさの最終判断（命名・反応・立体） |
| サムネ・図解のラフ案 | ブランド資産の改変（アイコン・バナー） |

**理由**: コミット儀式（版番号の一括更新・全テスト合格・UTF-8）を知らないモデルにコードを触らせると
整合性が壊れる。化学の誤りは教材として致命的で、検証コストが自作より高くつく。
→ **成果物がテキストで、こちらで検証できる仕事**だけを出す。

## 共通プリアンブル（毎回これを先頭に貼る）

```
あなたは日本の高校化学の教材づくりを手伝うアシスタントです。以下のプロジェクトの文脈で作業してください。

【プロジェクト】
SchoolLenz（スクールレンズ）— 「見えないしくみを、見えるように。」をタグラインとする無料の
学習アプリ群。化学サブブランド「化学レンズ」で、大学受験の化学を可視化するWebアプリを公開している。
・構造式パズル（有機化合物を画面上で組み立て、描くと化合物名が表示される）
・イオンでみる化学反応式（係数を粒の数で納得して反応式を書けるようにする）
URL: https://chem.schoollenz.com （無料・広告なし・ログイン不要・インストール不要）

【SNS展開】
X / YouTube / TikTok / Instagram を @SchoolLenz で運用開始。主目的は高校生・受験生への認知拡大。
縦型ショート動画（30〜60秒）を入口とし、YouTubeに解説を蓄積、Xで開発状況を発信する三層構造。

【トーン】
・誠実であること。「これだけで満点」「絶対受かる」等の誇大表現は使わない（教員層の信用を損なうため）
・煽りすぎない。知的な驚きで惹きつける
・対象は高校2〜3年生と受験生。専門用語は使ってよいが、初出時は一言添える
```

## タスクA: クイズ系ショートのネタ出し（最優先）

```
高校化学（有機分野が中心、無機・理論も可）で、15〜45秒の縦型ショート動画にできる
「クイズ型のネタ」を20案出してください。

【形式】各案について次の項目を表で:
1. フック（動画の冒頭3秒で出す問いかけ。20字以内）
2. 正解
3. 引っかかりポイント（多くの生徒が間違える理由を1文で）
4. 動画での見せ方（画面で何が起きると気持ちいいか。1文）
5. 想定尺（秒）

【条件】
・「答えが意外」「勘違いしていた」という驚きがあるものを優先
・コメント欄で議論が起きそうなもの（正解が割れる、続編を作れる）を歓迎
・構造式を組み立てる／分子を回転させる／反応させる といった「画面が動く」見せ方ができるものを優先
・高校の教科書範囲を逸脱しないこと。大学範囲の知識が必要なものは除く
・化学的に正確であること。少しでも不確かなものは「要確認」と明記する

【参考にしてよい既存案（重複させないでください）】
・C₅H₁₂の構造異性体は3種類
・エタノールを酸化するとアセトアルデヒド→酢酸
・2つの構造式が同じ分子か違う分子か（回転・鏡像）

【出力形式】
全体を1つのMarkdownコードブロックにまとめ、その先頭行を次のコメントにしてください:
<!-- save as: video-scripts/inbox/quiz-ideas.md -->
2行目にH1見出し「# クイズ系ショートのネタ案」、3行目に作成日を書き、以降に本文を続けてください。
（このコードブロックをそのままファイルに保存して使います）
```

## タスクB: 合成音声の利用規約リサーチ

```
日本の音声合成ソフトについて、YouTube・TikTok・Instagramでの動画公開に関する
利用規約を調査し、最新の情報をまとめてください。出典URLを必ず添えてください。

【調査対象】
1. VOICEROID2「結月ゆかり」（AHS / VOCALOMAKETS）
2. VOICEROID2「東北ずん子」（AHS / SSS合同会社）
3. VOICEVOX「ずんだもん」（無料ソフト）

【各ソフトについて知りたいこと】
・作成した音声を含む動画をYouTubeで公開し、広告収益を得ることは認められるか
・法人・団体名義（個人ではなくブランド名義）のアカウントで公開する場合に制限はあるか
・クレジット表記は必須か。必須なら「正確な表記例」
・教育目的・学習教材としての利用に特別な条件はあるか
・企業案件・スポンサー動画での利用可否（将来のため）

【出力形式】
ソフトごとに上記5項目を箇条書きで。最後に「この3つのうち、無料の学習アプリを運営する
個人が、ブランド名義のYouTube/TikTokで教育動画を出す用途に最も適しているのはどれか」を
理由つきで1つ推薦してください。

【注意】規約は改定されるため、必ず公式サイトの現行版を確認し、確認日を明記すること。
推測で答えず、確認できなかった項目は「公式に記載を確認できず」と書いてください。

【出力形式】
全体を1つのMarkdownコードブロックにまとめ、その先頭行を次のコメントにしてください:
<!-- save as: video-scripts/inbox/voice-terms.md -->
2行目にH1見出し「# 合成音声の利用規約（調査結果）」、3行目に「調査日: YYYY-MM-DD」を書き、
以降に本文を続けてください。（このコードブロックをそのままファイルに保存して使います）
```

## 持ち帰り後の扱い（Claude 側の作業）

- **タスクA** → 化学的正しさを検証 → 採用案を SNS_VIDEO_PLAN.md の動画リストに追加 → 台本化 → demos.json のデモ台本を実装
- **タスクB** → 採用キャラを確定 → SNS_PLAN.md とメモリに記録 → クレジット表記を投稿テンプレに反映
- **タスクC** → 文言を選抜・調整して V1.md §5 に反映
- **タスクD** → 構成パターンを SNS_PLAN.md の方針に反映（投稿時間の仮説を更新）
- **タスクE** → 採用案を brand/ の素材として実装

**重要**: 持ち帰った内容は**そのまま採用しない**。特にタスクAの化学的内容とタスクBの規約は、
Claude 側で必ず裏取りしてから反映する（誤った教材・規約違反はブランドの信用に直結するため）。
