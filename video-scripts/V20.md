## なぜこのネタか（2026-08-01 の判断）

LANES.md に「**数え上げは C₇H₁₆（V17）で打ち止め。同じ型を続けず視点を変えること**」とある。
C₄H₈ は形式こそ数え上げだが、**数える対象が「枝の置き方」から「二重結合と環」に変わる**。
シリーズが V4・V9・V16・V17 で積んだ「全部描いて名称チップで確定させる」という型はそのまま使いつつ、
**不飽和度**という新しい入口を開ける。既存5本のどれとも絵が似ないのも大きい（初めて二重結合と環が出る）。

**V17 の反転になっている。** V17 では「枝どうしの自動結合」が邪魔者で `cutBond` で消した。
本作では**同じ自動結合が主役**で、四角に並べた瞬間に環が閉じる（④）。シリーズを追っている人に効く。

## 2. ナレーション全文（ずんだもん版・VOICEVOX）

正は [narration/V20.json](narration/V20.json)。

> シーヨンエイチハチ。異性体は何種類あるのだ？
> 炭素4つに二重結合。はしなら、いち、ブテン。
> 真ん中にすると、に、ブテン。
> 枝分かれさせて、に、メチルプロペン。鎖だけなら3つ。
> でも、まだあるのだ。四角に並べると輪になる。シクロブタン。
> 三角の輪に枝を1本。メチルシクロプロパン。
> 3たす2で、5種類。二重結合1つと輪1つは、同じだけ水素が減るのだ。
> に、ブテンを曲げると名前が変わるのだ。続きは次回。

**「環」は使わず「輪」で書く。** 既知の誤読どおり「環」は「たまき」と読まれる。
「輪」なら「ワ」と読む（narrate.py の読み仮名出力で確認済み）。
数字つきの名称は V9・V16 の慣例に従い **「いち、ブテン」「に、メチルプロペン」**と仮名で書く。

**初稿は 48.6秒あって尺の上限（45秒）を超えた**ので、各行を削って 43.6秒に収めた。
削ったのは主に文末（「〜なのだ」の重複）と、答えの行の言い換え。

## 3. 操作手順（座標の根拠）

**正は [assembler/demos-isomer.json](../assembler/demos-isomer.json) の `isomer-c4h8`**。
V17 と同じく y=294 の横一列を基準にする。格子は 42px。

| # | 構造 | 座標・操作 |
|---|---|---|
| ① | 1-ブテン | (294〜420,294) の4個 ＋ `clickBond(315,294)` |
| ② | 2-ブテン | ①から `undo` ＋ `clickBond(357,294)` |
| ③ | 2-メチルプロペン | (294,294)(336,294)(378,294)＋(336,252) ＋ `clickBond(357,294)` |
| ④ | シクロブタン | (336,294)(378,294)(378,336)(336,336)＝正方形。**4個目で自動的に環が閉じる** |
| ⑤ | メチルシクロプロパン | (336,294)(378,294)(336,336)(294,294) ＋ **結合ツールで (378,294)→(336,336) をドラッグ** |
| ⑥ | シス-2-ブテン | (336,294)(378,294)(336,252)(378,252) ＋ `cutBond(357,252)` ＋ `clickBond(357,294)` |

### 三員環は格子に乗らない（⑤の理由）

自動結合は**直交して隣接（42px以内・±2pxで整列）**のときだけ働く（game.js の `threshold = GRID_SIZE + 2`）。
正三角形は 42px 格子に乗らないので、**三員環だけは自動では閉じない**。
そこで `#btn-tool-bond`（結合ツール）に切り替えて斜めに1本 `drag` する。
テロップに「斜めは結合ツール」と書いてあるのは、この操作自体が視聴者に渡したい手だから。

**⑥では逆に自動結合が効きすぎる。** 枝を両方とも上（(336,252)(378,252)）に置くと、
枝どうしが横に隣接して自動結合し**シクロブタンになる**。V17 と同じく `cutBond`（右クリック）で開く。
順序は「4個置く → 上の結合を切る → 真ん中を二重にする」。

### 2-ブテンの名称チップは「2-ブテン」で出る（確認済み）

compounds.json には**シス-2-ブテンとトランス-2-ブテンしかなく、素の「2-ブテン」の項目は無い**。
「立体を名前に反映する」は既定 ON なので、②が シス／トランス のどちらかで出てしまうと
「5種類」という主張と食い違う。**実機で確認した結果、一直線に描いた 2-ブテンは総称の「2-ブテン」**になる
（一直線＝結合幾何が読めないので立体指定エントリが候補から外れる）。
枝を折り曲げて初めて シス-2-ブテン になる ＝ ⑧のオチはこの挙動そのもの。

- 化学の裏取り: **6構造すべて実機の名称チップで検算済み**（すべて C₄H₈）。
  内訳は アルケン3（1-ブテン／2-ブテン／2-メチルプロペン）＋シクロアルカン2
  （シクロブタン／メチルシクロプロパン）＝**構造異性体5種類**。⑥は幾何異性体なので5には数えない
- LANES.md §4 の**貫通チェック（重原子が結合線に乗っていないか）を6構造すべてで実行し、すべて空配列**

```

  --base=http://localhost:8151/assembler/

  --audio=video-scripts/audio/V20/full.wav \

  --se=video-scripts/audio/se/tap.wav \
```

映像がナレーションより最大 3.4秒 先行していた（アクションの実測コストが表の値より安かった）。
