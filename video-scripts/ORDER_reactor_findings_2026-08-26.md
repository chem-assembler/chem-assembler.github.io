# 発注（Assembler レーンへ）: 反応実行モードを動画で通して見つけたこと（2026-08-26）

**ユーザー指示「アプリの動作確認も兼ね、作れるものはつくってみましょう」。**
反応シリーズ・高分子シリーズの新作を作るために、**未取材の反応をまとめて台本にして収録した**。
録画は実ブラウザで最後まで走るので、**「押せるのに効かない」類がそのまま出る**。

⚠ **この文書は動画レーンの観測記録**。直し方の指示ではなく、**再現手順と実測**を置いてある。

## 0. 通した5つと結果

| 反応 | 題材 | 結果 |
|---|---|---|
| 側鎖酸化 | トルエン | ✅ C₇H₆O₂ 安息香酸 |
| 芳香族置換: 臭素水（触媒なし） | フェノール | ✅ C₆H₃Br₃O 2,4,6-トリブロモフェノール |
| アセチル化 | サリチル酸 | ✅ C₉H₈O₄ アセチルサリチル酸 |

| **付加重合** | **スチレン ×4** | ⛔ **押せるのに何も起きない**（→ §1） |
| 付加重合 | 塩化ビニル ×4 | ✅ C₈H₁₂Cl₄R₂（PVC の鎖・R が両端） |

## 1. ⛔ 付加重合が**スチレンでは効かない**（塩化ビニルでは効く）

### 再現手順

```
自由モードで スチレン を summon で4つ並べる
→ 「反応させる・調べる」を開く
→ 「付加重合（並べた単量体をまとめて）→ 高分子の繰り返し単位」を押す
```

**ボタンは一覧に出ている**（画面を撮ってある。§3 の再現コマンドで同じ画が出る）。
**押しても分子はスチレン4つのまま**で、結末は `C₃₂H₃₂ ① スチレン ＋ ② スチレン ＋ ③ スチレン ＋ ④ スチレン`。

**同じ手順を 塩化ビニル に替えると通る**（`C₈H₁₂Cl₄R₂`）。
＝ **多分子・同一単量体の流れ自体は動いている**。スチレン側の何かで止まっている。

### 動画レーンが読んだ範囲（当たりを付けただけ。断定していない）

- `vinylBonds` は **環内の C=C と芳香族結合を除く**（1648行・1650行）ので、
  スチレンのビニル基（環の外）は1本だけ残るはず ＝ `detect` の
  「1分子に C=C が2本以上あるものは除く」には引っかからないように見える
- 頭尾は `heavyN` で決まる。スチレンは **環側の炭素が head、=CH₂ が tail** になる
- ⚠ **怪しいのは並べ替えの向き**（3128〜3141行・v1436 の §14 の直し）。
  `sum = Σ(head座標 − tail座標)` の符号で並べ替えの向きを決めているが、
  スチレンは **head 側に環がぶら下がっている**ので、`summon` が置いた配置での
  head/tail の向きがエチレン系と揃わない可能性がある。
  向きが逆だと**鎖が並びと逆向きに伸びようとして塞がれる**——
  同じ節のコメントが「右隣が塞がっているぶん階段状に折れていた」と書いている症状の親戚に見える
- **ただし今回は「折れた」のではなく「1本も繋がらなかった」**ので、別の原因かもしれない

### 動画レーンとしての扱い

**V120（発泡スチロール）は諦めて、塩化ビニル（PVC）に題材を替えた。**
スチレンで通るようになったら「発泡スチロールを一から」は作りたい
（**身近さでは PVC より強い**ので）。

## 2. ⚠ 側鎖酸化は**メチル基だけ**（仕様。念のため記録）

エチルベンゼンの反応一覧に側鎖酸化は出ず、「⚠ 酸化（ここでは図を変えない範囲）」だけが並ぶ。
台本が押しに行くと `reactionButton` が失敗して**再生がそこで止まる**（実際に止まった）。

**これは仕様**で、`reactor.js` 1452〜1456行に理由が書いてある——
「炭素2個以上の側鎖でも生成物は安息香酸だが、**切れて出ていく側の行き先（CO₂・カルボン酸）が
条件で変わるので図にしない**」（DESIGN_reaction_execution.md §10.3）。

⚠ **直してほしいという話ではない。** ただし動画レーンとしては
「トルエンでもエチルベンゼンでも同じ安息香酸」が**この回のいちばん面白いところ**だったので、
**§10.3 の線引きを緩める余地があるなら知りたい**（例: 切れた側を描かず「＋ 酸化生成物」とだけ置く、
info ルールで「エチルベンゼンも安息香酸になる」と文章で返す、など）。

## 3. 再現のしかた

台本は `assembler/demos-reaction.json` に入っている（`sns: true`）。

```
node tools/record/record.mjs --demo=reaction-polystyrene --format=short --base=http://localhost:8161/assembler/
```

⚠ **収録の `結末:` の行がそのまま検査結果になる**。反応が効いていなければ
入れた分子がそのまま並ぶので、**目で見なくても分かる**。
今回の5件はこの1行だけで切り分けた。

⚠ **`reactionButton` は文言が見つからないと例外を投げて再生が止まる**ので、
**録画の尺が台本より短ければ、そこで落ちている**（側鎖酸化のエチルベンゼンがそれ。
45秒の予定が 35.9秒で終わっていた）。
