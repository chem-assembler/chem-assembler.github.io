# 発注（Assembler レーンへ）: 反応実行モードを動画で通して見つけたこと（2026-08-26）

**ユーザー指示「アプリの動作確認も兼ね、作れるものはつくってみましょう」。**
反応シリーズ・高分子シリーズの新作を作るために、**未取材の反応をまとめて台本にして収録した**。
録画は実ブラウザで最後まで走るので、**「押せるのに効かない」類がそのまま出る**。

⚠ **この文書は動画レーンの観測記録**。直し方の指示ではなく、**再現手順と実測**を置いてある。

## 1. ⛔ 付加重合が**スチレンでは効かない**（塩化ビニルでは効く）

### 再現手順

```
自由モードで スチレン を summon で4つ並べる
→ 「反応させる・調べる」を開く
→ 「付加重合（並べた単量体をまとめて）→ 高分子の繰り返し単位」を押す
```

**ボタンは一覧に出ている**（画面を撮ってある。§3 の再現コマンドで同じ画が出る）。
**押しても分子はスチレン4つのまま**で、結末は `C₃₂H₃₂ ① スチレン ＋ ② スチレン ＋ ③ スチレン ＋ ④ スチレン`。

**同じ手順を 塩化ビニル に替えると通る**（`C₈H₁₂Cl₄R₂`）。
＝ **多分子・同一単量体の流れ自体は動いている**。スチレン側の何かで止まっている。

### 動画レーンが読んだ範囲（当たりを付けただけ。断定していない）

- `vinylBonds` は **環内の C=C と芳香族結合を除く**（1648行・1650行）ので、
  スチレンのビニル基（環の外）は1本だけ残るはず ＝ `detect` の
  「1分子に C=C が2本以上あるものは除く」には引っかからないように見える
- 頭尾は `heavyN` で決まる。スチレンは **環側の炭素が head、=CH₂ が tail** になる
- ⚠ **怪しいのは並べ替えの向き**（3128〜3141行・v1436 の §14 の直し）。
  `sum = Σ(head座標 − tail座標)` の符号で並べ替えの向きを決めているが、
  スチレンは **head 側に環がぶら下がっている**ので、`summon` が置いた配置での
  head/tail の向きがエチレン系と揃わない可能性がある。
  向きが逆だと**鎖が並びと逆向きに伸びようとして塞がれる**——
  同じ節のコメントが「右隣が塞がっているぶん階段状に折れていた」と書いている症状の親戚に見える
- **ただし今回は「折れた」のではなく「1本も繋がらなかった」**ので、別の原因かもしれない

### 動画レーンとしての扱い

**V120（発泡スチロール）は諦めて、塩化ビニル（PVC）に題材を替えた。**
スチレンで通るようになったら「発泡スチロールを一から」は作りたい
（**身近さでは PVC より強い**ので）。

## 2. ⚠ 側鎖酸化は**メチル基だけ**（仕様。念のため記録）

エチルベンゼンの反応一覧に側鎖酸化は出ず、「⚠ 酸化（ここでは図を変えない範囲）」だけが並ぶ。
台本が押しに行くと `reactionButton` が失敗して**再生がそこで止まる**（実際に止まった）。

**これは仕様**で、`reactor.js` 1452〜1456行に理由が書いてある——
「炭素2個以上の側鎖でも生成物は安息香酸だが、**切れて出ていく側の行き先（CO₂・カルボン酸）が
条件で変わるので図にしない**」（DESIGN_reaction_execution.md §10.3）。

⚠ **直してほしいという話ではない。** ただし動画レーンとしては
「トルエンでもエチルベンゼンでも同じ安息香酸」が**この回のいちばん面白いところ**だったので、
**§10.3 の線引きを緩める余地があるなら知りたい**（例: 切れた側を描かず「＋ 酸化生成物」とだけ置く、
info ルールで「エチルベンゼンも安息香酸になる」と文章で返す、など）。

## 3. 再現のしかた

台本は `assembler/demos-reaction.json` に入っている（`sns: true`）。

```
node tools/record/record.mjs --demo=reaction-polystyrene --format=short --base=http://localhost:8161/assembler/
```

⚠ **収録の `結末:` の行がそのまま検査結果になる**。反応が効いていなければ
入れた分子がそのまま並ぶので、**目で見なくても分かる**。
今回の5件はこの1行だけで切り分けた。

⚠ **`reactionButton` は文言が見つからないと例外を投げて再生が止まる**ので、
**録画の尺が台本より短ければ、そこで落ちている**（側鎖酸化のエチルベンゼンがそれ。
45秒の予定が 35.9秒で終わっていた）。

## 4. ⛔ 重合まわり（ユーザー申し送り「重合まわりはまだチェックできていない」を受けて）

**第2陣で 1,4-付加重合 と 加硫 を通した。§1（スチレンの付加重合）と同じ形の詰まりが出る。**

### 4-1. 加硫を1本の鎖に掛けると、**分子内で橋が架かる**

```
イソプレン ×4 を並べる → 1,4-付加重合 → 加硫
```

結末は `C₂₀H₃₄R₂S`。**硫黄は入る**（重合も加硫も動いている）。
⚠ ただし**鎖が1本しかないので、橋が同じ鎖の中で架かってループになる**。
画では鎖が斜めに引かれ、そこを硫黄の橋がまっすぐ横切る——
**「2本のゴムの鎖を橋でつなぐ」という加硫の絵になっていない**。

`vulcanization` のコメントは
「1本目の架橋で2本の鎖が1分子になっても、続けて架橋できる必要がある」と書いており、
**2本以上の鎖を前提にしている**ように読める。
だとすると **1本の鎖に掛けられてしまうのは想定外**かもしれない
（`vulcanizablePairs` が同一成分の C=C の組も返している）。

### 4-2. 鎖を2本つくろうとすると、**2回目の重合が効かない**

```
イソプレン ×2 → 1,4-付加重合（→ ① C₁₀H₁₆R₂ ができる）
→ イソプレン ×2 を追加 → 1,4-付加重合  ← ここが効かない
→ 加硫                                  ← ボタンが見つからず再生が止まる
```

結末は `C₂₀H₃₂R₂ ① （該当なし） ＋ ② イソプレン ＋ ③ イソプレン`
＝ **追加した2つはイソプレンのまま**。

⚠ **パネルの分析対象が ① に固定されている**のが関係していそう。画面にはこう出ている:

> **分析中: ① この分子 … C=C二重結合（アルケン）×2**
> 【3分子】キャンバス全体: C=C二重結合（アルケン）×6
> **いま見ている「C₁₀H₁₆R₂」が関わる反応だけを出しています**
> （ほかの分子の反応は、上のタブか図の分子名から切り替えると出ます）

この状態で「この分子にできること」に並ぶのは
酸化／付加: Br₂／H₂／HBr／HCl／HI で、**②③ のイソプレンどうしの重合は出ていない**。

⚠ **そのあとの加硫はボタンが見つからず、`reactionButton` が例外を投げて再生が止まる**
（38.56秒で終了。台本は約50秒の予定だった）。

### 4-3. §1 との関係

**スチレンの付加重合（§1）も「ボタンは出て押せるのに効かない」形**だった。
- スチレン ×4 … 押せる・効かない
- 塩化ビニル ×4 … 効く
- イソプレン ×4（1,4-付加重合）… 効く
- **イソプレン ×2 を2回に分けて** … 2回目が効かない

**「効く／効かない」がきれいに分かれていない**ので、動画レーンからは原因を1つに絞れない。
共通しているのは **多分子をまとめる系のルール**であることだけ。

### 4-4. 動画レーンとしての扱い

**V125（ゴムと加硫）は保留にした。**
- 1本の鎖に掛けた絵（§4-1）は**化学として誤解を招く**ので出せない
- 2本の鎖にする手順（§4-2）は**そもそも通らない**

⚠ **台本 `reaction-rubber-vulcanization` は消していない**——§4-2 の再現手順そのものなので、
`sns: false` にして**再現用に残してある**。

```
node tools/record/record.mjs --demo=reaction-rubber-vulcanization --format=short --base=http://localhost:8161/assembler/
```

### 4-5. ⚠ わざと落ちる台本は `demos*.json` に置けない（2026-08-26 に踏んだ）

最初は「再現用だから」と加硫の一手まで残し、`sns: false` にして置いた。
**回帰テスト N2 が落ちた**——

```
N2: 録画モード用のSNSデモ（demos*.json）が完走する（P13-2）
  デモ「reaction-rubber-vulcanization」の再生が落ちた: 反応ボタンが見つかりません: 加硫
```

N2 は `loadAllDemos()` の**全件**を回すので、**`sns` の値では対象から外れない**
（`assembler/tests.js` 11030〜11046行）。
`reactionButton` は文言が見つからないと例外を投げるので、**そこで必ず落ちる**。

→ **加硫の一手を外し、鎖を2本つくろうとするところまでを台本に残した。**
**再現するときは、再生したあと「加硫」を手で押す**（一覧に出てこないことが確かめられる）。
