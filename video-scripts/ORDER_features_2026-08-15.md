## A. エステルが「🔤 官能基をまとめる」でまとまらない

### 実測（v1375）

| 分子 | 押す前 | 押した後 |
|---|---|---|
| **酢酸** | `H H H H C C O O` | **`H H H C COOH`** ✅ |
| **酢酸エチル** | `H×8 C C O O C C` | **変化なし** ❌ |

酢酸ではトースト（「官能基をまとめて表示しています…」）が出てボタンも
`🔤 結合をすべて表示` に反転するが、**酢酸エチルでは何も起きない**。

### なぜ困るか

**示性式 `CH₃COOC₂H₅` は高校で必ず書かされる形**。エステルは
「カルボン酸とアルコールから水がとれてできる」を示性式で追うのが定番の説明で、
そこがまとまらないと**この機能はカルボン酸止まり**になる。

ボタンの title は「-COOH や -NO₂ などの官能基を、1つのカードにまとめて表示します」なので、
**意図的にエステルを外している可能性はある**。その場合は仕様として確認したい。

### 決めてほしいこと

1. **エステル `-COO-` をまとめる対象に足す**（`CH₃COOC₂H₅` まで出せるようにする）
2. **足さない**（カルボン酸・ニトロなど「1つの原子団で閉じる」ものだけに限る、が仕様）

**1を勧める**。エステルは高校有機の山場（けん化・油脂）で、示性式で書けないと説明が続かない。
ただし `-COO-` は**両側に炭素が続く**ので、カルボン酸のように「端の1かたまり」として
扱えない可能性がある——そこが実装上の難所だと思う。

### 受け入れ条件（1を選ぶ場合）

- [ ] 酢酸エチルで `CH₃COOC₂H₅` 相当の表示になる
- [ ] もう一度押すと結合が全部もどる（カルボン酸と同じ往復）
- [ ] 作図データが変わらない（トーストの文言どおり）
- [ ] 回帰テストが全合格

⚠ **V102 の台本は「カルボン酸で撮る」前提で書いてある**ので、**この件は収録の妨げにならない**。
1で直ったら、V102 の②に「エステルでも同じ」を1手足せる。

## B. 反応機構ビューアは「反応を選ぶ」だけでは始まらない

### 症状（v1375・実測）

**📚学習 → ⚗️ 反応機構ビューア** を開いて**一覧から反応を選んでも、何も起きない**。
キャンバスは空のまま、ステップ送りの帯（`#ws-reaction`）も出ない。

実体は**「反応機構モード」のチェックボックス**のほうで、そこを入れて初めて始まる
（`reactionPlayer.active` が false のあいだ、select の change は無視される実装）。
チェックを入れると学習モーダルが自動で閉じ、帯 `🔄 ⏮ ▶ ⏭ 🎯 予測 判定 やめる` が出る。

### なぜ困るか

**その場の案内文が「選べば始まる」と読める**:

> 反応を選ぶと、ステップ送り（⏮ ▶ ⏭）はキャンバスの下に出ます。

選んでも出ないので、**入口で止まる**。台本を書くためにこちらが押したときも実際に詰まった
（コードを知っていて、原因が分かるまで数回試した）。**初見の生徒は「壊れている」と判断する**。

### 直し方の案

1. **select を選んだら、チェックが入っていなくても始める**（＝ 案内文どおりにする）。
   実装は `selectEl` の change で `active` を見ずに `enter()` を呼ぶだけ。**これを勧める**
2. チェックを外すと止まる、は今のまま残す（出口としては分かりやすい）
3. 1が難しければ、**案内文を実態に合わせる**（「反応機構モードをオンにすると…」）。
   ただし**選んでも動かない**こと自体は残るので、次善

### 受け入れ条件（1の場合）

- [ ] 一覧から反応を選ぶだけで、学習モーダルが閉じて帯が出る
- [ ] チェックボックスの表示が「オン」に追従する（状態が2つに割れない）
- [ ] チェックを外すと今までどおり止まる
- [ ] 回帰テストが全合格

⚠ **V104 の台本はチェックを入れる手順で書いてある**ので、**収録の妨げにはならない**。
1で直ったら台本の②を1行消すだけ。

## 1. 押してみて分かった良かったこと（台本に使う）

改修ではないが、**台本の芯になったもの**を記録しておく。次に誰かが台本を書くときの下敷きになる。

- **🔢 主鎖と番号**は `C1 C2 … C5` の形で出て、**帯は結合線の下に敷かれる**。
  図の上に**名前も同時に出る**（番号を生んだ名前を必ず同じ画面に出す設計）。
  ⚠ **v1369 の直しが効いている**——自動水素と重なる番号がライブラリ全体で 184個 → 0個。
  **V103 はその成果を見せる回でもある**
- **🔤 官能基をまとめる**は押すと**モーダルが閉じてキャンバスに結果が出る**。
  ボタンが `🔤 結合をすべて表示` に反転するので**往復が撮れる**＝「表示だけで図は変わらない」が伝わる
- **元素分析から**は 質量 → 物質量 → 整数比 → 組成式 → **窒素則** → 分子式 → `この分子式を絞り込む`
  まで1画面。**V99（絞り込み）の手前がまるごと埋まる**ので、2本で構造決定の入口から出口までそろう
- **⚗️ 反応機構ビューア**は **14反応**が入っていて、巻矢印・中間体・電荷まで描かれる。
  ベンゼンのニトロ化を流した実測: ステップ1（矢印2本・**芳香族性が壊れた中間体**）→
  ステップ2（矢印1本・**芳香族性が回復**）→ 完了。キャンバスに `N⁺` `O⁻` が出る。
  **既存の反応シリーズは「何ができるか」で止まっていた**ので、**「どうやってできるか」**として層が違う（台本 V104）
- **🎯 予測モード**（生成物を自分で描いて判定）も帯にある。**今回は触っていない**——クイズ型として別に立つ

## 2. この回し方について

**1機能あたり実機を10分押すだけで、台本1本と改修の申し送りが同時に出る。**
L2 で4件・今回で2件。**机上のレビューでは出ない**ものばかりで、
どれも「押してみたら文言が違った／範囲が足りなかった」という形をしている。

**次にやるなら 🎯 予測モード**（生成物を自分で描いて判定）と、**立体まわりの未使用**
（🪞 立体異性体の書き出し練習・✏️ アルキル基の書き出し練習）。どちらもまだ一度も押していない。
