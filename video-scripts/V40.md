### 配向性のコメントは出る。**ただしこの回の見せ場にはできない**

`orientationNote()` は実在し、内容も正しい。実測した2例:

```
（ニトロベンゼン → 2回目のニトロ化・メタ位を選択）
この環にはすでに -NO₂（環から電子を引く基）がついているので、次の置換基は「メタ位」に
入りやすくなります（m-配向性）。いま選んだのはメタ位なので、これが主生成物です。

（トルエン → 1回目のニトロ化・オルト位を選択）
この環にはすでに アルキル基（環に電子を押し込む基）がついているので、次の置換基は
「オルト位」と「パラ位」に入りやすくなります（o,p-配向性）。いま選んだのはオルト位なので、
これが主生成物です。
```

**動画に使えないと判断した理由は3つ**:

1. **1手目には出ない。** `aromaticSiteRole()` は「環に置換基がちょうど1つ」のときだけ判断するので、
   **素のベンゼンに1つ目を入れる場面では必ず空文字**になる。この回は3手とも1手目なので**一度も出ない**
2. **置き場所が縦型の死にゾーン。** 実測すると `#canvas-toast` は **画面の高さの 82.9%〜91.7%・font-size 12px**。
   ショートの下部25〜30%はプラットフォームのUIに覆われる（style.css の `.rec-short` の但し書き）ので、
   **配向性の一文はほぼ隠れる**
3. **長すぎる。** 反応の解説文と連結されて 150字を超える。30〜45秒の尺で読ませられる量ではない

→ **配向性は独立の回にする。**「2つ目はどこに入る？」でクイズ型（IDEAS.md §1）にすれば、
o/m/p の3択がそのまま選択肢になり、**アプリの箇所選択UI（3箇所がハイライトされる）が見せ場になる**。
横型（`--format=wide`）ならトーストも読めるので、そちらの方が向いている。

### ⚠ 置換基が生える向きが**毎回同じとは限らない**（この回で見つけた）

同じ手順（全消去 → ベンゼン呼び出し → ニトロ化）を10回繰り返すと、**2通りの配置が混ざる**:

| 反応 | 出た配置（`calculateTargetBounds`） | 回数 |
|---|---|---|
| ニトロ化 | x 360–480 (w120) / y 260–340 (h80) … 真右に伸びる | 6/10 |
| 〃 | x 360–475 (w115) / y 265–389 (h124) … 右下に伸びる | 4/10 |
| スルホン化 | x 360–520 (w160) / y 260–340 (h80) | 6/10 |
| 〃 | x 360–475 (w115) / y 265–404 (h139) | 4/10 |
| 塩素化 | x 360–440 (w80) / y 265–369 (h104) | 8/10 |
| 〃 | x 360–480 (w120) / y 265–335 (h69) | 2/10 |

**原因は原子IDが乱数であること**。`aromaticSites()` は `mol.bonds` を走査して原子IDを `Set` に入れ、
**その挿入順の先頭**を置換位置に選ぶ。呼び出しのたびにIDが振り直されるため
`addBond` に渡る端点の順序が入れ替わり、**選ばれる環の頂点が変わる**（環の6頂点はどれも等価なので
化学的には正しいが、**絵は変わる**）。

- **したがって `frame` に `cx`/`cy` を書いてはいけない。**この回は全ステップで**自動中心**にしてある
- **`width` は2通りのどちらでも収まる値にする**。上の表の最大は w160・h139。
  水素の丸（r=6・最大 +16 外側）を左右上下に見て **+44** を足すと 204×183 →
  **`width 280`（→ 高さ 210）で両方の配置が収まる**。これが §5 の根拠
- 改修セッションが C-2（生成物を横一線に整える）を入れると**この揺れも変わる**。
  収録時に上の10回試行をやり直して、揺れが残っているか確かめること

## 5. 座標と構図の根拠（**すべて暫定値。収録時に測り直す**）

`frame` は `calculateTargetBounds`（＝重原子の中心）を基準に viewBox を張り直す。
水素の丸（r=6）は最大 +16 外側に出るので、**上下左右に +22 ずつ（計 +44）余分に取る**。

| ステップ | frame | 根拠 |
|---|---|---|
| 1・3・4・5 | **`width 280`（自動中心）** | ベンゼンと3つの生成物で**同じ幅にして、動くのは分子だけ**にする（V19 §6 と同じ考え）。最大の実体は スルホン化の 160×139 →＋44 で 204×183。`width 280` なら高さ 210 で収まる |
| 6 寄る | **`width 210`（自動中心）** | クロロベンゼン（最大 120×104 →＋44 で 164×148）に寄って「H が1つ Cl に置きかわっただけ」を見せる。高さ 157 |
| 7 TNT | **`width 380`（自動中心）** | 呼び出した TNT は x 276–483 / y 186–413（**207×227**）と大きい。＋44 で 251×271 → 高さが 271 要るので `width ≥ 361`。**`width 320` では上下が切れる** |

- **`cx`/`cy` は書かない**（§3 の「生える向きが揺れる」ため。自動中心なら向きが変わっても中心に来る）
- ステップ7だけスケールが変わるが、**別の分子に切り替わる合図**になるので意図どおり

### 測り直しの手順（実機のコンソール）

```js
// 目的の状態をキャンバスに出してから
const b = window.game.calculateTargetBounds(window.game.userMolecule);
[Math.round(b.maxX-b.minX), Math.round(b.maxY-b.minY)]   // → [w, h]
// frame の width は  max(w+44, (h+44)*4/3)  以上にする（frame の高さは width*3/4）
```
