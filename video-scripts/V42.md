## 3. 実機で確認したこと（2026-08-03・localhost:8123）

### プロペンに出る反応ボタンは付加4つ。**HBr は箇所選択が出ない**

| キャンバスの状態 | 出た反応ボタン |
|---|---|
| **プロペン（プロピレン）単体** | 付加: Br₂ / 付加: H₂ / **付加: HBr（マルコフニコフ則）** / 付加: H₂O |
| 反応後（2-ブロモプロパン） | 🔍 反応の前後を見る（付加: HBr（マルコフニコフ則）） のみ |

C=C は1本だけなので `multipleBondSites()` が返す site も1つ ＝ **`window.reactor.picking === false`**（実測）。
`reactionButton` は**押すだけで実行される**。`contains` は **`"HBr"`** で一意（反応前の4つのうち1つだけ）。

> 反応の**あと**は「🔍 反応の前後を見る（付加: HBr…）」に `HBr` が含まれる。**押すのは反応前なので当たらない**が、
> この回に2回目の HBr を足すときは `contains` を変えること（V41 の Br₂ と同じ注意）。

### マルコフニコフ則はモデル側に実装されている（reactor.js）

`addAcrossMultipleBond(game, site, 'Br', null, …)` が、**片側にしか置換基が付かない付加（HX・H₂O）のときだけ**
二重結合の両端の炭素の「炭素隣接数」を比べ、**多いほうに X を付ける**（reactor.js の `cX`/`cY` の入れ替え）。
`null` の側は明示原子を置かず自動水素に任せる ＝ **H が増えたことが H の丸の数で見える**。

→ プロペンでは C1（隣接する C は1つ）より C2（隣接する C は2つ）が多いので **Br は C2 ＝ 真ん中へ**。
**2-ブロモプロパン**（C₃H₇Br）が出る。**教科書どおりの主生成物**。

### 貫通チェック（LANES.md §4。**反応を実行したあとの生成物に対して流した**）

| 状態 | 名称チップ | 分子式 | 貫通 | 重原子の重なり |
|---|---|---|---|---|
| プロペン（呼び出し） | プロペン（プロピレン） | C₃H₆ | **0** | **0** |
| **HBr 付加の生成物** | **2-ブロモプロパン** | **C₃H₇Br** | **0** | **0** |

座標（重原子）:

```
呼び出し: C(358,300)=C(400,300) 二重結合 ／ C(421,336)-C(400,300)
付加後  : C(358,300)-C(400,300) 単結合   ／ C(421,336)-C(400,300) ／ Br(442,300)-C(400,300)
```

**呼び出しの時点で C=C が ±120° に開いている**（CLAUDE.md の「名称から呼び出した分子の、環に含まれない
C=C まわりは ±120°」）。そのため C3 が右下に落ち、**Br を置く右方向が空く**。
反応の前後で**炭素3つは1つも動かない**（Br が生えるだけ）ので、**変化点が Br だけ**に絞れている。

変化箇所のオレンジの点線は `(358,300) r25` `(400,300) r25` `(442,300) r17` の**3つ**。
**左の C にも印が付く**のは正しい ＝ そこに H が1つ増えているため。

### ⚠ Br が「右端」に見えないか（収録前に検討し、フレームで確認した）

Br は `(442,300)` ＝ **横一列に見ると右端**に置かれる。「真ん中の炭素についた」と言いながら
Br が右端に見えると誤読されうるので、**完成 mp4 のフレームで確かめた**（§5）。
結論: **真ん中の C から3本の結合（左の C・下の CH₃・右の Br）が出ている**のが太さで読めるうえ、
**オレンジの円が左の C・真ん中の C・Br の3つに付く**ので、Br の相手が真ん中の C であることは判別できる。
テロップも「Br は**真ん中の炭素に**ついた」と結合の相手を名指ししている。
