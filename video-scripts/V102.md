# V102 台本「構造式が示性式に変わる」（官能基シリーズ）

**縦 9:16・目標尺 25〜30秒・ずんだもん**。題材は **🔤 官能基をまとめる**。
まだ1本もショートにしていない機能で、**押した瞬間に絵が変わる**のがこの回の芯。

## 0. 実測（v1375・2026-08-15 に実機で確認）

**場所**: 分子を描く → 下の **`🔬 この分子を調べる`** → モーダルの中の **`🔤 官能基をまとめる`**
（⚠ 押すとモーダルは閉じる。結果はキャンバスの上に出るので、これは正しい振る舞い）

**酢酸で実測**:

| | キャンバスの文字 |
|---|---|
| 押す前 | `H H H H C C O O` |
| **押した後** | `H H H C **COOH**` |

- トースト: **「官能基をまとめて表示しています（作図データは変わっていません。クリックで元に戻せます）。」**
- ボタンのラベルが **`🔤 結合をすべて表示`** に反転する（＝ そのまま戻せる）

**つまり画面の上で「構造式 → 示性式」が起きる。** 高校生が板書で必ずやる書き換えが、
**同じ図のまま**目の前で切り替わる。

✅ **エステルも畳めるようになった**（発注書 A・v1380）。2026-08-16 に再実測:
**酢酸エチル `C C O O C C` → `C C C COO`**（`COO` が1かたまりになる）。
**この回はカルボン酸（酢酸）で撮り、最後に酢酸エチルを1つ足す**と
「カルボン酸だけの機能ではない」が1手で言える（下の章6）。

## 1. ナレーション（ずんだもん）

> **フック（0:00–0:06）**
> 構造式と示性式。**同じ分子の、書き方の違い**なのだ。

> **見せる（0:06–0:18）**
> 酢酸を描いたのだ。C と O が別々に並んでいる。
> 「この分子を調べる」から、**官能基をまとめる**。
> ——**-COOH** にまとまったのだ。CH₃COOH、これが示性式なのだ。

> **落ち（0:18–0:28）**
> 図はそのまま。**まとめて見せているだけで、作図データは変わっていない**のだ。
> もう一度押せば、結合が全部もどるのだ。

## 3. 収録（手動キャプチャ）

| # | 押すもの |
|---|---|
| 0 | **全消去** → 下の「名称から呼び出す」に **酢酸** |
| 1 | （**2秒静止**。C・C・O・O が別々に見える画） |
| 2 | 下の **`🔬 この分子を調べる`** |
| 3 | モーダルの **`🔤 官能基をまとめる`**（押すとモーダルは閉じる） |
| 4 | **`COOH` にまとまった瞬間で3秒静止**（ここが芯） |
| 5 | トーストの文（作図データは変わっていません）を見せる |
| 6 | **`🔤 結合をすべて表示`** を押して戻す（往復が見えると「表示だけ」が伝わる） |
| 7 | **全消去 → 酢酸エチル** を呼び出して同じことをする（`C C C COO`）。**尺が余ったときだけ** |

⚠ **切り出しはキャンバス側**。V99 のモーダル用 crop は使えない。
L1 リールと同じ手で**作図領域を crop して拡大**する（`crop=960:720:540:90 → 1080:810` が L1 での実測値）。

⚠ **戻す往復を必ず入れる。** 「図が変わってしまう」と誤解されるのがこの機能のいちばんの risk で、
往復1回でそれが消える。
