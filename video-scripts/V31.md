## 1. この回の芯: 3分子の「まん中」が同じ座標に並ぶ

`compounds.json` のアミノ酸のうち **グリシン・セリン・システイン・バリン・ロイシン・メチオニン・リシン
の7つは、まったく同じ骨格座標で作図されている**:

```
N(316,300) − C(358,300) − C(400,300) − O(442,300)
                            ‖
                          O(400,258)          側鎖は α炭素から真下（358,342 →384 →…）
```

呼び出すと 210px きざみで右へ平行移動して置かれるだけなので、
**3分子の N・α炭素・COOH が画面上でぴたりと横一列にそろう**（実測: x=316 / 526 / 736、y はすべて 300）。
つまり「共通の形は同じ・ちがうのは下にのびる側鎖だけ」を、**テロップで主張せずに画面の事実として**見せられる。

さらに ①②③ を同じ `width` で順に寄っていくと、**上の骨格は1ミリも動かず、下の側鎖だけが入れ替わる**
カメラワークになる。作図も反応実行もせず、`summon` と `frame` だけで組めるのはこのため。

**アラニンは使えない**（この理由でトリオから外した）。`compounds.json` に「アラニン」単体は無く、
**L-アラニン / D-アラニン は縦置き（COOH が上・CH₃ が下・NH₂ が左）で骨格の向きが違う**。
混ぜると横一列がそろわない。同じ横並び骨格を持つ7つの中から、側鎖の型が異なる
**グリシン（H）・セリン（-CH₂OH）・バリン（-CH(CH₃)₂）** を選んだ。

## 4. 座標と構図の根拠

呼び出したときの配置は固定なので `frame` は実測でよい（実機で `game.userMolecule.atoms` を読んだ）。

| 対象 | 論理座標の範囲 | frame |
|---|---|---|
| ① グリシン | x 316–442 / y 258–300（側鎖なし） | `cx 379, cy 315, width 250` |
| ② セリン | x 526–652 / y 258–384（側鎖 -CH₂OH が真下） | `cx 589, cy 315, width 250` |
| ③ バリン | x 736–862 / y 258–342（側鎖 -CH(CH₃)₂） | `cx 799, cy 315, width 250` |
| 3分子まとめて | x 316–862 / y 258–384 | `cx 589, cy 321, width 660` |
| ①② の対比（③ は画面外） | x 316–652 | `cx 484, cy 315, width 400` |

- **寄りの3枚は `cy` と `width` を固定してある**。`cx` だけ 379→589→799 と動くので、
  カメラは純粋な横パンになり、骨格が画面の同じ高さに居座り続ける。この回の主張そのもの
- 引きの `width 660` は、中身 546px に対して左右 57px ずつの余白。
  これ未満にすると端の H ラベルが切れる

### 不斉炭素マークの使い方（この回で分かったこと）

`#btn-asym-mark` は **ON にして炭素をタップすると `*` を付ける編集モード**で、
**押した炭素が本当に不斉炭素かどうかの検査はしない**（ホバー中のプレビュー円の色だけが
オレンジ＝正しい／赤＝誤マーク を教える）。したがって:

- **グリシンの α炭素は絶対にタップしない**。タップすれば嘘の `*` が付いてしまう
- ②③ だけをタップし、**「① には付いていない」を画で見せる**。
  アプリの判定そのものは実機コンソールで裏取りした（§6）
- **タップし終わったらもう一度 `#btn-asym-mark` を押して OFF に戻す**。
  ONのままだとカーソルの下の炭素に破線のプレビュー円が出っぱなしになり、
  最後の静止画で「セリンの α炭素が光っている」ように見えて `*` と紛らわしい。
  OFF に戻すとカーソルが下のツールバーへ抜けるので、分子の上から人差し指も消える
