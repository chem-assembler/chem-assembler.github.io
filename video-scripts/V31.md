## 1. この回の芯: 3分子の「まん中」が同じ座標に並ぶ

3つとも、次の**まったく同じ骨格**で描いてある（x は分子ごとに 260px きざみで右へずらすだけ）:

```
    N(328,270)
        \
         C(358,300) ── C(400,300) ── O(442,300)      ← -COOH
             |             ‖
             |           O(400,258)
        側鎖は α炭素の真下（358,342 → 384 → 426 …）
```

- **① グリシン** … 側鎖なし（H）。原子5個
- **② アラニン** … 側鎖 -CH₃ が1個ぶら下がるだけ
- **③ グルタミン酸** … 側鎖が -CH₂-CH₂-COOH と長く、**その先にもう1つカルボキシ基**

**N・α炭素・-COOH は3分子とも画面上の同じ高さ（y=270/300）にそろう**ので、
寄りのカメラを右へ振っても**上の骨格は1ミリも動かず、下の側鎖だけが伸びていく**。
「共通の形は同じ・ちがうのは側鎖だけ」を、テロップで主張せずに**画面の事実として**見せられる。

さらに、側鎖が長くなるほど分子が下へ伸びるので、**①→②→③ で側鎖が育つ**という
時間方向の見え方にもなる。作図も反応実行もせず `frame` だけで組めるのはこのため。

## 4. なぜ `summon` をやめて `state` にしたか（**この回でいちばん大事な発見**）

**名称から呼び出すと、この3種は骨格の向きがそろわない。**
アプリの名称ライブラリは `stages.json` と `compounds.json` を連結し、**`stages.json` を先に**引く。
3種とも stages 側に同名エントリがあるため、**compounds.json を整えても呼び出しには効かない**:

| 名前 | 呼び出しで出る図（stages.json） | compounds.json 側（C-4b で整えたもの） |
|---|---|---|
| グリシン | `N(316,300) C(358,300) C(400,300) O(400,258) O(442,300)` | 同じ |
| アラニン | `C(316,300) C(358,300) C(400,300) O(400,258) O(442,300) N(328,270)`<br>＝ **NH₂ が斜め・CH₃ が左端**（主鎖の左端が N ではない） | `N(316,300) … C(358,342)`<br>＝ NH₂ が左端・CH₃ が真下 |
| グルタミン酸 | `C(244,330) C(286,330) C(328,330) C(358,300) C(388,330) N(388,270) …`<br>＝ **側鎖の COOH が左・α炭素だけ上に飛び出るジグザグ** | 側鎖が x=358 を 42px きざみで真下 |

> **検品レビュー C-4b の「✅ 完了（v345）」は compounds.json 側の話**で、
> **呼び出しの見た目までは変わっていない**（実機で確認）。台本を書くときは
> **必ず実機で `summon` した結果の座標を読む**こと。データを読んだだけでは食い違う。

呼び出したままだと **α炭素の高さすら 3分子でそろわない**（グルタミン酸だけ y=258、他は y=300）ので、
「共通の形は同じ」という**この回の芯が画で成立しない**。そこで `state`（demos-stereo.json の V10 等と
同じ開始状態指定）で3分子を置き、**compounds.json 側の整った骨格に合わせて**描いている。

### 骨格は「NH₂ を斜め」にした（Fischer 誤読の回避）

**compounds.json の形（NH₂ が主鎖の左端＝ α炭素の真横）をそのまま使うと、
アラニンの名称チップが「D-アラニン」になる。**
α炭素のまわりが 上=H／右=COOH／下=CH₃／左=NH₂ の十字になり、
`readAtomParityFromFischer()`（±25°以内の4軸に全置換基が乗ると発動）が
**フィッシャー投影とみなしてパリティを読む**ため。天然のアラニンは L なので、これは出せない。

**stages.json のアラニンと同じく NH₂ を α炭素の左上 45°（-30,-30）に置くと**、
軸から外れて Fischer 読みが起きず、**「アラニン」と総称名で出る**（実機で確認）。
グリシン・グルタミン酸もこの形にそろえた。**立体を主張しない回では、この置き方が安全**。

> グルタミン酸は D/L のエントリが無いので Fischer 読みが起きても名前は変わらないが、
> **3分子の骨格をそろえるのが芯**なので同じ形にしてある。

### 冒頭の「シートが開いている 3.5秒」が消えた

`summon` は右パネル（モバイルではシート）を開くので、V11・旧 V31 は**冒頭 3.5秒がパネルで埋まって**いた。
`state` にしたことでこれが無くなり、**1フレーム目から3分子が並んでいる**。
カバー画像の選択肢が冒頭まで広がった（§7）。

## 5. 座標と構図の根拠（2026-08-01 実機実測）

分子は 260px きざみ。実機で `game.userMolecule.atoms` と見出し `text` の `getBBox()` を読んだ値:

| 対象 | 重原子の範囲 | 見出し | frame |
|---|---|---|---|
| ① グリシン | x 328–442 / y 258–300 | ① グリシン | `cx 385, cy 315, width 280` |
| ② アラニン | x 588–702 / y 258–342 | ② アラニン | `cx 645, cy 315, width 280` |
| ③ グルタミン酸 | x 848–962 / y 258–468 | ③ グルタミン酸 | `cx 905, cy 315, width 280` |
| 3分子まとめて | x 328–962 / y 258–468 | — | `cx 645, cy 385, width 710` |
| ①② の対比（③ は画面外） | x 328–702 | — | `cx 515, cy 350, width 450` |

- **H ラベルは重原子から左右へ 18.8px はみ出す**。上の x に ±18.8 して当たり判定すること
- **寄りの3枚は `cy 315`・`width 280` で固定**。`cx` だけ 385→645→905 と動くので、
  カメラは純粋な横パンになり、骨格が画面の同じ高さに居座り続ける。この回の主張そのもの

### ⚠ `frame` の縦の見え幅は `width × 3/4` ではない（2026-08-01 に判明）

`frame` は viewBox を `width × 0.75width` に張り直すが、**キャンバスの SVG 要素は 4:3 よりずっと縦長**
（収録時 810×約1250）なので、`preserveAspectRatio` の meet で**横に合わせて縦は余る**。
**実際に見えている縦幅 ≒ width × 1.59**（収録フレームから逆算）。したがって:

- **キャンバス見出し（①②③）を「4:3 の外だから写らない」と計算して落とすことはできない**。
  V32.md の旧記述「width 230 は見出しを画面外に落とす値」は**この誤解による**
- 縦は余るので、`cy` は「**名称チップ（画面上部の帯）に分子が被らない高さ**」で決めるのが実務
- 目安: **チップの下端は viewBox の上端から `width × 0.45` あたり**（2行チップの実測）。
  最初 `cy 350 / width 250` で組んだらグルタミン酸の上端がチップに食い込んだので、
  **`width 280 / cy 315`（＋分子間隔を 210→260 に拡大）**に直した

### 分子の間隔を 210 → 260 にした理由

`summon` の既定間隔 210px のままだと、**寄り（width 280）で隣の分子の H ラベルが画面に入る**。
`state` なら間隔は自由なので 260 にした。**寄りの3枚とも、隣は 44px 以上の余白をもって画面外**。

### 不斉炭素マークの使い方（この回で分かったこと）

`#btn-asym-mark` は **ON にして炭素をタップすると `*` を付ける編集モード**で、
**押した炭素が本当に不斉炭素かどうかの検査はしない**（ホバー中のプレビュー円の色だけが
オレンジ＝正しい／赤＝誤マーク を教える）。したがって:

- **グリシンの α炭素は絶対にタップしない**。タップすれば嘘の `*` が付いてしまう
- ②③ の α炭素（`(618,300)` と `(878,300)`）だけをタップし、**「① には付いていない」を画で見せる**。
  アプリの判定そのものは実機で裏取りした（§7）
- **タップし終わったらもう一度 `#btn-asym-mark` を押して OFF に戻す**（実機で2回押すと
  `game.asymmetricMode` が false・`active` クラスも外れることを確認）。
  ONのままだとカーソルの下の炭素に破線のプレビュー円が出っぱなしになる。
  OFF に戻すと収録カーソルが下のツールバーへ抜けるので、分子の上から人差し指も消える
