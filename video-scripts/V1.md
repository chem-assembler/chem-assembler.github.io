## 3. 操作手順（実演の詳細・収録者向け)

1. ステージは自由モード（検証や出題のない画面）で開始。キャンバスは空
2. 0-3s 用の完成フェノールは**先に作って画面収録**し、編集で冒頭に置く（撮影は逆順が楽）
3. 実演本体: C を3個 L 字に置く → 中央の結合をタップして二重結合→三重→単結合に戻す →
   全消し（または新規）→ ベンゼン環モジュール配置 → OH モジュールを環の1頂点へ →
   名称表示「フェノール」を1秒静止で見せる
4. Undo デモ: OH をもう1個 変な位置に付けて → Undo → 元に戻る様子
5. 立体ビュー: フェノールのまま立体ビューを開き、1回転だけ（2秒以内。見せすぎない）
