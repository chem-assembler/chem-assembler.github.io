## 1. この回の芯

**原子のつながり方が同じでも、立体が違えば別の物質。**
そして「別の物質」の意味は **「重ね合わせられない」** という1点に尽きる。

| 関係 | 意味 |
|---|---|
| 同じ分子 | 回転だけで重なる |
| **鏡像異性体** | **鏡に映せば重なるが、そのままでは重ならない** |
| 別の立体異性体（ジアステレオマー） | 鏡像でもなく、重ねられもしない |

**この回は「同じ分子か／鏡像か」だけで完結させ、R/S には一切踏み込まない。**
アプリの立体異性体クイズも CIP を使わず、**描かれた図から読んだ立体どうしの比較**で判定している
（`quiz.js` の `StereoQuiz.relationOf`。`chemistry.js:1222` ほかの方針どおり）。

## 3. ⚠ 化学で迷った点（この回の最大の注意）

**出題は答え（鏡像異性体）を固定できるが、どの化合物が出るかは固定できない。**
標準の出題範囲で「鏡像異性体」を指定すると、ライブラリの D/L の組だけが残る:

| 組 | 図 | 使える |
|---|---|---|
| D-乳酸 ／ L-乳酸 | どちらも**縦置き**のフィッシャー投影 | ◎ |
| D-アラニン ／ L-アラニン | どちらも**縦置き** | ◎ |
| D-グリセルアルデヒド ／ L-グリセルアルデヒド | どちらも**縦置き** | ◎ |
| **「乳酸」**（接頭辞なし） ／ L-乳酸 | 「乳酸」は**主鎖が横向き** | **✗ 使わない** |
| **「アラニン」**（接頭辞なし） ／ L-アラニン | 「アラニン」は**主鎖が横向き** | **✗ 使わない** |

`compounds.json` の接頭辞なしの「乳酸」「アラニン」は
`C(316,300) C(358,300) C(400,300)` ＝ **主鎖が横一直線**に登録されている。
アプリはこれを**フィッシャー投影の規約（縦＝奥・横＝手前）で読んで D と判定する**
（`readAtomParityFromFischer` は十字であれば向きを問わない。向きを見るのは
D/L の呼び名を決める `assignDLDescriptor` だけで、そちらは横向きを弾く＝
**だから名前に D が付かない**）。内部では筋が通っているが、**動画としては使えない**:

1. **接頭辞なしの「乳酸」を L-乳酸 と並べて「立体が違う」と言うのは紛らわしい**
   （ふつう接頭辞なしの名前は立体を指定しない）
2. **横置きの図と縦置きの図を並べて「違うのは立体だけ」と言うと、
   V51 で教えたばかりの「まるごと90°回すと鏡像になる」と真正面からぶつかる**

**採用した収録は L-グリセルアルデヒド（左）／ D-グリセルアルデヒド（右）**。
D/L の基準そのものの分子で、どちらも縦置きのフィッシャー投影
（CHO 上・CH₂OH 下・OH が D は右／L は左）＝ **この回にいちばん向いた組**だった。

- 収録は**6テイク**。答えは毎回 `quizForce` どおり鏡像異性体で出た（**答えの外れはゼロ**）ので、
  撮り直しの理由は**化合物の当たり外れ**と、下の §4 の詰め直しだけ

## 4. ⚠ タップの輪が取り残される（この回で見つけた不具合）

**解答ボタンを押すと、結果の文と「🫟 重ねて確かめる」が現れてモーダルが縦に伸びる。
モーダルは上下中央そろえなので中身が上へずれるが、タップの輪（カーソル）は画面座標に
残るため、輪だけが1つ下のボタンの上に取り残される。**

初回の収録では、テロップが「答え: 鏡像異性体」と出ているのに
**輪はオレンジの「別の立体異性体」の上にあり、誤答したように見えた**（約2.3秒）。

**対処: `button` の直後に `hover` を1つ置いて、輪を画面下の死角へ逃がす。**

```json
{ "type": "button", "selector": "#btn-sq-enantiomer" },
{ "type": "hover", "x": 400, "y": 583 },
```

- 論理座標 `(400, 583)` は 810×1440 で**画面下端（client 405,1330）**に落ちる。
  既定の選択ツールは `select` なので、`hover` はプレビューを描かない（LANES.md §4-8）
- **同じことが「🫟 重ねて確かめる」でも起きる**（解説文が下に増えて輪が文字に重なる）。
  こちらにも `hover` を入れてある
- 実測コストは **0.73秒**（LANES.md の 0.79秒とほぼ同じ）
