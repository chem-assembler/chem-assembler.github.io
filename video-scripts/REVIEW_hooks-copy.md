# タスクJ（フック35案）・タスクL（サイトコピー）の検証結果

検証日: 2026-07-28 / 検証者: Claude（Opus 5）

## タスクJ: フック文案35案

質は高い。型（疑問・断定・数字・共感）が指示どおり散らしてあり、字数も守られている。
**30案は使える。5案は方針違反または事実の裏付けがない。**

### 使わない・書き換える（5件）

| 動画 | 案 | 問題 |
|---|---|---|
| V7 | 「**9割が**「別物」と騙される回転トラップ」 | **依頼文で禁止した型**（「9割が知らない」の乱発を避ける）。しかも根拠のない数字。→「回転させただけ、それとも別物？」に |
| V2 | 「構造式を描き間違えると**危険な理由**」 | 前提が偽。紙に構造式を描き間違えても危険はない。煽りのための嘘 |
| V5 | 「ノートの描画を3Dに変える**神アプリ**」 | 自画自賛の俗語。誠実トーンの方針に反する（他人が言うのはよいが自分で言わない） |
| V3 | 「どの端末でも**1秒で動く**」 | 未計測の性能値（X投稿ネタと同じ問題）。実測してから使う |
| V8 | 「主要官能基**7選**」 | 7という数の根拠がない。実際に見せる官能基の数に合わせる |

### 特に良い（採用候補）

- **V6-1「お酒を放置すると酢になるって本当？」**——酢酸菌による酸化で実際に起こる。
  身近さと化学が正しくつながっている**今回いちばんの当たり**
- **V5-1「教科書の平面図、本物は立体でした」**——アプリの立体対照ビューの思想そのもの
- **V7-1「この2つの分子、同じ？それとも別物？」**——コメントを誘発する二者択一
- **V2-1「お酒の成分とガス、同じ分子式ってマジ？」**——ジメチルエーテルが常温で気体なのは事実
- **V6-3「Hが2個抜けるとアセトアルデヒド！」**——酸化＝脱水素を正しく言えている

## タスクL: サイトコピー

構成・語り口は良い（生徒の困りごとから書き起こせている）。ただし
**アプリの機能説明に、X投稿ネタと同じ種類の誇張・誤りが混じっている**ので、そのままは使えない。

### 要修正の記述

| 記述 | 事実 |
|---|---|
| 「**IUPAC化合物名**を自動判定」 | 正準コードによる同型判定＋**名称ライブラリとの照合**。IUPAC 命名規則から名前を生成しているわけではない。「登録済みの化合物名を自動で表示」が正確 |
| 「3D立体モデルに変換され、指やマウスで**自由自在に回転**」 | 立体ビューの回転は**軸の切り替えとスライダー・ボタン操作**。自由回転ではない |
| 「**官能基ごとの色分け**表示」 | そのような機能はない（あるのは「官能基をまとめる」縮約表示） |
| 「不斉炭素原子の**自動ハイライト**」 | 不斉判定は自動だが、表示は**✳マークを付けるモード**。「自動で光る」ではない |

### 採用してよい表現

- 「手書きでノートが汚れたり、異性体の書き漏らしで悩む受験生へ」——困りごとからの書き起こしが良い
- 「暗記に頼らず、分子の組み立て体験を通して」——アプリの思想と一致
- 「係数合わせを『単なる数字の計算』だと思っていませんか？」——ion-equation の狙いと一致
- カード用「タップで炭素をつなぐと化合物名が自動表示される有機化学パズル」——**事実に即していて簡潔。採用**

## 反映したもの

- 化学ハブ index.html の meta description / og:description を、
  **上記の誤りを避けつつ「困りごと起点」の良さを取り入れた文面**に差し替え（下記）
- 残り（アプリ紹介文の概要用・詳細用）は、機能記述を事実に直したうえでハブのカード文言に順次反映する

## 教訓の追加

**サイトコピーでも同様に起きる**。ユーザーに見える説明文はなおさら事実確認が要る。
