# 合成音声が読み違える語（ナレーション原稿を書くときの引き当て表）

**VOICEVOX は化学用語を読み違える。** 原稿の JSON に**かなで書いて回避する**
（VOICEVOX にルビの仕組みは無いので、漢字のままでは直せない）。

## 使い方

1. 原稿（`video-scripts/narration/V<N>.json`）を書くとき、下の表に載っている語は**かなで書く**
2. `python video-scripts/narrate.py <原稿>` は**1行ごとに読み（kana）を表示する**。
   **音を聞く前にここを読む**——これが唯一の検査で、聞き逃すと投稿まで気づかない
3. 新しい誤読を見つけたら**この表に足す**（下の「見つけ方」）

### ⚠ 「通り」——ここは3回外している（2026-08-19 に実測で決着）

**罠は「〜いち通り」だけ。** ほかの数はひらがなで正しく読める。V99 の原稿で実測した:

| 書き方 | 読まれ方 | 判定 |
|---|---|---|
| `にひゃくじゅういち通り` | ニ・ヒャクジュウ・**ヒトトオリ** | ❌ |
| `にひゃくじゅういちどおり` | （濁って不自然） | ❌ **この表に「どおりと書け」と書いてあったのが誤り** |
| `２１１とおり` | ニヒャク・ジュウ・**イットオリ** | ❌ 数字のままはさらに悪い |
| `にひゃくじゅういち とおり`（空白） | ニ・ヒャクジュウ・イチ・トオリ | △ 正しいが**区切れて 1.5秒長い** |
| **`にひゃくじゅういちトオリ`** | ニ・ヒャクジュウ・**イチトオリ** | ✅ **これが正解** |
| `ひゃくきゅうじゅうさんとおり` | ヒャクキュウジュウ・**サントオリ** | ✅ ひらがなでよい |
| `さんとおり` / `ごじゅうごとおり` | サントオリ／ゴジュウゴトオリ | ✅ ひらがなでよい |

**つまり「いち＋とおり」だけが「一通り」の語に吸われる。** カタカナの `トオリ` で書くと外れる。
**ほかの数まで巻き込んでカタカナにしない**（不要なうえ、読みが硬くなる）。

**数字も同じ**。V91 の原稿は温度を `ひゃくろくじゅうから、ひゃくななじゅう度` と
かなで書いてある（`160〜170` のままだと「〜」の読み方が安定しない）。
**単位つきの範囲・比・化学式の添字**は、原稿の時点でかなに開くのが安全。

## 見つけ方

- **narrate.py が出す kana を毎回読む。** 化学用語が並ぶ行はとくに
- **VOICEVOX が動いていれば1語ずつ確かめられる**（`http://127.0.0.1:50021`）:

```
python -c "import urllib.request,urllib.parse,json;q=urllib.request.urlopen(urllib.request.Request('http://127.0.0.1:50021/audio_query?speaker=3&text='+urllib.parse.quote('濃硫酸'),method='POST')).read();print(json.loads(q)['kana'])"
```

  ⚠ **VOICEVOX が起動していないと確かめられない**（この表を作った 2026-08-15 の時点では
  起動しておらず、濃硫酸が実際にどう読まれたかは**ユーザーの耳による報告**が根拠）

## なぜ表にするか

誤読は**投稿してから気づく**（V91 がそうだった）。ショートは差し替えができないので、
**同じ語を次に使うときに繰り返さない**ことしか手が無い。この表はそのためだけにある。
