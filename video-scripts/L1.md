## 2. ナレーション全文（実声・です/ます調）

そのまま読める文言。**尺の同期は「demo 側の narration フィールド」が正**
（各ステップの尺は narration の文字数から自動算出されるため、修正はこの台本→demo の順で反映する）。

> **OP**
> 構造式を、ノートに書く感覚で描けて、描いたそばから名前がわかる。
> 無料の学習アプリ「パズルでみる有機化学」の使い方を、ひととおり紹介します。
> インストールも登録もいりません。パソコンでもスマホでも、ブラウザでリンクを開けばすぐ使えます。
> リンクは概要欄にあります。

> **① 構造式を描く**
> まずは描き方です。マス目をタップすると、炭素が置かれます。隣のマスに置くと、自動でつながります。
> 水素は原子の手の数に合わせて自動で付くので、考えるのは炭素の骨組みと、酸素などの目立つ原子だけ。
> パレットから酸素を選んで、置いてみます。
> 間違えたら、消しゴムで消すか、「戻す」でやり直せます。

> **② 描くと名前がわかる**
> 描いた分子が何かは、名前チップがその場で教えてくれます。いま描いたのは、エタノール。
> ここで酸素を真ん中に差し替えると――ジメチルエーテルに変わりました。
> 分子式は同じ C2H6O でも、つながり方が違えば別の物質。
> 異性体の感覚が、手を動かしながら身につきます。

> **③ お題に挑戦**
> お題を解くパズルモードもあります。お題の分子を作って、構造判定ボタンを押すと、正しければクリア。
> 行き詰まったら、お手本を見ることもできます。
> ステージは基本から順に並んでいるので、授業の進み方に合わせて使えます。

> **④ 異性体を調べる**
> 「同じ分子式の異性体を調べる」ボタンを押すと、いま描いている分子と同じ分子式の構造異性体を、
> アプリが数え上げてくれます。C4H10O なら、アルコールが4つ、エーテルが3つで、合わせて7種類。
> 定期テスト前の書き出し練習に、答え合わせ付きで使えます。

> **⑤ 反応を実行する**
> 描いた分子に、反応を実行できます。エタノールを酸化すると、アセトアルデヒド。
> もう一度酸化すると、酢酸になりました。
> 結合が組み変わる様子がアニメーションで見えるので、
> 反応式を丸暗記ではなく、構造の変化として覚えられます。

> **⑥ 立体で見る**
> 平面の構造式は、立体でも見られます。「立体で見る」を押すと、くさび形の図と3Dモデルが並んで表示されて、
> ドラッグでくるくる回せます。不斉炭素に印を付ける道具や、フィッシャー投影の練習モードなど、
> 立体化学の道具も一そろい入っています。詳しい使い方は、別の動画で紹介します。

> **ED**
> 使い方は以上です。無料・登録不要で、概要欄のリンクからすぐ使えます。
> 姉妹アプリの「イオンでみる化学反応式」も同じ場所にあります。
> 新しい機能や短い解説を随時上げていくので、よければチャンネル登録をお願いします。

## 4. 収録・組み立て手順

```
# 0) サーバー（リポジトリルート）
python -m http.server 8125

# 1) 章ごとに wide で収録（テロップなし・等速）
node tools/record/record.mjs --demo=l1-intro    --format=wide --caption=0 --speed=1
node tools/record/record.mjs --demo=l1-naming   --format=wide --caption=0 --speed=1
#   … l1-stage / l1-isomers / l1-reaction / l1-stereo / l1-outro も同様

# 2) 章タイトルカード（3秒・6枚）を ffmpeg drawtext で生成し、連結リストへ
#    連結（同一コーデック・同一サイズなので concat demuxer。1回だけ再エンコード）
ffmpeg -f concat -safe 0 -i video-scripts/out/L1-list.txt -c:v libx264 -r 30 \
       video-scripts/out/L1-silent.mp4

# 3) 仮ナレで尺確認（VOICEVOX。読み上げ練習と章尺の検算用。公開には使わない）
python video-scripts/narrate.py video-scripts/narration/L1.json

# 4) 実声アフレコ: L1-silent.mp4 を再生しながら章単位で録音（スマホ録音可）
#    章ごとの wav を ffmpeg concat で full.wav に

# 5) mux（BGM は実声の邪魔をしない音量に）
node tools/record/mux.mjs --video=video-scripts/out/L1-silent.mp4 \
  --audio=video-scripts/audio/L1/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --meta=video-scripts/meta/L1.json --size=1920x1080 \
  --out=video-scripts/out/L1-final.mp4
```

- 手順2のタイトルカードが面倒なら、**1本目は demo 冒頭の caption（wide の既存字幕スタイル）で代用**してよい。
  カード生成がうまくいったら共通化して tools/record に足す
- 実声の録り直しは章単位で済む（映像は変わらないので mux だけやり直し）
