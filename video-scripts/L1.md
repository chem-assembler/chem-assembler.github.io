## 2. ナレーション全文（実声・です/ます調）

そのまま読める文言。**尺の同期は「demo 側の narration フィールド」が正**
（各ステップの尺は narration の文字数から自動算出。修正はこの台本→demo の順で反映する）。

> **OP**
> 構造式を、ノートに書く感覚で描けて、描いたそばから名前がわかる。
> 無料の学習アプリ「パズルでみる有機化学」の、はじめての使い方を3分で紹介します。
> インストールも登録もいりません。リンクは概要欄にあります。

> **① 構造式を描く**
> マス目をタップすると、炭素が置かれます。隣のマスに置くと、自動でつながります。
> 水素は原子の手の数に合わせて自動で付くので、考えるのは炭素の骨組みと、酸素などの目立つ原子だけ。
> パレットから酸素を選んで、置いてみます。
> 間違えたら、消しゴムで消すか、「戻す」でやり直せます。

> **② 描くと名前がわかる**
> 描いた分子が何かは、名前チップがその場で教えてくれます。いま描いたのは、エタノール。
> ここで酸素を真ん中に差し替えると――ジメチルエーテルに変わりました。
> 分子式は同じ C2H6O でも、つながり方が違えば別の物質。
> 異性体の感覚が、手を動かしながら身につきます。

> **③ お題に挑戦**
> お題を解くパズルモードもあります。お題の分子を作って、構造判定ボタンを押すと、正しければクリア。
> 行き詰まったら、お手本を見ることもできます。
> ステージは基本から順に並んでいるので、授業の進み方に合わせて使えます。

> **ED（ダイジェストに重ねる）**
> このほかにも、描いた分子を酸化したりエステルにしたりする反応実行、
> くさび図と3Dで見る立体表示、名前や異性体のクイズなど、道具がひととおり揃っています。
> 使い方は1本ずつ短い動画にしてあるので、概要欄の再生リストからどうぞ。
> アプリは無料・登録不要です。よければチャンネル登録もお願いします。

## 4. 収録・組み立て手順

```
# 0) サーバー（リポジトリルート）
python -m http.server 8125

# 1) 章ごとに wide で収録（テロップなし・等速）
node tools/record/record.mjs --demo=l1-intro  --format=wide --caption=0 --speed=1
node tools/record/record.mjs --demo=l1-naming --format=wide --caption=0 --speed=1
node tools/record/record.mjs --demo=l1-stage  --format=wide --caption=0 --speed=1
node tools/record/record.mjs --demo=l1-digest --format=wide --caption=0 --speed=1
node tools/record/record.mjs --demo=l1-outro  --format=wide --caption=0 --speed=1

# 2) 章タイトルカード（3秒・3枚。①は入れない＝OPから地続き）
#    ffmpeg は imageio-ffmpeg のフルビルドを使う（mux.mjs と同じ）:
#    FF=$(python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
"$FF" -y -f lavfi -i color=c=0x0b0f16:s=1920x1080:d=3:r=30 \
  -vf "drawtext=fontfile='C\:/Windows/Fonts/BIZ-UDGothicB.ttc':text='② 描くと名前がわかる':fontcolor=0xE8F8FF:fontsize=84:x=(w-text_w)/2:y=(h-text_h)/2" \
  -c:v libx264 -pix_fmt yuv420p video-scripts/out/L1-card2.mp4
#   card3「③ お題に挑戦（パズル）」・card4「まだまだあります」も同様

# 3) 連結（webm と mp4 の混在＋digest の2倍速化を concat フィルタで一括。
#    concat demuxer はコーデック混在で使えないのでフィルタ方式にした・2026-08-04 実施）
"$FF" -y -i out/l1-intro-wide.webm -i out/L1-card2.mp4 -i out/l1-naming-wide.webm \
  -i out/L1-card3.mp4 -i out/l1-stage-wide.webm -i out/L1-card4.mp4 \
  -i out/l1-digest-wide.webm -i out/l1-outro-wide.webm \
  -filter_complex "[0:v]fps=30,scale=1920:1080,setpts=PTS-STARTPTS,format=yuv420p[v0];（…各入力同様。digest だけ setpts=0.5*(PTS-STARTPTS) で2倍速…）;[v0][v1][v2][v3][v4][v5][v6][v7]concat=n=8:v=1:a=0[v]" \
  -map "[v]" -c:v libx264 -crf 18 video-scripts/out/L1-silent.mp4

# 4) 仮ナレで尺確認（VOICEVOX。読み上げ練習と章尺の検算用。公開には使わない）
python video-scripts/narrate.py video-scripts/narration/L1.json

# 5) 実声アフレコ: L1-silent.mp4 を再生しながら章単位で録音（スマホ録音可）
#    章ごとの wav を ffmpeg concat で full.wav に

# 6) mux（BGM は実声の邪魔をしない音量に）
node tools/record/mux.mjs --video=video-scripts/out/L1-silent.mp4 \
  --audio=video-scripts/audio/L1/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --meta=video-scripts/meta/L1.json --size=1920x1080 \
  --out=video-scripts/out/L1-final.mp4
```

- 手順3のタイトルカードが面倒なら、**1本目は demo 冒頭の caption（wide の既存字幕スタイル）で代用**してよい。
  カード生成がうまくいったら共通化して tools/record に足す
- 実声の録り直しは章単位で済む（映像は変わらないので mux だけやり直し）
