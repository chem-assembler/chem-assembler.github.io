## 3. 実機で確認したこと（2026-08-02・v362・localhost:8132）

### エチレンに出る反応ボタンは付加4つ。**ベンゼンには付加が1つも出ない**

| キャンバスの状態 | 出た反応ボタン |
|---|---|
| **エチレン（エテン）単体** | 付加: Br₂（臭素水の脱色） / 付加: H₂（水素化・Ni触媒） / 付加: HBr（マルコフニコフ則） / 付加: H₂O（酸触媒・水和） |
| **ベンゼン単体** | 芳香族置換: ニトロ化（濃硝酸＋濃硫酸） / 芳香族置換: スルホン化（濃硫酸） / 芳香族置換: 塩素化（Cl₂・鉄触媒） |
| **アセチレン（エチン）単体** | 付加4つ（エチレンと同じ顔ぶれ） |
| **エチレン ＋ ベンゼン**（この回の画） | 付加4つ ＋ 芳香族置換3つ ＝ 7つ |

**「ベンゼンには付加のボタンが出ない」こと自体が答え**になっている。
理由はモデル側にある: `multipleBondSites()` は `findFunctionalGroups()` の `cc_double` / `cc_triple` を
拾うが、**`findFunctionalGroups()` は芳香環の交互二重結合を除外する**（chemistry.js の
「C=C / C≡C（芳香環の交互二重結合は除く）」）。だから**ベンゼン環の6本は付加の候補にならない**。

### Br₂ の付加は**箇所選択（`picking`）が出ない**

2分子を並べても `multipleBondSites()` が返す site は**エチレンの C=C の1つだけ**なので、
`reactionButton` は**押すだけで実行される**（`window.reactor.picking === false` を実測）。
`contains` は **`"Br₂"`** で一意（反応前のボタン7つのうち Br₂ を含むのは1つだけ）。

> 反応の**あと**は「🔍 反応の前後を見る（付加: Br₂（臭素水の脱色））」が増えて
> `Br₂` を含むボタンが2つになる。**押すのは反応前なので当たらない**が、
> この回に2回目の Br₂ を足すときは `contains` を変えること。

### 生成物の貫通チェック（LANES.md §4。**反応を実行したあとの生成物に対して流した**）

| 状態 | 名称チップ | 分子式 | 貫通 | 重原子の重なり |
|---|---|---|---|---|
| エチレン ＋ ベンゼン（呼び出し） | ① エチレン（エテン） ＋ ② ベンゼン | C₈H₁₀ | **0** | **0** |
| **Br₂ 付加の生成物** | **① 1,2-ジブロモエタン ＋ ② ベンゼン** | **C₈H₁₀Br₂** | **0** | **0** |
| （参考）アセチレン → Br₂ 付加 | 1,2-ジブロモエテン | C₂H₂Br₂ | **0** | **0** |

生成物の座標（重原子）:

```
① C(379,300)-C(421,300) 単結合 ／ Br(379,258)-C(379,300) ／ Br(421,258)-C(421,300)
② C(566,300) C(546,335) C(506,335) C(486,300) C(506,265) C(546,265)  ← 呼び出したときと1つも動いていない
```

**②の6原子は反応の前後で完全に同一**。「変わらない」を座標でも裏づけてある。
**C=C が単結合になり、Br が2つ生えた**のが①だけ ＝ 教科書どおりの付加。

### 変化箇所のハイライトも ① にしか出ない

反応後のオレンジの点線は `(379,300) r25` `(421,300) r25`（C。自動水素を持つので25）と
`(379,258) r17` `(421,258) r17`（Br）の**4つだけ**。**②の上には1つも出ない**ので、
「どちらが反応したか」が色でも分かる。

### アセチレン（C≡C）も脱色する。**ただしこの回では使わない**

`アセチレン（エチン）` → Br₂ 付加 → **1,2-ジブロモエテン**（C₂H₂Br₂・貫通0）まで実機で通ることを確認した。
三重結合は1回の付加で二重結合まで戻るので、**付加ボタンがもう一度出る**（2回目も押せる）。
それでも今回に入れなかった理由:

- **モバイルのシートが開いている間に元のアセチレンが見えない**。`frame` がシートを閉じた瞬間には
  すでに生成物なので、**「三重結合が消えた」瞬間を見せられない**（呼び出しと反応を別ステップに割ると
  9ステップ・48秒級になり、尺の上限を超える）
- 単分子なのでキャンバス上の ①② 見出しが付かず、**並べて比べる**この回の型から外れる

→ **「C≡C も脱色する」は動画では言わない**（言うと画と食い違う）。**投稿文の説明欄にだけ書く**。
**三重結合を主役にするなら独立の回**にすること。素材はここに揃っている。

## 5. 座標と構図の根拠（**実測値**）

`frame` は指定した `cx`/`cy` を中心に viewBox を張り直す（`h = width × 3/4`）。
**ただし縦は `width × 3/4` では切れない。** 収録ビューポート 810×1440 で
`#chem-svg` の実寸は **796×1268 ＝ 縦横比 1.593** なので、`preserveAspectRatio` の meet は
**横で合わせて縦は `width × 1.593` ぶん見える**（実測。LANES.md §4-2 の「約1.59」を再確認した）。

→ **効くのは横幅だけ。`width` は「見せたいものの横幅 ＋ 余白」で決めてよい。**

測った実体（**キャンバスの ①② 見出しを含む**。見出しは 15px の `<text>` で分子の下に出る）:

| 見せたいもの | 実体の x | 実体の y | 内訳 |
|---|---|---|---|
| ①②の両方（反応後） | **324–588** | 241–387 | 見出し「① 1,2-ジブロモエタン」が x 324–476 で**分子より左に出る** |
| ① だけ | **324–476** | 241–352 | 見出しが分子（357–443）より広い |
| ② だけ | **464–588** | 246–387 | 見出し「② ベンゼン」は x 487–565 |

| ステップ | frame | 根拠 |
|---|---|---|
| 1・3・6 | **`cx 456, cy 312, width 310`** | 実体 324–588（幅264）を左右 23 ずつの余白で収める。**呼び出し直後・反応後とも同じ値**なので、ステップ3で**カメラは動かず分子だけが変わる** |
| 4 ① に寄る | **`cx 400, cy 300, width 190`** | 実体 324–476（幅152）＋左右 19。Br 2つとオレンジの円が画面いっぱいになる |

- **①②の見出しは分子より横に広い。** 分子の重原子だけで `width` を決めると**見出しが切れる**
- ステップ5の `cy` を 316 にしてあるのは、②の見出し（y 366–387）を中央寄りに置くため

### 測り直しの手順（実機のコンソール）

```js
// 目的の状態をキャンバスに出してから（見出しとオレンジ円まで入れて測る）
const svg = document.getElementById('chem-svg');
const xs = [...svg.querySelectorAll('text,circle')].map(e => e.getBBox())
  .flatMap(b => [b.x, b.x + b.width]);
[Math.round(Math.min(...xs)), Math.round(Math.max(...xs))]
```
