## 1. この回の芯: 「炭素の数」では答えが決まらない

縦に4つ並べ、3つがカルボン酸・1つだけエステルにした。

| # | 分子 | 分子式 | アプリの分類（`findFunctionalGroups`） |
|---|---|---|---|
| ① | 酢酸 | C₂H₄O₂ | カルボキシ基（カルボン酸） |
| ② | プロピオン酸 | C₃H₆O₂ | カルボキシ基（カルボン酸） |
| ③ | **酢酸エチル** | **C₄H₈O₂** | **エステル結合** ← 仲間はずれ |
| ④ | 酪酸（ブタン酸） | **C₄H₈O₂** | カルボキシ基（カルボン酸） |

**キャンバス全体の分類は「カルボキシ基（カルボン酸）×3、エステル結合」**（実機の `#molecule-props` で確認）。

### なぜこの4つか（題材選定の根拠）

1. **鎖の長さが答えにならない。** 炭素は 2/3/4/4。**③ と ④ は炭素4つで分子式まで同じ C₄H₈O₂**
   なので、「いちばん長いから」「いちばん短いから」では答えが1つに定まらない。
   **官能基を見るしかない構成**になっている
2. **芳香環などの別の手がかりを混ぜていない。** 候補にあった
   「アセトアルデヒド・プロパナール・ベンズアルデヒド・アセトン」は、
   **ベンズアルデヒドだけが芳香族**なので「仲間はずれ」の基準が2つできてしまう（不採用）
3. **アルコール／フェノールは V32 と題材が重なる**ので避けた
4. **アミドは使っていない**（`REVIEW_2026-08-01.md` A-3。アミドの C=O が「アルデヒド基」と誤分類される。
   パラセタモール・アセトアニリド・尿素は不可）
5. **カルボン酸とエステルは官能基シリーズで未収録**だった（V13 アルコール／V30 カルボニル／
   V31 アミノ酸／V32 フェノール類／V33 数え上げ）。シリーズに新しい官能基を1組足せる

### 化学的に迷った点

- **カルボン酸の -OH をアルコールと呼ばないこと**は台本では触れていない。V32 の内容と隣接するが、
  30秒に入らないので落とした（説明欄にも書いていない）
- **ギ酸は候補から外した**。カルボン酸だが銀鏡反応を示す（還元性がある）ので、
  「3つはただのカルボン酸」と言い切る回には持ち込まない方がよい
- **酪酸の名前**は `酪酸（ブタン酸）` で登録されているので、キャンバス見出しもその表記になる。
  ナレーションは「らくさん」と正しく読む

## 4. 構図の根拠（2026-08-03 実機実測）

### 4a. 縦積みにした理由

**名称チップ（`#mobile-name-chip`）は `rec-short` で画面の上から 21〜31% を占める**
（実測: 収録ビューポート 810×1440 で、SVG の見え幅に対し上から 0.2097〜0.3088 の帯）。
**4分子ぶんの名前が入るので3行になり、この帯がふだんより厚い。**

- **横並び**にすると、V33 と同じく `width` が 900〜1000 必要になり、**1分子が画面幅の 23%** にしかならない
- **縦積み**なら `width 560` で足り、**1分子が画面幅の 36%**。スマホで構造式を見比べる回なので
  **大きさを優先した**

### 4b. 寄り（ズーム）は成立しない

縦積みでは**寄りの枠を作れない**。計算で確かめた:

- 寄りの枠は、上から 30.9% がチップに隠れるので、**被写体は枠の下 69% に収まらなければならない**
- 1分子（高さ約103）を映す枠は横 250 以上必要 ＝ 縦 400 以上 ＝ **チップの下端が被写体より 124 下**に来る
- **段の間隔を 274 以上にしないと隣の分子が枠に入る**。そこまで広げると全体の枠が 864 必要になり、
  **横並びと同じ大きさに戻ってしまう**

→ **カメラは冒頭の1回だけ**にした。テロップの切り替わりで間が持つ構成にしてある。

### 4c. 実測値

- 段の間隔 **150**（chain の y は 260 / 410 / 560 / 710）。分子1つの占有は上下 103（=O の上端 −50、
  見出しの下端 +53）なので、段の間は 47 あく
- **カルボニル炭素の x をすべて 400 にそろえた**。=O と、その右の O が縦一列に並ぶので、
  **③ だけ「O のさきに炭素が続く」ことが一目で分かる**
- 引きの枠 **`cx 400 / cy 357 / width 560`**。実機で当てて確認:
  **切れている text 0個・チップと重なる text 0個**
- キャンバス見出しの幅は ① 48.4 ／ ② 108.4 ／ ③ 93.4 ／ ④ 138.4。縦積みなので横に重ならない

### 4d. 座標はライブラリのままではなく 42px グリッドに正規化した

**`酢酸` だけ `stages.json` に 80px 刻みで登録されている**（C(360,300) C(440,300) O(440,220) O(520,300)）。
他の3つは 42px 刻みなので、**そのまま並べると ① だけ結合が長く、形のちがいが目立って
「仲間はずれ探し」の邪魔になる**。そこで **4つとも 42px グリッド・カルボニルの =O は真上 42px** に
そろえ直した（トポロジーは呼び出したものと同一）。

**正しさは実機で検証済み**:

- 名称チップ **「① 酢酸 ＋ ② プロピオン酸 ＋ ③ 酢酸エチル ＋ ④ 酪酸（ブタン酸）　C₁₃H₂₆O₈」**

## 6. ⚠ `--trim=auto` は使わない（この回で見つけた不具合）

**`--trim=auto` は「最初の操作の `--lead` 秒前」で切るが、最初の操作は
`.mode-tab[data-mode="free"]` の `button` で、そのとき右パネルのシートが開いたまま。**
シートが閉じるのは次の `frame` なので、**冒頭 1.7秒が「設定パネルが画面いっぱいに開いた絵」**になる。

**V33 も同じ状態で焼かれている**（`out/V33 …mp4` の 0.2秒を確認。フックもカバー画像も潰れている）。
**`state` ＋ モードタブで始まる回はすべて同じ**はず（V31・V32 も要確認）。

対処:

1. `--trim=auto` をやめ、**`frame` イベントの 0.1〜0.15秒あとを `--trim=<秒>` で直接指定する**
   （`frame` はイベント記録 → シート閉じ 0.35秒 → viewBox 設定 の順なので、`frame` の時刻 +0.35 が目安）
2. そのぶん頭が短くなるので、**step1 の `wait` を足して、2行目以降のテロップが声より
   0.1〜0.4秒あとに来るようにそろえる**

**収録のたびに頭のリードが 1秒ほどぶれる**ので、**`--trim` の値は毎回 `--events` から計算し直すこと**。
この回の実績: `frame` 6.38秒 → **`--trim=6.85`**。テロップの遅れは +0.18〜0.21秒でそろった。

```
node tools/record/record.mjs --demo=fg-odd-one-out --format=short --base=http://localhost:8123/assembler/
node tools/record/mux.mjs --video=video-scripts/out/fg-odd-one-out-short.webm \
  --audio=video-scripts/audio/V34/full.wav \
  --bgm=video-scripts/audio/bgm/のんきな日常.mp3 \
  --se=video-scripts/audio/se/tap.wav \
  --events=video-scripts/out/fg-odd-one-out-short.events.json \
  --meta=video-scripts/meta/V34.json --trim=6.85 --size=1080x1920 \
  --out=video-scripts/out/V34-final.mp4
```
