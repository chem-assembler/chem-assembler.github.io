# クイズシリーズの計画（2026-08-19・ショートの主軸にする）

**ユーザー判断でショートはクイズ系を中心にする。** 目的は3つ。

- **アプリの値打ちがそのまま映る**——問題を自動生成するので「何問でも練習できる」が伝わる。
  「作ってみた」は絵で終わり、**使う理由にならない**
- **尽きない**——題材が有限でない
- **量産の型から遠い**——8/18 からの配信停止で最も疑わしいのが「同じ画面・同じ音声・同じ構成の量産」判定

## 1. ⭐ 効いているのは「型」ではなく「題材の有名さ」（実測）

> ### つまり計画の式は
>
> **クイズの型（＝アプリの値打ちが映る・尽きない）× 有名な題材（＝人が止まる）**
>
> **どちらか片方では足りない。** 一般的な例で作ったクイズは 90〜364 に沈み、
> 有名でない化合物を描いた回も 60〜133 に沈んでいる。

## 2. 題材は指定できる（技術的な裏付け・2026-08-19 に確認）

**抽選任せではない。** `quizForce` に指定の口がある（`assembler/tutorial.js`）:

| クイズ | 指定の書き方 |
|---|---|
| 命名 | `{type:'quizForce', quiz:'naming', name:'メントール'}` |
| 同じ？違う？ | `{type:'quizForce', quiz:'same', pair:['α-D-グルコース（…）','β-D-グルコース（…）']}` |
| 立体異性体 | `{type:'quizForce', quiz:'stereo', value:'enantiomer'}` |

⚠ **`quizForce` はクイズを開くより前に置く**（開いた時点で1問目が出る）。
⚠ **指定が出題プールに無ければ黙って無視される**——**範囲（教科書／すべて）を先に合わせる**。
⚠ **正解を押すのは `quizAnswer`**（何が出ても正解を押す。答えを外す回を撮るときは使わない）。

**この口は V63 の事故のあとに足された**（範囲を絞ってもナレーションが踏み込んだ話をすると、
想定外の分子が出た瞬間に嘘になる。実際、置換基のないナフタレンが出た）。

## 4. 制作の候補（有名さの順。実在は確認ずみ）

### A群 ⭐ 同じ？違う？ × 天然有機化合物（最優先）

| # | 題材 | フック | ライブラリ上の名前 |
|---|---|---|---|
| **A1** | **α-D-グルコース ⇄ β-D-グルコース** | 「同じブドウ糖なのに別物？」**-OH の向き1つ**。α/β 面マークが効く | `α-D-グルコース（α-D-グルコピラノース）` / `β-D-…` |
| **A2** | **D-グルコース ⇄ D-ガラクトース** | 「血糖」と「牛乳の糖」。**1か所だけ違う** | `D-グルコース（鎖状）` / `D-ガラクトース（鎖状）` |
| **A3** | **アドレナリン ⇄ ノルアドレナリン** | 「本気」と「集中」。**メチル基1つ** | `アドレナリン（エピネフリン）` / `ノルアドレナリン（ノルエピネフリン）` |
| **A4** | **カフェイン ⇄ テオブロミン** | コーヒーとチョコ。**メチル基1つ** | `カフェイン` / `テオブロミン` |

⚠ **A3・A4 は「作ってみた」で既出**（V80・V69）だが、**クイズの型では未使用**。
**同じ題材を別の型で出すのは連投ではない**——見せているものが違う（描く手 → 見分ける目）。

### B群 立体異性体は何種類？ × 有名分子

| # | 題材 | フック |
|---|---|---|
| **B1** | **メントール** | 「ミントのスースー」。**不斉炭素3個 → 8種類**。数が大きいので絵が効く |
| **B2** | **コレステロール** | 健康診断のあれ。**シリーズ最大の分子**で、数字が跳ねる |
| **B3** | 乳酸 | D/L の基本。**有名だが小さい**ので、B1・B2 が当たってからでよい |

### C群 命名 × 有名分子

| # | 題材 | フック |
|---|---|---|
| **C1** | **サリチル酸エチル** | 「湿布のにおい」。名前と構造が結びつく |
| **C2** | **クエン酸** | レモン。**-COOH が3つ**あるのに名前は1つ |
| **C3** | グリセリン | 化粧品。**油脂の骨格**でもある |

### D群 機能そのものを見せる（有名さに頼らない枠）

| # | 中身 | 効き |
|---|---|---|
| **D1** | **出題範囲を変える**（教科書306 → すべて1,059） | 「自分の学年に合わせられる」が伝わる。**アプリの値打ちの直球** |
| **D2** | **崩し方の強度**（弱／標準／強） | 同じ分子をどれだけ崩しても読めるか。**構造式は形でなくつながり**という核心 |

**D群は有名さで勝てない**ので、**A・B が当たってからの箸休め**に置く。連続させない。

## 5. 作る順（提案）

```
A1（α/β グルコース）→ B1（メントール）→ A2（グルコース/ガラクトース）
  → A3（アドレナリン）→ B2（コレステロール）→ D1（出題範囲）
```

**A と B を交互にする**（型が続かない）。**D1 は6本目**——それまでに当たりが出ていれば、
そこで初めて「機能そのもの」を見せる意味が出る。

## 6. 1本あたりの手順と costs

**V102 で確立した型がそのまま使える**（半日／本）:

```
台本 → ナレーション（narrate.py でかなを必ず目で追う）→ 各行の尺を測る
     → demo の wait をその尺に合わせる → record.mjs → 縦に切る＋テロップ → 整音 → 台帳
```

- **demo は `assembler/demos-quiz.json` に足す**（既存12件と同じ形）
- ⚠ **未使用の SNS 用デモはもう無い**。未使用に見える9件は V62〜V67 で消費ずみで、
  **古い台帳に `demo` の記録が無いだけ**だった
- ⚠ **クイズの画面はキャンバスではない**。切り出しは V99 と同じで**キャンバス用の crop は使えない**
- ⚠ **テロップに下付き文字は使えない**（BIZ-UDGothicB に無く豆腐になる）
