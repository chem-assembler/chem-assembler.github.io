## 3. アプリで実行した所と、言葉で補った所（V11 §3 と同じ判断）

**石けん＝高級脂肪酸のナトリウム塩**だが、**アプリは塩を表現できない**（イオンも対イオンも持たない）。
また **油脂＝トリグリセリドのエントリが compounds.json に無い**。そこで次のように分けた。

| | アプリが実行した | 呼び出して見せた | 言葉だけで補った |
|---|---|---|---|
| ステップ1〜4 | **酢酸エチルのけん化**（`hydrolysis_ester`）→ ① 酢酸 ＋ ② エタノール | — | NaOH を使うと生成物が塩になること |
| ステップ5〜7 | — | **ステアリン酸・グリセリン**（＝油脂のけん化で得られるもの） | 油脂そのもの／-COOH → -COONa／親油・親水 |

**「アプリが計算した」と誤解されない作りになっていることの根拠**:

- 後半の名称チップは最後まで **「① ステアリン酸 ＋ ② グリセリン C₂₁H₄₄O₅」** のまま。
  石けん（ステアリン酸ナトリウム）とは表示されない
- ステップ6・7のテロップは「石けん ＝ 脂肪酸のナトリウム塩」「-COONa は水になじむ」と
  **石けんの定義**を述べているだけで、画面の分子をそう呼んではいない
- ナレーションも「石けんは、**この脂肪酸の**ナトリウムえんなのだ」＝画面のステアリン酸を指して
  「その塩が石けん」と言う形にしてある

埋めるなら DEVELOPMENT.md の P12-4（反応データの拡充）側の仕事。**トリグリセリドを1件入れれば**
ステップ5〜7 は「呼び出し」を「実行」に差し替えられる（けん化ルール自体は 3か所の -COO- を
別々の site として拾えるので、そのまま動くはず）。塩の表現はさらに先の話。

## 4. 検算（LANES.md §4 の貫通チェック。**反応後の生成物に対して**流した）

実機（v342・localhost:8132）で3つの状態すべてを確認。**3状態とも `[]`（貫通ゼロ・重原子の重なりゼロ）**。

```
① 酢酸エチル（呼び出し直後）            貫通 0 / 重なり 0
② けん化の生成物（アプリが計算した配置）貫通 0 / 重なり 0
③ ステアリン酸 ＋ グリセリン（呼び出し）貫通 0 / 重なり 0
```

②の実測値（v341 の `bondStep()` により母体と同じ 42px 刻みで置かれている）:

```
原子: C(300,300) C(342,300) O(342,258)  ＋ O(384,300)      … ① 酢酸
      O(384,384) C(426,384) C(468,384)                     … ② エタノール
結合: C(342,300)-C(300,300) / O(342,258)=C(342,300) / O(384,300)-C(342,300)
      C(426,384)-O(384,384) / C(426,384)-C(468,384)
```

**結合のつながりも人の目で確かめた**: 酢酸は CH₃-C(=O)-OH、エタノールは HO-CH₂-CH₃。
エステルの C-O が切れて（アシル-酸素開裂）、O はアルコール側に残り、
カルボニル炭素には新しい -OH が付く＝教科書どおり。

## 5. 反応後のハイライトが次の分子に残る（この回で踏んだ落とし穴）

`reactor` は変化箇所をオレンジの点線で示すが、これは **`clearUIOverlay()` が呼ばれるまで
座標そのままで居座る**。`#btn-clear-all` も `summon` もこれを呼ばないので、
**全消去してステアリン酸を呼び出すと、けん化のハイライトが鎖の途中に貼りついたまま**になる
（初版の収録で実際に出た。x=342 と x=384 ＝ 酢酸のカルボニル炭素と新しい -OH の位置）。

**対処: ステップ5の `#btn-clear-all` の直後に `hover` を1つ置く**。
`hover` は SVG に `pointermove` を投げるだけで、選択ツールが `select` のときは
プレビューを何も描かずに `clearUIOverlay()` だけが走る（実機で確認: uiGroup の子が 2 → 0）。

```json
{ "type": "button", "selector": "#btn-clear-all" },
{ "type": "hover", "x": 400, "y": 300 },
{ "type": "summon", "name": "ステアリン酸" }
```

- **`hover` の実測コストは 0.79s**（`moveCursor` ＋ 300ms）。入れたら `wait` を同じだけ削る
- 反応を実行したあと**別の分子に持ち替える回では必ずこれが要る**。今後の反応回で使い回すこと

## 6. 座標と構図の根拠

`frame` は `calculateTargetBounds`（＝重原子の中心）を基準に viewBox を張り直す。
水素の丸（r=6）は最大 +16 外側に出るので、**端の -OH を切らないよう +22 は余分に取る**。

| ステップ | frame | 根拠 |
|---|---|---|
| 1・3 反応の前後 | `width 320`（自動中心） | 反応前 x 300–468 / y 258–300、反応後 x 300–468 / y 258–384。同じ幅にして**動くのは分子だけ**にする |
| 5 油脂の生成物 | `width 1040`（自動中心） | ステアリン酸 x 58–814・グリセリン x 904–988 の2分子で x 58–988。**1040 で左右に 25 ずつ余る** |
| 6 -COOH に寄る | `cx 690, cy 300, width 340` | 見せたいのは C(772,321)・O(814,321)・O(772,279)。**-OH の H は x=830（r=6）なので右端 860 で収まる**。グリセリンの最左の H は x=888 なので画角に入らない |
| 7 ステアリン酸1本 | `cx 436, cy 300, width 830` | x 21–851。**グリセリン（H で x=888 から）を外して脂肪酸だけにする**。自動中心の `width 1040` だと 1.04倍にしかならず鎖が細すぎた |

- ステップ5だけは 2分子を入れるので拡大率が 1.04倍と小さい。**「長い」を見せる画なので割り切る**。
  分子の同定は名称チップが担う
- ステップ5は `#btn-clear-all` ＋ `hover` ＋ `summon`×2 の間、モバイルのシートが約4秒開いたままになる
  （V18 の冒頭と同じ絵）。**`frame` がシートを閉じる**ので、閉じた瞬間に構図が決まる
