## 3. 実機で確認したこと（2026-08-01・v357 相当・localhost:8132）

### 酢酸エチルに出る反応ボタンは2つ。**「けん化」で一意に当たる**

```
加水分解（エステル + H₂O, 酸を触媒に加熱）
けん化（エステル + NaOH, 加熱）→ カルボン酸の塩
```

### けん化の生成物（**押したボタン＝「けん化（エステル + NaOH, 加熱）→ カルボン酸の塩」**）

| | 値 |
|---|---|
| 名称チップ | **① 酢酸ナトリウム ＋ ② エタノール** |
| 分子式 | **C₄H₉NaO₃** |
| 重原子 | `C(300,300) C(342,300) O(342,258)` ＋ `O(384,300) Na(426,300)` … ① 酢酸ナトリウム／`O(384,384) C(426,384) C(468,384)` … ② エタノール |
| 結合 | C(300,300)-C(342,300) / O(342,258)=C(342,300) / O(384,300)-C(342,300) / **O(384,300)-Na(426,300)** / O(384,384)-C(426,384) / C(426,384)-C(468,384) |
| 貫通チェック | **貫通 0 / 重原子の重なり 0** |

- **結合のつながりを人の目で確かめた**: 酢酸ナトリウムは CH₃-C(=O)-O-Na、エタノールは HO-CH₂-CH₃。
  エステルの C-O が切れて（アシル-酸素開裂）、O はアルコール側に残り、
  カルボニル炭素には **-O-Na** が付く＝教科書どおり
- **`-COO-Na` は単結合1本で表す**（v353 の設計。イオンや電荷はモデルに持ち込まない）。
  教科書が `CH₃COONa` と線で書くのに合わせてある
- **同じ手順を6回繰り返して座標が完全に一致することを確認**した。`frame` に `cx`/`cy` を書ける

### 呼び出して見せた分子（後半）

|---|---|---|---|---|
| セッケン単体 | **ステアリン酸ナトリウム（セッケン）** | C₁₈H₃₅NaO₂ | x 58–856 / y 279–321 | 0 / 重なり 0 |
| セッケン ＋ グリセリン | **① ステアリン酸ナトリウム（セッケン） ＋ ② グリセリン** | C₂₁H₄₃NaO₅ | x 58–1030 / y 279–342 | 0 / 重なり 0 |

**セッケンの右端は `C(772,321)-O(814,321)-Na(856,321)` ＋ `=O(772,279)`** ＝ そのまま R-COONa の形。

## 5. 反応後のハイライトが次の分子に残る（この回で踏んだ落とし穴）

`reactor` は変化箇所をオレンジの点線で示すが、これは **`clearUIOverlay()` が呼ばれるまで
座標そのままで居座る**。`#btn-clear-all` も `summon` もこれを呼ばないので、
**全消去してセッケンを呼び出すと、けん化のハイライトが鎖の途中に貼りついたまま**になる。

**対処: ステップ5の `#btn-clear-all` の直後に `hover` を1つ置く**。
`hover` は SVG に `pointermove` を投げるだけで、選択ツールが `select` のときは
プレビューを何も描かずに `clearUIOverlay()` だけが走る。

```json
{ "type": "button", "selector": "#btn-clear-all" },
{ "type": "hover", "x": 400, "y": 300 },
{ "type": "summon", "name": "ステアリン酸ナトリウム（セッケン）" }
```

**反応を実行したあと別の分子に持ち替える回では必ずこれが要る**（V40 でも3か所で使っている）。

   `play()` は最終ステップのあと `teardownOverlay()` でテロップを外すので、
   ここが早まると**次回予告が出ていない尻**ができる（初版で 0.5〜1.0秒ぶん出た）。
   → **ステップ8の `wait` は計算値に 1.5秒ほど上乗せする**。この回は 4000ms → **5600ms**。
   長すぎても `--trim=auto` が「音の終わり＋1.0秒」で切るので損はない
2. **テロップは狙いより早く出る。** `--events` 上で +0.3 に置いても、実物は声とほぼ同時〜わずかに先になる。
   **遅れ側（+0.3〜+0.5）に倒しておくのが安全**

**書き出したら必ず、完成 mp4 の「終わりの手前」のフレームを目視する**
（`node tools/frames.js <mp4> --width=300 <尺-0.1>`）。**テロップが写っていれば合格**。
この回は 44.2秒（尺 44.3秒）で次回予告が出ていることを確認した。ズレ幅は回ごとに違う
（V40 は約 0.5秒しかずれず、`wait 3600ms` でも尻は保った）ので、**毎回目視で確かめること**。
