## 3. 化学の裏取り

- **2-プロパノールの C2 は不斉ではない**。4つの置換基が OH・H・CH₃・CH₃ で、
  **メチル基が2本重複する**から。アプリも「同じ置換基（CH₃）が複数あるため、この炭素は不斉炭素ではありません」と書く
- **2-ブタノールの C2 は不斉**。OH・H・CH₃・C₂H₅ で4つとも異なる。
  **炭素4個が下限**なのは、C₃ 以下では中心炭素の枝に必ず同じものが出てしまうため
  （アルコールは -OH と -H を使うので、残り2本の炭素鎖を「違う長さ」にするには最低 CH₃ と C₂H₅ ＝ 主鎖4炭素が要る）
- 「並びを揃える」は**偶置換12通りを総当たりして、いちばん近い並びを出す**モード。
  くさび図（フィッシャー投影の規約）では偶置換＝回転で到達できる並べ替えなので、
  **それでも残る食い違い＝回転では重ね合わせられない**ことの証明になる。動画でここは言い切ってよい
- 残る食い違いがちょうど2か所なのは、鏡像との差が**転置1回（奇置換）ぶん**だから

```

  --meta=video-scripts/meta/V10.json --trim=auto --lead=0.3 --size=1080x1920 \
  --out=video-scripts/out/V10-final.mp4
```

- **冒頭は `state`（開始状態）で分子を置く。呼び出しでは間に合わない。**
  最初の版は「自由モードへ → 2-プロパノールを呼ぶ」で始めていたが、
  **モードタブが `#right-panel` の中にある**ため `syncSheetFor` がシートを開き、
  **フックの最初の2.3秒が操作パネルで埋まった**（完成 mp4 のフレームを抜いて発覚）。
  `state` に分子を持たせて**ステップ1を `frame` だけ**にし、モード切替はステップ2へ送って解決
- この回で足された実測コスト: **モーダル内のボタン 0.89〜1.24s**（`syncSheetFor` がシートを閉じるぶん
  1回目が高い）。**`state` 始まりのステップ1は固定オーバーヘッドが 0.36s ほど小さい**
- 追い込みは `--events` の時刻とナレーションの累積秒を並べる。**収録ごとに 0.2〜0.3秒の揺れがある**ので、
  1回で 0.1〜0.4秒の窓に全部入れようとせず、**ずれの向き（早い／遅い）だけを見て直す**。
  最終収録の実測: +0.18 / +0.25 / +0.35 / +0.35 / +0.26 / +0.20 / +0.18 / +0.25 秒（全ステップが窓の中）
