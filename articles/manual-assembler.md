# パズルでみる有機化学 — 使い方（全体編）

無料・登録不要・インストール不要のブラウザアプリです。
**構造式を組み立てると、名前が出ます。** そこから先に、調べる道具と練習する道具が付いています。

https://chem.schoollenz.com/assembler/

---

## この記事の役割

**アプリの中の「❓ヘルプ →📝 遊び方と操作方法」に、操作は全部書いてあります。**
原子の置き方、消し方、結合の伸ばし方、キーボード操作まで載っています。

**この記事はそれと役割を分けています。**

| | 答える問い |
|---|---|
| アプリ内のヘルプ | **どう動かすか**（操作の辞書） |
| **この記事** | **何ができて、いつ使うか**（機能の地図） |

「ボタンの押し方が分からない」ときはアプリ内のヘルプへ。
「何ができるアプリなのか」「どれを開けばいいのか」を知りたいときはこちらです。

---

## 1. 3つの入口

画面の上に **🧩パズル**・**📚学習**・**❓ヘルプ** が並んでいます。
何も選ばなければ**自由に描くモード**です。

| 入口 | 何をするところ | 向いている場面 |
|---|---|---|
| **（既定）自由に描く** | 好きな分子を描く。名前が自動で出る | 教科書の構造式を写す・確かめる |
| **🧩パズル** | お題の分子を組み立てる | 単元ごとに順に練習したい |
| **📚学習** | 練習と、調べる道具の入口 | クイズ・書き出し・入試の絞り込み |

**迷ったら 📚学習 を開いてください。** 練習の入口はほぼ全部そこにあります。

---

## 2. 描く

左のツール列から選んで、キャンバスを押すだけです。

- **原子の配置** — C・O・N・Cl・S・Br
- **環・官能基モジュール** — 五員環・六員環・**ベンゼン環**・任意員環・**ハース環**（ピラノース／フラノース）、
  **-OH・-COOH・-NH₂・-NO₂・-SO₃H**
- **作図の道具** — 選択と移動／結合を描く／消しゴム
- **結合タイプ** — 単結合・二重結合・三重結合
- **仕上げの印** — **✳ 不斉炭素原子マーク**・**⇄ シス/トランス整形**・**⬍ α/β 面マーク**

**環と官能基はモジュールとして置けます。** ベンゼン環を1つ置いて、-OH を貼るだけでフェノールです。
1個ずつ原子を並べる必要はありません。

> **描き方のコツ**
> 直交（縦横）で描いて構いません。**このアプリが見ているのは「原子のつながり方」だけ**で、
> 角度や長さは見た目の問題です。ノートに書く感覚のまま描けます。

**組み上がると、キャンバスの下に名前と分子式が出ます。**

---

## 3. 名前から呼び出す

作業帯の **🔤呼出** を押すと、名前の入力欄が出ます。
「酢酸」「カフェイン」「メントール」などと打って **呼び出す** を押すと、その構造式が描かれます。

**使いどころ**

- 教科書に名前しか載っていない分子の形を見たい
- **反応させる相手を用意したい**（例: エステル化の相手にエタノールを呼ぶ）
- 描くのが面倒な大きい分子（コレステロール・インジゴなど）

収録されている化合物は **900件以上**あります。

---

## 4. 調べる — ⚗ 反応させる・調べる

分子を描いたら、作業帯の **⚗ 反応させる・調べる（反応 N件）** を押します。
**カッコの中の数字が、その分子にできる反応の数**です。

開くと「**🔬 この分子について**」という1枚が出て、中は2つに分かれています。

### ⚗ 反応

- **分類** — アプリが図を読んで「1級アルコール」「カルボキシ基（カルボン酸）」などと判定します
- **できる反応の一覧** — その分類にできる反応が並びます。
  例（エタノール）: 酸化してアルデヒド／ヨードホルム反応／分子内脱水／ナトリウムとの反応/
  **＋ 相手を呼び出して**エステル化・分子間脱水
- **試薬をかける** — 瓶が **21本**並びます。臭素水・酸化剤・濃硫酸・NaOH・金属ナトリウム・
  無水酢酸・フェーリング液・ニンヒドリン…

> **同じ1つのルール表を、2つの向きから引けます。**
> 上の一覧は「**この分子にできる反応**」、下の瓶は「**この試薬で何が起きるか**」。
> **教科書は前者の順に並んでいて、実験は後者の順で起きます。**

**効かない試薬もわざと選べます。** エタノールに臭素水をかけると何も起きませんが、
**なぜ効かないかが文章で出ます**。「赤褐色が消えないこと自体が、不飽和結合が無いことの証拠」——
**空振りが答えになる**、というのが検出法の考え方です。

反応が通ると画面が閉じてキャンバスに戻り、**分子が実際に変わって名前も変わります**。
作業帯に **↩ 反応前に戻す** が出るので、何度でもやり直せます。

反応したあとは一覧に2つ増えます。

- **🔍 反応の前後を見る**
- **⚗ この反応の機構を見る（代表例）**

### 🔬 調べる

同じ1枚の下半分に、調べる道具の入口が集まっています。

| ボタン | 何をするか |
|---|---|
| **🔢 主鎖と番号を見る** | 図の上に**主鎖の帯と炭素番号**が乗ります。命名の確認に |
| **📚 同じ分子式の異性体を調べる** | いま描いている分子と同じ分子式の異性体を全部出します |
| **🧊 立体で見る（くさび図・3D）** | sp³ 炭素のくさび図と 3D。不斉炭素の印つき |
| **練習する** | その分子式の書き出し練習へ |

**🔢 主鎖と番号を見る は作業帯にも直接あります**（よく使うので）。

## 5. 練習する — 📚学習

**📚学習** を開くと、大きく2つに分かれています。

> 練習を始めると学習の画面は閉じてキャンバスに戻り、
> **操作と進み具合はキャンバスの下の帯に出ます。**

### 手を動かす

#### 🎓 クイズに挑戦

**問題は自動生成なので、何問でも解けます。** 11種類あります。

| クイズ | 何を問うか |
|---|---|
| 🎓 同じ化合物はどれ？ | 2つの図が同じ化合物か。**見るのはつながり方だけ** |
| 📝 命名クイズ | 崩して描かれた構造式の名前を4択で |
| 🪞 立体異性体クイズ | 2つの図の関係（同じ／鏡像／ジアステレオマー） |
| 🎯 同じ立体はどれ？（4択） | 立体まで含めて同じものを選ぶ |
| 🅳 D体・L体はどれ？（4択） | D/L の判定 |
| ⚖ 同じ？違う？（連続・タイムを計る） | 連続出題でタイムを競う |
| 🔤 記号でパズル（化学ぬき） | **化学の知識なしで**立体の操作だけ練習する |
| ⏱ 立体タイムアタック | 目標の立体に手数で到達する |
| ⏱ タイムアタック 上級 | 中心を切り替えながら解く |
| 🔃 フィッシャー投影の操作練習 | 90°回すと別物になる、を手で確かめる |
| 🔢 立体異性体は何種類？ | 総数を当てる。**なぜその数かまで出ます** |

**多くのクイズで出題範囲を絞れます。**

- **レベル** — 教科書（お題と定番）306件 ／ ＋命名の練習台 390件 ／ すべて（大学初級を含む）1,059件
- **分野** — 脂肪族 665 ／ 芳香族 277 ／ 天然有機化合物 75 ／ 高分子 5
- **シリーズ** — アルカン、アルコールとエーテル、ベンゼンとその同族体、アミノ酸と糖…（20区分）
- **崩し方** — 弱（回転・反転のみ）／標準／強

> **自分の学年と単元に合わせられます。** 高校範囲だけにしたいなら「教科書」、
> 芳香族の小テスト前なら「芳香族」に絞る、という使い方です。

#### ✏️ 構造の書き出し練習

**選択肢から選ぶのではなく、自分で全部描く**練習です。ダブりと抜けをその場で判定します。

- **✏️ 異性体の書き出し練習** — C₄H₁₀（2種）・C₅H₁₂（3種）・C₄H₁₀O（7種）・C₅H₁₀（10種）・
  C₅H₁₂O（14種）ほか **22通り**。鎖式だけ／環式だけ／立体まで、の指定もあります
- **✏️ アルキル基の書き出し練習** — C₃H₇–（2種）／C₄H₉–（4種）／C₅H₁₁–（8種）
- **🪞 立体異性体の書き出し練習** — 2-ブテン（2種）／乳酸（2種）／酒石酸（3種）／
  乳酸3分子の環状エステル（4種）／α/β-D-グルコピラノース（2種）

> **アルキル基の書き出しは、地味ですが効きます。**
> 構造決定の多くは「置換基を何通り書けるか」に帰着します。
> C₄H₉– の4種類が手で出せるかどうかで、解ける問題の幅が変わります。

#### 🔍 実験の結果から絞り込む

**構造決定を解くための道具**です。**🔍 実験カードで絞り込む** を開きます。

1. 分子式を決める（または**入試問題から**選ぶ）
2. 実験の結果をカードで積む——「ナトリウムで水素が発生した」「臭素水を脱色しなかった」など
3. **積むたびに残りの候補数が減ります**

**入試問題のプリセットが入っています。** 例として東京大学 2021年前期1I（C₆H₁₂O）なら、
211通り → エノールを除いて193通り → 問題の条件（不斉炭素原子1個）で55通り、
そこから実験を積んで 26 → 8 → 5 → 3 と落ちていきます。

**この画面の面白いところは、積み終わったあとです。**

- **どのカードが必須で、どれが冗長だったか**を分類して見せます
- **最短ルート**を総当たりで探します（「いま5手、最短2手」のように出ます）
- **1通りまで絞りきると、構造式が描かれます**

> **実験は、やる順番で効きが変わります。** 問題文の順に解くのが最短とは限りません。
> それが数字で見えるのが、このモードの値打ちです。

### 登録された反応を見る

**⚗️ 反応機構ビューア** — 代表例の分子で、**巻矢印のアニメーション**を再生します。

⚠ **こちらは「代表例の再生」**です。**自分が描いた分子を反応させるのは、
キャンバスの ⚗ 反応させる・調べる のほう**（上の §4）。入口が2つあるので混同しやすいところです。

## 6. 使いどころ

| 場面 | 開くもの |
|---|---|
| 教科書の構造式を確かめたい | 自由に描く → 名前を見る |
| 名前だけ知っている分子の形を見たい | **🔤呼出** |
| 命名の練習をしたい | 📚学習 → **📝 命名クイズ** |
| 異性体を数える課題が出た | 📚学習 → **✏️ 異性体の書き出し練習** |
| 立体が苦手 | 📚学習 → **🔤 記号でパズル**（化学ぬきで操作だけ）→ 🪞立体異性体クイズ |
| 反応を覚えたい | 分子を描く → **⚗ 反応させる・調べる** |
| 検出法を確かめたい | **試薬をかける**（効かない組み合わせも試す） |
| 構造決定の入試問題 | 📚学習 → **🔍 実験カードで絞り込む** |
| 単元ごとに順に進めたい | **🧩パズル** |

## よくある質問

**登録は要りますか**
要りません。インストールも不要です。ブラウザで開くだけです。

**スマホでも使えますか**
使えます。タッチ操作に対応しています（2本指で移動、ピンチで拡大）。
ただし**作図はある程度の画面の広さがあるほうが快適**です。

**描いた図は保存されますか**
ブラウザの中に残ります。別の端末には引き継がれません。

**答えが教科書と違うのですが**
分子式や数え方の前提が違うことがあります。よくあるのは、
**エノールを数えるかどうか**と、**シス・トランスを分けて数えるかどうか**です。
どちらも画面で切り替えられます。
