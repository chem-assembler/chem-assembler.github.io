アルケンは、**炭素間二重結合 C=C を1個だけもつ鎖式の炭化水素**です。二重結合が1本あるぶんアルカンより水素が2個少なく、一般式は **C~n~H~2n~** になります。

:::section
anchor: what
title: アルケンとは
lead: 一般式は C~n~H~2n~。n に炭素の数を入れれば分子式が出ます。名前は対応するアルカンの語尾を -ene に変えたものです。
terms:
- アルケン
- 不飽和炭化水素
- 炭素間二重結合
:::

一般式 C~n~H~2n~ の n に炭素の数を代入すれば、分子式が得られます。n=2 ならエテン C₂H₄、n=3 ならプロペン C₃H₆、n=4 ならブテン C₄H₈ です。

アルケンの名前は、**同じ炭素数のアルカンの語尾を -ane から -ene に変えて**つくります。エタン（ethane）ならエテン（ethene）、プロパン（propane）ならプロペン（propene）です。

二重結合や三重結合をまとめて**不飽和結合**、不飽和結合をもつ炭化水素を**不飽和炭化水素**といいます。アルケンは不飽和炭化水素の代表です。

:::table
caption: 主なアルケン
source: slides:有機の基本2-7「アルケンの性質」s4「主なアルケン」の5件。名称・示性式ともスライドのまま
head:
- 化合物
- 示性式
- 備考
align: left | left | left
rows:
- エテン（エチレン） | CH₂=CH₂ | いちばん小さいアルケン
- プロペン（プロピレン） | CH₂=CHCH₃ | —
- 1-ブテン | CH₂=CHCH₂CH₃ | 2-ブテンとは構造異性体
- シス-2-ブテン | CH₃CH=CHCH₃ | トランス体とは立体異性体
- トランス-2-ブテン | CH₃CH=CHCH₃ | シス体とは立体異性体
:::

**エテンとエチレン、プロペンとプロピレンは同じ物質です。**エチレン・プロピレンのほうは IUPAC 命名法に基づかない慣用名ですが、こちらのほうがよく使われます。**どちらの名前で出てきても同じものだと分かるようにしておいてください。**

:::section
anchor: shape
title: 二重結合のまわりの形
lead: C=C のまわりの6個の原子は同一平面上に固定され、結合角は約120°。二重結合は単結合より短く、三重結合より長いです。
terms:
- 同一平面
- 結合角
- 結合距離
:::

**炭素間二重結合のまわりの6個の原子は、すべて同一平面上に固定されて**います。二重結合をつくっている2個の炭素と、そこに直接くっついている4個の原子までが、1枚の板の上に乗っているということです。

:::figure
src: alkene-planar.png
alt: エテンの構造式。C=C と、そこに結合した4個の H が同じ平面（ピンク色の平行四辺形）の上に乗っていることを示し、結合角121度を書き込んだ図
caption: **C=C に隣接する原子まで**が同一平面上に固定されています。それより外側の原子は、単結合が回転するので位置が変わります。
:::

二重結合した炭素のまわりの結合角は、化合物によって多少変わりますが、だいたい **120°ずつに3等分**されています。**炭素のまわりに電子のまとまりが3組あり、たがいに反発していちばん遠い位置に配置されるため**です。

:::link
to: molecular-shape
text: 電子対の反発で分子の形が決まるしくみ（VSEPR）をもう少し詳しく
:::

炭素間の結合の長さは、**三重結合 C≡C（0.120 nm）＜ 二重結合 C=C（0.134 nm）＜ 単結合 C−C（0.156 nm）** の順です。**「結合の数が多いほど短い」**と覚えておけば十分で、**数値そのものを覚えていなくて困ることは、ほとんどありません。**

:::section
anchor: cistrans
title: シス－トランス異性体
lead: 二重結合は回転できません。そのため、置換基が同じ側にあるか逆側にあるかで別の分子になります。
terms:
- シス－トランス異性体
- 立体異性体
- シス型
- トランス型
:::

**単結合は自由に回転できますが、二重結合は回転できません。**1本のペンの両端を両手でもてば回せますが、2本のペンを平行にそろえて両端をもつと、ねじれてしまって回せません。二重結合が回転できないのは、これと同じ理屈だと考えるとよいでしょう。

回転できないので、二重結合の炭素についている原子・原子団の**並び方が固定されます。**置換基が二重結合の**同じ側にあるのがシス型、逆側にあるのがトランス型**で、この2つを**シス－トランス異性体**といいます。

:::figure
src: alkene-cis-trans.png
alt: シス-2-ブテンとトランス-2-ブテンの構造式。2個のメチル基が二重結合の同じ側にあるのがシス型、逆側にあるのがトランス型であることを示した図
caption: 同じ 2-ブテンでも、**2個のメチル基が同じ側か逆側か**で別の分子になります。
:::

シス－トランス異性体は**立体異性体**の一種です。分子式も、原子のつながり方も同じで、**空間での配置だけが違う**ものが立体異性体です。

シス－トランス異性体があるのは、**二重結合の2個の炭素それぞれに、違うものが1個ずつついているとき**です。2-ブテン CH₃CH=CHCH₃ は、どちらの炭素にも「CH₃ と H」が1個ずつついているので、同じ側と逆側の2通りができます。1-ブテン CH₂=CHCH₂CH₃ の左の炭素は H が2個なので、ひっくり返しても同じ分子です。

text: 構造異性体と立体異性体の分け方はこちら
:::

:::section
anchor: addition
title: 付加反応
lead: 二重結合は不安定で反応しやすく、二重結合が切れてそこに原子・原子団が入ります。アルカンの置換反応とは別のものです。
terms:
- 付加反応
- 臭素水の脱色
:::

アルケンの C=C は**不安定で反応しやすく**、付加反応・付加重合・酸化される反応を起こします。**「アルカンの反応は置換反応、アルケンの反応は付加反応」**と対にして覚えてしまってかまいません。

**付加反応**は、炭素間二重結合を切断して、そこに別の原子・原子団が結合する反応です。

アルケンは、**臭素 Br₂ や塩素 Cl₂ とは常温で触媒なしにすみやかに反応します。**臭素水（臭素の水溶液）と反応させると、**臭素水の赤褐色が消える**ので、反応が進んだことを目で確かめられます。

:::reaction
left: CH₂=CH₂ ＋ Br₂
right: CH₂BrCH₂Br
level: ★★★
note: できるのは 1,2-ジブロモエタン。二重結合が切れて、両側の炭素に Br が1個ずつ入っています。
:::

水素との付加反応だけは、**白金 Pt またはニッケル Ni の触媒**が要ります。水素が付加すると二重結合が単結合になり、アルカンになります。

:::reaction
left: CH₂=CH₂ ＋ H₂
over: PtまたはNi
right: CH₃CH₃
level: ★★★
note: エテンに水素が付加してエタンになります。不飽和だったものが飽和になる、という言い方もします。
:::

アルケンは、**水素原子と他の原子・原子団が結合した物質**（H−X 型の分子）とも付加反応します。X には Cl、Br、−OH、−CN、−OCOCH₃ などが入ります。

:::reaction
left: CH₂=CH₂ ＋ HCl
right: CH₃CH₂Cl
level: ★★★
note: クロロエタンができます。H と Cl が二重結合の両側の炭素に1個ずつ入りました。
:::

:::reaction
left: CH₂=CH₂ ＋ H₂O
right: CH₃CH₂OH
level: ★★★
note: 水が付加するとアルコール（エタノール）になります。
:::

:::reaction
left: CH₂=CH₂ ＋ CH₃COOH
right: CH₃COOC₂H₅
level: ★★★
note: 酢酸は「電離する H」と「残りの原子団 −OCOCH₃」に分かれて付加し、酢酸エチルになります。
:::

**エテンへの付加反応の式は、どれも書けるようにしてください。**ただし**触媒は、水素の付加の「白金またはニッケル」以外は覚えなくて構いません。**

:::link
to: reaction-mechanisms
text: 付加反応で電子対がどう動くかを、巻矢印のアニメで1段ずつ見る
:::

:::section
anchor: markovnikov
title: マルコフニコフ則 —— どちらが主に生じるか
lead: H−X が付加するとき、H は「水素がすでに多くついている炭素」のほうに結合しやすい、という決まりです。
terms:
- マルコフニコフ則
- 主生成物
- 副生成物
:::

二重結合の左右が同じ形をしていない場合、H−X の付き方は2通りあり、**2種類の生成物が考えられます。**どちらが主に生じるかを言い当てるのが**マルコフニコフ則**です。

**「付加する分子の H 原子は、H 原子が多く結合している C 原子に結合しやすい」**——これがマルコフニコフ則です。

:::figure
src: alkene-markovnikov.png
alt: プロペンに H−X が付加する2通りの反応を上下に並べた図。二重結合の左の炭素には H が2個、右の炭素には H が1個ついており、H が多い左の炭素に H−X の H が結合したものが主生成物、逆が副生成物と書かれている
caption: 緑の炭素には H が**2個**、紫の炭素には H が**1個**。H−X の H は**多いほうの緑**に付くので、上が**主生成物**、下が**副生成物**です。
:::

マルコフニコフ則で分かるのは**どちらが主に生じるか**だけで、**どの程度の割合で偏るかまでは分かりません。**

:::section
anchor: polymer
title: 付加重合とビニル化合物
lead: 二重結合が次々に開いて手をつなぐと、鎖状の高分子ができます。エテンから H を1個とった形をビニル基といいます。
terms:
- ビニル基
- ビニル化合物
- 付加重合
- 単量体
- 重合体
:::

エテン（エチレン）から水素原子を1個とった **−CH=CH₂** の構造を**ビニル基**、ビニル基をもつ化合物を**ビニル化合物**といいます。塩化ビニル CH₂=CHCl・酢酸ビニル・アクリロニトリルなどがそうです。

ビニル化合物は、適当な条件のもとで**連続的に付加反応を起こして、鎖状の高分子化合物**になります。二人組で手をつないで輪になった状態から片手をはなし、全員で1本の長い列になって手をつなぎ直した、と考えると分かりやすいかもしれません。

:::reaction
left: n CH₂=CHCl
right: ［CH₂−CHCl］ₙ
level: ★★★
note: 塩化ビニルが付加重合してポリ塩化ビニルになります。左辺の n と、右辺の角かっこの外の n が対応します。
:::

**単量体（モノマー）**が繰り返し結合して分子量の大きい**重合体（ポリマー）**になる反応を**重合**といい、そのうち**付加反応による重合**を**付加重合**といいます。重合には他に縮合重合などもあります。

:::section
anchor: oxidation
title: 酸化開裂と、不飽和結合の検出
lead: C=C は酸化されやすく、オゾンや過マンガン酸カリウムで切断されます。切れることを利用して、不飽和結合があるかどうかを調べられます。
terms:
- オゾン分解
- 酸化開裂
- 不飽和結合の検出
:::

炭素間二重結合は**酸化されやすく**、**オゾン O₃ と反応すると C=C が切断されて、アルデヒドまたはケトンが生じます。**これを**オゾン分解**といいます。

**過マンガン酸カリウム KMnO₄ と反応した場合も、同じように C=C が切断されますが、生じるのはカルボン酸またはケトンです。**オゾン分解では二重結合が切れるだけなのに対し、KMnO₄ による分解では**切れてできたアルデヒドがさらに酸化されてカルボン酸になる**ためです。

**オゾン分解も過マンガン酸カリウムによる分解も、反応式を暗記する必要はありません。**出題される場合は、反応式が問題文に与えられます。覚えておくのは「**C=C の位置で切れる**」という事実のほうです。

切れた位置が分かるということは、**逆にたどれば、もとの分子のどこに二重結合があったかが分かる**ということです。生じた2つのカルボニル化合物を C=O どうしでつなぎ直せば、もとのアルケンにもどります。**未知の物質の構造を決める問題で、この読み方がよく使われます。**

炭素間二重結合は、次の2つの**どちらか**で検出できます。

:::list
items:
- **臭素水に加えると、すみやかに付加反応が起きて臭素の赤褐色が消える。**
- **過マンガン酸カリウム水溶液に加えると、酸化還元反応が起きて KMnO₄ の赤紫色が消える。**
:::

:::callout
tone: caution
text: これらの反応は**炭素間三重結合 C≡C でも起こります。**正確には「二重結合の検出」ではなく**不飽和結合の検出**です。また、アルカンでも**光を当てて時間をかければ**置換反応が起きて臭素水を脱色するので、**「すみやかに消えるかどうか」**が分かれ目になります。
:::

:::section
anchor: ethene
title: エテン（エチレン）
lead: いちばん小さいアルケン。無色でかすかに甘いにおいの気体で、実験室ではエタノールを濃硫酸で脱水してつくります。
terms:
- エテン
- 分子内脱水
- 分子間脱水
:::

エテン（エチレン）C₂H₄ は、**無色で、かすかに甘いにおいのする気体**です。結合には極性がありますが、**分子全体で打ち消されるので無極性分子**になります。

無極性分子なので**水に溶けにくく、水上置換で捕集します。**反応性は高く、過マンガン酸カリウムやオゾンによって酸化される**還元剤**です。

**エテンは濃硫酸と付加反応してしまうので、乾燥剤に濃硫酸を使うことができません。**

工業的には、**ナフサ（粗製ガソリン）を熱分解して**つくります。実験室では、**160〜170℃ に熱した濃硫酸にエタノールを滴下**して、脱水反応でつくります。

:::reaction
left: CH₃CH₂OH
over: 濃硫酸
under: 160〜170℃
right: CH₂=CH₂ ＋ H₂O
level: ★★★
note: 1つの分子の中から水がとれるので**分子内脱水**といいます。無機化学で学んだ濃硫酸の脱水作用を使っています。
:::

**同じ組み合わせでも、温度を 130〜140℃ にすると、2つの分子の間で脱水が起こってジエチルエーテルが生じます。**こちらは**分子間脱水**です。

:::reaction
left: 2CH₃CH₂OH
over: 濃硫酸
under: 130〜140℃
right: C₂H₅OC₂H₅ ＋ H₂O
level: ★★★
note: 2分子から水が1個とれてジエチルエーテルになります。温度が低いほうが分子間脱水、と覚えます。
:::

**この2つの温度の使い分けは必ず暗記してください。**「**高いほうの 160〜170℃ でエテン、低いほうの 130〜140℃ でジエチルエーテル**」と、対にして押さえるのが確実です。

:::link
to: alcohol-dehydration
text: エタノール以外のアルコールを脱水すると、どのアルケンになるか
:::

エテン自身の反応は、ここまでに見てきたアルケンの反応そのままですが、**塩化ビニルの製法だけは個別に押さえておく必要があります。**エテンに塩素を付加して 1,2-ジクロロエタンにし、それを熱分解して塩化水素を脱離させます。

:::reaction
left: CH₂=CH₂ ＋ Cl₂
right: CH₂ClCH₂Cl
level: ★★★
note: まず塩素が付加して 1,2-ジクロロエタンになります。
:::

:::reaction
left: CH₂ClCH₂Cl
over: 熱分解
right: CH₂=CHCl ＋ HCl
level: ★★☆
note: 塩化水素が外れて（脱離して）塩化ビニルになります。工業的に塩化ビニルをつくるのに実際に使われている方法です。
:::

:::section
anchor: writeout
title: アルケンの書き出し
lead: 同じ分子式のアルケンを数え上げる手順です。同じ炭素数のアルカンを先に書き、二重結合をつくれる場所を探します。
terms:
- 構造異性体
- 書き出し
:::

「C₄H₈ のアルケンをすべて書け」のように、**同じ分子式の異性体を数え上げる**問題では、次の手順で書き出します。

:::list
ordered: true
items:
- **同じ炭素数のアルカンの構造異性体を、先に全部書き出す。**
　炭素数が4なら「ブタンとその異性体」、5なら「ペンタンとその異性体」を書きます。
- **書き出したそれぞれについて、炭素間の単結合を二重結合にできる場所を探す。**
　左右対称なところは同じものになるので、1つに数えます。
- **できたアルケンに、シス－トランス異性体があるかどうかを確かめる。**
　二重結合の炭素の片方に同じものが2個ついていたら、シス－トランス異性体はありません。
:::

具体例として、C₄H₈ のアルケン（ブテン）を書き出してみます。炭素数4のアルカンはブタンと 2-メチルプロパンの2種類です。直鎖のブタンは左右対称なので、二重結合をつくれる場所は2種類で、**1-ブテン**と **2-ブテン**が出ます。2-メチルプロパンは3つのメチル基が対称なので、二重結合をつくれる場所は1種類しかなく、**2-メチル-1-プロペン**だけです。

:::figure
src: alkene-butene-writeout.png

したがって、**ブテンの構造異性体は3種類、立体異性体まで含めると4種類**です。

二重結合をつくれる場所は、**炭素に水素が残っているかどうか**で決まります。**丁字交差点・道の途中・行き止まりの炭素は二重結合をつくれますが、十字交差点の炭素はつくれません。**十字交差点の炭素には、もう水素が1個もついていないためです。

text: **炭素数が5までのアルキル基は、書き出しの練習を徹底して、構造異性体の数も暗記してしまうとよいでしょう。**ここが速くなると、アルケンの書き出しも一気に速くなります。
:::

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: slides:有機の基本2-7「アルケンの性質」s16「練習1」（解答は s17）
prompt: 1-ブテン CH₂=CHCH₂CH₃ に塩化水素を付加したときに、**最も多く生じる**構造異性体の構造式を書け。
answer: **2-クロロブタン** CH₃CHClCH₂CH₃ です。1位の炭素には H が2個、2位の炭素には H が1個ついているので、マルコフニコフ則により、H の数が多い1位の炭素に HCl の H が結合します。その結果 Cl は2位につきます。ちなみに、もう一方（副生成物）は 1-クロロブタンです。
:::

:::exercise
source: slides:有機の基本2-10「アルケンの書き出し」s16「練習1」（解答は s17）
prompt: アルカンの書き出しを用いて、**ブテンの鎖式の構造異性体**の構造式をすべて書き出せ。
answer: 3種類です。**1-ブテン** CH₂=CHCH₂CH₃、**2-ブテン** CH₃CH=CHCH₃、**2-メチル-1-プロペン** CH₂=C(CH₃)₂。2-ブテンにはシス－トランス異性体があるので、立体異性体まで含めると4種類になります。
:::
