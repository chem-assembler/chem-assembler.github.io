直鎖のアルカンは、炭素を1列につないで、余った手をぜんぶ水素でうめた分子です。つなぎ方に選択の余地がないので、**名前は炭素の数だけで決まります**。

C1〜C4 の語幹（メタ・エタ・プロパ・ブタ）は数と関係のない古い呼び名ですが、C5 からは数を表す接頭辞（ペンタ=5・ヘキサ=6・ヘプタ=7・オクタ=8・ノナ=9・デカ=10）がそのまま名前になります。語尾はどれも **-ane（〜アン）**で、これが「飽和」の印です。

:::section
anchor: branched
title: 枝分かれしたアルカンの名前
lead: 主鎖と同じ炭素数のアルカンを基準に、「何が」「何個」「どこに」を読み取って、後ろから順に組み立てます。
terms:
- 主鎖
- 側鎖
- 置換基
- 接頭辞
:::



枝分かれがあるアルカンの名称は以下の手順で**後ろから順に**決めます。

:::list
ordered: true
items:
- 一番長い鎖（主鎖）を探し、炭素の数を数えて対応するアルカンの名称を末尾に置く。
　主鎖の炭素数が4なら「○○ブタン」、5なら「○○ペンタン」
- 主鎖に付いている枝（側鎖）を探し、アルキル基の種類と数を数えアルカンの名称の前に置く。
　数はギリシャ語の接頭辞（1：モノ、2：ジ、3：トリ、4：テトラ）を使って表します。
　アルキル基の名称は、対応する炭素数のアルカンの名称の語尾を **-yl（イル）**に変化させます。
　メチル基が1個付いたブタンなら「○○メチルブタン」（「モノ」は省略します）、メチル基が2個付いたペンタンなら「○○ジメチルペンタン」となります。
- 側鎖が主鎖のどの炭素原子に付いているか（端から数えて何番目の炭素原子に付いているか）を調べ数字で表す。
　主鎖の端から2番目の炭素原子にメチル基が1個付いたブタンなら「2-メチルブタン」、主鎖の端から2番目と3番目の炭素原子に1個ずつメチル基が付いたペンタンなら「2,3-ジメチルペンタン」となります。
:::

## 具体例1

:::figure
src: alkane-naming-example-chain.png
alt: 2,3-ジメチルペンタンの構造式。CH₃−CH−CH−CH₂−CH₃ が横一直線に並び、2番目と3番目の CH の上にメチル基 CH₃ が1つずつ付いていて、主鎖の下にオレンジの矢印が引いてある
caption: 今回の分子です。オレンジの矢印が主鎖（いちばん長い炭素の鎖）で、**構造式を書くときは主鎖を横一直線に書きます**。
:::

1. まず最も長い炭素鎖（主鎖）を見つけます。

:::figure
src: alkane-naming-wrong-chain.png
alt: 同じ分子を、横に並んだ炭素4個のほうを主鎖と取り違えて描いた構造式。その4個に端から4・3・2・1の番号が振ってある
caption: 主鎖を取り違えた図。この4個を主鎖にすると「2-エチル-3-メチルブタン」になってしまいます。**いちばん長い鎖は、紙の上でまっすぐ並んでいるとは限りません。**
:::

主鎖の炭素数は5なので、この分子の名称は「○○ペンタン」になります。分子式はC₇H₁₆でヘプタンの構造異性体ですが、名称は主鎖に着目して「ペンタンを基準にどこがどう違うか」で表します。

2. 次に主鎖に付いている枝（側鎖）を調べます。

//側鎖にマーカーを付けた構造式

この分子の側鎖はメチル基 −CH₃ が2個ですので、名称は「○○ジメチルペンタン」です。

3. 最後に側鎖の位置を調べます。

:::figure
src: alkane-naming-numbered.png
alt: 同じ分子に主鎖の番号を振った構造式。左端の CH₃ が1、その右の CH が2、次の CH が3、そこから上へ折れた CH₂ が4、その先の CH₃ が5
caption: 主鎖に端から番号を振ります。4と5が上へ折れているのは、主鎖がそこで曲がっているからです。
:::

2個のメチル基は主鎖の「2番目と3番目の炭素原子」に付いていますので、この分子の名称は「2,3-ジメチルペンタン」になります。

## 注意

//主鎖に逆の番号を振った構造式

:::mistake
wrong: 主鎖はどちらの端から数えても同じ長さなのだから、番号は好きな向きに振ってよい
right: 番号は「**名称の数字が小さくなるように**」振ります。さっきの分子なら **2,3-ジメチルペンタン**の1通りで、逆から振った「3,4-ジメチルペンタン」は名前として認められません。
why: 向きを1つに決めておかないと、同じ構造式に2つの名前が付いてしまいます。⚠ 番号の向きを決めるのは、**構造式と名称を1:1で対応させる**ためです。
:::

## 置換基が2種類以上ある場合

置換基が2種類以上ある場合は、続けて書き並べて名称にします。

:::figure
src: alkane-naming-ethyl-dimethyl-hexane.png
gen: name=3-エチル-2,3-ジメチルヘキサン chain=6 subs=2-メチル,3-メチル,3-エチル numbered
alt: 3-エチル-2,3-ジメチルヘキサンの構造式。炭素6個の主鎖が横一直線に並び、オレンジの帯が主鎖の上を通って左端から C₁ C₂ C₃ C₄ C₅ C₆ と番号が振ってある。C₂ と C₃ にメチル基 CH₃ が1個ずつ、C₃ にはさらにエチル基 CH₂CH₃ が1個付いている
caption: オレンジの帯が主鎖（炭素6個）で、番号は端から数えた位置です。枝は C₂ にメチル基、C₃ にメチル基とエチル基。
:::

この分子は主鎖の炭素数が6で、2,3番の炭素原子にメチル基が2個、3番の炭素原子にエチル基が1個付いているので「3-エチル-2,3-ジメチルヘキサン」になります。メチル基（methyl）とエチル基（ethyl）を書く順番はアルファベット順ですが、この順番については覚えなくても困ることはないと思います。一般に「名称→構造式」よりも「構造式→名称」の方が難しいです。複雑な分子については「名称→構造式」がわかれば十分でしょう。
