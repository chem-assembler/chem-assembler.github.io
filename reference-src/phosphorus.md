リン P は窒素と同じ15族の元素で、原子は5個の価電子をもちます。自然界では単体では存在せず、リン灰石（主成分はリン酸カルシウム Ca₃(PO₄)₂）などの鉱物として存在します。DNA などの核酸にも含まれ、窒素と同じく生命活動に欠かせない元素です。

リンの化合物は、**単体を燃やすと酸化物、酸化物に水を加えるとオキソ酸**という一本道でつながります。このページはその順に見ていきます。

:::section

title: 黄リンと赤リン —— リンの同素体
lead: 黄リンは反応性が高く、空気中で自然発火するので水中に保存します。赤リンはおだやかで、マッチの側薬に使われます。
terms:
- 同素体
- 黄リン
- 赤リン

同じ元素からできていて、性質の異なる単体どうしを**同素体**といいます。リンには黄リンと赤リンの2つの同素体があります。

:::table
caption: 黄リンと赤リン
source: textbook:R5化学Vol.2-4編（リンの同素体の本文と表の事実）。欄の並びはスライドの同素体の表（無機の基本６ s7 硫黄の同素体）にそろえた
head:
- 項目
- 黄リン
- 赤リン
align: left | left | left
rows:
- 色・ようす | 淡黄色のろう状の固体 | 赤褐色の粉末
- 化学式 | P₄（分子式） | P（組成式）
- 反応性 | 高い（空気中で自然発火する） | 低い
- 毒性 | 猛毒 | 毒性は少ない
- 二硫化炭素 CS₂ に | 溶ける | 溶けない
- 保存・用途 | **水中に保存する** | マッチ箱の側薬
:::

黄リンは P₄ という正四面体形の分子からなり、赤リンは多数の P 原子がつながった構造をしています。そのため黄リンは分子式 P₄、赤リンは組成式 P で書きます。

**黄リンは空気中で自然発火するので水中に保存します。**「黄リンは水中、ナトリウムは石油中」と、保存方法をセットで覚えておきましょう。黄リンは精製すると白色になるので、白リンとも呼ばれます。

:::link

text: ナトリウムを石油中に保存する理由はアルカリ金属のページへ
:::

:::section
anchor: p4o10
title: 十酸化四リン P₄O₁₀ —— 強力な乾燥剤
lead: リンを燃やすと白色の P₄O₁₀ になります。水をよく吸うので乾燥剤に使い、水と反応するとリン酸になります。
terms:
- 十酸化四リン
- 乾燥剤
- 酸性酸化物
:::

リンを空気中で燃焼させると、白色の粉末の十酸化四リン P₄O₁₀ になります。

:::reaction
left: 4P ＋ 5O₂
right: P₄O₁₀
level: ★★★
note: リンの燃焼です。黄リンでも赤リンでも同じ P₄O₁₀ になります。
:::

十酸化四リンは**酸性酸化物**で、水と反応してリン酸になります。

:::reaction
left: P₄O₁₀ ＋ 6H₂O
over: 加熱
right: 4H₃PO₄
level: ★★★
note: 酸性酸化物と水の反応です。係数は P を4個そろえて H₃PO₄ を4個、次に H を12個そろえて H₂O を6個、の順に決まります。
:::

**この2本は必ず書けるようにしてください。**P₄O₁₀ ＋ 6H₂O → 4H₃PO₄ は、酸性酸化物と水の反応の代表として、SO₃ ＋ H₂O → H₂SO₄ とならんでよく登場します。

:::link
to: oxoacid
text: 酸性酸化物と水の反応をまとめて見るページへ
:::

十酸化四リンは水をよく吸うので、**強力な乾燥剤**として使われます。**酸性の乾燥剤**なので、塩基性の気体のアンモニアの乾燥には使えません（中和してしまうため）。

乾燥剤は「**酸性の気体には酸性の乾燥剤、塩基性の気体には塩基性の乾燥剤**」と、中和が起こらない組み合わせで選びます。乾燥剤を並べた表と例外は、気体の早見のページが持っています。

:::link
to: gas-preparation
text: 気体ごとの捕集法と乾燥剤を横に並べた早見のページへ
:::

十酸化四リンは、五酸化二リン P₂O₅ という名前でも売られています。組成式で書くと P₂O₅ で、実際の分子が P₄O₁₀ です。

:::section
anchor: phosphoric-acid
title: リン酸 H₃PO₄ —— 3価の酸
lead: 3つの H⁺ を段階的に出す3価の酸です。高校化学では弱酸として扱います。
terms:
- リン酸
- 価数
- 過リン酸石灰
:::

リン酸 H₃PO₄ は無色の結晶で、水によく溶けます。**1分子から H⁺ を3個まで出せる3価の酸**です。

:::reaction
left: H₃PO₄
right: 3H⁺ ＋ PO₄³⁻
level: ★★☆
note: 価数を確かめるためにまとめて書いた式です。実際は H⁺ を1個ずつ3段階に分けて出し、どの段階も電離はごく一部です。
:::

「**強酸は3つ覚える（HCl・HNO₃・H₂SO₄）、その他は弱酸**」の決め方で、リン酸は**弱酸**に入ります。

:::callout
tone: caution
text: リン酸は酢酸などよりは強く、「中程度の強さの酸」と書かれることもあります。ただし強酸の3つには入らないので、pH や中和の問題では弱酸として扱えば困りません。
:::

中和では、**価数の逆の比**で塩基と反応します。3価のリン酸と2価の水酸化バリウムなら、物質量の比 2：3 で完全に中和します。

:::reaction
left: 2H₃PO₄ ＋ 3Ba(OH)₂
right: Ba₃(PO₄)₂ ＋ 6H₂O
level: ★★★
note: H⁺ も OH⁻ も6個ずつなので、生じる H₂O も6個です。
:::

水酸化ナトリウムとは、加える量によって1段目・2段目・3段目の塩ができます（NaH₂PO₄ → Na₂HPO₄ → Na₃PO₄）。

## 肥料としてのリン

リン酸カルシウムは水に溶けないので、そのままでは植物が吸収できません。硫酸と反応させて水に溶けるリン酸二水素カルシウムに変えたものを**過リン酸石灰**といい、リン酸肥料に使います。

:::reaction
left: Ca₃(PO₄)₂ ＋ 2H₂SO₄
right: Ca(H₂PO₄)₂ ＋ 2CaSO₄
level: ★☆☆
note: 実際にできるのはリン酸二水素カルシウムの一水和物 Ca(H₂PO₄)₂・H₂O と CaSO₄ の混合物で、これが過リン酸石灰です。
:::

**過リン酸石灰の反応式は覚えなくても構いません。**「リン酸カルシウムを硫酸で水に溶ける形にしたもの」と言えれば十分です。

:::section
anchor: range
title: 覚える範囲
lead: 黄リンの保存方法、P₄O₁₀ の2本の式、リン酸が3価の弱酸であることの3つです。
:::

**次の3つは必ず覚えてください。**

:::list
items:
- 黄リンは空気中で自然発火するので水中に保存する（赤リンはマッチ）
- 4P ＋ 5O₂ → P₄O₁₀ と P₄O₁₀ ＋ 6H₂O → 4H₃PO₄
- P₄O₁₀ は酸性の乾燥剤で、NH₃ には使えない
:::

同素体の細かい性質（密度・発火点）と、過リン酸石灰の反応式は覚えなくても構いません。
