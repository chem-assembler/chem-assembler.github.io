反応エンタルピーの中には、実験で直接測れないものがあります。このページでは、測れる反応の ΔH を組み合わせて、測れない反応の ΔH を求める方法を扱います。ΔH の符号の約束（発熱は負）と、エネルギー図の描き方は前のページで扱いました。

text: ΔH の符号とエネルギー図の約束はこちら

:::section
anchor: law
title: ヘスの法則
lead: スタートとゴールが同じなら、途中の道すじを変えても、ΔH の合計は同じ値になります。
terms:
- ヘスの法則
- 総熱量保存の法則
:::

物質の最初の状態と最後の状態が決まっていれば、1段で一気に進めても、何段かに分けて進めても、ΔH を足し合わせた値は変わりません。この決まりが**ヘスの法則**（総熱量保存の法則）です。ヘスが 1840 年に、たくさんの反応の熱を測り比べて気づきました。

具体例1で、水素と酸素から液体の水 1mol をつくります。経路は2通りあります。

:::table
caption: 液体の水をつくる2つの経路（25℃）
source: 水素の燃焼の2つの式（反応エンタルピーのページの −286kJ・−242kJ）と、25℃ での水の凝縮（蒸発の 44kJ/mol の逆）を、経路ごとに1行へ並べたもの
head:
- 経路
- 反応
- ΔH
align: left | left | right
rows:
- Ⅰ（直接） | H₂(気) ＋ ½O₂(気) → H₂O(液) | −286 kJ
- Ⅱ の1段目（水蒸気をつくる） | H₂(気) ＋ ½O₂(気) → H₂O(気) | −242 kJ
- Ⅱ の2段目（凝縮させる） | H₂O(気) → H₂O(液) | −44 kJ
- Ⅱ の合計 | （はじめと終わりはⅠと同じ） | −286 kJ
:::

経路Ⅱの2段を足すと (−242) ＋ (−44) ＝ −286kJ で、経路Ⅰと同じになります。**物質はそれぞれ決まったエンタルピーをもっている**ので、はじめと終わりが同じなら、その差もどの道を通っても同じになるためです。

エネルギー図でいえば、**準位の高さは物質で決まっていて、どの経路を通っても高さの差は同じ**です。山登りで、どの登山道を通っても山頂と麓の標高差が変わらないのと同じです。

:::section
anchor: diagram
title: 準位を置いて高さの差をとる
lead: 基準の準位を 0 に置き、与えられた式から残りの準位の高さを決めます。求める ΔH は（到達点の高さ）−（出発点の高さ）です。
:::

ヘスの法則の計算は、エネルギー図の**準位の高さ**を決めていけば、足し算と引き算だけで解けます。次の順で進めます。

:::list
ordered: true
items:
- 与えられた式に出てくる状態を、準位として書き出す。
　準位は「C(黒鉛) ＋ O₂(気)」のように、**左辺全体・右辺全体を1つの準位**にする。
- どれか1つの準位を基準にして、高さを 0 とする。
　ふつうは、いちばん上に来る準位（単体の組など）を基準にします。
- 与えられた式を1本ずつ使い、基準から順に高さを置いていく。
　「○○ → △△　ΔH ＝ −□□kJ」なら、△△ は ○○ より □□ だけ低い。
- 求める反応の ΔH ＝（到達点の高さ）−（出発点の高さ）。
:::

具体例2で、一酸化炭素 CO の生成エンタルピーを求めます。C（黒鉛）を燃やすと CO₂ もできてしまうので、CO の生成は直接測れません。使うのは、測れる2つの燃焼の式です。

:::reaction
left: C(黒鉛) ＋ O₂(気)
right: CO₂(気)　ΔH ＝ −394 kJ
level: ★★★
note: 黒鉛の燃焼エンタルピー。CO₂ の生成エンタルピーでもあります。
:::

:::reaction
left: CO(気) ＋ ½O₂(気)
right: CO₂(気)　ΔH ＝ −283 kJ
level: ★★☆
note: 一酸化炭素の燃焼エンタルピー。
:::

:::list
ordered: true
items:
- 準位は「C(黒鉛) ＋ O₂(気)」「CO(気) ＋ ½O₂(気)」「CO₂(気)」の3つ。
- いちばん上の「C(黒鉛) ＋ O₂(気)」を 0 とする。
- 1本目の式から、CO₂(気) は −394。2本目の式から、CO(気) ＋ ½O₂(気) は CO₂ より 283 高いので、−394 ＋ 283 ＝ −111。
- 求める C(黒鉛) ＋ ½O₂(気) → CO(気) は、0 から −111 へ下りるので、ΔH ＝ −111 − 0 ＝ **−111kJ**。
:::

:::mistake
wrong: 「ヘスの法則は ΔH を足す法則」と覚えて、CO の生成エンタルピーを (−394) ＋ (−283) ＝ −677kJ とする
right: 求める反応がどの準位からどの準位へ行くのかを図で決め、**（到達点の高さ）−（出発点の高さ）**をとります。この例では −111kJ です。
why: 足すか引くかを式の見た目で決めると、逆向きにたどる所で符号を落とします。★ 図に矢印を描けば、逆向きにたどる所は矢印が逆を向くので、符号の反転が目で見えます。
:::

:::section
anchor: formation
title: 生成エンタルピーで反応エンタルピーを出す
lead: 単体の組をいちばん上の基準 0 に置くと、各化合物の生成エンタルピーがそのまま準位の高さになります。反応エンタルピー ＝（生成物の生成エンタルピーの和）−（反応物の生成エンタルピーの和）です。
terms:
- 生成エンタルピー
:::

**単体の組を基準 0 に置くと、生成エンタルピーがそのまま高さになります。**生成エンタルピーは「単体から化合物 1mol ができるときの ΔH」なので、単体からの高さの差そのものだからです。

そのため、生成エンタルピーが分かっている物質だけでできた反応は、次の関係で ΔH が出ます。

**反応エンタルピー ＝（生成物の生成エンタルピーの和）−（反応物の生成エンタルピーの和）**

式の形は「（到達点の高さ）−（出発点の高さ）」と同じです。**単体の生成エンタルピーは 0** なので、O₂ などの単体は足しても引いても変わりません。

具体例3で、メタンの燃焼エンタルピーを生成エンタルピーから求めます。CH₄ −75kJ/mol、CO₂ −394kJ/mol、H₂O（液）−286kJ/mol です。

:::reaction
left: CH₄(気) ＋ 2O₂(気)
right: CO₂(気) ＋ 2H₂O(液)　ΔH ＝ x kJ
level: ★★★
note: 反応物の高さは −75 ＋ 0、生成物の高さは −394 ＋ 2×(−286) ＝ −966 です。
:::

:::list
ordered: true
items:
- 基準 0 の準位は、C(黒鉛) ＋ 2H₂(気) ＋ 2O₂(気)。
- 反応物 CH₄(気) ＋ 2O₂(気) の高さは −75。
- 生成物 CO₂(気) ＋ 2H₂O(液) の高さは −394 ＋ 2×(−286) ＝ −966。
- x ＝ −966 −（−75）＝ **−891kJ**。
:::

⚠ **係数の分だけ生成エンタルピーを掛けます。** H₂O は 2mol できるので、−286 を2倍します。

:::section
anchor: algebra
title: 別解 —— 式を足し引きする
lead: 与えられた式を数式のように足し引きして、求める式を組み立てる方法もあります。式を逆向きにしたら ΔH の符号も逆にします。
:::

与えられた式を、**求める式の左辺と右辺に合うように並べ替えて足し引きする**方法もあります。具体例2なら、1本目の式から2本目の式を引くと、CO₂ が消えて C(黒鉛) ＋ ½O₂ → CO が残り、ΔH は (−394) − (−283) ＝ −111kJ です。

この方法では、**式を逆向きにしたら ΔH の符号を逆にし、式を ○○ 倍したら ΔH も ○○ 倍にする**のを忘れないようにします。どちらの解き方でも答えは同じなので、慣れたほうを使ってかまいません。準位の数が多い問題では、図のほうが見通しがよくなります。

:::section
anchor: range
title: 覚える範囲
lead: 「経路によらず、はじめと終わりで決まる」と、準位を置いて差をとる手順を覚えます。値は問題文に書かれます。
:::

**「スタートとゴールが同じなら、どの道すじでも ΔH の合計は同じ」というヘスの法則の中身は必ず覚えてください。**計算は「基準を 0 に置く → 準位の高さを決める → 到達点 − 出発点」の3段で、どの問題も同じです。

「（生成物の生成エンタルピーの和）−（反応物の生成エンタルピーの和）」は覚えてもよいですが、**図を描けば出てくる式なので、丸暗記より図から出せるようにしましょう。**生成エンタルピーや燃焼エンタルピーの数値は、問題文で与えられるので覚える必要はありません。

## 例題

:::exercise
source: 自作（ratio/thermo の h6 と同じ題材。値は ratio の問題データ）
prompt: C(黒鉛) ＋ O₂(気) → CO₂(気)　ΔH ＝ −394 kJ、C(ダイヤモンド) ＋ O₂(気) → CO₂(気)　ΔH ＝ −396 kJ である。**(1) C(黒鉛) → C(ダイヤモンド) の ΔH は何 kJ か。　(2) 黒鉛とダイヤモンドは、どちらがエネルギーの低い（安定な）状態か。**
answer: (1) **＋2kJ**。C(黒鉛) ＋ O₂ を 0 とすると、CO₂ は −394。C(ダイヤモンド) ＋ O₂ は CO₂ より 396 高いので −394 ＋ 396 ＝ ＋2。黒鉛（0）からダイヤモンド（＋2）へ上るので ΔH ＝ ＋2 − 0 ＝ ＋2kJ。　(2) **黒鉛**。ダイヤモンドのほうが 2kJ 高いためです。炭素の生成エンタルピーの基準（0）を黒鉛にとるのも、黒鉛が安定だからです。
:::

:::exercise
source: 自作（このページの「生成エンタルピーから」の節から作った問い。数値は教科書の表1・表3の値を丸めたもの）
prompt: エタノール C₂H₅OH（液）の燃焼エンタルピーは −1368kJ/mol、CO₂（気）と H₂O（液）の生成エンタルピーはそれぞれ −394kJ/mol、−286kJ/mol である。**エタノールの生成エンタルピーは何 kJ/mol か。**
answer: **−278kJ/mol**。燃焼の式は C₂H₅OH(液) ＋ 3O₂(気) → 2CO₂(気) ＋ 3H₂O(液)　ΔH ＝ −1368 kJ。単体の組 2C(黒鉛) ＋ 3H₂(気) ＋ 7/2O₂(気) を 0 とすると、生成物の高さは 2×(−394) ＋ 3×(−286) ＝ −1646。反応物（エタノール ＋ 3O₂）の高さを x とすると、−1646 − x ＝ −1368 より x ＝ −278。O₂ の高さは 0 なので、これがエタノールの生成エンタルピーです。
:::
