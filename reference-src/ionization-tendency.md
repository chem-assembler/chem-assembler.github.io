金属は、単体が e⁻ を失って陽イオンになる**還元剤**としてはたらきます。そのなりやすさは金属ごとに違い、この順を知っていると、金属どうし・金属と酸の反応が起こるかどうかを予想できます。

:::link
to: redox-basics
text: 還元剤は e⁻ を与える物質、酸化剤は e⁻ を受け取る物質（「酸化と還元」）
:::

:::section
anchor: series
title: イオン化傾向とイオン化列
lead: 水溶液の中で陽イオンになりたがる順に金属を並べると、イオン化列ができます。
terms:
- イオン化傾向
- イオン化列
:::

金属を水溶液に入れると、e⁻ を手放して陽イオンになり、液の中へ溶け出そうとします。その「なりたがり具合」を金属どうしで比べたものが「イオン化傾向」です。

:::reaction
left: Cu
right: Cu²⁺ ＋ 2e⁻
level: ★★★
note: 銅の単体（酸化数 0）が e⁻ を2個失って、水溶液中の Cu²⁺（酸化数 ＋2）になる反応。イオン化傾向が大きい金属ほど、この反応を起こしやすい（＝ 強力な還元剤）です。
:::

よく出てくる金属を、イオン化傾向の強いものから弱いものへ1列に並べると「イオン化列」になります。

　Li ＞ K ＞ Ca ＞ Na ＞ Mg ＞ Al ＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞ (H₂) ＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au

**イオン化列は必ず暗記してください。**H は非金属元素ですが、例外的に陽イオン H⁺ になるので、他の金属と同じようにイオン化列の位置から性質を考えることができます。

:::mistake
wrong: イオン化傾向は、イオン化エネルギーが小さい順に並べたものである
right: イオン化傾向は、**水溶液中で**金属が陽イオンになるなりやすさです。気体の原子から e⁻ を取り去るのに要するイオン化エネルギーとは別の量です。
why: どちらも「イオン化」と名前が似ているので混同しやすいところです。例えば Li はイオン化エネルギーはアルカリ金属の中で最も大きいのに、イオン化傾向は最も大きい金属です。
:::

:::heading
title: Li のイオン化傾向がいちばん大きいわけ
advanced: true
:::

金属が水溶液中で陽イオンになるには、固体の金属をばらばらの原子にする・原子から e⁻ を取り去る・できたイオンが水分子に囲まれる（水和）、の3段階を通ります。Li はイオン化エネルギーは大きいものの、Li⁺ はイオンが小さいので水分子を強く引きつけ、水和で大きく安定になります。3段階を合わせると、Li がいちばん陽イオンになりやすくなります。

:::section
anchor: reversible
title: 単体は還元剤、陽イオンは酸化剤
lead: 金属の単体と陽イオンは可逆的に変化します。イオン化傾向が大きい金属は単体が、小さい金属は陽イオンが強くはたらきます。
terms:
- 金属の単体
- 金属の陽イオン
:::

金属の単体は e⁻ を放出して陽イオンになるので**還元剤**、金属の陽イオンは e⁻ を受け取って単体になるので**酸化剤**です。2つの反応は逆向きの関係にあり、1本にまとめて書けます。

:::reaction
left: Cu
arrow: ⇄
right: Cu²⁺ ＋ 2e⁻
level: ★★★
note: 右向きは単体 Cu が還元剤、左向きは Cu²⁺ が酸化剤としてはたらく反応です。
:::

**イオン化傾向が大きい金属は単体が強力な還元剤、小さい金属は陽イオンが強力な酸化剤**です。

## 具体例

Na はイオン化傾向が非常に大きいので、単体の還元力が非常に強く、水とも激しく反応します。逆に Na⁺ が酸化剤としてはたらくことは通常はありません（溶融塩電解で e⁻ を無理に押し付けると、Na⁺ を還元できます）。

:::section
anchor: tree
title: 金属樹と、金属が希酸に溶ける反応
lead: どちらも同じしくみです。生じる単体が金属の固体か、非金属の気体かの違いしかありません。
terms:
- 金属樹
- 希酸
:::

イオン化傾向が大きい金属の単体（還元剤）と、イオン化傾向が小さい金属の陽イオン（酸化剤）が出会うと、酸化還元反応が起こります。

## 金属樹の生成

亜鉛 Zn を硫酸銅(Ⅱ) CuSO₄ 水溶液に入れると、イオン化傾向は Zn ＞ Cu なので、Zn が e⁻ を手放して Zn²⁺ になり、Cu²⁺ がその e⁻ を受け取って Cu として析出します（銅樹）。

:::reaction
left: Zn ＋ Cu²⁺
right: Zn²⁺ ＋ Cu
level: ★★★
note: Zn → Zn²⁺ ＋ 2e⁻ と Cu²⁺ ＋ 2e⁻ → Cu を足した式。
:::

:::reaction
left: Cu ＋ 2Ag⁺
right: Cu²⁺ ＋ 2Ag
level: ★★★
note: 銀樹。イオン化傾向は Cu ＞ Ag。Ag⁺ の半反応式を2倍して e⁻ をそろえます。
:::

## 金属が希酸に溶解する反応

亜鉛を希塩酸に入れると、イオン化傾向は Zn ＞ H₂ なので、Zn が陽イオンになり、H⁺ が e⁻ を受け取って H₂ が発生します。

:::reaction
left: Zn ＋ 2H⁺
right: Zn²⁺ ＋ H₂↑
level: ★★★
note: 化学反応式では Zn ＋ 2HCl → ZnCl₂ ＋ H₂（希塩酸）、Zn ＋ H₂SO₄ → ZnSO₄ ＋ H₂（希硫酸）。
:::

:::figure
src: ionization-tendency-tree.png

## 水との反応

:::reaction
left: 2Na ＋ 2H₂O
right: 2NaOH ＋ H₂↑
level: ★★★
note: 常温の水。Na → Na⁺ ＋ e⁻ を2倍し、水が酸化剤としてはたらく 2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ と足します。
:::

:::reaction
left: Mg ＋ 2H₂O
over: 熱水
right: Mg(OH)₂ ＋ H₂↑
level: ★★☆
note: Mg は、常温の水ではほぼ反応が見えず、熱水に入れると反応します。
:::

:::reaction
left: 3Fe ＋ 4H₂O
over: 高温
right: Fe₃O₄ ＋ 4H₂
level: ★☆☆
note: 高温の水蒸気との反応。水酸化物ではなく酸化物ができます。
:::

## 酸との反応

水素よりイオン化傾向が大きい金属は、希塩酸・希硫酸の H⁺ に e⁻ を渡して H₂ に変え、自分は陽イオンになって溶けていきます。水素より小さい Cu・Hg・Ag は H⁺ を還元できないので、希塩酸・希硫酸には溶けません。

「酸化力のある酸」は、**希硝酸（→ NO）、濃硝酸（→ NO₂）、熱濃硫酸（→ SO₂）の3つ**で、H⁺ よりも強い酸化力をもつ陰イオンをもつ酸のことです。Cu・Hg・Ag はこれらには溶け、このとき発生する気体は H₂ ではありません。

## 表の例外

:::list
items:
- 鉛 Pb はイオン化列で水素より左にあるのに、塩酸や希硫酸にはほとんど溶けない。溶けはじめるとすぐ、表面が水に溶けない PbCl₂ や PbSO₄ で覆われ、ふたをされた形になるためです。
- アルミニウム Al・鉄 Fe・ニッケル Ni は濃硝酸には溶けない。表面をすき間のない酸化物の膜が覆い、その膜が中の金属を守るためです。この状態を**不動態**とよびます。
- 白金 Pt・金 Au は、硝酸にも熱濃硫酸にも溶けない。ところが王水（濃硝酸と濃塩酸を体積比 1：3 で混ぜた液体）に入れると溶ける。
:::

**この3つの例外は、表と一緒に覚えておきましょう。**特に不動態の「Al・Fe・Ni」はよく登場します。

:::heading
title: 王水が金を溶かすわけ
advanced: true
:::

王水が金を溶かすのは、単に酸化力が強いからではありません。濃塩酸から供給される多量の Cl⁻ が、生じた金(Ⅲ)イオンと安定な錯イオン [AuCl₄]⁻ をつくるため、金がイオンになる反応が進みやすくなります。

## 例題

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.71-75（練習11）
prompt: A〜E は、ナトリウム・亜鉛・銅・銀・白金の単体のいずれかである。(ア) A〜E を希塩酸に入れたところ、B・C が溶けた。(イ) A〜E を希硝酸に入れたところ、A のみが溶けなかった。(ウ) A〜E を常温の水に入れたところ、B のみが溶けた。(エ) D のイオンを含む水溶液に E の小片を入れると、表面に D が析出した。**(1) A〜E を元素記号で答えよ。(2) (エ)の反応をイオン反応式で書け。(3) B が水に溶ける反応を化学反応式で書け。**
answer: **(1) A：Pt　B：Na　C：Zn　D：Ag　E：Cu　(2) Cu ＋ 2Ag⁺ → Cu²⁺ ＋ 2Ag　(3) 2Na ＋ 2H₂O → 2NaOH ＋ H₂** です。(ア) 希塩酸に溶けるのは水素よりイオン化傾向が大きい Na・Zn なので B・C が Na か Zn。(イ) 希硝酸にも溶けないのは Pt だけなので A は Pt。(ウ) 常温の水に溶けるのは Na なので B が Na、C が Zn。残る D・E は Cu か Ag で、(エ) E が D のイオンに e⁻ を渡しているのでイオン化傾向は E ＞ D。よって E が Cu、D が Ag です。
:::
