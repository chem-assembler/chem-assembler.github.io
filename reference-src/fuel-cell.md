電池は、実際に使われている**実用電池**を中心に、たくさんの種類が知られています。ただし、仕組みまで覚えておかないと解けない問題が出るのは、**鉛蓄電池と燃料電池の2つだけ**です。このページでは実用電池を一覧でおさえ、燃料電池の反応式をつくれるようにします。

:::section
anchor: practical
title: 一次電池と二次電池
lead: 充電できない使い切りの電池を一次電池、充電してくり返し使える電池を二次電池（蓄電池）といいます。
terms:
- 実用電池
- 一次電池
- 二次電池
- 蓄電池
- 充電
- 放電
:::

電池から電流を取り出すことを**放電**といいます。放電を続けると、電池の起電力はしだいに下がります。

放電したあと元にもどせない、使い切りの電池を**一次電池**といいます。代表例は**マンガン乾電池**です。

外部の電源から放電のときと逆向きに電流を流すと、起電力を回復させられる電池を**二次電池**または**蓄電池**といい、この操作を**充電**といいます。代表例は**鉛蓄電池**と**リチウムイオン電池**です。

リチウムイオン電池は広く使われているので、教科書・参考書に難しい反応式まで載っています。ですが、出題されるときは電池の原理の理解や読解力を問う形になるので、**反応式を暗記する必要はありません**。

:::section
anchor: fuel
title: 燃料電池の仕組み
lead: 燃料（還元剤）の H₂ と、酸化剤の O₂ を別々の電極に送り込んで電気を取り出します。全体では H₂ の燃焼と同じ反応です。
terms:
- 燃料電池
- 多孔質電極
- リン酸型燃料電池
:::

燃料（還元剤）と酸素（酸化剤）を反応させて、燃焼の熱の代わりに電気エネルギーを取り出す装置を**燃料電池**といいます。代表的なのは、燃料に水素 H₂、電解液にリン酸 H₃PO₄ 水溶液を使う**リン酸型燃料電池**です。電極には、気体が通れるように細かい穴の空いた**多孔質電極**を使います。

リン酸型燃料電池の構成は **（−）H₂｜H₃PO₄aq｜O₂（＋）** です。

:::figure
src: fuel-cell-phosphoric.png
alt: リン酸型燃料電池の模式図。左の多孔質電極に H₂ が送り込まれ、H⁺ となって電解液に溶け込み、e⁻ は導線を通って右の電極へ流れる。右の多孔質電極には O₂ が送り込まれ、H⁺ と e⁻ と反応して H₂O ができる
caption: 負極では H₂ が H⁺ になって電解液に溶け込み、e⁻ が正極へ流れます。正極では O₂・H⁺・e⁻ が反応して H₂O ができます。
:::

負極では、H₂ が e⁻ を放出して H⁺ となり、電解液に溶け込みます。正極では、O₂ が電解液中の H⁺ と導線から来た e⁻ を受け取って、H₂O になります。

:::reaction
left: H₂
right: 2H⁺ ＋ 2e⁻
level: ★★★
note: 負極（リン酸型）。H₂ が還元剤としてはたらきます。
:::

:::reaction
left: O₂ ＋ 4H⁺ ＋ 4e⁻
right: 2H₂O
level: ★★★
note: 正極（リン酸型）。O₂ が酸化剤としてはたらきます。
:::

:::link
app: ion-equation/halflist
text: 半反応式の一覧で、燃料電池の負極・正極の式（酸型・アルカリ型）を確かめる
:::

2本の式の e⁻ の係数をそろえて足すと、全体の反応式になります。負極の式を2倍すると e⁻ が 4e⁻ でそろい、足すと e⁻ が消えます。

:::reaction
left: 2H₂ ＋ O₂
right: 2H₂O
level: ★★★
note: 全体の反応。H₂ の燃焼と同じ式で、水の電気分解のちょうど逆向きです。
:::

⚠ 足し合わせると e⁻ は式から消えますが、**この式1本ぶんの反応で 4e⁻ が負極から正極へ受け渡されています**。量を計算するときは、この「4e⁻」が主役になります。

:::section
anchor: alkaline
title: アルカリ型燃料電池の反応式
lead: 電解液が KOH 水溶液のときは、リン酸型の式の H⁺ を、同じ数の OH⁻ で中和して書き換えます。
terms:
- アルカリ型燃料電池
:::

電解液に水酸化カリウム KOH 水溶液を使う燃料電池を**アルカリ型燃料電池**といい、構成は（−）H₂｜KOHaq｜O₂（＋）です。

塩基性の水溶液の中では、H⁺ は OH⁻ とすぐに結びついて H₂O になります。水のイオン積 [H⁺][OH⁻] ＝ 1.0×10⁻¹⁴（mol/L）² がほぼ0なので、**H⁺ と OH⁻ はどちらか一方しか存在できないためです**。「**そこに存在しない物質は、反応式の左辺には書けない**」ので、アルカリ型では H⁺ を使わない形に書き換えます。

書き換えの手順は次のとおりです。

:::list
ordered: true
items:
- リン酸型の式（H⁺ を使う式）を書く。
- 式の中の H⁺ と同じ数の OH⁻ を、両辺に加える。
　H⁺ が右辺に 2H⁺ あれば、両辺に ＋2OH⁻。左辺に 4H⁺ あれば、両辺に ＋4OH⁻。
- H⁺ と OH⁻ が同じ辺にそろった所を H₂O にまとめる（中和）。
- 両辺に同じ数の H₂O があれば消す。
:::

具体例で、負極の式を書き換えます。右辺に 2H⁺ があるので、両辺に 2OH⁻ を加えます。右辺の 2H⁺ ＋ 2OH⁻ は 2H₂O になります。

:::reaction
left: H₂ ＋ 2OH⁻
right: 2H₂O ＋ 2e⁻
level: ★★★
note: 負極（アルカリ型）。H₂ → 2H⁺ ＋ 2e⁻ の両辺に 2OH⁻ を足したもの。
:::

正極は、左辺に 4H⁺ があるので両辺に 4OH⁻ を加えます。左辺は 4H₂O になり、右辺の 2H₂O と打ち消し合って、左辺に 2H₂O が残ります。

:::reaction
left: O₂ ＋ 2H₂O ＋ 4e⁻
right: 4OH⁻
level: ★★★
note: 正極（アルカリ型）。O₂ ＋ 4H⁺ ＋ 4e⁻ → 2H₂O の両辺に 4OH⁻ を足し、両辺の 2H₂O を消したもの。
:::

:::link
app: ion-equation/condition
id: b1
text: H⁺ を含む半反応式に OH⁻ を足して、塩基性の式に書き換える
:::

アルカリ型でも、負極の式を2倍して足すと、全体は 2H₂ ＋ O₂ → 2H₂O になります。電解液が違っても、全体の反応はリン酸型と同じです。

:::mistake
wrong: アルカリ型燃料電池の正極の反応式は O₂ ＋ 4H⁺ ＋ 4e⁻ → 2H₂O である
right: 電解液が KOH 水溶液なので H⁺ はほとんど存在しません。正極は **O₂ ＋ 2H₂O ＋ 4e⁻ → 4OH⁻** です。
why: リン酸型の式を覚えたまま、電解液を見ずに書いてしまうためです。★ 式を書く前に「電解液は酸性か塩基性か」を1回確かめる癖をつけると防げます。
:::

:::section
anchor: range
title: 覚える範囲
lead: 燃料電池の構成と、リン酸型の両極の式を覚えます。アルカリ型は覚えるのではなく、リン酸型から書き換えて出します。
:::

**リン酸型燃料電池の構成と、負極 H₂ → 2H⁺ ＋ 2e⁻・正極 O₂ ＋ 4H⁺ ＋ 4e⁻ → 2H₂O の2本は必ず暗記してください。**

アルカリ型の2本は丸暗記してもよいですが、**リン酸型の式に OH⁻ を足して中和する操作で書けるようにしましょう**。覚える式が2本で済み、ほかの電解液の問題にもそのまま使えます。

:::

:::exercise
source: slides:電池の基本３「鉛蓄電池」s4「復習」（リン酸型燃料電池で H₂O が 10mol 生成したときの電子の物質量。解答も同じ枚）
prompt: リン酸型燃料電池（−）H₂｜H₃PO₄aq｜O₂（＋）を放電して、H₂O が 10mol 生成した。流れた電子の物質量〔mol〕を有効数字2桁で求めよ。
answer: 2.0×10 mol（20mol）　負極の式を2倍して正極と足すと 2H₂ ＋ O₂ → 2H₂O で、このとき 4e⁻ が受け渡されています。係数の比 ＝ mol の比なので、H₂O 2mol : e⁻ 4mol ＝ H₂O 10mol : e⁻ x mol より、x ＝ 20 です。
:::
