lead: ハロゲンの原子は価電子を7個もち、あと1個 e⁻ が入れば貴ガスと同じ電子配置になります。だから1価の陰イオンになりやすいのです。電気陰性度は F が全元素で最大、Cl は3番目です。
terms:
- ハロゲン
- 電気陰性度
:::

ハロゲンは価電子が7個なので、e⁻ を1個受け取って貴ガスと同じ電子配置の**1価の陰イオン**（F⁻・Cl⁻・Br⁻・I⁻）になりやすい元素です。陰性が強く、同じ周期の中で電子親和力・電気陰性度が最大で、イオン化エネルギーは貴ガスに次いで大きくなります。

電気陰性度は、**F ＞ O ＞ Cl ＞ N ＞ …C・S などの非金属… ＞ H ＞ ふつうの金属 ＞ アルカリ土類金属・アルカリ金属** の順です。すべての元素の中で F が最も大きく、Cl は3番目です。この並びは酸化数を決めるときにも使うので、上位の4つ（F・O・Cl・N）は覚えておきましょう。

**単体の状態と色はよく登場するので、4つとも必ず暗記してください。**「気・気・液・固」「淡黄・黄緑・赤褐・黒紫」と上から唱えれば覚えられます。

酸化力が原子半径の小さい順になるのは、クーロン力が距離の2乗に反比例するためです。ハロゲンどうしでは有効核電荷が等しいので、距離の影響だけを考えればよく、原子核に近いところへ e⁻ を引き込める小さい原子ほど e⁻ を強く受け取ります。

## 酸化力を比べる —— 強い方が勝つ

臭化カリウム KBr 水溶液に塩素 Cl₂ を通じると、臭素 Br₂ が遊離します。Cl₂ は右向き（Cl₂ → Cl⁻）、Br₂ は左向き（Br⁻ → Br₂）に反応を進めようとしますが、酸化力は Cl₂ ＞ Br₂ なので Cl₂ が勝ち、反応は右向きに進みます。

:::reaction
left: Cl₂ ＋ 2KBr
right: 2KCl ＋ Br₂
level: ★★★
note: Cl₂ ＋ 2e⁻ → 2Cl⁻ と 2Br⁻ → Br₂ ＋ 2e⁻ を足し、両辺に K⁺ を戻したものです。
:::

逆に、塩化カリウム KCl 水溶液に Br₂ を通じても反応は起こりません。酸化力の弱い Br₂ は、Cl⁻ から e⁻ を奪えないためです。

:::table
caption: ハロゲン化カリウム水溶液とハロゲンの単体が反応するか（○ が反応する組み合わせ）
source: slides:無機の基本５「ハロゲン」s10「ハロゲンの単体の酸化力の比較②」の ○× 表（そのまま）
head:
- 水溶液 ＼ 加える単体
- Cl₂ を加える
- Br₂ を加える
- I₂ を加える
align: left | center | center | center
rows:
- KCl 水溶液 | − | × | ×
- KBr 水溶液 | ○ | − | ×
- KI 水溶液 | ○ | ○ | −
:::

表を覚える必要はありません。**加えた単体の方が、水溶液のイオンのもとの単体より酸化力が強ければ反応する**、だけで全部の欄が埋まります。

:::reaction
left: Cl₂ ＋ 2KI
right: 2KCl ＋ I₂
level: ★★★
note: この反応は、Cl₂ がヨウ化カリウムデンプン紙を青変させる反応（Cl₂ の検出）と同じものです。
:::

:::

## フッ素の反応

:::reaction
left: F₂ ＋ 2e⁻
right: 2F⁻
level: ★★★
note: F は17族なので安定な F⁻ になります。極めて強い2価の酸化剤です。
:::

:::reaction
left: 2F₂ ＋ 2H₂O
right: 4HF ＋ O₂↑
level: ★★★
note: F₂ が酸化剤、H₂O が還元剤。2F₂ ＋ 4e⁻ → 4F⁻ と 2H₂O → 4H⁺ ＋ O₂ ＋ 4e⁻ を足したものです。
:::

F₂ が H₂O の O 原子から e⁻ を奪えるのは、電気陰性度が F ＞ O だからです。強力な酸化剤の KMnO₄ でさえ H₂O を酸化せずに水溶液として存在できることと比べると、F₂ の酸化力の強さがわかります。F₂ は貴ガスのキセノン Xe とも反応します。

:::callout
tone: caution
text: F₂ は最強の酸化剤ですが、HF は酸化剤ではありません。HF の H⁺ が酸化剤としてはたらくのは、イオン化傾向が大きい金属の単体が相手のときだけです（ほかの酸と同じ）。
:::

## フッ化水素の製法 —— 揮発性の酸の遊離

ホタル石（主成分 CaF₂）に濃硫酸を加えて加熱すると、HF が発生します。揮発性の酸である HF が、不揮発性の酸である H₂SO₄ によって追い出される反応です。

:::reaction
left: CaF₂ ＋ H₂SO₄
over: 加熱
right: CaSO₄ ＋ 2HF↑
level: ★★★
note: 「揮発性の酸と塩基の塩 ＋ 不揮発性の酸 → 不揮発性の酸と塩基の塩 ＋ 揮発性の酸」の型。弱酸 HF が強酸 H₂SO₄ に追い出される（弱酸の遊離）と読んでもかまいません。
:::

「**濃硫酸が登場する反応は加熱が必要**」と覚えておきましょう。塩化ナトリウムに濃硫酸を加えて HCl をつくる反応も同じ型です。

## フッ化水素とガラス

フッ化水素酸（HF の水溶液）はガラスの主成分 SiO₂ を溶かします。そのため、フッ化水素酸はガラスびんではなくポリエチレンの容器に保存します。

:::reaction
left: 6HF ＋ SiO₂
right: H₂SiF₆ ＋ 2H₂O
level: ★★★
note: 生じる H₂SiF₆ は**ヘキサフルオロケイ酸**。SiO₂ に対応するオキソ酸（ケイ酸 H₂SiO₃）の O 原子3個を、F 原子6個で置き換えた形です。
:::

:::reaction
left: SiO₂ ＋ 4HF
right: SiF₄ ＋ 2H₂O
level: ★☆☆
note: 気体の HF とガラスの反応。SiO₂ の O²⁻ 2個が F⁻ 4個と置き換わります。
:::

ヘキサフルオロケイ酸の化学式は、「O 原子1個の −2 を F 原子2個の −1 で置き換える」と考えると、イオンの電荷から組み立てられます。同じ考えで、アルミニウムの溶融塩電解に使う**氷晶石 Na₃AlF₆** も 3Na⁺ ＋ Al³⁺ ＋ 6F⁻ と電荷を合わせて覚えられます。

## 臭素

臭素 Br₂ は**赤褐色の液体**です。常温で単体が液体の元素は、臭素 Br と水銀 Hg の2つだけです。無極性分子なので水には溶けにくく、ヘキサンなどの無極性溶媒によく溶けます。

:::reaction
left: Br₂ ＋ H₂O
arrow: ⇄
right: HBr ＋ HBrO
level: ★☆☆
note: 水に溶けるときは Cl₂ と同じ型です。
:::

臭化銀 AgBr は感光性が強く、かつては銀塩写真（フィルム）に使われていました。光によって 2AgBr → 2Ag ＋ Br₂ の反応が起こり、生じた Ag で像ができます。

## ヨウ素

ヨウ素 I₂ は**黒紫色の固体**で、分子結晶なので昇華しやすい物質です。昇華性の分子結晶は、ドライアイス・ヨウ素・ナフタレンの3つを覚えておきましょう。

I₂ は無極性分子で水にはほとんど溶けませんが、ヨウ化カリウム KI 水溶液にはよく溶け、褐色の溶液になります。この褐色は三ヨウ化物イオン I₃⁻ の色で、ヨウ素ヨウ化カリウム溶液はうがい薬に使われています。

:::reaction
left: I₂ ＋ I⁻
right: I₃⁻
level: ★☆☆
note: ヨウ素がヨウ化カリウム水溶液に溶けるときの反応。
:::

I₂ はデンプンと反応して青〜青紫色になります（**ヨウ素デンプン反応**）。デンプンのらせん構造の中に I₃⁻ が入ると色が出ます。

:::

## ヨウ素の酸化還元 —— ヨウ素滴定

I₂ は弱い酸化剤、ヨウ化物イオン I⁻ は弱い還元剤としてはたらきます。どちらの向きの式も書けるようにしましょう。

:::reaction
left: I₂ ＋ 2e⁻
right: 2I⁻
level: ★★★
note: I₂ が酸化剤としてはたらくとき。
:::

:::reaction
left: 2I⁻
right: I₂ ＋ 2e⁻
level: ★★★
note: I⁻ が還元剤としてはたらくとき。O₃ や Cl₂ がヨウ化カリウムデンプン紙を青変させるのは、この反応で I₂ ができるためです。
:::

酸化剤にヨウ素 I₂、還元剤にチオ硫酸ナトリウム Na₂S₂O₃ を使う酸化還元滴定を**ヨウ素滴定**といいます。指示薬にデンプンを加え、I₂ がなくなってヨウ素デンプン反応の青紫色が消えたところを終点にします。

:::reaction
left: I₂ ＋ 2Na₂S₂O₃
right: 2NaI ＋ Na₂S₄O₆
level: ★☆☆
note: 2S₂O₃²⁻ → S₄O₆²⁻ ＋ 2e⁻ と I₂ ＋ 2e⁻ → 2I⁻ を足し、両辺に 4Na⁺ を戻したもの。**Na₂S₂O₃ の半反応式は問題で与えられるので暗記は要りません。**与えられた式から組み立てられれば十分です。
:::

## 例題 —— 臭素とヨウ素

:::exercise
source: slides:無機の基本５「ハロゲン」s46「練習７」（解答は s47）
prompt: 次の反応式を書け。**(1) ヨウ化カリウム水溶液にヨウ素が溶解した（イオンを含む反応式で）　(2) ヨウ素が酸化剤としてはたらいた（e⁻ とイオンを含む反応式で）　(3) ヨウ化物イオンが還元剤としてはたらいた（e⁻ とイオンを含む反応式で）**
answer: (1) I₂ ＋ I⁻ → I₃⁻　(2) I₂ ＋ 2e⁻ → 2I⁻　(3) 2I⁻ → I₂ ＋ 2e⁻　(2) と (3) は同じ式の向きを変えただけで、まとめると I₂ ＋ 2e⁻ ⇄ 2I⁻ です。
:::
