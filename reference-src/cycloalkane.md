シクロアルカンは、**環状構造を1個もち、結合はすべて単結合**という炭化水素です。名前は、同じ炭素数のアルカンの頭に **cyclo-（シクロ－）** をつけてつくります。

:::section
anchor: what
title: 一般式はアルケンとまったく同じ
lead: 環を1個つくると水素が2個減るので、アルカンより H が2個少なくなります。アルケンと分子式が同じになるのが肝心なところです。
terms:
- シクロアルカン
- 環式炭化水素
- 飽和炭化水素
:::

鎖の両端の水素を1個ずつとりさって、あいた手どうしをつなぐと環になります。**水素が2個減る**ので、アルカンの C~n~H~2n+2~ を基準にして、シクロアルカンの一般式は **C~n~H~2n~** です。

:::figure
src: hydrocarbon-ring.png
alt: プロパンの構造式の両端の H に緑の丸をつけ、矢印でシクロプロパンの三角形の構造式に変わるようすを描いた図
caption: プロパン C₃H₈ の**両端の H を1個ずつとりさって手をつなぐ**と、シクロプロパン C₃H₆ になります。
:::

n=3 を代入すればシクロプロパン C₃H₆、n=6 を代入すればシクロヘキサン C₆H₁₂ です。

:::table
caption: 主なシクロアルカン

head:
- 化合物
- 分子式

rows:
- シクロプロパン | C₃H₆
- シクロブタン | C₄H₈
- シクロペンタン | C₅H₁₀
- シクロヘキサン | C₆H₁₂

**この C~n~H~2n~ は、アルケンの一般式とまったく同じです。**つまり **C₅H₁₀ と言われただけでは、ペンテン（アルケン）なのかシクロペンタンなのか決められません。**異性体を書き出す問題で「鎖式に限る」と書いていなければ、**環式も書かなければならない**、ということです。

:::callout
tone: memorize
text: **「シクロアルカン C~n~H~2n~ は、アルケン C~n~H~2n~ の構造異性体」**——この1行は覚えてしまってください。異性体の数え上げで書き落とす原因の第1位がここです。
:::

書き落としを防ぐには、**環の大きさで場合分けして書き出す**のがいちばん確実です（C₅H₁₀ なら 5員環 → 4員環 → 3員環）。

:::section
anchor: props
title: 性質はアルカンとほとんど同じ
lead: 同じ飽和炭化水素なので、起こす反応も置換反応です。環があるかどうかで性質はほとんど変わりません。
terms:
- 置換反応
:::

シクロアルカンもアルカンと同じ**飽和炭化水素**なので、**化学的性質はアルカンとほぼ同じ**です。起こす反応も**置換反応**です。

**環状構造は、不飽和結合と違って付加反応を起こしません。**そのため、**炭化水素の性質は環があるかどうかではほとんど変わりません。**

:::section
anchor: strain
title: 三員環と四員環だけは不安定
lead: 炭素本来の結合角は109.5°。三員環は60°、四員環は90°でつながるので、大きくゆがんでいて反応しやすくなります。
terms:
- 三員環
- 四員環
- 結合角のひずみ
- 開環
:::

シクロアルカンも、アルカンと同じく**正四面体構造の炭素**でできています。正四面体の結合角は **109.5°** で、これが炭素本来の角度です。

ところが、**三員環（原子3個の輪）をつくるには正三角形の内角の 60°**、**四員環（原子4個の輪）をつくるには正方形の内角の 90°** で結合しなければなりません。**本来の 109.5° から大きくゆがむので、不安定で反応しやすくなります。**これを**結合角のひずみ**といいます。

:::figure
src: cycloalkane-strain.png
alt: 左にシクロプロパンの構造式で結合角60度、右にシクロブタンの構造式で結合角90度を書き込んだ図
caption: 炭素本来の **109.5°** に対して、三員環は **60°**、四員環は **90°**。この差がひずみです。
:::

具体的には、**シクロプロパンやシクロブタンは水素 H₂ や臭素 Br₂ などと反応して開環し、鎖式化合物になります。**

:::reaction
left: C₃H₆（シクロプロパン） ＋ Br₂
right: BrCH₂CH₂CH₂Br
gen: シクロプロパン ＋ 臭素 → 1,3-ジブロモプロパン
app: ring_opening_addition
level: ★★☆
note: 環が開いて、両端に Br が1個ずつ付いた鎖式化合物になります。**環が大きければこの反応は起こりません。**
:::

**「三員環・四員環はひずみが大きく、不安定で開環しやすい」**——シクロアルカンについて覚えておくのは、ここだけと言ってよいくらいです。

:::section
anchor: stereo
title: 環にもシス－トランス異性体がある
advanced: true
lead: 環は回転できないので、置換基が環の上側にあるか下側にあるかで別の分子になります。二重結合のシス－トランス異性体と同じ考え方です。
terms:
- シス－トランス異性体
- 不斉炭素原子
- メソ化合物
:::

環状構造も、**二重結合と同じように回転できません。**そのため、**置換基が環の同じ側にあればシス型、逆側にあればトランス型**になります。炭素間二重結合について考えるときと、まったく同じ考え方です。

環をつくっている炭素が**不斉炭素原子かどうか**の判定は、**その炭素の4つの手それぞれに何が結合しているかを、環の原子を順にたどって調べます。**

エチルシクロプロパンの枝の付け根の炭素は、**左右の手に同じ原子団が結合している**ので不斉炭素原子ではありません。1,2-ジメチルシクロプロパンの枝の付け根の炭素は、**4つの手すべてに違う原子・原子団が結合している**ので不斉炭素原子です。

不斉炭素原子が n 個あれば、立体異性体は 2 の n 乗だけ考えられます。ところが、**複数の不斉炭素原子をもち、しかも分子に対称性がある化合物**では、**同じものが重なって数が減ります。**このような化合物を**メソ化合物（メソ体）**といいます。

1,2-ジメチルシクロプロパンは不斉炭素原子を2個もつので 2 の2乗で4種類の立体構造が考えられますが、**そのうち2つは上下にひっくり返すと重なるので、立体異性体は3種類**です。「上下にひっくり返す」は、**机の上に置いた本を上下逆さまにする**イメージです。

**高校化学では、環の上側・下側のどちらに置換基があるかで考えれば十分です。**鏡像異性体を R と S で区別する **RS 表示（RS 表記法）**という書き方もありますが、**空間図形が得意でなければ、無理に使う必要はありません。**
