硫酸銅(Ⅱ) 水溶液にアンモニア水を過剰に加えると、深青色の水溶液になります。これは、Cu²⁺ に NH₃ 分子が4個結びついて、**[Cu(NH₃)₄]²⁺** というイオンができたためです。このように、金属イオンに分子や陰イオンが**配位結合**してできたイオンを**錯イオン**といいます。

:::section

title: 錯イオンのつくり —— 中心の金属イオンと配位子
lead: 非共有電子対をもつ分子や陰イオン（配位子）が、中心の金属イオンに配位結合します。結びついた配位子の数を配位数といいます。
terms:
- 錯イオン
- 配位結合
- 配位子
- 配位数
- 錯塩
:::

NH₃ の N 原子には**非共有電子対**が1組あります。この電子対を Cu²⁺ に一方的に提供して結合するのが**配位結合**です。配位結合する分子や陰イオンを**配位子**、1つの金属イオンに結合した配位子の数を**配位数**といいます。[Cu(NH₃)₄]²⁺ なら、配位子は NH₃、配位数は4です。

錯イオンの化学式は、**全体を [ ] で囲み、右上に錯イオン全体の電荷**を書きます。電荷は「中心の金属イオンの電荷 ＋ 配位子の電荷の合計」です。NH₃ や H₂O は電荷をもたないので [Cu(NH₃)₄]²⁺ は ＋2 のまま、OH⁻ は −1 なので Al³⁺ に4個つくと [Al(OH)₄]⁻（3 − 4 ＝ −1）になります。

錯イオンを含む塩を**錯塩**といいます。ヘキサシアニド鉄(Ⅲ)酸カリウム K₃[Fe(CN)₆] は錯塩の例です。

名前は、次の手順で**前から順に**組み立てます。

:::list
ordered: true
items:
- 配位数を数詞で言い、続けて配位子名を言う。
　NH₃ が4個なら「テトラアンミン○○」、CN⁻ が6個なら「ヘキサシアニド○○」
- 中心の金属の名前を続け、酸化数をローマ数字で（ ）に入れる。
　Cu²⁺ なら「○○銅(Ⅱ)」、Ag⁺ なら「○○銀(Ⅰ)」
- 錯イオン全体が陽イオンなら「イオン」、陰イオンなら「酸イオン」を付ける。
　陽イオンなら「○○銅(Ⅱ)イオン」、陰イオンなら「○○鉄(Ⅲ)酸イオン」
:::

## 具体例

[Cu(NH₃)₄]²⁺ は、NH₃（アンミン）が4個（テトラ）、中心は Cu²⁺（銅(Ⅱ)）、全体が陽イオンなので、**テトラアンミン銅(Ⅱ)イオン**です。

[Fe(CN)₆]³⁻ は、CN⁻（シアニド）が6個（ヘキサ）、中心は Fe³⁺（鉄(Ⅲ)）、全体が陰イオン（3 − 6 ＝ −3）なので、**ヘキサシアニド鉄(Ⅲ)酸イオン**です。

酸化数は中心の金属のものを書きます。[Fe(CN)₆]³⁻ の「3−」を見て「鉄(Ⅲ)」としたのではありません。中心の Fe の酸化数を x とすると、x ＋ (−1)×6 ＝ −3 より x ＝ ＋3 です。[Fe(CN)₆]⁴⁻ なら x ＝ ＋2 で、ヘキサシアニド鉄(Ⅱ)酸イオンになります。

**名前から化学式、化学式から名前の両方向に書けるようにしてください。**手順の3段と、配位子名5つ・数詞4つ（ジ・テトラ・ヘキサと、あまり使わないトリ）を覚えれば、主な錯イオンはすべて組み立てられます。

配位数は、**中心の金属イオンの電荷の2倍**になっていることが多いので、目安に使えます（Ag⁺ は2、Cu²⁺・Zn²⁺ は4、Fe²⁺ は6）。ただし Fe³⁺ も6なので、あくまで目安です。**表の上の3つ（Ag・Cu・Zn のアンミン錯イオン）は、名前・配位数・形・色をすべて覚えてください。**

:::mistake
wrong: 配位数が4の錯イオンは、どれも正方形である。
right: [Cu(NH₃)₄]²⁺ は**正方形**ですが、[Zn(NH₃)₄]²⁺ は**正四面体形**です。
why: 配位数4の形は、中心の金属の種類で分かれます。「銅は正方形、亜鉛は正四面体」を組にして覚えます。配位数2（直線形）と6（正八面体形）は形が1通りです。
:::

色が付いているのは、遷移元素（Cu・Fe）の錯イオンです。Zn・Al の錯イオンは無色で、Ag の錯イオンも無色です。

:::section

title: 沈殿が錯イオンになって溶ける2つの型
lead: 過剰のアンモニア水で溶けるのは Ag・Cu・Zn、過剰の NaOH 水溶液で溶けるのは両性金属の Al・Zn・Sn・Pb。Zn は両方に入ります。
terms:
- 沈殿の再溶解
:::

金属イオンの水溶液に少量の塩基を加えてできた沈殿が、試薬を**過剰に**加えると溶けることがあります。どちらも、錯イオンができて水に溶けるためです。

- 過剰の NH₃ | Zn(OH)₂（白色） | [Zn(NH₃)₄]²⁺（無色）
- 過剰の NaOH | Al(OH)₃（白色） | [Al(OH)₄]⁻（無色）
- 過剰の NaOH | Zn(OH)₂（白色） | [Zn(OH)₄]²⁻（無色）

**「NH₃ で溶けるのは Ag・Cu・Zn」「NaOH で溶けるのは Al・Zn・Sn・Pb」の2つは必ず暗記してください。**両方に入る Zn と、どちらにも入らない Fe³⁺（赤褐色の沈殿のまま）が、金属イオンを分けるときの目印になります。

代表的な式を2本だけ示します。沈殿が溶ける反応は、**右辺を錯イオンのまま書き、押し出された OH⁻ や Cl⁻ を別に書きます**。

right: [Cu(NH₃)₄]²⁺ ＋ 2OH⁻
level: ★★★
note: 過剰のアンモニア水。深青色になります。
:::

level: ★★★
note: 過剰の NaOH 水溶液。無色になります。
:::

## チオ硫酸ナトリウムで溶ける臭化銀（発展）

臭化銀 AgBr はアンモニア水にはわずかにしか溶けませんが、チオ硫酸ナトリウム Na₂S₂O₃ 水溶液にはよく溶けます。チオ硫酸イオン S₂O₃²⁻ が配位子になって錯イオンをつくるためです。写真の現像で、光が当たらずに残った AgBr を取り除くのに使われてきました。

:::reaction
left: AgBr ＋ 2S₂O₃²⁻
right: [Ag(S₂O₃)₂]³⁻ ＋ Br⁻
level: ★☆☆
note: ビス(チオスルファト)銀(Ⅰ)酸イオン。名前も式も覚えなくて構いません。
:::

## 必ず覚えるもの（★★★）

:::list
items:
- 配位子名（アンミン・アクア・シアニド・ヒドロキシド・クロリド）と数詞（ジ・テトラ・ヘキサ）
- [Ag(NH₃)₂]⁺ 直線形・無色、[Cu(NH₃)₄]²⁺ 正方形・深青色、[Zn(NH₃)₄]²⁺ 正四面体形・無色
- [Fe(CN)₆]⁴⁻・[Fe(CN)₆]³⁻ は正八面体形
- 過剰の NH₃ で溶ける Ag・Cu・Zn、過剰の NaOH で溶ける Al・Zn・Sn・Pb
:::

配位結合の電子の動き（どの軌道に入るか）や、錯イオンの色が出る理由は高校化学の範囲を超えるので、考えなくて構いません。
