2つの炭化水素基が酸素原子をはさんでつながった **R−O−R'** の構造をもつ化合物を**エーテル**といい、まん中の **−O−** を**エーテル結合**といいます。

:::section
anchor: formula
title: 一般式はアルコールと同じ CₙH₂ₙ₊₂O
lead: アルカンの C−C のあいだに O を1個入れた形。だから炭素の数が同じアルコールとは構造異性体です。
terms:
- 一般式
- エーテル結合
- 構造異性体
:::

鎖状で飽和のエーテルの一般式は **C~n~H~2n+2~O** です。n=2 を代入すると C₂H₆O で、これがいちばん小さいエーテルであるジメチルエーテル CH₃OCH₃ の分子式です。

この式は、アルカンの一般式 C~n~H~2n+2~ の **C−C 結合のあいだに O 原子を1個割り込ませた**形をしています。酸素が1個増えるだけなので、C~n~H~2n+2~O になります。

:::figure
src: ether-from-alkane.png
alt: アルカンの構造式から矢印が伸び、C−C 間に O 原子を入れるとエーテルになることを示した図。左がアルカン CnH2n+2、右がエーテル CnH2n+2O
caption: 同じ O を **C−H のあいだ**に入れるとアルコールになります。入れる場所が違うだけで、分子式はどちらも同じです。
:::

だから**炭素の数が同じエーテルとアルコールは、互いに構造異性体**です。ジメチルエーテル C₂H₆O とエタノール C₂H₆O が、いちばん小さい組み合わせになります。

**一般式 C~n~H~2n+2~O は必ず暗記してください。**この式が「アルコールとエーテルのどちらか」を意味することが、構造決定の出発点になります。

:::link
to: alcohol
text: アルコールの側から見た一般式・級・沸点・命名はこちら
:::

:::section
anchor: naming
title: エーテルの命名
lead: 両側の2つのアルキル基の名称をアルファベット順に続けて、語尾に「エーテル」を付けた慣用名を使います。
terms:
- ジエチルエーテル
:::

規則どおりの名称は「（側鎖のアルキル基）オキシ（主鎖のアルカン）」の形で、ジエチルエーテルなら「エトキシエタン」です。ただし高校化学でこの名前を見かけることはまずありません。

**覚えるのは慣用名のほう**です。エーテル結合の両側にあるアルキル基の名称を**アルファベット順**に2つ続け、語尾に「エーテル」を付けます。2つが同じなら「ジ○○エーテル」です。

:::figure
src: ether-naming.png
alt: ジメチルエーテル・エチルメチルエーテル・ジエチルエーテルの構造式に、両側のアルキル基の名前と命名の注意を書き添えた図
caption: まん中の例は、エチル（ethyl）とメチル（methyl）を**アルファベット順**に並べて「エチルメチルエーテル」です。炭素の数の順ではありません。
:::

**ジエチルエーテル C₂H₅OC₂H₅ は、名称も示性式も必ず暗記してください。**エーテルのうち出題されるのはほとんどがこれです。

**エトキシエタン・メトキシメタンといった規則どおりの名称のほうは、覚える必要はありません。**

:::section
anchor: props
title: エーテルの性質
lead: 反応しない・沸点が低い・水に溶けにくい・引火しやすい。どれも「−O−H をもたない」ことから出てきます。
terms:
- 有機溶媒
- 水素結合
:::

エーテルは常温では安定で、高校化学の範囲では**反応を起こしません**。そのため**有機溶媒**として使われます。

エーテルは**沸点が低く**、**水に溶けにくい**という性質をもちます。どちらも、エーテルには −O−H が無いので**分子どうしが水素結合をつくれない**ためです。同じ分子式のアルコールとは、ここが決定的に違います。

**ジエチルエーテルの沸点は 34℃ です。**問題文にこの数字が出てきたらジエチルエーテルだと決まるので、**この数字は必ず暗記してください。**「酢酸の融点 17℃ のちょうど2倍」「体温で沸騰する」と結び付けておくと忘れにくくなります。

エーテルは**発火点が低く、引火しやすい**ので、火の近くで扱えません。蒸発しやすいうえ蒸気が空気より重く、机の上にたまりやすいことも、引火事故が起こりやすい理由です。

ジエチルエーテルには**麻酔作用**があります。

:::section
anchor: distinguish
title: アルコールとの判別
lead: 分子式が同じでも、金属ナトリウムを加えれば1回で分かれます。反応するのがアルコール、しないのがエーテルです。
terms:
- ナトリウムアルコキシド
:::

アルコールは**金属ナトリウム Na と反応して水素 H₂ を発生**し、ナトリウムアルコキシドになります。ヒドロキシ基の水素原子とナトリウム原子が入れ替わる反応だと考えるとよいでしょう。

:::reaction
left: 2C₂H₅OH ＋ 2Na
right: 2C₂H₅ONa ＋ H₂
level: ★★★
note: できるのは**ナトリウムエトキシド** C₂H₅ONa です。水 H₂O やカルボン酸 R−COOH も同じように反応して H₂ を発生します。
:::

**エーテルはこの反応を起こしません。**だから**金属ナトリウムを加えて水素が発生すればアルコール、しなければエーテル**と判別できます。**この判別は必ず暗記してください。**構造決定の問題文では、ほとんどいつもこの一手から始まります。

違いをまとめると次のようになります。

head:
- くらべる点
- アルコール
- エーテル
align: left | left | left
rows:
- 沸点 | 高い | 低い
- 溶けやすさ | 水に溶ける | 水に溶けにくく、有機溶媒に溶ける
- 金属ナトリウム | 反応して H₂ を発生する | 反応しない
- 酸化 | 還元剤としてはたらき、アルデヒド・ケトン・カルボン酸になる | 反応しない
- 脱水 | 分子内脱水でアルケン、分子間脱水でエーテルになる | 反応しない
:::

:::section
anchor: prep
title: エーテルのつくり方 —— アルコールの分子間脱水
lead: 濃硫酸を 130〜140℃ にして、2分子のアルコールから水1分子がとれると、エーテルができます。
terms:
- 分子間脱水
- 分子内脱水
:::

濃硫酸を加えたアルコールを **130〜140℃** に加熱すると、**2つの分子のあいだ**で脱水反応が起こってエーテルが生じます。分子と分子のあいだで脱水するので**分子間脱水**といいます。

:::reaction
left: 2C₂H₅OH
over: 濃硫酸
under: 130〜140℃
right: C₂H₅OC₂H₅ ＋ H₂O
level: ★★★
note: エタノール2分子から水1分子がとれて、**ジエチルエーテル**ができます。
:::

同じエタノールでも、温度を **160〜170℃** まで上げると、こんどは**1つの分子の中**で脱水が起こり、アルケンのエテン（エチレン）が生じます。こちらは**分子内脱水**です。

:::reaction
left: C₂H₅OH
over: 濃硫酸
under: 160〜170℃
right: CH₂=CH₂ ＋ H₂O
level: ★★★
note: 温度が高いほうが分子内脱水、低いほうが分子間脱水です。
:::

**この2つの温度と生成物の組み合わせは必ず暗記してください。**「高い温度でアルケン、低い温度でエーテル」がそのまま問われます。

## エーテルの構造異性体の数え方

エーテルは反応を起こさないので、反応の結果から1つに絞ることができません。そのぶん、**構造異性体を全部書き出して、枝分かれの有無などで選ばせる**出題になります。書き出しは次の手順で行います。

:::list
ordered: true
items:
- 分子式の炭素原子を、エーテル結合の左右 R−O−R' に割り振る。
　炭素が4個なら「0と4」「1と3」「2と2」「3と1」「4と0」の5通り
- 片方が炭素0個（＝水素原子）になる組み合わせを外す。
　それはエーテルではなくアルコールです
- 左右を入れ替えただけの組み合わせを外す。
　エーテルは左右対称なので、「1と3」と「3と1」は同じものです
- 残った組み合わせについて、アルキル基の種類の数だけ構造異性体がある。
　メチル基は1種類、エチル基は1種類、プロピル基は2種類、ブチル基は4種類
:::

炭素4個の C₄H₁₀O で数えてみます。残る割り振りは「1と3」と「2と2」の2通り。「1と3」はメチル基1種類とプロピル基2種類で2個、「2と2」はエチル基どうしで1個。合わせて**3種類**です。

prompt: 分子式が C₄H₁₀O である構造異性体 A〜G がある。金属ナトリウムを加えたところ、A〜D は水素を発生したが、E・F・G は反応しなかった。A〜D を硫酸酸性過マンガン酸カリウムで十分に酸化させたところ、A と C は酸性の物質を、B は中性の物質を生じたが、D は酸化されなかった。A・D・F は炭素鎖に枝分かれをもち、G はエタノールに濃硫酸を加えて加熱すると生じる物質である。**A〜G の構造式を書け。**
