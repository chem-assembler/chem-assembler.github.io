アルカンは、**炭素どうしが単結合だけでつながっている**炭化水素です。二重結合も三重結合も環も無いので、炭素に付ける手はぜんぶ水素で埋まって（＝ **飽和して**）います。

:::section
anchor: structure
title: どんな形をしているか
lead: メタンの正四面体が繰り返しつながった形で、炭素どうしの単結合は自由に回転できます。
terms:

- 飽和炭化水素
- 正四面体
- 結合角
- 単結合の回転
:::

いちばん小さいアルカンであるメタン CH₄ は、炭素を中心にした**正四面体**の形をしています。炭素のまわりにある**4組の電子対が、負の電荷でたがいに反発して、いちばん遠い位置に散る**ためで、結合角は **約109.5°** になります。

:::link
to: molecular-shape
text: 電子対の反発で分子の形が決まるしくみ（VSEPR）をもう少し詳しく
:::

//ここにメタンの正四面体構造・電子式

アルカンは、この正四面体が繰り返しつながった形です。**炭素間の単結合は自由に回転できる**ので、同じ分子でも変形することができ見え方は一定ではありません。

:::section anchor: formula title: アルカンの一般式は CnH2n+2 

lead: 丸暗記もよいが、図形的に導けるようにしよう。 

terms:

- 一般式
- メチレン基
- 同族体
:::

枝分かれの無い直鎖のアルカンは、いくつかの**メチレン基 −CH₂− と、両端の水素2個**でできています。C原子の数を n 個とすると、水素原子はメチレン基の部分に 2n 個、両端の2個あるので合計 2n+2 個になります。

//直鎖のアルカンがメチレン基と両端の水素原子で構成されている図

どんな構造のアルカンも「**鎖を伸ばす」、「枝分かれをつくる」、の2つの操作だけでつくることができますが、いずれの場合もメチレン基 −CH₂− を足している**ので、アルカンの分子式（一般式）は必ず **C~n~H~2n+2~**になります。

//全図にメチレン基を挿入して枝分かれ、直鎖の伸長を行った図

この一般式の n に n=1 を代入すれば炭素数1のアルカンであるメタンの分子式 CH₄ が、n=3 を代入すれば炭素数3のアルカンであるプロパンの分子式 C₃H₈ が得られます。

アルカンの常温での状態

アルカンは**無極性分子**なので、分子どうしを引きつけているのは弱いファンデルワールス力だけです。ファンデルワールス力は**分子量が大きくなるほど引きつけ合う力は強くなる**ので、蒸発しにくくなり、沸点が高くなります。だから **C₁〜C₄ は気体、C₅〜C₁₇ は液体、C₁₈ 以上は固体**です。液体と固体の境界についてはほとんど問われることはありませんが、ブタン C₄H₁₀ やペンタン C₅H₁₂ はよく登場するので気体と液体の境界はしっかりと覚えるようにしましょう。

:::link
to: intermolecular-force
text: 分子間力そのものと、沸点との関係をまとめて見る
:::

//ここは発展的・見出しつけたい

同じ分子式のアルカン同士で比較すると、**枝分かれが多いほど沸点は低く**なります。枝分かれすると分子の形が球に近づき、**分子どうしが触れ合う面積が減って**引きつけ合う力が弱くなるためです。

:::link

:::

//ここはアルカンの性質・配置を考える

無極性であることは、水への溶けかたにもそのまま出ます。**アルカンは水に溶けにくく、水より密度が小さい**ので、水と混ぜると上に分かれます。

:::section
anchor: alkyl
title: アルキル基 —— アルカンから水素を1つ取ったもの
lead: 枝の名前はここから来ます。語尾の -ane を -yl に変えるだけです。
terms:

- アルキル基
- メチル基
- エチル基
:::

アルカン C~n~H~2n+2~ から水素原子を1個取り去った原子団を**アルキル基 −C~n~H~2n+1~** といいます。分子ではなく、分子の一部（パーツ）です。名前は、もとのアルカンの語尾 **-ane を -yl（イル）に変える**だけです。

:::list
items:

- メタン CH₄ → **メチル基** −CH₃
- エタン C₂H₆ → **エチル基** −C₂H₅
- プロパン C₃H₈ → **プロピル基** −C₃H₇（2種類）
- ブタン C₄H₁₀ → **ブチル基** −C₄H₉（4種類）
- ペンタン C₅H₁₂ → **ペンチル基** −C₅H₁₁（8種類）
:::

炭素が3個以上になると、**どの水素を取ったか**で違う基になります。プロピル基が2種類あるのはそのためで、枝分かれしたアルカンの名前が何通りにもなる理由もここにあります。

:::link
open: practice
text: 書き出し練習をひらく（分子式から異性体を全部たどる）
:::

:::section
anchor: substitution
title: アルカンの反応 —— 置換反応
lead: アルカンが常温付近で起こす反応はこれ1つです。光を当てて、ハロゲンと水素を入れ替えます。
terms:

- 置換反応
- 置換基
- 置換体
- ハロゲン化
:::

アルカンは常温では反応性が低いのですが、**ハロゲンの単体と混ぜて光を当てる**と反応します。メタンと塩素なら、メタンの水素1個と塩素分子の塩素1個が**入れ替わって**、クロロメタンと塩化水素ができます。

:::figure
src: alkane-substitution.png
alt: メタンの水素1個と塩素分子の塩素原子が入れ替わり、クロロメタンと塩化水素ができることを構造式と矢印で示した図
caption: 入れ替わっているのは、メタンの H 1個と、塩素分子の Cl 1個。
:::

:::reaction left: CH₄ ＋ Cl₂ over: 光 right: CH₃Cl ＋ HCl level: ★★★ note: 原子が入れ替わるので置換反応といいます。**アルカンの反応は置換反応**、と覚えてしまってかまいません。
:::

このように、分子の中の原子（原子団）が他の原子（原子団）と**置き換わる**反応を**置換反応**、入ってきた原子（原子団）を**置換基**、できた物質をもとの分子の**置換体**といいます。

//ここは発展

電子対がどう動いてこの入れ替わりが起きるのかは、別ページの「反応の道すじ（反応機構）」で巻矢印のアニメとして1段ずつ追えます。

条件を整えると、置換は1回では止まりません。メタン CH₄ には**水素が4個あるので、4回まで続けて起こります。**

:::figure
src: alkane-chlorination-chain.png
alt: メタンが光と塩素で順にクロロメタン、ジクロロメタン、トリクロロメタン、テトラクロロメタンへ変わっていく連続置換の図
caption: 塩素が1個入るたびに Cl₂ が1分子ずつ使われます。
:::

:::list
ordered: true
items:

- CH₃Cl **クロロメタン**（塩素1個）
- CH₂Cl₂ **ジクロロメタン**（2個）
- CHCl₃ **トリクロロメタン**（3個。クロロホルムのこと）
- CCl₄ **テトラクロロメタン**（4個）
:::

置換体の名前は、**入った塩素の数を表す接頭辞（ジ・トリ・テトラ）＋ クロロ ＋ もとのアルカンの名前**です。係数は、**塩素を1個入れるのに Cl₂ が1分子要る**ことから決まります。

:::reaction
left: CH₄ ＋ 3Cl₂
over: 光
right: CHCl₃ ＋ 3HCl
level: ★★★
note: 塩素を3個入れたいので Cl₂ が3分子、外れた水素3個は HCl になって出ていきます。
:::

もう1つ、アルカンが起こす反応が**燃焼**です。高温ではアルカンは還元剤としてはたらき、多量の熱を出して燃えます。**燃料に使われるのはこのため**です。完全燃焼すれば、生成物は二酸化炭素と水だけになります。

:::reaction
left: CH₄ ＋ 2O₂
over: 完全燃焼
right: CO₂ ＋ 2H₂O
level: ★★★
note: 炭素は CO₂ へ、水素は H₂O へ。他のアルカンでも、係数を合わせるだけで同じ形の式になります。
:::

:::section anchor: methane title: メタン CH₄ lead: いちばん小さいアルカン。無色無臭の気体で水に溶けにくく、実験室では酢酸ナトリウムと水酸化ナトリウムを加熱してつくります。 terms:

- メタン
- 実験室的製法
- 水上置換
- 無極性分子
:::

メタンは無色無臭の気体で、天然ガスの主成分です。C−H 結合には極性がありますが、**正四面体なので分子全体では打ち消し合い**、分子としては無極性になります。無極性だから水に溶けにくく**水上置換**で捕集します。

:::figure
src: methane-electron-dot.png
alt: メタンの電子式と、結合の極性δ+δ−を書き込んだ構造式。結合の極性が分子全体で打ち消されて無極性になることを示している
caption: 結合1本ずつには極性がありますが、正四面体なので分子全体では打ち消されます。
:::

実験室では、**酢酸ナトリウムと水酸化ナトリウムの混合物を加熱して**つくります。どちらも固体なので、加熱が要ります。

:::reaction
left: CH₃COONa ＋ NaOH
over: 加熱
right: CH₄↑ ＋ Na₂CO₃
level: ★★☆
note: 固体どうしの反応なので加熱します。出てきたメタンは水上置換で集めます。
:::

:::callout tone: memorize text: この反応式は**丸暗記**でかまいません。係数はすべて 1 なので、反応物を暗記すればメタン CH₄ ができたあまりが炭酸ナトリウム Na₂CO₃ です。 :::
