アルカンは、炭素と水素だけでできていて、**炭素どうしが単結合だけでつながっている**分子です。二重結合も三重結合も環も無いので、炭素に付ける手はぜんぶ水素で埋まります ＝ **飽和**しています。ここから先の性質は、ほとんどすべて「単結合だけ」「電荷のかたよりが無い」の2つから出てきます。

:::section
anchor: structure
title: どんな形をしているか
lead: メタンの正四面体が繰り返しつながった形で、炭素どうしの単結合は自由に回転できます。
terms:
  - 飽和炭化水素
  - 正四面体
  - 結合角
  - 単結合の回転
:::

いちばん小さいアルカンであるメタン CH₄ は、炭素を中心にした**正四面体**の形をしています。平面の十字ではありません。炭素のまわりにある**4組の電子対が、負の電荷でたがいに反発して、いちばん遠い位置に散る**ためで、結合角は **約109.5°** になります。

アルカンは、この正四面体が繰り返しつながった形です。そして**炭素間の単結合は自由に回転できる**ので、同じ分子でも見え方はいくらでも変わります。紙の上で折れ線に見えるか一直線に見えるかは、**構造の違いではありません**。

:::figure
src: alkane-structure.png
alt: メタンの正四面体構造（結合角109.5度）、炭素のまわりの4組の電子対、エタンの炭素間単結合が回転できることを示した図
caption: 左からメタンの正四面体、電子対が反発して正四面体になること、エタンの単結合が回転できること。
:::

:::callout
tone: caution
text: **「反応しにくい」と「反応しない」は違います。** アルカンは常温では反応性が低いだけで、光を当てればハロゲンと置換反応を起こし、高温では燃焼します。「アルカンは安定だから何も起きない」と覚えると、下の2つの反応が抜けます。
:::

:::section
anchor: formula
title: 一般式 CnH2n+2 はどこから出てくるか
lead: 覚える式ではなく、メチレン基 −CH₂− を1つずつ足していく操作から出てくる式です。
terms:
  - 一般式
  - メチレン基
  - 同族体
:::

枝分かれの無い直鎖のアルカンは、**メチレン基 −CH₂− がいくつかと、両端の水素2個**でできています。メチレン基が n 個なら水素は 2n 個、これに両端の2個を足して 2n+2 個 ＝ **C~n~H~2n+2~** です。

枝分かれのあるアルカンも同じ式になります。**鎖を伸ばすときも、枝分かれをつくるときも、足しているのはメチレン基1つ**だからです。この2つの操作だけで、どんなアルカンの構造も作れます。

:::figure
src: alkane-formula-derivation.png
alt: 直鎖アルカンがメチレン基と両端の水素2個からできていること、鎖を伸ばす操作と枝分かれをつくる操作のどちらもメチレン基を1つ足すだけであることを示した図
caption: 鎖を伸ばしても、枝分かれをつくっても、足しているのはメチレン基 −CH₂− 1つ。だから一般式は変わりません。
:::

こうして炭素の数だけが違い、同じ一般式で表される化合物のならびを**同族体**といいます。名前の付け方（メタン・エタン・プロパン…と、枝分かれのある場合の番号の振り方）は、別ページの「アルカンの命名」にまとめてあります。

terms:

  - 分子間力
  - ファンデルワールス力
  - 無極性分子
:::

アルカンは**無極性分子**なので、分子どうしを引きつけているのは弱いファンデルワールス力だけです。それでも**分子量が大きくなるほど引きつけ合う力は強くなる**ので、蒸発しにくくなり、沸点が上がります。だから **C₁〜C₄ は気体、C₅〜C₁₇ は液体、C₁₈ 以上は固体**です。

同じ分子式でも、**枝分かれが多いほど沸点は低く**なります。枝分かれすると分子の形が球に近づき、**分子どうしが触れ合う面積が減って**引きつけ合う力が弱くなるためです。

無極性であることは、水への溶けかたにもそのまま出ます。**アルカンは水に溶けにくく、水より密度が小さい**ので、水と混ぜると上に分かれます。

:::callout
tone: skip
text: 名称は暗記しますが、**入試で頻繁に出るのはヘキサン（C₆）まで**です。オクタン以降の名前を覚えていなくて困ることは、ほとんどありません。
:::

:::section
anchor: alkyl
title: アルキル基 —— アルカンから水素を1つ取ったもの
lead: 枝の名前はここから来ます。語尾の -ane を -yl に変えるだけです。
terms:
  - アルキル基
  - メチル基
  - エチル基
:::

アルカン C~n~H~2n+2~ から水素原子を1個取り去った原子団を**アルキル基 −C~n~H~2n+1~** といいます。分子ではなく、分子の一部（パーツ）です。名前は、もとのアルカンの語尾 **-ane を -yl（イル）に変える**だけです。

:::list
items:
  - メタン CH₄ → **メチル基** −CH₃
  - エタン C₂H₆ → **エチル基** −C₂H₅
  - プロパン C₃H₈ → **プロピル基** −C₃H₇（2種類）
  - ブタン C₄H₁₀ → **ブチル基** −C₄H₉（4種類）
  - ペンタン C₅H₁₂ → **ペンチル基** −C₅H₁₁（8種類）
:::

炭素が3個以上になると、**どの水素を取ったか**で違う基になります。プロピル基が2種類あるのはそのためで、枝分かれしたアルカンの名前が何通りにもなる理由もここにあります。

:::section
anchor: substitution
title: アルカンの反応 —— 置換反応
lead: アルカンが常温付近で起こす反応はこれ1つです。光を当てて、ハロゲンと水素を入れ替えます。
terms:
  - 置換反応
  - 置換基
  - 置換体
  - ハロゲン化
:::

アルカンは常温では反応性が低いのですが、**ハロゲンの単体と混ぜて光を当てる**と反応します。メタンと塩素なら、メタンの水素1個と塩素分子の塩素1個が**入れ替わって**、クロロメタンと塩化水素ができます。

:::figure
src: alkane-substitution.png
alt: メタンの水素1個と塩素分子の塩素原子が入れ替わり、クロロメタンと塩化水素ができることを構造式と矢印で示した図
caption: 入れ替わっているのは、メタンの H 1個と、塩素分子の Cl 1個。
:::

:::reaction
left: CH₄ ＋ Cl₂
over: 光
right: CH₃Cl ＋ HCl
level: ★★★
note: できるのはクロロメタン CH₃Cl と塩化水素 HCl。**アルカンの反応は置換反応**、と覚えてしまってかまいません。
:::

このように、分子の中の原子（原子団）が他の原子（原子団）と**置き換わる**反応を**置換反応**、入ってきた原子（原子団）を**置換基**、できた物質をもとの分子の**置換体**といいます。

条件を整えると、置換は1回では止まりません。**水素が4個あるので、4回まで続けて起こります。**

:::figure
src: alkane-chlorination-chain.png
alt: メタンが光と塩素で順にクロロメタン、ジクロロメタン、トリクロロメタン、テトラクロロメタンへ変わっていく連続置換の図
caption: 塩素が1個入るたびに Cl₂ が1分子ずつ使われます。
:::

:::list
ordered: true
items:
  - CH₃Cl **クロロメタン**（塩素1個）
  - CH₂Cl₂ **ジクロロメタン**（2個）
  - CHCl₃ **トリクロロメタン**（3個。クロロホルムのこと）
  - CCl₄ **テトラクロロメタン**（4個）
:::

置換体の名前は、**入った塩素の数を表す接頭辞（ジ・トリ・テトラ）＋ クロロ ＋ もとのアルカンの名前**です。係数は、**塩素を1個入れるのに Cl₂ が1分子要る**ことから決まります。

:::reaction
left: CH₄ ＋ 3Cl₂
over: 光
right: CHCl₃ ＋ 3HCl
level: ★★★
note: 塩素を3個入れたいので Cl₂ が3分子、外れた水素3個は HCl になって出ていきます。
:::

もう1つ、アルカンが起こす反応が**燃焼**です。高温ではアルカンは還元剤としてはたらき、多量の熱を出して燃えます。**燃料に使われるのはこのため**です。完全燃焼すれば、生成物は二酸化炭素と水だけになります。

:::reaction
left: CH₄ ＋ 2O₂
over: 完全燃焼
right: CO₂ ＋ 2H₂O
level: ★★★
note: 炭素は CO₂ へ、水素は H₂O へ。他のアルカンでも、係数を合わせるだけで同じ形の式になります。
:::

:::section
anchor: methane
title: メタン CH₄
lead: いちばん小さいアルカン。無色無臭で水に溶けにくく、実験室では酢酸ナトリウムと水酸化ナトリウムを加熱してつくります。
terms:
  - メタン
  - 実験室的製法
  - 水上置換
  - 無極性分子
:::

メタンは無色無臭の気体で、天然ガスの主成分です。C−H 結合には極性がありますが、**正四面体なので分子全体では打ち消し合い**、分子としては無極性になります。無極性だから水に溶けにくく、水に溶けにくいから**水上置換**で集められます。

:::figure
src: methane-electron-dot.png
alt: メタンの電子式と、結合の極性δ+δ−を書き込んだ構造式。結合の極性が分子全体で打ち消されて無極性になることを示している
caption: 結合1本ずつには極性がありますが、正四面体なので分子全体では打ち消されます。
:::

実験室では、**酢酸ナトリウムと水酸化ナトリウムの混合物を加熱して**つくります。どちらも固体なので、加熱が要ります。

:::reaction
left: CH₃COONa ＋ NaOH
over: 加熱
right: CH₄↑ ＋ Na₂CO₃
level: ★★☆
note: 固体どうしの反応なので加熱します。出てきたメタンは水上置換で集めます。
:::

:::callout
tone: memorize
text: この製法の反応式は、**組み立てて出すのではなく丸暗記**でかまいません。左辺の2つと右辺の2つを、そのまま覚えてしまうのがいちばん速いところです。
:::
