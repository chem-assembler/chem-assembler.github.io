周期表の1族のうち、水素を除いた Li・Na・K・Rb・Cs・Fr の6元素を**アルカリ金属**といいます。原子は価電子を1個もち、**1価の陽イオン**になりやすい元素です。

:::

:::section
anchor: element
title: 単体の性質 —— 水と激しく反応する
lead: 単体は軟らかく軽い金属で、常温の水と反応して水素を発生し、水溶液は強塩基性になります。
terms:
- アルカリ金属
- 溶融塩電解
:::

アルカリ金属は**イオン化傾向がとても大きい**ので、自然界には単体では存在せず、化合物として存在します。同じ理由で、水溶液を電気分解しても単体は得られません（先に水が還元されます）。単体は、塩化ナトリウムなどを**融解して電気分解（溶融塩電解）**してつくります。

:::table
caption: アルカリ金属の単体

head:
- 元素
- 炎色反応
- 水との反応
- 密度
align: center | center | left | left
rows:
- **Li** | 赤色 | おだやかに反応 | 水より小さい
- **Na** | 黄色 | 激しく反応 | 水より小さい
- **K** | 赤紫色 | さらに激しく反応 | 水より小さい
:::

原子番号が大きいほど反応性が大きくなります。原子半径が大きくなり、最外殻の電子が原子核から遠くなって、**電子を放出しやすくなるため**です。

単体は空気中の酸素や水とすぐに反応するので、**石油（灯油）の中に保存します**。ナイフで切れるほど軟らかく、切り口はすぐに酸化されて銀白色の光沢を失います。

## 水との反応

ナトリウムを水に入れると、ナトリウムが**還元剤**、水が**酸化剤**としてはたらき、水素が発生します。半反応式を先に書いてから組み立てます。

:::reaction
left: Na
right: Na⁺ ＋ e⁻
level: ★★★
note: 還元剤の半反応式。1族なので e⁻ を1個出します。
:::

:::reaction
left: 2H₂O ＋ 2e⁻
right: H₂ ＋ 2OH⁻
level: ★★★
note: 中性の水が酸化剤になるときの半反応式です。
:::

上の式を2倍して足し、Na⁺ と OH⁻ を組んで NaOH にすると、全体の式になります。

:::reaction
left: 2Na ＋ 2H₂O
right: 2NaOH ＋ H₂
level: ★★★
note: K でも同じ形です（2K ＋ 2H₂O → 2KOH ＋ H₂）。
:::

:::link
to: ionization-tendency
text: 常温の水と反応する金属（Li・K・Ca・Na）はイオン化傾向のページへ
:::

ちなみに、ナトリウムは空気中で酸化されて酸化ナトリウムになります。酸化ナトリウムは塩基性酸化物で、水と反応して水酸化ナトリウムになります。

:::reaction
left: 4Na ＋ O₂
right: 2Na₂O
level: ★★☆
:::

:::reaction
left: Na₂O ＋ H₂O
right: 2NaOH
level: ★★☆
note: 塩基性酸化物と水の反応です。
:::

:::link
to: oxoacid
text: 酸化物の分類（酸性・塩基性・両性）と水との反応は酸化物とオキソ酸のページへ
:::

**「潮解は NaOH、風解は Na₂CO₃・10H₂O」は組にして覚えてください。**どちらも空気中に置いたときの変化ですが、向きが逆です。潮解は水を**吸って**溶けること、風解は水和水を**失って**崩れることです。

:::mistake
wrong: 炭酸水素ナトリウムは名前に「水素」があり酸性塩なので、水溶液は酸性を示す。
right: 炭酸水素ナトリウムの水溶液は**弱塩基性**です。
why: 塩の分類（正塩・酸性塩・塩基性塩）は組成で決めた名前で、水溶液の液性とは直接関係しません。液性は、もとの酸（炭酸＝弱酸）と塩基（NaOH＝強塩基）のどちらが強いかで決まります。
:::

## 水酸化ナトリウム【塩基】

水酸化ナトリウムは白色の固体で、水によく溶けて強塩基性を示します。**強塩基**なので、酸性酸化物の二酸化炭素を吸収します。

:::reaction
left: 2NaOH ＋ CO₂
right: Na₂CO₃ ＋ H₂O
level: ★★★
note: 固体の NaOH を空気中に置くと表面が炭酸ナトリウムに変わるのはこの反応のためです。
:::

工業的には、**塩化ナトリウム水溶液の電気分解（イオン交換膜法）**でつくります。陰極側に NaOH ができます。

:::link
to: electrolysis-industry
text: イオン交換膜法の陽極・陰極の式は電気分解の工業的利用のページへ
:::

## 炭酸塩と炭酸水素塩【弱酸の遊離】【熱分解】

炭酸ナトリウムも炭酸水素ナトリウムも、塩酸などの強酸を加えると、**弱酸の炭酸が追い出されて**二酸化炭素が発生します。

:::reaction
left: Na₂CO₃ ＋ 2HCl
right: 2NaCl ＋ H₂O ＋ CO₂
level: ★★★
note: 弱酸の遊離。H₂CO₃ は不安定なので H₂O と CO₂ にして書きます。
:::

:::reaction
left: NaHCO₃ ＋ HCl
right: NaCl ＋ H₂O ＋ CO₂
level: ★★★
:::

炭酸水素ナトリウムは、**加熱するだけで分解**して二酸化炭素を出します。炭酸ナトリウムは加熱しても分解しません。この違いで2つを区別できます。

:::reaction
left: 2NaHCO₃
over: 加熱
right: Na₂CO₃ ＋ H₂O ＋ CO₂
level: ★★★
note: ベーキングパウダーでケーキがふくらむのはこの CO₂ のためです。
:::

炭酸ナトリウムの水溶液から結晶を取り出すと、十水和物 Na₂CO₃・10H₂O が得られます。空気中に置くと水和水の大部分を失い、白色粉末の一水和物になります（風解）。

:::reaction
left: Na₂CO₃・10H₂O
right: Na₂CO₃・H₂O ＋ 9H₂O
level: ★☆☆
note: 風解。式を書かせる問題はほとんど出ないので、「十水和物 → 一水和物」の名前だけで十分です。
:::

:::section
anchor: solvay
title: アンモニアソーダ法（ソルベー法）
lead: 塩化ナトリウムと石灰石から炭酸ナトリウムをつくる工業的製法で、CO₂ と NH₃ を回収して使い回します。
terms:
- アンモニアソーダ法
- ソルベー法
:::

原料は**塩化ナトリウム NaCl（飽和水溶液）と石灰石 CaCO₃** の2つだけです。途中で使う NH₃ と CO₂ は、工程の中で回収して再び使います。

:::list
ordered: true
items:
- NaCl の飽和水溶液に NH₃ を十分に吸収させ、そこへ CO₂ を通じる。溶解度の比較的小さい NaHCO₃ が沈殿する。
　NaCl ＋ H₂O ＋ NH₃ ＋ CO₂ → NaHCO₃ ＋ NH₄Cl
- 沈殿した NaHCO₃ を取り出して加熱し、Na₂CO₃ にする。出てきた CO₂ は ① へもどす。
　2NaHCO₃ → Na₂CO₃ ＋ H₂O ＋ CO₂
- CO₂ の不足分は、石灰石を熱分解してつくる。
　CaCO₃ → CaO ＋ CO₂
- できた CaO に水を加えて Ca(OH)₂ にする。
　CaO ＋ H₂O → Ca(OH)₂
- Ca(OH)₂ と ① でできた NH₄Cl から NH₃ を回収し、① へもどす。
　Ca(OH)₂ ＋ 2NH₄Cl → CaCl₂ ＋ 2H₂O ＋ 2NH₃
:::

① で NaHCO₃ が沈殿するのは、水に溶けているイオン（Na⁺・Cl⁻・NH₄⁺・HCO₃⁻）の組み合わせのうち、**NaHCO₃ の溶解度がいちばん小さいため**です。⑤ は弱塩基の遊離（強塩基の Ca(OH)₂ が弱塩基の NH₃ を追い出す）です。

## 全体の式を導く

途中で回収して使い回す物質（NaHCO₃・NH₄Cl・NH₃・CO₂・CaO・Ca(OH)₂）が両辺で消えるように足し合わせます。① を2倍し、②〜⑤ をそのまま足すと次の式が残ります。

:::reaction
left: 2NaCl ＋ CaCO₃
right: Na₂CO₃ ＋ CaCl₂
level: ★★★
note: ①×2 ＋ ② ＋ ③ ＋ ④ ＋ ⑤。原料2つと生成物2つだけが残ります。
:::

**全体の式と、① ② の2本は必ず書けるようにしてください。** ③〜⑤ は、①② で使った NH₃ と CO₂ を「どこから補うか」を考えれば出てくる式なので、丸暗記しなくても構いません。全体の式は、原料（NaCl と CaCO₃）と、ほしい物（Na₂CO₃）を覚えていれば、余りが CaCl₂ になると分かります。

:::figure
src: solvay-flow.png
svg: solvay-flow.svg
alt: アンモニアソーダ法の流れ図。左の列は NaCl の飽和水溶液から ①②を経て Na₂CO₃ へ、右の列は石灰石 CaCO₃ から ③④⑤を経て CaCl₂ へ進む。②と③で出た CO₂、⑤で追い出した NH₃、①でできた NH₄Cl は点線の矢印で工程の中を戻っている
caption: 実線をたどると、入っていくのは **NaCl と CaCO₃ だけ**、出てくるのは **Na₂CO₃ と CaCl₂ だけ**です。点線の分が両辺で消えるので、全体の式が 2NaCl ＋ CaCO₃ → Na₂CO₃ ＋ CaCl₂ になります。
:::

## 必ず覚えるもの（★★★）

:::list
items:
- 2Na ＋ 2H₂O → 2NaOH ＋ H₂
- 2NaOH ＋ CO₂ → Na₂CO₃ ＋ H₂O
- Na₂CO₃ ＋ 2HCl → 2NaCl ＋ H₂O ＋ CO₂
- 2NaHCO₃ → Na₂CO₃ ＋ H₂O ＋ CO₂（加熱）
- アンモニアソーダ法の ①・② と全体の式

炎色反応の色（Li 赤・Na 黄・K 赤紫）も必ず覚えてください。反応性の順（Li ＜ Na ＜ K）は「原子が大きいほど電子を出しやすい」という理由と組にしておけば、覚えなくても出てきます。Rb・Cs・Fr の性質は覚えなくても構いません。

## 例題

:::exercise
source: 自作（このページの ★★★ の式を物質名から書く）
prompt: 次の変化を化学反応式で書け。**(1) ナトリウムを水に入れると気体が発生した　(2) 水酸化ナトリウムの固体を空気中に置くと、二酸化炭素を吸収した　(3) 炭酸水素ナトリウムを加熱した　(4) 炭酸ナトリウムに希塩酸を加えた**
answer: (1) 2Na ＋ 2H₂O → 2NaOH ＋ H₂　(2) 2NaOH ＋ CO₂ → Na₂CO₃ ＋ H₂O　(3) 2NaHCO₃ → Na₂CO₃ ＋ H₂O ＋ CO₂　(4) Na₂CO₃ ＋ 2HCl → 2NaCl ＋ H₂O ＋ CO₂
:::

:::exercise
source: 自作（アンモニアソーダ法の5本を足し合わせて全体の式を導く）
prompt: アンモニアソーダ法の5つの反応 ① NaCl ＋ H₂O ＋ NH₃ ＋ CO₂ → NaHCO₃ ＋ NH₄Cl　② 2NaHCO₃ → Na₂CO₃ ＋ H₂O ＋ CO₂　③ CaCO₃ → CaO ＋ CO₂　④ CaO ＋ H₂O → Ca(OH)₂　⑤ Ca(OH)₂ ＋ 2NH₄Cl → CaCl₂ ＋ 2H₂O ＋ 2NH₃ を1つの式にまとめよ。また、Na₂CO₃ を 1.06 kg つくるのに必要な NaCl は何 kg か（式量 NaCl ＝ 58.5、Na₂CO₃ ＝ 106）。
answer: ① を2倍して ②〜⑤ を足すと、途中の物質が消えて **2NaCl ＋ CaCO₃ → Na₂CO₃ ＋ CaCl₂** が残ります。係数の比 ＝ mol の比なので NaCl : Na₂CO₃ ＝ 2 : 1 です。Na₂CO₃ 1.06 kg は 1.06×10³ ÷ 106 ＝ 10 mol なので、NaCl は 20 mol ＝ 20 × 58.5 ＝ 1170 g ＝ **1.17 kg** です。
:::
