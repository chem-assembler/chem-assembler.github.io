アルキンは、**炭素間三重結合 C≡C を1個だけもつ鎖式の炭化水素**です。三重結合が1本あるぶんアルカンより水素が4個少なく、一般式は **C~n~H~2n-2~** になります。

:::section
anchor: what
title: アルキンとは
lead: 一般式は C~n~H~2n-2~。名前は対応するアルカンの語尾を -yne に変えたものです。名前のついたアルキンは2つしかありません。
terms:
- アルキン
- 炭素間三重結合
- 不飽和炭化水素
:::

一般式 C~n~H~2n-2~ の n に炭素の数を代入すれば、分子式が得られます。n=2 ならエチン C₂H₂、n=3 ならプロピン C₃H₄、n=4 ならブチン C₄H₆ です。

アルキンの名前は、**同じ炭素数のアルカンの語尾を -ane から -yne に変えて**つくります。エタン（ethane）ならエチン（ethyne）、プロパン（propane）ならプロピン（propyne）です。

:::table
caption: 主なアルキン
source: slides:有機の基本2-9「アルキンの性質」s3「主なアルキン」の2件。名称・示性式ともスライドのまま
head:
- 化合物
- 示性式
align: left | left
rows:
- エチン（アセチレン） | CH≡CH
- プロピン | CH≡CCH₃
:::

**名前で呼ばれるアルキンは、この2つだけです。**アセチレンは IUPAC 命名法に基づかない慣用名ですが、こちらのほうがよく使われます。**エチンとアセチレンが同じものだと分かるようにしておいてください。**

:::section
anchor: shape
title: 三重結合のまわりの形
lead: C≡C のまわりの4個の原子は一直線上に固定されます。結合角は180°、炭素間の距離はいちばん短くなります。
terms:
- 直線形
- 結合角
:::

**炭素間三重結合のまわりの4個の原子は、すべて一直線上に固定されて**います。結合角は **180°** です。

:::figure
src: alkyne-linear.png
alt: エチン（アセチレン）の構造式 H−C≡C−H。4個の原子が一直線上に並び、結合角180度が書き込まれた図
caption: **C≡C に隣接する原子まで**が一直線上に固定されています。
:::

直線になるのは、**炭素のまわりに電子のまとまりが2組しかなく、負の電荷でたがいに反発していちばん遠い位置、つまり正反対に配置されるため**です。アルケンで電子のまとまりが3組で正三角形になったのと、同じ考え方です。

炭素間の距離は **C≡C（0.120 nm）がいちばん短く**、次が C=C（0.134 nm）、いちばん長いのが C−C（0.156 nm）です。**「結合の数が多いほど短い」**とだけ押さえておけば十分です。

:::section
anchor: addition
title: 付加反応は2段階で進む
lead: アルキンもアルケンと同じ付加反応をしますが、三重結合なので2回ぶん付加できます。条件を変えれば1段階目で止められます。
terms:
- 付加反応
- 不飽和結合の検出
:::

アルキンの C≡C も**不安定で反応しやすく**、付加反応・付加重合・酸化される反応を起こします。**「アルキンはアルケンと同じ反応を、2段階でする」**と考えてよいでしょう。

:::reaction
left: CH≡CH ＋ Br₂
right: CHBr=CHBr
level: ★★★
note: 1段階目。三重結合が二重結合になり、1,2-ジブロモエテンができます。
:::

:::reaction
left: CHBr=CHBr ＋ Br₂
right: CHBr₂CHBr₂
level: ★★★
note: 2段階目。二重結合が単結合になり、1,1,2,2-テトラブロモエタンになります。
:::

**反応条件を調節すれば、付加反応を1段階目で止めることもできます。**なお1段階目で生じるのはトランス型ですが、**これは覚えなくても構いません。**

アルキンの C≡C も、アルケンの C=C と同じく**臭素水の赤褐色を消す・過マンガン酸カリウム水溶液の赤紫色を消す**ので、この2つで検出できます。**だから正確には「二重結合の検出」ではなく「不飽和結合の検出」**なのでした。

:::

:::section
anchor: vinyl
title: エチンからビニル化合物をつくる
lead: エチンに1分子だけ付加させると、いろいろなビニル化合物が得られます。ビニル化合物は付加重合の材料になります。
terms:
- ビニル化合物
- 付加重合
- 単量体
:::

エチン CH≡CH に**1分子だけ付加**させると、**ビニル化合物 CH₂=CHX** が得られます。何を付加させるかで、できるビニル化合物が変わります。

:::table
caption: エチンに1分子付加してできるビニル化合物
source: slides:有機の基本2-9「アルキンの性質」s8「エチン（アセチレン）の反応①【付加反応によるビニル化合物の生成】」の表の4件
head:
- 付加する物質
- 入る原子・原子団 −X
- できるビニル化合物
align: left | center | left
rows:
- 水素 H₂ | −H | エテン（エチレン）
- 塩化水素 HCl | −Cl | 塩化ビニル
- 酢酸 CH₃COOH | −OCOCH₃ | 酢酸ビニル
- シアン化水素 HCN | −C≡N | アクリロニトリル
:::

:::reaction
left: CH≡CH ＋ HCl
right: CH₂=CHCl
level: ★★★
note: 塩化ビニル。付加重合させるとポリ塩化ビニルになります。
:::

:::reaction
left: CH≡CH ＋ CH₃COOH
right: CH₃COOCH=CH₂
level: ★★★
note: 酢酸ビニル。付加重合させるとポリ酢酸ビニルになります。
:::

**この表の4つは、そのまま高分子の単量体（モノマー）になります。**エチンは「ビニル化合物の入口」だと思っておくと、あとで高分子を学ぶときに効いてきます。

text: 付加重合そのもののしくみ（単量体と重合体）はアルケンのページに

:::section
anchor: ketoenol
title: エチンに水を付加すると、アセトアルデヒドになる
lead: できるはずのビニルアルコールは不安定で、ただちにアセトアルデヒドに変わります。答えるのはアセトアルデヒドのほうです。
terms:
- ビニルアルコール
- アセトアルデヒド
- エノール型
- ケト型
:::

エチン CH≡CH に**硫酸水銀(II) HgSO₄ を触媒として水 H₂O を付加**させると、いったん**ビニルアルコール CH₂=CHOH** ができます。ところがこれは**不安定で、ただちにアセトアルデヒド CH₃CHO に変わります。**

:::figure
src: alkyne-vinyl-alcohol.png
alt: ビニルアルコール CH2=CHOH がアセトアルデヒド CH3CHO に変わるようすの構造式。ヒドロキシ基の水素が、二重結合のもう一方の炭素へ移る矢印が描かれている
caption: **−OH の水素が、二重結合のもう一方の炭素へ移る**と、C=C が単結合になり、かわりに C=O ができます。
:::

:::reaction
left: CH≡CH ＋ H₂O
over: HgSO₄
right: CH₃CHO
level: ★★★
note: 途中でビニルアルコールを経ますが、最後まで進めてアセトアルデヒドと答えます。
:::

**エチンに水を付加させたときに生じる物質を問われたら、ビニルアルコールではなくアセトアルデヒドと答えてください。**「この反応の**中間生成物**で不安定な物質は何か」と問われたときだけ、ビニルアルコールと答えます。**この問われ方の違いは覚えておきましょう。**

ビニルアルコールのように**炭素間二重結合にヒドロキシ基が結合した形をエノール型**、そこから生じるアセトアルデヒドのような形を**ケト型**といいます。両者は平衡状態にありますが、**エノール型は不安定なのでケト型に偏ります。**

:::callout
tone: memorize
text: 高校化学では、**「炭素間二重結合の炭素原子にヒドロキシ基 −OH はつかない」**と考えてかまいません。**構造決定の問題でも、エノール型は答えの候補から外します。**この1行は丸暗記してしまってよいところです。
:::

:::section
anchor: ethyne
title: エチン（アセチレン）
lead: 無色無臭の気体。実験室では炭化カルシウムに水を加えてつくります。酸素との混合気体は金属の溶接・切断に使われます。
terms:
- エチン
- 炭化カルシウム
- アセチリドイオン
- 酸素アセチレン炎
:::

エチン（アセチレン）C₂H₂ は、**無色・無臭の気体**です。結合には極性がありますが、**分子全体で打ち消されるので無極性分子**になり、**水に溶けにくく、水上置換で捕集します。**

反応性は高く、過マンガン酸カリウムやオゾンによって酸化される**還元剤**です。**エチンも濃硫酸と反応するので、乾燥剤に濃硫酸を使うことができません。**

**酸素との混合気体は約3000℃の高温で燃え、「酸素アセチレン炎」**とよばれて、**金属の切断や溶接**に使われています。

実験室では、**炭化カルシウム（カルシウムカーバイド）CaC₂ に水を加えて**つくります。

:::reaction
left: CaC₂ ＋ 2H₂O
right: C₂H₂ ＋ Ca(OH)₂
level: ★★★
note: **イオンの組み換え**として読めます。係数の 2 を落としやすいので気をつけてください。
:::

炭化カルシウムは、**カルシウムイオン Ca²⁺ とアセチリドイオン C₂²⁻ からなるイオン結晶**です。アセチリドイオンは、エチンから水素イオンを2個とりさったものです。

:::figure
src: alkyne-carbide-ions.png
alt: 炭化カルシウムと水の反応をイオンの組み換えとして描いた図。Ca2+ とアセチリドイオン、H+ と OH- の組み合わせが入れ替わり、エチンと水酸化カルシウムになるようすを矢印で示している
caption: **Ca²⁺ と OH⁻**、**アセチリドイオンと H⁺** が組み直されただけ、と読めます。
:::

**アセチリドイオンという名前は覚えなくても構いません**が、「イオンの組み換えで書ける」と分かっていれば、**反応式をその場で組み立てられます。**

工業的には、**炭化水素を熱分解して**つくります。上の実験室的製法と同じ方法も使われます。

:::section
anchor: ethyne-reactions
title: エチンのその他の反応
lead: 3分子が重合するとベンゼンになり、アンモニア性硝酸銀水溶液に吹き込むと銀アセチリドの白色沈殿ができます。
terms:
- 3分子重合
- 銀アセチリド
:::

エチンを**鉄管または石英管の中で加熱すると、3分子が付加重合してベンゼン**になります。

:::reaction
left: 3C₂H₂
over: 赤熱した鉄管
right: C₆H₆
level: ★★★
note: エチン3分子が輪になって手をつなぎ、六員環ができます。芳香族の入口になる反応です。
:::

:::figure
src: alkyne-benzene.png
alt: エチン3分子が三角形に並び、たがいの三重結合のあいだを巻矢印が回って環をつくるようすを描いた図
caption: 3分子が輪になって、**となりどうしで手をつなぎ直す**とベンゼンの六員環になります。
:::

**アンモニア性硝酸銀水溶液にエチンを吹き込むと、銀アセチリド AgC≡CAg の白色沈殿**が生じます。

:::reaction
left: C₂H₂ ＋ 2［Ag(NH₃)₂］⁺
right: AgC≡CAg↓ ＋ 2NH₄⁺ ＋ 2NH₃
level: ★★☆
note: これも**イオン・分子の組み換え**として読めます。銀アセチリドという名前は、陰イオン（アセチリドイオン）と陽イオン（銀イオン）の名前をつないだだけです。
:::

**この沈殿は、末端に ≡CH をもつアルキンでしか起こりません。**2-ブチン CH₃C≡CCH₃ のように三重結合が分子の内側にあるものでは沈殿しないので、**末端に三重結合があるかどうかを見分ける手がかりになります。**

:::section
anchor: writeout
title: アルキンの書き出し
lead: アルケンの書き出しとほぼ同じ手順です。ただし三重結合をつくれる炭素の条件が、二重結合よりきびしくなります。
terms:
- 構造異性体
- 書き出し
:::

アルキンの書き出し方は、**アルケンの書き出し方とほぼ同じ**です。

:::list
ordered: true
items:
- **同じ炭素数のアルカンの構造異性体を、先に全部書き出す。**
　炭素数が5なら「ペンタンとその異性体（3種類）」を書きます。
- **書き出したそれぞれについて、炭素間の単結合を三重結合にできる場所を探す。**
　左右対称なところは同じものになるので、1つに数えます。
:::

**三重結合をつくれるかどうかの条件は、二重結合より1段きびしくなります。**三重結合をつくるには、その炭素から水素が2個抜けなければならないためです。

:::list
items:
- **道の途中・行き止まりの炭素は、三重結合をつくれる。**
- **丁字交差点・十字交差点の炭素は、三重結合をつくれない。**
　「**枝分かれしている部分の炭素は三重結合をつくれない**」と理解してもかまいません。
:::

具体例として、C₅H₈ のアルキン（ペンチン）を書き出してみます。炭素数5のアルカンはペンタン・2-メチルブタン・2,2-ジメチルプロパンの3種類です。直鎖のペンタンは左右対称なので、三重結合をつくれる場所は2種類で、**1-ペンチン**と **2-ペンチン**が出ます。2-メチルブタンは丁字交差点の炭素があるので、つくれる場所は1種類で **3-メチル-1-ブチン**。2,2-ジメチルプロパンは十字交差点の炭素しかないので、三重結合をつくれる場所がありません。

したがって、**ペンチンの構造異性体は3種類**です。**同じ C₅ でも、ペンテン（アルケン）は5種類ありました。**三重結合のほうが条件がきびしいぶん、数が少なくなります。
