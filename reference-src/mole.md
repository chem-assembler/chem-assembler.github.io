原子量・分子量は、¹²C 1個を 12 としたときの「1個あたりの重さの比」でした。このページでは、目に見える量（g や L）と、目に見えない粒子の個数を結びつける**物質量**を導入します。化学の計算は、ほとんどがこのページの比例式の組み合わせです。

:::section

title: 物質量 —— mol は数の単位
lead: 6.0×10²³ 個の粒子の集まりを 1mol といい、mol を単位として表した粒子の量を物質量といいます。
terms:
- 物質量
- モル
- アボガドロ定数
:::

鉛筆 12 本を「1ダース」とまとめて数えるように、化学では**粒子 6.0×10²³ 個をまとめて 1mol（モル）**と数えます。mol で表した粒子の量を**物質量**といいます。

「**mol は数の単位**」です。1ダースが 12 本であることと、1mol が 6.0×10²³ 個であることは同じ種類の約束です。

「1mol には粒子が何個入っているか」を表す数が**アボガドロ定数**（記号 NA）で、その値は 6.02×10²³/mol です。計算では 6.0×10²³/mol を使います。

//式: NA の A は下付き。Unicode に下付きの大文字 A が無いので第2周で器を考える

なぜ 6.0×10²³ という中途半端な数なのかというと、**この個数を集めると、ちょうど原子量・分子量に g をつけた質量になる**ように決めてあるからです。¹²C を 6.0×10²³ 個集めると 12g、H₂O を 6.0×10²³ 個集めると 18g になります。

1mol あたりの質量（g/mol）を**モル質量**、1mol あたりの体積（L/mol）を**モル体積**といいます。0℃・1.013×10⁵Pa を**標準状態**といい、気体のモル体積は**気体の種類によらず約 22.4L/mol**です。

気体の種類によらないのは、同じ温度・同じ圧力の気体では、同じ体積に同じ数の分子が含まれるからです（アボガドロの法則）。

:::link
to: chemical-laws
text: アボガドロの法則が生まれた経緯は、化学の基本法則のページへ
:::

:::mistake
wrong: 水 H₂O 1mol の体積は 22.4L である
right: 22.4L は**標準状態の気体**だけに使える値です。水は 0℃ では液体か固体なので、1mol（18g）はおよそ 18mL しかありません。
why: 「1mol ＝ 22.4L」だけを覚えてしまい、「気体なら」という条件が抜け落ちるためです。★ 表の3行めの「気体だけ」を必ずセットで覚えましょう。
:::

温度が 0℃ でない気体（27℃ など）は、22.4L をそのまま使えません。そのときは気体の法則のページの方法で換算します。

:::link
to: gas-laws
text: 0℃ 以外の気体の体積は、気体の法則のページへ
:::

:::section
anchor: proportion
title: 主語をつけた比例式を、倍率で解く
lead: 換算はすべて「1mol の顔 ＝ 既知と未知」の比例式にします。左辺に定義、右辺に問題の量を書き、両辺の主語（何の粒子か）をそろえ、倍率を掛けて □ を埋めます。
:::

物質量の換算は、公式を覚える代わりに、**比例式1つ**で解きます。形は毎回同じです。

:::list
ordered: true
items:
- 左辺に 1mol の顔（表の1行）を書く。★ 必ず主語（何の粒子か）をつける。
　「CH₄ 1mol : 16g」「H₂ 1mol : 6.0×10²³ 個」「O₂ 1mol : 22.4L」
- 右辺に、問題で与えられた量と、求める量 □ を、左辺と同じ並びで書く。
　○○ 1mol : ○○g ＝ ○○ ○○mol : □g
- 与えられた量どうしを見比べて、倍率を見つける。
　1mol → 0.25mol なら「×1/4」。
- 同じ倍率を、もう一方に掛けて □ を埋める。
:::

具体例1で、メタン CH₄（分子量 16）0.25mol の質量を求めます。

:::table
caption: CH₄ 0.25mol の質量（倍率 ×1/4 を両方に掛ける）
source: slides:物質量練習帳解答 No.1(1) の比例式と赤の倍率の矢印を表に組み直した
head:
- 主語
- 物質量
- 質量
align: left | right | right
rows:
- CH₄（1mol の顔） | 1mol | 16g
- 倍率 | ×1/4 | ×1/4
- CH₄（問題） | 0.25mol | □ ＝ 4.0g
:::

★ **内項と外項を掛ける（□ × 1 ＝ 16 × 0.25）解き方でも答えは同じです。**ただ、倍率で解くと「0.25mol は 1mol の 1/4 だから、質量も 1/4」と意味を追いながら計算できるので、桁の間違いにすぐ気づけます。

倍率が分数のまま使えると計算が楽になります。銅原子 3.3×10²³ 個の物質量なら、3.3 と 6.0 の比 11/20 を倍率にして、1mol × 11/20 ＝ 0.55mol です。

## 例題 —— 主語をつけた比例式を、倍率で解く

:::exercise
source: slides:物質量練習帳解答 No.2(2)
prompt: 一酸化窒素 NO（分子量 30）0.66g の物質量は何 mol か。有効数字2桁で答えよ。
answer: 0.022mol。NO 1mol : 30g ＝ NO □mol : 0.66g。0.66 ＝ 30 × 22/1000 と見ると倍率は ×22/1000 なので、22/1000 ＝ 0.022mol。
:::

:::section
anchor: via-mol
title: まずは mol を求めよう —— 2段の換算
lead: 質量から体積、個数から質量のように「mol 以外どうし」を換算するときは、1段めで mol を出し、2段めで目的の量にします。
:::

g から L、個数から g のような換算も、**必ず mol を経由して2段で**解きます。道筋を先に書いておくと迷いません。

:::list
items:
- g → 「1mol で分子量 g」→ mol → 「気体 1mol で 22.4L」→ L
- 個 → 「1mol で 6.0×10²³ 個」→ mol → 「1mol で分子量 g」→ g
:::

具体例2で、メタン CH₄（分子量 16）24g の標準状態での体積を求めます。

:::list
ordered: true
items:
- 1段め：CH₄ 1mol : 16g ＝ CH₄ □mol : 24g。倍率は 24/16 ＝ ×3/2 なので、3/2 mol。
- 2段め：CH₄ 1mol : 22.4L ＝ CH₄ 3/2 mol : □L。同じ ×3/2 で、22.4 × 3/2 ＝ 33.6 ≒ 34L。
:::

★ 1段めの mol は、**分数のまま次へ渡します**（3/2 mol を 1.5 と小数にしなくてよい）。有効数字の2桁に丸めるのは最後の1回だけです。

具体例3で、酸素 O₂ 分子 3.6×10²⁴ 個の質量を求めます。

:::list
ordered: true
items:
- 先に桁をそろえる：3.6×10²⁴ ＝ 36×10²³。
- 1段め：O₂ 1mol : 6.0×10²³ 個 ＝ O₂ □mol : 36×10²³ 個。倍率は ×6 なので 6mol。
- 2段め：O₂ 1mol : 32g ＝ O₂ 6mol : □g。32 × 6 ＝ 192 ≒ 1.9×10²g。
:::

**「数と桁を分けて、桁を先にそろえる」**のは、個数の計算でいつも使う手です。6.0×10²³ の 10²³ にそろえておけば、あとは 36 と 6.0 の比だけ見ればよくなります。

## 例題 —— 2段の換算

:::exercise
source: slides:物質量練習帳解答 No.4(4)
prompt: 硫化水素 H₂S（分子量 34）の分子 2.4×10²² 個は、標準状態で何 L を占めるか。アボガドロ定数は 6.0×10²³/mol、有効数字2桁で答えよ。
answer: 0.90L。1段め：H₂S 1mol : 6.0×10²³ 個 ＝ □mol : 2.4×10²² 個。2.4×10²² ＝ 0.24×10²³ で、0.24/6.0 ＝ 4/100 より 4/100 mol。2段め：H₂S 1mol : 22.4L ＝ 4/100 mol : □L で、22.4 × 4/100 ＝ 0.896 ≒ 0.90L。
:::

:::exercise
source: slides:物質量練習帳解答 No.8(1)
prompt: 標準状態での密度が 1.25g/L の気体の分子量を求めよ。
answer: 28。「気体 1L で 1.25g」なので、1L : 1.25g ＝ 22.4L : □g。22.4L は 1mol なので、□ ＝ 1.25 × 22.4 ＝ 28g が 1mol の質量、つまり分子量 28 です。
:::

:::section
anchor: particle
title: 粒子1個の質量と、成分元素の物質量
lead: 「1個」も「原子」も、比例式の主語を変えるだけで同じ形で解けます。分子と原子のどちらの話かを、主語で必ず区別します。
:::

具体例4で、酸素 O₂ 分子1個の質量を求めます。O₂ 6.0×10²³ 個 : 32g ＝ O₂ 1個 : □g で、倍率は ×1/(6.0×10²³) です。

:::list
items:
- 数：32 ÷ 6.0 ≒ 5.3
- 桁：1/10²³ ＝ 10⁻²³
- 答え：5.3×10⁻²³ g
:::

分子の中の原子の数を問われたら、**主語を「分子」と「原子」に分けて**比例式を立てます。水 H₂O は H−O−H なので、**H₂O 1個 : H原子 2個**です。mol は数の単位なので、mol でも同じ比になります。

具体例5で、H₂O 2.0mol に含まれる水素原子の物質量を求めます。H₂O 1個 : H原子 2個 ＝ H₂O 2.0mol : H原子 □mol で、倍率 ×2.0 より 4.0mol です。

:::mistake
wrong: H₂O 2.0mol に含まれる水素は、H₂ として 2.0mol なので 2.0mol
right: 聞かれているのは**水素原子 H** の物質量です。H₂O 1個の中に H原子は2個あるので、4.0mol です。
why: 「水素」という言葉が、H原子・H₂分子のどちらを指すかを確かめずに式を立てるためです。★ 比例式の両辺に主語を書けば、分子と原子の取り違えは起きません。
:::

## 例題 —— 粒子1個の質量と、成分元素の物質量

:::exercise
source: slides:物質量練習帳解答 No.5(5)
prompt: 標準状態で 78.4L のアンモニア NH₃ に含まれる水素原子の物質量は何 mol か。有効数字2桁で答えよ。
answer: 11mol。1段め：NH₃ 1mol : 22.4L ＝ □mol : 78.4L。78.4/22.4 ＝ 7/2 なので 7/2 mol。2段め：NH₃ 1個 : H原子 3個 ＝ NH₃ 7/2 mol : H原子 □mol で、21/2 ＝ 10.5 ≒ 11mol。
:::

:::section
anchor: formula
title: 組成式を求める —— 式量は質量に比例する
lead: 化合物の中の原子の数の比は、それぞれの質量を原子量で割った mol の比です。「原子の数の比 ＝ mol の比」から組成式が決まります。
terms:
- 組成式
:::

原子量 56 の金属 M 5.6g を完全に酸化すると、酸化物が 8.0g できたとします。結びついた酸素は 8.0 − 5.6 ＝ 2.4g です。

:::list
ordered: true
items:
- M は 5.6g ÷ 56 ＝ 0.10mol、O は 2.4g ÷ 16 ＝ 0.15mol。
- 原子の数の比は mol の比なので、M : O ＝ 0.10 : 0.15 ＝ 2 : 3。
- 組成式は M₂O₃。
:::

★ **組成式の問題は、どの元素も「まず mol」にしてから比をとる**と覚えておけば十分です。「M : O ＝ 1個 : x個」とおいて、式量と質量の比例式から x ＝ 3/2 を出す方法もあります。どちらで解いても同じです。

## 例題 —— 組成式を求める

:::exercise
source: slides:物質量練習帳解答 No.9(2)
prompt: 原子量 56 の金属元素 M 5.6g を完全に酸化したところ、酸化物が 8.0g 得られた。この酸化物の組成式を M を用いて表せ（O＝16）。
answer: M₂O₃。結びついた O は 8.0 − 5.6 ＝ 2.4g。M は 5.6/56 ＝ 0.10mol、O は 2.4/16 ＝ 0.15mol で、M : O ＝ 0.10 : 0.15 ＝ 2 : 3。
:::

:::section
anchor: range
title: 覚える範囲
lead: 1mol の3つの顔（分子量 g・6.0×10²³ 個・気体 22.4L）と、「気体だけ」の条件は必ず覚えます。
:::

**「1mol ＝ 分子量に g をつけた質量 ＝ 6.0×10²³ 個 ＝ 気体なら標準状態で 22.4L」は必ず暗記してください。**特に 22.4L には「気体だけ・0℃・1.013×10⁵Pa」の条件をセットで覚えましょう。

アボガドロ定数の正確な値（6.02214076×10²³/mol）は覚えなくて構いません。問題文では 6.0×10²³/mol か 6.02×10²³/mol で与えられます。

O₂ 3.0mol の体積は 22.4 × 3 ＝ 67.2L ですが、**有効数字2桁の指示があるときは、最後に 67L と丸めます。**途中は分数や3桁のまま持って構いません。
