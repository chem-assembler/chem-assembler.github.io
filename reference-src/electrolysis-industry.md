電気分解は、工業的にも大量の物質をつくるのに使われています。代表的なのが、**水酸化ナトリウムの製造（イオン交換膜法）**、**純銅の製造（銅の電解精錬）**、**アルミニウムの製造（溶融塩電解）**の3つです。どれも、陽極・陰極で何が反応するかの優先順位で説明できます。

:::section
anchor: membrane
title: イオン交換膜法 —— 水酸化ナトリウムの製造
lead: 炭素電極で塩化ナトリウム水溶液を電気分解し、陽イオン交換膜で Na⁺ だけを陰極側へ通して、純度の高い NaOH をつくります。
terms:
- イオン交換膜法
- 陽イオン交換膜
:::

塩化ナトリウム水溶液を炭素電極で電気分解すると、陽極では Cl⁻ が反応して Cl₂ が、陰極では H₂O が反応して H₂ と OH⁻ ができます（Na⁺ は水溶液の中では還元されません）。

:::reaction
left: 2Cl⁻
right: Cl₂ ＋ 2e⁻
level: ★★★
note: 陽極。Cl₂ は気体として外へ出ていきます。
:::

:::reaction
left: 2H₂O ＋ 2e⁻
right: H₂ ＋ 2OH⁻
level: ★★★
note: 陰極。H₂ は外へ出ていき、OH⁻ は水溶液に残ります。
:::

陽極側では Cl⁻ が消費されて正の電荷が余り、陰極側では OH⁻ ができて負の電荷が余ります。そこで両極の間を**陽イオン交換膜**で仕切ると、Na⁺ だけが膜を通って陽極側から陰極側へ移動します。Cl⁻ は膜を通れないので、陰極側には**不純物の Cl⁻ を含まない NaOH 水溶液**がたまります。これを**イオン交換膜法**といいます。

:::figure
src: electrolysis-industry-membrane.png
alt: イオン交換膜法の装置図。中央の陽イオン交換膜で仕切られ、左の陽極側では Cl⁻ が Cl₂ になり、飽和食塩水を補い、うすい食塩水が出ていく。右の陰極側では H₂O が H₂ と OH⁻ になり、水を補い、NaOH 水溶液が取り出される。Na⁺ が膜を通って左から右へ移動する
caption: 陽イオン交換膜は **Na⁺ を通し、Cl⁻ を通さない**ので、陰極側から Cl⁻ を含まない NaOH 水溶液が得られます。
:::

両極の式を足し、両辺に 2Na⁺ を加えてまとめると、全体の反応式になります。

:::reaction
left: 2NaCl ＋ 2H₂O
right: 2NaOH ＋ H₂ ＋ Cl₂
level: ★★☆
note: 全体の反応。陽極の式と陰極の式を足して、2Na⁺ を両辺に加えたものです。
:::

生じた H₂ と Cl₂ を反応させると、塩化水素もつくれます（H₂ ＋ Cl₂ → 2HCl）。

:::section
anchor: copper
title: 銅の電解精錬 —— 粗銅から純銅へ
lead: 粗銅を陽極、純銅を陰極にして硫酸銅(Ⅱ)水溶液を電気分解すると、陰極に純度の高い銅だけが析出します。
terms:
- 電解精錬
- 粗銅
- 純銅
- 陽極泥
:::

鉱石からつくった銅は、金・銀・鉄・亜鉛などの不純物を含んでいて、純度は約99％です。これを**粗銅**といいます。粗銅を陽極、純銅を陰極にして、硫酸酸性の硫酸銅(Ⅱ)水溶液を低い電圧で電気分解すると、純度99.99％以上の**純銅**が得られます。これを**銅の電解精錬**といいます。

:::reaction
left: Cu
right: Cu²⁺ ＋ 2e⁻
level: ★★★
note: 陽極（粗銅）。電極の Cu が Cu²⁺ になって溶けだし、陽極板は小さくなります。
:::

:::reaction
left: Cu²⁺ ＋ 2e⁻
right: Cu
level: ★★★
note: 陰極（純銅）。Cu²⁺ が Cu として析出し、陰極板は大きくなります。
:::

陽極が C・Au・Pt 以外の金属（銅）なので電極の Cu が溶け、陰極では Al よりイオン化傾向が小さい Cu²⁺ が析出する、という優先順位のとおりの反応です。

粗銅に含まれる不純物は、イオン化傾向によって行き先が2つに分かれます。

:::list
items:
- イオン化傾向が Cu より**小さい** Au・Ag・Pt は、陽イオンにならず固体のままで、まわりの Cu が溶けると陽極の下に落ちてたまる。これを**陽極泥**という。
- イオン化傾向が Cu より**大きい** Fe・Zn・Ni などは、Cu より先に陽イオンになって溶けだす。ただし Cu²⁺ より e⁻ を受け取る力が弱いので、陰極には析出せず、水溶液中にとどまる。
:::

:::figure
src: electrolysis-industry-copper.png
alt: 銅の電解精錬の装置図。左の粗銅（陽極）から Cu²⁺ と Zn²⁺ が溶けだし、Cu²⁺ だけが右の純銅（陰極）に析出する。Zn²⁺ は水溶液中にとどまり、Au・Pt・Ag は陽極の下に陽極泥として落ちる
caption: Cu より**イオン化傾向が小さい**金属は陽極泥に、**大きい**金属は水溶液中に残ります。陰極に析出するのは Cu だけです。
:::

**「陽極泥になるのは Au・Ag（Pt）、水溶液に残るのは Fe・Zn・Ni」を必ず覚えてください。**どちらもイオン化傾向と優先順位で説明できるようにしましょう。

:::mistake
wrong: 粗銅に含まれる亜鉛は、イオン化傾向が大きいので溶けださずに陽極泥になる
right: イオン化傾向が大きい金属ほど陽イオンになりやすいので、Zn は **Cu より先に溶けだし**、水溶液中にとどまります。陽極泥になるのは、イオン化傾向が**小さい** Au・Ag・Pt です。
why: 「陽極泥 ＝ 不純物がたまるところ」とだけ覚えて、どの不純物もそこへ行くと思ってしまうためです。★ 溶けるか溶けないかはイオン化傾向で決まり、析出するかどうかは陰極の優先順位で決まる、と2段に分けて考えます。
:::

:::section
anchor: molten
title: 溶融塩電解 —— アルミニウムの製造
lead: 水があると Al³⁺ は還元できないので、水を使わず、融解した塩を電気分解します。
terms:
- 溶融塩電解
- 融解塩電解
- ボーキサイト
- アルミナ
- 氷晶石
:::

イオン化傾向が Al 以上に大きい金属の陽イオン（Al³⁺・Na⁺・Ca²⁺ など）は、水溶液の中では還元されません。Al³⁺ より H₂O のほうが e⁻ を受け取る力が強く、陰極では水が反応して H₂ が出るだけだからです。

そこで、**水の無い環境で電気分解**します。イオン結晶は、水に溶かす（溶解）か、高温で融かす（融解）かすればイオンが動けるようになり、電気を通します。融解した塩を電気分解する方法を**溶融塩電解**（融解塩電解）といいます。

アルミニウムは、鉱石のボーキサイトから精製した酸化アルミニウム Al₂O₃（アルミナ）を原料にします。Al₂O₃ は融点が2000℃以上と高いので、融かした**氷晶石** Na₃AlF₆ に Al₂O₃ を溶かし込み、約1000℃で融解状態にして、炭素電極で電気分解します。氷晶石の役目は、Al₂O₃ を溶かし込んで**融点を下げる**ことです。

:::reaction
left: Al³⁺ ＋ 3e⁻
right: Al
level: ★★★
note: 陰極。融解状態の Al の単体が得られます。水溶液では起こせなかった反応です。
:::

:::reaction
left: C ＋ 2O²⁻
right: CO₂ ＋ 4e⁻
level: ★★☆
note: 陽極。高温なので、ふつうは反応しない炭素電極そのものが酸化されます（C の酸化数 0 → ＋4）。
:::

:::reaction
left: C ＋ O²⁻
right: CO ＋ 2e⁻
level: ★★☆
note: 陽極。一部は CO になります（C の酸化数 0 → ＋2）。陽極の炭素は反応で減っていきます。
:::

Na や Ca のように、イオン化傾向が Al より大きい金属の単体も、同じように溶融塩電解でつくります。たとえば塩化ナトリウムを融かして電気分解すると、陰極で Na⁺ ＋ e⁻ → Na、陽極で 2Cl⁻ → Cl₂ ＋ 2e⁻ が起こります。

:::section
anchor: range
title: 覚える範囲
lead: 3つの製法の両極の式と、イオン交換膜・陽極泥・氷晶石がそれぞれ何のためにあるかを覚えます。
:::

**イオン交換膜法・銅の電解精錬・アルミニウムの溶融塩電解の、両極の反応式は必ず書けるようにしてください。**どれも優先順位から出るので、「なぜその極でその物質が反応するか」を言えるようにしておくと忘れません。

装置については、**陽イオン交換膜は Na⁺ だけを通す／陽極泥は Cu よりイオン化傾向の小さい金属／氷晶石は Al₂O₃ を低い温度で融かすため**、の3点をおさえましょう。電解精錬の電圧や、陽極の CO₂ と CO の割合は覚えなくても構いません。

:::table
caption: 3つの製法の見比べ
source: このページの3つの節の両極の式と装置の説明（イオン交換膜・陽極泥・氷晶石）を1枚に並べ直したもの
head:
- 製法
- 陽極
- 陰極
- 装置のかなめ
align: left | left | left | left
rows:
- イオン交換膜法（NaOH） | 2Cl⁻ → Cl₂ ＋ 2e⁻ | 2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ | 陽イオン交換膜が Na⁺ だけを陰極側へ通す
- 銅の電解精錬 | Cu → Cu²⁺ ＋ 2e⁻（粗銅） | Cu²⁺ ＋ 2e⁻ → Cu（純銅） | Cu よりイオン化傾向の小さい金属が陽極泥になる
- 溶融塩電解（Al） | C ＋ 2O²⁻ → CO₂ ＋ 4e⁻ | Al³⁺ ＋ 3e⁻ → Al | 氷晶石で Al₂O₃ を低い温度で融かす
:::

ちなみに、電気分解で金属の表面に別の金属の薄い膜をつける方法を**電気めっき**といい、めっきしたい物を陰極にします。鉄を亜鉛でめっきしたものがトタン、スズでめっきしたものがブリキです。
