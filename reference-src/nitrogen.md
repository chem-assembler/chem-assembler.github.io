窒素 N は周期表の15族の元素で、原子は5個の価電子をもちます。空気の体積の約78%を占める窒素 N₂ のほか、アンモニア NH₃・窒素酸化物・硝酸 HNO₃ と、酸化数 −3 から +5 までの化合物がそろっています。

このページの反応式は、酸塩基（アンモニアの遊離）と酸化還元（硝酸・窒素酸化物）の2つの型でほぼすべて説明できます。

窒素 N₂ は無色・無臭の気体で、水にほとんど溶けません。2つの N 原子が**三重結合**で結びついていて、この結合が非常に切れにくいため、常温ではほとんど反応しません。

工業的には液体空気の分留で得られます。沸点は −196℃ で、液体窒素は冷却剤に使われます。

:::reaction
left: NH₄NO₂
over: 加熱
right: N₂ ＋ 2H₂O
level: ★☆☆
note: 実験室での製法（亜硝酸アンモニウムの分解）。NH₄⁺ の N（−3）と NO₂⁻ の N（+3）が同じ酸化数 0 にそろう酸化還元です。
:::

**窒素の単体の製法は覚えなくても構いません。**窒素そのものは「安定で反応しにくい」「空気の約78%」の2つを押さえておけば十分です。

## 弱塩基の遊離でつくる（実験室的製法）

塩化アンモニウム NH₄Cl と水酸化カルシウム Ca(OH)₂ の混合物を加熱すると、アンモニアが発生します。強塩基が、弱塩基の NH₃ を追い出す反応です。

:::reaction
left: 2NH₄Cl ＋ Ca(OH)₂
over: 加熱
right: CaCl₂ ＋ 2H₂O ＋ 2NH₃↑
level: ★★★
note: 本体は NH₄⁺ ＋ OH⁻ → NH₃ ＋ H₂O です。Ca(OH)₂ が OH⁻ を出し、NH₄⁺ の相手だった Cl⁻ は Ca²⁺ と組んで CaCl₂ になります。
:::

水酸化ナトリウムを使っても同じ反応が起こります。**係数は、イオン反応式 NH₄⁺ ＋ OH⁻ → NH₃ ＋ H₂O を先に書き、省いたイオンを両辺に戻せば出ます。**

:::reaction
left: NH₄Cl ＋ NaOH
right: NaCl ＋ H₂O ＋ NH₃↑
level: ★★★
note: 固体どうしを加熱する実験では Ca(OH)₂ を使うのが定番です。
:::

## 塩基としての反応

アンモニアは水に溶けると、一部が水から H⁺ を受け取って OH⁻ を生じます。電離はごく一部で、多くは NH₃ 分子のまま溶けています。

:::reaction
left: NH₃ ＋ H₂O
right: NH₄⁺ ＋ OH⁻
level: ★★★
note: （可逆）弱塩基なので、電離はごく一部です。
:::

//⇄ この式は可逆。便0a で :::reaction に arrow: が入ったら ⇄ に直す

アンモニウムイオン NH₄⁺ は、NH₃ の N がもつ非共有電子対を H⁺ に与えてできる、**配位結合**をもつイオンです。

酸と出会うと中和して塩をつくります。塩化水素との反応では、生じた NH₄Cl の細かい結晶が**白煙**として見えるので、アンモニアの検出に使われます。

:::reaction
left: NH₃ ＋ HCl
right: NH₄Cl
level: ★★★
note: 白煙の正体は NH₄Cl の微粒子です。塩化水素の検出にも、同じ反応を使います。
:::

:::reaction
left: 2NH₃ ＋ H₂SO₄
right: (NH₄)₂SO₄
level: ★★★
note: 硫酸アンモニウム（硫安）は窒素肥料として使われます。
:::

一酸化窒素は、空気に触れるとすぐに酸化されて赤褐色の二酸化窒素に変わります。無色の気体が赤褐色になることで、NO があったと分かります。空気と混ぜると変わってしまうので、水上置換で集めます。

:::reaction
left: 2NO ＋ O₂
right: 2NO₂
level: ★★★
note: 無色 → 赤褐色。NO の検出に使います。
:::

二酸化窒素は、一部が無色の四酸化二窒素 N₂O₄ と平衡の状態にあります。

:::reaction
left: 2NO₂
right: N₂O₄
level: ★★☆
note: （可逆）赤褐色の NO₂ と無色の N₂O₄ の平衡です。化学平衡の単元で、温度を変えると色が変わる例としてよく登場します。
:::

一酸化窒素は、エンジンの中のような高温で窒素と酸素が直接反応しても生じます。NO や NO₂ などをまとめて NOₓ（ノックス）と呼び、大気汚染や酸性雨の原因になります。

硝酸は、塩酸 HCl・硫酸 H₂SO₄ とならぶ**強酸**です。「強酸は3つ覚える」の1つにあたります。

:::link
to: acid-base-strength
text: 強酸・弱酸の見分けと電離の式のページへ
:::

硝酸はそれに加えて、**イオン化傾向が H₂ より小さい銅や銀も溶かします。**ふつうの酸が金属を溶かすときの酸化剤は H⁺ ですが、硝酸では NO₃⁻ が H⁺ より強い酸化剤としてはたらくためです。このような酸を「**酸化力のある酸**」といい、希硝酸（→ NO）・濃硝酸（→ NO₂）・熱濃硫酸（→ SO₂）の3つです。

:::table
caption: 硝酸が酸化剤としてはたらくときの半反応式
source: slides:無機の基本１「無機の前に復習すべきこと」p.38「主な酸化剤の半反応式一覧」の希硝酸・濃硝酸の2行（⚠ p.65 の濃硝酸の式は H₂O の係数が2になっている誤記。ここでは正しい 1 で書いた）
head:
- 酸化剤
- 半反応式
- 出てくる気体
align: left | left | left
rows:
- 希硝酸 | HNO₃ ＋ 3H⁺ ＋ 3e⁻ → NO ＋ 2H₂O | NO（無色）
- 濃硝酸 | HNO₃ ＋ H⁺ ＋ e⁻ → NO₂ ＋ H₂O | NO₂（赤褐色）
:::

**この2本の半反応式は必ず覚えてください。**「希硝酸は NO、濃硝酸は NO₂」と生成物を暗記すれば、あとは H₂O → H⁺ → e⁻ の順に数を合わせて書けます。

銅との反応は、銅の半反応式 Cu → Cu²⁺ ＋ 2e⁻ と組み合わせて e⁻ をそろえ、省いた NO₃⁻ を両辺に戻して組み立てます。

:::reaction
left: 3Cu ＋ 8HNO₃
over: 希硝酸
right: 3Cu(NO₃)₂ ＋ 4H₂O ＋ 2NO↑
level: ★★★
note: 希硝酸の半反応式を2倍、銅の半反応式を3倍して足し、NO₃⁻ を6個戻します。HNO₃ 8個のうち、酸化剤として NO になるのは2個だけで、残り6個は Cu²⁺ の相手の NO₃⁻ として残ります。
:::

:::reaction
left: Cu ＋ 4HNO₃
over: 濃硝酸
right: Cu(NO₃)₂ ＋ 2H₂O ＋ 2NO₂↑
level: ★★★
note: 濃硝酸の半反応式を2倍して、銅の半反応式と足します。
:::

## 不動態・保存・王水

**アルミニウム Al・鉄 Fe・ニッケル Ni は濃硝酸に溶けません。**表面に緻密な酸化物の膜ができて、内部が守られるためです。この状態を**不動態**といいます。「濃硝酸で不動態になる金属は Al・Fe・Ni」と3つ覚えておきましょう。

//要確認: 化学新研究2015・総合的研究化学 濃硝酸で不動態になる金属の範囲（Cr・Co を加えているか）

硝酸は光や熱で分解しやすいので、**褐色のびんに入れて冷暗所に保存します。**

濃硝酸と濃塩酸を体積比 1：3 で混ぜた液を**王水**といい、硝酸でも溶けない金 Au や白金 Pt を溶かします。**王水は組成（濃硝酸：濃塩酸 ＝ 1：3）だけ覚えておけば十分です。**

:::callout
tone: skip
text: 王水が金を溶かすのは、酸化力が強いからだけではありません。塩化物イオンが金のイオンと安定な錯イオン [AuCl₄]⁻ をつくることが効いています。この仕組みは覚えなくても構いません。
:::

## ハーバー・ボッシュ法

アンモニアは、四酸化三鉄 Fe₃O₄ を主成分とする触媒を使い、窒素と水素から直接合成します。これを**ハーバー・ボッシュ法**といいます。

:::reaction
left: N₂ ＋ 3H₂
over: Fe₃O₄ を主成分とする触媒
under: 高温・高圧
right: 2NH₃
level: ★★★
note: （可逆）化学平衡の単元で、圧力と温度の条件を選ぶ例としてよく登場します。
:::

## オストワルト法

硝酸は、アンモニアを原料に3段階でつくります。これを**オストワルト法**といいます。

:::list
ordered: true
items:
- アンモニアを白金 Pt を触媒にして酸化し、一酸化窒素にする。
- 一酸化窒素を空気中の酸素で酸化して、二酸化窒素にする。
- 二酸化窒素を温水に吸収させて、硝酸にする。このとき出る NO は、2段目にもどして使う。
:::

:::reaction
left: 4NH₃ ＋ 5O₂
over: Pt
right: 4NO ＋ 6H₂O
level: ★★★
note: 1段目。触媒の白金は覚えておきましょう。
:::

:::reaction
left: 2NO ＋ O₂
right: 2NO₂
level: ★★★
note: 2段目。NO の検出と同じ式です。
:::

:::reaction
left: 3NO₂ ＋ H₂O
right: 2HNO₃ ＋ NO
level: ★★★
note: 3段目。NO₂ の N（+4）の一部が +5（HNO₃）に、一部が +2（NO）になる**自己酸化還元**です。
:::

3本の式をまとめると、次の1本になります。**NO を2段目にもどして使い切ると考え、NO と NO₂ が消えるように足し合わせます。**

:::reaction
left: NH₃ ＋ 2O₂
right: HNO₃ ＋ H₂O
level: ★★★
note: 係数から、**NH₃ 1 mol から HNO₃ 1 mol**ができると読めます。量の計算ではこの1本を使います。
:::

**オストワルト法は3本の式もまとめた1本も書けるようにしてください。**まとめた式は、N 原子が NH₃ から HNO₃ まで1個ずつ受け渡されていく、と考えれば係数を覚えずに確かめられます。

:::mistake
wrong: オストワルト法の3本の式を足せば、そのまま全体の式になる
right: 3本をそのまま足すと NO と NO₂ が残ります。**3段目で出た NO を2段目にもどして使い切る**と考え、NO と NO₂ が両辺から消えるように係数を選んで足します。
why: 工程が「循環」していることを式に入れ忘れるためです。★ まとめた式 NH₃ ＋ 2O₂ → HNO₃ ＋ H₂O で、N が1個ずつ受け渡されていることを確かめましょう。
:::

title: 覚える範囲

**★★★ の式は、物質名から書けるようにしてください。**とくに次の3つは、無機のほかのページでもくり返し出てきます。

:::list
items:
- アンモニアの製法（NH₄Cl ＋ Ca(OH)₂）と検出（NH₃ ＋ HCl → NH₄Cl の白煙）
- 希硝酸と濃硝酸の半反応式（生成物は NO と NO₂）
- オストワルト法の3本と、まとめた1本
:::

窒素の単体の製法（NH₄NO₂ の分解）と、王水が金を溶かす仕組みは覚えなくても構いません。
