**電気分解**では、電池の反応とは逆に、外部の電源（電池）で e⁻ を押し付けたり奪ったりして、無理やり酸化還元反応を起こします。反応する物質は、酸化剤・還元剤の強さ（イオン化傾向）で決まるので、酸化還元とイオン化傾向がこのページの前提です。

:::section
anchor: mechanism
title: 電気分解の仕組み
lead: 電源の正極につないだ電極が陽極、負極につないだ電極が陰極です。陽極では酸化、陰極では還元が起こります。
terms:
- 電気分解
- 陽極
- 陰極
- 電解槽
- 電解液
:::

外部の電池（電源）を利用して電流を流し、無理やり酸化還元反応を起こすことを**電気分解**といいます。イオンを含む水溶液（電解液）を入れた容器を電解槽といいます。

電源の**正極**につないだ電極を**陽極**、電源の**負極**につないだ電極を**陰極**といいます。e⁻ は電源の負極から出て、導線を通って陰極へ流れ込み、陽極から出て電源の正極へもどります（電流は e⁻ の逆向き）。電解液の中では、e⁻ の代わりにイオンが移動して回路をつなぎます。

:::figure

caption: 陰極は e⁻ を**押し付けられ**、酸化剤が還元されます。陽極は e⁻ を**奪われ**、還元剤が酸化されます。
:::

**「陽極は e⁻ を奪われて還元剤が酸化される、陰極は e⁻ を押し付けられて酸化剤が還元される」を必ず覚えてください。**電池の正極・負極と名前が似ていますが、電池の負極（酸化が起こる）に対応するのは電気分解の陽極です。

:::section
anchor: anode
title: 陽極で反応するもの —— 4段の優先順位
lead: ①電極の金属 → ②ハロゲン化物イオン → ③OH⁻ → ④H₂O の順に、e⁻ を奪われやすいものから反応します。
terms:
- ハロゲン化物イオン
:::

陽極では e⁻ が奪われる反応（酸化される反応）が、次の優先順位で起こります。**上にあるものが1つでもあれば、それが反応します。**

:::list
ordered: true
items:
- 炭素 C・金 Au・白金 Pt 以外の電極の金属が、e⁻ を失って陽イオンになり電解液に溶け込む。
　例：Cu → Cu²⁺ ＋ 2e⁻、Ag → Ag⁺ ＋ e⁻
- 電解液中のハロゲン化物イオンが e⁻ を失い、ハロゲンの単体ができる。
　例：2Cl⁻ → Cl₂ ＋ 2e⁻、2I⁻ → I₂ ＋ 2e⁻
- 電解液中の水酸化物イオン OH⁻ が e⁻ を失い、酸素 O₂ が発生する（塩基性のときだけ）。
　例：4OH⁻ → O₂ ＋ 2H₂O ＋ 4e⁻
- 電解液中の水 H₂O が e⁻ を失い、酸素 O₂ が発生する。
　例：2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻
:::

③の OH⁻ は、**塩基性の水溶液の中にしか存在しません**。中性・酸性の水溶液では OH⁻ はほとんど無いので、③は飛ばして④の水が反応します。

:::section
anchor: cathode
title: 陰極で反応するもの —— 2段の優先順位
lead: Al よりイオン化傾向が小さい金属の陽イオン（H⁺ も含む）があればそれが、無ければ H₂O が e⁻ を受け取ります。
:::

陰極では e⁻ を押し付けられる反応（還元される反応）が、次の優先順位で起こります。

:::list
ordered: true
items:
- 電解液中の、Al よりイオン化傾向が小さい金属の陽イオンが e⁻ を受け取り、単体の金属として析出する。H⁺ の場合は H₂ が発生する。
　例：Cu²⁺ ＋ 2e⁻ → Cu、Ag⁺ ＋ e⁻ → Ag、2H⁺ ＋ 2e⁻ → H₂
- 水 H₂O が e⁻ を受け取り、水素 H₂ が発生する。
　例：2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻
:::

イオン化列 Li ＞ K ＞ Ca ＞ Na ＞ Mg ＞ Al ＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞ (H₂) ＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au のうち、**Li から Al までの陽イオン（K⁺・Ca²⁺・Na⁺・Mg²⁺・Al³⁺ など）は、水溶液の中では還元されません**。これらの陽イオンより、H₂O のほうが e⁻ を受け取る力が強いためです。

**「Al までの陽イオンは水溶液では還元されない」という境界線は必ず覚えてください。**Na や Al の単体を電気分解でつくるには、水の無い状態（融解した塩）で電気分解します。

:::

ちなみに、Zn²⁺・Ni²⁺・Fe²⁺ のようにイオン化傾向が中くらいの金属の陽イオンでは、濃度や電圧によって、金属の析出と H₂ の発生が同時に起こることがあります（金属イオンが濃いときは金属の析出が、薄いときは H₂ の発生が優勢になります）。**高校の問題では、優先順位のとおり金属が析出するとして解いて構いません。**

具体例で、塩化ナトリウム水溶液を白金電極で電気分解する場合をたどります。

:::list

- 陰極：陽イオンは Na⁺ だけで、Na は Al よりイオン化傾向が大きい（n）ので、**H₂O が反応**して H₂ が発生する。

:::section
anchor: why
title: 優先順位がこうなる理由
lead: 陽極では e⁻ を失いやすいもの、陰極では e⁻ を受け取りやすいものから反応します。
:::

電極の金属は、e⁻ を放出して陽イオンになる**還元剤**なので、e⁻ を奪われる陽極でしか反応しません。**陰極では電極の金属は反応しません。**

Au と Pt は、イオン化傾向がきわめて小さく、単体が酸化されにくいので、陽極にしても反応しません。炭素 C は非金属元素で、共有結合の結晶なので e⁻ を奪われにくく、やはり陽極で反応しません。

ハロゲン化物イオンの中では、I⁻ ＞ Br⁻ ＞ Cl⁻ の順に陽極で反応しやすく、F⁻ は反応しません。ハロゲンの単体の酸化力は原子が小さいほど強く（F₂ ＞ Cl₂ ＞ Br₂ ＞ I₂）、その逆向きの反応であるハロゲン化物イオンの酸化は、原子が小さいほど起こりにくいためです。

NO₃⁻ や SO₄²⁻ などの陰イオンは安定で、H₂O より e⁻ を奪われにくいので、水溶液では陽極で反応しません。**「NO₃⁻・SO₄²⁻ があるときは、陽極では水（塩基性なら OH⁻）が反応する」と覚えましょう。**

:::mistake
wrong: 硫酸銅(Ⅱ)水溶液を白金電極で電気分解すると、陽極では SO₄²⁻ が反応する
right: SO₄²⁻ は水溶液の中では陽極で反応しません。陽極では **H₂O** が反応して O₂ が発生します。
why: 「陰イオンは陽極へ移動する」から「陽極へ来た陰イオンが反応する」と短絡してしまうためです。★ 移動することと、e⁻ を奪われることは別で、奪われやすさは優先順位で決まります。
:::

:::section
anchor: range
title: 覚える範囲
lead: 陽極4段・陰極2段の優先順位と、「Al までの陽イオンは水溶液では還元されない」境界を覚えます。
:::

**陽極の優先順位「①C・Au・Pt 以外の電極の金属 ②ハロゲン化物イオン ③OH⁻（塩基性のとき） ④H₂O」と、陰極の優先順位「①Al よりイオン化傾向が小さい金属の陽イオン（H⁺ も含む） ②H₂O」は必ず暗記してください。**フローチャートの形で覚えても構いません。

ハロゲン化物イオンの反応しやすさの順（I⁻ ＞ Br⁻ ＞ Cl⁻）は、問題で問われることはほとんどありません。**理由の説明として読めれば十分でしょう。**
