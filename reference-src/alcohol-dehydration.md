アルコールに濃硫酸を加えて160〜170℃に熱すると、**−OH と、その隣の炭素についている水素 H** がまとめて水 H₂O として抜け（脱離）、抜けたあとの2つの炭素原子のあいだに二重結合ができます。分子1つの中だけで起きるので**分子内脱水**といい、できるのは**アルケン**です。

:::reaction
left: C₂H₅OH
over: 濃硫酸
under: 160〜170℃
right: CH₂=CH₂ ＋ H₂O
level: ★★★
note: エタノールの分子内脱水。−OH と隣の炭素の H が水として抜けて、エテン（エチレン）ができます。⚠ 130〜140℃だと分子2つのあいだで水が取れて、ジエチルエーテルになります。
:::

図の2-プロパノールでは、H原子は左右どちらの炭素原子からも取れます。

ただし、2-プロパノールが左右対称なので、どちらの場合も同じプロペンが生じます。

2-ブタノールでは話が変わります。左の炭素から水素をとると1-ブテン、右の炭素から水素をとると2-ブテンが生じます。

caption: 2-ブタノール。−OH が付いた C₂ の隣は、左が C₁、右が C₃ で、**左右で形が違います**。

:::

2-ブタノールを濃硫酸で分子内脱水させると、1-ブテンと2-ブテンの混合物が得られます。2-ブテンはシス-トランス異性体がありますので、立体異性体も区別すると1-ブテン、シス-2-ブテン、トランス-2-ブテンの3種類が得られます。

1-ブテンと2-ブテンのうち優先的に生じるのは2-ブテンですが、それについては次のページをご覧ください。

メタノール CH₃OH からペンタノール C₅H₁₁OH までのアルコールと脱水生成物の対応をまとめると次のようになります。

:::dehydrationTable
source: alcohols:CnH2n+2O (n=1..5)
caption: C₁〜C₅ のアルコールと、分子内脱水でできるアルケン
:::

アルコールとアルケンの対応が1:1でないことに注意しましょう。脱水反応によってあるアルケンを生じるアルコールは1種類とは限りません。脱水の逆反応である H₂O の付加反応についても同様です。したがってアルコールとアルケンの対応関係は複雑になります。複数の化合物が生じる場合、付加反応の主生成物はマルコフニコフ則、脱水反応の主生成物はザイツェフ則で決まります。

:::link
to: alkene
text: 逆向き（アルケンに水を付加する）の主生成物を決めるマルコフニコフ則は「アルケン」で
:::

脱水・H₂O の付加によって**炭素骨格が変わらない**ことも注目すべき点です。ブタン C₄H₁₀ の構造異性体は2種類なので、炭素数4のアルコールとアルケンは2種類に分けて考えることができます。ペンタン C₅H₁₂ の構造異性体は3種類なので、炭素数5のアルコールとアルケンは3種類に分けて考えることができます。

## 脱水反応できないアルコール

メタノール CH₃OH は炭素原子が1個しかなく、「ヒドロキシ基 −OH がついた炭素の隣の炭素」が存在しないため脱水反応を起こしません。2,2-ジメチル-1-プロパノールは、「ヒドロキシ基 −OH がついた炭素の隣の炭素」に水素原子が1個もついていないため脱水反応を起こしません。

:::figure
src: alcohol-dehydration-methanol.png
gen: name=メタノール plain
alt: メタノールの構造式。炭素1個にヒドロキシ基 OH が1つと水素が3個付いているだけで、隣に炭素がない
caption: メタノール CH₄O。−OH が付いた炭素の**隣に炭素がありません**。二重結合を作る相手がいないので脱水できません。
:::

:::figure
src: alcohol-dehydration-neopentyl.png
gen: name=2,2-ジメチル-1-プロパノール formula=C5H12O plain
alt: 2,2-ジメチル-1-プロパノールの構造式。中心の炭素にメチル基 CH₃ が3個と、ヒドロキシ基 OH が付いた CH₂ が1個、合わせて4本の結合が出ている
caption: 2,2-ジメチル-1-プロパノール C₅H₁₂O。−OH が付いた炭素の隣（中心の炭素）は、**4本の手がすべて炭素でふさがっていて水素が1個もありません**。抜くものがないので脱水できません。
:::

アルコールの酸化と混同して「第3級アルコールは脱水できない」と誤解することが多いので注意してください。ちなみに、メタノールも2,2-ジメチル-1-プロパノールもどちらも第1級です。

## 例題

:::exercise
source: 本文の対応表（アプリが列挙器から C1〜C5 のアルコール16件を組んだもの）から作った問い。もとにした本はありません
prompt: 2-ブタノールを濃硫酸とともに160〜170℃に加熱した。**(1) 生じるアルケンを構造異性体として2つ書け。(2) そのうち主生成物はどちらか。(3) 主生成物には立体異性体が2つある。優先的に生じるのはどちらか。**
answer: (1) **1-ブテン** CH₂=CHCH₂CH₃ と **2-ブテン** CH₃CH=CHCH₃。−OH が付いた C₂ の隣が C₁ と C₃ の2つあり、どちらから H が抜けるかで行き先が分かれます。(2) 主生成物は **2-ブテン**（ザイツェフ則）。(3) **トランス-2-ブテン**。シス形は立体障害があるぶん不安定です。
:::
