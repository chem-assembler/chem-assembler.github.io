カルボキシ基 −COOH をもつ化合物を**カルボン酸**といいます。カルボキシ基は1個で1価の弱酸としてはたらくので、カルボン酸は酸の単元と有機の単元の両方に顔を出します。

:::section
anchor: class
title: カルボン酸の分け方
lead: 価数・鎖式かどうか・不飽和結合の有無・炭素数・ヒドロキシ基の有無。分類の軸が5つあります。
terms:
- カルボン酸
- カルボキシ基
- 価数
- 脂肪酸
- ヒドロキシ酸
:::

1つの分子内のカルボキシ基 −COOH の数を**カルボン酸の価数**といい、古代ギリシャ語由来の接頭辞を用いて、1価カルボン酸を**モノカルボン酸**、2価カルボン酸を**ジカルボン酸**といいます。酢酸 CH₃COOH は −COOH を1個もつのでモノカルボン酸、シュウ酸 (COOH)₂ は2個もつのでジカルボン酸です。

鎖式の1価カルボン酸を**脂肪酸**といいます。

炭化水素基がすべて単結合の脂肪酸を**飽和脂肪酸**、不飽和結合（C=C や C≡C）をふくむ脂肪酸を**不飽和脂肪酸**といいます。

C原子の数が多い脂肪酸を**高級脂肪酸**、少ない脂肪酸を**低級脂肪酸**といいます。

ヒドロキシ基 −OH をふくむカルボン酸を**ヒドロキシ酸**といいます。乳酸 CH₃CH(OH)COOH は −OH と −COOH を合わせもつので、ヒドロキシ酸です。

**この5つの分け方の名前は、どれも覚えてください。**軸が別なので、1つの化合物に2つ以上の名前が同時に付きます。たとえばオレイン酸は「鎖式の1価カルボン酸」で「C=C をもつ」「C原子が18個ある」ので、**高級不飽和脂肪酸**と呼ばれます。この重ね方が読めれば、油脂の単元で出てくる長い呼び名はその場で分解できます。

to: fat
text: 高級脂肪酸が3つ集まってできる油脂のページへ
:::

:::section
anchor: props
title: カルボン酸の性質
lead: 一般式・水への溶けやすさ・沸点・酸の強さ。カルボン酸はエステルと同じ一般式をもちます。
terms:
- 一般式
- 構造異性体
- 二量体
- 弱酸
:::

鎖式で不飽和結合をもたないカルボン酸の一般式は **C~n~H~2n~O~2~** です。n = 2 を代入すると C₂H₄O₂ ＝ 酢酸 CH₃COOH の分子式が得られます。

エステルも同じ一般式 C~n~H~2n~O~2~ をもつので、**同じ分子式のカルボン酸とエステルは互いに構造異性体**です。C₂H₄O₂ なら酢酸とギ酸メチル HCOOCH₃ が、この関係にあたります。

カルボキシ基は極性が強いうえに電離するので、炭素数4のカルボン酸まではある程度水に溶けます。炭素数5以上のモノカルボン酸はほとんど水に溶けません。

**「アルコール・アルデヒド・ケトン・カルボン酸は、どれも炭素数4まで水に溶ける」と覚えましょう。**官能基ごとに別々の境界を覚える必要はありません。

//スライド 3-5 s3 の本文と読み上げ原稿は、ここを「炭素数4のブタナール（ブチルアルデヒド）まで」と書いていますが、カルボン酸の話なので炭素数4は酪酸（ブタン酸）のはずです。アルデヒドの回の言い回しが残ったものと見て、ここでは「炭素数4のカルボン酸まで」と書きました。スライド側を直すかどうかは校正時に判断してください。

カルボン酸は2分子が水素結合で会合して**二量体**をつくるので、同じ分子量のアルコールよりも沸点が高くなります。二量体は分子量が2倍の1個の分子として振る舞うためです。

:::figure
src: carboxylic-dimer.png
alt: 酢酸2分子が向かい合って環をつくった二量体の構造式。一方の O−H の H と他方の C=O の O が点線の水素結合で結ばれ、それぞれに δ＋ と δ− が書き添えられている
caption: 酢酸の**二量体**。O−H の H（δ＋）と、相手の C=O の O（δ−）が向かい合って、**水素結合が2本**できています。
:::

**この二量体の構造式は、書けるようにしておきましょう。**書かせる問題がよく登場します。カルボキシ基を向かい合わせて、水素結合を2本引くだけです。

二量体は1個の分子として振る舞うので、凝固点降下度を測ると、どれだけの割合が会合しているか（**会合度**）が求められます。計算問題としてよく登場します。

カルボキシ基は**1価の弱酸**としてはたらき、塩基と中和して塩をつくります。

:::callout
tone: memorize
text: **カルボン酸は、炭酸 H₂CO₃ より強い酸です。**この1行が次の節の遊離反応をすべて決めるので、丸暗記してください。
:::

カルボン酸の名前は、対応するアルカンの語尾に「酸」を付け加えるのが IUPAC 命名法です。メタンからは「メタン酸」、エタンからは「エタン酸」となります。ただし高校化学でこの名前を見かけることはまずないので、**慣用名のほうを覚えます**。メタン酸がギ酸、エタン酸が酢酸、プロパン酸がプロピオン酸です。

**ギ酸と酢酸は必ず覚えてください。**プロピオン酸から先は、慣用名を覚えていないと解けない問題はかなりレアなので、名前を見て「カルボン酸の仲間だ」と分かれば十分です。

**酢酸の融点17℃は覚えておくとよい数値です。**「ジエチルエーテルの沸点34℃の半分」と関連付けておくと、2つまとめて思い出せます。

## ギ酸だけは還元性を示す

ギ酸 HCOOH は、見方を変えるとホルミル基 −CHO をもっています。だからカルボン酸でありながら、アルデヒドと同じように**還元性**を示し、銀鏡反応を示します。

:::figure
src: carboxylic-formic-formyl.png
alt: ギ酸の構造式 H−C(=O)−OH。左側の H−C=O の部分だけが橙色の角丸で塗られ、その左に「ホルミル基」と書かれている
caption: ギ酸 HCOOH を切り分けると、**H−C=O** ＝ ホルミル基がそのまま入っています。残りの −OH と合わせるとカルボキシ基です。
:::

- **マレイン酸** | CH(COOH)=CH(COOH) | **シス**形。加熱すると分子内脱水して無水マレイン酸になる。分子内でも水素結合するので融点が低い
- **フマル酸** | CH(COOH)=CH(COOH) | **トランス**形。分子間でしか水素結合しないので融点が高い
- **乳酸** | CH₃CH(OH)COOH | ヒドロキシ酸。不斉炭素原子を1個もつので鏡像異性体がある

## 「還元性」という言葉が2つのものを指している

シュウ酸とギ酸は、どちらも「還元剤としてはたらく」のに、**銀鏡反応を示すのはギ酸だけ**です。同じ「還元性」という言葉が、別のものを指しています。

ギ酸が示す還元性は**ホルミル基によるもの**なので、銀鏡反応もフェーリング液の還元も示します。シュウ酸にはホルミル基がないので、**過マンガン酸カリウムの滴定で2価の還元剤としてはたらく**一方で、**銀鏡反応は示しません**。

//ここに「ギ酸／シュウ酸」を2列で見比べる小さな表を入れたい、という注文です（ホルミル基の有無・銀鏡反応・還元剤としてのはたらき、の3行）。いまは本文で書き分けてあります。

**「還元性を示す物質は、アルデヒドとギ酸とギ酸エステル」と覚えましょう。**シュウ酸をこの仲間に入れないことが、この3つを覚える理由です。

:::callout
tone: caution
text: ギ酸は銀鏡反応を示しますが、フェーリング反応はほとんど示しません。ただし**「ギ酸は還元性を示す」＝「ギ酸はフェーリング反応を示す」として答えないと解けない問題が出題される**ことがあるので、答案では還元性を示す側に立って構いません。
:::

## マレイン酸とフマル酸は融点が違う

シス形のマレイン酸は2つのカルボキシ基 −COOH の位置が近く、**分子内でも水素結合をつくります**。分子内で使われたぶん分子どうしを結びつける力が弱くなるので、融点が低くなります。トランス形のフマル酸は分子間でしか水素結合しないので、融点が高くなります。

:::figure
src: maleic-fumaric-hbond.png
alt: マレイン酸とフマル酸の構造式を並べた図。マレイン酸は2つのカルボキシ基が同じ側にあり、分子内の O−H と O が緑の点線で結ばれている。フマル酸は2つのカルボキシ基が反対側にあり、外へ向かう橙色の点線だけが描かれている
caption: 左の**マレイン酸**（シス形）は**分子内**で水素結合をつくれます。右の**フマル酸**（トランス形）は**分子間**でしか結べません。
:::

## 酒石酸は不斉炭素原子を2個もつ（発展）

酒石酸は不斉炭素原子を2個もちますが、分子内に対称面をもつ**メソ化合物**があるため、立体異性体は 2×2 − 1 = 3 種類になります。**メソ化合物まで覚える必要はありません。**酒石酸という名前と、フェーリング液の材料であることが分かれば十分です。

//「立体異性体は全部で 2×2－1 = 4 種類」と読み上げ原稿にありますが、メソ体を1つ引くと3種類です（4は数え方が別の可能性があります）。校正のときに確かめてください。

:::section
anchor: liberation
title: 弱酸の遊離 —— 炭酸より強いことが効いてくる
lead: 「強酸 ＞ カルボン酸 ＞ 炭酸」の順番だけで、3本の反応式が決まります。
terms:
- 弱酸の遊離
- 炭酸水素ナトリウム
:::

弱酸の遊離は、**相対的に強い酸が塩から弱い酸を追い出す**反応です。だから覚えるのは酸の強さの順番だけで足ります。

**「強酸 ＞ R−COOH ＞ H₂CO₃」の順番は必ず暗記してください。**カルボン酸は塩酸・硫酸・硝酸などの強酸に比べれば弱い酸ですが、炭酸よりは強い酸です。

この順番から、次の3本が出てきます。

:::reaction
left: Na₂CO₃ ＋ 2CH₃COOH
right: 2CH₃COONa ＋ H₂O ＋ CO₂↑
level: ★★★
note: 炭酸ナトリウムは「弱酸と強塩基の塩」。そこへ強いほうの酢酸を加えると、弱いほうの炭酸が追い出されます。遊離した炭酸は溶けきれずに二酸化炭素として出ていきます。
:::

:::reaction
left: NaHCO₃ ＋ CH₃COOH
right: CH₃COONa ＋ H₂O ＋ CO₂↑
level: ★★★
note: 炭酸水素ナトリウムでも同じことが起こります。係数がすべて 1 になるので、こちらのほうが書きやすいです。
:::

:::reaction
left: CH₃COONa ＋ HCl
right: NaCl ＋ CH₃COOH
level: ★★★
note: 今度はカルボン酸が追い出される側です。塩酸のほうが酢酸より強いので、酢酸が遊離します。
:::

**「カルボン酸を加えると気体が出る」のは、カルボン酸が炭酸より強い酸だからです。**炭酸水素ナトリウム水溶液に入れて二酸化炭素が出るかどうかは、カルボン酸を見分ける手がかりとしてよく登場します。

:::section
anchor: anhydride
title: 酸無水物 —— カルボキシ基から水がとれる
lead: 2つのカルボキシ基から水1分子がとれると酸無水物になります。1分子の中で起こるか、2分子の間で起こるかの2通りです。
terms:
- 酸無水物
- 無水マレイン酸
- 無水酢酸
- 分子内脱水
:::

カルボン酸のカルボキシ基2個から水1分子がとれて縮合したものを**酸無水物**といいます。とれかたは2通りあって、**1つの分子の中で起こる場合（分子内脱水）**と、**2つの分子の間で起こる場合（分子間の脱水縮合）**に分かれます。

シス形のマレイン酸を加熱すると、2つのカルボキシ基が近いところにあるので、**分子内脱水**して無水マレイン酸になります。

:::reaction
left: マレイン酸
over: 加熱
right: 無水マレイン酸 ＋ H₂O
level: ★★★
note: 逆向きにも進む反応で、無水マレイン酸は加水分解するとマレイン酸にもどります。
:::

:::figure
src: maleic-anhydride.png
alt: マレイン酸が加熱によって五員環の無水マレイン酸と水になる反応の構造式。左のマレイン酸の2つのカルボキシ基の OH と HO が橙色の枠で囲まれ、そこから伸びる矢印が右端の H₂O を指している
caption: 向かい合った **OH と HO** から水1分子がとれて、五員環の**無水マレイン酸**ができます。
:::

**この反応は、マレイン酸とフマル酸を見分ける条件として頻出です。**トランス形のフマル酸は2つのカルボキシ基が離れているので、加熱しても分子内脱水は起こりません。「加熱すると分子内脱水した」とあればシス形、と読み取ってください。

酢酸は脱水剤（十酸化四リン P₄O₁₀ など）とともに加熱すると、**2分子の間で**脱水縮合して無水酢酸になります。

:::reaction
left: 2CH₃COOH
under: 脱水剤・加熱
right: (CH₃CO)₂O ＋ H₂O
level: ★★★
note: これも逆向きに進み、無水酢酸は加水分解して酢酸にもどります。
:::

:::figure
src: acetic-anhydride.png
alt: 酢酸2分子が脱水縮合して無水酢酸と水になる反応の構造式。左の2分子の O−H の部分が橙色の枠で囲まれ、矢印が右端の H₂O を指している
caption: 上の分子からは **H** だけ、下の分子からは **O−H** がとれて、合わせて水1分子になります。
:::

無水酢酸はカルボキシ基をもたないので、**酸性を示しません**。水に溶けにくい無色の液体で、水とは徐々に反応して酢酸にもどります。名前に「酸」が入っているのに酸性を示さないところが問われます。

prompt: 次の化学反応式を書け。**(1) マレイン酸を加熱した　(2) 酢酸を脱水剤とともに加熱した**
answer: (1) マレイン酸 → 無水マレイン酸 ＋ H₂O（分子内脱水。C₄H₄O₄ → C₄H₂O₃ ＋ H₂O）　(2) 2CH₃COOH → (CH₃CO)₂O ＋ H₂O（分子間の脱水縮合）　どちらも「カルボキシ基2個から水1分子」がとれる点は同じで、それが1分子の中で起こるか2分子の間で起こるかだけが違います。
