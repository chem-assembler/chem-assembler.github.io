化学反応式のページで、係数は「原子の数がそろうように」決めました。係数は分子の個数の比でもあり、mol は数の単位なので、**係数の比はそのまま mol の比**になります。このページでは、反応式から反応する量・できる量を求めます。計算の道具は、物質量のページの比例式と、反応前・変化量・反応後の3行の表の2つだけです。

:::section
anchor: ratio
title: 係数の比 ＝ 分子の数の比 ＝ mol の比
lead: 反応式の係数の比は、反応する分子の数の比であり、物質量の比です。同温・同圧の気体なら体積の比にもなります。ただし質量の比にはなりません。
:::

水素の燃焼 2H₂ ＋ O₂ → 2H₂O を例に、係数が何の比を表しているかを並べます。

:::table
caption: 2H₂ ＋ O₂ → 2H₂O の係数が表すもの（H＝1.0、O＝16）
source: このページのために作った
head:
- 何の比か
- 2H₂
- O₂
- 2H₂O
- 係数の比か
align: left | right | right | right | left
rows:
- 分子の数 | 2個 | 1個 | 2個 | ○ 係数の比
- 物質量 | 2mol | 1mol | 2mol | ○ 係数の比
- 質量 | 4g | 32g | 36g | × 係数の比ではない（左辺の合計 ＝ 右辺）
- 気体の体積（標準状態） | 44.8L | 22.4L | ——（水は液体） | ○ 気体どうしなら係数の比
:::

**係数の比は「数」の比**です。mol は数の単位なので mol の比にもなり、同じ温度・圧力の気体は同じ体積に同じ数の分子を含むので、体積の比にもなります。一方、分子1個の重さは物質ごとに違うので、**質量の比にはなりません**。質量で言えるのは「左辺の合計 ＝ 右辺の合計」（質量保存の法則）だけです。

:::mistake
wrong: 2H₂ ＋ O₂ → 2H₂O なので、水素 2g と酸素 1g が反応する
right: 係数の比 2 : 1 は **mol の比**です。水素 2mol（4g）と酸素 1mol（32g）が反応します。質量で問われたら、必ず一度 mol に直します。
why: 反応式の数字を、問題で与えられた単位（g）のまま読んでしまうためです。★ 「係数の比は mol の比」と、主語を mol にして唱えましょう。
:::

:::section
anchor: three-rows
title: 3行の表 —— 変化量は「係数 × 倍率」
lead: 反応式の下に、反応前・変化量・反応後の3行の表を書きます。変化量の行は、係数に同じ倍率 x を掛けたものです。反応物は減り（−）、生成物は増えます（＋）。
terms:
- 反応前
- 変化量
- 反応後
:::

反応の量の計算は、反応式の下に**3行の表**を書いて進めます。

:::list
ordered: true
items:
- 反応式を書き、その下に「反応前」「変化量」「反応後」の3行をつくる。
- 反応前の行に、与えられた量を mol で入れる。
- 変化量の行は「**係数 × 倍率 x**」。反応物は − ○○x、生成物は ＋ ○○x。
　倍率 x は「反応が何回ぶん進んだか」です。
- 反応後 ＝ 反応前 ＋ 変化量。
:::

具体例1で、メタン CH₄ 0.50mol が完全燃焼したときにできる水の物質量を求めます（酸素は十分にある）。

:::table
caption: CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O（CH₄ 0.50mol が燃える・倍率 x ＝ 0.50）
source: このページのために作った（ratio の stoich の r2 と同じ反応と数値）
head:
- 項目
- CH₄
- 2O₂
- CO₂
- 2H₂O
align: left | right | right | right | right
rows:
- 反応前 | 0.50 | 十分 | 0 | 0
- 変化量 | −0.50 | −1.0 | ＋0.50 | ＋1.0
- 反応後 | 0 | —— | 0.50 | 1.0
:::

CH₄ の係数は 1 なので、0.50mol 燃えたなら倍率 x ＝ 0.50 です。**同じ倍率がすべての物質にかかる**ので、H₂O は 2 × 0.50 ＝ 1.0mol できます（単位はすべて mol）。

★ これは物質量のページの「倍率で解く比例式」と同じことです。CH₄ 1mol : H₂O 2mol ＝ CH₄ 0.50mol : H₂O □mol の比例式を、全部の物質について一度に書いたのが3行の表です。

:::section
anchor: units
title: g や L で与えられたら —— まず mol にそろえる
lead: 反応前の量が g や L で与えられたら、表に入れる前に mol に直します。答えを g や L で問われたら、最後に mol から戻します。
:::

3行の表の中は、**必ず mol で書きます**（気体どうしの例外は下の節）。流れは「g・L → mol → 3行の表 → mol → g・L」の3段です。

具体例2で、炭酸カルシウム CaCO₃（式量 100）25g に十分な量の塩酸を加えたとき、発生する二酸化炭素の標準状態での体積を求めます。

:::list
ordered: true
items:
- mol にそろえる：CaCO₃ 1mol : 100g ＝ □mol : 25g で、0.25mol。
- 3行の表：CaCO₃ ＋ 2HCl → CaCl₂ ＋ H₂O ＋ CO₂。CaCO₃ の係数は 1 なので x ＝ 0.25、CO₂ は ＋0.25mol。
- 単位を戻す：CO₂ 1mol : 22.4L ＝ 0.25mol : □L で、5.6L。
:::

:::section
anchor: limiting
title: 過不足 —— 「mol ÷ 係数」の小さい方で止まる
lead: 反応物が2つとも量で与えられたら、それぞれ「mol ÷ 係数」を出します。小さい方の値が倍率 x になり、その物質がなくなったところで反応は止まります。
terms:
- 過不足
:::

反応物が2つとも与えられたときは、どちらかが先になくなり、もう一方が余ります。どちらが先になくなるかは、**それぞれ「自分だけなら何回ぶん反応できるか」＝ mol ÷ 係数**を比べて決めます。**小さい方で反応は止まり**、その値が倍率 x です。

具体例3で、水素 0.30mol と酸素 0.10mol を反応させます。

:::list
ordered: true
items:
- H₂ は 0.30 ÷ 2 ＝ 0.15、O₂ は 0.10 ÷ 1 ＝ 0.10。
- 小さいのは O₂ の 0.10。倍率は x ＝ 0.10 で、O₂ が先になくなる。
- 3行の表を埋める。
:::

:::table
caption: 2H₂ ＋ O₂ → 2H₂O（H₂ 0.30mol・O₂ 0.10mol・倍率 x ＝ 0.10）
source: このページのために作った（ratio の stoich の r5 と同じ反応と数値）
head:
- 項目
- 2H₂
- O₂
- 2H₂O
align: left | right | right | right
rows:
- 反応前 | 0.30 | 0.10 | 0
- 変化量 | −0.20 | −0.10 | ＋0.20
- 反応後 | 0.10（余り） | 0 | 0.20
:::

H₂O は 0.20mol でき、H₂ が 0.10mol 余ります（単位はすべて mol）。

:::mistake
wrong: 窒素 0.20mol と水素 0.30mol を反応させると、量の多い水素が余る
right: N₂ ＋ 3H₂ → 2NH₃ では、N₂ は 0.20 ÷ 1 ＝ 0.20、H₂ は 0.30 ÷ 3 ＝ 0.10 で、**先になくなるのは水素**です。倍率 x ＝ 0.10 で、NH₃ は 0.20mol でき、N₂ が 0.10mol 余ります。
why: mol の大きさだけを比べて、係数で割るのを忘れるためです。★ 比べるのは mol そのものではなく「mol ÷ 係数」です。係数が 1 : 1 のときだけ、多い方が余ります。
:::

:::section
anchor: gas
title: 気体どうしは体積のまま計算できる
lead: 同じ温度・圧力の気体どうしなら、係数の比は体積の比です。22.4 で割って掛け直さず、L のまま3行の表を書けます。同じ容器の中なら、圧力〔Pa〕のままでも書けます。
:::

同温・同圧の気体は、同じ体積に同じ数の分子を含みます。だから**気体どうしの反応では、係数の比 ＝ 体積の比**です。問われている量も気体なら、mol に直さず **L のまま**3行の表を書けます。

具体例4で、同温・同圧で窒素 2.0L と水素 3.0L を反応させたときにできるアンモニアの体積を求めます。N₂ は 2.0 ÷ 1 ＝ 2.0、H₂ は 3.0 ÷ 3 ＝ 1.0 なので、水素が先になくなり、倍率 x ＝ 1.0（L）。NH₃ は 2 × 1.0 ＝ 2.0L できます。

:::link
app: ratio/stoich
id: r15
text: 窒素と水素の反応を、体積のまま解いてみよう
:::

⚠ ただし、**水のように反応後に液体になる物質の量を問われたら、L は使えません**。そのときは mol を経由します。

同じ容器の中（温度と体積が共通）で反応させるときは、**圧力が mol に比例する**ので、3行の表を圧力〔Pa〕のまま書けます。容器に O₂ 1.0×10⁵Pa と H₂ 0.8×10⁵Pa ぶんを入れて燃やすなら、H₂ 0.8 ÷ 2 ＝ 0.4 と O₂ 1.0 ÷ 1 ＝ 1.0 を比べて x ＝ 0.4、反応後は O₂ 0.6×10⁵Pa、H₂O 0.8×10⁵Pa（すべて気体と仮定したとき）です。水蒸気がどこまで気体でいられるかは、水蒸気を含む気体のページで扱います。

:::section
anchor: range
title: 覚える範囲
lead: 「係数の比は mol の比」「変化量は係数 × 倍率」「過不足は mol ÷ 係数の小さい方」の3つを覚えれば、量的関係の問題はすべてこの3行の表で解けます。
:::

**「係数の比 ＝ mol の比（質量の比ではない）」と「過不足は mol ÷ 係数の小さい方で止まる」の2つは必ず覚えてください。**

3行の表は、化学のあとの単元でも同じ形で何度も使います。化学平衡（平衡に達したときの量）・電離平衡（電離度）・気体の反応（圧力で書く表）は、どれも「反応前・変化量・反応後」の3行です。**ここで3行の表を書く習慣をつけておくと、あとが楽になります。**

量の少ない問題なら、表を書かずに比例式1本で解いても構いません。ただし過不足がある問題だけは、必ず表を書いて「何が余るか」を目で確かめましょう。

## 例題

:::exercise
source: このページのために作った（ratio の stoich の r10 と同じ反応と数値）
prompt: メタン CH₄ 0.50mol を完全燃焼させたとき、生成する水の質量は何 g か（H＝1.0、O＝16）。有効数字2桁で答えよ。
answer: 18g。CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O で、CH₄ の係数 1 から倍率 x ＝ 0.50。H₂O は 2 × 0.50 ＝ 1.0mol。H₂O 1mol : 18g なので 18g。
:::

:::exercise
source: このページのために作った（ratio の stoich の r13 と同じ反応と数値）
prompt: 水素 0.60g と酸素 3.2g を反応させた。生成する水は何 g か（H＝1.0、O＝16）。有効数字2桁で答えよ。
answer: 3.6g。mol にそろえると H₂ は 0.60 ÷ 2.0 ＝ 0.30mol、O₂ は 3.2 ÷ 32 ＝ 0.10mol。2H₂ ＋ O₂ → 2H₂O で、H₂ 0.30 ÷ 2 ＝ 0.15、O₂ 0.10 ÷ 1 ＝ 0.10 なので O₂ が先になくなり x ＝ 0.10。H₂O は 0.20mol ＝ 0.20 × 18 ＝ 3.6g（H₂ が 0.10mol 余る）。
:::

:::exercise
source: このページのために作った（ratio の stoich の r8 と同じ反応と数値）
prompt: メタン 0.30mol と酸素 0.40mol を反応させた。反応後に残るメタンは何 mol か。有効数字2桁で答えよ。
answer: 0.10mol。CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O で、CH₄ 0.30 ÷ 1 ＝ 0.30、O₂ 0.40 ÷ 2 ＝ 0.20。O₂ が先になくなり x ＝ 0.20。CH₄ は反応前 0.30、変化量 −0.20 で、反応後 0.10mol。
:::

:::exercise
source: このページのために作った（ratio の stoich の r16 と同じ反応と数値）
prompt: 標準状態で 11.2L のメタンを完全燃焼させたとき、生成する水は何 g か（H＝1.0、O＝16）。有効数字2桁で答えよ。
answer: 18g。水の質量を問われているので、L のままでは解けません。CH₄ は 11.2 ÷ 22.4 ＝ 0.50mol。x ＝ 0.50 で H₂O は 1.0mol、18g。
:::

:::exercise
source: このページのために作った（ratio の stoich の r18 と同じ反応と数値）
prompt: 同温・同圧で、メタン 2.0L と酸素 3.0L を混ぜて反応させた。生成する二酸化炭素は何 L か。有効数字2桁で答えよ。
answer: 1.5L。気体どうしなので L のまま解けます。CH₄ 2.0 ÷ 1 ＝ 2.0、O₂ 3.0 ÷ 2 ＝ 1.5 で O₂ が先になくなり x ＝ 1.5。CO₂ は 1 × 1.5 ＝ 1.5L（CH₄ が 0.5L 余る）。
:::
