ベンゼンの置換反応は、どれも**ベンゼン環の H が1個外れて、そこに別の原子・原子団が1個入る**反応です。外れた H は、入ってきた試薬の残りと結びついて、酸か水として出ていきます。

:::section
anchor: three
title: 3つの置換反応
lead: ハロゲン化・ニトロ化・スルホン化。試薬と触媒・条件が違うだけで、反応の形は同じです。
terms:
- ハロゲン化
- ニトロ化
- スルホン化
- 混酸
:::

## ハロゲン化

ベンゼンに**鉄（または塩化鉄(III)）を触媒**にして塩素を作用させると、H が1個 Cl に置き換わって**クロロベンゼン**ができます。

:::reaction
left: C₆H₆ ＋ Cl₂
over: Fe または FeCl₃
right: C₆H₅Cl ＋ HCl
level: ★★★
note: クロロベンゼンと塩化水素ができます。触媒の鉄が要ることが、紫外線での付加反応との分かれ目です。
:::

臭素でも同じように、鉄を触媒にするとブロモベンゼン C₆H₅Br ができます。

## ニトロ化

**濃硝酸と濃硫酸の混合物（混酸）**をベンゼンに加えて約 60℃ に温めると、H が1個ニトロ基 −NO₂ に置き換わって**ニトロベンゼン**ができます。

:::reaction
left: C₆H₆ ＋ HNO₃
over: 濃硫酸
under: 約60℃
right: C₆H₅NO₂ ＋ H₂O
level: ★★★
note: ニトロベンゼンと水ができます。濃硫酸は反応物ではなく、触媒としてはたらきます。
:::

**「混酸」「約 60℃」はそのまま問われる語なので覚えてください。**温度を上げすぎると、ニトロ基が2個入った m-ジニトロベンゼンまで進みます。

## スルホン化

ベンゼンに**濃硫酸**を加えて加熱すると、H が1個スルホ基 −SO₃H に置き換わって**ベンゼンスルホン酸**ができます。

:::reaction
left: C₆H₆ ＋ H₂SO₄
over: 加熱
right: C₆H₅SO₃H ＋ H₂O
level: ★★★
note: ベンゼンスルホン酸と水ができます。ニトロ化と違い、ここでは硫酸そのものが反応物です。
:::

:::mistake
wrong: ニトロ化でもスルホン化でも、濃硫酸は触媒としてはたらく。
right: ニトロ化では濃硫酸は触媒、スルホン化では濃硫酸そのものが反応してスルホ基 −SO₃H になる。
why: どちらも「濃硫酸を使う」とだけ覚えると、役割の違いが抜けます。生成物にS が入っているかどうかで見分けます。
:::

:::section
anchor: nitrobenzene
title: ニトロベンゼン
lead: 淡黄色で水より重い油状の液体。中性の物質で、還元するとアニリンになります。
terms:
- ニトロ基
:::

ニトロベンゼン C₆H₅NO₂ は、**淡黄色で特有のにおいをもつ、水より重い油状の液体**です。水に溶けにくいので、水と混ぜると**下の層**に沈みます。

:::figure
src: benzene-substitution-nitrobenzene.png
gen: name=ニトロベンゼン plain
alt: ニトロベンゼンの構造式。ベンゼン環の炭素1個にニトロ基が結合している
caption: **ニトロベンゼン C₆H₅NO₂**。環の H が1個、ニトロ基 −NO₂ に置き換わっています。
:::

ニトロベンゼンは酸でも塩基でもない**中性の物質**なので、酸や塩基の水溶液を加えても塩をつくりません。**「水より重い」「中性」の2つは、分離の問題で使うので覚えておきましょう。**

:::section
anchor: sulfonic
title: ベンゼンスルホン酸
lead: 水によく溶け、強い酸性を示します。カルボン酸やフェノールよりずっと強い酸です。
terms:
- スルホ基
- 強酸
:::

ベンゼンスルホン酸 C₆H₅SO₃H は、**水によく溶け、水溶液は強い酸性**を示します。スルホ基 −SO₃H はほぼ完全に電離するためです。

:::reaction
left: C₆H₅SO₃H
right: C₆H₅SO₃⁻ ＋ H⁺
level: ★★☆
note: ほぼ完全に電離します。弱酸のカルボン酸や、さらに弱いフェノールとはここが違います。
:::

**芳香族の酸の強さは「スルホン酸 ＞ カルボン酸 ＞ 炭酸 ＞ フェノール」の順です。**スルホン酸だけは強酸として扱う、と押さえてください。

:::section
anchor: orientation
title: 置換基が次の置換の位置を決める
advanced: true
lead: トルエンをニトロ化すると、メチル基から見て o と p の位置に入りやすくなります。これを配向性といいます。
terms:
- 配向性
- 2,4,6-トリニトロトルエン
:::

ベンゼン環にすでに置換基が付いていると、次の置換基がどの位置に入りやすいかが、その置換基によって決まります。これを**配向性**といいます。

たとえば、トルエン C₆H₅CH₃ をニトロ化すると、**o-ニトロトルエンと p-ニトロトルエンが主に**でき、m 体は少ししかできません。メチル基は o と p の位置に次の置換基を呼び込むはたらき（**o,p 配向性**）をもつためです。

:::reaction
left: C₆H₅CH₃ ＋ 3HNO₃
over: 濃硫酸
under: 加熱
right: C₆H₂(CH₃)(NO₂)₃ ＋ 3H₂O
level: ★☆☆
note: 2,4,6-トリニトロトルエン（TNT）ができます。メチル基から見て o・p・o の3か所に入るので、位置番号が 2,4,6 になります。
:::

**配向性をもつ基の一覧は覚えなくて構いません。**「トルエンなら o と p に入る」ことと、TNT という名前が分かれば十分です。フェノールの臭素化で 2,4,6 の位置に入るのも、同じ理由です。

:::figure
src: benzene-substitution-orientation.png
svg: benzene-substitution-orientation.svg
alt: トルエンの環の5か所に o・m・p の印を置き、o と p を赤、m を灰で塗り分けた図
caption: どれもメチル基から見た位置の呼び名です。赤い3か所が埋まると位置番号が 2,4,6 —— **TNT の名前の数字**になります。
:::
