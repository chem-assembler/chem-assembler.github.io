電気分解で変化する物質の量は、流れた電気の量で決まります。このページでは、電流と時間から e⁻ の物質量を出し、反応式の係数を使って生じる物質の量を求めます。回路が2つの電解槽に分かれるときの考え方もここで扱います。

:::section
anchor: charge
title: 電気量とファラデー定数
lead: 1A の電流が1秒流れたときの電気量が 1C です。e⁻ 1mol の電気量は 9.65×10⁴ C で、これをファラデー定数といいます。
terms:
- 電気量
- クーロン
- ファラデー定数
- 電気分解の法則
:::

1A（アンペア）の電流が1s（秒）流れたときの電気量を 1C（クーロン）といいます。電気量は、電流と時間の積で求めます。

**電気量〔C〕＝ 電流〔A〕× 時間〔s〕**（1C ＝ 1A × 1s）

e⁻ 1mol がもつ電気量は 9.65×10⁴ C で、これを**ファラデー定数**といい、F ＝ 9.65×10⁴ C/mol と表します。e⁻ 1個の電気量（電気素量 1.602×10⁻¹⁹ C）に、1mol に含まれる e⁻ の数（アボガドロ数）をかけた値です。

電気分解で変化する物質の量は、流れた電気量に比例します。これを**ファラデーの電気分解の法則**といいます。流れた e⁻ の物質量と電気量は、**e⁻ 1mol : 96500C** の比で比例します。

**ファラデー定数の数値は問題文で与えられるので、暗記しなくてよいです。**「e⁻ 1mol で 96500C」という比の形で使えるようにしておきましょう。

:::section
anchor: steps
title: 計算の手順
lead: 与えられた条件を mol に直し、反応式を書き、「係数の比 ＝ mol の比」で比例式を立てます。
:::

電気分解の計算は、次の順に1段ずつ進めます。

:::list
ordered: true
items:
- 時間を秒に直し、電気量〔C〕を先に出す。
　3分13秒なら、60×3＋13 ＝ 193s。
- 電気量を e⁻ の物質量に直す。
　e⁻ 1mol : 96500C ＝ e⁻ ○○mol : 電気量○○C
- 両極の反応式を書く。
- 反応式の「係数の比 ＝ mol の比」で、求める物質の mol を出す。
- 必要なら質量〔g〕や体積〔L〕に直す。
:::

⚠ 模範解答によくある「これを計算すれば解ける」1本の長い式（5A×(60×3＋13)s÷96500C/mol のような式）は、**計算ミスのもとなので避けます**。秒・電気量・mol を別々の段で出すほうが、どこで間違えたかも見つけやすくなります。

具体例1で、5.00A の電流を3分13秒流したときを計算します。

:::list
ordered: true
items:
- 時間は 60×3＋13 ＝ 193s。
- 電気量は 5.00A × 193s ＝ 965C。
- e⁻ 1mol : 96500C ＝ e⁻ x mol : 965C より、x ＝ 1.00×10⁻² mol。
:::

具体例2で、白金電極で塩化ナトリウム水溶液を 0.200A で48分15秒電気分解したとき、陽極で発生する気体の物質量を求めます。

:::list
ordered: true
items:
- 時間は 60×48＋15 ＝ 2895s ＝ 965×3 s。
　★ 96500 で割ることが分かっているので、965 のまま残して「965×3」と書いておくと後が楽です。
- 電気量は 0.200A × 965×3 s ＝ 965×0.6 C。e⁻ は 965×0.6 ÷ 96500 ＝ 6.00×10⁻³ mol。
- 陽極の反応式は 2Cl⁻ → Cl₂ ＋ 2e⁻。
- e⁻ : Cl₂ ＝ 2 : 1 ＝ 6.00×10⁻³ mol : y mol より、y ＝ 3.00×10⁻³ mol。
:::

:::section
anchor: align
title: 両極の式の e⁻ の係数をそろえる
lead: 陽極と陰極で流れる e⁻ の物質量は等しいので、式の e⁻ の係数をそろえておくと、2本の式にまたがって「係数の比 ＝ mol の比」が使えます。
:::

1つの回路では、陽極と陰極を流れる e⁻ の物質量は等しくなります。そこで、**両極の反応式の e⁻ の係数をそろえておく**と、どちらの式の係数どうしでも比がとれるようになります。

具体例3で、白金電極で硫酸ナトリウム水溶液を電気分解して、両極から気体が合計 33.6mL（標準状態）生じたときの電気量を求めます。

:::list
ordered: true
items:
- 気体の体積を mol に直す。1mol : 22.4L ＝ x mol : 33.6mL より、x ＝ 1.5×10⁻³ mol（1.5mmol）。
- 両極の反応式を書き、陰極の式を2倍して e⁻ を 4e⁻ にそろえる。
　陽極：2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻　陰極：4H₂O ＋ 4e⁻ → 2H₂ ＋ 4OH⁻
- 気体は O₂（係数1）と H₂（係数2）で合わせて係数3、e⁻ は係数4。気体 : e⁻ ＝ 3 : 4 ＝ 1.5mmol : e⁻ より、e⁻ は 2.0mmol。
- e⁻ 1mol : 96500C ＝ 2.0×10⁻³ mol : 電気量 より、電気量は 193C。
:::

⚠ e⁻ の係数をそろえずに、陽極の O₂ の係数1と陰極の H₂ の係数1を足して「2」としてはいけません。そろえていない2本の式では、係数1あたりの mol が違う（陽極は係数1あたり 0.5mmol、陰極は 1.0mmol）ためです。

:::section
anchor: circuit
title: 直列回路と並列回路
lead: 直列回路ではどこでも e⁻ の物質量が等しく、並列回路では分かれた電流の e⁻ の合計が、分かれる前の電流の e⁻ に等しくなります。
terms:
- 直列回路
- 並列回路
:::

電解槽が2つ以上あるとき、まず**どの電極が陽極で、どれが陰極か**を決めます。見分け方は2つあります。

:::list
ordered: true
items:
- 回路全体の e⁻ の流れを追う。電極に e⁻ が流れ込む（還元される）のが陰極、電極から e⁻ が出ていく（酸化される）のが陽極。
- 着目していない電解槽を手で隠す。すると電解槽が1つの電気分解に見えるので、電源の正極側が陽極、負極側が陰極と分かる。
:::

電流が枝分かれせずに1周している回路を**直列回路**といいます。同じ1つの回路なので、**直列回路ではどこでも、流れた e⁻ の物質量と電気量が等しくなります**。電解槽が1つだけの回路も、直列回路の仲間です。

:::figure
src: faraday-series.png
alt: 直列回路の図。電源から出た e⁻ が電解槽Ⅰの陰極に入り、電解槽Ⅰの陽極から電解槽Ⅱの陰極へ、電解槽Ⅱの陽極から電源へもどる。2つの電解槽を e⁻ が1本の道で流れる
caption: 直列回路では、電解槽Ⅰと電解槽Ⅱを同じ e⁻ が1本の道で通ります。**どこでも e⁻ の mol が等しい**のが直列回路です。
:::

電流が途中で枝分かれしている回路を**並列回路**といいます。並列回路では、**分かれた電流 I₁ と I₂ の e⁻ の物質量の合計が、分かれる前（合流したあと）の電流 I の e⁻ の物質量に等しくなります**。電気量でも同じです。

:::figure
src: faraday-parallel.png
alt: 並列回路の図。電源から出た電流 I が分岐して、I₁ が電解槽Ⅰへ、I₂ が電解槽Ⅱへ流れ、合流して I にもどる。右に I ＝ I₁ ＋ I₂ の式と、e⁻ の mol・電気量のどちらでも成り立つという注記
caption: 並列回路では I ＝ I₁ ＋ I₂。**e⁻ の mol でも電気量〔C〕でも、この足し算が成り立ちます**。
:::

**「直列はどこでも等しい」「並列は分かれた2本の合計が全体」の2つは必ず覚えてください。**直列・並列の問題は、この2つのどちらかを使えば、あとは1つの電解槽の計算と同じです。

:::table
caption: 直列回路と並列回路
source: このページの「直列回路と並列回路」の節の本文と図2枚を1枚に並べ直したもの
head:
- 回路
- 電流の道
- e⁻ の物質量（電気量）
align: left | left | left
rows:
- 直列回路 | 枝分かれせずに1周する | どの電解槽でも等しい
- 並列回路 | 途中で I₁ と I₂ に分かれる | I₁ の分と I₂ の分の合計が、分かれる前の I の分に等しい
:::

:::mistake
wrong: 並列回路でも、2つの電解槽には同じ量の e⁻ が流れる
right: 並列回路では、電流 I が I₁ と I₂ に分かれます。**2つの電解槽を流れる e⁻ の mol の合計**が、電源から流れ出た e⁻ の mol です。
why: 電解槽が2つある図をどちらも「つながっている」とだけ見て、直列と同じ扱いにしてしまうためです。★ 枝分かれしている点（分岐）を指で探せば、直列か並列かはすぐに分かります。
:::

:::section
anchor: range
title: 覚える範囲
lead: 電気量 ＝ 電流 × 時間、e⁻ 1mol : 96500C の比、直列・並列の規則を覚え、あとは比例式で解きます。
:::

**「電気量〔C〕＝ 電流〔A〕× 時間〔s〕」と「e⁻ 1mol : 96500C」、直列・並列の2つの規則は必ず覚えてください。**ファラデー定数の数値や電気素量の値は、問題文に書かれるので覚えなくて構いません。

計算は、**与えられた条件を mol に直す → 反応式を書く → 係数の比 ＝ mol の比**の順で進めます。これは電気分解に限らず、化学の計算すべてに共通する下ごしらえです。

## 例題

:::exercise
source: slides:電気分解の基本３「電気量と直列並列」s27〜s32「練習１」（解答は s28〜s32）
prompt: 電解槽Ⅰには硝酸銀水溶液と白金電極A（陽極）・B（陰極）、電解槽Ⅱには硫酸ナトリウム水溶液と銅電極C（陽極）・D（陰極）を入れ、2つを直列につないで電気分解したところ、電極Bの質量が 2.16g 増加した（Ag＝108、Cu＝64）。**(1) 電極A〜Dの反応を、e⁻ を含むイオン反応式で書け。　(2) 電極Cの質量はどのように変化したか。**
answer: (1) A：2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻　B：Ag⁺ ＋ e⁻ → Ag　C：Cu → Cu²⁺ ＋ 2e⁻　D：2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻　(2) 0.64g 減少した。Ag は 2.16 ÷ 108 ＝ 0.020mol。直列回路なので e⁻ の係数を 4e⁻ にそろえると B は 4Ag⁺ ＋ 4e⁻ → 4Ag、C は 2Cu → 2Cu²⁺ ＋ 4e⁻ で、Ag : Cu ＝ 4 : 2 ＝ 0.020mol : 0.010mol。Cu 0.010mol は 0.64g で、電極の Cu が溶けて水溶液中のイオンになったので、電極Cは軽くなります。
:::

:::exercise
source: slides:電気分解の基本３「電気量と直列並列」s33〜s36「練習２」（解答は s34〜s36）
prompt: 電解槽Ⅰには塩化ナトリウム水溶液と電極A（陽極）・B（陰極）、電解槽Ⅱには硫酸銅(Ⅱ)水溶液と電極C（陽極）・D（陰極）を入れ（電極はすべて白金）、2つを並列につないで 3.00A の電流で16分5秒間電気分解したところ、電極Cで標準状態で 112mL の気体が発生した（有効数字2桁）。**(1) 電解槽Ⅱを流れた電気量は何Cか。　(2) 電解槽Ⅰで発生した気体は、標準状態で合計何 mL か。**
answer: (1) 1.9×10³ C。電極Cの反応は 2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻ で、O₂ は 112mL ÷ 22.4L ＝ 5.0mmol。O₂ : e⁻ ＝ 1 : 4 より e⁻ は 20mmol、電気量は 96500 × 0.020 ＝ 1930C。　(2) 2.2×10² mL。回路全体は 3.00A × 965s ＝ 965×3 C で e⁻ 30mmol。並列回路なので、電解槽Ⅰを流れた e⁻ は 30 − 20 ＝ 10mmol。A：2Cl⁻ → Cl₂ ＋ 2e⁻、B：2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ より、Cl₂ も H₂ も 5.0mmol で合計 10mmol。22.4L × 0.010 ＝ 224mL。
:::
