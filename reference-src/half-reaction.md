酸化剤・還元剤それぞれが e⁻ をどう受け渡すかを書いたイオン反応式を「半反応式」といいます。酸化還元反応の反応式は、酸化剤と還元剤の半反応式を書いてから、2本を組み合わせてつくります。

:::link
to: redox-basics
text: 左辺に e⁻ があれば酸化剤、右辺にあれば還元剤（「酸化と還元」）
:::

:::section
anchor: memorize
title: 暗記するものと、手順で出すもの
lead: 反応前後の物質の化学式は暗記、係数は手順で出します。
terms:
- 半反応式
:::

半反応式で**暗記が必要なのは、反応前後の物質の化学式だけ**です。過マンガン酸イオン MnO₄⁻ が酸性で Mn²⁺ になる、ということは覚えるしかありません。

一方、H₂O・H⁺・e⁻ の係数は、**手順どおりに進めれば必ず出ます**。係数まで丸暗記してもよいですが、忘れたときに自分で組み立て直せるようにしておきましょう。

:::section
anchor: method1
title: 書き方その1 —— H₂O → H⁺ → e⁻
lead: O を H₂O で、H を H⁺ で、電荷を e⁻ で合わせます。
terms:
- 書き方その1
:::

過マンガン酸カリウム KMnO₄ の半反応式を、次の4段で書きます。

:::list
ordered: true
items:
- 酸化剤・還元剤の反応前後の物質（暗記）を書く。
　MnO₄⁻ → Mn²⁺
- H₂O で両辺の O 原子の数を合わせる。
　左辺に O 原子が4個あるので、右辺に 4H₂O を加える：MnO₄⁻ → Mn²⁺ ＋ 4H₂O
- H⁺ で両辺の H 原子の数を合わせる。
　右辺に H 原子が8個あるので、左辺に 8H⁺ を加える：MnO₄⁻ ＋ 8H⁺ → Mn²⁺ ＋ 4H₂O
- e⁻ で両辺の電荷を合わせる。
　左辺の電荷は合計 ＋7、右辺は合計 ＋2 なので、左辺に 5e⁻ を加える
:::

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 完成。Mn の酸化数は ＋7 → ＋2 で5減っており、**酸化数の変化と e⁻ の数が対応しています**（Mn⁷⁺ ＋ 5e⁻ → Mn²⁺）。
:::

:::figure
src: half-reaction-method1.png
alt: 過マンガン酸イオンの半反応式を、1 反応前後の物質、2 H₂O で O を合わせる、3 H⁺ で H を合わせる、4 e⁻ で電荷を合わせる の順に書いていく図。最後に Mn の酸化数 ＋7 と ＋2 の差が 5e⁻ に対応していることを矢印で示している
caption: 書き方その1。右の枠は各段で**何を数えてその数にしたか**です。
:::

:::section
anchor: method2
title: 書き方その2 —— 酸化数 → e⁻ → H⁺ → H₂O
lead: 先に酸化数の変化から e⁻ の数を決め、電荷を H⁺ で、O を H₂O で合わせます。
terms:
- 書き方その2
:::

同じ KMnO₄ を、酸化数から書く手順です。

:::list
ordered: true
items:
- 酸化剤・還元剤の反応前後の物質（暗記）を書く。
　MnO₄⁻ → Mn²⁺
- 酸化数が変化する原子の酸化数を書き、変化に合わせて e⁻ を加える。
　Mn は ＋7 から ＋2 へ変化しているので、左辺に 5e⁻ を加える：MnO₄⁻ ＋ 5e⁻ → Mn²⁺
- H⁺ で両辺の電荷を合わせる。
　左辺の電荷は合計 −6、右辺は ＋2 なので、左辺に 8H⁺ を加える：MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺
- H₂O で両辺の O 原子の数を合わせる。
　左辺に O 原子が4個あるので、右辺に 4H₂O を加える：MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺ ＋ 4H₂O
:::

その1とその2は、**同じ式にたどり着きます**。酸化数がすぐ決まる物質ならその2、酸化数がわかりにくい物質（有機化合物など）ならその1が速いでしょう。どちらか一方を確実に書けるようにしておけば十分です。

:::link

:::

:::section
anchor: oxidizers
title: 主な酸化剤の半反応式
lead: 9本。反応前後の物質は必ず暗記します。
terms:
- 酸化剤
- 酸化力のある酸
:::

次の9本は**必ず暗記してください**。表の物質名から、反応後の物質と半反応式が書けるようにしておきましょう。

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 過マンガン酸カリウム KMnO₄（硫酸酸性）。赤紫色の MnO₄⁻ が、淡赤色の Mn²⁺ になります（薄い水溶液ではほぼ無色に見えます）。
:::

:::reaction
left: Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻
right: 2Cr³⁺ ＋ 7H₂O
level: ★★★
note: 二クロム酸カリウム K₂Cr₂O₇（硫酸酸性）。赤橙色の Cr₂O₇²⁻ が、緑色の Cr³⁺ になります。
:::

:::reaction
left: HNO₃ ＋ 3H⁺ ＋ 3e⁻
right: NO↑ ＋ 2H₂O
level: ★★★
note: 希硝酸 HNO₃。無色の NO が発生します。
:::

:::reaction
left: HNO₃ ＋ H⁺ ＋ e⁻
right: NO₂↑ ＋ H₂O
level: ★★★
note: 濃硝酸 HNO₃。赤褐色の NO₂ が発生します。
:::

:::reaction
left: H₂SO₄ ＋ 2H⁺ ＋ 2e⁻
right: SO₂↑ ＋ 2H₂O
level: ★★★
note: 熱濃硫酸 H₂SO₄。**加熱した濃硫酸**だけが酸化剤としてはたらきます。
:::

:::reaction
left: H₂O₂ ＋ 2H⁺ ＋ 2e⁻
right: 2H₂O
level: ★★★
note: 過酸化水素 H₂O₂（酸性）。
:::

:::reaction
left: SO₂ ＋ 4H⁺ ＋ 4e⁻
right: S ＋ 2H₂O
level: ★★★
note: 二酸化硫黄 SO₂。H₂S のような強い還元剤が相手のときだけ酸化剤になります。
:::

:::reaction
left: Cl₂ ＋ 2e⁻
right: 2Cl⁻
level: ★★★
note: ハロゲンの単体（Cl₂ など）。H⁺ も H₂O も出てこない、液性に関係ない式です。
:::

:::reaction
left: I₂ ＋ 2e⁻
right: 2I⁻
level: ★★★
note: ヨウ素 I₂。ハロゲンの単体の中では弱い酸化剤です。
:::

## 酸化力のある酸の、もう1つの書き方

希硝酸・濃硝酸・熱濃硫酸の3つを「酸化力のある酸」といいます。これらは**陰イオン（NO₃⁻・SO₄²⁻）が酸化剤としてはたらく**ので、次のように書いてもかまいません。

:::table
caption: 酸化力のある酸の半反応式（陰イオンで書いた形）
source: スライド 無機の基本１ p.65 の注記（ユーザー自身の著作物）。⚠ 濃硝酸の式はスライドでは右辺が「＋ 2H₂O」で O がつり合わないため、「＋ H₂O」に直した
head:
- 酸
- 半反応式
align: left | left
rows:
- 希硝酸 | NO₃⁻ ＋ 4H⁺ ＋ 3e⁻ → NO ＋ 2H₂O
- 濃硝酸 | NO₃⁻ ＋ 2H⁺ ＋ e⁻ → NO₂ ＋ H₂O
- 熱濃硫酸 | SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻ → SO₂ ＋ 2H₂O
:::

HNO₃ の形の式の両辺に H⁺ を1個足して打ち消すと、NO₃⁻ の形の式になります。どちらで書いても、組み立てた全体の式は同じになります。

次の還元剤も**必ず暗記してください**。

:::reaction
left: H₂C₂O₄
right: 2CO₂↑ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: シュウ酸 H₂C₂O₄（(COOH)₂ とも書く）。
:::

:::reaction
left: Fe²⁺
right: Fe³⁺ ＋ e⁻
level: ★★★
note: 硫酸鉄(Ⅱ) FeSO₄。
:::

:::reaction
left: Sn²⁺
right: Sn⁴⁺ ＋ 2e⁻
level: ★★★
note: 塩化スズ(Ⅱ) SnCl₂。
:::

:::reaction
left: H₂S
right: S ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 硫化水素 H₂S。硫黄が析出して、水溶液が白く濁ります。
:::

:::reaction
left: 2I⁻
right: I₂ ＋ 2e⁻
level: ★★★
note: ヨウ化カリウム KI。生じた I₂ で水溶液が褐色になります。
:::

:::reaction
left: H₂O₂
right: O₂↑ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 過酸化水素 H₂O₂。KMnO₄ のような強い酸化剤が相手のときに還元剤になります。
:::

:::reaction
left: SO₂ ＋ 2H₂O
right: SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻
level: ★★★
note: 二酸化硫黄 SO₂。
:::

:::reaction
left: Na
right: Na⁺ ＋ e⁻
level: ★★★
note: 金属の単体（Na など）。金属の単体はすべて還元剤としてはたらきます。
:::

:::reaction
left: Cu
right: Cu²⁺ ＋ 2e⁻
level: ★★★
note: 銅。Cu⁺ ではなく **Cu²⁺** です。
:::

:::reaction
left: Fe
right: Fe²⁺ ＋ 2e⁻
level: ★★★
note: 鉄。単体の鉄が溶けるときは Fe³⁺ ではなく **Fe²⁺** です。
:::

:::reaction
left: Zn
right: Zn²⁺ ＋ 2e⁻
level: ★★★
note: 亜鉛。
:::

**金属イオンの種類や電荷は暗記**です。Cu は Cu⁺ ではなく Cu²⁺、単体の Fe は Fe³⁺ ではなく Fe²⁺ になります。

:::mistake
wrong: 鉄 Fe が酸に溶けると Fe³⁺ になる
right: 単体の鉄が溶けるときは **Fe²⁺** になります。Fe²⁺ → Fe³⁺ は、それとは別の還元剤の式です。
why: 鉄のイオンには Fe²⁺ と Fe³⁺ の2種類があるので、どちらになるかは反応ごとに覚えるしかありません。単体 Fe → Fe²⁺（金属の単体の式）と、Fe²⁺ → Fe³⁺（硫酸鉄(Ⅱ)の式）は別の行として覚えましょう。
:::

## 酸化剤にも還元剤にもなる物質

**過酸化水素 H₂O₂ と二酸化硫黄 SO₂ は、酸化剤・還元剤どちらとしてもはたらきます**。どちらになるかは相手で決まり、相手が強い酸化剤なら還元剤に、強い還元剤なら酸化剤になります。

:::table
caption: 2つの顔をもつ物質
source: このページの酸化剤・還元剤の節に書いた H₂O₂ と SO₂ の式を1つの表にまとめ直したもの（スライド 無機の基本１ p.65・p.67 の注記）
head:
- 物質
- 酸化剤のとき（酸化数が減る）
- 還元剤のとき（酸化数が増える）
align: left | left | left
rows:
- H₂O₂ | O は −1 → −2（H₂O になる） | O は −1 → 0（O₂ になる）
- SO₂ | S は ＋4 → 0（S になる） | S は ＋4 → ＋6（SO₄²⁻ になる）
:::

H₂O₂ はふつうは酸化剤で、還元剤としてはたらくのは KMnO₄ などの強い酸化剤が相手のときに限られます。SO₂ はふつうは還元剤で、酸化剤としてはたらくのは H₂S が相手のときがほとんどです。

## 例題

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.64-65（練習8）
prompt: 次の酸化剤の半反応式を書け。**(1) 二クロム酸カリウム（硫酸酸性）　(2) 熱濃硫酸　(3) 過酸化水素（硫酸酸性）**
answer: **(1) Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O　(2) H₂SO₄ ＋ 2H⁺ ＋ 2e⁻ → SO₂ ＋ 2H₂O　(3) H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O** です。(1) を書き方その1で書くと、Cr₂O₇²⁻ → 2Cr³⁺ のあと、O が7個なので右辺に 7H₂O、H が14個なので左辺に 14H⁺、電荷が左辺 ＋12・右辺 ＋6 なので左辺に 6e⁻ です。
:::

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.66-67（練習9）
prompt: 次の還元剤の半反応式を書け。**(1) シュウ酸　(2) 二酸化硫黄　(3) 鉄**
answer: **(1) H₂C₂O₄ → 2CO₂ ＋ 2H⁺ ＋ 2e⁻　(2) SO₂ ＋ 2H₂O → SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻　(3) Fe → Fe²⁺ ＋ 2e⁻** です。(2) を書き方その1で書くと、SO₂ → SO₄²⁻ のあと、O が右辺に2個多いので左辺に 2H₂O、H が左辺に4個あるので右辺に 4H⁺、電荷が左辺 0・右辺 ＋2 なので右辺に 2e⁻ です。(3) は Fe³⁺ ではなく Fe²⁺ です。
:::
