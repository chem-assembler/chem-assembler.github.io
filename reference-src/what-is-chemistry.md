化学は、物質が「**何からできているか**」「**どんな性質をもつか**」「**どう変わるか**」を調べ、その理由を**原子**という小さな粒子で説明する学問です。このページでは、化学がどこから出発した学問なのか、原子で考えると何が見えるのか、そして高校の化学がどこまでを扱うのかを見渡します。

:::section
anchor: discipline
title: 化学は「原子」から出発した学問
lead: 化学は「物質をつくる最小の単位は原子である」というところから出発し、知識を土台から順に積み上げていく学問です。
terms:
- 学問体系
- 学問対象
:::

学問には、大きく分けて2つの形があります。1つは、ある出発点から、知識と理解を**順に積み上げていく**形です。ここではこれを**学問体系**とよびます。もう1つは、興味のある**対象**を決めて、それをいろいろな角度から調べていく形です。ここではこれを**学問対象**とよびます。

近代の**化学**は、「**物質をつくる最小の単位は原子である**」というところから出発した学問体系です。**物理**は、「**物体の運動は数式で表せる**」というところから出発した学問体系です。どちらも出発点を土台にして、1段ずつ積み上げていきます。狭く深く学ぶイメージです。

一方、**生物**や**地学**は、生き物や地球という**対象**を決めた学問です。対象に迫るためなら、物理学や化学など、ほかの分野の方法もどんどん使います。広く学ぶイメージです。

:::figure
src: what-is-chemistry-disciplines.png
svg: what-is-chemistry-disciplines.svg
alt: 左右2つの図。左は「学問体系（化学・物理）」で、いちばん下の土台「原子」の上に「原子の結びつき」「物質の性質」「化学反応」の箱が順に積み上がっている。右は「学問対象（生物・地学）」で、中央の「生き物・地球」に、まわりの「物理学」「化学」「数学」「情報」から矢印が向かっている
caption: 化学や物理は、土台から順に積み上げる学問です。生物や地学は、対象にいろいろな分野の方法で迫る学問です。
:::

化学は積み上げの学問なので、土台の「原子」の理解があいまいなまま先へ進むと、上の段がぐらつきます。化学の暗記に苦しむ人も多いですが、その原因の一つは基本的な理解が不十分な状態で膨大な知識をただ暗記しようとしているからです。正しい基礎知識で点と点をつなげて体系的に理解すると、覚える量を驚くほど減らすことができます。

:::callout
tone: note
text: **寄り道 ―― 分野を越えて活躍した研究者**　学問対象の分野では、ほかの分野の専門家が研究の対象を移して、大きな成果を上げてきました。DNA の二重らせん構造を明らかにしたクリックは、もともと物理学を学んだ研究者です。大陸が動くという大陸移動説を唱えたウェゲナーは、気象学者でした。対象が決まっている学問では、どの分野の方法でも役に立つのです。
:::

:::section
anchor: substance
title: 物質を原子で見る
lead: 化学が見るのは、ものの形ではなく、ものをつくっている材料（物質）です。物質はすべて原子が結びついてでき、性質の違いは原子の種類とつながり方の違いから生まれます。
terms:
- 物質
- 物体
- 原子
- 元素
- 分子
- イオン
:::

コップを考えてみましょう。ガラスのコップもプラスチックのコップも、形と使い道は同じ「コップ」です。形や使い道に注目したときのものを**物体**、それをつくっている材料そのものを**物質**といいます。化学が見るのは物質のほうです。

物質は、すべて**原子**が結びついてできています。原子の種類を**元素**といい、周期表に並ぶ約118種類しかありません。それでも物質の種類が数えきれないほどあるのは、**同じ原子でも、組み合わせ方とつながり方が違えば、別の物質になる**からです。原子がいくつか結びついたまとまりを**分子**、電子を失ったり受け取ったりして電気を帯びた原子（や原子のまとまり）を**イオン**といいます。

たとえば、**黒鉛**（鉛筆の芯）と**ダイヤモンド**は、どちらも炭素原子だけでできています。それでも、黒鉛は黒くて軟らかく電気を通し、ダイヤモンドは無色透明でとても硬く、電気を通しません。違うのは、炭素原子どうしのつながり方だけです。

分子でも同じことが起こります。下の2つは、どちらも炭素C2個・水素H6個・酸素O1個からできていますが、酸素原子の位置が違います。

:::figure
src: what-is-chemistry-c2h6o.png
gen: name=エタノール plain paper expand=H
gen: name=ジメチルエーテル plain paper expand=H
alt: 左にエタノール、右にジメチルエーテルの構造式を並べた図。どちらも炭素C2個・酸素O1個・水素H6個からなるが、エタノールは O が端にあって H と結合し、ジメチルエーテルは O が2つの炭素の間にある
caption: 左がエタノール（常温で液体）、右がジメチルエーテル（常温で気体）。**原子の種類と数は同じ**でも、つながり方が違えば別の物質です。
:::

このように化学では、物質を「**何の原子が・いくつ・どうつながっているか**」で見分けます。色・硬さ・溶けやすさといった性質も、この原子の姿に戻して説明していきます。

:::section
anchor: change
title: 変化は原子の組みかえ
lead: 化学反応では、原子そのものは消えも生まれもせず、物質の間で原子が組みかわります。だから、反応の前と後で質量が変わりません。
terms:
- 状態変化
- 化学変化
- 化学反応
- 質量保存の法則
:::

氷がとけて水になり、水が蒸発して水蒸気になっても、そこにあるのはどれも水の分子 H₂O です。変わったのは、分子どうしの集まり方だけです。このような変化を**状態変化**といいます。

一方、水素と酸素を反応させると水ができます。反応の前には H₂ と O₂ の分子があり、反応のあとには H₂O の分子があります。**原子の組み合わせが変わって、別の物質ができた**のです。このような変化を**化学変化**（**化学反応**）といいます。

:::figure
src: what-is-chemistry-rearrange.png
svg: what-is-chemistry-rearrange.svg
alt: 左の「反応の前」の枠に、H が2個ずつつながった水素分子が2つと、O が2個つながった酸素分子が1つある。矢印の右の「反応の後」の枠には、O に H が2個ついた水分子が2つある。どちらの枠の下にも「H 原子 4個・O 原子 2個」と書いてある
caption: 2H₂ ＋ O₂ → 2H₂O。反応の前も後も、H 原子は4個、O 原子は2個です。変わったのは原子の組み合わせだけです。
:::

中学校で学んだ**質量保存の法則**（化学反応の前後で、物質全体の質量は変わらない）は、ここから理解できます。反応の前後で**原子の種類と数が変わらない**のだから、原子の質量の合計も変わりません。化学反応式で左右の原子の数をそろえるのも、このためです。

:::callout
tone: note
text: **寄り道 ―― 錬金術の夢**　物質の研究は、中世には**錬金術**が担っていました。錬金術師たちは、鉛のような金以外の金属から金をつくろうと、長いあいだ実験を重ねました。これらの試みがうまくいかなかった理由は、高校化学で学習する原子の性質を理解していれば説明できます。化学反応で変わるのは原子の組み合わせだけで、**原子の種類（元素）そのものは変わらない**からです。現在では、核融合や核分裂のように原子核そのものを変える反応を使えば、ほかの元素から金をつくれることが分かっています。ただしそれには、化学反応とは比べものにならないほど大きなエネルギーが必要です。それでも、錬金術のなかで工夫された蒸留などの実験の技術は、のちの化学に受けつがれました。
:::

:::section
anchor: history
title: 原子の考え方は意外と新しい
lead: 物質に最小の単位があるという考えは紀元前からありましたが、近代的な原子の考え方は、19世紀はじめのドルトンの原子説から始まりました。
terms:
- 原子説
:::

物質を細かく分けていくと、それ以上分けられない粒にたどりつく ―― この考えは、紀元前5世紀ごろの古代ギリシャにすでにありました。デモクリトスらは、その粒を「アトモス」（それ以上分けられないもの）とよびました。原子（アトム）という言葉のもとです。

ただし、これは実験で確かめられた考えではありませんでした。実験の結果をもとに、「物質は、元素ごとに決まった原子からできている」とする**原子説**を示したのは、19世紀のはじめ（1803年ごろ）のドルトンです。**近代的な原子の考え方には、まだ200年あまりの歴史しかありません。**意外と新しいと思いませんか。

:::figure
src: what-is-chemistry-timeline.png
svg: what-is-chemistry-timeline.svg
alt: 上から下へ時代が進む年表。紀元前5世紀ごろのデモクリトス「アトモス」、中世の錬金術、1774年ごろのラボアジエの質量保存の法則、1803年ごろのドルトンの原子説、1869年のメンデレーエフの周期表、1897年の電子の発見、1913年のボーアの原子モデル、1920年代の量子力学が並ぶ。ラボアジエから電子の発見までの右に「高校化学のおもな範囲（19世紀までの化学）」、ボーアの原子モデルの右に「＋ 高校で使う原子のモデル」の帯がある。間隔は年代に比例していない
caption: 原子の考え方の歩み（間隔は年代に比例していません）。高校の化学は、おもに19世紀までに形づくられた化学に、ボーアの原子モデルを加えて組み立てられています。
:::

高校の化学で学ぶのは、おもに19世紀の終わりまでに形づくられた化学です。原子のつくりについては、20世紀のはじめに示された**ボーアの原子モデル**（原子核のまわりを、電子が決まった道すじで回っているという描き方）を使って考えます。

:::figure
src: what-is-chemistry-bohr.png
svg: what-is-chemistry-bohr.svg
alt: ボーアの原子モデルでナトリウム原子を描いた図。中心に原子核（＋11）があり、そのまわりに同心円の電子殻が3つある。内側から K 殻に電子2個、L 殻に電子8個、M 殻に電子1個が置かれている
caption: ボーアの原子モデル（ナトリウム原子）。原子核のまわりの決まった道すじ（電子殻）に電子が入っていると考えます。いちばん外側の電子が、化学反応で主役になります。
:::

:::section
anchor: beyond-atom
title: 原子より小さな世界
advanced: true
lead: 原子はさらに小さな粒子からできていて、その世界は量子論という考え方で説明されます。高校の化学では、ここには大きく立ち入りません。
terms:
- 素粒子
- 量子論
:::

現在では、原子もさらに小さな粒子に分けられることが分かっています。原子は原子核と電子からでき、原子核の陽子や中性子は、さらに小さなクォークという粒子からできています。このように、それ以上分けられないと考えられている粒子を**素粒子**といいます。素粒子を扱うのは、おもに物理学や、物理学と化学の中間にあたる**物理化学**の分野です。

また、20世紀に入ると、電子のような小さな粒子のふるまいは、ふだん目にする物体とはまったく違う**量子論**という考え方で説明されるようになりました。実際の電子は、ボーアのモデルのように決まった円の上を回っているわけではありません。「シュレーディンガーの猫」や「不確定性原理」という言葉を聞いたことがあるかもしれませんが、これらも量子論の話です。高校で学ぶには難しすぎるので、高校の化学では、ボーアのモデルで説明できる範囲にとどめます。

:::section
anchor: electron
title: 化学反応は電子の奪い合い
lead: 原子核の陽子（＋）は電子（−）を引きつけます。この力をクーロン力といい、化学反応はこの力で説明できます。
terms:
- 原子核
- 電子
- クーロン力
:::

原子の中心には、正の電気をもつ陽子を含む**原子核**があり、そのまわりに負の電気をもつ**電子**があります。正の電気と負の電気は引き合います。この静電気の力を**クーロン力**といいます。

原子どうしが出会うと、電子の引っぱり合いが起こります。**原子の世界は、原子が電子を奪い合っている世界**です。電子を引きつける力の強さは原子の種類（元素）によって違うので、どちらが電子を得るのか、それとも分け合うのかが決まります。

:::figure
src: what-is-chemistry-tug.png
svg: what-is-chemistry-tug.svg
alt: 左右に原子核（＋）が1つずつあり、その間に電子（e⁻）が1個ある。左の原子核へ向かう矢印は細く、右の原子核へ向かう矢印は太い。左は「引きつける力が弱い原子（例：Na）→ 電子を失って陽イオンに」、右は「引きつける力が強い原子（例：Cl）→ 電子を受け取って陰イオンに」と書いてある
caption: 電子の引っぱり合い。引きつける力の強い原子のほうへ、電子が移ります。
:::

たとえばナトリウム Na と塩素 Cl では、電子を引きつける力が強い Cl が Na から電子を1個奪い、Na⁺ と Cl⁻ ができます。高校の化学では、**化学反応はすべてこのクーロン力で説明します**。

だから化学では、まず**原子の種類と性質**（とくに、電子をどれくらい強く引きつけるか）を学び、それをもとに**物質の性質**と**化学反応**を理解していきます。
