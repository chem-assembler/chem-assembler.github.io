分子量がおよそ1万を超える大きな分子を**高分子化合物**といいます。合成高分子は、小さな分子を何百、何千とつなげてつくります。どうつなげたかで3つの型に分かれ、合成樹脂・合成繊維・ゴムのどれを学ぶときもこの型の名前が出てきます。

:::section
anchor: what
title: 単量体と重合体
lead: つなげる前の小さな分子が単量体、つながってできた大きな分子が重合体です。くり返しの1つぶんを繰り返し単位、くり返しの数を重合度といいます。
terms:
- 単量体
- 重合体
- 重合
- 繰り返し単位
- 重合度
:::

高分子をつくるもとになる小さな分子を**単量体（モノマー）**、単量体がたくさんつながってできた大きな分子を**重合体（ポリマー）**といいます。単量体が次々に結合して重合体になる反応を**重合**といいます。

具体例で見ます。エチレン CH₂=CH₂ が数千個つながると、ポリエチレンになります。

:::reaction
left: n CH₂=CH₂
right: ［CH₂−CH₂］ₙ
level: ★★★
note: 左辺の n と、右辺の角かっこの外の n が対応します。
:::

重合体の中でくり返されている1つぶんの構造 ［CH₂−CH₂］ を**繰り返し単位**、くり返しの数 n を**重合度**といいます。ポリエチレンの「ポリ」は「たくさんの」という意味で、「たくさんのエチレン」という名前です。

caption: ポリエチレンの鎖の一部。CH₂−CH₂ の**繰り返し単位が3つ**並んでいて、両端の R の先にも同じ単位が続きます。
:::

:::figure
src: polymer-basics-repeat-unit.png
gen: name=ポリエチレン plain

caption: 囲んだ **CH₂−CH₂ の2個ぶん**が繰り返し単位です。この単位が n 回くり返されて1本の鎖になります。
:::

**単量体・重合体・繰り返し単位・重合度の4語は必ず暗記してください。**以降のページはすべてこの4語で書いてあります。

:::section
anchor: average-mw
title: 重合度と平均分子量
lead: 高分子は重合度の違う分子の混ざりものなので、分子量は平均分子量で表します。平均分子量は、繰り返し単位の式量に重合度をかけたものです。
terms:
- 平均分子量
- 平均重合度
:::

同じポリエチレンでも、つながった数が1000個の分子もあれば1200個の分子もあります。**高分子は重合度の違う分子の混合物**なので、分子量が1つに決まりません。そこで**平均分子量**で表します。

「平均分子量 ＝ 繰り返し単位の式量 × 平均重合度」と覚えましょう。両端の構造は鎖全体に比べてごくわずかなので、ふつうは無視します。

具体例で見ます。ポリエチレンの繰り返し単位 ［CH₂−CH₂］ の式量は 12×2 ＋ 1.0×4 ＝ 28 です。平均分子量が 2.8×10⁴ なら、平均重合度は 28000 ÷ 28 ＝ **1000** になります。

**この式は必ず使えるようにしてください。**高分子の計算問題は、ほとんどがこの形で登場します。

:::section
anchor: end-group
title: 末端基から鎖の本数を数える
advanced: true
lead: 鎖1本あたりの末端基の数は決まっているので、末端基の物質量から鎖の本数が分かり、平均分子量が出せます。
terms:
- 末端基
:::

鎖状の高分子は、**1本の鎖に端が2つ**あります。端にある基（**末端基**）の物質量を滴定などで求めれば、鎖の本数が分かります。

たとえば、両端にカルボキシ基が1個ずつある鎖状の高分子 1.0 g を中和するのに NaOH が 2.0×10⁻⁴ mol 要ったとします。鎖の本数は 1.0×10⁻⁴ mol なので、平均分子量は 1.0 ÷ (1.0×10⁻⁴) ＝ 1.0×10⁴ です。

鎖1本に末端基が何個あるか（両端とも同じ基か、片方だけか）は、**問題文が与えます。**手順も与えられることが多いので、考え方だけ分かっていれば十分でしょう。

:::section
anchor: addition
title: 重合の型① 付加重合
lead: C=C が開いて、そのまま次々につながります。何も出ていかないので、繰り返し単位の組成は単量体と同じです。
terms:
- 付加重合
- ビニル化合物
:::

二重結合 C=C をもつ単量体が、付加反応をくり返してつながる重合を**付加重合**といいます。**つなぐときに何も出ていきません。**

:::reaction
left: n CH₂=CHCl
right: ［CH₂−CHCl］ₙ
level: ★★★
note: 塩化ビニル → ポリ塩化ビニル。原子の出入りがないので、繰り返し単位の分子式は単量体と同じ C₂H₃Cl です。
:::

:::figure
src: polymer-basics-pvc.png
gen: name=ポリ塩化ビニル plain
alt: ポリ塩化ビニルの鎖の一部の構造式。炭素が一列につながり、1個おきの炭素に塩素原子が付き、両端の R から先にも鎖が続くことを示した図
caption: ポリ塩化ビニルの鎖の一部。塩化ビニルの **C=C が単結合に変わって**つながっただけで、1単位あたりの原子の数は塩化ビニルと同じです。
:::
//アプリで: 塩化ビニルを3個並べて反応実行モードの付加重合（addition_polymerization）を押した画面

付加重合の単量体は、エチレンの H を1個別の原子・原子団 X に置きかえた **CH₂=CH−X** の形（ビニル化合物）が大半です。X が −Cl なら「ポリ塩化ビニル」、−CH₃ なら「ポリプロピレン」のように、「ポリ○○」の○○に単量体の名前が入ります。

:::section
anchor: condensation
title: 重合の型② 縮合重合
lead: 1か所つなぐたびに水などの小さな分子がとれます。単量体には、反応できる官能基が1分子に2つずつ要ります。
terms:
- 縮合重合
- ポリエステル
- ポリアミド
:::

単量体どうしが、水などの簡単な分子をとり除きながらつながる重合を**縮合重合**といいます。**「縮合」は小さな分子がとれてつながる、という意味**です。

鎖になるためには、**1つの単量体に反応できる官能基が2つ**要ります。1つしかないと、1回つながったところで止まってしまうためです。

具体例は、テレフタル酸とエチレングリコールからできる**ポリエチレンテレフタラート（PET）**です。

:::reaction
left: n HOOC−C₆H₄−COOH ＋ n HO−CH₂CH₂−OH
right: ［CO−C₆H₄−CO−O−CH₂CH₂−O］ₙ ＋ 2n H₂O
level: ★★★
note: 1か所つなぐごとに水が1個とれます。1つの繰り返し単位の中にエステル結合が2か所あるので、n 組つなぐと水は 2n 個です。
:::
//アプリで: テレフタル酸2個とエチレングリコール2個を並べ、反応実行モードの縮合重合（condensation_polymerization）を押した画面（とれた水が残る）

つながった所にできる結合で名前が付きます。エステル結合でつながったものが**ポリエステル**、アミド結合でつながったものが**ポリアミド**です。

:::section
anchor: ring-opening
title: 重合の型③ 開環重合
lead: 環状の単量体の環が1か所ほどけて、次々につながります。何も出ていかないので、組成は単量体と同じです。
terms:
- 開環重合
- ラクタム
:::

環状の構造をもつ単量体が、環を開きながらつながる重合を**開環重合**といいます。付加重合と同じく、**何も出ていきません。**

具体例は、ε-カプロラクタム C₆H₁₁NO からできる**ナイロン6**です。

:::reaction
left: n C₆H₁₁NO（ε-カプロラクタム）
over: 少量の水
under: 加熱
right: ［NH−(CH₂)₅−CO］ₙ
level: ★★★
note: 環の中のアミド結合が1か所切れて鎖になり、次の分子とつながります。水はきっかけとして働くだけなので、反応式の両辺には出てきません。
:::

terms:
- 付加縮合
:::

:::table
caption: 重合の型

- 型
- 単量体に要るもの
- 出ていくもの
- 代表例
align: left | left | left | left
rows:
- 付加重合 | C=C（二重結合） | **なし** | ポリエチレン・ポリ塩化ビニル・ポリスチレン

- 開環重合 | 環状の構造 | **なし** | ナイロン6
- 付加縮合 | 付加と縮合を交互にくり返せる組み合わせ | **水** | フェノール樹脂・尿素樹脂・メラミン樹脂
:::

**付加・縮合・開環の3つの名前と、「何が出ていくか」は必ず暗記してください。**「付加と開環は何も出ない、縮合は水が出る」と対にして覚えるのが確実です。

付加縮合は、合成樹脂のうち網目になるものだけに出てくる型です。

:::link
to: plastic
text: 付加縮合でできる熱硬化性樹脂（フェノール樹脂・尿素樹脂など）
:::

:::mistake
wrong: ナイロン6 は、ナイロン66 と同じ縮合重合でできる
right: ナイロン6 は**開環重合**でできます。ε-カプロラクタムの環が開くだけで、水はとれません。
why: 「ナイロン＝アミド結合＝縮合」と結合の種類から型を決めてしまうためです。★ 型は結合の種類ではなく「つなぐときに何が出ていくか」で決まります。
:::

:::section
anchor: copolymer
title: 共重合
lead: 2種類以上の単量体をまぜて重合させると、1本の鎖に両方の単位が入った共重合体ができます。混ぜる比で性質を調節できます。
terms:
- 共重合
- 共重合体
:::

2種類以上の単量体を混ぜて重合させることを**共重合**、できた重合体を**共重合体**といいます。**単量体の種類と混ぜる割合を変えることで、材料の硬さや弾性を調節できます。**

具体例は、スチレンと 1,3-ブタジエンからできる**スチレン-ブタジエンゴム（SBR）**です。

:::reaction
left: n CH₂=CH−C₆H₅ ＋ m CH₂=CH−CH=CH₂
right: ［CH₂−CH(C₆H₅)］ₙ［CH₂−CH=CH−CH₂］ₘ
level: ★★☆
note: 2種類の単位が1本の鎖の中に混ざって並びます。式では2つに分けて書きますが、実際にはこの順にかたまって並ぶわけではありません。
:::

:::section
anchor: property
title: 高分子はどんな物質か
lead: 鎖がそろった結晶部分と、乱れた非晶部分が混ざっています。はっきりした融点がなく、加熱するとだんだんやわらかくなります。
terms:
- 結晶部分
- 非晶部分
- 軟化点
- 膨潤
:::

高分子の固体の中では、鎖が規則正しく並んだ**結晶部分**と、鎖が不規則にからみ合った**非晶部分**が混ざっています。

:::figure
src: polymer-basics-crystal-amorphous.png
svg: polymer-basics-crystal-amorphous.svg
alt: 固体の中の高分子の鎖の模式図。左では5本の鎖がそろって並び、右では同じ鎖がうねって交差している
caption: 別々の粒が混ざっているのではなく、**1本の鎖が両方にまたがって**います。次の段落の「一斉に融けない」は、この形から来ます。
:::

高分子は**はっきりした融点を示さず、加熱すると徐々にやわらかくなります。**やわらかくなり始める温度を**軟化点**といいます。分子量の違う分子の混合物で、しかも結晶部分と非晶部分が混ざっているため、ある温度で一斉に融けることがないためです。

結晶部分が多いほど、鎖どうしが密に詰まるので、**硬く、強く、不透明**になります。同じポリエチレンでも、枝分かれが少なく結晶部分の多いものは硬い材料になります。

:::link
to: plastic
text: 結晶部分の多さで硬さが変わる例 —— 高密度ポリエチレンと低密度ポリエチレン
:::

高分子を溶媒に入れると、すぐには溶けず、溶媒の分子がまず鎖のすき間に入り込んで**ふくらみます（膨潤）**。そのあと溶けると、分子1個がコロイド粒子ほどの大きさなので**コロイド溶液**になります。

「融点ではなく軟化点」「溶ける前に膨潤」の2つは覚えておきましょう。**軟化点の具体的な温度は覚えなくて構いません。**

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: qa:org.poly.average-mw（計算の型と数値はこのページで作問した）
prompt: 平均分子量が 1.4×10⁵ のポリ塩化ビニルの平均重合度を求めよ。原子量は H＝1.0、C＝12、Cl＝35.5 とする。
answer: **2240**。繰り返し単位 ［CH₂−CHCl］ の式量は 12×2 ＋ 1.0×3 ＋ 35.5 ＝ 62.5 です。140000 ÷ 62.5 ＝ 2240 になります。
:::

:::exercise
source: qa:org.poly.addition-vs-condensation / org.poly.ring-opening（問いの形はこのページで作問した）
prompt: 次の繰り返し単位をもつ高分子は、それぞれ何重合でできたか。また単量体の名称を答えよ。(1) ［CH₂−CH(CN)］ₙ　(2) ［NH−(CH₂)₅−CO］ₙ
answer: (1) **付加重合**、単量体は**アクリロニトリル** CH₂=CHCN。繰り返し単位の C−C を1本 C=C に戻せば単量体になります。(2) **開環重合**、単量体は **ε-カプロラクタム**。組成が繰り返し単位と同じで、鎖の両端をつなげば環に戻ります。
:::

:::exercise
source: qa:org.poly.addition-vs-condensation（数値はこのページで作問した）
prompt: テレフタル酸とエチレングリコールを縮合重合させ、平均重合度 n ＝ 100 のポリエチレンテレフタラートをつくった。このとき、鎖1本あたり何個の水分子がとれたと考えられるか。鎖の端の構造は無視してよい。
answer: **200個**。繰り返し単位1つの中にエステル結合が2か所あり、1か所つなぐごとに水が1個とれるので、2 × 100 ＝ 200 個です。
:::
