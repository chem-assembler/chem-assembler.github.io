物質量と化学反応式のページでは、「原子の数は反応の前後で変わらない」「同じ温度・圧力の気体は、同じ体積に同じ数の分子を含む」ことを当たり前のように使いました。このページでは、化学者たちがどんな実験の事実から、原子と分子という考えにたどり着いたかをたどります。法則の名前と内容を、流れの中で覚えるのが目標です。

:::section
anchor: mass
title: 質量保存の法則と定比例の法則
lead: 反応の前後で物質の総質量は変わりません（質量保存の法則）。1つの化合物をつくる元素の質量の比は、つくり方によらず一定です（定比例の法則）。
terms:
- 質量保存の法則
- 定比例の法則
- ラボアジエ
- プルースト
:::

「**化学反応の前後で、物質の総質量は変化しない**」。これを**質量保存の法則**といいます（1774年、ラボアジエ）。密閉した容器の中で反応させれば、何が起きても容器全体の質量は変わりません。

「**1つの化合物に含まれる成分元素の質量の比は、つくり方によらず常に一定である**」。これを**定比例の法則**といいます（1799年、プルースト）。

具体例1で、マグネシウムを燃やして酸化マグネシウム MgO をつくる場合を考えます。どの方法でつくった MgO でも、マグネシウムと酸素の質量の比は 24 : 16 ＝ 3 : 2 で一定です。マグネシウム 1.2g が燃えれば酸素 0.8g と結びつき、MgO が 2.0g できます（質量保存の法則）。

:::section
anchor: atom
title: 原子説と倍数比例の法則
lead: ドルトンは、2つの法則を「物質はそれ以上分けられない原子からなる」と考えて説明しました（原子説）。原子説から予言されたのが倍数比例の法則です。
terms:
- 原子説
- ドルトン
- 倍数比例の法則
:::

ドルトンは 1803 年に、次のような**原子説**を唱えました。

:::list
items:
- 物質は、それ以上分けられない粒子（原子）からなる。同じ元素の原子は、同じ質量と大きさをもつ。
- 化合物は、異なる原子が一定の数の割合で結びついたものである。
- 化学変化では原子の組み合わせが変わるだけで、原子が新しく生じたり消えたりしない。
:::

原子が消えないなら総質量は変わらず（質量保存）、化合物の原子の数の割合が決まっているなら質量の比も一定になります（定比例）。**2つの法則が、原子という1つの考えで説明できた**わけです。

原子説からは、次の法則も導かれます。「**2種類の元素 A・B からなる化合物が2種類以上あるとき、一定の質量の A と結びつく B の質量は、化合物どうしで簡単な整数比になる**」。これを**倍数比例の法則**といいます（1803年、ドルトン）。

具体例2で、窒素の酸化物 NO と NO₂ を比べます。窒素 14g と結びつく酸素は、NO では 16g、NO₂ では 32g で、**16 : 32 ＝ 1 : 2** の簡単な整数比です。酸素原子が「1個か2個か」で、半端な数では結びつけないからです。

:::mistake
wrong: NO と NO₂ で、窒素と酸素の質量の比が違うのは、定比例の法則に反している
right: 定比例の法則は「**1つの化合物**の中の質量の比が一定」という法則です。NO と NO₂ は別の化合物なので、比が違ってかまいません。別の化合物どうしを比べて「整数比になる」と言うのが**倍数比例の法則**です。
why: 名前がどちらも「比例」で、どちらも質量の比の話なので、何と何を比べているかが混ざるためです。★ 「定比例は1つの化合物の中、倍数比例は化合物どうし」と区別しましょう。
:::

定比例の法則は「一定組成の法則」、倍数比例の法則は「倍数組成の法則」とも呼ばれます。どちらの名前で出ても同じ法則です。

:::section
anchor: gas
title: 気体反応の法則と、原子説との食い違い
lead: 気体どうしの反応では、反応・生成する気体の体積が簡単な整数比になります（気体反応の法則）。ところが原子説のままだと、この事実を説明しようとすると原子が割れてしまいます。
terms:
- 気体反応の法則
- ゲーリュサック
:::

「**気体どうしが反応するとき、同温・同圧で測った反応・生成する気体の体積は、簡単な整数比になる**」。これを**気体反応の法則**といいます（1808年、ゲーリュサック）。例えば、水素 1 体積と塩素 1 体積から、塩化水素が 2 体積できます。

ここで、「同じ体積には同じ数の**原子**が含まれる」と考えてみます。水素原子 1 個と塩素原子 1 個から、塩化水素の粒子が 2 個できることになり、**1 個の塩化水素の粒子に水素原子が半分ずつ入る**ことになってしまいます。原子はそれ以上分けられないはずなので、原子説と食い違います。

src: chemical-laws-gas-volumes.png

alt: 同じ大きさの箱を並べた図。上の段は原子だけで考えた場合で、水素原子1個と塩素原子1個から2つの箱をつくるため、どちらの箱にも半分に割れた原子が入っている。下の段は分子で考えた場合で、H₂ 1個と Cl₂ 1個から HCl 1個ずつが入った箱が2つできて、割れた粒子は出てこない

:::section
anchor: molecule
title: 分子説とアボガドロの法則
lead: アボガドロは、気体は原子がいくつか結びついた分子からなり、同温・同圧・同体積の気体には同じ数の分子が含まれると考えました。これで気体反応の法則と原子説の食い違いが解けました。
terms:
- 分子説
- アボガドロの法則
- アボガドロ
:::

アボガドロは 1811 年に、「**気体は、いくつかの原子が結びついた分子という粒子からなる**」と考えました。これを**分子説**といいます。

水素と塩素を、原子2個が結びついた分子 H₂・Cl₂ と考えると、H₂ 1 個と Cl₂ 1 個が反応するとき、分子が割れて原子になり、HCl が 2 個できます。**割れるのは分子で、原子は割れない**ので、原子説と食い違いません。

:::reaction
left: H₂ ＋ Cl₂
right: 2HCl
level: ★★★
note: 1体積 ＋ 1体積 → 2体積。係数の比 1 : 1 : 2 が、そのまま気体の体積の比になっています。
:::

あわせて、「**同温・同圧・同体積の気体には、気体の種類によらず同じ数の分子が含まれる**」とも考えました。これを**アボガドロの法則**といいます。気体の 1mol が気体の種類によらず標準状態で 22.4L になるのも、気体どうしの反応で係数の比が体積の比になるのも、この法則のおかげです。

:::section
anchor: range
title: 覚える範囲
lead: 5つの法則と2つの説の、名前・中身・人名の対応を覚えます。年号は覚えなくて構いません。
:::

**法則の名前と中身の対応は必ず覚えてください。**特に、定比例の法則（1つの化合物の中）と倍数比例の法則（化合物どうし）の違いと、気体反応の法則が分子説を必要とした理由は、文章で説明できるようにしておきましょう。

人名は、ラボアジエ（質量保存）・プルースト（定比例）・ドルトン（原子説・倍数比例）・ゲーリュサック（気体反応）・アボガドロ（分子説）の組み合わせを覚えておけば十分です。

**年号は覚える必要はありません。**ただし「原子説（ドルトン）のあとに気体反応の法則が見つかり、それを分子説（アボガドロ）が解いた」という**順番**は、表の流れとして押さえておきましょう。

## 例題

:::exercise
source: このページのために作った
prompt: 次の (1)〜(3) に最も関係の深い法則の名前を答えよ。(1) 同温・同圧で、窒素 1 体積と水素 3 体積から、アンモニアが 2 体積できる。(2) 水を電気分解してつくった水素と酸素、天然の水の成分を調べたものは、どちらも水素と酸素の質量の比が 1 : 8 である。(3) 密閉した容器の中でスチールウールを燃やしても、容器全体の質量は変わらない。
answer: (1) 気体反応の法則（体積が 1 : 3 : 2 の簡単な整数比）。(2) 定比例の法則（1つの化合物 H₂O の中の質量の比が、つくり方によらず一定）。(3) 質量保存の法則。
:::

:::exercise
source: このページのために作った
prompt: 窒素の酸化物 A・B がある。A は窒素 7.0g と酸素 4.0g、B は窒素 7.0g と酸素 16g からなる。(1) 一定質量の窒素と結びつく酸素の質量の比（A : B）を求めよ。(2) この関係を表す法則の名前を答えよ。
answer: (1) 4.0 : 16 ＝ 1 : 4。(2) 倍数比例の法則。窒素の質量をそろえてから酸素の質量を比べると、簡単な整数比になっています（A は N₂O、B は NO₂ にあたります）。
:::

:::exercise
source: このページのために作った
prompt: マグネシウム 1.2g を完全に燃焼させると、酸化マグネシウムが 2.0g できた。マグネシウム 3.0g を完全に燃焼させると、酸化マグネシウムは何 g できるか。また、このとき使った2つの法則の名前を答えよ。
answer: 5.0g。定比例の法則から、Mg : MgO の質量比は 1.2 : 2.0 で一定なので、倍率 3.0/1.2 ＝ ×5/2 を掛けて 2.0 × 5/2 ＝ 5.0g。結びついた酸素の質量を 2.0 − 1.2 ＝ 0.8g と出すところで、質量保存の法則を使っています。
:::

:::exercise
source: このページのために作った
prompt: 「同温・同圧で、水素 1 体積と塩素 1 体積から塩化水素 2 体積ができる」という事実が、ドルトンの原子説だけでは説明できない理由と、アボガドロがそれをどう解決したかを説明せよ。
answer: 同じ体積に同じ数の原子があると考えると、水素原子 1 個と塩素原子 1 個から塩化水素の粒子が 2 個でき、1 個の粒子に水素原子が半分ずつ入ることになる。原子は分けられないので原子説と食い違う。アボガドロは、気体は原子が結びついた分子（H₂・Cl₂）からなり、同温・同圧・同体積には同数の分子があると考えた。反応で割れるのは分子で、H₂ ＋ Cl₂ → 2HCl となるので、原子を割らずに体積比 1 : 1 : 2 が説明できる。
:::
