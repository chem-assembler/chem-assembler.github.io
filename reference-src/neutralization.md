酸と塩基を混ぜると、酸の H⁺ と塩基の OH⁻ が結びついて H₂O ができ、互いの性質が打ち消されます。この反応を**中和反応**（中和）といいます。酸と塩基が何であるか（定義・価数）は前のページで扱っています。

:::

:::section
anchor: mechanism
title: 中和反応の仕組み —— イオンの組み換え
lead: 酸と塩基が中和すると、塩（塩基の陽イオン＋酸の陰イオン）と水（酸の H⁺＋塩基の OH⁻）ができます。
terms:
- 中和反応
- 塩
:::

「**酸が出した H⁺ と塩基が出した OH⁻ がくっついて H₂O が生じる反応**」を**中和反応**といいます。このとき、残った**塩基の陽イオンと酸の陰イオン**が組んでできる物質を**塩（えん）**といいます。

:::figure
src: neutralization-recombination.png
svg: neutralization-recombination.svg
alt: 反応前の酸（H⁺ と陰イオン）と塩基（陽イオンと OH⁻）から、反応後は陽イオンと陰イオンが組んだ塩と、H⁺ と OH⁻ が組んだ水ができることを矢印で示した図
caption: 中和は**イオンの組み換え**。H⁺ と OH⁻ は水に、塩基の陽イオンと酸の陰イオンは塩になります。
:::

具体例として、塩酸と水酸化ナトリウム水溶液の中和では、H⁺ と OH⁻ から H₂O が、Na⁺ と Cl⁻ から塩の NaCl ができます。

:::reaction
left: HCl ＋ NaOH
right: NaCl ＋ H₂O
level: ★★★
note: 反応しているのは H⁺ ＋ OH⁻ → H₂O の部分だけで、Na⁺ と Cl⁻ は水溶液中ではイオンのまま残ります。水を蒸発させると塩 NaCl が取り出せます。
:::

:::link
app: ion-equation/index
id: s1
text: 塩酸と水酸化ナトリウムを反応させ、傍観イオンが残るのを見る
:::

「**中和は H⁺ と OH⁻ が結びついて H₂O になる反応、残りが塩**」と覚えましょう。

:::section
anchor: ratio
title: 中和の量的関係 —— 価数の逆の比
lead: 酸の出す H⁺ の数と塩基の出す OH⁻ の数が等しいとき、ちょうど完全に中和します。a 価の酸と b 価の塩基は b mol : a mol で完全に中和します。
terms:
- 完全中和
- 中和点
:::

H⁺ と OH⁻ は同じ数（mol）どうしで反応するので、完全に中和する条件は次の1つです。

:::list
items:
- **（酸の放出した H⁺ の mol）＝（塩基の放出した OH⁻ の mol）**
- （酸の価数）×（酸の mol）＝（塩基の価数）×（塩基の mol）
:::

具体例として、1価の酸2個と1価の塩基2個、2価の酸1個と1価の塩基2個は、どちらも H⁺ と OH⁻ が2個ずつなので完全に中和します。3価の酸と2価の塩基なら、最小公倍数の6個ずつにそろえて、**3価の酸2個と2価の塩基3個**で完全に中和します。

つまり、**酸と塩基は価数の逆の比で完全に中和します**。a 価の酸と b 価の塩基は **b mol : a mol** です。

:::table
caption: 価数の組と、完全に中和する物質量の比
source: slides:酸塩基の基本４ p.8〜10・p.16（練習1）の組み合わせを、価数の組ごとに並べた
head:
- 酸の価数
- 塩基の価数
- 酸 : 塩基（mol）
- 具体例
align: center | center | center | left
rows:
- 1 | 1 | 1 : 1 | HCl と NaOH
- 1 | 2 | 2 : 1 | HCl と Ca(OH)₂
- 2 | 1 | 1 : 2 | H₂SO₄ と NaOH
- 3 | 2 | 2 : 3 | H₃PO₄ と Ca(OH)₂
:::

:::section
anchor: equation
title: 完全に中和する反応式の書き方
lead: 価数の逆の比で反応することを使って、係数も含めて左から順に書きます。あとから数合わせをしません。
:::

★ 中和の反応式は、**係数も含めて左から順に書く**のがこの書き方の要点です。

:::list
ordered: true
items:
- 酸と塩基の価数を確かめる。
　「1価の酸と2価の塩基」なら係数は 2 : 1、「3価の酸と2価の塩基」なら 2 : 3
- 左辺に、価数の逆の比の係数をつけて酸と塩基を書く。
- 左辺のイオンを組み替えて、右辺に塩を書く（塩基の陽イオン＋酸の陰イオン）。
- 右辺に H₂O を書く。係数は左辺の H⁺（＝ OH⁻）の数。
:::

具体例として、塩酸と水酸化カルシウムで順になぞります。

:::list
ordered: true
items:
- HCl は1価、Ca(OH)₂ は2価。価数の逆の比は **2 : 1**
- 左辺は **2HCl ＋ Ca(OH)₂**
- Ca²⁺ 1個と Cl⁻ 2個を組んで **CaCl₂**
- H⁺ と OH⁻ は2個ずつなので **2H₂O**
:::

:::figure
src: neutralization-writing.png
alt: 2HCl ＋ Ca(OH)₂ → CaCl₂ ＋ 2H₂O の式の下に、左辺の H⁺・Cl⁻・Ca²⁺・OH⁻ のイオンが右辺の CaCl₂ と 2H₂O に組み替わる様子を線でつないだ図
caption: **価数の逆の比（2 : 1）で係数を先に決め**、左辺のイオンを組み替えて右辺を書きます。
:::

:::reaction
left: 2HCl ＋ Ca(OH)₂
right: CaCl₂ ＋ 2H₂O
level: ★★★
note: 1価の酸と2価の塩基なので 2 : 1。
:::

:::reaction
left: H₂SO₄ ＋ 2NaOH
right: Na₂SO₄ ＋ 2H₂O
level: ★★★
note: 2価の酸と1価の塩基なので 1 : 2。
:::

:::reaction
left: 2H₃PO₄ ＋ 3Ca(OH)₂
right: Ca₃(PO₄)₂ ＋ 6H₂O
level: ★★☆
note: 3価の酸と2価の塩基なので 2 : 3。H⁺ と OH⁻ は6個ずつなので H₂O も6です。
:::

**中和の反応式は、物質名を見たらこの手順で書けるようにしてください。**反応物と生成物の化学式を丸暗記する必要はありません。

:::mistake
wrong: 2H₃PO₄ ＋ 3Ca(OH)₂ → Ca₃(PO₄)₂ ＋ 3H₂O
right: 2H₃PO₄ ＋ 3Ca(OH)₂ → Ca₃(PO₄)₂ ＋ **6H₂O**。H₂O の係数は、中和した H⁺（＝ OH⁻）の数です。
why: 塩を組むところで満足して、H₂O の係数を酸か塩基の係数から写してしまうためです。★ 左辺の H⁺ は 2 × 3 ＝ 6 個、OH⁻ も 3 × 2 ＝ 6 個なので、H₂O は6です。
:::

text: 塩の化学式から、もとの酸と塩基を復元して反応式を書く方法は、塩のページへ
:::

:::section
anchor: calculation
title: 中和の計算
lead: 「価数 × mol/L × 体積」を酸と塩基で等しいとおく式を1本立てれば、濃度・体積が求まります。
terms:
- 中和滴定
:::

水溶液どうしの中和では、酸の H⁺ の mol と塩基の OH⁻ の mol を、それぞれ次の形で書いて等しいとおきます。

:::list
items:
- （酸の価数）×（酸の mol/L）×（体積 L）＝（塩基の価数）×（塩基の mol/L）×（体積 L）
:::

両辺とも体積を mL で書けば、1000 で割る操作は両辺で消えるので、そのまま mL で計算できます。

:::figure
src: neutralization-app-h2so4.png

caption: 「H⁺ の mol ＝ OH⁻ の mol」を帯の長さで見た図。**2価の硫酸は、同じ mol でも帯が2倍の長さ**になります。
:::

:::link
app: ratio/titration
text: 中和の計算（価数 × 物質量のつり合い）
:::

具体例として、0.020 mol/L の水酸化カルシウム水溶液 12 mL とちょうど中和する 0.0080 mol/L の硫酸の体積を x mL とすると、

:::list
items:
- 2 × 0.0080 × x ＝ 2 × 0.020 × 12
- x ＝ **30 mL**
:::

左辺が「H₂SO₄ の価数 × H₂SO₄ の mol/L × mL」で H₂SO₄ の出した H⁺、右辺が「Ca(OH)₂ の価数 × Ca(OH)₂ の mol/L × mL」で Ca(OH)₂ の出した OH⁻ です。**式の各項が何の mol かを言えるように立ててください。**

:::callout
tone: caution
text: 中和の量的関係は、酸・塩基の強弱に関係しません。弱酸の酢酸も、中和されていくうちに次々と電離するので、1価の酸として最後まで NaOH と反応します。
:::

## 固体や気体の酸・塩基を含むとき

固体の酸・塩基は質量から mol を出し、同じように「H⁺ の mol ＝ OH⁻ の mol」とおきます。具体例として、固体の NaOH 0.40 g（式量 40）は 0.010 mol なので、これを中和する 0.50 mol/L の塩酸は 1 × 0.50 × x ＝ 1 × 0.010 × 1000 より **x ＝ 20 mL** です。

気体の酸・塩基は、体積から mol を出します。標準状態（0℃・1.013×10⁵Pa）なら 1mol が 22.4L なので、体積を 22.4L で割ります。気体の塩基のアンモニアは、多くの場合、次の逆滴定の形で出てきます。

:::section
anchor: back-titration
title: 逆滴定
lead: 気体の塩基（NH₃ など）は直接滴定できないので、多めの酸にいったん吸収させ、残った酸を塩基で滴定して差し引きで求めます。
terms:
- 逆滴定
:::

アンモニアのような気体は、そのままでは滴定できません。そこで、**量のわかった多めの酸に吸収させて中和させ、余った酸を別の塩基で滴定**します。このような滴定を**逆滴定**といいます。

★ 式は「酸の H⁺ の mol ＝ 吸収させた塩基の OH⁻ の mol ＋ 滴定に使った塩基の OH⁻ の mol」の1本です。

具体例として、ある量のアンモニアを 0.050 mol/L の硫酸 20.0 mL に吸収させ、残った硫酸は、0.10 mol/L の水酸化ナトリウム水溶液 12.0 mL で過不足なく中和されたとします。アンモニアを y mol とすると、

:::list
items:
- 2 × 0.050 × 20.0/1000 ＝ 1 × y ＋ 1 × 0.10 × 12.0/1000
- 2.0 × 10⁻³ ＝ y ＋ 1.2 × 10⁻³
- y ＝ **8.0 × 10⁻⁴ mol**
:::

**逆滴定は「足し算の式」を1本立てられれば十分です。**
