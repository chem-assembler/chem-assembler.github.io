油脂を水酸化ナトリウムでけん化して得られる、**高級脂肪酸のナトリウム塩**を**セッケン**といいます。汚れを落とすはたらきは、1つの分子の中に「水になじむ部分」と「油になじむ部分」が同居していることから生まれます。

:::section
anchor: prep
title: セッケンのつくり方
lead: 油脂に水酸化ナトリウム水溶液を加えて加熱するとけん化が起こり、セッケンとグリセリンができます。飽和食塩水を加えると、セッケンが固まって浮き上がります。
terms:
- セッケン
- けん化
- 塩析
:::

油脂に**水酸化ナトリウム水溶液**を加えて加熱すると、3か所のエステル結合が切れる**けん化**が起こり、**グリセリン**と**高級脂肪酸のナトリウム塩 R−COONa**、つまりセッケンができます。

具体例として、ステアリン酸だけからなる油脂で書くと次のようになります。

:::reaction
left: C₃H₅(OCOC₁₇H₃₅)₃ ＋ 3NaOH
over: 加熱
right: C₃H₅(OH)₃ ＋ 3C₁₇H₃₅COONa
level: ★★★
note: グリセリン1分子と、セッケンのステアリン酸ナトリウム3分子ができます。
:::

**「油脂1分子からセッケンは3分子」は必ず覚えてください。**けん化の反応式の立て方と、けん化価の計算は油脂のページで扱っています。

けん化したあとの液に**飽和食塩水**を加えると、セッケンが水に溶けにくくなって固まり、浮き上がります。このように、多量の塩を加えて物質を分離する操作を**塩析**といいます。

:::link
to: fat
text: 油脂の構造・けん化の反応式・けん化価の計算は油脂のページへ
:::

:::section
anchor: structure
title: セッケンの分子の形
lead: セッケンの分子は、油になじむ長い炭化水素基（疎水基）と、水になじむ −COO⁻ の部分（親水基）を1つずつもっています。
terms:
- 疎水基
- 親水基
- 親油基
:::

ステアリン酸ナトリウム C₁₇H₃₅COONa を具体例に見ます。水の中では C₁₇H₃₅COO⁻ と Na⁺ に電離しています。

C₁₇H₃₅COO⁻ のうち、**C₁₇H₃₅− の長い炭化水素基**は水になじまず、油になじみます。この部分を**疎水基（親油基）**といいます。**−COO⁻ の部分**はイオンなので水になじみます。この部分を**親水基**といいます。

**「セッケンの分子は、疎水基の長いしっぽと、親水基の頭をもつ」**と覚えましょう。以下の性質は、ほとんどこの形から出てきます。

:::section
anchor: micelle
title: ミセル
lead: セッケンの水溶液がある濃度より濃くなると、分子が疎水基を内側・親水基を外側に向けて集まり、球状の粒子になります。これをミセルといいます。
terms:
- ミセル
- 表面張力
- 界面活性剤
:::

セッケンを水に溶かすと、分子はまず**水面に並び**、疎水基を空気のほうへ、親水基を水のほうへ向けます。こうして水の**表面張力が小さくなり**、水が布などにしみこみやすくなります。

水面が分子でいっぱいになるくらいまで濃くすると、水の中の分子どうしが**疎水基を内側、親水基を外側**に向けて集まり、球状の粒子をつくります。これを**ミセル**といいます。ミセルはコロイド粒子の大きさです。

**「ミセルは疎水基が内側、親水基が外側」は必ず暗記してください。**向きを逆に書く誤りがよく登場します。

//図: ミセルの断面図（疎水基のしっぽを内側に、親水基の頭を外側に向けて丸く並んだ絵）。作図器では描けない

:::section
anchor: emulsify
title: 乳化 —— 汚れが落ちるしくみ
lead: セッケンの疎水基が油汚れを取り囲み、親水基を外に向けた粒子になって水の中に散らばります。これを乳化といいます。
terms:
- 乳化
- 乳濁液
- エマルション
:::

セッケン水に油汚れがふれると、セッケンの**疎水基が油のほうに入り込み**、油の粒を取り囲みます。外側には親水基が並ぶので、油の粒はそのまま**水の中に散らばる**ことができます。この作用を**乳化**といい、できた液を**乳濁液（エマルション）**といいます。

具体例として、油でよごれた布をセッケン水の中でもむと、油が小さな粒になって布から離れ、水の中に散らばります。

:::mistake
wrong: セッケンは、油汚れを溶かして落とす
right: セッケンは油汚れを**溶かすのではなく**、疎水基で**包んで、水の中に散らす**ことで落とします（乳化）。
why: 「汚れが見えなくなる」ことを「溶けた」と言いかえてしまうためです。★ 油の粒はそのまま残っていて、セッケンに包まれて水中に浮いているだけです。
:::

**「乳化は、油を包んで水の中に散らすこと」**と覚えましょう。

//図: 油の粒をセッケン分子が疎水基を内側に向けて取り囲んだ断面図。作図器では描けない

:::section
anchor: alkaline
title: セッケン水が塩基性になるわけ
lead: セッケンは弱酸である高級脂肪酸と、強塩基である水酸化ナトリウムからできた塩なので、水溶液中で加水分解して弱い塩基性を示します。
terms:
- 加水分解
- 弱酸の塩
:::

セッケンは、**弱酸**の高級脂肪酸 R−COOH と**強塩基**の NaOH からできた塩です。このような塩は、水に溶かすと一部が水と反応して **OH⁻** を生じます（塩の加水分解）。

:::reaction
left: C₁₇H₃₅COO⁻ ＋ H₂O
right: C₁₇H₃₅COOH ＋ OH⁻
level: ★★★
note: 弱酸のイオンが水から H⁺ を受け取り、OH⁻ が残ります。だから水溶液は弱い塩基性になります。
:::

**「セッケン水は弱い塩基性。弱酸と強塩基の塩だから」は、理由とセットで暗記してください。**

塩基性の水溶液はタンパク質を傷めるので、セッケンは**絹や羊毛**（どちらもタンパク質でできた動物性の繊維）の洗濯には向きません。

逆に、酸性の水の中では、弱酸である高級脂肪酸が遊離してしまい、セッケンとしてはたらきません。

:::reaction
left: C₁₇H₃₅COONa ＋ HCl
right: C₁₇H₃₅COOH ＋ NaCl
level: ★★☆
note: 弱酸の塩に強酸を加えると、弱酸が追い出されます。遊離したステアリン酸は水に溶けにくいので分離します。
:::

:::

:::section
anchor: hard-water
title: 硬水ではたらかないわけ
lead: カルシウムイオン Ca²⁺ やマグネシウムイオン Mg²⁺ を多くふくむ硬水の中では、セッケンが水に溶けない塩になって沈殿し、泡立たなくなります。
terms:
- 硬水
:::

Ca²⁺ や Mg²⁺ を多くふくむ水を**硬水**といいます。硬水の中でセッケンを使うと、セッケンの陰イオンがこれらのイオンと結びついて、**水に溶けない塩**になって沈殿します。

:::reaction
left: 2C₁₇H₃₅COO⁻ ＋ Ca²⁺
right: (C₁₇H₃₅COO)₂Ca（沈殿）
level: ★★★
note: 2価の Ca²⁺ 1個に、1価のセッケンの陰イオンが2個結びつきます。Mg²⁺ でも同じです。
:::

沈殿したぶんだけセッケンが減るので、**泡立ちが悪くなり、汚れも落ちにくく**なります。

**「セッケンは硬水で沈殿して泡立たない」は暗記してください。**係数の2は、電荷をつり合わせれば出せます。

:::section
anchor: detergent
title: 合成洗剤
lead: 合成洗剤は、強酸であるスルホン酸や硫酸エステルのナトリウム塩です。水溶液は中性で、硬水の中でも沈殿しません。
terms:
- 合成洗剤
- アルキルベンゼンスルホン酸ナトリウム
- 硫酸ドデシルナトリウム
:::

セッケンの2つの弱点（塩基性・硬水）を避けるために作られたのが**合成洗剤**です。セッケンと同じく疎水基と親水基をもちますが、親水基が **−SO₃⁻** や **−OSO₃⁻** になっています。

代表的なものは**アルキルベンゼンスルホン酸ナトリウム**です。長いアルキル基 R をもつベンゼンを**スルホン化**し、NaOH で中和してつくります。

:::reaction
left: R−C₆H₅ ＋ H₂SO₄
right: R−C₆H₄−SO₃H ＋ H₂O
level: ★★☆
note: 濃硫酸でベンゼン環をスルホン化します。R は炭素数12くらいのアルキル基です。
:::

:::reaction
left: R−C₆H₄−SO₃H ＋ NaOH
right: R−C₆H₄−SO₃Na ＋ H₂O
level: ★★☆
note: スルホン酸は強酸なので、できた塩の水溶液は中性です。
:::

もう1つの型は、高級アルコールを濃硫酸で**硫酸エステル**にしてから中和したものです。具体例は**硫酸ドデシルナトリウム** C₁₂H₂₅−OSO₃Na です。

:::reaction
left: C₁₂H₂₅−OH ＋ H₂SO₄
right: C₁₂H₂₅−OSO₃H ＋ H₂O
level: ★★☆
note: 高級アルコールの −OH と硫酸から水がとれて、硫酸エステルができます。これも NaOH で中和して使います。
:::

**「セッケンは弱酸の塩、合成洗剤は強酸の塩」の一点だけは必ず覚えてください。**液性も、硬水での沈殿も、絹・羊毛に使えるかも、すべてここから出ます。**アルキルベンゼンスルホン酸ナトリウムの構造（ベンゼン環に長いアルキル基と −SO₃Na）は書けるようにしておきましょう。**アルキル基の正確な炭素数は覚えなくて構いません。

:::section
anchor: surfactant
title: 界面活性剤
lead: セッケンも合成洗剤も、水の表面張力を小さくし、水と油をなじませるはたらきをもちます。このような物質をまとめて界面活性剤といいます。
terms:
- 界面活性剤
:::

ここまで見てきたセッケンと合成洗剤は、どちらも**1つの分子に疎水基と親水基をもち**、水の表面に並んで**表面張力を小さく**し、ミセルや乳化によって水と油をなじませます。このようなはたらきをもつ物質をまとめて**界面活性剤**といいます。

**「セッケンも合成洗剤も界面活性剤」**と、まとめの名前として覚えましょう。

:::section
anchor: phospholipid
title: リン脂質と細胞膜
advanced: true
lead: 細胞膜をつくるリン脂質も、1つの分子に疎水基と親水基をもちます。セッケンと同じしくみで、水の中で2層に並んで膜をつくります。
terms:
- リン脂質
:::

**リン脂質**は、グリセリンに脂肪酸が2個と、リン酸をふくむ部分が1個結合した分子です。脂肪酸の2本の鎖が疎水基、リン酸をふくむ部分が親水基で、**セッケンと同じく疎水基と親水基が同居**しています。

水の中では、リン脂質は疎水基どうしを内側に向けて向かい合い、親水基を両側の水に向けた**2層の膜**をつくります。これが細胞膜の骨組みです。**「ミセルと同じく、疎水基は水から隠れる側」**という1点がわかれば十分で、リン脂質の構造式は覚える必要はありません。

:::exercise
source: reference-outline/bio.md 第2部 soap の例題2（①ドラフトのために起こした記述問題）
prompt: 硬水の中でセッケンが泡立たなくなる理由を化学反応式を使って説明し、あわせて合成洗剤が硬水の中でも使える理由を書け。
answer: 2C₁₇H₃₅COO⁻ ＋ Ca²⁺ → (C₁₇H₃₅COO)₂Ca のように、セッケンが Ca²⁺ や Mg²⁺ と**水に溶けない塩をつくって沈殿する**ためです。合成洗剤は強酸であるスルホン酸や硫酸エステルの塩で、その**カルシウム塩やマグネシウム塩も水に溶ける**ので沈殿しません。
:::

:::exercise
source: reference-outline/bio.md 第2部 soap の例題3（①ドラフトのために起こした計算問題。油脂のページのけん化の 1対3 の関係を使う）
prompt: ステアリン酸だけからなる油脂 89.0 g を水酸化ナトリウムで完全にけん化したとき、得られるセッケンの質量を求めよ。油脂の分子量は890、C₁₇H₃₅COONa の式量は306とする。
answer: 油脂は 89.0 ÷ 890 ＝ 0.100 mol。**油脂1 mol からセッケンは3 mol** できるので、セッケンは 0.300 mol。306 × 0.300 ＝ **91.8 g** です。
:::
