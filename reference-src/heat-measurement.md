反応エンタルピーの値は、実際には水溶液の温度の変化から求めます。このページでは、温度の変化から熱量を出し、それを 1mol あたりの反応エンタルピーに直すまでを扱います。ΔH の符号の決め方は前のページで扱いました。

:::section
anchor: specific-heat
title: 比熱と熱量
lead: 同じ熱を与えても、温まりやすさは物質ごとに違います。その違いを数で表したのが比熱です。熱量〔J〕＝ 質量〔g〕× 比熱〔J/(g·K)〕× 温度変化〔K〕です。
terms:
- 比熱
- 熱量
:::

1g の物質を 1K だけ温めるのに要る熱の量は、物質ごとに決まった値をとります。これがその物質の**比熱**（比熱容量）で、単位は J/(g·K) です。水は 4.2J/(g·K)、銅は 0.4J/(g·K) くらいなので、水は温まりにくい物質です。

物質に出入りした熱量は、次の式で求めます。

**熱量〔J〕＝ 質量〔g〕× 比熱〔J/(g·K)〕× 温度変化〔K〕**

式を覚えるよりも、「水 1g を 1K 上げるのに 4.2J」から比例で考えるほうが確実です。質量が 100 倍なら熱量も 100 倍、温度変化が 5 倍なら熱量も 5 倍です。

具体例1で、水 100g の温度が 20.0℃ から 25.0℃ に上がったときの熱量を求めます。温度変化は 5.0K なので、4.2J × 100 × 5.0 ＝ 2100J ＝ 2.1kJ です。

**温度変化は、℃ の差をそのまま K の差として使ってかまいません。** ℃ と K は目盛りの幅が同じで、0 の位置がずれているだけだからです。

:::table
caption: 熱量の式に入れる3つの量
source: 教科書（R5化学Vol.1-2編 1章1節）の熱量の式を、入れる量ごとに単位と注意を並べ直したもの。注意の列はこのページの本文から
head:
- 量
- 単位
- 入れるときの注意
align: left | left | left
rows:
- 質量 | g | 水だけでなく、**溶かした溶質も含めた溶液全体**の質量。体積で与えられたら密度をかける
- 比熱 | J/(g·K) | 問題文で与えられる。水溶液は水と同じ 4.2 とすることが多い
- 温度変化 | K | ℃ の差のままでよい。**グラフを延ばして読んだ値**を使う
:::

:::section
anchor: extrapolate
title: 逃げた熱を補う —— グラフを延ばす
lead: 測定中にも熱は周りへ逃げています。温度が下がっていく直線部分を、反応を始めた時刻まで延ばした点の温度を、逃げなかった場合の最高温度とします。
:::

断熱容器（発泡ポリスチレンのコップ）を使っても、測っている間に熱は少しずつ周りへ逃げます。そのため、**温度計の最高値は、本当に上がるはずだった温度より低く**なります。

そこで、次の手順で温度変化を読みます。

:::list
ordered: true
items:
- 時間を横軸、温度を縦軸にとって、測った温度をグラフにする。
- 最高温度を過ぎてから温度がゆっくり下がっていく部分を、直線とみなす。
- その直線を、**反応を始めた時刻（溶かし始めた時刻・混ぜた時刻）まで延ばす。**
　延ばした先の温度を「逃げなかった場合の最高温度」とします。
- 温度変化 ＝（延ばした先の温度）−（はじめの温度）。
:::

:::figure
src: heat-measurement-extrapolation.png
svg: heat-measurement-extrapolation.svg
alt: 横軸が時間、縦軸が温度のグラフ。20.0℃ の水が混ぜた時刻から立ち上がり、29.8℃ を最高としてそのあとゆっくり直線的に下がる。下がる直線を点線で混ぜた時刻まで延ばした先が 30.6℃ で、はじめの温度との差 10.6 K が温度変化
caption: 使うのは温度計が示した 29.8℃ ではなく、**延ばした先の 30.6℃** です。混ぜてから最高温度に届くまでのあいだにも、熱は逃げ続けているからです。
:::

延ばした点は、「一瞬で反応が終わり、熱がまったく逃げなかったとしたら」の温度にあたります。下がっていく直線の傾きが、逃げていく熱の速さを表しているためです。

具体例2で、はじめ 20.0℃ の水に溶質を入れたところ、最高温度は 29.8℃ で、下がる直線を 0 分まで延ばすと 30.6℃ でした。使う温度変化は 30.6 − 20.0 ＝ 10.6K です。29.8 − 20.0 ＝ 9.8K を使うと、逃げた分だけ熱量を小さく見積もってしまいます。

:::mistake
wrong: 温度計が示した最高温度から、はじめの温度を引いて温度変化にする
right: 最高温度を過ぎて下がっていく直線を、**反応を始めた時刻まで延ばした点**の温度を使います。
why: 温度計の最高値は、それまでに逃げた熱の分だけ低くなっています。★ 問題にグラフが付いていたら、まず「延ばす直線」を探します。
:::

:::section
anchor: to-enthalpy
title: 熱量から反応エンタルピーへ
lead: 出てきた熱量を、着目する物質 1mol あたりに直します。発熱なら負、吸熱なら正の符号を付けたものが反応エンタルピーです。
:::

熱量が出たら、次の順で反応エンタルピーに直します。

:::list
ordered: true
items:
- 着目する物質の物質量を出す。
　溶解なら溶かした溶質、中和ならできた水 H₂O。
- 主語付きの比例式で 1mol あたりの熱量に直す。
　○○ ○○mol : ○○kJ ＝ ○○ 1mol : x kJ
- 温度が上がったなら発熱なので負、下がったなら吸熱なので正の符号を付ける。
:::

具体例3で、水 96g に水酸化ナトリウム NaOH（式量 40）の結晶 4.0g を溶かし、具体例2のグラフのとおり温度変化が 10.6K だったとします。

:::list
ordered: true
items:
- 溶液の質量は 96 ＋ 4.0 ＝ 100g。熱量は 4.2J × 100 × 10.6 ＝ 4452J ≒ 4.45kJ。
- NaOH は 4.0 ÷ 40 ＝ 0.10mol。NaOH 0.10mol : 4.45kJ ＝ NaOH 1mol : x kJ より、x ＝ 44.5。
- 温度が上がったので発熱。NaOH の溶解エンタルピーは **−44.5kJ/mol**。
:::

//app: ratio/proportion 「1mol あたりの熱量を比例式で出す」

中和エンタルピーを測るときは、**着目するのは酸でも塩基でもなく、できた水**です。1.0mol/L の塩酸 50mL と 1.0mol/L の水酸化ナトリウム水溶液 50mL を混ぜると、できる水は 0.050mol です。

:::mistake
wrong: 熱量を出したら、それを符号なしでそのまま答える
right: 反応エンタルピーは **1mol あたり**の値で、**符号つき**です。温度が上がった（発熱した）なら負の符号を付けます。
why: 実験で測れるのは「何 J 出たか」という符号の無い量です。★ 最後に「温度が上がった → 発熱 → ΔH は負」と一言書き足す習慣をつけます。
:::

固体の NaOH を塩酸に直接入れる実験と、いったん水に溶かしてから塩酸と混ぜる実験を比べると、2段に分けても合計の熱量は同じになります。これがヘスの法則です。

:::link
to: hess-law
text: 経路によらず熱量は同じ（ヘスの法則）はこちら
:::

:::section
anchor: range
title: 覚える範囲
lead: 熱量 ＝ 質量 × 比熱 × 温度変化、グラフを延ばすこと、1mol あたりに直して符号を付けること。比熱の値は与えられます。
:::

**「熱量 ＝ 質量 × 比熱 × 温度変化」と「グラフを反応開始の時刻まで延ばす」の2つは必ず覚えてください。**質量には溶質も含めること、最後に 1mol あたりに直して符号を付けることも、毎回の手順にしましょう。

**比熱の値（水の 4.2J/(g·K) など）は問題文で与えられるので、覚えなくても構いません。**水溶液の密度も、1.0g/cm³ として与えられることがほとんどです。

## 例題

:::exercise
source: 自作（このページの「熱量から反応エンタルピーへ」の手順から作った問い。数値は中和エンタルピー −56.5kJ/mol から逆算した）
prompt: 1.0mol/L の塩酸 50mL と 1.0mol/L の水酸化ナトリウム水溶液 50mL を断熱容器で混ぜたところ、グラフを延ばして読んだ温度変化は 6.7K だった。水溶液の密度は 1.0g/cm³、比熱は 4.2J/(g·K) とする。**(1) 発生した熱量は何 kJ か。　(2) 中和エンタルピーは何 kJ/mol か。**
answer: (1) **2.8kJ**。水溶液は 50 ＋ 50 ＝ 100mL で 100g。4.2J × 100 × 6.7 ＝ 2814J ≒ 2.8kJ。　(2) **−56kJ/mol**。できる水は HCl と同じ 1.0 × 50/1000 ＝ 0.050mol。H₂O 0.050mol : 2.8kJ ＝ H₂O 1mol : x kJ より x ≒ 56。発熱なので負の符号を付けます。
:::

:::exercise
source: 自作（このページの「逃げた熱を補う」の節から作った問い）
prompt: 水 48g に硝酸アンモニウム NH₄NO₃（式量 80）2.0g を溶かしたところ、温度は 20.0℃ から下がり、最低温度は 17.3℃ だった。そのあと温度がゆっくり上がっていく直線を溶かし始めた時刻まで延ばすと 16.9℃ だった。比熱は 4.2J/(g·K) とする。**NH₄NO₃ の溶解エンタルピーは何 kJ/mol か。**
answer: **＋26kJ/mol**。温度変化は 20.0 − 16.9 ＝ 3.1K（温度が下がる場合も、延ばした点を使います。周りから熱が入ってきて温度が戻っていくためです）。溶液は 48 ＋ 2.0 ＝ 50g で、熱量は 4.2J × 50 × 3.1 ＝ 651J ≒ 0.651kJ。NH₄NO₃ は 2.0 ÷ 80 ＝ 0.025mol。NH₄NO₃ 0.025mol : 0.651kJ ＝ NH₄NO₃ 1mol : x kJ より x ≒ 26。温度が下がったので吸熱で、符号は正です。
:::
