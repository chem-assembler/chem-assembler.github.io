多数のアミノ酸がつながってできた天然高分子を**タンパク質**といいます。筋肉・皮膚・毛・酵素・ヘモグロビンなど、生物の体のはたらきの多くをタンパク質が受け持っています。

:::section
anchor: peptide
title: ペプチド結合
lead: 一方のアミノ酸の −COOH と、もう一方のアミノ酸の −NH₂ から水1分子がとれてできる −CO−NH− の結合をペプチド結合といいます。
terms:
- ペプチド結合
- ペプチド
- ジペプチド
- トリペプチド
- ポリペプチド
:::

アミノ酸どうしが、一方の **−COOH** ともう一方の **−NH₂** から**水1分子がとれて**縮合すると、**−CO−NH−** の結合ができます。アミノ酸どうしのこの結合を**ペプチド結合**といい、できた化合物を**ペプチド**といいます。

具体例として、グリシン2分子からは**グリシルグリシン**ができます。

:::reaction
left: H₂N−CH₂−COOH ＋ H₂N−CH₂−COOH
right: H₂N−CH₂−CO−NH−CH₂−COOH ＋ H₂O
level: ★★★
note: 左のグリシンの −COOH の OH と、右のグリシンの −NH₂ の H から水がとれています。
:::

:::figure
src: protein-glycylglycine.png
gen: name=グリシルグリシン（ジペプチド） plain
alt: グリシルグリシンの構造式。左端にアミノ基、右端にカルボキシ基があり、まん中に C=O と N−H が並んだペプチド結合がある
caption: **グリシルグリシン**。まん中の −CO−NH− がペプチド結合です。
:::

アミノ酸2分子からできたものを**ジペプチド**、3分子なら**トリペプチド**、多数なら**ポリペプチド**といいます。タンパク質は、ポリペプチドが決まった形に折りたたまれたものです。

ペプチド結合は、カルボン酸とアミンからできる**アミド結合と同じ結合**です。アミノ酸どうしのときだけ、特にペプチド結合と呼びます。

**「ペプチド結合は −CO−NH−、−COOH と −NH₂ から水がとれてできる」は必ず暗記してください。**

タンパク質を塩酸と加熱するか酵素で加水分解すると、ペプチド結合が切れて α-アミノ酸の混合物になります。

:::reaction
left: ポリペプチド ＋ 水
over: 塩酸または酵素
right: α-アミノ酸の混合物
level: ★★☆
note: ペプチド結合1個を切るごとに水が1分子要ります。
:::

:::section
anchor: dipeptide-count
title: ペプチドは何種類できるか
lead: ペプチドには向きがあり、−NH₂ が残る端と −COOH が残る端を区別します。だから同じアミノ酸の組み合わせでも、並び順が違えば別の物質です。
terms:
- N末端
- C末端
:::

ペプチドの鎖の、−NH₂ が残っている端を**N末端**、−COOH が残っている端を**C末端**といいます。両端が違うので、ペプチドには**向き**があります。

具体例として、グリシン（Gly）とアラニン（Ala）を1分子ずつ使ったジペプチドは、**Gly−Ala と Ala−Gly の2種類**です。どちらのアミノ酸の −COOH を使うかで、別の物質になります。

:::list
items:
- 2種類のアミノ酸を1回ずつ使うジペプチドは「○○」種類 ＝ 2 × 1 ＝ 2種類
- 3種類のアミノ酸を1回ずつ使うトリペプチドは「○○」種類 ＝ 3 × 2 × 1 ＝ 6種類
- N 種類のアミノ酸を1回ずつ使うと、並べ方の数 N! ＝「○○」種類
:::

**「ペプチドには向きがあるので、逆順は別物として数える」**と覚えましょう。不斉炭素原子による鏡像異性体まで数える問題は、そう指示があるときだけ考えれば構いません。

:::section
anchor: structure
title: 一次構造から四次構造まで
lead: アミノ酸の並び順を一次構造、水素結合でできるらせんやひだ状の形を二次構造、分子全体の折りたたみを三次構造、複数の鎖の集まりを四次構造といいます。
terms:
- 一次構造
- 二次構造
- α-ヘリックス
- β-シート
- 三次構造
- 四次構造
- ジスルフィド結合
:::

タンパク質の形は、4つの段階に分けて考えます。

ポリペプチドの**アミノ酸の並び順**を**一次構造**といいます。どのタンパク質も、決まった一次構造をもっています。

ペプチド結合の **C=O** の O と、別のペプチド結合の **N−H** の H の間には**水素結合**ができます。この水素結合によって、鎖がらせん状に巻いた **α-ヘリックス**や、鎖が並んでひだ状になった **β-シート**ができます。これを**二次構造**といいます。

二次構造をもった鎖が、さらに分子全体として立体的に折りたたまれた形を**三次構造**といいます。三次構造は、側鎖どうしの**ジスルフィド結合 −S−S−**（システインの −SH どうしからできる）・イオン結合・水素結合などで保たれています。

三次構造をもった鎖（サブユニット）が、いくつか集まってできた形を**四次構造**といいます。ヘモグロビンは4本の鎖が集まった四次構造をもちます。

:::table
caption: タンパク質の構造
source: qa:org.bio.protein-structure・org.bio.protein-higher の各段階の定義と、それを保つ結合を並べた
head:
- 段階
- 何を指すか
- おもに何で保たれているか
align: left | left | left
rows:
- 一次構造 | アミノ酸の**並び順** | ペプチド結合
- 二次構造 | α-ヘリックス・β-シート | ペプチド結合の C=O と N−H の間の**水素結合**
- 三次構造 | 分子全体の折りたたみ | **ジスルフィド結合**・イオン結合・水素結合など
- 四次構造 | サブユニットの集まり | サブユニットどうしの弱い結びつき
:::

:::section
anchor: classification
title: タンパク質の分類
lead: アミノ酸だけからなるものを単純タンパク質、糖や色素などもふくむものを複合タンパク質といいます。形からは球状タンパク質と繊維状タンパク質に分けます。
terms:
- 単純タンパク質
- 複合タンパク質
- 球状タンパク質
- 繊維状タンパク質
:::

加水分解したときに**アミノ酸だけ**が得られるものを**単純タンパク質**、アミノ酸のほかに**糖・リン酸・色素・核酸など**もふくむものを**複合タンパク質**といいます。

形で分けると、鎖が丸くまとまって水に溶けやすい**球状タンパク質**と、鎖が束になって水に溶けにくい**繊維状タンパク質**があります。

:::table
caption: タンパク質の分類と例
source: qa:org.bio.protein-classification の2通りの分け方と、代表例（絹のフィブロイン・羊毛のケラチンは骨子の第2部で足したもの）
head:
- 分け方
- 種類
- 例
align: left | left | left
rows:
- 成分で | 単純タンパク質（アミノ酸だけ） | アルブミン（卵白）・ケラチン（羊毛・毛・爪）・フィブロイン（絹）・コラーゲン（皮膚・骨）
- 成分で | 複合タンパク質（ほかの成分もふくむ） | カゼイン（牛乳・リン酸をふくむ）・ヘモグロビン（血液・色素をふくむ）
- 形で | 球状タンパク質（水に溶けやすい） | アルブミン・ヘモグロビン
- 形で | 繊維状タンパク質（水に溶けにくい） | ケラチン・フィブロイン・コラーゲン
:::

**「単純／複合」「球状／繊維状」の4つの名前と意味は暗記してください。**例として、**絹はフィブロイン、羊毛はケラチン**の2つは覚えておきましょう。それ以外のタンパク質がどれにあたるかの一覧は、覚える必要はありません。

球状タンパク質を水に溶かすと、分子1個がコロイド粒子の大きさになるので、コロイド溶液になります。多量の塩を加えると沈殿します（塩析）。

:::section
anchor: denaturation
title: 変性
lead: 熱・強い酸や塩基・重金属イオン・アルコールなどによって、タンパク質の立体構造がこわれることを変性といいます。ペプチド結合は切れないので、一次構造は変わりません。
terms:
- 変性
:::

タンパク質に**熱**を加えたり、**強い酸や塩基**、**重金属イオン（Cu²⁺・Hg²⁺・Pb²⁺ など）**、**エタノールなどの有機溶媒**を加えたりすると、二次構造以上を保っていた水素結合などが切れて、**立体構造がこわれます**。これを**変性**といいます。

具体例として、生卵を加熱すると白く固まり、冷やしても元に戻りません。卵白のアルブミンが熱で変性したためです。消毒用アルコールが細菌を殺すのも、細菌のタンパク質を変性させるためです。

**「変性でこわれるのは立体構造。ペプチド結合は切れないので、一次構造は変わらない」**と覚えましょう。変性したタンパク質は、ふつう元の形に戻りません。

:::mistake
wrong: 変性すると、タンパク質のペプチド結合が切れてアミノ酸にばらばらになる
right: 変性で切れるのは、立体構造を保っていた**水素結合など**です。**ペプチド結合は切れず、一次構造は変わりません。**
why: 「こわれる」を加水分解と同じものとして覚えてしまうためです。★ ペプチド結合を切るのは、酸や酵素による**加水分解**のほうです。
:::

text: 酵素が高温ではたらかなくなるのも変性のためです（酵素のページへ）
:::

:::section

title: 呈色反応
lead: ビウレット反応はペプチド結合、キサントプロテイン反応はベンゼン環、硫黄の検出は硫黄、ニンヒドリン反応はアミノ基を検出します。

- ビウレット反応
- キサントプロテイン反応
- 硫黄の検出
- ニンヒドリン反応

タンパク質やアミノ酸を検出する反応は4つあります。**どれも「何を検出しているか」で使い分けます。**

:::table
caption: タンパク質・アミノ酸の呈色反応
source: qa:org.bio.biuret・org.bio.xanthoproteic・org.bio.protein-sulfur-test・org.bio.ninhydrin の試薬・色・検出対象を並べた。ニンヒドリンの色は qa/KNOWLEDGE_CAVEATS.md A-6 の「青紫〜赤紫」にそろえた
head:
- 名称
- 試薬と操作
- 色
- 何を検出しているか
align: left | left | left | left
rows:
- ビウレット反応 | NaOH 水溶液を加えて塩基性にし、少量の CuSO₄ 水溶液を加える | 赤紫色 | **ペプチド結合2個以上**（トリペプチド以上）
- キサントプロテイン反応 | 濃硝酸を加えて加熱し、冷やしてからアンモニア水で塩基性にする | 黄色 → 橙黄色 | 側鎖の**ベンゼン環**
- 硫黄の検出 | NaOH 水溶液を加えて加熱し、酢酸鉛(II) 水溶液を加える | 黒色沈殿（PbS） | 側鎖の**硫黄**
- ニンヒドリン反応 | ニンヒドリン水溶液を加えて温める | 青紫色〜赤紫色 | **アミノ基 −NH₂**
:::

**この表は4行とも「試薬・色・何を検出しているか」まで暗記してください。**反応の仕組みは覚える必要はありません。

キサントプロテイン反応の黄色は、側鎖の**ベンゼン環がニトロ化**されたためです。ベンゼン環をもつアミノ酸の中でも、**チロシン**のように環に −OH が付いたものがよく反応します。

:::reaction
left: 側鎖のベンゼン環 ＋ HNO₃
over: 加熱
right: ニトロ化されたベンゼン環（黄色） ＋ H₂O
level: ★★☆
note: ベンゼンのニトロ化と同じ置換反応です。
:::

硫黄の検出では、NaOH と加熱して側鎖の硫黄を硫化物イオン S²⁻ に変えてから、鉛(II)イオンで黒い沈殿にします。

:::reaction
left: S²⁻ ＋ Pb²⁺
right: PbS（黒色沈殿）
level: ★★★
note: 黒色沈殿が出れば、システインなど硫黄をもつアミノ酸をふくみます。
:::

ビウレット反応は、Cu²⁺ が**2個以上のペプチド結合**の N 原子にはさまれて錯イオンをつくり、赤紫色になるものです。ペプチド結合を1個しかもたないジペプチドでは、はさむ相手が足りないので呈色しません。

:::link
to: benzene-substitution
text: ベンゼン環のニトロ化そのものは、ベンゼンの置換反応のページへ
:::

:::section
anchor: kjeldahl
title: ケルダール法（窒素の定量）
advanced: true
lead: タンパク質中の窒素をアンモニアに変えて酸に吸収させ、残った酸を滴定することで、窒素の量からタンパク質の量を求めます。
terms:
- ケルダール法
- 逆滴定
:::

食品にふくまれるタンパク質の量は、タンパク質中の**窒素の量**から求めることができます。この方法を**ケルダール法**といいます。

手順は3段です。

:::list
ordered: true
items:
- 試料を濃硫酸と加熱して分解し、窒素をアンモニウムイオン NH₄⁺ に変える。
- 濃い水酸化ナトリウム水溶液を加えて加熱し、出てきたアンモニア NH₃ を、量のわかっている硫酸に吸収させる。
- 余った硫酸を水酸化ナトリウム水溶液で滴定する（逆滴定）。
　硫酸がもともと出せた H⁺ の物質量 ＝ NH₃ の物質量 ＋ 滴定に使った NaOH の物質量
:::

求めた NH₃ の物質量が、試料中の窒素原子の物質量です。タンパク質の窒素の質量の割合（およそ16%）が問題文に与えられれば、窒素の質量からタンパク質の質量が出ます。**式の立て方は、中和滴定の物質量の関係そのものなので、公式として覚える必要はありません。**

prompt: 生卵を加熱すると白く固まり、冷やしても元に戻らない。この現象の名前と、そのときタンパク質の分子に何が起きているかを書け。
answer: **変性**です。熱によって、立体構造を保っていた**水素結合などが切れて、二次構造以上の立体構造がこわれます**。ペプチド結合は切れないので一次構造は変わりませんが、ふつう元の形には戻りません。

:::exercise
source: reference-outline/bio.md 第1部 protein の例題(b)（①ドラフトのために起こした記述問題）
prompt: ビウレット反応は、トリペプチドでは陽性だが、ジペプチドでは陰性になる。その理由を書け。
answer: ビウレット反応の赤紫色は、Cu²⁺ が**2個以上のペプチド結合**にはさまれてできる錯イオンの色だからです。ジペプチドはペプチド結合を**1個**しかもたないので、呈色しません。
