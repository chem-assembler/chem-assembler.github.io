酸化還元反応は、還元剤が放出した e⁻ を酸化剤が受け取る反応です。この e⁻ のやりとりを、導線を通して外に取り出す装置が**電池**です。酸化剤・還元剤とイオン化傾向は、このページの前提になります。

:::section
anchor: principle
title: 電池は酸化剤と還元剤の場所を離した装置
lead: 還元剤が負極、酸化剤が正極になり、e⁻ は負極から導線を通って正極へ流れます。
terms:
- 電池
- 正極
- 負極
- 活物質
- 負極活物質
- 正極活物質
:::

酸化剤と還元剤を直接ふれさせると、e⁻ はその場で受け渡されて熱になるだけです。**2つの場所を離し、間を導線でつなぐ**と、e⁻ は導線を通って還元剤から酸化剤へ流れます。この e⁻ の流れが電流です。このように酸化還元反応にともなう e⁻ の流れを外に取り出す装置を**電池**といいます。

還元剤は e⁻ を放出するので、e⁻ が出ていく側の電極になります。これを**負極**といいます。酸化剤は e⁻ を受け取るので、e⁻ が入ってくる側の電極になります。これを**正極**といいます。

負極で還元剤としてはたらく物質を**負極活物質**、正極で酸化剤としてはたらく物質を**正極活物質**といい、まとめて**活物質**といいます。

:::table
caption: 電池の負極と正極
source: slides:電池の基本１ s7「電池はどのような装置か」の本文（還元剤は e⁻ を放出するので負極・酸化剤は e⁻ を受け取るので正極・e⁻ は負極から出て正極にもどる・活物質の定義）を2列に並べ直したもの
head:
- 項目
- 負極
- 正極
align: left | center | center
rows:
- はたらく物質 | 還元剤（負極活物質） | 酸化剤（正極活物質）
- e⁻ | 放出する（出ていく） | 受け取る（入ってくる）
- 起こる反応 | 酸化される反応 | 還元される反応
:::

**「負極は還元剤、正極は酸化剤」「e⁻ は負極から出て正極にもどる」の2つは必ず覚えてください。**電池のどの問題も、ここから考え始めます。

:::section
anchor: tree
title: 金属樹の反応を引き離すとダニエル電池になる
lead: 亜鉛板を Cu²⁺ の水溶液に入れると銅が析出します。この反応の酸化剤と還元剤を別の容器に分けたものがダニエル電池です。
terms:
- 金属樹
- 銅樹
- ダニエル電池
:::

亜鉛板を硫酸銅(Ⅱ)水溶液に入れると、Zn が e⁻ を失って Zn²⁺ として溶けだし、Cu²⁺ が亜鉛板の上で e⁻ を受け取って Cu が析出します（銅樹）。イオン化傾向が Zn ＞ Cu なので、Zn のほうが陽イオンになりやすく、Cu のほうが単体になりやすいためです。

:::reaction
left: Zn
right: Zn²⁺ ＋ 2e⁻
level: ★★★
note: 還元剤。亜鉛板から水溶液中へ溶けだします。
:::

:::reaction
left: Cu²⁺ ＋ 2e⁻
right: Cu
level: ★★★
note: 酸化剤。水溶液中の Cu²⁺ が、板の上で Cu になって析出します。
:::

銅樹では、この2つの反応が**同じ亜鉛板の上**で起こっています。還元剤の Zn と酸化剤の Cu²⁺ を別々の容器に分け、導線でつなぐと、e⁻ は導線を通って流れるしかなくなります。これが**ダニエル電池**です。**銅樹の生成とダニエル電池は、同じ反応式で書ける同じ原理の反応です。**

:::section
anchor: daniell
title: ダニエル電池の仕組み
lead: 硫酸亜鉛水溶液に亜鉛板、硫酸銅(Ⅱ)水溶液に銅板を浸し、素焼き板で仕切ります。負極活物質は Zn、正極活物質は Cu²⁺ です。
terms:
- 素焼き板
- 電池の構成
:::

ダニエル電池は、硫酸亜鉛 ZnSO₄ 水溶液に亜鉛板を、硫酸銅(Ⅱ) CuSO₄ 水溶液に銅板を浸し、2つの水溶液を素焼き板で仕切った電池です。電池のつくりは、左から負極・電解液・正極の順に化学式で書き、これを電池の構成といいます。

ダニエル電池の構成は **（−）Zn｜ZnSO₄aq｜CuSO₄aq｜Cu（＋）** です。負極の Zn が溶けだし、正極の銅板の上に Cu が析出します。

:::figure
src: cell-basics-daniell.png
alt: ダニエル電池の模式図。左の硫酸亜鉛水溶液に亜鉛板、右の硫酸銅(Ⅱ)水溶液に銅板があり、間に素焼き板がある。亜鉛板から Zn²⁺ が溶けだし、e⁻ が導線を通って銅板へ流れ、銅板の上で Cu²⁺ が Cu になる。SO₄²⁻ が素焼き板を通って右から左へ移動している
caption: 亜鉛板（負極）から出た e⁻ は導線を通って銅板（正極）へ流れます。水溶液の中では、**素焼き板を SO₄²⁻ が通ることで回路が閉じます**。
:::

放電を続けると、負極側では Zn²⁺ が増え、正極側では Cu²⁺ が減ります。負極側で余った正の電荷と、正極側で余った負の電荷を打ち消すように、主に SO₄²⁻ が素焼き板を通って正極側から負極側へ移動します。

:::section
anchor: plate
title: 素焼き板の2つの役割
lead: 素焼き板は電解液が混ざるのを防ぎ、同時にイオンを通して回路をつくります。
terms:
- 素焼き板
:::

素焼き板には、細かい穴が無数に空いています。この穴のおかげで、素焼き板は次の2つの役割を同時に果たします。

:::list
ordered: true
items:
- 2つの電解液が混ざるのを（ある程度）防ぐ。
　混ざると Cu²⁺ が亜鉛板の上で直接 e⁻ を受け取るようになり、電流を取り出せなくなります（金属樹に逆戻り）。
- イオンを通して回路をつくる。
　イオンが通れないと、負極側に陽イオン、正極側に陰イオンが余り、その反発ですぐに反応が止まります。
:::

:::figure
src: cell-basics-porous-plate.png
alt: 左は素焼き板で仕切ったダニエル電池で、還元剤の Zn と酸化剤の Cu²⁺ が離れている。右は仕切りが無く2つの水溶液が混ざった場合で、Cu²⁺ が亜鉛板の上で直接 e⁻ を受け取っている
caption: 素焼き板が無いと電解液が混ざり、Cu²⁺ が亜鉛板の上で直接 e⁻ を受け取ってしまいます（金属樹に逆戻り）。
:::

素焼き板の代わりにガラス板で仕切った場合を考えると、2つ目の役割がよく分かります。ガラス板はイオンを通さないので、負極側には Zn²⁺ が、正極側には SO₄²⁻ が余ります。この電気的な反発で、電池の反応はすぐに止まってしまいます。

:::mistake
wrong: 素焼き板は、2つの電解液を完全に分けるための仕切りである
right: 素焼き板は**イオンを通す**仕切りです。混ざるのを防ぐ役割と、イオンの通り道になって回路をつくる役割の両方があります。
why: 「仕切り」という見た目から、1つ目の役割だけを覚えてしまうためです。★ ガラス板に替えると電流が止まる、と1つ具体例で覚えておけば、2つ目の役割を忘れません。
:::

:::section
anchor: positive
title: どちらが正極になるか
lead: イオン化傾向が小さい金属（e⁻ を受け取る力が強い側）が正極になります。
terms:
- イオン化傾向
:::

2種類の金属でつくった電池では、**イオン化傾向が大きい金属が負極、小さい金属が正極**になります。イオン化傾向が大きい金属の単体は e⁻ を放出しやすく（還元剤として強い）、イオン化傾向が小さい金属の陽イオンは e⁻ を受け取りやすい（酸化剤として強い）ためです。

具体例で確かめます。イオン化傾向は Zn ＞ Ni ＞ Cu ＞ Ag なので、Cu と Zn の組み合わせでは Cu が、Cu と Ag の組み合わせでは Ag が、Zn と Ni の組み合わせでは Ni が正極になります。

ちなみに、亜鉛板と銅板を希硫酸に浸した電池を**ボルタ電池**といい、構成は（−）Zn｜H₂SO₄aq｜Cu（＋）と書きます。正極では Cu²⁺ ではなく H⁺ が e⁻ を受け取って H₂ が発生します。**ボルタ電池は構成が書ければ十分です。**

:::section
anchor: range
title: 覚える範囲
lead: 負極・正極と還元剤・酸化剤の対応、ダニエル電池の構成と両極の反応式、素焼き板の2つの役割を覚えます。
:::

**ダニエル電池の構成（−）Zn｜ZnSO₄aq｜CuSO₄aq｜Cu（＋）と、両極の反応式2本は必ず書けるようにしてください。**反応式は、銅樹の反応式と同じです。

素焼き板は「混ざるのを防ぐ」「イオンを通して回路をつくる」の2つをセットで説明できるようにしましょう。電池の起電力の値や、標準電極電位の数値は覚えなくても構いません。
