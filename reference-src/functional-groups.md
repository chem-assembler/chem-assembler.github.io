有機化合物の特徴的な構造（パーツ）を**官能基**といいます。有機化合物の性質の大部分は官能基によって決まるため、分類や命名も官能基をもとに行われます。

:::section
anchor: what
title: 官能基とは何か
lead: 骨格が違っても、同じ官能基を持っていれば同じ性質を示します。だから官能基で分類します。
terms:
- 官能基
- 示性式
:::

例えば、エタノールとジメチルエーテルはどちらも同じ分子式 C₂H₆O をもちますが、その性質は大きく異なります。エタノールはヒドロキシ基 −OH をもつためアルコールに分類され、水に溶けやすい液体であるのに対し、ジメチルエーテルはエーテル結合 −O− をもつためエーテルに分類され、水に溶けにくい気体です。

//ジメチルエーテルとエタノールの構造式

逆に、骨格が違っても同じ官能基をもっていれば、同じはたらきをします。酢酸 CH₃COOH とギ酸 HCOOH は炭素の数が違いますが、どちらもカルボキシ基 −COOH を1個もつので、どちらも1価の弱酸（カルボン酸）です。

:::figure
src: functional-group-carboxy.png
alt: 酢酸とギ酸の構造式。どちらもカルボキシ基の部分が水色で囲まれ、その端の H 原子に「このH原子がH+となって電離する」と注が付いている
caption: 骨格（左の部分）は違っても、青く囲んだ**カルボキシ基**が同じなら、同じ「1価の弱酸」としてはたらきます。
:::

**表の上から9つ（太字の行）は、いますべて暗記してください。**残りの6つは、その名前が出てくる単元まで覚えなくて構いません —— ただし**「そういう名前の基がある」ことだけ**は、ここで見ておいてください。名前を知らないと、出てきたときに調べようがないからです。

原子の結合の手の数（原子価）を意識して、省略のない構造式を書けるようにしてください。結合の手の数は、C原子4本、O原子2本、H原子1本、N原子3本です。結合の手の数が合っていない構造式はよくある間違いです。特に初学者は、構造式を書くときに毎回すべての原子の手の数を確認するようにしましょう。

:::section
anchor: neighbor
title: 同じ官能基でも、隣が変われば別のグループ
lead: ヒドロキシ基 −OH は、付いている炭素がベンゼン環かどうかで、フェノール類とアルコールに分かれます。
terms:
- アルコール
- フェノール類
:::

ヒドロキシ基 −OH の場合は、結合しているC原子が、ベンゼン環（フェノール類）か、その他（アルコール）か、で性質も分類も変わります。

:::figure
src: functional-group-alcohol-phenol.png
alt: ヒドロキシ基をもつ化合物グループの図。上が R−O−H でアルコール、下が六角形のベンゼン環に −O−H が付いたフェノール
caption: 同じ −OH でも、付いている相手が**ベンゼン環かどうか**で、アルコールとフェノール類に分かれます。
:::

:::section
anchor: nitro-sulfo
title: ニトロ基とスルホ基は、硝酸と硫酸から来ている
advanced: true
lead: 構造には配位結合が含まれるので、そこは発展内容です。まずは −NO₂ と −SO₃H の形だけ覚えれば十分です。
terms:
- ニトロ基
- スルホ基
- 配位結合
:::

ニトロ基 −NO₂ とスルホ基については、配位結合を含むので発展内容になります。まずは省略した −NO₂ と −SO₃H を覚えていれば十分です。硝酸から OH をとった構造がニトロ基、硫酸から OH をとった構造がスルホ基であることを理解し、知識の関連付けをすると暗記が楽になります。

:::figure
src: nitro-from-nitric.png
alt: 硝酸 HNO3 の構造式と電子式。H−O−N と並び、N から O へ二重結合と、矢印で書いた配位結合が1本ずつ伸びている
caption: **硝酸 HNO₃** から −OH を取り去った残りが**ニトロ基 −NO₂** です。N から O へ伸びる矢印が配位結合。
:::

:::figure
src: sulfo-from-sulfuric.png
alt: 硫酸 H2SO4 の構造式と電子式。中心の S から O へ矢印で書いた配位結合が2本、H−O− が2本伸びている
caption: **硫酸 H₂SO₄** から −OH を1つ取り去った残りが**スルホ基 −SO₃H** です。
:::
