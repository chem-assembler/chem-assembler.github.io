化学反応では、反応物の結合が切れて、生成物の新しい結合ができます。このページでは、結合を切るのに要るエネルギーから反応エンタルピーを求める方法を扱います。どの経路を通っても高さの差は同じ、というヘスの法則をそのまま使います。

terms:
- 結合エンタルピー
- 結合エネルギー

気体分子の中の共有結合を切るのに必要なエネルギーを、その結合の**結合エンタルピー**（結合エネルギー）といいます。結合 1mol あたりの値で、単位は kJ/mol です。

具体例1で、水素分子 H₂ 1mol をばらばらの水素原子 2mol にするには 436kJ が要ります。H−H の結合エンタルピーは 436kJ/mol です。

:::reaction
left: H₂(気)
right: 2H(気)　ΔH ＝ ＋436 kJ
level: ★★★
note: 結合を切るにはエネルギーが要るので、ΔH はいつも正です。
:::

逆に、水素原子 2mol が結合して H₂ 1mol ができるときは、436kJ が放出されます（ΔH ＝ −436kJ）。**結合を切るときは ＋、結合ができるときは −** です。結合ができると原子どうしが安定になり、その分のエネルギーが外に出るためです。

多原子分子では、分子の中の結合の数で割って、結合 1 本あたりの値にします。

具体例2で、メタン CH₄ 1mol の結合をすべて切って C 原子 1mol と H 原子 4mol にするには 1664kJ が要ります。CH₄ 1 分子には C−H 結合が4本あるので、C−H の結合エンタルピーは 1664 ÷ 4 ＝ 416kJ/mol です。

**結合エンタルピーの値は問題文で与えられるので、覚える必要はありません。**ただし、二重結合は同じ原子どうしの単結合より大きい（切りにくい）ことは知っておきましょう。

:::section
anchor: diagram
title: 原子をいちばん上に置く図
lead: 反応物を基準 0 に置き、結合をすべて切った原子の状態をその上に、生成物を下に置きます。反応エンタルピーは、原子の状態を経由した高さの差で求められます。
:::

結合エンタルピーを使うときは、エネルギー図に**「結合をすべて切った原子の状態」**という準位を1つ足します。どの反応物も生成物も、結合を切れば同じ原子の組になるので、この準位を経由すればヘスの法則が使えます。

次の順で進めます。

:::list
ordered: true
items:
- 反応物・生成物の構造式を描き、切れる結合と、できる結合を数える。
- 反応物を基準 0 に置く。
- 反応物の結合をすべて切った原子の状態は、0 ＋（反応物の結合エンタルピーの和）の高さ。
- 生成物は、原子の状態から（生成物の結合エンタルピーの和）だけ下。
- 反応エンタルピー ＝（生成物の高さ）− 0。
:::

具体例3で、H₂ ＋ Cl₂ → 2HCl の反応エンタルピーを求めます。

:::list
ordered: true
items:
- 切れるのは H−H 1本と Cl−Cl 1本、できるのは H−Cl 2本。
- 反応物 H₂(気) ＋ Cl₂(気) を 0 とする。
- 原子 2H(気) ＋ 2Cl(気) の高さは 436 ＋ 243 ＝ ＋679。
- 生成物 2HCl(気) は、原子の状態から 2×432 ＝ 864 下なので、679 − 864 ＝ −185。
- ΔH ＝ −185 − 0 ＝ **−185kJ**。
:::

:::reaction
left: H₂(気) ＋ Cl₂(気)
right: 2HCl(気)　ΔH ＝ −185 kJ
level: ★★★
note: 切るのに 679kJ 要り、できるときに 864kJ 出るので、差し引き 185kJ の発熱です。
:::

この図から、次の関係が出てきます。

**反応エンタルピー ＝（反応物の結合エンタルピーの和）−（生成物の結合エンタルピーの和）**

:::table
caption: 生成エンタルピーの式と、結合エンタルピーの式
source: このページと hess-law のページの本文の2つの式を、基準の置き方と一緒に並べたもの
head:
- 使う値
- 基準 0 に置く準位
- 反応エンタルピー
align: left | left | left
rows:
- 生成エンタルピー | いちばん上の単体の組 | （生成物の和）−（反応物の和）
- 結合エンタルピー | 反応物（原子はその上） | （反応物の和）−（生成物の和）
:::

:::mistake
wrong: 結合エンタルピーでも、生成エンタルピーと同じく「（生成物）−（反応物）」で計算する
right: 結合エンタルピーは**（反応物の和）−（生成物の和）**です。生成エンタルピーとは引く向きが逆になります。
why: 生成エンタルピーは単体（いちばん上）から下向きに測った値、結合エンタルピーは原子（いちばん上）へ向かって上向きに測った値で、**測る向きが逆**だからです。★ 式を覚えるより、原子を上に置いた図を描けば向きは迷いません。
:::

:::callout
tone: caution
text: 結合エンタルピーで計算できるのは、**反応物も生成物もすべて気体**のときだけです。液体の水ができる反応では、水蒸気ができるとして計算し、そのあと凝縮のエンタルピー（−44kJ/mol）を足します。
:::

:::section
anchor: range
title: 覚える範囲
lead: 「切るときは ＋、できるときは −」と、原子をいちばん上に置く図を覚えます。結合エンタルピーの値は与えられます。
:::

**「結合を切るときは ＋、できるときは −」と「原子の状態をいちばん上に置く図」は必ず覚えてください。**図が描ければ、（反応物の和）−（生成物の和）の式も、その逆問題も同じ手順で解けます。

結合の数え間違いがいちばん多い失点です。**係数の分だけ分子があり、1分子の中にも同じ結合が何本もある**（CH₄ の C−H は4本、CO₂ の C＝O は2本）ことに気をつけましょう。

## 例題

:::exercise
source: 自作（このページの表の値から作った問い。答えは教科書の水蒸気の生成エンタルピー −242kJ/mol とほぼ一致する）
prompt: H−H、O＝O、O−H の結合エンタルピーをそれぞれ 436kJ/mol、498kJ/mol、463kJ/mol とする。**H₂(気) ＋ ½O₂(気) → H₂O(気) の反応エンタルピーは何 kJ か。**
answer: **−241kJ**。切れるのは H−H 1本と O＝O ½本で、436 ＋ 498×½ ＝ 685。できるのは O−H 2本で、2×463 ＝ 926。反応物を 0 とすると原子の状態は ＋685、生成物は 685 − 926 ＝ −241。ΔH ＝ −241kJ。
:::

:::exercise
source: 自作（ratio/thermo の h5 と同じ型の逆問題）
prompt: H₂(気) ＋ ½O₂(気) → H₂O(気)　ΔH ＝ −242 kJ である。H−H、O＝O の結合エンタルピーをそれぞれ 436kJ/mol、498kJ/mol とするとき、**O−H の結合エンタルピーは何 kJ/mol か。**
answer: **464kJ/mol**。反応物を 0 とすると、原子の状態は 436 ＋ 249 ＝ ＋685、生成物 H₂O(気) は −242。原子の状態から生成物までは 685 −（−242）＝ 927 下りるので、O−H 2本の和が 927kJ。1本あたり 927 ÷ 2 ≒ 464kJ/mol。
:::
