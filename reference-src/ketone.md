カルボニル基 C=O が炭素鎖の途中にあり、**両側を炭化水素基にはさまれている**化合物 —— これが**ケトン**です。示性式は **R−CO−R'** と書き、いちばん簡単なものが**アセトン** CH₃COCH₃ です。

:::section
anchor: what
title: ケトンはどんな化合物か
lead: アルデヒドと同じ一般式 C~n~H~2n~O。2級アルコールを酸化するとできて、そこから先へは進みません。
terms:
- カルボニル化合物
- 構造異性体
:::

鎖式で飽和のケトンの一般式は **C~n~H~2n~O** で、アルデヒドとまったく同じです。n=3 を代入すると C₃H₆O で、これがアセトンの分子式です。同じ C₃H₆O をもつアルデヒドはプロピオンアルデヒド CH₃CH₂CHO で、**この2つは互いに構造異性体**です。

アルデヒドとケトンをまとめて**カルボニル化合物**とよびます。構造上の違いは、**カルボニル基が鎖の端にあるか（アルデヒド）、端以外にあるか（ケトン）**の1点だけです。

ケトンは**2級アルコールを酸化すると生じます**。アルデヒドと違って、**そこからさらに酸化されることはありません**。

:::link
to: alcohol-oxidation-map
text: 1級アルコール→アルデヒド→カルボン酸、2級アルコール→ケトンという酸化の行き先の対応表はこちら
:::

カルボニル基は極性が強いので、**炭素数3のアセトンは水と任意の割合で混ざり合い**、**炭素数4の2-ブタノンまでは水に溶けます**。炭素数5以上のケトンはほとんど水に溶けません。

ケトンは常温では安定で、高校化学の範囲では反応しません。そのため**有機溶媒**として使われます。

:::section
anchor: naming
title: ケトンの命名
lead: 両側の2つのアルキル基の名称を続けて、語尾に「ケトン」を付けた慣用名を使います。
terms:
- アセトン
- メチルエチルケトン
:::

規則どおりの名称は、対応するアルカンの語尾「-ane（アン）」を「-anon（アノン）」に変えたものです。炭素3個なら「2-プロパノン」、4個なら「2-ブタノン」になります。

ただし高校化学ではこの名前をまず見かけないので、**覚えるのは慣用名のほう**です。慣用名は、カルボニル基の両側にあるアルキル基の名称を2つ続けて、語尾に「ケトン」を付けてつくります。2つが同じなら「ジ○○ケトン」です。

:::figure

caption: 上は両側ともメチル基なので「ジメチルケトン」ですが、**アセトン**という呼び方のほうが圧倒的によく使われます。下はメチル基とエチル基で「メチルエチルケトン」です。
:::

**アセトン CH₃COCH₃ は示性式ごと必ず暗記してください。**2-ブタノンのほうは「メチルエチルケトン」という呼び名で出てくることが多いので、そう呼ばれたときに構造が書ければ十分です。

:::section
anchor: distinguish
title: アルデヒドとの区別 —— 還元性がない
lead: ケトンは酸化されにくく、銀鏡反応もフェーリング液の還元も示しません。分子式が同じアルデヒドとの決め手がこれです。
terms:
- 還元性
:::

アルデヒドは酸化されてカルボン酸になりやすく、そのぶん**還元性**を示しました。**ケトンは酸化されにくいので、還元性を示しません。**

したがってケトンは、**銀鏡反応もフェーリング液の還元も起こしません**。分子式が同じアルデヒドとケトンを見分けるときは、この2つの反応を使います。

:::table
caption: 同じ一般式 C~n~H~2n~O のアルデヒドとケトンを並べる

- 比べる点
- アルデヒド
- ケトン

rows:

- 何を酸化するとできるか | 第1級アルコール | 第2級アルコール

- 銀鏡反応・フェーリング液の還元 | 示す | 示さない
- 例（C₃H₆O） | プロピオンアルデヒド CH₃CH₂CHO | アセトン CH₃COCH₃

**「アルデヒドは還元性あり、ケトンは還元性なし」は必ず暗記してください。**構造決定でいちばんよく使う分岐の1つです。

ただし、あとで出てくる糖類の**フルクトース**はケトンの仲間なのにフェーリング液を還元します。カルボニル基のとなりにヒドロキシ基があり、塩基性の中でアルデヒドの構造に変わるためです。

**ケトンを還元すると2級アルコールに戻ります**が、これは高校化学の範囲の外の反応なので**覚えなくても構いません。**問題文に「還元して」と出てきたら、酸化の逆向きが起きたと考えれば十分です。

:::section
anchor: iodoform
title: ケトンとヨードホルム反応
lead: アセチル基 −COCH₃ をもつケトンは、ヨウ素と水酸化ナトリウム水溶液を加えて加熱すると黄色沈殿を出します。ケトンでは実質アセトンの話です。
terms:
- ヨードホルム反応
- アセチル基
:::

**カルボニル基 −CO− の一方にメチル基 −CH₃ が結合している**化合物 ＝ **アセチル基 −COCH₃** をもつ化合物は、ヨウ素 I₂ と水酸化ナトリウム水溶液とともに加熱すると、**ヨードホルム CHI₃ の黄色沈殿**を生じます。これを**ヨードホルム反応**といいます。

ケトンでこの条件に当てはまるのは、**アセトン CH₃COCH₃** をはじめとする「メチル○○ケトン」の形のものです。**アセトンがヨードホルム反応を示すことは必ず覚えてください。**アセトンかどうかを1回で決める手として、構造決定でよく使われます。

:::link

:::

:::section
anchor: acetone
title: アセトン
lead: 各論として出るケトンはアセトンだけ。つくり方が3通りあります。
terms:
- アセトン
- 乾留
:::

**アセトン CH₃COCH₃** は無色で特有のにおいのある揮発性の液体です。水と任意の割合で混ざるうえ、多くの有機化合物も溶かし、それ自身は反応しにくいので、**溶媒**としてよく使われます。

つくり方は3通り出てきます。1つめは、2級アルコールである**2-プロパノールの酸化**です。

2つめは、**酢酸カルシウムの乾留**（空気を断って加熱すること）です。

:::reaction
left: (CH₃COO)₂Ca
over: 乾留
right: CH₃COCH₃ ＋ CaCO₃
level: ★★★
note: **丸暗記**でかまいません。係数はすべて 1 なので、反応物さえ覚えていればアセトン CH₃COCH₃ の残りが炭酸カルシウム CaCO₃ です。
:::

3つめは工業的な方法で、**プロペンの酸化**です。

:::reaction
left: 2CH₂=CHCH₃ ＋ O₂
over: PdCl₂・CuCl₂
right: 2CH₃COCH₃
level: ★★☆
note: エテンからアセトアルデヒドをつくるときと同じ触媒です。並べて覚えると1つぶん得をします。
:::

このほか、芳香族で学習する**クメン法**でフェノールと同時に得られます。
