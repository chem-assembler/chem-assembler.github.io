**鉛蓄電池**は、自動車のバッテリーに使われる代表的な二次電池です。燃料電池と並んで、仕組みまで覚えておくべき電池です。このページでは、両極の反応式を1段ずつ組み立て、質量と濃度の変化を計算できるようにします。

:::section
anchor: outline
title: 鉛蓄電池のつくり
lead: 負極に鉛 Pb、正極に酸化鉛(Ⅳ) PbO₂、電解液に希硫酸を使います。放電すると両極に硫酸鉛(Ⅱ) PbSO₄ が付き、硫酸の濃度が下がります。
terms:
- 鉛蓄電池
- 酸化鉛(Ⅳ)
- 硫酸鉛(Ⅱ)
:::

鉛蓄電池の構成は **（−）Pb｜H₂SO₄aq｜PbO₂（＋）** です。負極活物質は鉛 Pb、正極活物質は酸化鉛(Ⅳ) PbO₂ で、電解液には希硫酸を使います。起電力は約 2.0V です。

:::figure
src: lead-storage-battery-overview.png
alt: 鉛蓄電池の模式図。左の負極 Pb から Pb²⁺ が出て SO₄²⁻ と結びつき、極板の表面に付く。右の正極 PbO₂ からも Pb²⁺ が出て SO₄²⁻ と結びつき、PbO₂ の O は H⁺ と H₂O になる。電解液は希硫酸
caption: 両極とも Pb²⁺ になって溶けだそうとしますが、SO₄²⁻ とすぐに沈殿して、極板の表面に PbSO₄ が付きます。
:::

放電のときに起こることは、次の4つにまとめられます。

:::list
ordered: true
items:
- 負極の Pb が e⁻ を失って、鉛(Ⅱ)イオン Pb²⁺ として溶けだそうとする。
- 正極の PbO₂ が e⁻ を受け取って、Pb²⁺ として溶けだそうとする。
- PbO₂ の O 原子は、電解液中の H⁺ と結びついて H₂O になる。
- Pb²⁺ は SO₄²⁻ と沈殿をつくるので、両極の表面に PbSO₄ が付く。
　溶けださずに極板に付くので、電解液の硫酸は濃度が下がっていきます。
:::

:::section
anchor: negative
title: 負極の反応式の組み立て
lead: Pb → Pb²⁺ ＋ 2e⁻ の両辺に SO₄²⁻ を足して、Pb²⁺ を PbSO₄ にします。
:::

負極の鉛は、まず e⁻ を2個失って Pb²⁺ になろうとします。

:::reaction
left: Pb
right: Pb²⁺ ＋ 2e⁻
level: ★★☆
note: 組み立ての1段目。Pb の酸化数は 0 → ＋2。
:::

Pb²⁺ は電解液中の SO₄²⁻ と沈殿をつくります。そこで、**両辺に SO₄²⁻ を加えて**、右辺の Pb²⁺ を PbSO₄ にまとめます。

:::reaction
left: Pb ＋ SO₄²⁻
right: PbSO₄ ＋ 2e⁻
level: ★★★
note: 負極の反応式。極板の Pb が、極板の上の PbSO₄ に変わります。
:::

負極の極板は、**e⁻ 2mol が流れるごとに Pb 1mol（207g）が PbSO₄ 1mol（303g）に変わります**。付け加わるのは SO₄ の分なので、**質量は 96g 増えます**（Pb＝207、S＝32、O＝16）。

:::section
anchor: positive
title: 正極の反応式の組み立て
lead: PbO₂ を Pb⁴⁺ と 2O²⁻ に分けて考え、Pb⁴⁺ を PbSO₄ に、2O²⁻ を 4H⁺ と合わせて 2H₂O にします。
:::

PbO₂ に含まれる Pb の酸化数は ＋4 です。この Pb⁴⁺ が e⁻ を2個受け取って Pb²⁺ になり、残った O は O²⁻ として出ていく、と考えます。

:::reaction
left: PbO₂ ＋ 2e⁻
right: Pb²⁺ ＋ 2O²⁻
level: ★☆☆
note: 組み立ての1段目（考えるための式で、書く必要はありません）。Pb の酸化数は ＋4 → ＋2。
:::

負極と同じように、両辺に SO₄²⁻ を加えて Pb²⁺ を PbSO₄ にします。さらに、O²⁻ は電解液中の H⁺ と結びついて H₂O になるので、**両辺に 4H⁺ を加えて** 2O²⁻ を 2H₂O にまとめます。

:::reaction
left: PbO₂ ＋ 4H⁺ ＋ SO₄²⁻ ＋ 2e⁻
right: PbSO₄ ＋ 2H₂O
level: ★★★
note: 正極の反応式。極板の PbO₂ が、極板の上の PbSO₄ に変わります。
:::

:::link
app: ion-equation/halfreaction
id: Pb_ox,PbO2_red
text: 鉛蓄電池の負極・正極の半反応式を組む
:::

正極の極板は、**e⁻ 2mol が流れるごとに PbO₂ 1mol（239g）が PbSO₄ 1mol（303g）に変わります**。差し引きで S 1個・O 2個の分、**質量は 64g 増えます**。

:::mistake
wrong: 放電すると、負極の鉛は溶けて軽くなる
right: 負極の鉛は Pb²⁺ になっても溶けださず、**PbSO₄ として極板に付く**ので、負極も正極も**重くなります**。
why: 「負極の金属は溶ける」というダニエル電池の印象を、そのまま当てはめてしまうためです。★ 鉛蓄電池では Pb²⁺ が SO₄²⁻ と沈殿する、の1点だけが違います。
:::

:::section
anchor: whole
title: 全体の反応式と電解液の変化
lead: 両極の式を足すと、e⁻ 2mol あたり H₂SO₄ が 2mol 減り、H₂O が 2mol 増えます。
:::

両極の式は、どちらも e⁻ の係数が2でそろっているので、そのまま足し合わせます。左辺の 4H⁺ と 2SO₄²⁻ を 2H₂SO₄ にまとめると、全体の反応式になります。

:::reaction
left: Pb ＋ PbO₂ ＋ 2H₂SO₄
over: 放電
arrow: ⇄
right: 2PbSO₄ ＋ 2H₂O
level: ★★★
note: 全体の反応。右向きが放電、左向きが充電です。e⁻ 2mol が流れるごとに、電解液では H₂SO₄ が 2mol 減り、H₂O が 2mol 増えます。
:::

放電すると H₂SO₄ が減って H₂O が増えるので、**電解液の硫酸の濃度（密度）は下がります**。

head:
- 項目
- 負極
- 正極

:::section
anchor: charge
title: 充電と、鉛蓄電池を動かす力
lead: 外部電源の正極を鉛蓄電池の正極に、負極を負極につなぐと、放電と逆向きの反応が進んで充電できます。
terms:
- 充電
:::

鉛蓄電池は二次電池です。外部の電源の正極を鉛蓄電池の正極へ、負極を負極へつなぐと、放電のときと逆向きに電流が流れ、両極で逆向きの反応が起こります。放電のときは e⁻ 2mol につき PbSO₄ が 2mol できますが、充電のときは e⁻ 2mol につき PbSO₄ が 2mol 分解されます。

ダニエル電池は、2種類の金属のイオン化傾向の差で e⁻ を流していました。鉛蓄電池は、正極も負極も同じ鉛でできています。それでも電流が流れるのは、**酸化数が ＋4 の Pb と 0 の Pb が、どちらも ＋2 になろうとする**ためです。

:::figure
src: lead-storage-battery-oxnum.png
alt: 左に PbO₂ ＋ 2e⁻ → Pb²⁺ ＋ 2O²⁻（酸化数 ＋4 → ＋2）と Pb → Pb²⁺ ＋ 2e⁻（0 → ＋2）の式。右に酸化数の軸があり、＋4 の Pb⁴⁺ と 0 の Pb が矢印で ＋2 の Pb²⁺ に向かっている
caption: e⁻ の数（酸化数）が違う Pb 原子どうしが、e⁻ の数の等しい ＋2 にそろおうとする力が、鉛蓄電池を動かしています。
:::

:::section
anchor: range
title: 覚える範囲
lead: 構成と、負極・正極・全体の3本の式を覚えます。質量の増え方は式から出します。
:::

**鉛蓄電池の構成と、負極・正極・全体の反応式3本は必ず暗記してください。**3本とも、上の組み立ての順（溶けだそうとする → SO₄²⁻ と沈殿 → O は H⁺ と H₂O）で思い出せるようにしておくと、忘れても書き直せます。

「負極 96g 増・正極 64g 増（e⁻ 2mol あたり）」は、覚えてもよいですが、式の両辺の式量の差からその場で出せるようにしましょう。起電力の約 2.0V は覚えなくても構いません。

## 例題

:::exercise
source: slides:電池の基本３「鉛蓄電池」s14〜s17「練習」(1)(2)（解答も同じ枚）
prompt: 鉛蓄電池を放電して 1.0mol の電子を流した（Pb＝207、H＝1.0、O＝16、S＝32）。**(1) 正極、負極の質量変化を有効数字2桁で求めよ。　(2) 放電前の電解液を 1.0kg の 30% 希硫酸として、放電後の質量パーセント濃度を求めよ。**
answer: (1) 正極は 32g 増加、負極は 48g 増加。正極 PbO₂ ＋ 4H⁺ ＋ SO₄²⁻ ＋ 2e⁻ → PbSO₄ ＋ 2H₂O より e⁻ 2mol で 64g 増なので、e⁻ 1mol では 32g 増。負極 Pb ＋ SO₄²⁻ → PbSO₄ ＋ 2e⁻ より e⁻ 2mol で 96g 増なので、e⁻ 1mol では 48g 増。　(2) 22%。全体の式から e⁻ 2mol で H₂SO₄ 2mol 減・H₂O 2mol 増なので、e⁻ 1mol では H₂SO₄ が 1mol（98g）減り、H₂O が 1mol（18g）増える。放電前は H₂SO₄ 300g・H₂O 700g・全体 1000g なので、放電後は H₂SO₄ 202g・全体 920g。202 ÷ 920 × 100 ＝ 21.9… ≒ 22%。
:::

:::exercise
source: 自作（slides:電池の基本３ s12「まとめ」の★★★の式を物質名から書く問いにしたもの）
prompt: 鉛蓄電池の負極・正極の反応を e⁻ を含むイオン反応式で書き、それを足し合わせて全体の化学反応式を書け。
answer: 負極：Pb ＋ SO₄²⁻ → PbSO₄ ＋ 2e⁻　正極：PbO₂ ＋ 4H⁺ ＋ SO₄²⁻ ＋ 2e⁻ → PbSO₄ ＋ 2H₂O　全体：Pb ＋ PbO₂ ＋ 2H₂SO₄ → 2PbSO₄ ＋ 2H₂O（左辺の 4H⁺ と 2SO₄²⁻ を 2H₂SO₄ にまとめる）
:::
