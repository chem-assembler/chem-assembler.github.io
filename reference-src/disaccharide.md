単糖2分子から水1分子がとれてつながった糖を**二糖**といいます。砂糖の主成分のスクロースも、麦芽に多いマルトースも二糖です。

:::section
anchor: definition
title: 二糖とは
lead: 単糖2分子が脱水縮合してできます。六炭糖2分子からできる二糖の分子式は、どれも C₁₂H₂₂O₁₁ です。
terms:
- 二糖
- グリコシド結合
- 縮合
:::

二糖は、単糖2分子から**水1分子がとれて**つながったものです。このつながりを**グリコシド結合**といいます。

分子式をその場で引き算してみます。C₆H₁₂O₆ が2分子で C₁₂H₂₄O₁₂、ここから H₂O を1つ引くと **C₁₂H₂₂O₁₁** です。分子量も 180 × 2 − 18 ＝ **342** になります。

:::reaction
left: 2C₆H₁₂O₆
right: C₁₂H₂₂O₁₁ ＋ H₂O
level: ★★☆
note: 二糖ができる縮合。逆向きに水を加えて切るのが加水分解です。
:::

**「二糖の分子式は C₁₂H₂₂O₁₁、分子量は342」は覚えておきましょう。**忘れても、上の引き算で毎回出せます。

- ラクトース（乳糖） | グルコース ＋ ガラクトース | ラクターゼ | あり

**この表の4行（構成する単糖・酵素・還元性）は暗記してください。**α-1,4 のような結合の位置の番号は覚えなくて構いません。

**「還元性が無いのはスクロースだけ」**と覚えましょう。

具体例として、マルトースの加水分解を式で書くとグルコース2分子になります。

:::reaction
left: C₁₂H₂₂O₁₁（マルトース） ＋ H₂O
over: マルターゼ
right: 2C₆H₁₂O₆（グルコース）
level: ★★★
note: 酸を加えて加熱しても同じように加水分解されます。
:::

:::reaction
left: C₁₂H₂₂O₁₁（ラクトース） ＋ H₂O
over: ラクターゼ
right: C₆H₁₂O₆（グルコース） ＋ C₆H₁₂O₆（ガラクトース）
level: ★★☆
note: 乳にふくまれる二糖です。
:::

:::reaction
left: C₁₂H₂₂O₁₁（セロビオース） ＋ H₂O
over: セロビアーゼ
right: 2C₆H₁₂O₆（グルコース）
level: ★★☆
note: セルロースを途中まで加水分解すると得られます。マルトースとは、つながっているグルコースが α形か β形かだけが違います。
:::

マルトースとセロビオースはどちらもグルコース2分子ですが、**マルトースは α-グルコース、セロビオースは β-グルコース**がつながったものです。それぞれデンプンとセルロースの部分構造にあたります。

:::section
anchor: sucrose
title: スクロースだけ還元性を示さないわけ
lead: 還元性の出どころは「環が開いてホルミル基が現れる部分」です。スクロースはその部分どうしでつながっているので、どちらの環も開けません。
terms:
- 還元性
- スクロース
:::

単糖の還元性は、環が開いて鎖状になり、**ホルミル基が現れる**ことから出ます。環が開けるのは、グルコースなら1位の炭素の −OH の部分です。

マルトースでは、片方のグルコースの1位が相手とつながっていますが、**もう片方のグルコースの1位は −OH のまま残っています**。だからそちらの環が開けて、還元性を示します。

スクロースでは、グルコースの1位とフルクトースの2位（どちらも環が開ける部分）**どうしでつながっています**。両方ともふさがっているので、どちらの環も開けず、**還元性を示しません**。

:::figure
src: disaccharide-sucrose.png
gen: name=スクロース（ショ糖） plain
alt: スクロースの構造式を直交で描いた図。六員環のグルコースと五員環のフルクトースが、1個の酸素原子を間にはさんでつながっている
caption: **スクロース**。六員環のグルコースと五員環のフルクトースが、環が開ける部分どうしでつながっています。
:::

//図: マルトース（環が開ける端が1つ残る）とスクロース（両方ふさがる）の、その1か所を丸で囲んだ図（作図器＋印）

:::mistake
wrong: 二糖はどれも単糖が2つつながったものなので、単糖と同じように還元性を示す
right: **スクロースは還元性を示しません。**マルトース・ラクトース・セロビオースは示します。
why: 「単糖はすべて還元性を示す」をそのまま二糖に広げてしまうためです。★ 還元性はつなぎ方で決まり、スクロースは環が開ける部分どうしでつながっています。
:::

:::section
anchor: invert-sugar
title: 転化糖
lead: スクロースを加水分解すると、グルコースとフルクトースの等量混合物になります。これを転化糖といい、還元性を示します。
terms:
- 転化糖
- スクラーゼ
- インベルターゼ
:::

スクロースに**希硫酸を加えて加熱する**か、酵素**スクラーゼ（インベルターゼ）**を作用させると、グルコースとフルクトースに分かれます。この等量混合物を**転化糖**といいます。

:::reaction
left: C₁₂H₂₂O₁₁（スクロース） ＋ H₂O
over: スクラーゼまたは希硫酸
right: C₆H₁₂O₆（グルコース） ＋ C₆H₁₂O₆（フルクトース）
level: ★★★
note: ふさがっていた部分がほどけて、単糖が2つとも還元性を示すようになります。
:::

**「スクロースは還元性なし、加水分解した転化糖は還元性あり」は必ず暗記してください。**

⚠ 希硫酸で加水分解した液は酸性なので、**中和してから**フェーリング液を加えます。フェーリング液は塩基性でないとはたらかないためです。

名前の「転化」は、加水分解の前後で、液が偏光を回す向き（旋光性）が逆に転じることから来ています。旋光性そのものは覚えなくて構いません。

:::section
anchor: glycoside
title: 配糖体
advanced: true
lead: 糖の環が開ける部分の −OH が、糖以外の分子と結合したものを配糖体といいます。スクロースが還元性を示さないのと同じ仕掛けです。
terms:
- 配糖体
:::

植物の色素や薬の成分には、糖の環が開ける部分の −OH が、糖ではない別の分子と結合しているものがあります。これを**配糖体**といいます。

環が開ける部分がふさがっているので、配糖体そのものは還元性を示しません。加水分解すると糖がはずれて、還元性が現れます。**スクロースと同じ仕掛け**と考えれば十分です。個々の配糖体の名前は覚えなくて構いません。

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: reference-outline/bio.md 第2部 disaccharide の例題1（①ドラフトのために起こした記述問題）
prompt: スクロースが還元性を示さない理由を書け。
answer: グルコースとフルクトースが、**たがいの環が開ける部分（還元性を示す部分）どうしで結合している**ためです。どちらの環も開けないので、ホルミル基が現れません。
:::

:::exercise
source: reference-outline/bio.md 第2部 disaccharide の例題2（①ドラフトのために起こした計算問題）
prompt: スクロース 34.2 g を完全に加水分解したとき、得られる転化糖の質量を求めよ。H ＝ 1、C ＝ 12、O ＝ 16 とする。
answer: スクロースの分子量は342なので 0.100 mol。水 0.100 mol（1.80 g）が加わるので、**36.0 g**（グルコース 18.0 g ＋ フルクトース 18.0 g）です。
:::

:::exercise
source: reference-outline/bio.md 第1部 disaccharide の例題(b)（①ドラフトのために起こした選択問題）
prompt: 次のうち、還元性を示すものをすべて選べ。マルトース、スクロース、ラクトース、セロビオース、転化糖
answer: **マルトース、ラクトース、セロビオース、転化糖**。還元性を示さないのはスクロースだけです。
:::
