酸化剤と還元剤は、e⁻ の数がちょうど釣り合う量どうしで反応します。そこで、濃さを正確に知っている酸化剤の水溶液をビュレットから加えていき、相手の還元剤がちょうど使い切られるまでの体積を読めば、還元剤の濃さが逆算できます（酸化剤と還元剤を入れ替えても同じです）。これが「酸化還元滴定」です。

:::link
to: redox-equation
text: 酸化剤と還元剤は価数の逆の比で反応する（「酸化還元反応式の組み立て」）
:::

用いる器具と操作法は、中和滴定とほぼ同じです。

:::link
to: titration
text: ビュレット・ホールピペットの使い方と共洗いは「中和滴定」で
:::

:::section
anchor: relation
title: 終点で成り立つ関係
lead: 終点では、酸化剤が受け取った e⁻ の物質量と、還元剤が放出した e⁻ の物質量が等しくなります。
terms:
- 酸化還元滴定
- 終点
:::

酸化還元滴定の終点では、e⁻ のやりとりがちょうど完了した状態になっています。

　（酸化剤が受け取った e⁻ の物質量）＝（還元剤が放出した e⁻ の物質量）

　（酸化剤の価数）×（酸化剤の物質量）＝（還元剤の価数）×（還元剤の物質量）

**計算はこの1本で解けます**。反応式の係数から比を立ててもかまいませんが、価数がわかっていれば化学反応式を書かずに式を立てられます。

高校化学で扱う酸化還元滴定は、次の2つでほぼ十分です。**終点をどう見分けるか**まで、セットで覚えておきましょう。

:::section

title: 過マンガン酸カリウムによる滴定
lead: KMnO₄ は自分の色が指示薬になります。終点は、滴下した赤紫色が消えずに残ったときです。
terms:
- 過マンガン酸カリウム
- 指示薬

硫酸酸性の KMnO₄ 水溶液では、赤紫色の MnO₄⁻ が淡赤色の Mn²⁺ に変わります。滴定の濃さでは Mn²⁺ の色はほぼ無色に見えます。

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 5価の酸化剤。赤紫色 → 淡赤色（滴定ではほぼ無色に見える）。
:::

還元剤の水溶液に KMnO₄ 水溶液を滴下すると、還元剤が残っているあいだは赤紫色がすぐに消えます。還元剤がなくなると、**滴下した KMnO₄ の赤紫色が消えずに残ります**。ここが終点です。**KMnO₄ は自分自身が指示薬の役目をする**ので、別の指示薬を加える必要がありません。

## 硫酸で酸性にする理由

MnO₄⁻ が Mn²⁺ まで還元されるには H⁺ が必要なので、水溶液を酸性にします。このとき**使うのは希硫酸で、塩酸や硝酸は使いません**。

:::mistake
wrong: 酸性にするだけなら、塩酸や硝酸を加えてもよい
right: KMnO₄ の滴定では、**希硫酸**で酸性にします。
why: 塩酸を使うと、塩化物イオン Cl⁻ が KMnO₄ に酸化されてしまい（Cl⁻ 自身が還元剤としてはたらく）、KMnO₄ の消費量が多くなります。硝酸を使うと、硝酸まで酸化剤として還元剤から e⁻ を受け取ってしまい、KMnO₄ が受け取るはずの e⁻ が横取りされます。どちらも滴下量が本当の値からずれます。硫酸は酸化剤にも還元剤にもならない（熱濃硫酸を除く）ので、H⁺ を出すだけの役に徹します。
:::

KMnO₄ 水溶液は光が当たると少しずつ分解します。そのため、ビュレットは茶色いガラスでできた褐色ビュレットを選びます。

## 具体例 —— シュウ酸で KMnO₄ 水溶液の濃度を決める

濃度 0.0500 mol/L のシュウ酸 (COOH)₂ 水溶液 10.0 mL をとり、希硫酸を加えて温め、濃度不明の KMnO₄ 水溶液で滴定したところ、8.00 mL 加えたところで赤紫色が消えなくなったとします。

:::list
ordered: true
items:
- 酸化剤と還元剤の価数を半反応式から読む。
　KMnO₄ は5価（MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺ ＋ 4H₂O）、シュウ酸は2価（H₂C₂O₄ → 2CO₂ ＋ 2H⁺ ＋ 2e⁻）
- それぞれの物質量を、濃度 × 体積で表す。
　KMnO₄ は x × 8.00/1000 mol、シュウ酸は 0.0500 × 10.0/1000 mol
- e⁻ の物質量の等式を立てて解く。
　x × 8.00/1000 × 5 ＝ 0.0500 × 10.0/1000 × 2 より、x ＝ 0.0250 mol/L
:::

シュウ酸と KMnO₄ の反応は常温ではゆっくりなので、シュウ酸の水溶液を約 60℃ に温めてから滴定します。

:::reaction
left: 2KMnO₄ ＋ 5(COOH)₂ ＋ 3H₂SO₄
right: 2MnSO₄ ＋ K₂SO₄ ＋ 10CO₂↑ ＋ 8H₂O
level: ★★☆
note: KMnO₄：シュウ酸 ＝ 2：5（価数5と2の逆の比）。イオン反応式は 2MnO₄⁻ ＋ 5H₂C₂O₄ ＋ 6H⁺ → 2Mn²⁺ ＋ 10CO₂ ＋ 8H₂O。
:::

:::heading
title: 温める温度と、途中から反応が速くなるわけ
advanced: true
:::

ただし熱くしすぎてはいけません。80℃ あたりを超えると KMnO₄ そのものが壊れはじめ、滴下量が狂います。また、滴定の最初は赤紫色がなかなか消えませんが、いったん反応が始まると色がすぐに消えるようになります。生じた Mn²⁺ がこの反応を速める触媒としてはたらくためです（**自触媒作用**）。

## 例題 —— 過マンガン酸カリウムによる滴定

:::exercise
source: このページの KMnO₄ の節と、スライド 無機の基本１ p.37 の「価数の逆の比」から作った問い。もとにした本はありません
prompt: コニカルビーカーに過酸化水素水を 25.0 mL はかりとり、希硫酸を加えて酸性にした。ここへビュレットから 0.0100 mol/L の KMnO₄ 水溶液を少しずつ加えていくと、18.0 mL 加えた時点で、振り混ぜても淡い赤紫色が残るようになった。**この過酸化水素水の濃度は何 mol/L か。有効数字3桁で答えよ。**
answer: **0.0180 mol/L** です。KMnO₄ は5価の酸化剤、H₂O₂ は2価の還元剤なので、e⁻ の物質量の等式は 0.0100 × 18.0/1000 × 5 ＝ x × 25.0/1000 × 2。左辺は 9.00×10⁻⁴ mol、右辺は x × 5.00×10⁻² なので、x ＝ 0.0180 mol/L です。
:::

:::section
anchor: iodine
title: ヨウ素滴定
lead: 測りたい酸化剤を、同じ物質量の I₂ に置き換えてから、チオ硫酸ナトリウムで滴定します。
terms:
- ヨウ素滴定
- チオ硫酸ナトリウム
- ヨウ素デンプン反応
:::

酸化剤にヨウ素 I₂、還元剤にチオ硫酸ナトリウム Na₂S₂O₃ を使う酸化還元滴定を「ヨウ素滴定」といいます。指示薬としてデンプンを加え、**I₂ がなくなってヨウ素デンプン反応の青紫色が消えるところを終点**とします。

:::reaction
left: I₂ ＋ 2e⁻
right: 2I⁻
level: ★★★
note: ヨウ素は弱い酸化剤です。
:::

:::reaction
left: 2S₂O₃²⁻
right: S₄O₆²⁻ ＋ 2e⁻
level: ★☆☆
note: チオ硫酸イオン（還元剤）。**この半反応式は問題で与えられるので暗記の必要はありません**。与えられた式から反応式を組み立てられれば十分です。
:::

:::reaction
left: I₂ ＋ 2Na₂S₂O₃
right: 2NaI ＋ Na₂S₄O₆
level: ★☆☆
note: イオン反応式は I₂ ＋ 2S₂O₃²⁻ → 2I⁻ ＋ S₄O₆²⁻。
:::

## 2段で測る理由

過酸化水素 H₂O₂ と KI の反応には、終点を目で確かめられる適当な指示薬がありません。**酸化還元滴定は、反応ごとに個別の指示薬を用意する必要があります**。

そこで、まず H₂O₂ に**過剰の KI** を反応させて、H₂O₂ と同じ物質量の I₂ を生じさせます。次に、その I₂ を Na₂S₂O₃ で滴定すれば、デンプンを指示薬に使えます。**H₂O₂ の物質量を I₂ の物質量に置き換えているのが、ヨウ素滴定の肝**です。

:::reaction
left: H₂O₂ ＋ 2KI ＋ H₂SO₄
right: 2H₂O ＋ I₂ ＋ K₂SO₄
level: ★★☆
note: 1段目。硫酸酸性で H₂O₂ が酸化剤、KI が還元剤。H₂O₂ 1 mol から I₂ 1 mol が生じます。
:::

:::figure
src: redox-titration-iodine-two-steps.png
svg: redox-titration-iodine-two-steps.svg
alt: ヨウ素滴定の2段の反応の組み立て。(1) H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O と 2I⁻ → I₂ ＋ 2e⁻ を足し、SO₄²⁻ と 2K⁺ を加えて H₂O₂ ＋ H₂SO₄ ＋ 2KI → 2H₂O ＋ I₂ ＋ K₂SO₄。(2) I₂ ＋ 2e⁻ → 2I⁻ と 2S₂O₃²⁻ → S₄O₆²⁻ ＋ 2e⁻ を足して I₂ ＋ 2S₂O₃²⁻ → 2I⁻ ＋ S₄O₆²⁻
caption: 1段目は H₂O₂ が酸化剤・KI が還元剤、2段目は1段目で生じた I₂ が酸化剤・Na₂S₂O₃ が還元剤です。**どちらも半反応式を足して組み立てます**。
:::

1段目で加える KI と硫酸は、**H₂O₂ がすべて反応する量を過剰に加えればよい**ので、量は正確でなくてかまいません。問題文でも、そうした量は有効数字1桁で与えられていることが多いです。


## 例題 —— ヨウ素滴定

:::exercise
source: slides:無機の基本５「ハロゲン」s48-50（練習8）
prompt: 濃度未知の過酸化水素水 10 mL に、1 mol/L のヨウ化カリウム水溶液 10 mL と 2 mol/L の硫酸 3 mL を加えて、過酸化水素が完全になくなるまで反応させた。その後、指示薬を加え、0.10 mol/L のチオ硫酸ナトリウム水溶液を滴下したところ、12 mL で終点となった。ただし、チオ硫酸イオンの半反応式は 2S₂O₃²⁻ → S₄O₆²⁻ ＋ 2e⁻ である。**(1) はじめの反応の化学反応式を書け。(2) 加えた指示薬の名称と、終点での色の変化を答えよ。(3) 過酸化水素水の濃度〔mol/L〕を有効数字2桁で求めよ。**
answerSrc: redox-titration-iodine-mol.png
answerAlt: 1本目の式 H₂O₂ ＋ H₂SO₄ ＋ 2KI → 2H₂O ＋ I₂ ＋ K₂SO₄ と2本目の式 I₂ ＋ 2S₂O₃²⁻ → 2I⁻ ＋ S₄O₆²⁻ を並べ、Na₂S₂O₃ 1.2 mmol → I₂ 0.6 mmol → H₂O₂ 0.6 mmol と係数の比でたどり、0.6 mmol：10 mL ＝ 0.06 mol：1 L から 0.060 mol/L を出す図
answer: **(1) H₂O₂ ＋ H₂SO₄ ＋ 2KI → 2H₂O ＋ I₂ ＋ K₂SO₄　(2) デンプン、青紫色から無色　(3) 0.060 mol/L** です。(3) 終点までに加えた Na₂S₂O₃ は 0.10 mol/L × 12 mL ＝ 1.2 mmol。I₂ ＋ 2S₂O₃²⁻ → 2I⁻ ＋ S₄O₆²⁻ より I₂ は 0.60 mmol。1段目の式より H₂O₂ と I₂ は等 mol なので、H₂O₂ も 0.60 mmol。これが 10 mL に含まれていたので、0.60 mmol ÷ 10 mL ＝ 0.060 mol/L です。
:::
