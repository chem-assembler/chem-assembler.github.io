生物の細胞の核などにふくまれ、遺伝情報を担う天然高分子を**核酸**といいます。核酸には **DNA（デオキシリボ核酸）** と **RNA（リボ核酸）** の2種類があります。

:::section
anchor: nucleotide
title: ヌクレオチド
lead: 核酸の構成単位をヌクレオチドといいます。ヌクレオチドは、五炭糖・リン酸・塩基が1個ずつ結合したものです。
terms:
- ヌクレオチド
- 五炭糖
- 塩基
:::

核酸を加水分解すると、**ヌクレオチド**という単位に分かれます。ヌクレオチドは、次の3つの部品が1個ずつ結合したものです。

:::list
items:
- **五炭糖**（炭素を5個もつ糖）… DNA ではデオキシリボース、RNA ではリボース
- **リン酸** H₃PO₄
- **塩基**（窒素をふくむ環状の化合物）… アデニン（A）・グアニン（G）・シトシン（C）・チミン（T）・ウラシル（U）
:::

**「ヌクレオチド ＝ 五炭糖 ＋ リン酸 ＋ 塩基」は必ず暗記してください。**

3つの部品が結合するときは、それぞれのつなぎ目で水が1分子ずつとれます。

:::reaction
left: 五炭糖 ＋ リン酸 ＋ 塩基
right: ヌクレオチド ＋ 2H₂O
level: ★★☆
note: 糖とリン酸の間、糖と塩基の間の2か所で、水が1分子ずつとれます。
:::

:::section
anchor: chain
title: 核酸の鎖のつくり
lead: ヌクレオチドの糖とリン酸が交互にエステル結合でつながって長い鎖になり、その鎖から塩基が枝のように出ています。
terms:
- ポリヌクレオチド
- リン酸エステル
:::

ヌクレオチドどうしは、**一方の糖の −OH と、もう一方のリン酸**の間で水がとれてつながります。これは、リン酸と糖の −OH からできる**エステル結合**です。

こうして**糖とリン酸が交互につながった長い鎖**ができ、それぞれの糖から**塩基が枝のように**出ています。ヌクレオチドが多数つながったこの鎖を**ポリヌクレオチド**といい、核酸はポリヌクレオチドでできています。

**「背骨は糖とリン酸、枝が塩基」**と覚えましょう。どの糖のどの位置の炭素でつながっているか（3′位・5′位）は覚えなくて構いません。

:::section
anchor: base-pair
title: 塩基の対と二重らせん
lead: DNA の2本の鎖は、塩基どうしが水素結合で対をつくってつながり、二重らせんになっています。対になるのは A と T、G と C です。
terms:
- 相補的塩基対
- 二重らせん
- 水素結合
:::

DNA の2本のポリヌクレオチドは、向かい合った塩基どうしが**水素結合**で対をつくってつながっています。対になる相手は決まっていて、**アデニン（A）とチミン（T）**、**グアニン（G）とシトシン（C）**です。このような決まった組み合わせの対を**相補的塩基対**といいます。

2本の鎖は、この対をはさんでねじれ、**二重らせん**になっています。

**「A と T、G と C」**と覚えましょう。RNA では T の代わりに U なので、**A と U** が対になります。

対の相手が決まっているので、DNA では **A の数 ＝ T の数、G の数 ＝ C の数**になります。具体例として、ある DNA の塩基のうち A が 20% なら、T も 20%、残りの 60% を G と C が半分ずつ分けて、G と C は 30% ずつです。

//図: A−T と G−C の塩基対を、水素結合を点線で結んで描いた図。塩基は作図器で描けるが、2分子を並べて点線を足すのは描けない

//図: 二重らせんの模式図。作図器では描けない

:::mistake
wrong: DNA の塩基はどれも同じ割合でふくまれるので、4種類とも25%ずつになる
right: DNA で等しくなるのは、**A と T どうし、G と C どうし**だけです。A と G の割合は DNA ごとに違います。
why: 「対になるものが同じ数」を「4種類がすべて同じ数」と広げてしまうためです。
:::

:::section
anchor: flow
title: 遺伝情報の流れ
advanced: true
lead: DNA の塩基の並び順が RNA に写しとられ、RNA の塩基の並び順にしたがってアミノ酸がつながり、タンパク質ができます。
terms:
- 遺伝情報
:::

DNA の**塩基の並び順**が遺伝情報です。この並び順が、塩基の対の決まりにしたがって RNA に写しとられ、RNA の塩基3個の並びごとに1つのアミノ酸が決まって、タンパク質の**一次構造**（アミノ酸の並び順）ができます。

**DNA → RNA → タンパク質**という情報の向きだけ知っておけば十分です。写しとる仕組みの名前や、どの塩基の並びがどのアミノ酸になるかは、化学では覚える必要はありません。

:::link
to: protein
text: タンパク質の一次構造（アミノ酸の並び順）はタンパク質のページへ
:::

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: reference-outline/bio.md 第2部 nucleic-acid の例題1（①ドラフトのために起こした問い）
prompt: ある DNA の一方の鎖の塩基の並び順が A−T−G−C−C−A であるとき、これと対をつくるもう一方の鎖の塩基の並び順を、向かい合う順に書け。
answer: **T−A−C−G−G−T**。A の相手は T、G の相手は C です。
:::

:::exercise
source: reference-outline/bio.md 第2部 nucleic-acid の例題2（①ドラフトのために起こした計算問題）
prompt: 2本鎖の DNA にふくまれるアデニンの数が、全塩基の数の30%であった。グアニンは全塩基の何%か。
answer: A ＝ T なので、A と T を合わせて 60%。残りの 40% を G と C が半分ずつ分けるので、グアニンは **20%** です。
:::

:::exercise
source: reference-outline/bio.md 第1部 nucleic-acid の節3（DNA と RNA の違い）をもとに、①ドラフトのために起こした問い
prompt: DNA と RNA の違いを、構成する五炭糖と塩基の2点について答えよ。
answer: 五炭糖は、DNA が**デオキシリボース**、RNA が**リボース**。塩基は、DNA が A・G・C・**T（チミン）**、RNA が A・G・C・**U（ウラシル）**です。
:::
