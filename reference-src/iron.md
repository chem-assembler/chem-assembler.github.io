鉄 Fe は8族の遷移元素で、地殻中ではアルミニウムに次いで多い金属です。化合物の中では、酸化数 **＋2（鉄(Ⅱ)）と ＋3（鉄(Ⅲ)）**の2通りをとります。

:::section
anchor: smelting
title: 鉄の製錬 —— 溶鉱炉と転炉
lead: 鉄鉱石を、コークスからできた一酸化炭素 CO で還元して銑鉄をつくり、転炉で炭素を減らして鋼にします。
terms:
- 赤鉄鉱
- 磁鉄鉱
- 溶鉱炉
- 銑鉄
- 鋼
:::

鉄鉱石には**赤鉄鉱**（主成分 Fe₂O₃）や**磁鉄鉱**（主成分 Fe₃O₄）があります。これを**コークス C** と**石灰石 CaCO₃** といっしょに溶鉱炉に入れ、下から熱風を送ります。

:::list
ordered: true
items:
- コークスが燃えて CO₂ になり、それがさらにコークスと反応して一酸化炭素 CO ができる。
　C ＋ O₂ → CO₂、CO₂ ＋ C → 2CO
- CO が還元剤になって、鉄の酸化物を順に還元する。
　Fe₂O₃ → Fe₃O₄ → FeO → Fe（全体では下の式）
- 石灰石は、鉱石に混じった SiO₂ などの不純物と結びついて**スラグ**になり、融けた鉄の上に浮いて取り除かれる。
:::

:::reaction
left: Fe₂O₃ ＋ 3CO
right: 2Fe ＋ 3CO₂
level: ★★☆
note: CO が還元剤。途中の Fe₃O₄・FeO を経る段ごとの式は覚えなくて構いません。
:::

溶鉱炉から出る鉄を**銑鉄**といい、炭素を約4％含むので硬くてもろい性質があります。銑鉄を**転炉**に移して酸素を吹き込み、炭素を燃やして減らしたものが**鋼**（炭素 2％以下）で、ねばり強く、建材などに使われます。鉄にクロム Cr やニッケル Ni を混ぜた合金が**ステンレス鋼**で、さびにくくなります。

**「鉄鉱石を還元するのは CO」「銑鉄は炭素が多く、転炉で鋼にする」の2点は必ず覚えてください。**段ごとの還元の式は、問題文に誘導があるのがふつうです。

:::section
anchor: element
title: 単体 —— 希酸に溶けると Fe²⁺
lead: 鉄は希塩酸・希硫酸に溶けて水素を出し、Fe³⁺ ではなく Fe²⁺ になります。濃硝酸では不動態になります。
terms:
- 不動態
- 赤さび
:::

鉄はイオン化傾向が H₂ より大きいので、希塩酸や希硫酸に溶けて水素を発生します。このとき生じるのは **鉄(Ⅱ)イオン Fe²⁺** です。

:::reaction
left: Fe ＋ H₂SO₄
right: FeSO₄ ＋ H₂
level: ★★★
note: 希硫酸。塩酸なら Fe ＋ 2HCl → FeCl₂ ＋ H₂。
:::

:::mistake
wrong: 鉄を希硫酸に溶かすと Fe³⁺ になり、硫酸鉄(Ⅲ) Fe₂(SO₄)₃ ができる。
right: 希塩酸・希硫酸で生じるのは **Fe²⁺**（FeSO₄・FeCl₂）です。
why: H⁺ は Fe を Fe²⁺ まで酸化する力しかないためです。Fe³⁺ にするには、塩素や過酸化水素・硝酸などの、もっと強い酸化剤が要ります。
:::

鉄は**濃硝酸には溶けません**。表面に緻密な酸化被膜ができる**不動態**になるためです（Al・Ni も同じ）。

鉄は湿った空気中で酸化されて、**赤さび**（主成分は酸化水酸化鉄(Ⅲ) や Fe₂O₃ の水和物）を生じます。一方、鉄を空気中で強く熱すると、表面に黒色の Fe₃O₄（**黒さび**）ができます。黒さびは内部を守るので、鉄器の表面処理に使われます。

- ヘキサシアニド鉄(Ⅲ)酸カリウム K₃[Fe(CN)₆] | **濃青色沈殿** | 褐色の溶液（沈殿しない）

//要確認: 化学新研究2015 —— K₃[Fe(CN)₆] ＋ Fe³⁺ と K₄[Fe(CN)₆] ＋ Fe²⁺ の色の書き方（「褐色の溶液」「青白色沈殿」を本文に出すか、「変化が目立たない」と書くか）

**覚え方は「数字が違えば濃青色」です。**Fe²⁺ には鉄(Ⅲ)の K₃[Fe(CN)₆]、Fe³⁺ には鉄(Ⅱ)の K₄[Fe(CN)₆] を加えたときに濃青色沈殿ができます。KSCN で血赤色になるのは Fe³⁺ だけです。この3つの組は**必ず暗記してください。**

濃青色沈殿はどちらの組でも同じ組成の物質で、かつては Fe²⁺ の側をターンブルブルー、Fe³⁺ の側をプルシアンブルー（ベルリンブルー）と呼び分けていました。名前は覚えなくても構いません。

## 水酸化物の沈殿

:::reaction
left: Fe²⁺ ＋ 2OH⁻
right: Fe(OH)₂↓
level: ★★★
note: 緑白色の沈殿。空気中に置くと酸化されて、しだいに赤褐色に変わります。
:::

:::reaction
left: Fe³⁺ ＋ 3OH⁻
right: Fe(OH)₃↓
level: ★★☆
note: 赤褐色の沈殿。過剰の NaOH にも過剰の NH₃ にも溶けません。
:::

:::callout
tone: caution
text: Fe³⁺ にできる赤褐色の沈殿は、ふつう「水酸化鉄(Ⅲ) Fe(OH)₃」と呼ばれますが、実際は決まった組成をもたない水和酸化物です。資料によっては「酸化水酸化鉄(Ⅲ) FeO(OH)」と書かれます。問題文でどちらの式が出てきても、同じ赤褐色の沈殿のことです。
:::

title: Fe²⁺ は還元剤 —— 酸化されて Fe³⁺ になる
lead: Fe²⁺ は e⁻ を1個出して Fe³⁺ になりやすく、過マンガン酸カリウムや二クロム酸カリウムの相手（還元剤）としてよく登場します。

:::reaction
left: Fe²⁺
right: Fe³⁺ ＋ e⁻
level: ★★★
note: 還元剤の半反応式。e⁻ は1個です。
:::

Fe²⁺ の水溶液が空気中で黄褐色に変わっていくのは、溶けている酸素で Fe³⁺ に酸化されるためです。

硫酸酸性の二クロム酸カリウムと反応させると、Cr₂O₇²⁻ 1個が e⁻ を6個受け取るので、Fe²⁺ は6個要ります。

:::reaction
left: Cr₂O₇²⁻ ＋ 6Fe²⁺ ＋ 14H⁺
right: 2Cr³⁺ ＋ 6Fe³⁺ ＋ 7H₂O
level: ★★☆
note: 酸化剤の半反応式 Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O と、Fe²⁺ の式を6倍して足したもの。
:::

## 必ず覚えるもの（★★★）

:::list
items:
- 鉄鉱石を還元するのは CO。銑鉄 → 転炉 → 鋼
- Fe ＋ H₂SO₄ → FeSO₄ ＋ H₂（Fe²⁺ になる）
- Fe²⁺ 淡緑色・Fe³⁺ 黄褐色、Fe(OH)₂ 緑白色・水酸化鉄(Ⅲ) 赤褐色
- K₃[Fe(CN)₆] は Fe²⁺ と、K₄[Fe(CN)₆] は Fe³⁺ と濃青色沈殿。KSCN は Fe³⁺ で血赤色
- Fe²⁺ → Fe³⁺ ＋ e⁻
:::

## 例題

:::exercise
source: 自作（このページの ★★★ の式と表を物質名・操作から書く）
prompt: **(1)** 鉄を希塩酸に溶かしたときの化学反応式を書け。**(2)** (1) の水溶液に水酸化ナトリウム水溶液を加えたときに生じる沈殿の化学式と色を答えよ。**(3)** ある水溶液にチオシアン酸カリウム水溶液を加えると血赤色になった。この水溶液に含まれる鉄のイオンを答えよ。
answer: (1) Fe ＋ 2HCl → FeCl₂ ＋ H₂　(2) Fe(OH)₂、緑白色（Fe²⁺ なので、赤褐色ではありません）　(3) Fe³⁺
:::

:::exercise
source: 自作（Fe²⁺ の半反応式と Cr₂O₇²⁻ の半反応式から全体の式を組み立て、量を求める）
prompt: 硫酸酸性の二クロム酸カリウム水溶液と硫酸鉄(Ⅱ) 水溶液の反応を、イオン反応式で書け。また、Cr₂O₇²⁻ 0.010 mol とちょうど反応する Fe²⁺ は何 mol か。
answer: Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O と、Fe²⁺ → Fe³⁺ ＋ e⁻ を6倍して足すと、**Cr₂O₇²⁻ ＋ 6Fe²⁺ ＋ 14H⁺ → 2Cr³⁺ ＋ 6Fe³⁺ ＋ 7H₂O** です。係数の比 ＝ mol の比なので、Cr₂O₇²⁻ : Fe²⁺ ＝ 1 : 6。Fe²⁺ は 0.010 × 6 ＝ **0.060 mol** です。
:::
