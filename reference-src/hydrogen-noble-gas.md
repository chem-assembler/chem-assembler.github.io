周期表の18族の元素を**貴ガス**といいます。貴ガスはほかの原子とほとんど化合物をつくらないので、覚えるのは性質と利用だけです。一方の**水素**は、ほとんどすべての元素と化合物をつくり、反応では**還元剤**としてはたらきます。水素の反応は、半反応式を先に書いてから全体の式を組み立てます。半反応式の書き方は「半反応式の書き方」のページで確かめてください。

18族のヘリウム He・ネオン Ne・アルゴン Ar・クリプトン Kr・キセノン Xe・ラドン Rn を**貴ガス**といいます。価電子の数は0個で、安定した電子配置をもつため、ほかの原子とほとんど化合物をつくりません。常温ではすべて無色・無臭の**単原子分子**の気体です。

貴ガスは無極性分子で分子間力が弱いため、沸点がとても低くなります。液体ヘリウムは −269℃ と極めて低温です。分子量が大きい貴ガスほど分子間力が大きくなり、沸点は高くなります。

化合物をつくらないので、貴ガスは**液体空気の分留**か、地中に閉じ込められている気体を採掘して得ます。名前の「貴ガス（noble gas）」は「高貴な気体」、以前の呼び名「希ガス（rare gas）」は「稀な気体」という意味です。

構造式は H−H、電子式は H:H で、2つの H 原子が共有電子対1組で結びついた無極性分子です。**「気体は性質表の7つの欄で覚える」**のがこのシリーズの型で、酸素・塩素・硫化水素なども同じ欄で並べます。

## 実験室的製法1 —— 亜鉛に希硫酸を加える

亜鉛 Zn に希硫酸 H₂SO₄ を加えると水素が発生します。Zn が還元剤、希硫酸の H⁺ が酸化剤としてはたらく酸化還元反応です。

:::reaction
left: Zn ＋ H₂SO₄
right: ZnSO₄ ＋ H₂↑
level: ★★★
note: イオン化傾向が H₂ より大きい金属の単体は、酸の H⁺ と反応して H₂ を発生します（金属樹ができるのと同じ原理）。
:::

半反応式を2本足してから、省いた SO₄²⁻ を両辺に戻すと化学反応式になります。

:::figure
src: hydrogen-noble-gas-zn-h2so4.png
alt: Zn → Zn²⁺ ＋ 2e⁻ と 2H⁺ ＋ 2e⁻ → H₂ を足して Zn ＋ 2H⁺ → Zn²⁺ ＋ H₂ とし、さらに両辺に SO₄²⁻ を加えて Zn ＋ H₂SO₄ → ZnSO₄ ＋ H₂ を得る筆算
caption: 半反応式を足し、省いたイオン SO₄²⁻ を両辺に戻す。
:::

慣れてきたら、**Zn²⁺ と SO₄²⁻ が 1:1 でくっついて ZnSO₄ になる**ことに着目すれば1行で書けます（余った H 原子は H₂ になります）。塩酸なら Zn²⁺ と Cl⁻ が 1:2 でくっつくので、左辺は「Zn ＋ 2HCl」になります。

:::reaction
left: Zn ＋ 2HCl
right: ZnCl₂ ＋ H₂↑
level: ★★★
note: 塩酸でも水素は発生しますが、揮発した HCl が混じります。
:::

酸は希硫酸を使います。希塩酸では揮発した HCl が混じり、希硝酸では NO₃⁻ が酸化剤としてはたらいて NO が混じるためです。熱濃硫酸ではなく希硫酸なので、酸化剤の本体は H⁺ です。

## 実験室的製法2 —— 水を電気分解する

:::reaction
left: 2H₂O
right: 2H₂ ＋ O₂
level: ★★★
note: 陽極・陰極の H₂O の半反応式を組み合わせてもつくれますが、**水素の燃焼（燃料電池の反応）の逆**と考えたほうが楽に書けます。
:::

陰極では H₂O が酸化剤、陽極では H₂O が還元剤としてはたらきます。この組み立て方に実用性はありませんが、H₂O がどちらの役もする半反応式を使いこなすことが大切です。ほかに、Al や Zn などの両性元素の単体に水酸化ナトリウム水溶液を加えても水素が発生します。

## 工業的製法

工業的には、炭素や炭化水素を高温の水蒸気と反応させます。**CO と H₂ ができることを覚えて係数を合わせる**だけで書けます。

:::reaction
left: C ＋ H₂O
over: 赤熱したコークス
right: CO ＋ H₂
level: ★☆☆
note: 生じた CO と H₂ の混合気体を**水性ガス**といい、燃料やメタノール CH₃OH の合成原料になります。
:::

:::reaction
left: CH₄ ＋ H₂O
over: Ni 触媒・高温
right: CO ＋ 3H₂
level: ★☆☆
note: 実際にはメタン以外のさまざまな炭化水素（天然ガス・ナフサ）が反応します。
:::

さらに水性ガスの CO を水蒸気で酸化し（CO ＋ H₂O → CO₂ ＋ H₂）、生じた CO₂ を取り除くと H₂ が得られます。工業的製法の細部は優先度が低いので、丸暗記に時間を使う必要はありません。

:::section
anchor: hydrogen-reactions
title: 水素の反応 —— すべて還元剤としての反応
lead: 水素の反応は H₂ → 2H⁺ ＋ 2e⁻ の半反応式1本と、相手の酸化剤の半反応式を足して書けます。
terms:
- 還元剤
- 酸水素炎
- 塩素爆鳴気
:::

水素 H₂ は高温では**2価の還元剤**としてはたらきます。H 原子は基本的に H⁺ になると覚えれば、半反応式は1本で済みます。

:::reaction
left: H₂
right: 2H⁺ ＋ 2e⁻
level: ★★★
note: 水素が還元剤としてはたらくときの半反応式。以下の3本はすべてこの式と相手の式を足したものです。
:::

## 燃焼 —— 水素の検出

水素は燃焼性があり、空気中で点火するとポンと音を立てて爆発します。これが**水素の検出**です。

:::reaction
left: 2H₂ ＋ O₂
right: 2H₂O
level: ★★★
note: H₂ が還元剤、空気中の O₂ が酸化剤。発熱が大きく、H₂ と O₂ の混合気体をバーナーで燃やすと約 2800℃ の炎（**酸水素炎**）が得られ、溶接に使われます。
:::

:::figure
src: hydrogen-noble-gas-combustion.png
alt: O₂ ＋ 4e⁻ → 2O²⁻ と 2H₂ → 4H⁺ ＋ 4e⁻ を足して 2H₂ ＋ O₂ → 2H₂O を得る筆算
caption: 空気中の反応なので、O は H⁺ や H₂O を加えずに安定な O²⁻ として書きます。燃焼反応では H₂O や CO₂ ができます。
:::

## 金属の酸化物を還元する

:::reaction
left: CuO ＋ H₂
over: 高温
right: Cu ＋ H₂O
level: ★★☆
note: CuO が酸化剤、H₂ が還元剤。銅以外の金属の酸化物も同じように還元できます。
:::

「**金属の酸化物は還元されると単体に、H₂ は酸化されると H₂O になる**」と考えると、反応式はすぐに書けます。半反応式で組み立てるときは、これが固体と気体の反応なので、O 原子を H₂O で合わせません。O²⁻ は SO₄²⁻ と同じ「反応に直接関わらないイオン」として、最後に両辺へ戻します。

有機化学で学ぶ水素の付加反応（CH₂=CH₂ ＋ H₂ → CH₃CH₃ など）も、水素が還元剤としてはたらく反応です。

## 塩素と反応する —— 塩素爆鳴気

:::reaction
left: H₂ ＋ Cl₂
over: 光
right: 2HCl
level: ★★☆
note: 水素と塩素の混合気体（**塩素爆鳴気**）に光を当てると爆発的に反応します。Cl₂ が酸化剤、H₂ が還元剤。塩化水素の合成反応でもあります。
:::

光で Cl₂ が分解されて反応しやすい塩素原子ができるため、光が引き金になります。

## 水素の化合物

水素は貴ガス以外のほぼすべての元素と化合物をつくります。非金属元素とは共有結合して CH₄・NH₃・H₂O・HCl などをつくります。水素は非金属の中では事実上いちばん電気陰性度が小さいので、相手との間に極性が生じやすく、その代表が分子間に水素結合をつくる NH₃・H₂O・HF です。

一方、金属元素よりは電気陰性度が大きいので、アルカリ金属などとは**水素化物イオン H⁻** となってイオン結合します（NaH など）。
