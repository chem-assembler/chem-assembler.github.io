炭素が4個以上のアルカンには、同じ分子式でも別の構造の分子（異性体）が存在します。

:::section
anchor: what
title: つなぎ方が違えば、別の分子
lead: 原子の種類と数が同じでも、つながり方が違えば別の物質です。これが構造異性体です。
terms:
- 異性体
- 構造異性体
- 枝分かれ
:::

炭素が4個以上になると、1列につなぐほかに**枝分かれ**のつなぎ方ができます。原子の種類と数（＝分子式）は同じなのに、つながり方が違う別の分子になる —— これが**構造異性体**です。

いちばん小さい例が C₄H₁₀ です。炭素4個を全部1列に使えば直鎖の**ブタン**、3個を1列にして残りの1個を枝（メチル基）にすれば **2-メチルプロパン**。この2つで打ち止めで、3つ目はありません。

:::figure
src: alkane-isomers-c4-straight.png
alt: ブタンの構造式。炭素4個が横一直線に並び、それぞれの炭素から結合の手が上下左右に出ている（水素原子は省略してある）
caption: 炭素4個を全部主鎖に使った形 ＝ **ブタン**。水素を省いて結合の手だけを書いてあります。
:::

:::figure
src: alkane-isomers-c4-branch.png
alt: 2-メチルプロパンの構造式。炭素3個が横一直線に並んで左から1・2・3の番号が振ってあり、2番の炭素から下へ炭素1個が伸びている（水素原子は省略してある）
caption: 主鎖を3個にして、残りの1個を枝にした形 ＝ **2-メチルプロパン**。枝を主鎖の**端**（1番か3番）に付けると主鎖が伸びてブタンに戻ってしまうので、付けられるのは両端以外の炭素だけです。
:::

:::link
to: alkane-naming
text: 「2-メチルプロパン」という名前の作り方（主鎖の選び方・番号の振り方）は「アルカンの命名」で
:::

:::section
anchor: count
title: 異性体はいくつあるか
lead: C₄ から C₇ まで 2・3・5・9。この4つは覚えてしまいましょう。
terms:
- 構造異性体の数
- 主鎖
:::

:::stageTable
variant: grouped
series: 異性体をつくる（枝分かれアルカン）
source: stages:異性体をつくる（枝分かれアルカン）
caption: 枝分かれしたアルカン C4〜C7
:::

分子式ごとの件数を縦に読むと、枝分かれは C₄ で1つ、C₅ で2つ、C₆ で4つ、C₇ で8つ。ここに枝のない直鎖（「アルカンの命名」の表にある分）を1つずつ足すと、構造異性体の総数は **2・3・5・9** になります。炭素が1個増えるたびに増え方が急になっていくのは、1行ずつでは見えず、並べて初めて見えます。

**C₄=2・C₅=3・C₆=5・C₇=9 の4つは暗記してください。**自分で数え上げた答えが合っているかを、その場で確かめられます。C₈ 以降（18・35・75…）は覚えなくても困ることはありません。

いちばん右の列（主鎖の炭素の数）も一緒に見てください。**同じ分子式でも主鎖の長さが違う**ことがあります。C₅H₁₂ では 2-メチルブタンの主鎖が4本（母体はブタン）、2,2-ジメチルプロパンの主鎖は3本（母体はプロパン）。**名前の後半が変わるのは、主鎖の長さが変わるから**です。

:::example
stageId: 2-methylbutane
lead: ひとつ作ってみましょう。**表を閉じてから**、炭素4個の鎖に炭素1個の枝を付けて 2-メチルブタン を組みます。
note: 組み上がりの判定は、いつものパズルと同じお題（異性体をつくる（枝分かれアルカン）の2問目）がそのまま受け持ちます。
:::

:::section
anchor: writeout
title: 異性体の書き出し —— 数え上げの手順
lead: 分子式を1つ与えられて、その異性体をすべて書く問題です。どの系列も、まず同じ炭素数のアルカンを書くところから始まります。
terms:
- 書き出し
:::

「C₄H₈ の異性体をすべて書け」のように、**分子式を1つ与えられて、その異性体を数え上げる**問題を、ここでは**書き出し**とよびます。

手順の骨は、どの系列でも同じ2段構えです。**まず同じ炭素数のアルカンの構造異性体を全部書き出し、そのあとで二重結合・三重結合・環を入れられる場所を探す。**つまり**アルカンの書き出しが土台**で、ここが速くなると残りも一気に速くなります。

この節から下は、**アルカン／アルケン・シクロアルカン／アルキン**の順に、系列ごとに分けて見ていきます。

:::link
open: practice
text: 書き出し練習をひらく（分子式を選んで、自分で全部たどってみる）
:::

:::section
anchor: writeout-alkane
title: アルカンの書き出し —— 枝分かれの違いだけで分かれる
lead: 結合はすべて単結合なので、分かれ道は枝の付け方だけです。主鎖の長いものから順に書きます。
terms:
- 直鎖
- 側鎖
:::

アルカンは結合がすべて単結合なので、分かれ道は**枝分かれのしかた**だけです。**主鎖の炭素数が多いものから順に、主鎖を横一直線にして書く**と、重複ともれを防げます。

:::list
ordered: true
items:
- **全部の炭素を1列に使った直鎖から書く。**
　炭素数が5なら、まずペンタンです。
- **主鎖を1個短くして、余った炭素を枝（側鎖）として付ける。**
　付けられるのは**両端以外の炭素**だけです。端に付けると主鎖が伸びて、前に書いたものに戻ってしまいます。
- **主鎖をさらに1個ずつ短くして、余った炭素の分け方と付け場所で場合分けする。**
　余りが2個なら「まとめて1本のエチル基 −CH₂CH₃ にするか、別々の2本のメチル基 −CH₃ にするか」、メチル基2本なら「同じ炭素に2本つけるか、別の炭素に1本ずつつけるか」を分けます。
:::

書き終えたら、上の表の **2・3・5・9** と数を突き合わせてください。合わなければ、数え落としているか、同じものを2回書いています。

:::callout
tone: memorize
text: **炭素数が5までのアルキル基は、書き出しの練習を徹底して、構造異性体の数も暗記してしまうとよいでしょう。**ここが速くなると、アルケンの書き出しも一気に速くなります。
:::

to: alkane
text: アルキル基（メチル基・エチル基…）の作り方と、炭素数ごとの種類の数はアルカンのページに
:::

:::section
anchor: writeout-alkene-cyclo
title: アルケン・シクロアルカンの書き出し —— 鎖式と環式は同じ分子式
lead: 一般式はどちらも C~n~H~2n~。「鎖式に限る」と断っていなければ、二重結合の形と環の形を両方書きます。
terms:
- 鎖式
- 環式
:::

アルケンもシクロアルカンも一般式は **C~n~H~2n~** で、たがいに構造異性体です。だから **C₅H₁₀ と言われただけでは、ペンテン（アルケン）なのかシクロペンタンなのか決められません。**問題文が「鎖式に限る」と断っていなければ、**環式も書かなければならない**、ということです。

## 二重結合を入れる（アルケン）

:::list
ordered: true
items:
- **同じ炭素数のアルカンの構造異性体を、先に全部書き出す。**
　炭素数が4なら「ブタンとその異性体」、5なら「ペンタンとその異性体」を書きます。
- **書き出したそれぞれについて、炭素間の単結合を二重結合にできる場所を探す。**
　左右対称なところは同じものになるので、1つに数えます。
- **できたアルケンに、シス－トランス異性体があるかどうかを確かめる。**
　二重結合の炭素の片方に同じものが2個ついていたら、シス－トランス異性体はありません。
:::

具体例として、C₄H₈ のアルケン（ブテン）を書き出してみます。炭素数4のアルカンはブタンと 2-メチルプロパンの2種類です。直鎖のブタンは左右対称なので、二重結合をつくれる場所は2種類で、**1-ブテン**と **2-ブテン**が出ます。2-メチルプロパンは3つのメチル基が対称なので、二重結合をつくれる場所は1種類しかなく、**2-メチル-1-プロペン**だけです。

gen: name=1-ブテン plain paper newrow
gen: name=2-ブテン plain paper

alt: 上の段にブタンと2-メチルプロパンの構造式、下の段に1-ブテン・2-ブテン・2-メチル-1-プロペンの構造式を並べた書き出しの図。ブタンの炭素間結合に1・2・1の番号、2-メチルプロパンの結合に3の番号が振ってある
caption: 上のアルカンの**炭素間結合に番号を振り**、同じ番号の場所を二重結合にしたものが下のアルケンです。2-ブテンだけがシス－トランス異性体をもちます。
:::

したがって、**ブテンの構造異性体は3種類、立体異性体まで含めると4種類**です。

二重結合をつくれる場所は、**炭素に水素が残っているかどうか**で決まります。**丁字交差点・道の途中・行き止まりの炭素は二重結合をつくれますが、十字交差点の炭素はつくれません。**十字交差点の炭素には、もう水素が1個もついていないためです。

## 環をつくる（シクロアルカン）

環のほうは、**主鎖の炭素数のかわりに、環の構成原子数で場合分けする**ところが違います。

:::list
ordered: true
items:
- **考えられるいちばん大きい環から始めて、環の原子を1個ずつ減らしていく。**
　炭素数が5なら「5員環 → 4員環 → 3員環」の順です。**2員環以下は考えません。**
- **環からはみ出した炭素を、側鎖として環につける。**
　側鎖になる炭素が2個以上なら、「まとめて1個のエチル基 −CH₂CH₃ にするか、別々の2個のメチル基 −CH₃ にするか」で場合分けします。
- **メチル基を2個以上つけるときは、つける場所で場合分けする。**
　「環の同じ炭素に2個まとめてつけるか、別々の炭素に1個ずつつけるか」を分けます。
:::

具体例として、C₅H₁₀ の環式の構造異性体を書き出してみます。

:::list
items:
- **5員環** … **シクロペンタン**の1種類。
- **4員環** … 残り1個の炭素を側鎖にします。4員環は対称なのでつけ方は1通りで、**メチルシクロブタン**の1種類。
- **3員環** … 残り2個の炭素を側鎖にします。まとめて1個のエチル基にすると**エチルシクロプロパン**、別々の2個のメチル基にすると、同じ炭素につけて **1,1-ジメチルシクロプロパン**、別の炭素につけて **1,2-ジメチルシクロプロパン**の、合わせて3種類。
:::

caption: C₅H₁₀ の環式構造異性体 —— 環の大きさで場合分けした5種

- 4員環 | メチル基1個 | メチルシクロブタン
- 3員環 | 2個をまとめてエチル基1個 | エチルシクロプロパン
- 3員環 | メチル基2個を同じ炭素に | 1,1-ジメチルシクロプロパン
- 3員環 | メチル基2個を別の炭素に | 1,2-ジメチルシクロプロパン

以上で**環式の構造異性体は5種類**です。**鎖式（ペンテン）も含めると構造異性体は10種類、立体異性体まで含めると13種類**になります。

## 例題 —— アルケン・シクロアルカンの書き出し

:::exercise

answer: 3種類です。**1-ブテン** CH₂=CHCH₂CH₃、**2-ブテン** CH₃CH=CHCH₃、**2-メチル-1-プロペン** CH₂=C(CH₃)₂。2-ブテンにはシス－トランス異性体があるので、立体異性体まで含めると4種類になります。

answer: 構造異性体は5種類、立体異性体まで含めると6種類です。**環式**は、4員環の**シクロブタン**と、3員環の**メチルシクロプロパン**の2種類。**鎖式**は **1-ブテン**・**2-ブテン**・**2-メチル-1-プロペン**の3種類で、このうち 2-ブテンにシス－トランス異性体があるので1つ増えます。
:::

:::exercise
source: slides:有機の基本2-12「シクロアルカンの書き出し」s12「練習2」（解答は s13・s14）

answer: 構造異性体は10種類、立体異性体まで含めると13種類です。**環式が5種類**（シクロペンタン・メチルシクロブタン・1,1-ジメチルシクロプロパン・1,2-ジメチルシクロプロパン・エチルシクロプロパン）、**鎖式が5種類**（1-ペンテン・2-ペンテン・2-メチル-1-ブテン・2-メチル-2-ブテン・3-メチル-1-ブテン）です。
:::

:::section
anchor: writeout-alkyne
title: アルキンの書き出し —— 三重結合はつくれる場所がきびしい
lead: アルケンの書き出しとほぼ同じ手順です。ただし三重結合をつくれる炭素の条件が、二重結合よりきびしくなります。
terms:
- 三重結合をつくれる炭素
:::

アルキンの書き出し方は、**アルケンの書き出し方とほぼ同じ**です。

:::list
ordered: true
items:
- **同じ炭素数のアルカンの構造異性体を、先に全部書き出す。**
　炭素数が5なら「ペンタンとその異性体（3種類）」を書きます。
- **書き出したそれぞれについて、炭素間の単結合を三重結合にできる場所を探す。**
　左右対称なところは同じものになるので、1つに数えます。
:::

**三重結合をつくれるかどうかの条件は、二重結合より1段きびしくなります。**三重結合をつくるには、その炭素から水素が2個抜けなければならないためです。

:::list
items:
- **道の途中・行き止まりの炭素は、三重結合をつくれる。**
- **丁字交差点・十字交差点の炭素は、三重結合をつくれない。**
　「**枝分かれしている部分の炭素は三重結合をつくれない**」と理解してもかまいません。
:::

具体例として、C₅H₈ のアルキン（ペンチン）を書き出してみます。炭素数5のアルカンはペンタン・2-メチルブタン・2,2-ジメチルプロパンの3種類です。直鎖のペンタンは左右対称なので、三重結合をつくれる場所は2種類で、**1-ペンチン**と **2-ペンチン**が出ます。2-メチルブタンは丁字交差点の炭素があるので、つくれる場所は1種類で **3-メチル-1-ブチン**。2,2-ジメチルプロパンは十字交差点の炭素しかないので、三重結合をつくれる場所がありません。

したがって、**ペンチンの構造異性体は3種類**です。**同じ C₅ でも、ペンテン（アルケン）は5種類ありました。**三重結合のほうが条件がきびしいぶん、数が少なくなります。

:::
