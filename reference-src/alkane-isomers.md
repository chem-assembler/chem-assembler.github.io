炭素が4個以上のアルカンには、同じ分子式でも別の構造の分子（異性体）が存在します。

:::section
anchor: what
title: つなぎ方が違えば、別の分子
lead: 原子の種類と数が同じでも、つながり方が違えば別の物質です。これが構造異性体です。
terms:
- 異性体
- 構造異性体
- 枝分かれ
:::

炭素が4個以上になると、1列につなぐほかに**枝分かれ**のつなぎ方ができます。原子の種類と数（＝分子式）は同じなのに、つながり方が違う別の分子になる —— これが**構造異性体**です。

いちばん小さい例が C₄H₁₀ です。炭素4個を全部1列に使えば直鎖の**ブタン**、3個を1列にして残りの1個を枝（メチル基）にすれば **2-メチルプロパン**。この2つで打ち止めで、3つ目はありません。

:::figure
src: alkane-isomers-c4-straight.png
alt: ブタンの構造式。炭素4個が横一直線に並び、それぞれの炭素から結合の手が上下左右に出ている（水素原子は省略してある）
caption: 炭素4個を全部主鎖に使った形 ＝ **ブタン**。水素を省いて結合の手だけを書いてあります。
:::

:::figure
src: alkane-isomers-c4-branch.png
alt: 2-メチルプロパンの構造式。炭素3個が横一直線に並んで左から1・2・3の番号が振ってあり、2番の炭素から下へ炭素1個が伸びている（水素原子は省略してある）
caption: 主鎖を3個にして、残りの1個を枝にした形 ＝ **2-メチルプロパン**。枝を主鎖の**端**（1番か3番）に付けると主鎖が伸びてブタンに戻ってしまうので、付けられるのは両端以外の炭素だけです。
:::

:::link
to: alkane-naming
text: 「2-メチルプロパン」という名前の作り方（主鎖の選び方・番号の振り方）は「アルカンの命名」で
:::

:::section
anchor: count
title: 異性体はいくつあるか
lead: C₄ から C₇ まで 2・3・5・9。この4つは覚えてしまいましょう。
terms:
- 構造異性体の数
- 主鎖
:::

:::stageTable
variant: grouped
series: 異性体をつくる（枝分かれアルカン）
source: stages:異性体をつくる（枝分かれアルカン）
caption: 枝分かれしたアルカン C4〜C7
:::

分子式ごとの件数を縦に読むと、枝分かれは C₄ で1つ、C₅ で2つ、C₆ で4つ、C₇ で8つ。ここに枝のない直鎖（「アルカンの命名」の表にある分）を1つずつ足すと、構造異性体の総数は **2・3・5・9** になります。炭素が1個増えるたびに増え方が急になっていくのは、1行ずつでは見えず、並べて初めて見えます。

**C₄=2・C₅=3・C₆=5・C₇=9 の4つは暗記してください。**自分で数え上げた答えが合っているかを、その場で確かめられます。C₈ 以降（18・35・75…）は覚えなくても困ることはありません。

いちばん右の列（主鎖の炭素の数）も一緒に見てください。**同じ分子式でも主鎖の長さが違う**ことがあります。C₅H₁₂ では 2-メチルブタンの主鎖が4本（母体はブタン）、2,2-ジメチルプロパンの主鎖は3本（母体はプロパン）。**名前の後半が変わるのは、主鎖の長さが変わるから**です。

:::example
stageId: 2-methylbutane
lead: ひとつ作ってみましょう。**表を閉じてから**、炭素4個の鎖に炭素1個の枝を付けて 2-メチルブタン を組みます。
note: 組み上がりの判定は、いつものパズルと同じお題（異性体をつくる（枝分かれアルカン）の2問目）がそのまま受け持ちます。
:::
