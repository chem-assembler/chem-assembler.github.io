カルボニル基 C=O が炭素鎖の端に来ると、その炭素には水素原子が付いて **−CHO** という形になります。この形の基が**ホルミル基**（アルデヒド基）で、ホルミル基をもつ化合物の仲間を**アルデヒド**と呼びます。示性式は **R−CHO** と書きます。

//「アルコールの −OH と混同しないよう RCOH とは書かない」という注意（s2 の最終行）は、先回りの否定になるので本文には入れていません。②で必要と判断されたら足してください。

:::section
anchor: formula
title: アルデヒドとケトンの一般式は CₙH₂ₙO
lead: 鎖式で飽和のアルデヒドとケトンは、どちらも C~n~H~2n~O。炭素の数が同じなら互いに構造異性体です。
terms:
- 一般式
- カルボニル化合物
- 構造異性体
:::

鎖式で飽和のアルデヒドの一般式は **C~n~H~2n~O** です。n に炭素の数を代入すれば分子式が出ます —— n=2 を代入すると C₂H₄O で、これがアセトアルデヒドの分子式です。

ケトンの一般式もまったく同じ C~n~H~2n~O なので、**炭素の数が同じアルデヒドとケトンは互いに構造異性体**です。アルデヒドとケトンをまとめて**カルボニル化合物**とよぶこともあります。

この式は、アルカンの一般式 C~n~H~2n+2~ の**メチレン基 −CH₂− を1つ、カルボニル基 −CO− に取り替えた**形をしています。水素原子が2個減って酸素原子が1個増えるので、C~n~H~2n+2~ から C~n~H~2n~O になります。

:::figure
src: carbonyl-from-alkane.png
alt: アルカンの構造式から矢印が伸び、端のメチレン基をカルボニル基に変えるとアルデヒド、端以外のメチレン基を変えるとケトンになることを示した2段の図
caption: 取り替えるのが**鎖の端**のメチレン基ならアルデヒド、**端以外**ならケトンです。アルデヒドとケトンの構造上の違いは、カルボニル基が鎖の端にあるかどうか、ただ1つです。
:::

**一般式 C~n~H~2n~O は必ず暗記してください。**分子式 C₃H₆O を見た瞬間に「アルデヒドかケトン」と言えると、構造決定で候補がすぐ絞れます。

//計算の図
アルキル基 −C~m~H~2m+1~ にホルミル基が結合しているところから同じ式を計算で導くこともできますが、**この計算のほうは覚える必要はありません。**結果が同じ式になることを一度見ておけば十分です。

規則どおりの名称は、対応するアルカンの語尾「-ane（アン）」を「-anal（アナール）」に変えたものです。炭素1個のメタンなら「メタナール」、2個のエタンなら「エタナール」になります。

ただし高校化学でこの名前を見かけることはまずないので、**覚えるのは慣用名のほう**です。

caption: 左がもとのアルカン、右が対応するアルデヒドです。かっこの中が**慣用名**で、高校化学ではこちらを使います。
:::

**ホルムアルデヒド HCHO・アセトアルデヒド CH₃CHO・プロピオンアルデヒド CH₃CH₂CHO の3つの慣用名は暗記してください。**このうち前の2つは各論として出題されるので、示性式も書けるようにしておきましょう。

**メタナール・エタナール・プロパナールという規則どおりの名称は、覚えていなくて困ることはほとんどありません。**

:::section

lead: アルデヒドは酸化されてカルボン酸になりやすく、そのぶん相手を還元します。銀鏡反応とフェーリング液の還元がその検出です。
terms:
- 還元性
- 銀鏡反応

アルデヒドは1級アルコールを酸化すると生じ、**さらに酸化されるとカルボン酸になります**。この2段目がとても起こりやすいことが、アルデヒドのいちばんの特徴です。

:::link
to: alcohol-oxidation-map
text: 1級アルコール→アルデヒド→カルボン酸、2級アルコール→ケトンという酸化の行き先の対応表はこちら
:::

自分が酸化されやすいということは、**相手に電子を奪われる**ということです。この性質を**還元性**といいます。アルデヒドは2価の還元剤としてはたらき、半反応式は R−CHO ＋ H₂O → R−COOH ＋ 2H⁺ ＋ 2e⁻ となります。

この還元性を目に見える形にしたのが、次の2つの検出反応です。**どちらも塩基性の条件で行います。**アルデヒドは塩基性のほうが還元力が強いためです。

## 銀鏡反応

**銀鏡反応**では、アンモニア性硝酸銀水溶液を加えて温めます。銀イオンが還元されて単体の銀 Ag になり、**器壁に鏡のように析出**します。標準レベルでは反応式を書けるようにする必要はありません。アルデヒドがアンモニア性硝酸銀と反応すると銀 Ag が析出することを覚えましょう。

## 銀鏡反応の反応式（発展）

:::reaction
left: R−CHO ＋ 2[Ag(NH₃)₂]⁺ ＋ 3OH⁻
over: 加温
right: R−COO⁻ ＋ 2Ag ＋ 2H₂O ＋ 4NH₃
level: ★★☆
note: 銀イオンは塩基性では沈殿してしまうので、アンモニアを過剰に加えて**ジアンミン銀イオン**という錯イオンにしてあります。だから左辺は [Ag(NH₃)₂]⁺ の形で書きます。
:::

この反応は酸化還元反応なので、反応式を書くには半反応式から組み立てます。還元剤のアルデヒドはカルボン酸に、酸化剤の銀イオン Ag⁺ は銀 Ag になることがわかれば半反応式が書けます。ただし、塩基性条件で反応を行うので、反応によって生じるカルボン酸は中和したイオン −COO⁻ の形にします。また、NH₃ は電子のやりとりに関与しないので省略し、ジアンミン銀中の Ag⁺ だけを取り出して考えます。

## フェーリング液の還元

**フェーリング液の還元**（フェーリング反応）では、フェーリング液を加えて加熱します。銅(II)イオンが還元されて、**酸化銅(I) Cu₂O の赤色沈殿**が生じます。標準レベルでは反応式を書けるようにする必要はありません。アルデヒドがフェーリング反応を起こすと、赤色の Cu₂O が沈殿することを覚えましょう。

## フェーリング液の還元の反応式（発展）

フェーリング液は2つの液を使う直前に混ぜてつくります。A液は硫酸銅(II) 水溶液、B液は水酸化ナトリウム水溶液に酒石酸ナトリウムカリウムを溶かしたものです。

:::reaction
left: R−CHO ＋ 2Cu²⁺ ＋ 5OH⁻
over: 加熱
right: R−COO⁻ ＋ Cu₂O ＋ 3H₂O
level: ★★☆
note: こちらも銅(II)イオンが塩基性で沈殿しないよう、酒石酸イオンと錯イオンをつくらせてあります。左辺の Cu²⁺ と OH⁻ をくっつけて Cu(OH)₂ と書かないのはそのためです。
:::

この反応も酸化還元反応なので、半反応式からの組み立てを行います。酸化剤の Cu²⁺ は Cu₂O になります。

:::section
anchor: each
title: ホルムアルデヒドとアセトアルデヒド
lead: アルデヒドで各論として出るのはこの2つ。どちらも「どうやってつくるか」が問われます。
terms:
- ホルマリン
- ビニルアルコール

**ホルムアルデヒド HCHO** は無色で刺激臭のある**気体**で、水によく溶けます。その約37パーセント水溶液が**ホルマリン**で、消毒剤や防腐剤に使われます。シックハウス症候群の原因物質になることについて言及されることもあります。
//データ

ホルムアルデヒドは、1級アルコールであるメタノールを酸化してつくります。空気中で銅線を加熱すると黒色の酸化銅(II) ができ、熱いうちにメタノールの蒸気に触れさせるとホルムアルデヒドが生じます。

:::reaction
left: 2CH₃OH ＋ O₂
over: 熱した銅
right: 2HCHO ＋ 2H₂O
gen: 2 メタノール ＋ 酸素 → 2 ホルムアルデヒド ＋ 2 水
level: ★★☆
note: 酸化銅(II) は反応後に銅にもどるので、**銅は触媒**です。酸化剤としてはたらいているのは空気中の酸素のほうです。
:::

**アセトアルデヒド CH₃CHO** は無色で刺激臭のある**液体**で、水によく溶けます。つくり方は2通り出てきます。

1つはエチン（アセチレン）に水を付加させる方法です。いったん不安定な**ビニルアルコール** CH₂=CH(OH) ができ、すぐにアセトアルデヒドに変わります。

:::reaction
left: CH≡CH ＋ H₂O
over: HgSO₄
right: CH₃CHO
gen: アセチレン ＋ 水 → アセトアルデヒド
app: add_water
level: ★★★
note: 途中のビニルアルコールは取り出せないので、反応式にはアセトアルデヒドだけを書きます。**丸暗記**でかまいません。
:::

もう1つは工業的な方法で、エテン（エチレン）を酸素で酸化します。

:::reaction
left: 2CH₂=CH₂ ＋ O₂
over: PdCl₂・CuCl₂
right: 2CH₃CHO
gen: 2 エチレン ＋ 酸素 → 2 アセトアルデヒド
app: wacker_oxidation
level: ★★☆
note: 触媒の名前まで問われることがあります。**塩化パラジウム(II) と塩化銅(II)** の組み合わせです。
:::

実験室では、エタノール（1級アルコール）をおだやかに酸化してもアセトアルデヒドが得られます。
