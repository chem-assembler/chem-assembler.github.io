気体の計算は、1種類の気体だけとは限りません。空気のように何種類もの気体が混ざった気体を**混合気体**といいます。このページでは、混合気体の圧力を成分ごとに分けて考える方法（分圧）と、てんびんで全圧や平均分子量を求める方法をまとめます。計算は、気体の法則のページの「比例・反比例」と準標準状態の考え方をそのまま使います。

:::section
anchor: partial
title: ドルトンの分圧の法則
lead: 混合気体全体の圧力（全圧）は、成分気体それぞれの圧力（分圧）の和になります。
terms:
- 混合気体
- 全圧
- 分圧
- ドルトンの分圧の法則
:::

混合気体全体の圧力を**全圧**、成分気体がそれぞれ単独で容器全体を占めたときに示す圧力を**分圧**といいます。気体 A と B からなる混合気体の全圧 P は、A の分圧 P_A と B の分圧 P_B の和になります。これを**ドルトンの分圧の法則**といいます。

//式: P ＝ P_A ＋ P_B の下付きの A・B（P_A・P_B）。Unicode の下付き英大文字が無いので、第2周で器を考える

**P ＝ P_A ＋ P_B** となるのは、気体の圧力が、分子が壁にぶつかって押す力だからです。A と B の混合気体では、A の分子も B の分子も壁を押すので、全体で壁を押す力は A の分と B の分の合計になります。

//焼成: 気体の基本２ PDF p5 範囲 0.07,0.415,0.94,0.765
:::figure
src: gas-mixture-partial-pressure.png
alt: 3つの容器を「＋」と「＝」でつないだ図。気体 A の分子だけが入った容器では A が壁を押す力が P_A、気体 B の分子だけが入った容器では B が壁を押す力が P_B。両方の分子が入った容器では、A と B の混合気体が壁を押す力が P になる。どの容器も右の壁に分子がぶつかる矢印が描かれている
caption: 混合気体では、A の分子も B の分子もそれぞれ壁にぶつかるので、壁を押す力は2つの合計になります。
:::

:::section
anchor: mole-ratio
title: 分圧は物質量に比例する
lead: 同じ容器の中では温度 T と体積 V が共通なので、分圧は物質量に比例します。
terms:
- モル分率
:::

同じ容器の中にある気体は、どれも同じ温度 T・同じ体積 V です。PV ＝ nRT の ＝ の逆側にある P と n は比例するので、**分圧の比は物質量の比に等しく**なります。

**P : P_A : P_B ＝ n : n_A : n_B**（n は全体の物質量で n ＝ n_A ＋ n_B）です。

全体の物質量を 1 としたときの、各成分の物質量の割合を**モル分率**といいます。A のモル分率は n_A ／（n_A ＋ n_B）です。上の比例式から、分圧は次のように求められます。

**（分圧）＝（モル分率）×（全圧）**になります。

//式: モル分率 n_A ／（n_A ＋ n_B）を縦の分数で組む

具体例で確かめます。A 2mol と B 3mol の混合気体の全圧が 1.0×10⁵Pa なら、全体は 5mol で、A のモル分率は 2/5 ＝ 0.4、B のモル分率は 3/5 ＝ 0.6 です。分圧は P_A ＝ 0.4 × 1.0×10⁵Pa ＝ 0.4×10⁵Pa、P_B ＝ 0.6 × 1.0×10⁵Pa ＝ 0.6×10⁵Pa で、足すと全圧の 1.0×10⁵Pa に戻ります。

**入試では、モル分率の定義を知らないと解けない問題はまれです。**ただし、定期試験では「モル分率を求めよ」とそのまま問われることがあるので、「全体を1としたときの mol の割合」という定義は言えるようにしておきましょう。

:::section
anchor: volume
title: 成分気体の体積は、混合気体の体積と同じ
lead: 気体はすき間だらけなので、混合気体の成分は同じ体積を共有しています。成分ごとの体積を分けて考えません。
:::

N₂ と O₂ を物質量の比 4 : 1 で混ぜた混合気体が 10L あるとき、N₂ と O₂ の体積はそれぞれ何 L でしょうか。

「N₂ が 8L、O₂ が 2L」と答えたくなりますが、正しくは **N₂ も O₂ も 10L** です。気体はすき間だらけで、どちらの分子も容器全体に広がって飛び回っているので、成分気体はどれも混合気体と同じ体積を共有しています。

:::mistake
wrong: N₂ : O₂ ＝ 4 : 1 の混合気体 10L の中の N₂ は 8L、O₂ は 2L
right: N₂ も O₂ も 10L です。成分気体の体積は、混合気体の体積と同じです。4 : 1 に分かれるのは、体積ではなく物質量と分圧です。
why: 液体を混ぜるときのように、成分がそれぞれの場所を占めていると考えてしまうためです。気体は、すべての成分が容器全体に広がっています。
:::

//焼成: 気体の基本２ PDF p10 範囲 0.08,0.28,0.88,0.58
:::figure
src: gas-mixture-volume.png
alt: 同じ大きさの容器を3つ並べ、「N₂ と O₂ の混合気体 10L」＝「O₂ 10L」＋「N₂ 10L」と書いた図。O₂ の分子（少ない）も N₂ の分子（多い）も、それぞれ容器全体に散らばっている
caption: 分子の数は N₂ が多く O₂ が少なくても、どちらも容器全体に広がっているので、体積はどちらも 10L です。

なお、「空気の体積の 21% が O₂」のような体積百分率は、同じ温度・同じ圧力で成分を別々に取り出したときの体積の割合で、物質量の割合（モル分率）と同じ値になります。

:::section
anchor: cock
title: コックを開く問題 —— 分圧を出して足す
lead: 2つの容器をつなぐと、それぞれの気体は容器全体に広がります。広がった後の分圧を反比例で出し、足せば全圧です。
:::

コックでつながった2つの容器に別々の気体を入れ、コックを開く問題は、次の順に解きます。

:::list
ordered: true
items:
- コックを開いた後の体積（2つの容器の合計）を出す。
- それぞれの気体について、体積が何倍になったかを書く。
- P と V は反比例なので、分圧は体積の倍率の逆数倍になる。
　温度も変わるなら、P と T は比例なので温度の倍率も掛けます。
- 分圧を足して全圧にする。
:::

具体例で、容器 A（2.0L）に 1.5×10⁵Pa の N₂、容器 B（3.0L）に 2.5×10⁵Pa の H₂ を入れてコックを開いたときの全圧を求めます（温度は一定）。

:::table
caption: コックを開いたときの分圧（温度一定）

head:
- 気体
- 開く前の圧力
- 体積の変化
- 圧力に掛ける倍率（反比例）
- 開いた後の分圧
align: left | right | right | right | right

- N₂ | 1.5×10⁵Pa | 2L → 5L（×5/2） | ×2/5 | 0.6×10⁵Pa
- H₂ | 2.5×10⁵Pa | 3L → 5L（×5/3） | ×3/5 | 1.5×10⁵Pa

:::

全圧は 0.6×10⁵ ＋ 1.5×10⁵ ＝ **2.1×10⁵Pa** です。★ 計算の途中では 0.6×10⁵Pa のまま置いておき、6.0×10⁴Pa のように桁を直さないようにしましょう。直すと手間が増えるうえ、比例関係が見えにくくなります。有効数字の形に直すのは最後だけです。

:::section
anchor: balance
title: てんびんで加重平均を求める
lead: 全圧は、2つの圧力の間を「存在比の逆の比」に内分する点です。合言葉は「多い方に近い」です。
terms:
- 加重平均
- てんびん
- 平均分子量
:::

上の具体例は、てんびんでも解けます。圧力 1.5×10⁵Pa の N₂ が 2L、圧力 2.5×10⁵Pa の H₂ が 3L あるので、全圧は **1.5 と 2.5 の間を、存在比 2 : 3 の逆の比 3 : 2 に内分する点**になります。1.5 と 2.5 の差は 1.0 なので、1.5 から 0.6 進んだ（2.5 から 0.4 戻った）**2.1×10⁵Pa** です。

//焼成: 気体の基本２ PDF p15 範囲 0.07,0.265,0.53,0.56
:::figure
src: gas-mixture-balance.png
alt: 数直線の左端に N₂（1.5×10⁵Pa）、右端に H₂（2.5×10⁵Pa）。左端から 2L、右端から 3L のおもりの札が、それぞれ反対側のウデの長さ 2 と 3 に矢印で結ばれている。支点は 2.1×10⁵Pa で、左のウデは 3（0.6）、右のウデは 2（0.4）。「多い方に近い」の注記つき
caption: おもりの 2L と 3L を、それぞれ反対側のウデの長さにします。支点の 2.1×10⁵Pa は、多い H₂ の側に寄っています。
:::

てんびんは、（腕の長さ）×（おもりの重さ）が左右で等しいときにつり合います。おもりの重さが存在比（ここでは混ぜる前の体積）、支点の位置が求める平均です。重いおもり（多い方）の側の腕が短くなるので、**支点は多い方に近く**なります。

**「存在比の逆の比で内分する」と覚えると、比を逆にし忘れる間違いが起こります。「多い方に近い」と覚えておけば、内分する向きを間違えません。**

この計算は、1.5点の生徒が2人、2.5点の生徒が3人いるテストの平均点を求めるのと同じです。点数に重み（人数）をつけた平均を**加重平均**といいます。

てんびんで正しく求められる理由は、式を並べると分かります（10⁵Pa を単位にします）。分圧を足す式は 1.5 × 2/5 ＋ 2.5 × 3/5 ＝ 2.1、1.5 と 2.5 の間を 3 : 2 に内分する点の座標を求める式も 1.5 × 2/5 ＋ 2.5 × 3/5 で、**同じ式**です。

//焼成: 気体の基本２ PDF p16 範囲 0.04,0.28,0.689,0.535（右下の隅に次の図の N₂ の字がわずかに入る）
:::figure
src: gas-mixture-same-formula.png
alt: 上の行に全圧の式 P全 ＝ P_N₂ ＋ P_H₂ ＝ 1.5×2/5 ＋ 2.5×3/5 ＝ 2.1。その下に「点 1.5 と点 2.5 の間を 3 : 2 に内分する点の座標は」と書き、分数 (1.5×2 ＋ 2.5×3)／(2 ＋ 3) ＝ 2.1。2つの式が「同じ式」の札で結ばれている
caption: 分圧を足す計算と、内分点の座標を求める計算は、並べると同じ式になります。これが、てんびんで全圧が求められる理由です。
:::

**分圧を求める必要がないときは、てんびんを使いましょう。**分圧を足して解いたときも、てんびんで「多い方に近いか」を確かめると、答えの妥当性を検討できます。

同じてんびんで、混合気体の**平均分子量**も求められます。混合気体を1種類の分子からできた気体とみなしたときの見かけの分子量を平均分子量といい、成分の分子量を物質量の比で加重平均したものです。例えば空気を N₂ : O₂ ＝ 4 : 1 とみなすと、28 と 32 の間を 1 : 4 に内分して、平均分子量は 28.8 です。

//app: ratio/balance 「てんびんで平均分子量を求める」

:::mistake
wrong: N₂ 2L と H₂ 3L を混ぜたので、全圧は 1.5 と 2.5 の間を 2 : 3 に内分する点
right: 内分する比は存在比の逆の 3 : 2 です。多い H₂ の圧力（2.5）の方に近い 2.1×10⁵Pa になります。
why: 存在比をそのまま内分の比に使うと、少ない方に近い点になってしまうためです。答えが「多い方に近い」かどうかを必ず確かめましょう。
:::

:::section
anchor: range
title: 覚える範囲
lead: 「全圧は分圧の和」「分圧は物質量に比例」「成分の体積は混合気体の体積」「てんびんは多い方に近い」の4つを覚えます。
:::

**必ず覚えるのは、「全圧 ＝ 分圧の和」「同じ容器なら分圧の比 ＝ 物質量の比」「成分気体の体積は混合気体の体積と同じ」「てんびんは多い方に近い」の4つです。**（分圧）＝（モル分率）×（全圧）は、分圧が物質量に比例することから出てくるので、覚えていなくても困りません。

もう1つ、PV ＝ nRT から **物質量 n は PV に比例する**ことも使えるようにしておきましょう。温度が同じなら、混ぜる前の「圧力 × 体積」の比がそのまま物質量の比になります。

## 例題

:::exercise
source: slides:気体の基本２「混合気体と水蒸気圧」s24〜26「練習１」とその別解（別解の本文の「2.1×10⁵Pa」は 2.8 に直した）
prompt: 容器 A（3.0L）に 2.8×10⁵Pa の N₂、容器 B（4.0L）に 1.4×10⁵Pa の H₂ を入れ、温度を一定に保ってコックを開いた。混合気体の全圧を求めよ。
answer: 2.0×10⁵Pa。合計 7L。N₂ は 3L → 7L なので分圧は 2.8×10⁵ × 3/7 ＝ 1.2×10⁵Pa、H₂ は 4L → 7L なので 1.4×10⁵ × 4/7 ＝ 0.8×10⁵Pa。足して 2.0×10⁵Pa。【てんびん】2.8 と 1.4 の間（差 1.4）を、存在比 3 : 4 の逆の 4 : 3 に内分。多い H₂ の 1.4 に近く、1.4 ＋ 1.4 × 3/7 ＝ 2.0×10⁵Pa。
:::

:::exercise
source: slides:気体の基本２「混合気体と水蒸気圧」s27〜28「練習２」
prompt: 上の例題の混合気体の平均分子量を、小数第1位まで求めよ。ただし、H ＝ 1.0、N ＝ 14 とする。
answer: 17.6。n は PV に比例するので、N₂ : H₂ ＝ 2.8×10⁵ × 3 : 1.4×10⁵ × 4 ＝ 3 : 2。分子量 28 と 2 の間（差 26）を 3 : 2 の逆の 2 : 3 に内分し、多い N₂ の 28 に近い点を求めます。28 − 26 × 2/5 ＝ 17.6。
:::

:::exercise
source: slides:気体の基本２「混合気体と水蒸気圧」s29〜31「練習３」とその別解
prompt: 300K で、容器 A（1.0L）に 1.8×10⁵Pa の O₂、容器 B（2.0L）に 2.7×10⁵Pa の H₂ を入れ、コックを開いた後、容器を 400K に保った。混合気体の全圧を有効数字2桁で求めよ。
answer: 3.2×10⁵Pa。合計 3L。O₂ は体積 ×3（反比例で ×1/3）・温度 ×4/3（比例）で 1.8×10⁵ × 1/3 × 4/3 ＝ 0.8×10⁵Pa。H₂ は体積 ×3/2（×2/3）・温度 ×4/3 で 2.7×10⁵ × 2/3 × 4/3 ＝ 2.4×10⁵Pa。足して 3.2×10⁵Pa。【てんびん】300K のまま 1.8 と 2.7 の間を 2 : 1 に内分すると、多い H₂ の 2.7 に近い 2.4×10⁵Pa。これを温度の倍率 4/3 倍して 3.2×10⁵Pa。
:::
