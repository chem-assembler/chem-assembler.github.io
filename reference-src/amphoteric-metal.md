アルミニウム Al・亜鉛 Zn・スズ Sn・鉛 Pb の単体は、**酸とも強塩基とも反応して水素を発生します**。このような元素を**両性元素**、単体を**両性金属**といいます。4つは「**あ（Al）あ（Zn）すん（Sn）なり（Pb）**」とまとめて覚えましょう。

両性元素は、周期表の金属元素と非金属元素の境界付近にあります。**両性元素はこの4つで覚えれば十分です。**

:::callout
tone: caution
text: 亜鉛 Zn は12族です。12族を遷移元素に含める場合と含めない場合があります。このページでは、性質の似ている Al と並べて両性金属として扱います。
:::

周期表で見ると、1族・2族以外の典型金属元素は、金属と非金属の境界に近いので、**ほとんどが両性を示します**。高校で出てくる Al・Sn・Pb はすべてこれに当てはまります。

ただし、同じ族では下の元素ほど陽性が強くなり、酸化物は塩基性に寄っていきます。そのため、13族の最も下にあるタリウム Tl や、15族のビスマス Bi の酸化物は塩基性で、両性元素には入りません。「1族・2族以外の典型金属はすべて両性」は、高校で出てくる元素に限って成り立つ見方です。

亜鉛 Zn は、2023年からの教科書では12族を遷移元素に含めるので、この見方からは外れます。それでも Zn は両性元素なので、4つの中に入れて覚えます。

## 酸との反応

アルミニウムも亜鉛も、イオン化傾向が H₂ より大きいので、塩酸や希硫酸に溶けて水素を出します。

:::reaction
left: 2Al ＋ 6HCl
right: 2AlCl₃ ＋ 3H₂
level: ★★★
note: Al は3価なので、Al 2個に H₂ が3個です。
:::

:::reaction
left: Zn ＋ 2HCl
right: ZnCl₂ ＋ H₂
level: ★★★
note: 希硫酸なら Zn ＋ H₂SO₄ → ZnSO₄ ＋ H₂（水素の実験室的製法）。
:::

## 強塩基との反応

水酸化ナトリウム水溶液の中では H⁺ はほとんど存在しないので、**酸化剤は H₂O** です。半反応式から組み立てます。

:::list
ordered: true
items:
- 還元剤の半反応式を書く。
　Al → Al³⁺ ＋ 3e⁻
- 酸化剤（H₂O）の半反応式を書き、e⁻ の数をそろえて足す。
　2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ を3倍して、2Al ＋ 6H₂O → 2Al³⁺ ＋ 3H₂ ＋ 6OH⁻
- 塩基性の水溶液の中の Al³⁺ には OH⁻ が4個配位するので、足りない OH⁻ を左辺に足して錯イオンにする。
　2Al³⁺ ＋ 8OH⁻ → 2[Al(OH)₄]⁻
- 左辺の OH⁻ を NaOH にもどし、右辺を塩の形にまとめる。
:::

:::reaction
left: 2Al ＋ 2NaOH ＋ 6H₂O
right: 2Na[Al(OH)₄] ＋ 3H₂
level: ★★★
note: Na[Al(OH)₄] はテトラヒドロキシドアルミン酸ナトリウム。
:::

:::reaction
left: Zn ＋ 2NaOH ＋ 2H₂O
right: Na₂[Zn(OH)₄] ＋ H₂
level: ★★★
note: Na₂[Zn(OH)₄] はテトラヒドロキシド亜鉛(Ⅱ)酸ナトリウム。Zn²⁺ は2価なので [Zn(OH)₄]²⁻ です。
:::

**「Al には OH⁻ が4個、Zn にも OH⁻ が4個」と覚えてください。**錯イオンの電荷は「金属の価数 − 4」で、Al なら 3 − 4 ＝ −1、Zn なら 2 − 4 ＝ −2 になります。これさえ決まれば、H₂O と H₂ の係数は原子の数合わせで出ます。

:::link
to: half-reaction
text: 半反応式の書き方は半反応式のページへ
:::

## 不動態 —— 濃硝酸には溶けない

アルミニウムは、**濃硝酸には溶けません**。表面に緻密な酸化被膜ができて、内部を守るためです。この状態を**不動態**といいます。鉄 Fe・ニッケル Ni も同じく濃硝酸で不動態になります。

**「Al・Fe・Ni は濃硝酸で不動態」は必ず覚えてください。**濃硝酸を運ぶ容器にアルミニウムが使えるのはこのためです。

## スズと鉛 —— 酸への溶け方が違う

スズは塩酸に溶けて Sn²⁺ になります。鉛は**塩酸や希硫酸にはほとんど溶けません**。表面に水に溶けにくい PbCl₂・PbSO₄ ができて、反応が止まるためです。鉛は**硝酸**には溶けます（Pb(NO₃)₂ は水に溶けるため）。

:::reaction
left: Sn ＋ 2HCl
right: SnCl₂ ＋ H₂
level: ★☆☆
:::

スズと鉛の単体も強塩基には溶けますが、式を書かせる問題はほとんど出ないので覚えなくても構いません。スズはめっき（ブリキ）や合金（青銅・はんだ）に、鉛は鉛蓄電池の電極や放射線の遮蔽に使われる、と用途を1つずつ覚えておけば十分です。

:::section
anchor: hydroxide
title: 水酸化物 —— 過剰の NaOH と 過剰の NH₃
lead: 両性金属のイオンに少量の塩基を加えると白色沈殿。過剰の NaOH ではすべて溶けますが、過剰の NH₃ で溶けるのは Zn だけです。
terms:
- 両性水酸化物
- 両性酸化物
- テトラヒドロキシドアルミン酸イオン
:::

Al³⁺ や Zn²⁺ に水酸化ナトリウム水溶液を少しずつ加えると、はじめは水酸化物の**白色沈殿**ができ、さらに加えると沈殿が**溶けて無色の水溶液**になります。溶けるのは、水酸化物に OH⁻ が配位して錯イオンになるためです。2段に分けて書きます。

:::reaction
left: Al³⁺ ＋ 3OH⁻
right: Al(OH)₃↓
level: ★★★
note: 少量の塩基。白色ゲル状の沈殿です。
:::

:::reaction
left: Al(OH)₃ ＋ OH⁻
right: [Al(OH)₄]⁻
level: ★★★
note: 過剰の NaOH。無色の水溶液になります。
:::

:::reaction
left: Zn²⁺ ＋ 2OH⁻
right: Zn(OH)₂↓
level: ★★★
note: 少量の塩基。白色沈殿です。
:::

:::reaction
left: Zn(OH)₂ ＋ 2OH⁻
right: [Zn(OH)₄]²⁻
level: ★★★
note: 過剰の NaOH。
:::

## アンモニア水を過剰に加えたとき

アンモニア水は弱塩基で OH⁻ が少ないので、Al(OH)₃ を [Al(OH)₄]⁻ にするほどの力はありません。**Al(OH)₃ は過剰のアンモニア水には溶けません。**一方、Zn(OH)₂ は NH₃ が4個配位した錯イオンになって溶けます。OH⁻ ではなく NH₃ が配位する、別の仕組みです。

:::reaction
left: Zn(OH)₂ ＋ 4NH₃
right: [Zn(NH₃)₄]²⁺ ＋ 2OH⁻
level: ★★★
note: テトラアンミン亜鉛(Ⅱ)イオン。無色です。
:::

:::table
caption: 水酸化物の沈殿は、過剰の試薬で溶けるか

head:
- イオン
- 少量の塩基でできる沈殿
- 過剰の NaOH
- 過剰の NH₃
align: center | left | left | left
rows:
- Al³⁺ | Al(OH)₃ 白色 | **溶ける** [Al(OH)₄]⁻ | 溶けない
- Zn²⁺ | Zn(OH)₂ 白色 | **溶ける** [Zn(OH)₄]²⁻ | **溶ける** [Zn(NH₃)₄]²⁺
- Sn²⁺ | Sn(OH)₂ 白色 | **溶ける** | 溶けない
- Pb²⁺ | Pb(OH)₂ 白色 | **溶ける** [Pb(OH)₄]²⁻ | 溶けない
:::

**「過剰の NaOH で溶けるのは両性金属の4つ、過剰の NH₃ で溶けるのは Zn（と、両性でない Cu・Ag）」は必ず覚えてください。**Al³⁺ と Zn²⁺ を分けるには、アンモニア水を過剰に加えるのが決め手になります。

:::mistake
wrong: 両性金属の水酸化物は、アンモニア水を過剰に加えても溶ける。
right: 過剰のアンモニア水で溶けるのは、両性金属では **Zn(OH)₂ だけ**です。Al(OH)₃・Pb(OH)₂ は溶けません。
why: 「両性」は酸と**強塩基**の両方に溶けるという意味で、弱塩基のアンモニア水では OH⁻ が足りないためです。Zn(OH)₂ が溶けるのは、両性だからではなく NH₃ と錯イオンをつくるためです。
:::

## 酸化物も両性

酸化アルミニウム Al₂O₃（アルミナ）と酸化亜鉛 ZnO も、酸にも強塩基にも溶ける**両性酸化物**です。式は、水酸化物の式と同じ錯イオンを右辺に置けば書けます。

:::reaction
left: Al₂O₃ ＋ 6HCl
right: 2AlCl₃ ＋ 3H₂O
level: ★★☆
:::

:::reaction
left: Al₂O₃ ＋ 2NaOH ＋ 3H₂O
right: 2Na[Al(OH)₄]
level: ★★☆
:::

:::reaction
left: ZnO ＋ 2NaOH ＋ H₂O
right: Na₂[Zn(OH)₄]
level: ★★☆
:::

:::section
anchor: aluminium
title: アルミニウムの製法と化合物
lead: アルミニウムは酸化アルミニウムの溶融塩電解でつくります。テルミット反応とミョウバンもここで扱います。
terms:
- ボーキサイト
- 溶融塩電解
- テルミット反応
- ミョウバン
:::

アルミニウムはイオン化傾向が大きいので、水溶液の電気分解では得られません。鉱石の**ボーキサイト**から純粋な酸化アルミニウム（アルミナ）をつくり、**氷晶石**とともに融解して電気分解（溶融塩電解）します。氷晶石を加えるのは、融点を下げるためです。

:::link
to: electrolysis-industry
text: 溶融塩電解の陽極・陰極の式は電気分解の工業的利用のページへ
:::

アルミニウムの粉末と酸化鉄(Ⅲ)の混合物に点火すると、激しく反応して融解した鉄ができます。Al が O と結びつきやすい（酸化されやすい）ことを使った反応で、**テルミット反応**といいます。

:::reaction
left: 2Al ＋ Fe₂O₃
right: Al₂O₃ ＋ 2Fe
level: ★★☆
note: Al が還元剤です。レールの溶接などに使われます。
:::

硫酸アルミニウムと硫酸カリウムの混合水溶液を濃縮すると、**ミョウバン** AlK(SO₄)₂・12H₂O の無色の結晶ができます。2種類の塩が一定の割合で結びついた塩を**複塩**といいます。**ミョウバンの化学式は書けるようにしておきましょう。**

## 必ず覚えるもの（★★★）

:::list
items:
- 両性元素は Al・Zn・Sn・Pb（あ あ すん なり）
- Al・Zn と塩酸、Al・Zn と NaOH 水溶液の反応式（4本）
- Al³⁺・Zn²⁺ に少量の塩基 → 白色沈殿、過剰の NaOH → 溶ける（4本）
- Zn(OH)₂ は過剰の NH₃ にも溶ける（[Zn(NH₃)₄]²⁺）。Al(OH)₃ は溶けない
- Al・Fe・Ni は濃硝酸で不動態
:::

酸化物の式（★★☆）は、水酸化物の式と同じ錯イオンを右辺に置けば出てくるので、丸暗記しなくても構いません。Sn・Pb の強塩基との反応式は覚えなくても困ることはほとんどありません。

## 例題

:::exercise
source: 自作（このページの ★★★ の式を物質名から書く）
prompt: 次の変化を化学反応式で書け。**(1) アルミニウムに塩酸を加えた　(2) アルミニウムに水酸化ナトリウム水溶液を加えた　(3) 亜鉛に水酸化ナトリウム水溶液を加えた　(4) 水酸化亜鉛に過剰のアンモニア水を加えた（イオン反応式）**
answer: (1) 2Al ＋ 6HCl → 2AlCl₃ ＋ 3H₂　(2) 2Al ＋ 2NaOH ＋ 6H₂O → 2Na[Al(OH)₄] ＋ 3H₂　(3) Zn ＋ 2NaOH ＋ 2H₂O → Na₂[Zn(OH)₄] ＋ H₂　(4) Zn(OH)₂ ＋ 4NH₃ → [Zn(NH₃)₄]²⁺ ＋ 2OH⁻
:::

:::exercise
source: 自作（過剰の NaOH・過剰の NH₃ の表を使って2つのイオンを見分ける）
prompt: Al³⁺ を含む水溶液と Zn²⁺ を含む水溶液がある。1種類の試薬だけで2つを見分けるには、何を加えて、それぞれどうなればよいか。
answer: **アンモニア水を過剰に加えます。**どちらもはじめは白色沈殿ができますが、Zn²⁺ の方は沈殿が溶けて無色の [Zn(NH₃)₄]²⁺ になり、Al³⁺ の方は Al(OH)₃ の白色沈殿が残ります。水酸化ナトリウム水溶液では、どちらも過剰で溶けてしまうので見分けられません。
:::
