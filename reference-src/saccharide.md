炭素・水素・酸素からなり、分子の中に**ヒドロキシ基 −OH をたくさん**もち、さらに**ホルミル基 −CHO かカルボニル基 C=O を1個**もつ化合物を**糖類**といいます。ご飯のデンプンも、砂糖のスクロースも、血液中のグルコースも糖類です。

:::section
anchor: definition
title: 糖類とは何か
lead: 多くの糖類は C~m~(H₂O)~n~ の形の分子式に書けるので「炭水化物」とも呼ばれます。実際は多価アルコールにホルミル基かカルボニル基が付いた化合物です。
terms:
- 糖類
- 炭水化物
:::

グルコースの分子式は C₆H₁₂O₆ で、これは C₆(H₂O)₆ と書き直せます。このように多くの糖類の分子式が C~m~(H₂O)~n~ の形になるので、糖類は**炭水化物**とも呼ばれます。

実際の構造は、炭素の鎖に −OH がたくさん付き、1か所がホルミル基かカルボニル基になっている化合物です。**「−OH がたくさん ＋ C=O が1個」**と覚えておくと、構造式を見て糖だと気づけます。

:::figure
src: saccharide-carbohydrate-name.png
svg: saccharide-carbohydrate-name.svg
alt: グルコースの分子式 C6H12O6 から矢印を引いて C6(H2O)6 と書き直した図。書き直した式の (H2O)6 の部分に括弧の線を引き、水が6個ぶんと添えてある。下に、分子の中に水が入っているわけではないという注意書きがある
caption: 分子式を書き直すと「炭素と水」の形に見えます。**見かけの式の形**から付いた呼び名です。
:::

:::section
anchor: class
title: 単糖・二糖・多糖
lead: 加水分解して、それ以上小さな糖にならないものが単糖です。単糖が2個つながったものが二糖、多数つながったものが多糖です。
terms:
- 単糖
- 二糖
- 多糖
:::

:::section
anchor: monosaccharide
title: 代表的な単糖
lead: グルコース・フルクトース・ガラクトースは、どれも分子式 C₆H₁₂O₆ の異性体です。
terms:
- グルコース
- フルクトース
- ガラクトース
- アルドース
- ケトース
- 六炭糖
:::

炭素を6個もつ単糖を**六炭糖（ヘキソース）**といいます。代表的な3つはどれも分子式が C₆H₁₂O₆ で、たがいに**異性体**の関係にあります。

鎖状構造でホルミル基 −CHO をもつ単糖を**アルドース**、カルボニル基 C=O を鎖の途中にもつ単糖を**ケトース**といいます。グルコースとガラクトースはアルドース、フルクトースはケトースです。

:::table
caption: 代表的な単糖（六炭糖）

head:
- 名称
- 分類
- 特徴
- 還元性
align: left | left | left | center
rows:
- グルコース（ブドウ糖） | アルドース | 血液中に約0.1%ふくまれる。水溶液中で六員環をつくる | あり
- フルクトース（果糖） | ケトース | 糖の中でいちばん甘い。水溶液中で六員環と五員環の両方をとる | あり
- ガラクトース | アルドース | ラクトースの成分。グルコースと −OH の向きが1か所だけ違う | あり
:::

:::section
anchor: glucose-chain
title: グルコースの鎖状構造
lead: 鎖の一端がホルミル基、残りの5個の炭素に −OH が1個ずつ付いています。不斉炭素原子は4個です。
terms:
- 鎖状構造
- ホルミル基
- 不斉炭素原子
:::

グルコースの鎖状構造は、示性式で CH₂OH−CHOH−CHOH−CHOH−CHOH−CHO と書けます。**一端がホルミル基 −CHO** なので、グルコースはアルドースです。

まん中の4つの CHOH の炭素には、H・OH と、左右の違う原子団が付いています。4つとも違うものが付いているので、**不斉炭素原子は4個**です。両端の CH₂OH と CHO の炭素は、同じ H を2個もつか二重結合をもつので不斉炭素原子ではありません。

src: saccharide-glucose-chain.png

caption: 鎖の一端が**ホルミル基**。間の4個の炭素が不斉炭素原子です。
:::

:::section
anchor: ring
title: 環状構造と α形・β形
lead: 1位の炭素と5位の炭素の −OH の酸素がつながると六員環になります。そのとき1位にできる −OH の向きで α形と β形に分かれます。
terms:
- 環状構造
- α-グルコース
- β-グルコース
:::

グルコースの結晶や水溶液の大部分は、鎖状ではなく**六員環の環状構造**をとっています。鎖状構造の**5位の炭素に付いた −OH の酸素**が、**1位のホルミル基の炭素**と結合して環が閉じます。

環が閉じると、1位の炭素に新しく −OH ができます。この −OH が環の下側を向いたものを**α-グルコース**、上側を向いたものを**β-グルコース**といいます（環を、酸素を右奥に置く向きで描いたとき）。

**「α形とβ形の違いは、1位の −OH の向きだけ」**と覚えましょう。この1か所の違いが、多糖類ではデンプンとセルロースの違いになります。

:::section
anchor: equilibrium
title: 水溶液中の平衡と還元性
lead: 水溶液中では α形・鎖状構造・β形の3つが平衡になって共存しています。開いた鎖状構造のホルミル基が還元性を示します。
terms:
- 平衡
- 還元性
- 銀鏡反応
- フェーリング液の還元
:::

α-グルコースの結晶を水に溶かすと、環の一部が開いて鎖状構造になり、それがまた閉じるときに β形にもなります。こうして水溶液中では**α形・鎖状構造・β形の3つが平衡の状態**で共存します。

:::reaction
left: α-グルコース（環状）
right: 鎖状構造（ホルミル基をもつ）
level: ★★★
note: 1位の炭素と環の酸素の間の結合が切れて環が開きます。水溶液中では左右に行き来しています。
:::

:::reaction
left: 鎖状構造（ホルミル基をもつ）
right: β-グルコース（環状）
level: ★★★
note: 開いた鎖がもう一度閉じるとき、1位の −OH が反対を向くと β形になります。
:::

**「環状の結晶を水に溶かすと、一部が鎖状に開く」**と覚えましょう。鎖状構造はごくわずかですが、ここに**ホルミル基**が現れるので、グルコースの水溶液は**還元性**を示します。

:::reaction
left: CH₂OH(CHOH)₄CHO ＋ 2[Ag(NH₃)₂]⁺ ＋ 3OH⁻
right: CH₂OH(CHOH)₄COO⁻ ＋ 2Ag ＋ 4NH₃ ＋ 2H₂O
level: ★★☆
note: 銀鏡反応。鎖状構造のホルミル基が酸化されて、銀が析出します。
:::

:::reaction
left: CH₂OH(CHOH)₄CHO ＋ 2Cu²⁺ ＋ 5OH⁻
right: CH₂OH(CHOH)₄COO⁻ ＋ Cu₂O ＋ 3H₂O
level: ★★☆
note: フェーリング液の還元。酸化銅(I) Cu₂O の赤色沈殿ができます。
:::

**「グルコースは銀鏡反応もフェーリング液の還元も陽性」は必ず暗記してください。**イオン反応式そのものは、アルデヒドの式の R を糖の形に置き換えただけなので、丸暗記しなくても書けます。

:::section
anchor: fructose
title: フルクトースが還元性を示すわけ
lead: フルクトースはホルミル基をもたないケトースですが、塩基性の水溶液中で一部がホルミル基をもつ形に変わるので、還元性を示します。
terms:
- フルクトース
:::

フルクトースの鎖状構造には**ホルミル基がありません**。それでもフルクトースは、銀鏡反応もフェーリング液の還元も陽性です。

これは、銀鏡反応やフェーリング液の反応が起こる**塩基性の水溶液中で、フルクトースの一部がホルミル基をもつ構造に変わる**ためです。

:::mistake
wrong: フルクトースはケトースでホルミル基をもたないので、還元性を示さない
right: フルクトースも**還元性を示します**。塩基性の水溶液中で、一部がホルミル基をもつ構造に変わるためです。
why: 「還元性 ＝ ホルミル基」を逆向きに使って「ホルミル基が無い ＝ 還元性が無い」としてしまうためです。★ **単糖はすべて還元性を示す**、と覚えておけば迷いません。
:::

**「単糖はすべて還元性を示す」と覚えてください。**変わる仕組みの名前や途中の構造は、覚える必要はありません。

:::section
anchor: fermentation
title: アルコール発酵
lead: 酵母のもつ酵素群チマーゼで、グルコースはエタノールと二酸化炭素に分解されます。
terms:
- アルコール発酵
- チマーゼ
:::

グルコースやフルクトースなどの単糖に**酵母**を加えておくと、酵母がもつ酵素群**チマーゼ**のはたらきで、**エタノールと二酸化炭素**が生じます。これを**アルコール発酵**といいます。

:::reaction
left: C₆H₁₂O₆
over: チマーゼ
right: 2C₂H₅OH ＋ 2CO₂
level: ★★★
note: 係数の2と2は、左右で炭素6個・水素12個・酸素6個を合わせればその場で出てきます。
:::

**この反応式は暗記してください。**係数を忘れても、C₂H₅OH と CO₂ ができることさえ覚えていれば、原子の数を合わせて係数を出せます。
