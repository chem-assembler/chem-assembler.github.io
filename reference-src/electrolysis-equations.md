電気分解で両極の反応式を書くには、まず**何が反応するか**を優先順位で決めます。決まったら、反応する物質を3つに分けて式を書きます。

:::section
anchor: classes
title: 反応する物質は3つに分けられる
lead: 電気分解で反応するのは、金属・ハロゲン化物イオン・水関係（H₂O・H⁺・OH⁻）の3つだけです。
terms:
- 水関係
:::

陽極の優先順位（電極の金属・ハロゲン化物イオン・OH⁻・H₂O）と、陰極の優先順位（金属の陽イオン・H₂O）に出てくる物質を並べ直すと、**金属**、**ハロゲン化物イオン**、**水関係**（H₂O・H⁺・OH⁻）の3つに分けられます。NO₃⁻ や SO₄²⁻ などの陰イオンは水溶液の中では反応しないので、どこにも入りません。

:::table
caption: 電気分解で反応する物質の3分類
source: slides:電気分解の基本２ s14「電気分解で反応する物質の分類」（陽極・陰極の優先順位の各行を、金属・ハロゲン化物イオン・水関係の3つに色分けした図）を表に直したもの
head:
- 分類
- 陽極（酸化）
- 陰極（還元）
align: left | left | left
rows:
- 金属 | C・Au・Pt 以外の電極の金属が溶ける | Al よりイオン化傾向が小さい金属の陽イオンが析出する
- ハロゲン化物イオン | Cl⁻・Br⁻・I⁻ がハロゲンの単体になる | ——
- 水関係 | H₂O（中・酸性）か OH⁻（塩基性）から O₂ | H₂O（中・塩基性）か H⁺（酸性）から H₂
:::

:::section
anchor: metal
title: 金属の反応式
lead: 金属の単体と陽イオンは可逆で、陽極では単体が溶け、陰極では陽イオンが析出します。イオンの電荷を覚えていれば書けます。
:::

金属の単体は e⁻ を放出して陽イオンになる**還元剤**、金属の陽イオンは e⁻ を受け取って単体になる**酸化剤**で、この2つは1本の可逆な式で結ばれています。陽極では右向き（単体が溶ける）、陰極では左向き（陽イオンが析出する）に進みます。

:::figure
src: electrolysis-equations-metal.png
svg: electrolysis-equations-metal.svg
alt: 金属の反応の表。Cu ⇄ Cu²⁺ ＋ 2e⁻（Cu⁺ も存在するが Cu²⁺ になる）、Ag ⇄ Ag⁺ ＋ e⁻（Ag⁺ のみ）、Fe ⇄ Fe²⁺ ＋ 2e⁻（Fe³⁺ も存在するが Fe²⁺ になる）、Zn ⇄ Zn²⁺ ＋ 2e⁻、Al ⇄ Al³⁺ ＋ 3e⁻、H₂ ⇄ 2H⁺ ＋ 2e⁻。上に、還元剤の Cu が陽極で、酸化剤の Cu²⁺ が陰極で反応することを示す矢印
caption: 右向きが陽極での反応、左向きが陰極での反応です。**Cu は Cu²⁺、Fe は Fe²⁺** になる、というイオンの電荷だけは覚えておきます。
:::

具体例で、硫酸銅(Ⅱ)水溶液を銅電極で電気分解する場合の式を書きます。

:::reaction
left: Cu
right: Cu²⁺ ＋ 2e⁻
level: ★★★
note: 陽極。電極の Cu が溶けて Cu²⁺ になります。
:::

:::reaction
left: Cu²⁺ ＋ 2e⁻
right: Cu
level: ★★★
note: 陰極。水溶液中の Cu²⁺ が陰極の上に析出します。
:::

**Cu は Cu⁺ ではなく Cu²⁺、Fe は Fe³⁺ ではなく Fe²⁺ になる**ことは必ず覚えてください。Ag は Ag⁺ にしかなりません。

:::section
anchor: halogen
title: ハロゲン化物イオンの反応式
lead: 2X⁻ → X₂ ＋ 2e⁻ の形で、ハロゲンの単体ができます。
:::

ハロゲン化物イオンは陽極で e⁻ を奪われ、ハロゲンの単体になります。どれも同じ形 2X⁻ → X₂ ＋ 2e⁻ で書けます。

:::reaction
left: 2Cl⁻
right: Cl₂ ＋ 2e⁻
level: ★★★
note: Cl₂ は黄緑色の気体なので、↑ を付けて Cl₂↑ と書くこともあります。
:::

:::reaction
left: 2I⁻
right: I₂ ＋ 2e⁻
level: ★★★
note: I₂ は黒紫色の固体です（水溶液中では I⁻ と結びついて褐色の液になります）。
:::

:::reaction
left: 2Br⁻
right: Br₂ ＋ 2e⁻
level: ★★☆
note: Br₂ は赤褐色の液体です。気体ではないので ↑ は付けません。
:::

:::section
anchor: water
title: 水関係の4本の式
lead: 陽極では O₂、陰極では H₂ が発生します。H₂O の係数はすべて2、発生する気体の係数は1です。
terms:
- 液性
:::

水関係の反応式は、液性によって書き方が変わります。**中・塩基性の水溶液には H⁺ がほとんど無く、中・酸性の水溶液には OH⁻ がほとんど無い**ためです（そこに存在しない物質は、反応式の左辺には書けません）。

:::table
caption: 水関係の4本の式
source: slides:電気分解の基本２ s21「水関係の反応式のまとめ」の4本と、陽極・陰極それぞれの「中・酸性なら／塩基性なら」の文を表に直したもの
head:
- 電極
- 液性
- 反応するもの
- 反応式
align: center | center | center | left
rows:
- 陽極 | 中性・酸性 | H₂O | 2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻
- 陽極 | 塩基性 | OH⁻ | 4OH⁻ → O₂ ＋ 2H₂O ＋ 4e⁻
- 陰極 | 中性・塩基性 | H₂O | 2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻
- 陰極 | 酸性 | H⁺ | 2H⁺ ＋ 2e⁻ → H₂
:::

**「電気分解の反応式に出てくる H₂O の係数はすべて2」「陰極では H₂、陽極では O₂ が発生し、係数は1」と覚えましょう。**この2つを覚えておけば、4本とも残りは H と電荷の数合わせで出ます。

:::figure
src: electrolysis-equations-water.png
alt: 水関係の反応式のまとめ。陽極は 2H₂O → 4H⁺ ＋ O₂ ＋ 4e⁻ と 4OH⁻ → 2H₂O ＋ O₂ ＋ 4e⁻ が ＋OH⁻・＋H⁺ の矢印で行き来し、陰極は 2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ と 2H⁺ ＋ 2e⁻ → H₂ が ＋OH⁻・＋H⁺ の矢印で行き来する
caption: 同じ電極の2本は、両辺に H⁺ か OH⁻ を足せば互いに書き換えられます。**陽極は「2H₂O が O₂ になる」式を、陰極は「2H⁺ が H₂ になる」式を起点にする**と楽です。
:::

:::section
anchor: cathode-water
title: 陰極の H₂O の式は H⁺ の式から導く
lead: 簡単に書ける 2H⁺ ＋ 2e⁻ → H₂ の両辺に 2OH⁻ を足すと、中・塩基性の式になります。
:::

陰極の H⁺ の式は、金属の陽イオンと同じ要領ですぐ書けます。そこから H₂O の式を導く手順は次のとおりです。

:::list
ordered: true
items:
- 酸性の式 2H⁺ ＋ 2e⁻ → H₂ を書く。
- 左辺の H⁺ と同じ数の OH⁻（2OH⁻）を両辺に足す。
- 左辺の 2H⁺ ＋ 2OH⁻ を 2H₂O にまとめる。
　2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻
:::

酸性の水溶液の中では、生じた OH⁻ はすぐに H⁺ と結びついて H₂O になる（中和）ので、H⁺ の式のまま書きます。

:::figure
src: electrolysis-equations-app-condition.png
shot: url=/ion-equation/condition.html?s=b1 sel=#timeline 状態=開いた直後（OH⁻ の数は 0 のまま）
alt: アプリ「イオンでみる化学反応式」の液性の書き換えの画面。酸性条件の半反応式 2H⁺ ＋ 2e⁻ → H₂ を出発点に、両辺に足す OH⁻ の数を選ぶ欄と、H⁺ と OH⁻ が結びついて H₂O になる様子の図がある
caption: 両辺に足す OH⁻ の数を選ぶと、H⁺ と OH⁻ が結びついて H₂O になる様子が見られます。
:::

:::section
anchor: anode-water
title: 陽極の H₂O の式は直接つくる
lead: 陽極は OH⁻ の式がつくりづらいので、「2H₂O が O₂ になる」ことだけを覚えて、H⁺ と e⁻ で数を合わせます。
:::

陽極の OH⁻ の式は、そのままではつくりづらいので、H₂O の式を直接つくります。**2H₂O が還元剤としてはたらいて O₂ になる**、と考えます。

:::list
ordered: true
items:
- 2H₂O を左辺に、O₂ を右辺に書く。
　2H₂O → O₂
- H⁺ で両辺の H 原子の数を合わせる。
　2H₂O → O₂ ＋ 4H⁺
- e⁻ で両辺の電荷を合わせる。
　2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻
:::

塩基性のときは、できた式の両辺に 4OH⁻ を足して、4H⁺ ＋ 4OH⁻ を 4H₂O にまとめ、両辺の 2H₂O を消すと、4OH⁻ → O₂ ＋ 2H₂O ＋ 4e⁻ になります。

:::section
anchor: sono2
title: 水の式の書き方その2 —— 電荷を持つものはどれか
lead: 2H₂O から e⁻ を取り去れば H⁺ が、e⁻ を加えれば OH⁻ ができる、と考えても書けます。
:::

H₂O の式は、H⁺・OH⁻ の式を経由せずに直接つくることもできます。

:::list
ordered: true
items:
- 陰極（その2）：2H₂O を左辺に書く。左辺に e⁻ を加えるので、右辺には H と O でできた負の電荷をもつもの、つまり OH⁻ ができるはず。O 2個をすべて OH⁻ にして右辺に 2OH⁻、残った H 2個で H₂ をつくり、e⁻ で合わせる。
　2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻
- 陽極（その2）：2H₂O を左辺に書く。e⁻ を取り去るので、右辺には H と O でできた正の電荷をもつもの、つまり H⁺ ができるはず。H 4個をすべて H⁺ にして右辺に 4H⁺、残った O 2個で O₂ をつくり、e⁻ で合わせる。
　2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻
:::

**その1・その2はどちらを使っても構いません。**書きやすいほうを1つ決めて、くり返し使えるようにしましょう。

:::mistake
wrong: 陽極の水の反応がわからないので 2H₂O → 2H₂ ＋ O₂ と書いた
right: 陽極では e⁻ を奪われるので、式の**右辺に e⁻** が出ます。2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻ です。
why: 反応式の書き方がわからないとき、右辺にむやみに単体をつくってしまうためです。単体はエネルギーが高く不安定なので、知識として知っている場合以外は右辺に単体をつくりません。★ 陰極は「e⁻ を押し付けられる → 左辺に e⁻」、陽極は「e⁻ を奪われる → 右辺に e⁻」から書き始めます。
:::

:::section
anchor: range
title: 覚える範囲
lead: 金属イオンの電荷・ハロゲンの単体の化学式・水関係の「係数2と1」を覚え、あとは手順で書きます。
:::

**水関係の4本の式は必ず書けるようにしてください。**丸暗記してもよいですが、「H₂O の係数は2・気体の係数は1」と、陰極は H⁺ の式から・陽極は 2H₂O → O₂ から、の2つを覚えておけば、液性がどちらでもその場でつくれます。

金属とハロゲン化物イオンの式は、イオンの電荷（Cu²⁺・Fe²⁺・Ag⁺ など）と単体の化学式を覚えていれば書けるので、式そのものを暗記する必要はありません。
