化学反応では、物質が変わるのと同時に熱が出入りします。このページでは、その熱を**エンタルピーの変化 ΔH** で表し、化学反応式に添えて書くところまでを扱います。水の融解や蒸発のように、状態が変わるときにも熱が出入りすることは、物質の状態のページで見ました。

:::section
anchor: sign
title: 発熱反応と吸熱反応 —— ΔH の符号
lead: 反応エンタルピー ΔH は（反応後のエンタルピー）−（反応前のエンタルピー）です。発熱反応では ΔH が負、吸熱反応では ΔH が正になります。
terms:
- 発熱反応
- 吸熱反応
- エンタルピー
- 反応エンタルピー
:::

反応が進むと、まわりが温まるものと冷えるものがあります。まわりへ熱を出す反応が**発熱反応**、まわりから熱を取りこむ反応が**吸熱反応**です。燃焼や中和は発熱反応、炭素と水蒸気から一酸化炭素と水素ができる反応は吸熱反応です。

熱の出どころをたどると、物質の1つ1つが内にたくわえているエネルギーに行き着きます。圧力を一定に保った条件で、このたくわえを量として表したものが**エンタルピー**（記号 H）です。

反応の後と前でエンタルピーがどれだけ変わったかが**反応エンタルピー**で、記号 ΔH で書きます。

**ΔH ＝（反応後のエンタルピーの和）−（反応前のエンタルピーの和）**

発熱反応では、反応後のほうがエンタルピーが低くなります。下がった分が熱として外に出ていくので、**ΔH は負**になります。吸熱反応は逆で、外から熱を受け取ってエンタルピーが上がるので、**ΔH は正**になります。

具体例1で、メタン CH₄ 1mol を完全に燃やすと 891kJ の熱が出ます。反応前（CH₄ 1mol と O₂ 2mol）のエンタルピーの合計は、反応後（CO₂ 1mol と H₂O（液）2mol）の合計より 891kJ 高いので、ΔH ＝ −891kJ です。

具体例2で、C（黒鉛）1mol と H₂O（気）1mol から CO と H₂ ができると、131kJ の熱を吸収します。反応後のほうが 131kJ 高いので、ΔH ＝ ＋131kJ です。

この関係は、**エネルギーの高いものを上、低いものを下**に並べた図で見るのがいちばん確かです。これを**エネルギー図**といいます。上から下へ向かう矢印が発熱（ΔH が負）、下から上へ向かう矢印が吸熱（ΔH が正）です。

//app: ratio/thermo 「エネルギー図で ΔH の符号を確かめる」

**逆向きの反応の ΔH は、符号だけを反転させた値**になります。CO₂ を C（黒鉛）と O₂ に分けるには ＋394kJ が要ります。エネルギー図で矢印の向きを逆にしただけなので、高さの差は同じで、向きが逆になるためです。

:::mistake
wrong: 発熱反応は熱が「出る」ので、ΔH はプラスで書く
right: ΔH は**物質の側から見た**エンタルピーの変化です。発熱反応では物質のエンタルピーが下がるので **ΔH は負**、吸熱反応では上がるので **ΔH は正**です。
why: 「出てきた熱の量」を主語にすると符号が逆になります。★ エネルギー図を描いて、矢印が下向きなら負、上向きなら正と決めれば迷いません。
:::

:::section
anchor: write
title: 反応エンタルピーの書き方
lead: 着目する物質の係数を1にした化学反応式を書き、状態を添え、右に ΔH ＝ ○○kJ を書き加えます。
:::

反応エンタルピーは、化学反応式の右に書き加えて表します。次の順で書きます。

:::list
ordered: true
items:
- 化学反応式を書く。
　水素の燃焼なら 2H₂ ＋ O₂ → 2H₂O。
- 着目する物質の係数を1にする。ほかの係数は分数になってもよい。
　「H₂ 1mol が燃焼するとき」なら H₂ ＋ ½O₂ → H₂O。
- 化学式のすぐ後ろに状態を添える。（気）＝気体、（液）＝液体、（固）＝固体、aq ＝水溶液。同素体がある単体は C（黒鉛）のように区別する。
- 右辺の後に ΔH ＝ ○○kJ を書き加える。発熱なら ΔH ＝ −○○kJ、吸熱なら ΔH ＝ ＋○○kJ。
:::

具体例3で、水素 H₂ 1mol が燃焼して液体の水ができるとき、286kJ の熱が出ることを式にします。

:::reaction
left: H₂(気) ＋ ½O₂(気)
right: H₂O(液)　ΔH ＝ −286 kJ
level: ★★★
note: 発熱なので ΔH は負。着目する H₂ の係数を1にしたので、O₂ の係数は ½ になります。
:::

**式に書くときの単位は kJ、「○○エンタルピーは −286kJ/mol」と言うときの単位は kJ/mol** です。式は係数の mol ぶんの熱を表し、名前の付いた値は 1mol あたりの熱を表すためです。

⚠ **状態を書き落とすと値が変わります。** 同じ水素の燃焼でも、水蒸気ができるときは ΔH ＝ −242kJ です。差の 44kJ は、水 1mol が蒸発するのに使われた熱（蒸発エンタルピー）の分です。

:::reaction
left: H₂(気) ＋ ½O₂(気)
right: H₂O(気)　ΔH ＝ −242 kJ
level: ★★☆
note: 液体の水ができるときより 44kJ 小さい発熱。生じた水を蒸発させる分だけ、外に出る熱が減ります。
:::

:::mistake
wrong: C(黒鉛) ＋ O₂(気) ＝ CO₂(気) ＋ 394 kJ のように、熱を右辺に足して書く
right: いまの書き方では、化学反応式の右に **ΔH ＝ −394 kJ** を添えます。C(黒鉛) ＋ O₂(気) → CO₂(気)　ΔH ＝ −394 kJ
why: 古い参考書や過去の入試問題は「熱化学方程式」で書かれていて、発熱を**正の反応熱**（＋394kJ）で表していました。2023 年度の改訂で ΔH に切り替わり、**符号の向きが逆**になっています。古い問題を解くときは、反応熱 Q ＝ −ΔH と読みかえます。
:::

:::section
anchor: kinds
title: いろいろな反応エンタルピー
lead: 燃焼・生成・中和・溶解のエンタルピーは、それぞれ決まった物質 1mol あたりの値です。何を 1mol にそろえるかを名前ごとに押さえます。
terms:
- 燃焼エンタルピー
- 生成エンタルピー
- 中和エンタルピー
- 溶解エンタルピー
:::

反応エンタルピーには、反応の種類ごとに名前が付いています。**名前ごとに「何を 1mol にそろえるか」が決まっている**ので、式を書くときはその物質の係数を1にします。

:::table
caption: 名前の付いた反応エンタルピー
source: 教科書（R5化学Vol.1-2編 1章1節）の各エンタルピーの定義と表1〜3の値を、「何を 1mol にそろえるか」の列で並べ直したもの
head:
- 名前
- 1mol にそろえる物質
- 符号
- 例（kJ/mol）
align: left | left | left | left
rows:
- 燃焼エンタルピー | 燃焼する物質（完全燃焼） | いつも負 | CH₄ −891、C（黒鉛）−394、H₂ −286
- 生成エンタルピー | できる化合物（成分元素の単体から） | 負も正もある | H₂O（液）−286、CO₂ −394、C₂H₂ ＋227
- 中和エンタルピー | できる水 H₂O | いつも負 | 強酸と強塩基の希薄水溶液で −56.5
- 溶解エンタルピー | 溶かす溶質（多量の水に） | 負も正もある | NaOH（固）−44.5、KNO₃（固）＋34.9
- 融解・蒸発エンタルピー | 状態が変わる物質 | いつも正 | H₂O 融解 ＋6.0、蒸発 ＋44
:::

**生成エンタルピーは「単体から」がつくので、安定な単体の生成エンタルピーは 0kJ/mol** と決めます。同素体があるときは安定なほう（炭素なら黒鉛、酸素なら O₂）を 0 にします。

具体例4で、アンモニア NH₃ の生成エンタルピー −46kJ/mol を式にします。着目するのは NH₃ なので、NH₃ の係数を1にします。

:::reaction
left: ½N₂(気) ＋ 3/2H₂(気)
right: NH₃(気)　ΔH ＝ −46 kJ
level: ★★☆
note: 生成エンタルピーの式は、左辺が成分元素の単体だけ、右辺がその化合物 1mol だけになります。
:::

//式: 3/2H₂ の分数は、第2周で縦の分数の器ができたら組み直す

中和エンタルピーは、**強酸と強塩基の希薄水溶液どうしなら、酸と塩基の種類によらずほぼ −56.5kJ/mol** です。どれも H⁺ aq ＋ OH⁻ aq → H₂O(液) という同じ反応だからです。

:::link
to: neutralization
text: 中和の反応（H⁺ と OH⁻ が結びつく）はこちら
:::

溶解エンタルピーは、発熱のもの（NaOH・濃硫酸）も吸熱のもの（KNO₃・NH₄NO₃）もあります。冷却パックは、硝酸アンモニウムや尿素が水に溶けるときの吸熱を使っています。

:::section
anchor: range
title: 覚える範囲
lead: ΔH ＝（反応後）−（反応前）と「発熱は負」、式の書き方、各エンタルピーが何 1mol あたりかを覚えます。値そのものは問題文に書かれます。
:::

**「ΔH ＝（反応後）−（反応前）」「発熱は負・吸熱は正」「単体の生成エンタルピーは 0」の3つは必ず覚えてください。**名前の付いたエンタルピーは、上の表の「1mol にそろえる物質」の列を書けるようにしましょう。

燃焼エンタルピーや生成エンタルピーの**数値は、問題文で与えられるので覚える必要はありません。**ただし、中和エンタルピーの −56.5kJ/mol と、水の蒸発エンタルピーが ＋44kJ/mol 程度であることは、知っていると検算に使えます。

## 例題

:::exercise
source: 自作（このページの「書き方」の手順と表の値から作った問い。もとにした本はありません）
prompt: 次の (1)〜(3) の内容を、化学反応式の右に ΔH を添えた形で書け。**(1) エタノール C₂H₅OH（液）の燃焼エンタルピーは −1368kJ/mol である（生じる水は液体）。　(2) 塩化ナトリウム NaCl（固）の生成エンタルピーは −411kJ/mol である。　(3) 冷却パックに使う硝酸アンモニウム NH₄NO₃（固）0.20mol を多量の水に溶かしたところ、5.2kJ の熱が奪われた。**
answer: (1) C₂H₅OH(液) ＋ 3O₂(気) → 2CO₂(気) ＋ 3H₂O(液)　ΔH ＝ −1368 kJ。着目する C₂H₅OH の係数を1にして、C・H・O の順に数を合わせます。　(2) Na(固) ＋ ½Cl₂(気) → NaCl(固)　ΔH ＝ −411 kJ。生成エンタルピーなので、左辺はふだんの状態の単体（固体の Na と気体の Cl₂）だけ、NaCl の係数は1です。　(3) NH₄NO₃(固) ＋ aq → NH₄NO₃ aq　ΔH ＝ ＋26 kJ。0.20mol : 5.2kJ ＝ 1mol : x kJ より 1mol あたり 26kJ の吸熱で、吸熱なので ΔH は正です。
:::

:::exercise
source: 自作（このページの「符号」の節から作った問い。数値は教科書の表1・表3の値）
prompt: C(黒鉛) ＋ O₂(気) → CO₂(気)　ΔH ＝ −394 kJ である。**(1) この反応は発熱反応か、吸熱反応か。　(2) CO₂(気) → C(黒鉛) ＋ O₂(気) の ΔH は何 kJ か。　(3) CO₂ 0.50mol ができるとき、何 kJ の熱が出るか。**
answer: (1) ΔH が負なので**発熱反応**。　(2) **＋394kJ**。逆向きにたどると符号だけが反転します。　(3) **197kJ**。CO₂ 1mol : 394kJ ＝ CO₂ 0.50mol : x kJ より、x ＝ 197。
:::
