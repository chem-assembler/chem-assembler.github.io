酸素 O₂・オゾン O₃・過酸化水素 H₂O₂ は、どれも**酸化剤**としてはたらく物質です。反応式は、それぞれの半反応式を先に書いてから、相手の半反応式と足して組み立てます。半反応式の書き方は「半反応式の書き方」のページで確かめてください。

構造式は O=O で、2つの O 原子が二重結合で結びついた無極性分子です。

## 酸化剤としての反応

空気中の反応なので、H⁺ や H₂O を加えず、**O 原子は安定な O²⁻ になる**と書きます。

:::reaction
left: O₂ ＋ 4e⁻
right: 2O²⁻
level: ★★★
note: 空気中で O₂ が酸化剤としてはたらくときの半反応式。O 原子1個が e⁻ を2個受け取るので、O₂ 1分子では 4価です。
:::

O₂ は金や白金を除くほとんどの金属を空気中で酸化し、表面に酸化物をつくります。**生じる金属イオンの価数を覚えていれば**、反応式が書けます。

:::reaction
left: 2Cu ＋ O₂
right: 2CuO
level: ★★★
note: Cu が還元剤、O₂ が酸化剤。2Cu → 2Cu²⁺ ＋ 4e⁻ と O₂ ＋ 4e⁻ → 2O²⁻ を足したものです。高温では 4Cu ＋ O₂ → 2Cu₂O と反応します。
:::

O₂ は高温で非金属元素の化合物の多くを酸化します。完全燃焼すると、各元素の最高酸化数の酸化物（CO₂・H₂O など）ができます。**「完全燃焼で CO₂ と H₂O ができる」ことを覚えて係数を合わせる**だけです。

:::reaction
left: CH₄ ＋ 2O₂
right: CO₂ ＋ 2H₂O
level: ★★★
note: 炭素は CO₂、水素は H₂O になります。
:::

## 酸素の実験室的製法

:::reaction
left: 2H₂O₂
over: MnO₂（触媒）
right: 2H₂O ＋ O₂↑
level: ★★★
note: 過酸化水素水に触媒として酸化マンガン(Ⅳ) MnO₂ を加えます。H₂O₂ は不安定なので、安定な H₂O になって O₂ を出します。
:::

この反応は、酸化剤も還元剤も H₂O₂ という**自己酸化還元反応**です。H₂O₂ が酸化剤としてはたらく半反応式と、還元剤としてはたらく半反応式を足すと組み立てられます（下の「過酸化水素」の節）。反応速度の単元でもよく登場し、「H₂O₂ の係数は2だが1次反応」と覚えておきます。

:::figure
src: oxygen-ozone-h2o2-decomp.png
alt: H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O と H₂O₂ → O₂ ＋ 2H⁺ ＋ 2e⁻ を足して 2H₂O₂ → 2H₂O ＋ O₂ を得る筆算
caption: 酸化剤の H₂O₂ と還元剤の H₂O₂ を足すと、H⁺ と e⁻ が消えて分解の式になります。実用性はありませんが、H₂O₂ の2本の半反応式を覚える助けになります。
:::

:::reaction
left: 2KClO₃
over: MnO₂（触媒）・加熱
right: 2KCl ＋ 3O₂↑
level: ★★☆
note: 塩素酸カリウム KClO₃ と酸化マンガン(Ⅳ)の混合物を加熱します。どちらも固体なので加熱が必要です。KClO₃ の Cl（+5）が安定な Cl⁻ になって O₂ を出す自己酸化還元反応です。
:::

希硫酸や水酸化ナトリウム水溶液を電気分解しても、**陽極**から O₂ が出ます（陰極からは H₂）。

:::reaction
left: 2H₂O
right: O₂↑ ＋ 4H⁺ ＋ 4e⁻
level: ★★★
note: 希硫酸（酸性）の電気分解の陽極。
:::

:::reaction
left: 4OH⁻
right: O₂↑ ＋ 2H₂O ＋ 4e⁻
level: ★★★
note: 水酸化ナトリウム水溶液（塩基性）の電気分解の陽極。
:::

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::section
anchor: hydrogen-peroxide
title: 過酸化水素 —— 酸化剤にも還元剤にもなる
lead: H₂O₂ の O は酸化数 −1。ふつうは −2 になる酸化剤、KMnO₄ や K₂Cr₂O₇ のような極めて強い酸化剤が相手のときだけ 0 になる還元剤です。
terms:
- 過酸化水素
- オキシドール
- 自己酸化還元反応
codes:
- inorg.nonmetal.h2o2-dual
:::

過酸化水素 H₂O₂ は無色の液体で、ふつうは水溶液（過酸化水素水）として使います。約3%の水溶液は**オキシドール**とよばれ、消毒に使われます。傷口に塗ると泡が出るのは、H₂O₂ が分解して O₂ が発生するためです。

H₂O₂ の O 原子の酸化数は −1 です。H₂O₂ は不安定なので、安定な H₂O（O の酸化数 −2）になろうとする、比較的強い**2価の酸化剤**です。

:::reaction
left: H₂O₂ ＋ 2H⁺ ＋ 2e⁻
right: 2H₂O
level: ★★★
note: 酸化剤としてはたらくとき（酸性条件）。O 原子2個が e⁻ を1個ずつ受け取って −1 → −2。
:::

一方、過マンガン酸カリウム KMnO₄ や二クロム酸カリウム K₂Cr₂O₇ のように**極めて酸化力の強い相手には還元剤**としてはたらき、O₂（酸化数 0）になります。

:::reaction
left: H₂O₂
right: O₂↑ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 還元剤としてはたらくとき。「H₂O₂ は還元剤になると O₂ になる」と覚えれば、あとは手順どおりに書けます。
:::

「**酸化剤なら H₂O、還元剤なら O₂**」の2本はどちらも必ず覚えてください。どちらではたらくかは相手で決まり、相手が KMnO₄・K₂Cr₂O₇ のような強い酸化剤のときに還元剤になります。

:::callout
tone: caution
text: 「強い酸化剤が相手なら還元剤」と覚えると、相手を広げすぎます。H₂O₂ が還元剤としてはたらく相手として登場するのは、ほぼ KMnO₄ と K₂Cr₂O₇ だけです。
:::

:::link
to: transition-oxidizers
text: 過マンガン酸カリウム・二クロム酸カリウムの半反応式はこちら
:::

二酸化硫黄 SO₂ が相手なら、H₂O₂ は酸化剤としてはたらき、硫酸ができます。

:::reaction
left: H₂O₂ ＋ SO₂
right: H₂SO₄
level: ★★★
note: H₂O₂ が酸化剤、SO₂ が還元剤。H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O と SO₂ ＋ 2H₂O → SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻ を足すと、H⁺ と H₂O が打ち消し合います。
:::

O₃ は折れ線形の極性分子で、構造式の中に**配位結合**を1つ含みます。O₂ と O₃ は同じ元素 O からなる単体どうしで、互いに**同素体**です。

酸素中で**無声放電**（音の出ない放電）を行うと、オゾンができます。紫外線を当てても同じ反応が起こります。O₃ は不安定で、O₂ との間を行き来する可逆反応です。

## 酸化剤としての反応 —— 液性で書き分ける

O₃ は極めて強い**2価の酸化剤**です。3個の O 原子のうち1個だけが還元されて −2 になり、残り2個は O₂ のまま出ていきます。**「O₃ は O₂ になる」**と覚えると、半反応式は手順どおりに書けます。

:::reaction
left: O₃ ＋ 2H⁺ ＋ 2e⁻
right: O₂↑ ＋ H₂O
level: ★★☆
note: 酸性条件の半反応式。
:::

中・塩基性の水溶液では、H⁺ は OH⁻ と結びついて H₂O として存在しています。そこで、酸性の式の**両辺に H⁺ と同じ数だけ OH⁻ を足し**、H⁺ と OH⁻ を H₂O にしてから、両辺に共通する H₂O を消します。

:::reaction
left: O₃ ＋ H₂O ＋ 2e⁻
right: O₂↑ ＋ 2OH⁻
level: ★★☆
note: 中・塩基性条件の半反応式。O₃ が実際に使われるのはこの条件なので、**O₃ の半反応式はこちらを使います**。
:::

:::figure
src: oxygen-ozone-o3-basic.png
alt: O₃ ＋ 2H⁺ ＋ 2e⁻ → O₂ ＋ H₂O の両辺に 2OH⁻ を足し、左辺の 2H₂O と右辺の H₂O を1つずつ消して O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ を得る筆算
caption: 両辺に OH⁻ を2個ずつ足すと、左辺の 2H⁺ は 2H₂O になります。両辺に共通する H₂O を1つ消せば中・塩基性の式です。
:::

## オゾンの検出 —— ヨウ化カリウムデンプン紙

O₃ が出ているかは、**ヨウ化カリウムデンプン紙**を水でぬらしてかざすと分かります。紙が青く染まれば、O₃ がある目印です。紙に含まれるヨウ化物イオン I⁻ が還元剤としてはたらいてヨウ素 I₂ ができ、I₂ がデンプンとヨウ素デンプン反応を起こして青〜青紫色になります。

:::reaction
left: O₃ ＋ 2KI ＋ H₂O
right: I₂ ＋ 2KOH ＋ O₂↑
level: ★★☆
note: 酸を加えていないので、**中・塩基性条件の半反応式**を使って組み立てます。O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ と 2I⁻ → I₂ ＋ 2e⁻ を足し、両辺に 2K⁺ を戻すと KOH ができます。
:::

ヨウ化カリウムデンプン紙は、O₃ だけでなく Cl₂ など酸化剤一般の検出に使います。
