細く長く引きのばして糸にできる高分子を**繊維**といいます。合成繊維は、石油などからつくった単量体を重合させた、**天然には存在しない**高分子の繊維です。

:::section
anchor: by-type
title: 合成繊維を重合の型で整理する
lead: 合成繊維を、重合の型・単量体・主鎖の結合で並べます。開環重合でできるのはナイロン6だけです。
:::

合成繊維をつくる重合の型は、**つなぐときに何がとれるか**で3つに分かれます。

:::list
items:
- **縮合重合**：単量体の官能基どうしから、水 H₂O などの小さな分子がとれてつながります。−COOH と −NH₂ ならアミド結合、−COOH と −OH ならエステル結合になります
- **開環重合**：環状の単量体の環が開いてつながります。何もとれません
- **付加重合**：単量体の C=C が開いてつながります。何もとれません。ビニル化合物なら n CH₂=CHX → ［CH₂−CHX］ₙ の形です
:::

:::section
anchor: nylon66
title: ナイロン66
lead: アジピン酸とヘキサメチレンジアミンの縮合重合でできます。主鎖がアミド結合でつながったポリアミドです。
terms:
- ナイロン66
- アミド結合
- ポリアミド
:::

アジピン酸 HOOC−(CH₂)₄−COOH とヘキサメチレンジアミン H₂N−(CH₂)₆−NH₂ を縮合重合させると、**ナイロン66** ができます。−COOH と −NH₂ から水がとれて、**アミド結合 −CO−NH−** でつながります。

:::reaction
left: n HOOC−(CH₂)₄−COOH ＋ n H₂N−(CH₂)₆−NH₂
right: ［CO−(CH₂)₄−CO−NH−(CH₂)₆−NH］ₙ ＋ 2n H₂O
level: ★★★
note: 1つの繰り返し単位の中にアミド結合が2か所あるので、n 組つなぐと水は 2n 個とれます。
:::

//図: ナイロン66の繰り返し単位の構造式。⚠ gen: name=ナイロン66 で焼くと 16.7:1 で平たすぎて止まった（2026-09-14 実測）。繰り返し単位1つだけの登録か、折り返した配置が要る
//アプリで: アジピン酸とヘキサメチレンジアミンを並べ、反応実行モードの縮合重合（condensation_polymerization）を押した画面

名前の「66」は、**ヘキサメチレンジアミンの炭素が6個、アジピン酸の炭素が6個**であることを表しています。アジピン酸の式の (CH₂)₄ は、両端の −COOH の炭素2個を除いた数なので、合わせて6個です。他の類似の化合物でナイロン610などもあります。**数字はジアミンの炭素数、ジカルボン酸の炭素数の順**なので、ナイロン610 は**ヘキサメチレンジアミン（炭素6個）とセバシン酸 HOOC−(CH₂)₈−COOH（炭素10個）**からできます。

アミド結合をくり返しもつ高分子を**ポリアミド**といいます。

:::section
anchor: nylon6
title: ナイロン6
lead: 環状のアミドであるε-カプロラクタムに少量の水を加えて加熱すると、環が開いてつながります。何もとれない開環重合です。
terms:
- ナイロン6
- ε-カプロラクタム
- 開環重合
:::

ε-カプロラクタム C₆H₁₁NO は、アミド結合を環の中にもつ七員環の化合物です。少量の水を加えて加熱すると、**環が1か所開いて次々につながり**、**ナイロン6** ができます。

:::reaction
left: n C₆H₁₁NO（ε-カプロラクタム）
over: 少量の水
under: 加熱
right: ［NH−(CH₂)₅−CO］ₙ
level: ★★★
note: 環の中のアミド結合が切れて鎖になり、次の分子とつながります。水はきっかけとして働くだけで、反応式には出てきません。
:::
//アプリで: ε-カプロラクタムを並べて反応実行モードの開環重合（ring_opening_polymerization）を押した画面

名前の「6」は、**単量体1個に含まれる炭素が6個**であることを表しています。

ナイロン66 とナイロン6 は、どちらもアミド結合でつながったポリアミドですが、できかたが違います。**ナイロン66 は2種類の単量体から水がとれる縮合重合、ナイロン6 は1種類の環が開くだけで何もとれない開環重合**です。

:::section
anchor: polyamide-silk
title: ナイロンが絹に似ている理由
lead: 絹や羊毛のタンパク質もアミド結合でつながっています。同じ結合をもつので、ナイロンは絹に似た光沢と手ざわりになります。
terms:
- ペプチド結合
:::

絹や羊毛は、アミノ酸がつながった**タンパク質**でできています。アミノ酸どうしのつながりは、−CO−NH− の**アミド結合**で、タンパク質の場合はとくに**ペプチド結合**とよびます。**アミド結合とペプチド結合は同じ結合で、呼び名が違うだけ**です。

ナイロンは絹と同じアミド結合をくり返しもつので、**絹に似た光沢と手ざわり**をもち、強くしなやかな繊維になります。鎖と鎖のあいだで、アミド結合の N−H と C=O が水素結合をつくって引き合うためです。

ナイロンは、絹に代わる繊維として開発され、ストッキングなどに使われました。

:::section
anchor: aramid
title: アラミド繊維
lead: テレフタル酸ジクロリドと p-フェニレンジアミンの縮合重合でできる芳香族ポリアミドです。鎖がまっすぐで、きわめて強い繊維になります。
terms:
- アラミド繊維
- 芳香族ポリアミド
:::

テレフタル酸ジクロリド ClOC−C₆H₄−COCl と p-フェニレンジアミン H₂N−C₆H₄−NH₂ を縮合重合させると、ベンゼン環がアミド結合でつながった**アラミド繊維**（ポリ(p-フェニレンテレフタルアミド)）ができます。**芳香族ポリアミド**の一種です。

:::reaction
left: n ClOC−C₆H₄−COCl ＋ n H₂N−C₆H₄−NH₂
right: ［CO−C₆H₄−CO−NH−C₆H₄−NH］ₙ ＋ 2n HCl
level: ★☆☆
note: どちらの単量体もベンゼン環のパラ位に官能基があるので、鎖が一直線に伸びます。1つの繰り返し単位の中にアミド結合が2か所あるので、とれる HCl は 2n 個です。
:::
//反応式は構造式で（⚠ 保留 v1580: :::reaction は文字だけで組む器で、構造式を並べられない。テレフタル酸ジクロリドとポリ(p-フェニレンテレフタルアミド)も化合物ライブラリに無い。ジクロリドを正とし説明を加えるのは v1580 で済み）

**テレフタル酸ジクロリドは、テレフタル酸の −COOH の −OH を −Cl に置きかえた化合物**です。−COCl はカルボン酸の −COOH よりずっと反応しやすく、加熱しなくてもアミノ基とすばやくアミド結合をつくります。そのため、−COOH と −NH₂ から**水**がとれるナイロン66 と違い、ここでとれるのは**塩化水素 HCl** です。

**ベンゼン環が主鎖に入って鎖が曲がりにくく、鎖どうしがすき間なく並ぶので、同じ重さの鋼鉄より強い**繊維になります。防弾チョッキや消防服に使われます。

ナイロン66 との違いは、**アミド結合のあいだが脂肪族の −(CH₂)− か、芳香族のベンゼン環か**だけです。名前と「芳香族ポリアミド」の一言が分かれば十分でしょう。

:::section
anchor: polyester
title: ポリエステル繊維（PET）
lead: テレフタル酸とエチレングリコールの縮合重合でできるポリエチレンテレフタラート（PET）を繊維にしたものです。主鎖がエステル結合でつながったポリエステルです。
terms:
- ポリエステル繊維
:::

テレフタル酸 HOOC−C₆H₄−COOH とエチレングリコール HO−CH₂CH₂−OH を縮合重合させると、**ポリエチレンテレフタラート（PET）**ができます。−COOH と −OH から水がとれて、**エステル結合 −CO−O−** でつながります。PET を繊維にしたものが**ポリエステル繊維**です。

:::reaction
left: n HOOC−C₆H₄−COOH ＋ n HO−CH₂CH₂−OH
right: ［CO−C₆H₄−CO−O−CH₂CH₂−O］ₙ ＋ 2n H₂O
level: ★★★
note: 1つの繰り返し単位の中にエステル結合が2か所あるので、水は 2n 個とれます。ナイロン66 のアミド結合が、エステル結合に変わった形です。
:::

PET は**吸湿性をほとんど示さない**ので、洗ってもしわになりにくく、乾きが速い繊維になります。そのため、衣料品に広く使われています。

:::

:::section
anchor: acrylic
title: アクリル繊維
lead: アクリロニトリルの付加重合でできるポリアクリロニトリルが主成分です。やわらかく保温性があり、羊毛に似た風合いになります。
terms:

level: ★★★

:::section
anchor: vinylon
title: ビニロン
lead: 水に溶けるポリビニルアルコールの −OH の一部をホルムアルデヒドでつなぎ（アセタール化）、水に溶けないようにした繊維です。
terms:
- ビニロン
- アセタール化
:::

ビニロンは、酢酸ビニルから次の順につくります。

:::list
ordered: true
items:
- 酢酸ビニル CH₂=CH−OCOCH₃ を**付加重合**させて、ポリ酢酸ビニルにする
- ポリ酢酸ビニルを水酸化ナトリウム水溶液で**けん化**して、**ポリビニルアルコール（PVA）**にする。側鎖の −OCOCH₃ が −OH に変わり、炭素の主鎖はそのまま残る
- PVA の水溶液を細い穴から押し出して、繊維の形に固める（紡糸）
- 繊維にした PVA をホルムアルデヒドの水溶液で処理し、−OH の一部を**アセタール化**して**ビニロン**にする
:::

ポリビニルアルコール（PVA）は −OH を多くもつので、**水に溶けてしまい、そのままでは繊維になりません。**そこで、紡糸した PVA をホルムアルデヒドの水溶液で処理し、となりあう −OH 2個を −O−CH₂−O− の橋でつなぎます。これを**アセタール化**といい、できた繊維が**ビニロン**です。

**アセタール化するのは −OH の一部（30〜40% 程度）だけ**なので、−OH が残ります。そのため、ビニロンは合成繊維としてはめずらしく**吸湿性**があり、木綿に似た性質をもちます。**日本で開発された合成繊維**で、ロープや漁網、作業服などに使われます。

「**PVA は水に溶ける → −OH の一部をアセタール化 → 残った −OH で吸湿性**」の流れで覚えましょう。PVA までの2段（酢酸ビニルの付加重合とけん化）は、合成樹脂のページで扱います。

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: qa:org.poly.nylon66（計算の設定と数値はこのページで作問した）
prompt: ナイロン66 を 1.00 kg つくるのに必要なアジピン酸は何 g か。反応は完全に進むものとし、鎖の端の構造は無視してよい。原子量は H＝1.0、C＝12、N＝14、O＝16 とする。
answer: **約 646 g**。繰り返し単位 ［CO−(CH₂)₄−CO−NH−(CH₂)₆−NH］ は C₁₂H₂₂N₂O₂ で、式量は 226 です。1000 ÷ 226 ＝ 4.42 mol の繰り返し単位に、アジピン酸（分子量 146）も 4.42 mol 要るので、146 × 4.42 ＝ 646 g です。★ 単量体の合計 146 ＋ 116 ＝ 262 から、とれた水2個ぶんの 36 を引いて 226 になることを確かめると、式量の計算ミスが防げます。
:::

:::exercise
source: qa:org.poly.vinylon-acetal（数値はこのページで作問した）
prompt: ポリビニルアルコールの −OH のうち 40% をアセタール化して、ビニロンをつくった。ポリビニルアルコールの繰り返し単位 100 個あたり、反応したホルムアルデヒドは何分子か。
answer: **20分子**。−OH は 100 個あり、その 40% の 40 個が反応します。**ホルムアルデヒド1分子が −OH を2個ずつつなぐ**ので、40 ÷ 2 ＝ 20 分子です。
:::

answer: **縮合重合**：ナイロン66・ポリエチレンテレフタラート。**付加重合**：アクリル繊維・ビニロン（もとになる酢酸ビニルの重合が付加重合）。**開環重合**：ナイロン6。
