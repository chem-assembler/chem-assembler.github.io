化学反応で出入りするエネルギーは、熱だけではありません。このページでは、**光を吸収して進む反応**と、**光を出す反応**を扱います。エネルギーの高い状態を上、低い状態を下に描くエネルギー図の見方は、反応エンタルピーのページと同じです。

:::section
anchor: light
title: 光のエネルギー
lead: 光は波長によって紫外線・可視光線・赤外線に分かれます。波長が短いほど、光のエネルギーは大きくなります。
terms:
- 紫外線
- 可視光線
- 赤外線
:::

光は波長によって、**紫外線**（約 380nm より短い）・**可視光線**（約 380〜780nm）・**赤外線**（約 780nm より長い）に分かれます。可視光線の中では、紫が短く、赤が長い波長です。

**波長が短いほど、光のエネルギーは大きくなります。**紫外線が日焼けを起こすのに、赤外線は温めるだけなのは、紫外線のエネルギーのほうが大きいためです。

具体例1で、可視光線のエネルギーを 1mol あたりに直すと、赤い光で約 150kJ、紫の光で約 300kJ です。Cl−Cl の結合エンタルピー 243kJ/mol と同じくらいの大きさなので、**可視光線や紫外線を吸収すると、結合が切れることがあります。**

:::figure
src: light-energy-spectrum.png
svg: light-energy-spectrum.svg
alt: 横に伸びた帯。左が紫外線、中央が紫から赤へ変わる可視光線、右が赤外線で、境は 380 nm と 780 nm。帯の下に、右へ向かう「波長が長くなる」の矢印と、左へ向かう「エネルギーが大きくなる」の矢印がある

:::

:::section
anchor: absorb
title: 光を吸収して進む反応 —— 光化学反応
lead: 光を吸収することで起こる反応や、光で速くなる反応を光化学反応といいます。水素と塩素・臭化銀の感光・光合成・オゾンの生成が代表です。
terms:
- 光化学反応
- 光合成
- 感光性
:::

光を吸収することで起こる反応、光によって速くなる反応を**光化学反応**といいます。分子が光のエネルギーを受け取って、エネルギーの高い状態になるためです。

具体例2で、水素と塩素の混合気体は、暗い所ではほとんど反応しません。ところが強い光を当てると、爆発的に反応して塩化水素ができます。**塩素分子が光を吸収して塩素原子に分かれ**、それが反応の口火になるためです。

:::reaction
left: H₂ ＋ Cl₂
over: 光
right: 2HCl
level: ★★★
note: 暗所ではほとんど進まず、光を当てると爆発的に進みます。
:::

具体例3で、臭化銀 AgBr は光が当たると分解して、銀が析出します。このように光で変化する性質を**感光性**といい、写真のフィルムに使われてきました。

:::reaction
left: 2AgBr
over: 光
right: 2Ag ＋ Br₂
level: ★★★
note: 析出した銀の細かい粒が黒く見えます。塩化銀 AgCl も同じように光で分解します。
:::

:::link
to: copper-silver
text: 銀の化合物（ハロゲン化銀の沈殿と感光性）はこちら
:::

具体例4で、上空の酸素 O₂ は紫外線を吸収して酸素原子に分かれ、それが別の O₂ と結びついてオゾン O₃ ができます。

:::reaction
left: 3O₂
over: 紫外線
right: 2O₃
level: ★★☆
note: O₂ が2つの O 原子に分かれる段は吸熱で、常温では進みません。紫外線のエネルギーでこの段が進みます。
:::

**濃硝酸や硝酸銀の水溶液を褐色のびんに入れて保存する**のも、光で分解するのを防ぐためです。

具体例5で、緑色植物の**光合成**は、光のエネルギーを吸収して、エネルギーの低い CO₂ と H₂O から、エネルギーの高いグルコースなどの糖をつくる反応です。

:::reaction
left: 6CO₂(気) ＋ 6H₂O(液)
over: 光
right: C₆H₁₂O₆(固) ＋ 6O₂(気)　ΔH ＝ ＋2803 kJ
level: ★★★
note: 吸熱反応です。足りないエネルギーを光から受け取って、エネルギー図を上に登ります。
:::

:::mistake
wrong: 光合成は光を浴びて進むので、エネルギーを出す反応（発熱反応）である
right: 光合成は**吸熱反応**（ΔH ＝ ＋2803kJ）です。光のエネルギーを吸収して、エネルギーの低い CO₂ と H₂O から、エネルギーの高い糖をつくります。
why: 逆向きの反応（糖の燃焼・呼吸）が発熱反応なので、そちらと取り違えやすいのです。★ エネルギー図で、CO₂ ＋ H₂O が下、糖 ＋ O₂ が上にあることを描けば、光合成が上り坂だと分かります。
:::

:::section
anchor: emit
title: 光を出す反応 —— 化学発光
lead: 反応物と生成物のエネルギーの差（またはその一部）が光として出る現象を化学発光といいます。ルミノール反応が代表です。
terms:
- 化学発光
- ルミノール反応
:::

反応物と生成物のエネルギーの差、またはその一部が、熱ではなく光として出る現象を**化学発光**といいます。エネルギー図を下りるときに、下りた分を光として出す反応です。

**出てくる光の色は、エネルギーの差で決まります。**差が大きいほど波長の短い光（青・紫の側）、差が小さいほど波長の長い光（赤の側）になります。

具体例6で、**ルミノール**を塩基性の水溶液にし、過酸化水素 H₂O₂ を加えて酸化すると、青白い光を出します。この反応は鉄を含む物質が触媒になるので、血液の鉄（ヘモグロビン）で光ることを利用して、血痕を探すのに使われます。これを**ルミノール反応**といいます。

具体例7で、一酸化窒素 NO とオゾン O₃ が反応するときも光が出ます。この発光を測って、空気中のわずかな NO の濃度を調べる装置があります。

:::reaction
left: NO(気) ＋ O₃(気)
right: NO₂(気) ＋ O₂(気)　ΔH ＝ −199.8 kJ
level: ★☆☆
note: 下りたエネルギーの一部が、赤い側の光として出ます。
:::

折って光らせるケミカルライトや、ホタルの光も化学発光です。ホタルのように生物が起こす化学発光を、特に生物発光ということがあります。

:::table
caption: 光とかかわる反応
source: このページの本文の例を、「光を吸収するか、出すか」で並べ直したもの
head:
- 光とのかかわり
- 名前
- 例
align: left | left | left
rows:
- 光を吸収して進む | 光化学反応 | H₂ ＋ Cl₂ → 2HCl（爆発的）、2AgBr → 2Ag ＋ Br₂（感光性）、3O₂ → 2O₃（紫外線）
- 光を吸収して進む（吸熱） | 光合成 | 6CO₂ ＋ 6H₂O → C₆H₁₂O₆ ＋ 6O₂　ΔH ＝ ＋2803kJ
- 光を出す | 化学発光 | ルミノール ＋ H₂O₂（塩基性）、NO ＋ O₃、ケミカルライト、ホタル
:::

:::section
anchor: range
title: 覚える範囲
lead: 光化学反応と化学発光の意味、それぞれの代表例を覚えます。光のエネルギーを求める式は覚えなくてよいです。
:::

**「光化学反応 ＝ 光を吸収して進む反応」「化学発光 ＝ エネルギーの差が光として出る現象」の2つの意味と、上の表の例は必ず覚えてください。**とくに、**水素と塩素の爆発的な反応・臭化銀の感光性・光合成が吸熱反応であること・ルミノール反応**は、名前と一緒によく登場します。

**光子のエネルギーを求める式（E ＝ hν）や、波長の境目の正確な値は、覚える必要はありません。**「波長が短いほどエネルギーが大きい」の向きだけ押さえておけば十分です。

:::exercise
source: 自作（このページの表から作った問い）
prompt: 次の(ア)〜(オ)のうち、**光を吸収して進む反応**と、**化学発光**を、それぞれすべて選べ。(ア) 水素と塩素の混合気体に強い光を当てる　(イ) ルミノールの塩基性水溶液に過酸化水素水を加える　(ウ) 臭化銀に光を当てる　(エ) 緑色植物が CO₂ と H₂O からグルコースをつくる　(オ) 塩酸と水酸化ナトリウム水溶液を混ぜる
answer: **光を吸収して進む反応：(ア)・(ウ)・(エ)**、**化学発光：(イ)**。(オ) の中和は熱を出す発熱反応で、光とはかかわりません。
:::

:::exercise
source: 自作（hess-law の生成エンタルピーの計算を光合成に当てた問い。生成エンタルピーの値は教科書の表3と同じ丸め方）
prompt: CO₂（気）、H₂O（液）、C₆H₁₂O₆（固）の生成エンタルピーをそれぞれ −394kJ/mol、−286kJ/mol、−1273kJ/mol とする。**6CO₂(気) ＋ 6H₂O(液) → C₆H₁₂O₆(固) ＋ 6O₂(気) の ΔH は何 kJ か。また、この反応は発熱反応か、吸熱反応か。**
answer: **＋2807kJ、吸熱反応**。単体の組を 0 とすると、反応物の高さは 6×(−394) ＋ 6×(−286) ＝ −4080、生成物の高さは −1273 ＋ 0 ＝ −1273。ΔH ＝ −1273 −（−4080）＝ ＋2807kJ。正なので吸熱反応で、足りないエネルギーは光から受け取ります（値を丸めずに計算すると ＋2803kJ）。
:::
