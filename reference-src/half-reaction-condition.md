半反応式は、ふつうは酸性の水溶液で書いた形で覚えます。中性や塩基性の水溶液で反応するときは、**その液性で実際に存在するものを使って書き直す**必要があります。

:::link
to: half-reaction
text: 酸性で書いた半反応式の書き方と、主な酸化剤・還元剤は「半反応式の書き方」で
:::

:::section
anchor: why
title: なぜ書き換えるのか —— H⁺ と OH⁻ は共存しない
lead: 中・塩基性では H⁺ は存在せず、OH⁻ とくっついて H₂O として存在しています。
terms:
- 水のイオン積
- 液性
:::

**中・塩基性の水溶液中では H⁺ は存在せず、OH⁻ とくっついて H₂O として存在しています。**逆に、**中・酸性の水溶液中では OH⁻ は存在せず、H⁺ とくっついて H₂O として存在しています。**

これは、水のイオン積 Kw ＝ [H⁺][OH⁻] ＝ 1.0×10⁻¹⁴（mol/L）² がほぼ 0 だからです。[H⁺] と [OH⁻] のどちらか一方はほぼ 0 で、中性ならどちらも 1.0×10⁻⁷ mol/L でほぼ 0 です。

**「そこに存在しない物質は反応式の左辺には書けない」**ので、塩基性の水溶液で起こる反応の左辺に H⁺ を書くことはできません。

酸性の水溶液中で OH⁻ が生じても、すぐに H⁺ とくっついて H₂O になります（中和反応）。

:::link
to: neutralization
text: H⁺ と OH⁻ が結びついて水になる反応は「中和反応と量的関係」で
:::

:::section
anchor: method
title: 書き換えの手順 —— 両辺に OH⁻ を足して打ち消す
lead: H⁺ と同じ数の OH⁻ を両辺に足し、H⁺ ＋ OH⁻ を H₂O にまとめます。
terms:
- 書き換え
:::

酸性で書いた式を塩基性に直すときは、次の順に進めます。

:::list
ordered: true
items:
- 酸性で半反応式を書く。
- 式の中の H⁺ と同じ数の OH⁻ を、両辺に足す。
- H⁺ と OH⁻ を合わせて H₂O にする。
- 両辺に H₂O があれば、同じ数だけ消す。
:::

## 具体例 —— 電気分解の陰極

陰極で H₂ が発生する式は、酸性では 2H⁺ ＋ 2e⁻ → H₂ です。両辺に 2OH⁻ を足すと、左辺の 2H⁺ ＋ 2OH⁻ が 2H₂O になります。

:::reaction
left: 2H⁺ ＋ 2e⁻
right: H₂↑
level: ★★★
note: 酸性。陰極で H⁺ が e⁻ を受け取って H₂ が発生します。
:::

:::reaction
left: 2H₂O ＋ 2e⁻
right: H₂↑ ＋ 2OH⁻
level: ★★★
note: 中・塩基性。上の式の両辺に 2OH⁻ を足して導きます。
:::

:::figure
src: half-reaction-condition-app-cathode.png
shot: url=/ion-equation/condition.html?s=b1 sel=#step2 状態=「両辺に OH⁻ を足す」の ＋ を2回押して完成させてから撮った（ion v215・1200px 幅・deviceScaleFactor 1）
alt: 2H⁺ ＋ 2e⁻ → H₂ の両辺に 2OH⁻ を足し、H⁺ と OH⁻ が結びついて H₂O になって 2e⁻ ＋ 2H₂O → H₂ ＋ 2OH⁻ になる筆算と、H⁺ 2個と OH⁻ 2個が組になって H₂O 2個になる模式図
caption: 酸性の式にある H⁺ は2個なので、同じ数の OH⁻ を両辺に足すと、左辺の H⁺ はすべて H₂O になります。
:::

逆に、2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ の両辺に 2H⁺ を足せば、酸性の式に戻ります。**2つの反応式は本質的には同じ**です。

## 具体例 —— 電気分解の陽極

陽極で O₂ が発生する式も、同じ要領で互いに導けます。

:::reaction
left: 4OH⁻
right: 2H₂O ＋ O₂↑ ＋ 4e⁻
level: ★★★
note: 塩基性。陽極で OH⁻ が e⁻ を失って O₂ が発生します。
:::

:::reaction
left: 2H₂O
right: O₂↑ ＋ 4H⁺ ＋ 4e⁻
level: ★★★
note: 中・酸性。上の式の両辺に 4H⁺ を足すと、左辺が 4H₂O、右辺が 2H₂O ＋ O₂ ＋ 4e⁻ になるので、両辺の 2H₂O を消して導きます。
:::

:::figure
src: half-reaction-condition-water.png
alt: 陽極の2本（2H₂O → 4H⁺ ＋ O₂ ＋ 4e⁻ と 4OH⁻ → 2H₂O ＋ O₂ ＋ 4e⁻）と、陰極の2本（2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻ と 2H⁺ ＋ 2e⁻ → H₂）を上下に並べ、＋H⁺・＋OH⁻ の矢印で行き来できることを示した図
caption: 水関係の4本の式。**＋H⁺・＋OH⁻ で互いに行き来できます**。陽極は中・酸性なら H₂O が、塩基性なら OH⁻ が e⁻ を失って O₂。陰極は中・塩基性なら H₂O が、酸性なら H⁺ が e⁻ を受け取って H₂。
:::

:::section
anchor: shortcut
title: 楽な道 —— 陰極は H⁺ の式から、陽極は 2H₂O から直接
lead: 陰極の H₂O の式は H⁺ の式から導き、陽極の H₂O の式は 2H₂O → O₂ を直接つくるのが楽です。
terms:
- 水関係の反応式
:::

陰極の H₂O の式は、簡単に書ける H⁺ の式（金属の陽イオンと同じ要領）から導くのが楽です。

陽極は OH⁻ の式がつくりづらいので、**H₂O の式を直接つくります**。

:::list
ordered: true
items:
- 2H₂O を左辺に、O₂ を右辺に書く。
　2H₂O → O₂
- H⁺ で両辺の H 原子の数を合わせる。
　2H₂O → O₂ ＋ 4H⁺
- e⁻ で両辺の電荷を合わせる。
　2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻
:::

**電気分解の反応式に登場する H₂O の係数はすべて2**、**発生する気体 H₂・O₂ の係数は1**と覚えておきましょう。この2つを覚えていれば、水関係の4本はどれも素早く書けます。

:::mistake
wrong: 水の電気分解だから、2H₂O → 2H₂ ＋ O₂ と書けばよい
right: 電極ごとに**半反応式**で書きます。陰極は 2H₂O ＋ 2e⁻ → H₂ ＋ 2OH⁻、陽極は 2H₂O → O₂ ＋ 4H⁺ ＋ 4e⁻ です。
why: 書き方がわからないときに、**むやみに右辺に単体をつくらない**ことが大切です。単体は高エネルギーで不安定な物質なので、知識として生じることを知っている場合以外は右辺につくりません。逆に H₂O や CO₂ のような酸化物を右辺につくるのは問題ありません。
:::

## オゾン O₃

O₃ は極めて強い2価の酸化剤で、酸性では次の式ではたらきます。

:::reaction
left: O₃ ＋ 2H⁺ ＋ 2e⁻
right: O₂↑ ＋ H₂O
level: ★★☆
note: 酸性。酸化数が変化した O を含む物質は H₂O ですが、「O₃ は O₂ になる」と覚えると手順どおりに書けます。
:::

中・塩基性では、両辺に 2OH⁻ を足して書き換えます。**O₃ の半反応式は、中・塩基性のこの式を使います**。

:::reaction
left: O₃ ＋ H₂O ＋ 2e⁻
right: O₂↑ ＋ 2OH⁻
level: ★★☆
note: 中・塩基性。O₃ ＋ 2H⁺ ＋ 2OH⁻ ＋ 2e⁻ → O₂ ＋ H₂O ＋ 2OH⁻ の左辺の 2H⁺ ＋ 2OH⁻ を 2H₂O にまとめ、両辺の H₂O を1個ずつ消します。
:::

湿らせたヨウ化カリウムデンプン紙で O₃ を検出する反応は、**酸を加えていないので中・塩基性の式で組み立てます**（下の例題）。

## 過酸化水素 H₂O₂（酸化剤）

:::reaction
left: H₂O₂ ＋ 2e⁻
right: 2OH⁻
level: ★☆☆
note: 中・塩基性。酸性の H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O の両辺に 2OH⁻ を足し、両辺の 2H₂O を消して導きます。
:::

## 過マンガン酸イオン MnO₄⁻

MnO₄⁻ は、硫酸酸性では Mn²⁺ まで還元されますが、**中性や塩基性の水溶液中では MnO₂ までしか還元されません**。反応後の物質が変わるので、単なる書き換えではなく別の式として覚えます。

:::reaction
left: MnO₄⁻ ＋ 2H₂O ＋ 3e⁻
right: MnO₂ ＋ 4OH⁻
level: ★★☆
note: 中性・塩基性。黒褐色の MnO₂ が沈殿します。Mn の酸化数は ＋7 → ＋4 で、e⁻ は3個です。
:::

## アルカリ型燃料電池

燃料電池の電極の式も、同じ手で書き換えます。リン酸型（酸性）の式の H⁺ を、同じ数の OH⁻ で中和させるとアルカリ型の式になります。

:::table
caption: 燃料電池の電極の式（酸性と塩基性）

- アルカリ型（塩基性）

:::exercise
source: slides:無機の基本４「酸素と酸化物」s13・無機の基本５「ハロゲン」s5-6（復習(9)）
prompt: オゾンが、湿らせたヨウ化カリウムデンプン紙を青変させた。**この反応の化学反応式を書け。**
answer: **O₃ ＋ 2KI ＋ H₂O → I₂ ＋ 2KOH ＋ O₂** です。酸を加えていないので、O₃ は中・塩基性の式 O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ ではたらきます。還元剤の式 2I⁻ → I₂ ＋ 2e⁻ と足すと O₃ ＋ 2I⁻ ＋ H₂O → I₂ ＋ 2OH⁻ ＋ O₂。両辺に 2K⁺ を加えて KI と KOH に組みます。生じた I₂ がデンプンと反応して青〜青紫色になります。
:::

:::exercise
source: slides:電池の基本２「実用電池と燃料電池」s7-8

answer: **O₂ ＋ 2H₂O ＋ 4e⁻ → 4OH⁻** です。左辺の H⁺ の数だけ両辺に 4OH⁻ を足すと O₂ ＋ 4H₂O ＋ 4e⁻ → 2H₂O ＋ 4OH⁻ になり、両辺にある 2H₂O を消します。
:::
