気体の製法・捕集・乾燥は、気体を1つずつ覚えるより、**横に並べて規則を見る**ほうが楽に覚えられます。このページは、各物質のページに散っている気体を1枚に並べた早見表です。

製法の反応式は、ほとんどが「弱酸（弱塩基・揮発性の酸）の遊離」か「酸化還元」のどちらかの型です。型の見分け方は先に入口のページで確かめてください。

**色のついた気体は O₃（淡青色）・F₂（淡黄色）・Cl₂（黄緑色）・NO₂（赤褐色）の4つだけです。必ず覚えてください。**においは「H₂S が腐卵臭」を覚え、あとは「水に溶けて酸性か塩基性を示す気体は刺激臭」とまとめて覚えると楽です（CO₂ だけは無臭です）。

水溶液が塩基性を示す気体は **NH₃ ただ1つ**です。捕集法と乾燥剤の選び方で、NH₃ だけが例外になるのはこのためです。

:::section
anchor: heating
title: 加熱が要るかどうか
lead: 濃硫酸を使う反応と、固体どうしの反応は加熱が要ります。
:::

:::list
items:
- **濃硫酸が登場する反応は加熱が必要**（HCl・HF・SO₂（熱濃硫酸）・CO）
- **固体どうしの反応は加熱が必要**（NH₄Cl と Ca(OH)₂、KClO₃ と MnO₂）
- **MnO₂ と濃塩酸**は、例外として覚える（加熱が必要）
:::

MnO₂ と濃塩酸の反応は、本来は Cl₂ のほうが MnO₂ より酸化力が強いので逆向きに進みたい反応です。濃い塩酸を使い、加熱して発生した Cl₂ を追い出すことで、無理に進めています。

**この3つの規則を覚えれば、加熱の要否を個別に覚える必要はありません。**

:::section
anchor: collection
title: 捕集法の選び方
lead: 水に溶けにくい気体は水上置換、水に溶けて空気より重い気体は下方置換、水に溶けて空気より軽い気体は上方置換で集めます。
terms:
- 水上置換
- 下方置換
- 上方置換
:::

:::list
ordered: true
items:
- 水に溶けにくいか。溶けにくければ**水上置換**。
　H₂・O₂・N₂・CO・NO
- 水に溶けるなら、空気（平均分子量 28.8）より重いか軽いかを比べる。重ければ**下方置換**。
　Cl₂（71）・HCl（36.5）・H₂S（34）・SO₂（64）・NO₂（46）・CO₂（44）・HF
- 軽ければ**上方置換**。
　NH₃（17）だけ
:::

具体例: HCl は水によく溶けるので水上置換は使えません。分子量は 36.5 で空気の平均分子量 28.8 より大きいので、下方置換で集めます。

水上置換は空気が混じりにくく、発生した量も分かるので、使えるときは水上置換を選びます。**NO は水に溶けにくく、空気中の O₂ とすぐに反応して NO₂ になるので、必ず水上置換で集めます。**CO₂ は水に少し溶けるだけなので、水上置換で集めることもあります。

HF は分子量 20 で空気より軽いはずですが、分子どうしが水素結合で2〜5個つながって（会合して）いるので、空気より重い気体としてふるまい、下方置換で集めます。**上方置換は NH₃ だけ、と覚えてください。**

:::section
anchor: drying
title: 乾燥剤の選び方
lead: 乾燥剤は、乾燥したい気体と中和しないものを選びます。酸性の気体には酸性か中性の乾燥剤、塩基性の気体には塩基性か中性の乾燥剤です。
terms:
- 乾燥剤
- ソーダ石灰
:::

:::figure
src: gas-preparation-drying-agents.png
alt: 濃硫酸・十酸化四リン・シリカゲルは酸性、塩化カルシウムは中性、ソーダ石灰は塩基性の乾燥剤として、乾燥できる気体と例外を並べた表
caption: 乾燥剤の性質と、乾燥できる気体。例外は H₂S と濃硫酸、NH₃ と塩化カルシウムの2つです。ソーダ石灰は NaOH と CaO の混合物です。
:::

乾燥剤と気体が中和すると、気体が塩になって乾燥剤に吸収されてしまいます。だから、酸性の気体（HF・HCl・Cl₂・H₂S・SO₂・NO₂・CO₂）に塩基性の乾燥剤（ソーダ石灰）は使えず、塩基性の気体 NH₃ に酸性の乾燥剤（濃硫酸・十酸化四リン）は使えません。中性の気体（H₂・O₂・N₂・NO・CO）はどの乾燥剤でも構いません。

**例外は2つだけです。必ず覚えてください。**

:::list
items:
- **H₂S に濃硫酸は使えない**。H₂S は還元力が強く、濃硫酸と酸化還元反応を起こすためです。
- **NH₃ に塩化カルシウムは使えない**。CaCl₂ は中性の乾燥剤ですが、NH₃ と特異的に反応して CaCl₂・8NH₃ になるためです。
:::

NH₃ を乾燥できるのは、ソーダ石灰（または酸化カルシウム CaO）だけです。

シリカゲルは中性の乾燥剤に分類されることもありますが、酸性酸化物の SiO₂ でできていて、ごく弱い酸性をもちます。

:::section
anchor: washing
title: 洗気瓶で不純物を除く
lead: 発生させた気体に混じった不純物は、洗気瓶に通して除きます。塩素なら「水 → 濃硫酸」の順です。
terms:
- 洗気瓶
:::

MnO₂ と濃塩酸で発生させた Cl₂ には、塩酸から蒸発した HCl と H₂O が混じっています。まず水に通して HCl を溶かし取り、次に濃硫酸に通して H₂O を吸収させます。順番を逆にすると、水の洗気瓶で新たに蒸発した H₂O が残ってしまうので不適です。**「水 → 濃硫酸」の順は必ず覚えてください。**

lead: 色のある気体4つ、塩基性の気体は NH₃ だけ、加熱の規則3つ、捕集法の決め方、乾燥剤の例外2つを覚えます。

**必ず覚えるもの**は次のとおりです。

:::list
items:
- 色のある気体 O₃・F₂・Cl₂・NO₂ と、腐卵臭の H₂S
- 水溶液が塩基性の気体は NH₃ だけ
- 加熱が要るのは「濃硫酸」「固体どうし」「MnO₂ と濃塩酸」
- 捕集法の決め方（水に溶けるか → 空気より重いか）と、上方置換は NH₃ だけ
- 乾燥剤の例外（H₂S と濃硫酸、NH₃ と CaCl₂）
:::

製法の反応式のうち ★★★ のものは、試薬の名前から書けるようにしておきます。N₂ の製法（★☆☆）は、問題文に試薬が書かれていれば読み取れれば十分で、覚えなくても構いません。
