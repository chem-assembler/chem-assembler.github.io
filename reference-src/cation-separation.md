何種類かの金属イオンが混ざった水溶液から、試薬を順に加えて、1種類ずつ沈殿として分けていく操作を**金属イオンの系統分離**といいます。

使うのは、沈殿のページで見た「どの陰イオンが、どの陽イオンと沈殿をつくるか」の知識だけです。**新しく覚えるのは、試薬を加える順番と、その順番である理由**です。

text: 陰イオンごとの沈殿と色のページへ
:::

:::section
anchor: procedure
title: 分離の手順 —— 試薬を加える順番
lead: 希塩酸 → 硫化水素（酸性）→ 煮沸・希硝酸・アンモニア水 → 硫化水素（塩基性）→ 炭酸アンモニウム → 炎色反応、の順です。
terms:
- 系統分離
- ろ過
- ろ液
:::

Ag⁺・Cu²⁺・Fe³⁺・Zn²⁺・Ca²⁺・Na⁺ を含む水溶液を例に、手順を見ていきます。各操作のあとは**ろ過して沈殿とろ液に分け、ろ液に次の試薬を加えます。**

**この6段の順番は必ず覚えてください。**段ごとに加える試薬が決めている陰イオン（Cl⁻ → 酸性の S²⁻ → OH⁻ → 塩基性の S²⁻ → CO₃²⁻）の順で覚えると、沈殿の知識とつながります。

参考書によっては、各段で沈むイオンのまとまりを「第1属」〜「第6属」と呼びます。呼び名は覚えなくても構いません。

:::section
anchor: why-order
title: なぜこの順番なのか
lead: 沈殿をつくる相手が少ない試薬から先に使い、前の段の試薬が次の段をじゃましないように片付けてから進みます。
terms:
- 煮沸
- 希硝酸
- 塩化アンモニウム
:::

順番には、1段ずつ理由があります。

:::list
ordered: true
items:
- **希塩酸が最初。**Cl⁻ で沈むのは Ag⁺ と Pb²⁺ だけなので、ほかを巻き込まずに取り出せる。さらに、溶液が酸性になって次の段の準備になる。
- **硫化水素は、まず酸性で通す。**酸性では S²⁻ がごくわずかなので、CuS のようなとても溶けにくい硫化物だけが沈む。ZnS・FeS はここでは沈まない。
- **煮沸して硫化水素を追い出し、希硝酸を加える。**段2で Fe³⁺ は硫化水素に還元されて Fe²⁺ になっているので、希硝酸で Fe³⁺ にもどす。そのあと塩化アンモニウムとアンモニア水を加えると、Fe³⁺ と Al³⁺ が水酸化物として沈む。Zn²⁺ は過剰のアンモニアで [Zn(NH₃)₄]²⁺ になって溶けたまま残る。
- **塩基性で、もう一度硫化水素を通す。**こんどは S²⁻ が多いので、ZnS が沈む。
- **炭酸アンモニウムを加える。**CO₃²⁻ で Ca²⁺・Ba²⁺ が沈む。
- **最後に残るのは Na⁺・K⁺。**どの試薬とも沈殿しないので、炎色反応で確かめる。
:::

段2と段3で起こる、鉄のイオンの酸化数の変化は次のとおりです。

:::reaction
left: 2Fe³⁺ ＋ H₂S
right: 2Fe²⁺ ＋ S ＋ 2H⁺
level: ★★☆
note: 段2。硫化水素が還元剤としてはたらき、硫黄の淡黄色の濁りが出ます。鉄はろ液に残ります。
:::

:::reaction
left: Fe³⁺ ＋ 3OH⁻
right: FeO(OH)↓ ＋ H₂O
level: ★★★
note: 段3。赤褐色の沈殿。古い本では Fe(OH)₃ と書かれます。
:::

塩化アンモニウムを先に加えるのは、**NH₄⁺ を多くして、アンモニアの電離をおさえ、OH⁻ を少なめに保つ**ためです。こうすると、FeO(OH)・Al(OH)₃ のように溶けにくい水酸化物だけが沈み、Zn²⁺ などは沈まずに次の段へ進みます。

//要確認: 化学新研究2015・総合的研究化学 段3で塩化アンモニウムを加える理由の書き方（OH⁻ を少なく保つ／Zn²⁺ を錯イオンのまま残す／Mg(OH)₂ を沈ませない、のどれを挙げているか）

:::mistake
wrong: 煮沸と希硝酸は、なくても結果は変わらない
right: 希硝酸を加えないと、鉄は Fe²⁺ のまま段3を素通りし、段4で **FeS として ZnS と一緒に沈みます。**鉄と亜鉛が分けられず、鉄の沈殿は空になります。
why: 段2で Fe³⁺ が Fe²⁺ に変わっていることが、見た目では分かりにくいためです。★ Fe(OH)₂ は FeO(OH) ほど沈みやすくないので、OH⁻ を少なめにした段3では沈みません。煮沸は、残った硫化水素が希硝酸で酸化されたり、段3で硫化物を沈めたりしないように追い出す操作です。
:::

:::mistake
wrong: 硫化水素は1回通せば、硫化物は全部まとめて取り出せる
right: 酸性で通す（段2）と、塩基性で通す（段4）の**2回に分けます。**塩基性で先に通すと、CuS と ZnS・FeS がまとめて沈んでしまいます。
why: 硫化物は液性で沈むものが変わるので、液性を変えて2回通すことで、2つのまとまりに分けられるためです。
:::

rows:
- 1 | AgCl・PbCl₂ | 熱水を注ぐ | PbCl₂ だけが溶ける（ろ液に K₂CrO₄ で黄色の PbCrO₄）。AgCl はアンモニア水に溶ける
- 3 | FeO(OH)・Al(OH)₃ | 過剰の NaOH 水溶液を加える | 両性の Al(OH)₃ だけが [Al(OH)₄]⁻ になって溶ける
- 5 | CaCO₃・BaCO₃ | 希酢酸に溶かし、クロム酸カリウム水溶液を加える | 黄色の BaCrO₄ だけが沈む。Ca²⁺ は炎色反応（橙赤）で確かめる
:::

**段1の AgCl と PbCl₂ を熱水で分けるのは、必ず覚えてください。**段3・段5の分け方は、余裕があれば覚えましょう。どれも、沈殿のページと両性金属のページで見た性質をそのまま使っています。

:::section
anchor: range
title: 覚える範囲
lead: 6段の順番と、それぞれの理由（とくに酸性と塩基性の硫化水素・煮沸と希硝酸）です。
:::

**次の3つは必ず覚えてください。**

:::list
items:
- 試薬の順番: 希塩酸 → 硫化水素（酸性）→ 煮沸・希硝酸・NH₄Cl と NH₃ 水 → 硫化水素（塩基性）→ 炭酸アンモニウム → 炎色反応
- 硫化水素を酸性と塩基性の2回に分ける理由（液性で沈む硫化物が変わる）
- 希硝酸を加える理由（段2で Fe²⁺ になった鉄を Fe³⁺ にもどす）
:::

「第○属」の呼び名と、段5の Ca と Ba の分け方は、覚えなくても構いません。

## 例題

:::exercise
source: 自作（2種類のイオンを分ける試薬を選ぶ。muki の型Bと同じ「見分ける操作を1つ選ぶ」問い）
prompt: 次の2種類の金属イオンを含む水溶液から、一方だけを沈殿させて分けたい。加える試薬と、沈殿の化学式を答えよ。**(1) Pb²⁺ と Zn²⁺　(2) Cu²⁺ と Zn²⁺　(3) Fe³⁺ と Zn²⁺　(4) Ca²⁺ と Na⁺**
answer: (1) 希塩酸（PbCl₂）　(2) 酸性にして硫化水素（CuS）　(3) 過剰のアンモニア水（FeO(OH)。Zn²⁺ は [Zn(NH₃)₄]²⁺ になって溶ける）　(4) 炭酸アンモニウム水溶液（CaCO₃）
:::

:::exercise
source: 自作（手順の理由を問う。muki:tree-model.js の「煮沸＋希硝酸を飛ばすと鉄と亜鉛が混ざる」の筋）
prompt: Ag⁺・Cu²⁺・Fe³⁺・Zn²⁺ を含む水溶液の系統分離で、硫化水素で CuS を沈殿させたあとのろ液を、煮沸も希硝酸も加えずに、そのままアンモニア水で塩基性にした。どのような不都合が起こるか。
answer: ろ液に硫化水素が残っているので、塩基性になった時点で ZnS と FeS が沈み、水酸化物の沈殿に混ざります。また、鉄は段2で Fe²⁺ に還元されたままなので、FeO(OH) として取り出すこともできません。
:::

:::exercise
source: 自作（段1の沈殿を分ける操作）
prompt: 希塩酸を加えて生じた白色沈殿が AgCl か PbCl₂ かを確かめるには、どうすればよいか。2通り答えよ。
answer: (1) 熱水を注ぐ。溶ければ PbCl₂、溶けなければ AgCl。(2) アンモニア水を加える。溶ければ AgCl（[Ag(NH₃)₂]⁺ になる）、溶けなければ PbCl₂。
:::
