**アミノ基 −NH₂** がベンゼン環に直接結合した化合物を**芳香族アミン**といいます。代表が**アニリン C₆H₅NH₂** で、ニトロベンゼンからつくり、染料の原料になります。

:::section
anchor: aniline
title: アニリンの性質
lead: 無色の油状の液体で、空気中で酸化されて褐色になります。水溶液は弱い塩基性です。
terms:
- 芳香族アミン
- アミノ基
- アニリン
:::

アニリンは、**特有のにおいをもつ無色の油状の液体**です。水に溶けにくく、有毒です。**空気中に置いておくと酸化されて、しだいに褐色になります**。古い試薬びんのアニリンが茶色く見えるのは、このためです。

:::figure
src: aniline-aniline.png
gen: name=アニリン plain
alt: アニリンの構造式。ベンゼン環の炭素1個にアミノ基が直接結合している
caption: **アニリン C₆H₅NH₂**。アミノ基 −NH₂ が環に直接付いています。
:::

:::example
stageId: aniline
lead: アニリンを組んで、−NH₂ が環に直接付いていることを手で確かめます。
note: 窒素は手が3本なので、環との結合1本と H 2個でちょうど埋まります。
:::

:::section
anchor: base
title: 弱い塩基性
lead: アニリンは塩酸と中和して塩になり、水に溶けるようになります。アンモニアより弱い塩基です。
terms:
- 弱塩基
- アニリン塩酸塩
:::

アニリンは**弱い塩基**で、塩酸と中和して**アニリン塩酸塩**になります。塩になると**水によく溶けます**。

:::reaction
left: C₆H₅NH₂ ＋ HCl
right: C₆H₅NH₃Cl
level: ★★★
note: アニリン塩酸塩ができます。水に溶けにくいアニリンも、塩酸には溶けます。
:::

アニリン塩酸塩の水溶液に強塩基の水酸化ナトリウムを加えると、弱塩基のアニリンが**遊離**します。

:::reaction
left: C₆H₅NH₃Cl ＋ NaOH
right: C₆H₅NH₂ ＋ NaCl ＋ H₂O
level: ★★★
note: 強い塩基が、塩から弱い塩基を追い出します。弱酸の遊離と同じ形です。
:::

**「塩酸で塩になって水に溶け、NaOH で戻る」の2本は必ず書けるようにしてください。**分離の問題でそのまま使います。アニリンの塩基性はアンモニアより弱いのですが、その理由までは覚えなくて構いません。

:::section
anchor: prep
title: ニトロベンゼンを還元してつくる
lead: スズと塩酸で還元すると、まずアニリン塩酸塩ができます。NaOH を加えて初めてアニリンが得られます。
terms:
- 還元
- スズ
:::

アニリンは、**ニトロベンゼンをスズ（または鉄）と塩酸で還元**してつくります。塩酸の中で還元するので、できるのはアニリンではなく**アニリン塩酸塩**です。

:::reaction
left: 2C₆H₅NO₂ ＋ 3Sn ＋ 14HCl
right: 2C₆H₅NH₃Cl ＋ 3SnCl₄ ＋ 4H₂O
level: ★★☆
note: ①還元してアニリン塩酸塩にします。
:::

:::reaction
left: C₆H₅NH₃Cl ＋ NaOH
right: C₆H₅NH₂ ＋ NaCl ＋ H₂O
level: ★★★
note: ②NaOH 水溶液を加えてアニリンを遊離させます。
:::

**還元の式の係数は覚えなくて構いませんが、「還元してできるのはアニリン塩酸塩で、NaOH を加えてアニリンにする」という2段の流れは必ず覚えてください。**

:::mistake
wrong: ニトロベンゼンをスズと塩酸で還元すると、そのままアニリンが得られる。
right: スズと塩酸で還元するとアニリン塩酸塩ができ、そこに NaOH 水溶液を加えて初めてアニリンが遊離する。
why: 還元は塩酸の中で行うので、塩基のアニリンは塩酸と中和して塩のまま残ります。
:::

:::section
anchor: detect
title: アニリンを見分ける
lead: さらし粉水溶液で赤紫色に呈色します。二クロム酸カリウムで酸化すると黒色のアニリンブラックになります。
terms:
- さらし粉
- アニリンブラック
:::

アニリンの水溶液に**さらし粉水溶液**を加えると、**赤紫色**に呈色します。**「アニリンはさらし粉で赤紫」と覚えましょう。**アニリンの検出によく使われます。

また、アニリンを硫酸酸性の**二クロム酸カリウム**で酸化すると、**黒色の物質（アニリンブラック）**ができます。アニリンブラックは黒色の染料に使われます。

:::figure
src: aniline-detect.png
svg: aniline-detect.svg
alt: アニリンの水溶液を入れた試験管2本の模式図。左はさらし粉水溶液を加えて赤紫色になり、右は硫酸酸性の二クロム酸カリウム水溶液を加えて黒色になっている
caption: 左はアニリンの検出に使う反応、右は黒色の染料をつくる反応です。**「さらし粉で赤紫」「二クロム酸カリウムで黒」を対にして**覚えましょう。
:::

:::section
anchor: acetyl
title: アセチル化してアセトアニリドにする
lead: 無水酢酸と反応させると、アミノ基がアセチル化されてアミド結合をもつアセトアニリドになります。
terms:
- アセチル化
- アセトアニリド
- アミド結合
:::

アニリンに**無水酢酸**を作用させると、アミノ基の H がアセチル基 −COCH₃ に置き換わって、**アセトアニリド**の白色の結晶ができます。

:::reaction
left: C₆H₅NH₂ ＋ (CH₃CO)₂O
right: C₆H₅NHCOCH₃ ＋ CH₃COOH
level: ★★★
note: アセトアニリドができます。−NH−CO− の結合を**アミド結合**といいます。
:::

同じ無水酢酸で、サリチル酸の −OH もアセチル化されてアセチルサリチル酸になります。**試薬は同じで、反応する基がアミノ基か −OH かの違いです。**

:::link
to: aromatic-carboxylic-acid
text: 同じ無水酢酸でサリチル酸をアセチル化する
:::

:::section
anchor: diazo
title: ジアゾ化 —— 5℃以下で行う
lead: アニリンを塩酸に溶かし、冷やしながら亜硝酸ナトリウムを加えると、塩化ベンゼンジアゾニウムができます。温めると分解します。
terms:
- ジアゾ化
- 塩化ベンゼンジアゾニウム
- 亜硝酸ナトリウム
:::

アニリンの塩酸溶液を**氷で 5℃以下に冷やしながら**、亜硝酸ナトリウム NaNO₂ 水溶液を加えると、**塩化ベンゼンジアゾニウム**ができます。この反応を**ジアゾ化**といいます。

:::reaction
left: C₆H₅NH₂ ＋ 2HCl ＋ NaNO₂
over: 5℃以下
right: C₆H₅N₂Cl ＋ NaCl ＋ 2H₂O
level: ★★★
note: 塩化ベンゼンジアゾニウムができます。「5℃以下に冷やす」がそのまま問われる条件です。
:::

塩化ベンゼンジアゾニウムは不安定で、**温度が上がると水と反応して分解**し、窒素を出してフェノールになります。

:::reaction
left: C₆H₅N₂Cl ＋ H₂O
over: 加熱
right: C₆H₅OH ＋ N₂↑ ＋ HCl
level: ★★★
note: フェノールと窒素ができます。ジアゾ化を冷やして行うのは、この分解を起こさないためです。
:::

**「ジアゾ化は 5℃以下、温めるとフェノールと窒素に分解する」を対にして覚えてください。**

:::section
anchor: coupling
title: カップリングとアゾ染料
lead: 塩化ベンゼンジアゾニウムにナトリウムフェノキシドを加えると、橙赤色の p-ヒドロキシアゾベンゼンができます。
terms:
- カップリング
- アゾ基
- アゾ化合物
- アゾ染料
- p-ヒドロキシアゾベンゼン
:::

塩化ベンゼンジアゾニウムの水溶液に**ナトリウムフェノキシド**の水溶液を加えると、**橙赤色の p-ヒドロキシアゾベンゼン**ができます。このように、ジアゾニウム塩から**アゾ基 −N=N−** をもつ化合物をつくる反応を**カップリング**といいます。

:::reaction
left: C₆H₅N₂Cl ＋ C₆H₅ONa
right: C₆H₅−N=N−C₆H₄−OH ＋ NaCl
level: ★★★
note: p-ヒドロキシアゾベンゼン（p-フェニルアゾフェノール）ができます。フェノールの −OH から見て p の位置で結びつきます。
:::

:::figure
src: aniline-hydroxyazobenzene.png
gen: name=p-ヒドロキシアゾベンゼン（p-フェニルアゾフェノール） plain
alt: p-ヒドロキシアゾベンゼンの構造式。2個のベンゼン環が −N=N− でつながり、片方の環の向かい側の炭素にヒドロキシ基が結合している
caption: **p-ヒドロキシアゾベンゼン**。2個の環を**アゾ基 −N=N−** がつないでいます。
:::

アゾ基をもつ化合物を**アゾ化合物**といいます。アゾ化合物の多くは黄色〜赤色の色をもち、**アゾ染料**として使われます。
