合成高分子のうち、加熱して成形して使うものを**合成樹脂（プラスチック）**といいます。合成樹脂は、**鎖状か網目か**で性質がはっきり2つに分かれます。

:::section
anchor: two-kinds
title: 熱可塑性樹脂と熱硬化性樹脂
lead: 鎖状の樹脂は加熱するとやわらかくなり、網目の樹脂は加熱すると硬くなって二度とやわらかくなりません。
terms:
- 熱可塑性樹脂
- 熱硬化性樹脂
- 鎖状構造
- 立体網目構造
:::

長い鎖が1本ずつ独立している**鎖状構造**の樹脂は、加熱するとやわらかくなり、冷やすと再び固まります。これを**熱可塑性樹脂**といいます。鎖どうしは分子間力で引き合っているだけなので、温めると鎖がずれ動けるようになるためです。

鎖と鎖が共有結合で橋かけされ、全体が1つの巨大な分子になった**立体網目構造**の樹脂は、加熱すると硬化し、再び加熱してもやわらかくなりません。これを**熱硬化性樹脂**といいます。鎖どうしが共有結合で固定されていて、温めてもずれ動けないためです。

:::table
caption: 熱可塑性樹脂と熱硬化性樹脂
source: qa:org.poly.thermoplastic-thermoset の対比に、このページの各節で扱う樹脂を割り振ったもの
head:
- 比べる点
- 熱可塑性樹脂
- 熱硬化性樹脂
align: left | left | left
rows:
- 構造 | 鎖状（1本ずつ独立） | 立体網目（全体がつながっている）
- 加熱すると | やわらかくなる（冷やすと固まる） | 硬化する（再加熱しても軟化しない）
- 成形し直せるか | できる | できない
- つくり方 | 付加重合・縮合重合 | 付加縮合・3価以上の単量体の縮合重合
- 例 | ポリエチレン・ポリ塩化ビニル・PET | フェノール樹脂・尿素樹脂・メラミン樹脂・アルキド樹脂
:::

「**鎖状は熱可塑性、網目は熱硬化性**」と覚えましょう。どの樹脂がどちらかは、この合言葉と、各節の「網目になるかどうか」で決まります。

:::section
anchor: polyethylene
title: ポリエチレン
lead: エチレンの付加重合でできます。つくり方で枝分かれの数が変わり、やわらかい低密度と、硬い高密度の2種類になります。
terms:
- ポリエチレン
- 低密度ポリエチレン
- 高密度ポリエチレン
:::

エチレンを付加重合させると**ポリエチレン**ができます。

:::reaction
left: n CH₂=CH₂
right: ［CH₂−CH₂］ₙ
level: ★★★
note: 同じ式でも、つくり方で枝分かれの数が変わり、別の性質の材料になります。
:::

高い圧力で重合させると、枝分かれの多い**低密度ポリエチレン**になります。触媒を使って低い圧力で重合させると、枝分かれの少ない**高密度ポリエチレン**になります。**枝分かれが少ないと鎖がそろって並びやすく、結晶部分が多くなるので、硬く不透明になるためです。**

:::section
anchor: pva
title: ポリ酢酸ビニルとポリビニルアルコール
lead: ビニルアルコールは単量体として使えないので、酢酸ビニルを重合させてからけん化して、ポリビニルアルコールをつくります。
terms:
- ポリ酢酸ビニル
- ポリビニルアルコール

:::

酢酸ビニルを付加重合させると**ポリ酢酸ビニル**ができます。

:::reaction
left: n CH₂=CH−OCOCH₃
right: ［CH₂−CH(OCOCH₃)］ₙ
level: ★★★
note: X ＝ −OCOCH₃ のビニル化合物です。
:::

ポリ酢酸ビニルを水酸化ナトリウム水溶液で**けん化**すると、エステル結合が切れて **ポリビニルアルコール（PVA）** になります。

:::reaction
left: ［CH₂−CH(OCOCH₃)］ₙ ＋ n NaOH
right: ［CH₂−CH(OH)］ₙ ＋ n CH₃COONa
level: ★★★
note: 繰り返し単位ごとにエステル結合が1つあるので、NaOH も n 個要ります。酢酸ナトリウムが出ていき、−OH が残ります。
:::

src: plastic-pva.png

:::section
anchor: pmma-teflon
title: ポリメタクリル酸メチルとテフロン
lead: ポリメタクリル酸メチルは透明で有機ガラスに、テフロンは薬品や熱に強く摩擦が小さいので、フライパンの表面加工などに使われます。
terms:
- ポリメタクリル酸メチル
- テフロン
:::

メタクリル酸メチルを付加重合させると、**ポリメタクリル酸メチル（PMMA）**ができます。**透明度が高いので、有機ガラスとして水槽や風防に使われます。**

:::reaction
left: n CH₂=C(CH₃)COOCH₃
right: ［CH₂−C(CH₃)(COOCH₃)］ₙ
level: ★★☆
note: 1つの炭素に −CH₃ と −COOCH₃ の2つがぶら下がっています。側鎖がかさばって鎖が規則正しく並べず、光を散らす結晶部分ができにくいので透明になります。
:::

テトラフルオロエチレン CF₂=CF₂ を付加重合させると、**ポリテトラフルオロエチレン（テフロン）**ができます。**薬品にも熱にも強く、表面がすべりやすい**ので、フライパンの表面加工などに使われます。

:::reaction
left: n CF₂=CF₂
right: ［CF₂−CF₂］ₙ
level: ★★☆
note: エチレンの H が4つとも F に置きかわった形です。C−F 結合がとても強いので、薬品に侵されにくくなります。
:::

:::figure
src: plastic-teflon-chain.png
svg: plastic-teflon-chain.svg
alt: 炭素6個が一列につながり、それぞれの炭素の上下にフッ素原子が1個ずつ付いた鎖の構造式

「PMMA は有機ガラス」「テフロンは F を含み、薬品・熱に強い」の2点で十分でしょう。

:::section
anchor: network
title: 橋かけで網目にする
lead: 鎖と鎖を共有結合でつなぐことを橋かけ（架橋）といいます。橋が十分にかかると、全体が1つの巨大な分子になります。
terms:
- 橋かけ
- 架橋
:::

鎖と鎖のあいだを共有結合でつなぐことを**橋かけ（架橋）**といいます。**橋かけが十分に進むと、樹脂全体が1つの巨大な分子になり、立体網目構造**になります。

網目をつくるには、1つの単量体が**3か所以上で結合できる**ことが要ります。2か所だけなら、何個つながっても一本の鎖のままだからです。この「3か所以上」の実例が、次の節から出てくるフェノール・尿素・メラミン・グリセリンです。

ゴムに硫黄を加えて鎖どうしをつなぐ加硫も、同じ橋かけの操作です。

:::section
anchor: phenol-resin
title: フェノール樹脂
lead: フェノールとホルムアルデヒドが付加と縮合をくり返す付加縮合でつながり、立体網目構造の熱硬化性樹脂になります。
terms:
- フェノール樹脂
- 付加縮合
:::

フェノールとホルムアルデヒドを、酸または塩基を触媒として加熱すると、**付加と縮合をくり返す付加縮合**が起こります。こうしてできる立体網目構造の樹脂が**フェノール樹脂**です。

まず1か所つながったところを見ます。ホルムアルデヒドが、フェノールのベンゼン環に −CH₂− の橋をかけ、水が1個とれます。

:::reaction
left: 2 C₆H₅OH ＋ HCHO
right: HO−C₆H₄−CH₂−C₆H₄−OH ＋ H₂O
level: ★★☆
note: この −CH₂− の橋が、ベンゼン環の残りの位置（−OH から見てオルト位とパラ位の3か所）にも次々にかかって網目になります。
:::

:::figure
src: plastic-phenol-network.png
svg: plastic-phenol-network.svg
alt: OH の付いたベンゼン環を5個並べ、環どうしを CH2 と書いた橋でつないだ模式図。中央の環は3方向に橋が出ていて、外側の環からは橋が図の外へ続いている
caption: 橋はどれも **−CH₂−** で、1つの環から最大3方向へ出ます。実際はこれが立体に広がった網目です。
:::

フェノールは1分子で**3か所**（オルト位2つとパラ位1つ）に橋を受けられるので、網目になります。電気を通しにくく熱に強いので、電気部品や配線基板に使われます。

**フェノール樹脂の構造式そのものは書けなくて構いません。**「フェノール ＋ ホルムアルデヒド」「付加縮合」「熱硬化性」の3語の組み合わせで足ります。

## ノボラックとレゾール（発展）

酸を触媒にすると、網目になる前の鎖状の中間体**ノボラック**ができ、これに硬化剤を加えて加熱すると網目になります。塩基を触媒にすると、別の中間体**レゾール**ができ、これは加熱するだけで網目になります。

:::section
anchor: amino-alkyd
title: 尿素樹脂・メラミン樹脂・アルキド樹脂
lead: 尿素樹脂とメラミン樹脂は、相手がどちらもホルムアルデヒドの付加縮合です。アルキド樹脂は無水フタル酸とグリセリンの縮合重合です。
terms:
- 尿素樹脂
- メラミン樹脂
- アルキド樹脂
:::

尿素とホルムアルデヒドから**尿素樹脂**が、メラミンとホルムアルデヒドから**メラミン樹脂**ができます。どちらもフェノール樹脂と同じ**付加縮合**で、−NH₂ の H が −CH₂− の橋に置きかわりながら網目になります。

:::reaction
left: 2 CO(NH₂)₂ ＋ HCHO
right: H₂N−CO−NH−CH₂−NH−CO−NH₂ ＋ H₂O
level: ★☆☆
note: 尿素2分子が −CH₂− の橋でつながったところです。尿素1分子には H を出せる −NH₂ が2つ（H は4個）あるので、橋が何か所にもかかって網目になります。
:::

無水フタル酸とグリセリンを縮合重合させると、エステル結合でつながった**アルキド樹脂**ができます。**グリセリンは −OH を3個もつので、鎖が枝分かれして網目になります。**2価のアルコールどうしなら、PET のように鎖のままです。

:::table
caption: 熱硬化性樹脂
source: qa:org.poly.phenol-resin / org.poly.urea-melamine-alkyd の原料と樹脂の対応。原料の登録は compounds.json の urea・phthalic-anhydride・glycerol。できる結合と重合の型は原料の官能基から
head:
- 樹脂
- 原料
- 重合の型
- 橋・結合
- 用途
align: left | left | left | left | left
rows:
- フェノール樹脂 | フェノール ＋ ホルムアルデヒド | 付加縮合 | −CH₂− の橋 | 電気部品・配線基板
- 尿素樹脂 | 尿素 ＋ ホルムアルデヒド | 付加縮合 | −CH₂− の橋 | ボタン・電気器具
- メラミン樹脂 | メラミン ＋ ホルムアルデヒド | 付加縮合 | −CH₂− の橋 | 食器・化粧板
- アルキド樹脂 | 無水フタル酸 ＋ グリセリン | 縮合重合 | エステル結合 | 塗料
:::

**4つの樹脂の名前と原料の組み合わせは必ず暗記してください。**「ホルムアルデヒドを使う3つは付加縮合、アルキド樹脂だけはグリセリンで網目になる縮合重合」と分けると覚えやすくなります。構造式は書けなくて構いません。

:::mistake
wrong: 縮合重合でできた樹脂は、どれも熱可塑性樹脂である
right: 縮合重合でも、**3価以上の単量体（グリセリンなど）を使うと網目になり、熱硬化性樹脂**になります。アルキド樹脂がその例です。
why: 縮合重合の代表例が鎖状の PET やナイロン66 なので、「縮合重合＝鎖状」と結び付けてしまうためです。★ 網目になるかどうかは重合の型ではなく、**単量体が何か所で結合できるか**で決まります。
:::

:::section
anchor: superabsorbent
title: 高吸水性樹脂
lead: ポリアクリル酸ナトリウムを橋かけして網目にしたもので、自分の重さの数百倍の水を吸ってゲルになります。
terms:
- 高吸水性樹脂
- ポリアクリル酸ナトリウム
:::

アクリル酸ナトリウムを重合させた**ポリアクリル酸ナトリウム**を、少しだけ橋かけして網目にしたものが**高吸水性樹脂**です。**自分の重さの数百〜千倍の水を吸収してゲルになり、少し押しても水を放しません。**紙おむつや、土の保水材に使われます。

:::reaction
left: n CH₂=CH−COONa
right: ［CH₂−CH(COONa)］ₙ
level: ★★☆
note: これを橋かけして網目にしたものが高吸水性樹脂です。
:::

水を吸うと、−COONa が電離して網目に **−COO⁻** が並びます。**−COO⁻ どうしが反発して網目が広がり、網目の内側のイオンの濃度が外より高くなるので、水が浸透して入り込むためです。**網目なので、鎖がばらばらに溶け出すこともありません。

:::figure
src: plastic-superabsorbent.png
svg: plastic-superabsorbent.svg
alt: 左に目のつまった網目、右に目の広がった網目を描いた図。左には -COONa、右には -COO- と書いてあり、右では2つの -COO- のあいだに反発を表す矢印があって、網目の中に水を表す点がたくさん入っている
caption: 網目の中に **−COO⁻** が並び、たがいに反発して広がります。広がった網目が水をかかえこみます。
:::

「網目」「−COO⁻」「紙おむつ」の3語を押さえておけば十分でしょう。

:::section
anchor: ion-exchange
title: イオン交換樹脂
lead: スチレンとジビニルベンゼンの共重合体に酸性や塩基性の基を付けた網目の樹脂で、溶液中のイオンを H⁺ や OH⁻ と交換します。
terms:
- イオン交換樹脂
- 陽イオン交換樹脂
- 陰イオン交換樹脂
- ジビニルベンゼン
:::

スチレンに少量の**ジビニルベンゼン**を混ぜて共重合させると、ジビニルベンゼンが鎖どうしの橋になって網目ができます。このベンゼン環にスルホ基 **−SO₃H** を付けたものが**陽イオン交換樹脂**、トリメチルアンモニウム基 **−N⁺(CH₃)₃** などの塩基性の基を付けたものが**陰イオン交換樹脂**です。

:::figure
src: plastic-ion-exchange-resin.png
svg: plastic-ion-exchange-resin.svg
alt: 上下に2本のポリスチレンの鎖を描き、それぞれからベンゼン環がぶら下がって -SO3H が付いている模式図。中央では1つの環が上下の鎖の両方に結合していて、ジビニルベンゼンによる橋かけと書かれている
caption: 鎖は**ジビニルベンゼンの橋**でつながっているので溶け出しません。交換にはたらくのは環に付いた **−SO₃H** です。
:::

陽イオン交換樹脂に塩化ナトリウム水溶液を通すと、**溶液中の Na⁺ が樹脂の H⁺ と入れかわり**、流れ出てくる液は塩酸になります。樹脂の本体を R と書きます。

:::reaction
left: R−SO₃H ＋ Na⁺
right: R−SO₃Na ＋ H⁺
level: ★★★
note: 入っていった Na⁺ の代わりに、同じ電荷ぶんの H⁺ が出てきます。
:::

:::reaction
left: 2 R−SO₃H ＋ Ca²⁺
right: (R−SO₃)₂Ca ＋ 2 H⁺
level: ★★☆
note: 2価の陽イオンなら、樹脂の −SO₃H 2個ぶんと交換し、H⁺ が2個出てきます。
:::

陰イオン交換樹脂は、**溶液中の陰イオンを樹脂の OH⁻ と入れかえます。**

:::reaction
left: R−N(CH₃)₃OH ＋ Cl⁻
right: R−N(CH₃)₃Cl ＋ OH⁻
level: ★★☆
note: 入っていった Cl⁻ の代わりに OH⁻ が出てきます。
:::

使い終わった樹脂は、陽イオン交換樹脂なら**濃い塩酸**、陰イオン交換樹脂なら**濃い水酸化ナトリウム水溶液**を流すと、上の反応が逆に進んでもとに戻ります（**再生**）。

用途は次の3つです。

:::list
items:
- **純水の製造**：陽イオン交換樹脂と陰イオン交換樹脂を続けて通すと、出てきた H⁺ と OH⁻ が中和して水になり、イオンをほとんど含まない水が得られます。
- **硬水の軟化**：Ca²⁺ や Mg²⁺ を樹脂に吸着させて取り除きます。家庭用の軟水器では、H⁺ の代わりに Na⁺ を付けた樹脂を使い、Ca²⁺ を Na⁺ と交換します。
- **アミノ酸の分離**：pH によってアミノ酸の電荷が変わるので、樹脂への吸着のしやすさの違いで分けられます。
:::

:::figure
src: plastic-ion-exchange-column.png
svg: plastic-ion-exchange-column.svg
alt: 上が漏斗状に広がったガラス管に、樹脂の粒がぎっしり詰まっている装置の絵。上から塩化ナトリウム水溶液を流し込み、下のコックから出てきた液をビーカーで受けている
caption: 上から流した水溶液が粒のあいだを通るあいだに、**Na⁺ が樹脂につかまり H⁺ が押し出されます**。受けた液は塩酸です。
:::

**イオン交換樹脂は、構造（スチレン－ジビニルベンゼンに −SO₃H）と交換の反応式を書けるようにしましょう。**計算問題は「入った陽イオンの電荷の合計 ＝ 出てきた H⁺ の物質量」の1本で解けます。

:::section

title: 生分解性高分子とリサイクル
lead: 微生物に分解される高分子を生分解性高分子といい、代表はポリ乳酸です。使い終わった樹脂は、溶かして成形し直すか、分解して原料に戻します。

- 生分解性高分子

- ケミカルリサイクル

微生物のはたらきで、最終的に二酸化炭素と水にまで分解される高分子を**生分解性高分子**といいます。代表が**ポリ乳酸**です。

:::reaction
left: n CH₃CH(OH)COOH
right: ［O−CH(CH₃)−CO］ₙ ＋ n H₂O
level: ★★☆
note: 乳酸は1分子に −OH と −COOH をもつので、1種類だけで縮合重合できます。実際の製造では、乳酸2分子の環状エステル（ラクチド）をつくってから開環重合させます。
:::

使い終わったプラスチックの行き先は、次の3つに分けられます。

:::table
caption: 使い終わったプラスチックの行き先
source: qa:org.poly.biodegradable-recycle のリサイクルの2種に、熱として回収する方法を並べた。ケミカルリサイクルの例は polymer-basics の PET の縮合重合の逆反応から
head:
- 名前
- やること
- 例
align: left | left | left
rows:
- マテリアルリサイクル | 溶かして成形し直す | PET ボトル → 繊維・シート
- ケミカルリサイクル | 化学反応で分解して、原料や単量体に戻す | PET → テレフタル酸 ＋ エチレングリコール
- サーマルリサイクル | 燃やして熱エネルギーとして使う | ごみ発電
:::

**ケミカルリサイクルで PET を単量体に戻す反応は、縮合重合の逆 ＝ 加水分解です。**また、**熱硬化性樹脂は加熱してもやわらかくならないので、マテリアルリサイクルができません。**

「マテリアルは形を変える、ケミカルは分子を変える」と覚えましょう。

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: qa:org.poly.vinyl-monomers / org.poly.pet（問いの形はこのページで作問した）
prompt: 次の重合体の単量体を、示性式で書け。(1) ［CH₂−CH(C₆H₅)］ₙ　(2) ［CH₂−CH(OCOCH₃)］ₙ　(3) ［CO−C₆H₄−CO−O−CH₂CH₂−O］ₙ
answer: (1) **スチレン** CH₂=CHC₆H₅。(2) **酢酸ビニル** CH₂=CHOCOCH₃。この2つは付加重合なので、繰り返し単位の C−C を C=C に戻すだけです。(3) **テレフタル酸** HOOC−C₆H₄−COOH と**エチレングリコール** HOCH₂CH₂OH の2つ。縮合重合なので、エステル結合を切り、切り口に −OH と −H を補って戻します。
:::

:::exercise
source: qa:org.poly.ion-exchange（数値はこのページで作問した）
prompt: 0.10 mol/L の塩化カルシウム水溶液 10 mL を、十分な量の陽イオン交換樹脂（H⁺ 形）を詰めたカラムに通し、純水で洗って流出液をすべて集めた。この流出液を中和するのに必要な 0.10 mol/L 水酸化ナトリウム水溶液は何 mL か。
answer: **20 mL**。Ca²⁺ は 0.10 × 10/1000 ＝ 1.0×10⁻³ mol 入ります。2価なので、出てくる H⁺ はその2倍の 2.0×10⁻³ mol です。0.10 mol/L の NaOH なら 2.0×10⁻³ ÷ 0.10 ＝ 0.020 L ＝ 20 mL になります。★ 「入った陽イオンの電荷の合計 ＝ 出てきた H⁺ の物質量」で考えます。
:::

:::exercise
source: qa:org.poly.thermoplastic-thermoset（問いの形はこのページで作問した）
prompt: 次のうち、熱硬化性樹脂をすべて選べ。ポリスチレン、メラミン樹脂、ポリエチレンテレフタラート、フェノール樹脂、アルキド樹脂、ポリ塩化ビニル
answer: **メラミン樹脂・フェノール樹脂・アルキド樹脂**の3つです。見分け方は「立体網目構造かどうか」の一点で、**ホルムアルデヒドと付加縮合するもの**と、**グリセリンのような3価以上の単量体を使うもの**が網目になります。
:::
