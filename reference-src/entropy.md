化学反応の熱は、反応エンタルピーのページで ΔH で表しました。発熱反応では物質のエンタルピーが下がり、エネルギーの低い安定な状態に移ります。では、**エンタルピーが上がる吸熱の変化は、なぜ自然に起こるのでしょうか。**このページでは、反応が自然に進む向きを決める2つ目の傾向、**エントロピー**を扱います。

:::section
anchor: endothermic
title: 吸熱なのに自然に進む変化
lead: 物質はエンタルピーが下がる向き（発熱の向き）に変化しやすい一方で、吸熱なのに自然に進む変化もあります。ΔH の符号だけでは、変化の向きは決まりません。
terms:
- 自発的な変化
:::

外から何もしなくても自然に進む変化を、**自発的な変化**といいます。

多くの自発的な変化は発熱です。燃焼や中和は、エンタルピーの高い反応物から低い生成物へ下がる変化で、下がった分が熱として出ていきます。

ところが、**吸熱なのに自然に進む変化**も身のまわりにたくさんあります。

:::list
items:
- 具体例1で、室温に置いた氷は、周りから熱を受け取ってとけます。H₂O の融解エンタルピーは ＋6.0kJ/mol で、吸熱です。
- 具体例2で、硝酸アンモニウム NH₄NO₃ や硝酸カリウム KNO₃ は、水に入れると熱を吸収しながら溶けます。溶けたあとの水溶液は冷たくなります。
- 具体例3で、コップに入れた水は、周りから熱を受け取って少しずつ蒸発します。蒸発エンタルピーは ＋44kJ/mol です。
:::

:::reaction
left: NH₄NO₃(固) ＋ aq
right: NH₄NO₃ aq　ΔH ＝ ＋26 kJ
level: ★★☆
note: 吸熱なのに、水に入れるだけで溶けていきます。冷却パックはこの吸熱を使っています。
:::

どれも、物質のエンタルピーは**上がって**います。エンタルピーが下がる向きだけが変化を進めるなら、これらは起こらないはずです。**エンタルピーとは別に、変化を進めるもう1つの傾向がある**ということです。

:::mistake
wrong: 自然に進む変化は、すべて発熱の変化である
right: 氷の融解や硝酸アンモニウムの溶解のように、**吸熱なのに自然に進む変化**があります。
why: 変化の向きを決めるのは、エンタルピーが下がる傾向だけではないためです。もう1つの傾向（乱雑さが大きくなる傾向）が吸熱の不利を上回れば、吸熱の変化も自然に進みます。
:::

:::section
anchor: entropy
title: エントロピー —— 乱雑さの大きさ
lead: 粒子の散らばり具合（乱雑さ）の大きさを表す量をエントロピー（記号 S）といいます。物質は、エントロピーが大きくなる向きに変化しようとします。固体 → 液体 → 気体の順にエントロピーは大きくなります。
terms:
- エントロピー
- 乱雑さ
- エントロピー変化
:::

物質をつくる粒子は、熱運動をしています。粒子がどれだけばらばらに散らばっているか、つまり**乱雑さの大きさを表す量**を、**エントロピー**（記号 S）といいます。変化の前後のエントロピーの差を**エントロピー変化**（記号 ΔS）といい、**乱雑さが大きくなる変化では ΔS が正、小さくなる変化では ΔS が負**です。

自然界には、**乱雑さが大きくなる向きに変化しようとする傾向**があります。インクを水にたらすと、かき混ぜなくても全体に広がっていきます。広がったインクが、ひとりでに1か所に集まることはありません。

三態で比べると、エントロピーは**固体 ＜ 液体 ＜ 気体**の順に大きくなります。

:::

変化の前とくらべて、粒子がより散らばるならエントロピーは増え、より集まって並ぶなら減ります。よく出る変化を、増える側と減る側に分けて並べます。

:::table
caption: エントロピーが増える変化・減る変化
source: 教科書（R5化学Vol.1-2編 1章1節 E、第一学習社化学R4 Ⅱ-1-⑤）の記述をもとに、状態変化・混合と溶解・反応の3つの行に分けて並べ直したもの
head:
- 変化の種類
- エントロピーが増える（ΔS ＞ 0）
- エントロピーが減る（ΔS ＜ 0）
align: left | left | left
rows:
- 状態変化 | 融解（固体 → 液体）・蒸発（液体 → 気体）・昇華（固体 → 気体） | 凝固（液体 → 固体）・凝縮（気体 → 液体）
- 混合と溶解 | 気体どうしの拡散・液体どうしの混合・固体が水に溶ける | 気体が水に溶ける・水溶液から沈殿ができる
- 反応 | 気体の分子の数が増える反応（2H₂O₂(液) → 2H₂O(液) ＋ O₂(気)） | 気体の分子の数が減る反応（N₂ ＋ 3H₂ → 2NH₃）
:::

**反応では、まず気体の分子の数を数えます。**気体は液体や固体よりずっと乱雑さが大きいので、気体が増える反応は ΔS が正、気体が減る反応は ΔS が負と見てよいです。N₂ ＋ 3H₂ → 2NH₃ なら、気体が 4 個から 2 個に減るので ΔS は負です。

**「固体が水に溶けるとエントロピーが増える」と覚えましょう。**硝酸アンモニウム・硝酸カリウム・砂糖など、高校で扱う例はどれもこれで考えられます。

:::heading
title: 溶けてもエントロピーがほとんど増えない固体
advanced: true
:::

固体が溶けると粒子が散らばるので、エントロピーはふつう増えます。ただし、溶けたイオンのまわりには水分子が強く引きつけられて並ぶ（水和）ので、そのぶん水の側の乱雑さは減ります。水和の強いイオンでは、この2つがほぼ打ち消し合います。

たとえば水酸化ナトリウムは、標準状態のエントロピーの値（1 mol/kg の水溶液が基準）で比べると、溶けたときの ΔS はわずかに負になります。教科書によっては水酸化ナトリウムの溶解を「乱雑さが大きくなる」例に挙げていますが、多量の水に溶かすほど散らばるぶんが大きくなるので、条件しだいで符号が変わる、きわどい例です。

:::section
anchor: two-tendencies
title: 自然に進む向きを決める2つの傾向
lead: 変化は「エンタルピーが下がる（発熱）」と「エントロピーが増える」の2つの傾向で進みます。2つがそろえば必ず進み、2つとも逆なら進まず、引っぱり合うときは影響の大きいほうが勝ちます。
:::

変化を進める傾向は、次の2つです。

:::list
ordered: true
items:
- **エンタルピーが下がる向き**（ΔH ＜ 0、発熱）
- **エントロピーが増える向き**（ΔS ＞ 0、乱雑さが増す）
:::

2つの向きの組み合わせは4通りです。**2つがそろえば自然に進み、2つとも逆なら自然には進みません。**向きが食い違うときは、影響の大きいほうの向きに進みます。

:::table
caption: ΔH と ΔS の向きの組み合わせと、変化が自然に進むか
source: 教科書（第一学習社化学R4 Ⅱ-1-⑤）の組み合わせを、「そろう／逆／引っぱり合い」の順に並べ直し、例をこのページの具体例に差しかえたもの
head:
- エンタルピー
- エントロピー
- 自然に進むか
- 例
align: left | left | left | left
rows:
- 下がる（発熱） | 増える | どの温度でも進む | 過酸化水素の分解 2H₂O₂(液) → 2H₂O(液) ＋ O₂(気)　ΔH ＝ −196 kJ
- 上がる（吸熱） | 減る | どの温度でも進まない | 酸素からオゾン 3O₂ → 2O₃　ΔH ＝ ＋285 kJ
- 下がる（発熱） | 減る | 低い温度ほど進みやすい | 水の凝固・水蒸気の凝縮、N₂ ＋ 3H₂ → 2NH₃　ΔH ＝ −92 kJ
- 上がる（吸熱） | 増える | 高い温度ほど進みやすい | 氷の融解・水の蒸発、NH₄NO₃ や KNO₃ の溶解
:::

酸素からオゾンができる変化は、吸熱で、しかも気体の分子が 3 個から 2 個に減ります。どちらの傾向も逆向きなので、酸素を置いておくだけではオゾンはできません。**紫外線や放電でエネルギーを与えて、はじめて進みます。**

## 温度が高いほど、エントロピーの影響が大きい

向きが食い違うときの勝ち負けは、温度で変わります。**温度が高いほど、エントロピーの影響が大きくなります。**

具体例4で、大気圧のもとで氷がとける変化は、吸熱（エンタルピーの面では不利）で、乱雑さが増す（エントロピーの面では有利）変化です。

:::list
items:
- 0℃ より高い温度では、エントロピーの影響が勝ち、**氷がとけます**。
- 0℃ より低い温度では、エンタルピーの影響が勝ち、逆向きの**水が凍る**変化が進みます。
- ちょうど 0℃ では2つがつり合い、氷と水が共存します。
:::

石灰石（炭酸カルシウム）CaCO₃ を強く熱すると、酸化カルシウムと二酸化炭素に分解します。この分解は吸熱ですが、気体の CO₂ ができてエントロピーが増えるので、**温度を高くするとエントロピーの影響が勝って**進むようになります。

:::reaction
left: CaCO₃(固)
right: CaO(固) ＋ CO₂(気)　ΔH ＝ ＋178 kJ
level: ★☆☆
note: 吸熱で、気体ができてエントロピーが増える組み合わせ。室温では進まず、強く熱すると進みます。
:::

## 自然に進む向きと、進む速さは別

2つの傾向が決めるのは、**変化が自然に進む向き**だけです。**どれだけ速く進むかは、別の話**です。

:::mistake
wrong: 自然に進む向きの反応なら、物質を混ぜればすぐに反応が進む
right: 水素と酸素から水ができる反応は、発熱で自然に進む向きの反応ですが、**室温で混ぜただけではほとんど反応しません。**点火すると一気に進みます。
why: 反応が進むには、活性化エネルギーの山を越える必要があるためです。向き（どちらへ進むか）はエンタルピーとエントロピーで決まり、速さ（どれだけ速く進むか）は活性化エネルギーと温度・触媒で決まります。過酸化水素の分解も、どの温度でも進む向きですが、酸化マンガン(IV) MnO₂ を加えないとゆっくりにしか進みません。
:::

:::section
anchor: gibbs
title: ギブズエネルギー —— 2つの傾向を1つの式にまとめる
advanced: true
lead: エンタルピーとエントロピーの2つの傾向は、ギブズエネルギー変化 ΔG ＝ ΔH − TΔS の1つの式にまとめられます。ΔG が負なら自然に進み、正なら自然には進みません。
terms:
- ギブズエネルギー
:::

2つの傾向を1つの量にまとめたものを、**ギブズエネルギー変化**（記号 ΔG）といいます。式は **ΔG ＝ ΔH − TΔS** で、T は絶対温度です。

**ΔG が負なら、その変化は自然に進みます。正なら自然には進みません。0 なら2つの傾向がつり合っています。**

ΔS に T がかかっているのが、「温度が高いほどエントロピーの影響が大きい」の正体です。T が大きいほど、−TΔS の項が ΔG を大きく動かします。

⚠ **単位をそろえます。**ΔH はふつう kJ、ΔS は J/K で与えられます。ΔS を 1000 で割って kJ/K に直してから T をかけます。

具体例5で、氷の融解がつり合う温度を求めます。H₂O 1mol あたり ΔH ＝ ＋6.0kJ、ΔS ＝ ＋22J/K ＝ ＋0.022kJ/K とします。つり合うのは ΔG ＝ 0 のときなので、

**0 ＝ 6.0kJ − T × 0.022kJ/K**　より　**T ＝ 6.0 ／ 0.022 ≒ 273K** です。

//式: T ＝ ΔH ／ ΔS は、第2周で縦の分数の器ができたら組み直す

273K は 0℃ です。これより高い温度では TΔS が ΔH より大きくなって ΔG が負になり、氷がとけます。低い温度では ΔG が正になり、とけずに逆向き（水が凍る）が進みます。

**ギブズエネルギーの式は覚える必要はありません。**入試で使うときは、式と意味が問題文で説明されます。ΔH と TΔS の大小で符号が決まる、という読み方ができれば十分です。

:::section
anchor: range
title: 覚える範囲
lead: 「エントロピー＝乱雑さ」「固体 ＜ 液体 ＜ 気体」「2つの傾向」の3つを覚えます。計算はほとんど問われません。
:::

**「エントロピーは乱雑さの大きさ」「エントロピーは固体 ＜ 液体 ＜ 気体」「変化は、エンタルピーが下がる向きとエントロピーが増える向きの2つに進もうとする」の3つは必ず覚えてください。**吸熱なのに自然に進む変化を見たら、「エントロピーの増大が勝った」と説明できるようにしましょう。

変化ごとの ΔS の正負は、上の表を丸暗記してもよいですが、**「粒子が散らばるか、集まって並ぶか」「気体の分子が増えるか、減るか」**の2つで考えれば、ほとんどの変化は判断できます。

エントロピーの値（J/(K·mol)）や ΔS の計算は、高校ではほとんど問われないので**覚える必要はありません。**

answer: (1) **どの温度でも自然に進む**。発熱で、気体の O₂ ができてエントロピーも増えるので、2つの傾向がそろっています。　(2) **どの温度でも自然には進まない**。吸熱で、気体が 3 個 → 2 個に減るのでエントロピーも減り、2つの傾向がどちらも逆向きです。　(3) **温度によって決まる・高温で進みやすい**。吸熱ですが、気体の CO₂ ができてエントロピーが増えます。温度が高いほどエントロピーの影響が大きくなるので、強く熱すると進みます。
