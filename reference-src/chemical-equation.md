物質量のページでは、粒子の数を mol で数えました。化学反応では、原子どうしの結びつきが組み換わるだけで、**原子そのものは増えも減りもしません**。このページでは、その「原子の数の保存」を式に書き表す化学反応式のつくり方を扱います。係数が正しく書ければ、次のページで反応の量が計算できます。

:::section
anchor: rules
title: 化学反応式の書き方 —— 約束は3つ
lead: 反応前の物質を左、反応後の物質を右に置いて矢印でつなぎ、どの原子も左右で同じ個数になるよう係数で調整します。反応しても変わらずに残る物質は書きません。
terms:
- 化学反応式
- 反応物
- 生成物
- 係数
:::

どの物質がどれだけ反応して、何ができるか。それを化学式だけで書き表したものが**化学反応式**（反応式）です。反応に使われる側の物質を**反応物**、反応でできる側の物質を**生成物**とよびます。書き方の約束は3つだけです。

:::list
ordered: true
items:
- 反応物の化学式を左辺、生成物の化学式を右辺に書き、→ で結ぶ。
- 左辺と右辺で、どの原子も同じ個数になるように、化学式の前に**係数**を置く。係数はこれ以上割れない整数の組にそろえ、1 は書かない。
- 反応の前後で変化しない物質（溶媒の水・触媒）は式に書かない。
:::

具体例1で、メタン CH₄ の燃焼を見ます。

:::reaction
left: CH₄ ＋ 2O₂
right: CO₂ ＋ 2H₂O
level: ★★★
note: 左辺は C 1・H 4・O 4、右辺も C 1・H 4・O 4。原子の種類と数が両辺でそろっています。
:::

触媒は式に書かない代わりに、→ の上に書き添えることがあります（例：過酸化水素の分解の MnO₂）。

:::reaction
left: 2H₂O₂
over: MnO₂
right: 2H₂O ＋ O₂
level: ★★★
note: MnO₂ は触媒なので、反応の前後で変化しません。左辺にも右辺にも書かず、矢印の上に添えています。
:::

:::mistake
wrong: H₂O ＋ O₂ → H₂O₂ の O の数を合わせるために、右辺を H₂O₃ に書き換える
right: 数を合わせるときに変えてよいのは**係数だけ**です。化学式の右下の小さな数字（H₂O の 2 など）を変えると、別の物質になってしまいます。
why: 係数と化学式の中の数字が、どちらも「原子の数」を表しているように見えるためです。★ 化学式は物質の名札、係数はその物質の個数、と分けて考えましょう。
:::

:::section
anchor: inspection
title: 目算法 —— いちばん複雑な物質を 1 とおく
lead: いちばん複雑な物質の係数を 1 とおき、1か所にしか出てこない原子から順に合わせます。O と H は最後に回し、分数が出たら最後に全体を整数倍します。
terms:
- 目算法
:::

ほとんどの反応式は、次の順に係数を決めれば、試行錯誤なしで書けます。この方法を**目算法**といいます。

:::list
ordered: true
items:
- 原子の種類と数がいちばん多い物質の係数を 1 とおく。
- その物質に含まれる原子のうち、**ほかに1か所にしか出てこない原子**から合わせる。燃焼なら C → H の順。
- **単体（O₂ など）の係数は最後**に決める。単体の係数はほかに影響しないので、分数になってもよい。
- 分数が出たら、全体を何倍かして分母をはらう。
:::

具体例2で、プロパン C₃H₈ の燃焼の係数を決めます。

:::table
caption: プロパンの燃焼 C₃H₈ ＋ ○O₂ → ○CO₂ ＋ ○H₂O（1段ずつ原子の数をそろえる）
source: このページのために作った
head:
- 手順
- 決めた係数
- C（左 : 右）
- H（左 : 右）
- O（左 : 右）
align: left | left | left | left | left
rows:
- 1. C₃H₈ を 1 とおく | C₃H₈ 1 | 3 : ? | 8 : ? | ? : ?
- 2. C を合わせる | CO₂ 3 | 3 : 3 | 8 : ? | ? : 6 ＋ ?
- 2. H を合わせる | H₂O 4 | 3 : 3 | 8 : 8 | ? : 6 ＋ 4 ＝ 10
- 3. O₂ を最後に | O₂ 5 | 3 : 3 | 8 : 8 | 10 : 10
:::

:::reaction
left: C₃H₈ ＋ 5O₂
right: 3CO₂ ＋ 4H₂O
level: ★★★
note: 目算法で、C₃H₈ → CO₂ → H₂O → O₂ の順に決めた係数です。
:::

具体例3で、ブタン C₄H₁₀ の燃焼を見ます。係数に分数が出る例です。

:::list
ordered: true
items:
- C₄H₁₀ を 1 とおく。C が 4 なので CO₂ は 4、H が 10 なので H₂O は 5。
- 右辺の O は 4 × 2 ＋ 5 ＝ 13。O₂ の係数は 13/2。
- 全体を2倍して分母をはらう。
:::

:::reaction
left: 2C₄H₁₀ ＋ 13O₂
right: 8CO₂ ＋ 10H₂O
level: ★★☆
note: 途中で O₂ の係数が 13/2 になったので、全体を2倍しました。
:::

★ 炭化水素 CₘHₙ の燃焼は、いつも同じ型です。**「C の数だけ CO₂、H の数の半分だけ H₂O、最後に O₂」**と覚えておけば、どの燃焼の式も目算法で1分以内に書けます。

　CₘHₙ ＋ ○○O₂ → m CO₂ ＋ n/2 H₂O

:::section
anchor: undetermined
title: 未定係数法 —— 目算法で詰まったとき
lead: 係数を文字でおき、原子ごとに「左辺の数 ＝ 右辺の数」の式を立て、連立方程式を解きます。どの原子も複数の物質に出てくる反応で使います。
terms:
- 未定係数法
:::

どの原子も2か所以上に出てくる反応では、目算法の「1か所にしか出てこない原子から」が使えません。そのときは、係数を a・b・c … とおいて、原子ごとに等式を立てます。これを**未定係数法**といいます。

具体例4で、銅と希硝酸の反応（生成物は硝酸銅(Ⅱ)・一酸化窒素・水）を考えます。

a Cu ＋ b HNO₃ → c Cu(NO₃)₂ ＋ d NO ＋ e H₂O

:::list
ordered: true
items:
- 原子ごとに等式を立てる。
　Cu：a ＝ c　H：b ＝ 2e　N：b ＝ 2c ＋ d　O：3b ＝ 6c ＋ d ＋ e
- どれか1つを 1 とおく。a ＝ c ＝ 1 とすると、N の式から d ＝ b − 2、H の式から e ＝ b/2。
- O の式に入れる。3b ＝ 6 ＋ (b − 2) ＋ b/2 より b ＝ 8/3。すると d ＝ 2/3、e ＝ 4/3。
- 全体を3倍して、a : b : c : d : e ＝ 3 : 8 : 3 : 2 : 4。
:::

:::reaction
left: 3Cu ＋ 8HNO₃
right: 3Cu(NO₃)₂ ＋ 2NO ＋ 4H₂O
level: ★★☆
note: 未定係数法で求めた係数です。Cu 3・H 8・N 8・O 24 が両辺でそろっています。
:::

★ この反応は酸化還元反応です。**酸化還元の式は、半反応式を組み合わせる方がずっと速く書けます。**未定係数法は「どんな式でも最後は必ず解ける」安全網として知っておけば十分です。

:::

:::section
anchor: ionic
title: イオンを含む反応式 —— 電荷もそろえる
lead: 反応に関係したイオンだけを書いたイオン反応式では、原子の数に加えて、両辺の電荷の合計も等しくします。
terms:
- イオン反応式
:::

硝酸銀水溶液と食塩水を混ぜると、白い塩化銀 AgCl が沈殿します。このとき実際に反応しているのは Ag⁺ と Cl⁻ だけで、Na⁺ と NO₃⁻ は水溶液中にイオンのまま残っています。反応したイオンだけで書いた式を**イオン反応式**といいます。

:::reaction
left: Ag⁺ ＋ Cl⁻
right: AgCl
level: ★★★
note: 左辺の電荷は ＋1 と −1 で合計 0、右辺も 0。原子の数と電荷の両方がそろっています。
:::

イオン反応式では、**原子の数に加えて電荷の合計も両辺でそろえる**のが4つめの約束です。どのイオンが反応に関係するかの見分け方は、イオン反応式を組み立てるアプリで練習できます。

text: 沈殿のできる反応を、イオンを組み合わせて書いてみよう
:::

:::section
anchor: range
title: 覚える範囲
lead: 書き方の3つの約束と目算法の手順は、どの反応にも使うので身につけます。個々の反応式そのものは、無機・有機の各ページで覚えます。
:::

**「変えてよいのは係数だけ」「いちばん複雑な物質を 1 とおき、単体は最後」の2つは必ず覚えてください。**炭化水素の燃焼の式は、何も見ずに書けるようにしましょう。

未定係数法は、目算法や半反応式で書けないときの最後の手段です。**計算が長くなるので、試験で使うことはほとんどありません。**解き方を知っていれば十分です。

どの物質とどの物質が反応して何ができるか（反応物と生成物）は、このページでは覚えません。それは無機・有機の各ページで、反応ごとに覚える範囲を示しています。

## 例題

:::exercise
source: このページのために作った（このページの目算法の練習）
prompt: エタノール C₂H₆O が完全燃焼して、二酸化炭素と水ができる反応を化学反応式で表せ。
answer: C₂H₆O ＋ 3O₂ → 2CO₂ ＋ 3H₂O。C₂H₆O を 1 とおくと、C から CO₂ は 2、H から H₂O は 3。右辺の O は 2 × 2 ＋ 3 ＝ 7 で、左辺はエタノールに O が1個あるので、O₂ から 6 個 ＝ O₂ の係数 3。
:::

:::exercise
source: このページのために作った（このページの目算法の練習・分数をはらう）
prompt: アルミニウムの粉末を酸素の中で燃やすと、酸化アルミニウム Al₂O₃ ができる。この変化を化学反応式で書け。
answer: 4Al ＋ 3O₂ → 2Al₂O₃。Al₂O₃ を 1 とおくと、Al は 2。O は右辺 3 個なので O₂ は 3/2。全体を2倍して分母をはらいます。
:::

:::exercise
source: このページのために作った（このページの未定係数法の練習）
prompt: 銅と濃硝酸が反応して、硝酸銅(Ⅱ)・二酸化窒素 NO₂・水ができる反応を化学反応式で表せ。
answer: Cu ＋ 4HNO₃ → Cu(NO₃)₂ ＋ 2NO₂ ＋ 2H₂O。a Cu ＋ b HNO₃ → c Cu(NO₃)₂ ＋ d NO₂ ＋ e H₂O とおくと、Cu：a ＝ c、H：b ＝ 2e、N：b ＝ 2c ＋ d、O：3b ＝ 6c ＋ 2d ＋ e。a ＝ c ＝ 1 とすると d ＝ b − 2、e ＝ b/2 で、3b ＝ 6 ＋ 2(b − 2) ＋ b/2 より b ＝ 4、d ＝ 2、e ＝ 2。
:::
