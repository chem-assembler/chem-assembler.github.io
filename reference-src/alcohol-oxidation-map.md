アルコールを硫酸酸性条件の過マンガン酸カリウム KMnO₄ や二クロム酸カリウムで酸化すると、アルコールの級によって異なる反応を起こします。

:::figure
src: alcohol-class.png
alt: アルコールの級の図。ヒドロキシ基が付いた炭素を丸で囲み、その炭素に結合している炭素が1個なら1級、2個なら2級、3個なら3級と示している
caption: 数えるのは、丸で囲んだ炭素に**ほかの炭素がいくつ結合しているか**だけです。
:::

「ヒドロキシ基 −OH の結合している炭素原子」に結合している炭素原子の数が、0か1個は第1級、2個は第2級、3個は第3級です。

:::

:::section
anchor: primary
title: 第1級アルコールの酸化
lead: アルデヒドで止まるか、カルボン酸まで進むかの2段階です。
terms:
- 第1級アルコール
- アルデヒド
- カルボン酸
:::

第1級アルコールは、酸化されるとまずアルデヒド R−CHO になり、さらに酸化されるとカルボン酸になります。

:::reaction
left: R−CH₂OH
over: 酸化
right: R−CHO
level: ★★★
note: 第1段。−OH が付いた炭素から水素が2個取れて、C=O ができます。
:::

:::reaction
left: R−CHO
over: 酸化
right: R−COOH
level: ★★★
note: 第2段。アルデヒドはさらに酸化されてカルボン酸になります。⚠ ここで止めたいときは「おだやかに酸化」します。
:::

アルデヒドは還元性をもつため、銀鏡反応・フェーリング反応を起こします。

カルボン酸は酸性の物質です。脂肪族ではスルホン酸やフェノール類は登場しませんので、酸性であればカルボン酸と考えることができます。

:::link
to: aldehyde
text: 銀鏡反応・フェーリング反応（アルデヒドの還元性を見る試験）は「アルデヒドの性質」で
:::

:::link
to: carboxylic-acid
text: カルボン酸が酸性を示すことと、その確かめ方は「カルボン酸」で
:::

## メタテクニック

問題文に「おだやかに酸化した」とあるときは、反応をアルデヒドで止めたことを意味します。また、過マンガン酸カリウムを用いたときは、ほぼカルボン酸まで反応が進み、二クロム酸カリウムを用いたときは、アルデヒドで反応が止まっていることが多いです。

//「データを示す」の宿題（③のレーンで測った結果・2026-09-12）。入試DB（`問題集/_解析/db/problems.jsonl` 1108大問）で酸化剤に触れる大問は233件。⚠ そのうち**過マンガン酸の43件は「側鎖の酸化」**（トルエン→安息香酸）で、アルコールの酸化とは別の反応です。側鎖を除き、片方の酸化剤だけが出る大問で「生成物・答え」の欄に何が挙がるかを数えると、**過マンガン酸はアルデヒドだけで終わるものが48件中1件（2%）／二クロム酸は42件中16件（38%）**で、本文の向きは合っています。⚠ ただしこれは欄の文字列で数えた概算（「〜酸」に当てはまる語を全部カルボン酸と見なしている）なので、**画面に数字を出すなら1件ずつ読み直しが要ります。**本文は向きだけを言う形のままにしてあります。

:::section
anchor: secondary
title: 第2級アルコールの酸化
lead: ケトンになり、そこで止まります。アルデヒドと同じ分子式ですが、還元性はありません。
terms:
- 第2級アルコール
- ケトン
:::

第2級アルコールは、酸化されるとケトンになり、そこで反応が止まります。

:::reaction
left: R−CH(OH)−R'
over: 酸化
right: R−CO−R'
level: ★★★
note: 両側を炭素にはさまれた C=O ができます。これ以上は酸化されません。
:::

ケトンとアルデヒドは同じ分子式 C~n~H~2n~O をもつ互いに構造異性体の関係ですが、ケトンはアルデヒドと違い還元性をもちません。

:::link
to: ketone
text: ケトンの性質と、アルデヒドとの見分け方は「ケトンの性質」で
:::

:::section
anchor: tertiary
title: 第3級アルコールの酸化
lead: 酸化されません。−OH が付いた炭素に、取れる水素がないためです。
terms:
- 第3級アルコール
:::

第3級アルコールは酸化されにくく、硫酸酸性条件の過マンガン酸カリウムや二クロム酸カリウムとは反応しません。

:::figure
src: alcohol-oxidation-tertiary.png
gen: name=2-メチル-2-プロパノール plain
alt: 2-メチル-2-プロパノールの構造式。中心の炭素にメチル基 CH₃ が3個とヒドロキシ基 OH が1個、合わせて4本の結合が出ていて、中心の炭素には水素が1個もついていない
caption: 第3級アルコールの例（2-メチル-2-プロパノール）。**−OH が付いた炭素に水素が1個もありません**。C=O を作るには この炭素から水素が取れなければならないので、反応が起こりません。
:::

アルコールの級による酸化反応の違いをまとめると次のようになります。

:::table
caption: 級と、酸化の行き先
source: このページの3つの節（第1級・第2級・第3級）に書いてあることを1つの表にまとめ直したもの。もとにした本はありません
head:
- アルコールの級
- 酸化するとどうなるか
align: center | left
rows:
- 第1級 | アルデヒド −CHO になり、さらに酸化されるとカルボン酸 −COOH になる

:::

**この3行は必ず暗記してください。**実際の実験や入試問題では、酸化反応によって何が生じたか調べることにより、もとのアルコールの構造を決定します。

## 例題

:::exercise
source: slides:有機の基本3-1「アルコールの性質」の酸化の回で出している C₄H₁₀O の構造決定（②稿に本文がそのまま書かれていたもの）
prompt: アルコール A、B、C、D はすべて分子式が C₄H₁₀O で互いに構造異性体である。A、B、C、D に硫酸酸性条件で二クロム酸カリウムを作用させたところ、B は反応しなかったが、A からは E、C からは F、D からは G が生じた。E、F はフェーリング液を還元したが、G は還元しなかった。E は直鎖構造だが、F は枝分かれをもっていた。**アルコール A、B、C、D の構造式を書け。**
answer: **A は 1-ブタノール** CH₃CH₂CH₂CH₂OH、**B は 2-メチル-2-プロパノール** (CH₃)₃C−OH、**C は 2-メチル-1-プロパノール** (CH₃)₂CH−CH₂OH、**D は 2-ブタノール** CH₃CH(OH)CH₂CH₃ です。たどり方は3段：① 反応しなかった B は第3級。C₄H₁₀O のアルコール4種のうち第3級は 2-メチル-2-プロパノールだけです。② フェーリング液を還元した E・F はアルデヒドなので、A と C は第1級。還元しなかった G はケトンなので、D は第2級 ＝ 2-ブタノール。③ 残る2つの第1級のうち、E が直鎖なので A は 1-ブタノール、F が枝分かれなので C は 2-メチル-1-プロパノールです。
:::

## 半反応式同士の組み合わせ

上の4本のどれかと、酸化剤の半反応式（過マンガン酸カリウム MnO₄⁻ と二クロム酸カリウム Cr₂O₇²⁻ の2本）を組み合わせるので、反応式は全部で 4×2 ＝ 8本つくれます。

:::exercise
source: 上の半反応式の表と、酸化還元単元の二クロム酸カリウムの半反応式を組み合わせて作った問い。もとにした本はありません
prompt: エタノールを硫酸酸性の二クロム酸カリウム水溶液で酸化してアセトアルデヒドを得た。**この反応のイオン反応式を書け。**（二クロム酸イオンの半反応式は Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O）
answer: **3C₂H₅OH ＋ Cr₂O₇²⁻ ＋ 8H⁺ → 3CH₃CHO ＋ 2Cr³⁺ ＋ 7H₂O** です。エタノールの半反応式は C₂H₅OH → CH₃CHO ＋ 2H⁺ ＋ 2e⁻ で、電子を2個出します。相手は6個受け取るので、こちらを3倍して電子の数をそろえ、足し合わせてから両辺の H⁺ を6個ずつ消します。
:::
