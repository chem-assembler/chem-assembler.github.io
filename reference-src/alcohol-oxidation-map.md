有機化合物は、炭素と水素でできた骨格に、はたらきを決める部分がくっついた形をしています。この部分が**官能基**で、**名前の語尾も、示す性質も、官能基で決まります**。

:::section
anchor: table
title: 名前の語尾と、図のかたち
lead: 同じ分子式でも官能基が違えば別の物質。語尾 -オール・〜エーテル・〜アルデヒド・-オンで見分けます。
terms:
- 示性式
- 構造異性体
- アルコール
- エーテル
:::

同じ酸素1個でも、**−OH**（ヒドロキシ基）を持てばアルコール、炭素にはさまれた **C−O−C**（エーテル結合）ならエーテルです。表の分子式の列を見ると、エタノールとジメチルエーテルはどちらも C₂H₆O。**分子式が同じでも、官能基が違えば別の物質**です。

名前の語尾も見てください —— **-オール**なら −OH、**〜エーテル**なら −O−、**〜アルデヒド**なら −CHO。ケトンの代表であるアセトンは慣用名ですが、規則どおりに呼べば 2-プロパノンで、語尾は **-オン** です。**この4つの語尾は暗記してください。**名前を見ただけでどの官能基を持つかが言えるようになります。

:::

:::section
anchor: class
title: アルコールの級 —— 酸化の行き先を決めるもの
lead: −OH が付いた炭素に、ほかの炭素が何個結合しているか。それが1級・2級・3級です。
terms:
- アルコールの級
- 1級アルコール
- 2級アルコール
- 3級アルコール
:::

官能基の列で、アルコールが「1級」「2級」に分かれていることに注目してください。これは **−OH が付いた炭素に、ほかの炭素が何個結合しているか**の違いです（メタノールは0個なので別に出ています）。

:::figure
src: alcohol-class.png
alt: アルコールの級の図。ヒドロキシ基が付いた炭素を丸で囲み、その炭素に結合している炭素が1個なら1級、2個なら2級、3個なら3級と示している
caption: 丸で囲んだ炭素に、**ほかの炭素がいくつ結合しているか**を数えるだけです。数えるのは −OH の付いた炭素の隣であって、分子全体の炭素の数ではありません。
:::

この級の違いが、**酸化したときの行き先**を決めます —— 1級アルコールを酸化すると −CHO（アルデヒド）になり、さらに酸化すると −COOH（カルボン酸）まで進みます。2級アルコールを酸化すると、両側を炭素にはさまれた C=O（ケトン）になります。3級アルコールは酸化されません。

**「1級→アルデヒド→カルボン酸、2級→ケトン、3級→酸化されない」の3行は必ず暗記してください。**有機の構造決定では、この3行が使えるかどうかで手が止まるかが決まります。

その行き先も、同じ表の中にあります。メタノール→ホルムアルデヒド、エタノール→アセトアルデヒド（どちらも1級）、2-プロパノール→アセトン（2級）。**アルコールとその酸化生成物が、同じ表の別の行として並んでいる**ので、行をまたいで見比べてください。

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: slides:有機の基本3-1「アルコールの性質」s26「練習3」(1)（解答は s27）
prompt: **エタノールを二クロム酸カリウムでおだやかに酸化した。**このとき生じる有機化合物の名称と示性式を書け。
answer: **アセトアルデヒド CH₃CHO**。エタノール CH₃CH₂OH は −OH が付いた炭素にほかの炭素が1個 ＝ **1級アルコール**なので、行き先はアルデヒドです。「おだやかに酸化」とあるので**アルデヒドで止まり**、ここから先（カルボン酸の酢酸 CH₃COOH）へは進みません。「十分に酸化」と書かれていたら酢酸まで進みます。
:::
