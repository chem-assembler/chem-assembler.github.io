炭素 C とケイ素 Si は周期表の14族の元素で、原子は4個の価電子をもちます。どちらも4本の共有結合をつくり、単体は**共有結合の結晶**になります（ダイヤモンドとケイ素の結晶は同じ形です）。

酸化物は、炭素が CO と CO₂、ケイ素が SiO₂ です。CO₂ と SiO₂ はどちらも**酸性酸化物**で、塩基と反応して塩をつくります。

炭素には、ダイヤモンド・黒鉛（グラファイト）・フラーレンなどの同素体があります。

:::table

source: textbook:R5化学Vol.2-4編（炭素の同素体の表の事実）から、構造・色・電気伝導性・用途の4欄を取った。欄の並びはスライドの同素体の表（無機の基本６ s7）にそろえた
head:
- 同素体
- 構造
- ようす
- 電気伝導性
- 用途
align: left | left | left | center | left
rows:
- ダイヤモンド | 各 C が4個の C と共有結合した立体網目構造 | 無色透明・非常に硬い | なし | 宝石・研磨剤
- 黒鉛 | 各 C が3個の C と結合した平面の層が重なった構造 | 黒色・軟らかい・はがれやすい | **あり** | 電極・鉛筆の芯
- フラーレン | C₆₀ などの球状の分子 | 黒色の粉末 | なし | 材料の研究・添加剤
:::

ダイヤモンドは、すべての C が4本の共有結合で立体的につながっているので、非常に硬く、電気を通しません。

黒鉛は、各 C が3本の結合で平面の層をつくり、層どうしは弱い分子間力で重なっています。4つめの価電子が層の中を動けるので、**黒鉛は非金属の単体なのに電気をよく通します。**層どうしがずれやすいので、軟らかくはがれやすい性質をもちます。

**「電気を通すのは黒鉛だけ」と、その理由（動ける価電子がある）を言えるようにしてください。**フラーレンのほか、黒鉛の1層だけを取り出したグラフェン、それを筒状に丸めたカーボンナノチューブもありますが、名前を知っていれば十分です。

木炭やすすのように、小さな黒鉛の結晶が不規則に集まったものを無定形炭素といいます。多孔質の活性炭は吸着力が大きく、脱臭剤に使われます。

一酸化炭素は血液中のヘモグロビンと強く結びついて酸素の運搬をさまたげるので、**極めて有毒**です。空気中では青白い炎を出して燃え、CO₂ になります。

高温では、ほかの物質から酸素を奪って CO₂ になりやすいので、**還元剤**として金属の製錬に使われます。

:::reaction

right: 2Fe ＋ 3CO₂
level: ★★☆
note: 溶鉱炉で鉄鉱石を還元する反応です。
:::

## CO₂ のつくり方

実験室では、石灰石（主成分は炭酸カルシウム CaCO₃）に希塩酸を加えてつくります。強酸の HCl が、弱酸の炭酸を追い出す**弱酸の遊離**です。

:::reaction
left: CaCO₃ ＋ 2HCl
right: CaCl₂ ＋ H₂O ＋ CO₂↑
level: ★★★
note: 本体は CO₃²⁻ ＋ 2H⁺ → H₂O ＋ CO₂ です。希硫酸を使うと、水に溶けにくい CaSO₄ が石灰石の表面をおおって反応が止まるので、塩酸を使います。
:::

## 酸としての CO₂

CO₂ は水に少し溶け、その一部が電離して弱い酸性を示します。

:::reaction
left: CO₂ ＋ H₂O
arrow: ⇄
right: H⁺ ＋ HCO₃⁻
level: ★★★
note: 炭酸 H₂CO₃ を経て電離します。電離はごく一部なので、炭酸水は弱い酸性です。
:::

酸性酸化物なので、塩基と中和して塩をつくります。

:::reaction
left: CO₂ ＋ 2NaOH
right: Na₂CO₃ ＋ H₂O
level: ★★★
note: CO₂ を2価の酸 H₂CO₃ と見て、NaOH と価数の逆の比 1：2 で中和させます。
:::

石灰水（水酸化カルシウム Ca(OH)₂ の水溶液）に通すと、炭酸カルシウムの白色沈殿ができて**白濁**します。CO₂ の検出に使います。

:::reaction
left: Ca(OH)₂ ＋ CO₂
right: CaCO₃↓ ＋ H₂O
level: ★★★
note: 中和と沈殿が同時に起こる反応です。
:::

白濁したあとも CO₂ を通し続けると、沈殿が水に溶ける炭酸水素カルシウムになり、無色にもどります。

:::reaction
left: CaCO₃ ＋ CO₂ ＋ H₂O
right: Ca(HCO₃)₂
level: ★★☆
note: 鍾乳洞ができるのはこの反応によります（逆向きに進むと CaCO₃ が析出します）。
:::

CO₂ の固体はドライアイスといい、常圧では液体にならずに昇華します。まわりから熱を奪うので冷却剤に使われます。

:::section
anchor: silicon
title: ケイ素 Si —— 半導体
lead: 地殻中で酸素の次に多い元素です。単体は自然界に無く、SiO₂ を炭素で還元してつくります。
terms:
- ケイ素
- 半導体
:::

ケイ素は岩石や鉱物の成分として、地殻中で酸素の次に多く存在します。単体は自然界に存在しないので、二酸化ケイ素を電気炉で融解し、炭素で還元してつくります。

:::reaction
left: SiO₂ ＋ 2C
over: 電気炉で融解
right: Si ＋ 2CO
level: ★☆☆
note: 炭素が還元剤としてはたらきます。
:::

ケイ素の単体は、ダイヤモンドと同じ形の共有結合の結晶です。灰色で金属のような光沢があり、電気の通しやすさが金属と非金属の中間の**半導体**です。高純度のケイ素は、コンピュータの部品や太陽電池に使われます。

**ケイ素の単体の製法は覚えなくても構いません。**「ダイヤモンドと同じ構造」「半導体」の2つを押さえておきましょう。

:::section
anchor: sio2
title: 二酸化ケイ素 SiO₂ から シリカゲルまで
lead: SiO₂ は水とは反応しない酸性酸化物です。塩基と加熱してケイ酸ナトリウムにし、水ガラス → ケイ酸 → シリカゲルと変えていきます。
terms:
- 二酸化ケイ素
- ケイ酸ナトリウム
- 水ガラス
- ケイ酸
- シリカゲル
:::

二酸化ケイ素 SiO₂ は、Si 原子のまわりに O 原子が4個結合した四面体がつながった、**共有結合の結晶**です。水晶・石英・けい砂はほぼ純粋な SiO₂ で、光ファイバーにも使われます。

CO₂ と同じ酸性酸化物ですが、**SiO₂ は水とは反応しません。**そのため塩基とは、固体どうしを加熱・融解して反応させます。

:::reaction
left: SiO₂ ＋ 2NaOH
over: 加熱・融解
right: Na₂SiO₃ ＋ H₂O
level: ★★★
note: CO₂ ＋ 2NaOH → Na₂CO₃ ＋ H₂O と同じ形です。C を Si に置き換えるだけで書けます。
:::

:::reaction
left: SiO₂ ＋ Na₂CO₃
over: 加熱・融解
right: Na₂SiO₃ ＋ CO₂
level: ★★☆
note: 炭酸ナトリウムでも同じケイ酸ナトリウムができます。
:::

**SiO₂ ＋ 2NaOH の式は、CO₂ ＋ 2NaOH の式と並べて覚えるようにしましょう。**違いは「SiO₂ は水と反応しないので、加熱・融解が要る」の1点だけです。

SiO₂ は、酸の中でただ1つ**フッ化水素 HF（フッ化水素酸）には溶けます。**ガラスの主成分が SiO₂ なので、フッ化水素酸はガラスびんに保存できず、ポリエチレンの容器に入れます。

:::reaction
left: SiO₂ ＋ 6HF
right: H₂SiF₆ ＋ 2H₂O
level: ★★★
note: 生じるのはヘキサフルオロケイ酸 H₂SiF₆ です。ガラスに目盛りをつけるのに使われます。
:::

## 水ガラスからシリカゲルへ

ケイ酸ナトリウムから乾燥剤のシリカゲルができるまでは、次の順です。

:::list
ordered: true
items:
- ケイ酸ナトリウム Na₂SiO₃ に水を加えて加熱すると、無色透明で粘り気の強い**水ガラス**になる。
- 水ガラスに塩酸を加えると、弱酸のケイ酸 H₂SiO₃ が遊離して、白色のゲル状の沈殿になる。
- ケイ酸を加熱して水を除くと、多孔質の固体の**シリカゲル**になる。
:::

:::reaction
left: Na₂SiO₃ ＋ 2HCl
right: 2NaCl ＋ H₂SiO₃
level: ★★☆
note: 強酸の HCl が、弱酸のケイ酸を追い出す弱酸の遊離です。CaCO₃ ＋ 2HCl と同じ型です。
:::

シリカゲルは表面に −OH を多くもち、水分子を水素結合で引きつけるので、**乾燥剤**や吸着剤に使われます。お菓子の袋に入っている乾燥剤がこれです。

:::section
anchor: range
title: 覚える範囲
lead: CO の製法と毒性・還元性、CO₂ の製法と石灰水、SiO₂ が水と反応せず塩基・HF と反応すること、が中心です。
:::

**★★★ の式は、物質名から書けるようにしてください。**とくに次の2組は、並べて覚えると負担が半分になります。

:::list
items:
- CO₂ ＋ 2NaOH → Na₂CO₃ ＋ H₂O と SiO₂ ＋ 2NaOH → Na₂SiO₃ ＋ H₂O（C を Si に置き換える）
- CaCO₃ ＋ 2HCl → CaCl₂ ＋ H₂O ＋ CO₂ と Na₂SiO₃ ＋ 2HCl → 2NaCl ＋ H₂SiO₃（どちらも弱酸の遊離）
:::

同素体は「電気を通すのは黒鉛だけ」を押さえれば十分です。ケイ素の単体の製法と水性ガスの式は、覚えなくても構いません。
