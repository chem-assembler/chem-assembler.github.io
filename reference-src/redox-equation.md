酸化還元反応の反応式は、**酸化剤と還元剤の半反応式を組み合わせて**つくります。反応式を丸暗記する必要はなく、2本の半反応式が書ければ、どの組み合わせでも同じ手順で組み立てられます。

:::section
anchor: valence
title: 酸化剤・還元剤の価数と、反応の量的関係
lead: 酸化剤と還元剤は、価数の逆の比で反応します。
terms:
- 酸化剤の価数
- 還元剤の価数
:::

1個の酸化剤が受け取る e⁻ の数を「酸化剤の価数」、1個の還元剤が放出する e⁻ の数を「還元剤の価数」といいます。

## 具体例

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 1個の MnO₄⁻ が 5e⁻ を受け取っているので、KMnO₄ は **5価の酸化剤**です。
:::

:::reaction
left: H₂O₂
right: O₂↑ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 1個の H₂O₂ が 2e⁻ を放出しているので、H₂O₂ は **2価の還元剤**です。
:::

酸化剤と還元剤が過不足なく反応するのは、**酸化剤の受け取る e⁻ の数と、還元剤の放出する e⁻ の数が等しい**ときです。

　（酸化剤の価数）×（酸化剤の数）＝（還元剤の価数）×（還元剤の数）

したがって、**酸化剤と還元剤は価数の逆の比で反応します**。5価の KMnO₄ と2価の H₂O₂ なら、KMnO₄：H₂O₂ ＝ 2：5 です。

:::figure
src: redox-equation-valence.png
alt: 3価の酸化剤2個と2価の還元剤3個の図。還元剤3個がそれぞれ 2e⁻ を出して合計 6e⁻ になり、それを酸化剤2個が 3e⁻ ずつ受け取る。下に「酸化剤と還元剤は価数の逆の比で反応する」
caption: 3価の酸化剤2個と2価の還元剤3個で、ちょうど 6e⁻ がやりとりされます。**価数の逆の比**（3：2 の逆 → 2：3）で反応します。
:::

価数は丸暗記するものではありません。**半反応式が書ければ、e⁻ の係数から読めます**。

この関係は、酸塩基の中和で「酸と塩基は価数の逆の比で反応する」のと同じ形です。酸化還元滴定の計算もこの式で解きます。

:::section
anchor: assemble
title: 反応式の組み立て方
lead: 半反応式を整数倍して e⁻ をそろえて足し、省略されているイオンを両辺に加えます。
terms:
- イオン反応式
- 化学反応式
:::

硫酸酸性の過マンガン酸カリウム KMnO₄ 水溶液と過酸化水素 H₂O₂ 水の反応を、次の3段で組み立てます。

:::list
ordered: true
items:
- 酸化剤・還元剤の半反応式を書き、それぞれを整数倍して e⁻ の係数をそろえてから足し合わせる。
　KMnO₄ の式を2倍、H₂O₂ の式を5倍すると e⁻ がどちらも10個になり、足すと e⁻ が消える
- 反応式の左辺のイオンと、反応させた物質を比べて、省略されているイオンを両辺に加える。
　MnO₄⁻ はもともと K⁺ と、H⁺ はもともと SO₄²⁻ とくっついていたので、両辺に 2K⁺ と 3SO₄²⁻ を加える
- 左辺はイオンを組み合わせて反応させた物質を復元し、右辺は陽イオンと陰イオンを組み合わせて塩をつくる。
:::

:::figure
src: redox-equation-assemble.png
alt: 過マンガン酸イオンの半反応式を2倍、過酸化水素の半反応式を5倍して足し、2MnO₄⁻ ＋ 6H⁺ ＋ 5H₂O₂ → 2Mn²⁺ ＋ 5O₂ ＋ 8H₂O を得る図と、その両辺に 2K⁺ と 3SO₄²⁻ を加える段
caption: 1段目で 8H⁺ の2倍の 16H⁺ と、右辺の 10H⁺ が打ち消し合って 6H⁺ が残ります。2段目で、**省略されていた K⁺ と SO₄²⁻** を両辺に戻します。
:::

1段目で得られるイオン反応式と、3段目で得られる化学反応式は次のとおりです。

:::reaction
left: 2MnO₄⁻ ＋ 6H⁺ ＋ 5H₂O₂
right: 2Mn²⁺ ＋ 5O₂↑ ＋ 8H₂O
level: ★★★
note: イオン反応式。MnO₄⁻：H₂O₂ ＝ 2：5 で、価数の逆の比になっています。
:::

:::reaction
left: 2KMnO₄ ＋ 3H₂SO₄ ＋ 5H₂O₂
right: 2MnSO₄ ＋ K₂SO₄ ＋ 5O₂↑ ＋ 8H₂O
level: ★★★
note: 化学反応式。右辺は Mn²⁺ と SO₄²⁻ で MnSO₄、K⁺ と SO₄²⁻ で K₂SO₄ をつくります。
:::

## 左辺の物質は用意したもの、右辺はあるものを組み合わせてよい

**左辺の物質は、実際に用意したもの**でなければなりません。一方、**右辺のイオンは、あるものを自由に組み合わせて**塩にしてかまいません。

:::mistake
wrong: 左辺にある 2K⁺ と SO₄²⁻ で K₂SO₄ をつくって、左辺に K₂SO₄ を書く
right: 左辺には、**用意した KMnO₄ と H₂SO₄ と H₂O₂** を書きます。K₂SO₄ は右辺にだけ出てきます。
why: 用意していない物質は反応させることができないためです。K⁺ は KMnO₄ から、SO₄²⁻ は H₂SO₄ から来ているので、左辺ではそれぞれ元の物質に戻します。
:::

:::section
anchor: sulfuric
title: 具体例 —— H⁺ を硫酸から持ってくる反応
lead: KMnO₄ や K₂Cr₂O₇ の反応では、H⁺ を供給するために硫酸を加えます（硫酸酸性）。
terms:
- 硫酸酸性
:::

過マンガン酸カリウムと鉄(Ⅱ)イオンなら、5価の酸化剤と1価の還元剤なので、Fe²⁺ の式を5倍すると e⁻ がそろいます。

:::figure
src: redox-equation-app-kmno4-fe.png
shot: url=/ion-equation/redox.html?rxn=rs1 sel=#step1 状態=Fe²⁺ の行の倍数の欄に 5 を入れて（fill ＋ input/change）e⁻ がそろった表示にしてから撮った（ion v215・1200px 幅・deviceScaleFactor 1）
alt: Fe²⁺ → Fe³⁺ ＋ e⁻ に ×5、MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺ ＋ 4H₂O に ×1 を掛けて、e⁻ がどちらも5個にそろった状態。各式の Fe・Mn の下に酸化数（＋2 → ＋3、＋7 → ＋2）が添えてある
caption: 過マンガン酸イオン（5価）と鉄(Ⅱ)イオン（1価）。**価数の逆の比 1：5** で e⁻ がそろいます。
:::

二クロム酸カリウム K₂Cr₂O₇ 水溶液と硫酸鉄(Ⅱ) FeSO₄ 水溶液を、硫酸酸性で反応させます。

:::list
ordered: true
items:
- Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O と、Fe²⁺ → Fe³⁺ ＋ e⁻ を書き、FeSO₄ の式を6倍して足す。
- Cr₂O₇²⁻ はもともと K⁺ と、H⁺ と Fe²⁺ は SO₄²⁻ とくっついて H₂SO₄・FeSO₄ だったので、両辺に 2K⁺ と 7SO₄²⁻ ＋ 6SO₄²⁻ を加える。
- 右辺で K₂SO₄・Cr₂(SO₄)₃・Fe₂(SO₄)₃ に組む。
:::

:::reaction
left: Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6Fe²⁺
right: 2Cr³⁺ ＋ 6Fe³⁺ ＋ 7H₂O
level: ★★★
note: イオン反応式。6価の酸化剤と1価の還元剤なので 1：6 で反応します。
:::

:::reaction
left: K₂Cr₂O₇ ＋ 7H₂SO₄ ＋ 6FeSO₄
right: K₂SO₄ ＋ Cr₂(SO₄)₃ ＋ 3Fe₂(SO₄)₃ ＋ 7H₂O
level: ★★★
note: 化学反応式。両辺とも SO₄²⁻ は13個です。
:::

同じ K₂Cr₂O₇ を H₂O₂ と反応させると、H₂O₂ は還元剤としてはたらきます。

:::reaction
left: K₂Cr₂O₇ ＋ 3H₂O₂ ＋ 4H₂SO₄
right: Cr₂(SO₄)₃ ＋ K₂SO₄ ＋ 3O₂↑ ＋ 7H₂O
level: ★★★
note: イオン反応式は Cr₂O₇²⁻ ＋ 3H₂O₂ ＋ 8H⁺ → 2Cr³⁺ ＋ 3O₂ ＋ 7H₂O。
:::

:::section
anchor: nitric
title: 具体例 —— 硝酸は H⁺ も自分で出す
lead: 希硝酸は強酸なので、硫酸を加えて酸性にする必要がありません。
terms:
- 酸化力のある酸
:::

銅が希硝酸に溶ける反応では、**HNO₃ が酸化剤と H⁺ の供給役の2役**をします。**希硝酸は強酸なので、硫酸を加えて酸性にする必要がありません（硫酸酸性ではない）**。

:::list
ordered: true
items:
- HNO₃ ＋ 3H⁺ ＋ 3e⁻ → NO ＋ 2H₂O を2倍、Cu → Cu²⁺ ＋ 2e⁻ を3倍して足す。
　3Cu ＋ 2HNO₃ ＋ 6H⁺ → 3Cu²⁺ ＋ 2NO ＋ 4H₂O
- 左辺の H⁺ はもともと NO₃⁻ とくっついて HNO₃ だったので、両辺に 6NO₃⁻ を加える（H₂SO₄ は用意していないので、SO₄²⁻ は存在しません）。
- 酸化剤の 2HNO₃ と、H⁺ 供給役の 6HNO₃ をまとめて 8HNO₃ にし、右辺は Cu(NO₃)₂ に組む。
:::

:::reaction
left: 3Cu ＋ 8HNO₃
right: 3Cu(NO₃)₂ ＋ 2NO↑ ＋ 4H₂O
level: ★★★
note: 希硝酸。3価の酸化剤 HNO₃ と2価の還元剤 Cu は 2：3 で反応しますが、H⁺ 供給役の HNO₃ と合わせると HNO₃：Cu ＝ 8：3 になります。
:::

濃硝酸・熱濃硫酸でも、同じ手順で組み立てられます。

:::reaction
left: Cu ＋ 4HNO₃
right: Cu(NO₃)₂ ＋ 2NO₂↑ ＋ 2H₂O
level: ★★★
note: 濃硝酸。HNO₃ ＋ H⁺ ＋ e⁻ → NO₂ ＋ H₂O を2倍して Cu の式と足し、H⁺ 供給役の 2HNO₃ と合わせます。
:::

:::reaction
left: Cu ＋ 2H₂SO₄
over: 加熱
right: CuSO₄ ＋ SO₂↑ ＋ 2H₂O
level: ★★★
note: 熱濃硫酸。H₂SO₄ ＋ 2H⁺ ＋ 2e⁻ → SO₂ ＋ 2H₂O と Cu の式を足し、H⁺ 供給役の H₂SO₄ と合わせます。
:::

**この3本は、半反応式から組み立てられるようにしておきましょう。**係数を覚えていなくても、手順どおりに組めば必ず出ます。

## 例題

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.68-69（練習10(1)）
prompt: 過マンガン酸カリウム水溶液と過酸化水素水が、硫酸酸性条件で反応した。**この反応を化学反応式で書け。**
answer: **2KMnO₄ ＋ 3H₂SO₄ ＋ 5H₂O₂ → 2MnSO₄ ＋ K₂SO₄ ＋ 5O₂ ＋ 8H₂O** です。KMnO₄ の半反応式を2倍、H₂O₂ の半反応式を5倍して e⁻ を10個にそろえて足すと 2MnO₄⁻ ＋ 6H⁺ ＋ 5H₂O₂ → 2Mn²⁺ ＋ 5O₂ ＋ 8H₂O。両辺に 2K⁺ と 3SO₄²⁻ を加えて組みます。
:::

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.68・p.70（練習10(2)）
prompt: 二クロム酸カリウム水溶液と硫酸鉄(Ⅱ)水溶液が、硫酸酸性条件で反応した。**この反応を化学反応式で書け。**
answer: **K₂Cr₂O₇ ＋ 7H₂SO₄ ＋ 6FeSO₄ → K₂SO₄ ＋ Cr₂(SO₄)₃ ＋ 3Fe₂(SO₄)₃ ＋ 7H₂O** です。FeSO₄ の半反応式を6倍して足すと Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6Fe²⁺ → 2Cr³⁺ ＋ 6Fe³⁺ ＋ 7H₂O。両辺に 2K⁺ と 13SO₄²⁻（H₂SO₄ から7個、FeSO₄ から6個）を加えて組みます。
:::

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.71・p.74（練習11(3)）
prompt: 銅が希硝酸に溶解した。**この反応を化学反応式で書け。**
answer: **3Cu ＋ 8HNO₃ → 3Cu(NO₃)₂ ＋ 2NO ＋ 4H₂O** です。希硝酸の半反応式を2倍、Cu の半反応式を3倍して足すと 3Cu ＋ 2HNO₃ ＋ 6H⁺ → 3Cu²⁺ ＋ 2NO ＋ 4H₂O。H⁺ は HNO₃ から来ているので両辺に 6NO₃⁻ を加え、左辺の HNO₃ を 8HNO₃ にまとめます。
:::
