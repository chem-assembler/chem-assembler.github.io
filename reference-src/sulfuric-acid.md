硫酸 H₂SO₄ の S の酸化数は、最高の +6 です。同じ硫酸でも、水で薄めた**希硫酸**と、濃度 90〜98% の**濃硫酸**とでは、はたらきがまったく違います。反応式を書くときは、まず「希硫酸のはたらきか、濃硫酸のはたらきか」を見分けます。

## ② 熱濃硫酸は酸化力のある酸 —— Cu・Ag を溶かす

濃硫酸を熱すると、H⁺ ではなく硫酸の分子そのものが酸化剤としてはたらくようになります。これが**熱濃硫酸**で、H⁺ では歯が立たない Cu や Ag まで酸化して溶かします。硫酸の S は +6 → +4 に変わるので、SO₂ が出てきます。

:::reaction
left: H₂SO₄ ＋ 2H⁺ ＋ 2e⁻
right: SO₂↑ ＋ 2H₂O
level: ★★★
note: 熱濃硫酸が酸化剤としてはたらくときの半反応式。
:::

## ③ 溶解熱が大きい —— 薄めるときは水に濃硫酸を

H₂SO₄ は水に溶けると多量の熱を出します（1 mol あたり約 96 kJ の発熱）。水と強く結びつきやすい性質で、これが④の吸湿作用・⑤の脱水作用のもとになっています。

濃硫酸を薄めるときは、**多量の水に濃硫酸を少しずつ加えます**。逆に濃硫酸に水を加えると、密度の小さい水（1.0 g/cm³）が濃硫酸（約 1.8 g/cm³）の上に浮いたまま発熱で沸騰し、硫酸が飛び散って危険です。

:::mistake
wrong: 濃硫酸を薄めるときは、濃硫酸に水を少しずつ加える
right: **多量の水に、濃硫酸を少しずつ**加えます。
why: 「濃いものを薄める＝濃いものに水を足す」と考えてしまうためです。水は濃硫酸より軽いので表面にたまり、そこで一気に発熱して突沸します。
:::

## ④ 吸湿作用 —— 気体の乾燥剤

濃硫酸には吸湿性があり、気体の**乾燥剤**に使われます。空気中にもともと H₂O として存在している水蒸気を吸収するのが**吸湿作用**です。

乾燥剤を選ぶときは、**乾燥剤と乾燥させたい気体が中和反応しないこと**が条件です。反応すると、目的の気体が塩になって乾燥剤に吸収されてしまいます。

- 十酸化四リン P₄O₁₀ | 酸性 | 酸性・中性の気体 | −
- シリカゲル SiO₂・nH₂O | ごく弱い酸性 | 酸性・中性の気体 | −

- ソーダ石灰 NaOH ＋ CaO | 塩基性 | 中性・塩基性の気体 | −
:::

気体の液性は次の3つに分けて覚えます。**酸性の気体**: HF・HCl・Cl₂・H₂S・SO₂・NO₂・CO₂。**中性の気体**: H₂・O₂・N₂・NO・CO（水に溶けない気体）。**塩基性の気体**: NH₃ だけ。

**濃硫酸で乾燥できないのは NH₃（塩基性）と H₂S（還元剤）の2つ**、と覚えておけば十分です。シリカゲルは中性の乾燥剤に分類されることもありますが、酸性酸化物で、極めて弱い酸性の物質です。

## ⑤ 脱水作用 —— 分子から H と O を 2:1 で奪う

ほかの分子を壊して H 原子と O 原子から H₂O をつくって奪うのが**脱水作用**です。濃硫酸は H と O を 2:1 の割合で奪います。このときの濃硫酸は**脱水剤**です（触媒ではありません。奪った水を吸って自分は薄まります）。反応式には H₂SO₄ を入れず、分子から H₂O がとれる形で書きます。

:::reaction
left: C₆H₁₂O₆
right: 6C ＋ 6H₂O
level: ★★★
note: グルコース。とれるだけ H₂O をとって C を残します。
:::

:::reaction
left: C₁₂H₂₂O₁₁
right: 12C ＋ 11H₂O
level: ★★★
note: スクロース。
:::

炭素が遊離して黒くなる（炭化する）反応です。炭素 C と水 H₂O が結びついたように見える分子式をしているので**炭水化物**といい、脱水されると C だけが残ります。衣服に濃硫酸がつくと、同じ反応が起こって穴が開きます。グルコース・スクロースの分子式は、有機化学が未習なら覚えなくてもかまいません。

:::reaction
left: HCOOH
over: 濃硫酸・加熱
right: CO↑ ＋ H₂O
level: ★★★
note: ギ酸の脱水。とれるだけ H₂O をとって CO を残します（一酸化炭素の実験室的製法）。
:::

- 鉛蓄電池の電解液になり、両極に PbSO₄ が析出する | 脱水作用があり、ほかの分子を壊して H₂O を奪う
:::

**この10項目は、どちらの硫酸の性質かを言えるようにしてください。**反応式の問題では、問題文の「希硫酸」「濃硫酸」「加熱した」の言葉から、どのはたらきかが決まります。

:::mistake
wrong: 希硫酸は強酸だが、濃硫酸は弱酸である
right: 濃硫酸がほとんど電離していないのは、周りに H⁺ を渡す相手の H₂O がないためで、**酸としての強さ（相手に H⁺ を与える力）は強い**ままです。
why: 強酸として使うときは希硫酸を使い、濃硫酸はほとんど電離していないので「弱い」と取り違えます。水溶液の H⁺ は H₃O⁺ を省略した書き方で、酸が電離するには H⁺ を受け取る H₂O が要ります（H₂SO₄ ＋ H₂O → H₃O⁺ ＋ HSO₄⁻）。硫酸に限らず、どんな酸でも濃度が大きくなれば電離度は小さくなります。
:::

:::section
anchor: contact
title: 接触法 —— 硫黄を2段階で酸化して硫酸にする
lead: S を燃やして SO₂、V₂O₅ 触媒で SO₃、それを水と反応させて H₂SO₄。3本の式を足して1本にまとめます。
terms:
- 接触法
- 発煙硫酸
- 酸化バナジウム(Ⅴ)
:::

硫酸は工業的には**接触法**でつくります。原料の硫黄は、原油に不純物として含まれているものを取り除いて（脱硫して）得ます。

:::list
ordered: true
items:
- 硫黄 S を燃焼させて二酸化硫黄 SO₂ をつくる。
　空気中の燃焼では S の酸化数は +4 の SO₂ で止まる。
- SO₂ を酸化バナジウム(Ⅴ) V₂O₅ を触媒にして酸化し、三酸化硫黄 SO₃ をつくる。
　V₂O₅ 触媒で S の酸化数を +6 まで上げられる。
- SO₃ を濃硫酸に吸収させて発煙硫酸にする。
- 発煙硫酸を希硫酸で薄めて濃硫酸にする。
　酸性酸化物の SO₃ が H₂O と反応して、対応するオキソ酸 H₂SO₄ になっている。
:::

:::reaction
left: S ＋ O₂
right: SO₂
level: ★★★
note: ① 硫黄の燃焼（S: 0 → +4）。
:::

:::reaction
left: 2SO₂ ＋ O₂
over: V₂O₅
right: 2SO₃
level: ★★★
note: ② 触媒で酸化する（S: +4 → +6）。
:::

:::reaction
left: SO₃ ＋ H₂O
right: H₂SO₄
level: ★★★
note: ③ 酸性酸化物とオキソ酸（S: +6 のまま）。
:::

全体の式は、**中間の物質（SO₂ と SO₃）が消えるように係数をそろえて足します**。①×2 で SO₂ が、③×2 で SO₃ がそろうので、①×2 ＋ ② ＋ ③×2 です。

caption: 中間の物質（SO₂・SO₃）の係数をそろえてから足します。①×2 ＋ ② ＋ ③×2 です。

:::reaction
left: 2S ＋ 3O₂ ＋ 2H₂O
right: 2H₂SO₄
level: ★★★
note: 接触法全体の反応式。S 原子1個から H₂SO₄ 1分子ができる、と読みます。
:::

発煙硫酸は、濃硫酸に SO₃ を過剰に吸収させたもので、SO₃ が蒸発して煙を出しています。

src: sulfuric-acid-contact-flow.png

caption: S を2段階で酸化して +6 にし、最後の水との反応では酸化数は変わりません。

:::exercise

prompt: Ag⁺・Al³⁺・Ba²⁺・Ca²⁺・Cu²⁺・Fe²⁺・Mg²⁺・Na⁺・Pb²⁺ のうち、**(1) 硫酸イオンと沈殿をつくるもの　(2) 塩化物イオンと沈殿をつくるもの** をすべて選び、沈殿の化学式と色を書け。
answer: (1) BaSO₄ 白・CaSO₄ 白・PbSO₄ 白　(2) AgCl 白・PbCl₂ 白　Pb²⁺ は SO₄²⁻ とも Cl⁻ とも沈殿をつくります。代表的な強酸3つ（HCl・HNO₃・H₂SO₄）のうち、NO₃⁻ は沈殿をつくりません。
:::

//⚠ スライド s33 のイオンの並びに Mg²⁺ が2回出てくる（1つは別のイオンの書き誤りか）。例題では重複を1つにした

:::exercise
source: slides:無機の基本６「硫黄」s35「練習２」（解答は s36）
prompt: H₂・HCl・H₂S・NH₃・O₂・SO₂ のうち、乾燥剤として濃硫酸を用いることができる気体をすべて選び、化学式で答えよ。
answer: H₂・HCl・O₂・SO₂　濃硫酸は酸性の乾燥剤なので、中和反応する塩基性の気体 NH₃ には使えません。還元力の強い H₂S とは酸化還元反応するので、H₂S にも使えません。
:::

:::exercise
source: slides:無機の基本６「硫黄」s49「練習９」（解答は s50）
prompt: 次の化学反応式を書け。**(1) 銅が熱濃硫酸に溶解した　(2) 銀が熱濃硫酸に溶解した　(3) グルコース C₆H₁₂O₆ に濃硫酸を滴下した　(4) スクロース C₁₂H₂₂O₁₁ に濃硫酸を滴下した**
answer: (1) Cu ＋ 2H₂SO₄ → CuSO₄ ＋ 2H₂O ＋ SO₂↑　(2) 2Ag ＋ 2H₂SO₄ → Ag₂SO₄ ＋ 2H₂O ＋ SO₂↑　(3) C₆H₁₂O₆ → 6C ＋ 6H₂O　(4) C₁₂H₂₂O₁₁ → 12C ＋ 11H₂O　すべて★★★です。(3)(4) の濃硫酸は脱水剤なので、式には書きません。
:::

:::exercise
source: slides:無機の基本６「硫黄」s51「練習１０」（解答は s52・s53）
prompt: **(1) 硫黄を原料に硫酸を製造する接触法の反応を3本の化学反応式で書き、それらを1本の化学反応式にまとめよ。　(2) 接触法ですべての硫黄が硫酸に変えられたとすると、98% 濃硫酸 100 kg をつくるのに必要な硫黄は何 kg か（H＝1.0、O＝16、S＝32）。**
answer: (1) S ＋ O₂ → SO₂、2SO₂ ＋ O₂ → 2SO₃（触媒 V₂O₅）、SO₃ ＋ H₂O → H₂SO₄。まとめると 2S ＋ 3O₂ ＋ 2H₂O → 2H₂SO₄。　(2) 32 kg。① 98% 濃硫酸 100 kg に含まれる H₂SO₄ は 100 kg × 98/100 ＝ 98 kg。② 全体の式から、S 1 mol（32 g）から H₂SO₄ 1 mol（98 g）ができる。③ 比例式 H₂SO₄ 98 g : S 32 g ＝ H₂SO₄ 98 kg : S x kg より x ＝ 32。全体の式を書かなくても、S 原子の数に着目すれば「S 1 mol から H₂SO₄ 1 mol」とわかります。
:::
