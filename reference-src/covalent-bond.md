前のページでは、原子が電子を**やりとり**してイオンになる話をしました。非金属の原子どうしでは、どちらも電子を受け取りたいので、やりとりが起こりません。代わりに、電子を**出し合って共有**することで、どちらも貴ガスと同じ電子配置になります。このページの目標は、**分子の構造式と電子式を自分で書けるようになること**です。

:::section
anchor: valence
title: 原子価 —— 結合の手の数
lead: 原子は不対電子を出し合って共有結合するので、不対電子の数がそのまま結合の手の数（原子価）になります。H は1本、O は2本、N は3本、C は4本です。
terms:
- 共有結合
- 不対電子
- 共有電子対
- 非共有電子対
- 原子価
- 電子式
:::

2個の水素原子 H は、それぞれ1個の電子を出し合い、2個の電子を共有して水素分子 H₂ になります。共有した2個の電子は、どちらの H にとっても自分の電子として数えられるので、どちらも He と同じ電子配置（K 殻に2個）になります。このように、原子どうしが電子を出し合って共有してできる結合を**共有結合**といいます。

最外殻の電子を点で表した式を**電子式**といいます。電子式では、電子を元素記号の上下左右に置きます。

:::list
items:
- 対になっていない電子を**不対電子**という。結合に使われる電子である。
- 対になっている電子のうち、結合に使われていないものを**非共有電子対**、2つの原子の間で共有されているものを**共有電子対**という。
- 原子の電子式を書くときは、非共有電子対ができるだけ少なくなるように（不対電子ができるだけ多くなるように）電子を置く。
:::

族の番号の一の位と価電子の数は一致します。原子は不対電子を出し合って共有結合するので、**不対電子の数 ＝ 結合の手の数（原子価）**になります。

**「H1本・O2本・N3本・C4本」は必ず暗記してください。**ハロゲン（F・Cl・Br・I）は H と同じ1本です。この4つ（＋ハロゲン）を覚えておけば、高校化学で出てくる分子の構造式はほとんど書けます。

:::section
anchor: structural-formula
title: 構造式の書き方 —— 手と手をつなぐパズル
lead: 原子ごとに原子価の数だけ結合の手をもったパーツを用意し、手と手をつなぎ合わせて組み立てます。余った手が無いこと、原子の数が化学式と合っていることを確かめれば完成です。
terms:
- 構造式
- 単結合
- 二重結合
- 三重結合
:::

原子と原子をつなぐ共有電子対1組を1本の線（結合の手。価標ともいいます）で表した式を**構造式**といいます。構造式は、次の手順で書きます。

:::list
ordered: true
items:
- 化学式の原子を、原子価の数だけ手をもったパーツにする。
　H₂O なら H（1本）・H（1本）・O（2本）
- 手と手をつなぎ合わせて組み立てる。
　H−O−H
- すべての原子について、結合の手の数が原子価と合っているか確かめる。
- 化学式と原子の数が合っているか確かめる。
:::

2つの原子の間を2本・3本の手でつなぐこともあります。1組の共有電子対による結合を**単結合**、2組なら**二重結合**、3組なら**三重結合**といいます。

具体例として、二酸化炭素 CO₂ を組み立ててみましょう。パーツは C（4本）・O（2本）・O（2本）です。C の4本の手を、2本ずつ左右の O につなぐと、どちらの O も2本の手をすべて使い切ります。よって構造式は **O＝C＝O** です。

caption: 二酸化炭素 CO₂。C の4本の手を、2本ずつ左右の O につなぎます（二重結合が2つ）。
:::

同じように、アンモニア NH₃ は N（3本）の手すべてに H を、メタン CH₄ は C（4本）の手すべてに H をつなぎます。

:::figure
src: covalent-bond-nh3-ch4.png

alt: アンモニアとメタンの構造式。N から3本、C から4本の線が出て、その先に H が1個ずつ書かれている
caption: **アンモニア NH₃** と **メタン CH₄**。H を1つずつ書くと、手の本数をそのまま数えられます。
:::

構造式は原子のつながり方だけを表したもので、分子の実際の形（折れ線・三角錐・正四面体）は表していません。分子の形は別のページで扱います。

:::section
anchor: electron-formula
title: 電子式の書き方 —— 構造式から直すのが楽
lead: 電子式は、不対電子どうしをくっつけて共有電子対をつくるパズルです。すべての原子が安定な電子配置（H は2個、ほかは8個）になっているかを確かめます。先に構造式を書いてから、結合の手を共有電子対に直すのが楽です。
terms:
- 電子式
:::

電子式を書く手順は、構造式とまったく同じ形です。

:::list
ordered: true
items:
- 不対電子どうしをくっつけて共有電子対をつくり、原子ごとのパーツを組み立てる。
- すべての原子について最外殻の電子の数を数え、安定な電子配置になっているか確かめる。
　H は2個、ほかの原子は8個
- 化学式と原子の数が合っているか確かめる。
:::

構造式の結合の手1本は、電子式の共有電子対1組と対応しています。そこで、**先に構造式を書いてから電子式に直す**のが楽です。

:::list
ordered: true
items:
- 構造式を書く。
　H−O−H
- 結合の手1本を、共有電子対（点2個）1組に置きかえる。
- 非共有電子対を足して、H 以外の原子が8個になるようにする。
　O は共有電子対2組（4個）に非共有電子対2組（4個）を足して8個
:::

⚠ 共有電子対・非共有電子対の数は、**分子全体で数える**のか**1つの原子のまわりで数える**のかで答えが変わります。問題文がどちらを聞いているかを必ず確かめましょう（上の表は分子全体の数です）。

:::mistake
wrong: 二酸化炭素の電子式は、O と C の間に共有電子対を1組ずつ置けばよい
right: 共有電子対1組ずつだと、C のまわりは 4個・O のまわりは 7個（不対電子が残る）になり、安定な電子配置になりません。構造式 O＝C＝O のとおり、**C と O の間に共有電子対を2組ずつ**置くと、3つの原子すべてが8個になります。
why: 電子式をいきなり点で書こうとすると、二重結合を見落としやすいためです。★ 先に構造式を書いて手の数を合わせておけば、この間違いは起こりません。
:::

:::section
anchor: coordinate
title: 配位結合 —— 結合の手の数が変わる
lead: 一方の原子の非共有電子対を、もう一方の原子（イオン）と共有してできる共有結合を配位結合といいます。できた結合は、ふつうの共有結合と区別がつきません。配位結合すると、原子の結合の手の数が変わります。
terms:
- 配位結合
- オキソニウムイオン
- アンモニウムイオン
:::

ふつうの共有結合は、2つの原子が**互いに**不対電子を出し合って共有電子対をつくります。一方、**配位結合**は、一方の原子の非共有電子対を、電子をもたない相手（H⁺ など）と共有してできます。結合のでき方は違いますが、**できた結合はふつうの共有結合と区別がつきません**。

具体例として、水分子 H₂O の O 原子には非共有電子対が2組あります。ここに H⁺ が来ると、非共有電子対の1組を H⁺ と共有して、**オキソニウムイオン H₃O⁺** になります。

:::figure
src: oxoacid-coordinate-bond.png
alt: 水分子の電子式と、水分子の O 原子の非共有電子対に H⁺ が結合してオキソニウムイオンになる電子式
caption: 水分子の O 原子の結合の手は2本ですが、オキソニウムイオンの O 原子の結合の手は3本になっています。
:::

同じように、アンモニア NH₃ の N 原子の非共有電子対に H⁺ が配位結合すると、**アンモニウムイオン NH₄⁺** になります。アンモニア分子の N 原子の結合の手は3本ですが、アンモニウムイオンの N 原子の結合の手は4本になっています。4本の N−H 結合は、どれが配位結合だったか区別がつきません。

:::table
caption: 配位結合で結合の手の数が変わる例
source: slides:無機の基本１ s9〜10 の2例を並べた
head:
- もとの分子
- 加わるもの
- できるイオン
- 中心の原子の手の数
align: left | left | left | left
rows:
- 水 H₂O | H⁺ | オキソニウムイオン H₃O⁺ | O：2本 → 3本
- アンモニア NH₃ | H⁺ | アンモニウムイオン NH₄⁺ | N：3本 → 4本
:::

⚠ NH₃ と NH₄⁺ は存在しますが、**NH₄ という分子は存在しません**。N の手は3本なので、中性の分子では H を4つつなげないためです。**簡単な化合物は、結合の手の数を考えて正しい化学式を書けるようにすることが重要**です。

H₃O⁺ と NH₄⁺ のほかにも、硫酸 H₂SO₄ や硝酸 HNO₃ など、配位結合をもつ分子やイオンはたくさんあります。金属イオンに分子やイオンが配位結合してできる錯イオンも、同じ仕組みです。**配位結合の例として、H₃O⁺ と NH₄⁺ の2つは電子式まで書けるようにしましょう。**硫酸・硝酸の配位結合は、構造式を読めれば十分です。
