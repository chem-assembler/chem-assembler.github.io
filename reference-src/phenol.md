**ヒドロキシ基 −OH がベンゼン環に直接結合した化合物**を**フェノール類**といいます。アルコールと同じ −OH をもちますが、付いている相手がベンゼン環なので、性質がはっきり変わります。

:::section
anchor: def
title: フェノール類とは
lead: −OH が環に直接付いていればフェノール類、環から離れた炭素に付いていればアルコールです。
terms:
- フェノール類
- フェノール
- ベンジルアルコール
:::

いちばん簡単なフェノール類が**フェノール C₆H₅OH** です。ベンゼン環の炭素に −OH が直接付いています。

:::figure
src: phenol-phenol.png
gen: name=フェノール plain
alt: フェノールの構造式。ベンゼン環の炭素1個にヒドロキシ基が直接結合している
caption: **フェノール C₆H₅OH**。−OH が環の炭素に**直接**付いています。
:::

一方、**ベンジルアルコール C₆H₅CH₂OH** は、−OH が環ではなく、環に付いた CH₂ の炭素に付いています。ベンゼン環をもっていても、これは**アルコール**です。

:::figure
src: phenol-benzyl-alcohol.png
gen: name=ベンジルアルコール plain
alt: ベンジルアルコールの構造式。ベンゼン環に CH₂ が付き、その炭素にヒドロキシ基が結合している
caption: **ベンジルアルコール C₆H₅CH₂OH**。−OH と環のあいだに CH₂ が1個はさまっているので、アルコールです。
:::

**「−OH が環に直接付いているかどうか」でフェノール類かアルコールかが決まる、と覚えてください。**分子式が同じ C₇H₈O でも、クレゾール（フェノール類）とベンジルアルコール（アルコール）は別の仲間です。

:::

:::section
anchor: props
title: フェノールの性質
lead: 特有のにおいをもつ無色の結晶。水に少し溶け、皮膚をおかします。

:::

フェノールは、**特有のにおいをもつ無色の結晶**です。水には**少しだけ**溶け、有機溶媒にはよく溶けます。**有毒で、皮膚をおかします**。

:::section
anchor: acidity
title: 弱い酸性 —— アルコールとの決定的な違い
lead: フェノール類の水溶液はごく弱い酸性を示します。アルコールの −OH は中性です。
terms:
- 弱酸
- ナトリウムフェノキシド
:::

フェノール類は、水溶液中で −OH の H がわずかに電離するので、**ごく弱い酸性**を示します。同じ −OH をもつ**アルコールは中性**で、ここがフェノール類とアルコールの決定的な違いです。

:::reaction
left: C₆H₅OH
right: C₆H₅O⁻ ＋ H⁺
level: ★★☆
note: ごくわずかに電離します。電離する度合いは、酢酸などのカルボン酸よりもずっと小さいです。
:::

**「アルコールの −OH は中性、フェノールの −OH は弱酸性」と覚えましょう。**フェノール類の性質は、ほとんどがこの1行から出てきます。

弱いとはいえ酸なので、水酸化ナトリウム水溶液とは**中和して塩**をつくります。

:::reaction
left: C₆H₅OH ＋ NaOH
right: C₆H₅ONa ＋ H₂O
level: ★★★
note: ナトリウムフェノキシドができます。塩になると水によく溶けるので、水に溶けにくいフェノールも NaOH 水溶液には溶けます。
:::

:::link
to: alcohol
text: 同じ −OH をもつアルコールが中性であることは、アルコールのページへ
:::

:::section
anchor: carbonic
title: 炭酸より弱い酸
lead: 酸の強さは「強酸 ＞ カルボン酸 ＞ 炭酸 ＞ フェノール」。この順番で NaHCO₃ と CO₂ への応じ方が決まります。
terms:
- 弱酸の遊離
- 炭酸水素ナトリウム
:::

弱酸の遊離は、**強いほうの酸が、塩から弱いほうの酸を追い出す**反応です。フェノールは**炭酸よりも弱い酸**なので、次の2つが決まります。

**「強酸 ＞ カルボン酸 ＞ 炭酸 ＞ フェノール」の順番は必ず暗記してください。**カルボン酸のページで出てきた順番の、いちばん右にフェノールを足したものです。

:::reaction
left: C₆H₅OH ＋ NaHCO₃
right: 反応しない
level: ★★★
note: フェノールは炭酸より弱いので、炭酸水素ナトリウムから炭酸を追い出せません。CO₂ が出ないことが、カルボン酸との見分けになります。
:::

:::reaction
left: C₆H₅ONa ＋ CO₂ ＋ H₂O
right: C₆H₅OH ＋ NaHCO₃
level: ★★★
note: 逆向きは進みます。炭酸のほうが強い酸なので、ナトリウムフェノキシドの水溶液に CO₂ を吹き込むと、フェノールが遊離して白く濁ります。
:::

:::mistake
wrong: フェノールは酸なので、炭酸水素ナトリウム水溶液に溶けて二酸化炭素を出す。
right: フェノールは炭酸より弱い酸なので、炭酸水素ナトリウムとは反応せず、CO₂ は出ない。CO₂ を出して溶けるのはカルボン酸。
why: 「酸だから NaHCO₃ と反応する」と覚えていると、酸の強さの順番が抜けます。
:::

:::link
to: carboxylic-acid
text: 「強酸 ＞ カルボン酸 ＞ 炭酸」の順番と弱酸の遊離は、カルボン酸のページへ
:::

:::section
anchor: sodium
title: ナトリウムとの反応
lead: 金属ナトリウムと反応して水素を出します。これはアルコールでも起こるので、区別には使えません。
terms:
- 金属ナトリウム
:::

フェノールは、金属ナトリウムと反応して**水素を発生**し、ナトリウムフェノキシドになります。

:::reaction
left: 2C₆H₅OH ＋ 2Na
right: 2C₆H₅ONa ＋ H₂
level: ★★☆
note: −OH をもつ化合物に共通の反応で、アルコールでも同じように水素が出ます。
:::

**ナトリウムとの反応では、アルコールとフェノール類を区別できません。**区別するときは、NaOH 水溶液に溶けるか、塩化鉄(III) で呈色するかを使います。

:::

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: draft:reference-outline/aromatic.md の phenol の例題1（酸の強さの順番と NaHCO₃ への応じ方から作った問い。どの本の問題も見ていない）
prompt: フェノール・安息香酸・ベンジルアルコールの3つを、炭酸水素ナトリウム水溶液だけで見分けられるか。
answer: **安息香酸だけが見分けられます**（CO₂ を出して溶けます）。フェノールもベンジルアルコールも炭酸水素ナトリウムとは反応しないので、この試薬だけでは2つを分けられません。残る2つは、塩化鉄(III) で呈色するか（フェノール）で分けます。
:::

:::exercise
source: draft:reference-outline/aromatic.md の phenol の例題2（ナトリウムフェノキシドと CO₂ の弱酸の遊離から作った問い）
prompt: ナトリウムフェノキシドの水溶液に二酸化炭素を吹き込むと、白く濁った。このときの反応式を書け。
answer: C₆H₅ONa ＋ CO₂ ＋ H₂O → C₆H₅OH ＋ NaHCO₃ です。炭酸のほうがフェノールより強い酸なので、水に溶けにくいフェノールが遊離して濁ります。
:::
