芳香族化合物の混合物は、**分液漏斗**を使って分けます。水に溶けにくい有機化合物も、**塩にすると水に溶ける**ようになるので、この性質を使って、1つずつ水の層へ移していきます。

:::section
anchor: principle
title: 原理は1行
lead: 塩にすると水層へ移り、遊離させるとエーテル層へ戻ります。酸性の物質は塩基で、塩基性の物質は酸で塩にします。
terms:
- 分液漏斗
- 水層
- エーテル層
codes:
- org.aroN.separation-principle
- org.aroN.separatory-funnel
:::

芳香族化合物の混合物をジエチルエーテルに溶かし、分液漏斗に入れて水溶液と一緒に振ると、液は**2つの層**に分かれます。ジエチルエーテルは水より軽いので、**上がエーテル層、下が水層**です。

**「塩にすると水層へ移り、遊離させるとエーテル層へ戻る」と覚えましょう。**分離の問題は、ほとんどこの1行で解けます。

:::list
items:
- 酸性の物質（カルボン酸・フェノール類）は、**塩基**を加えて塩にする。
- 塩基性の物質（アニリン）は、**酸**を加えて塩にする。
- 中性の物質（ニトロベンゼンなど）は、何を加えても塩にならず、**エーテル層に残る**。
:::

caption: **ニトロベンゼン C₆H₅NO₂**。酸でも塩基でもないので、何を加えても塩にならず、最後までエーテル層に残ります。

:::section
anchor: base
title: 塩基性の物質（アニリン）を分ける
lead: 塩酸を加えると、アニリンだけが塩になって水層へ移ります。
terms:
- アニリン塩酸塩
:::

混合物のエーテル溶液に**塩酸**を加えて振ると、塩基性のアニリンだけが中和されて**アニリン塩酸塩**になり、**水層へ**移ります。

:::reaction
left: C₆H₅NH₂ ＋ HCl
right: C₆H₅NH₃Cl
gen: アニリン ＋ 塩化水素 → アニリン塩酸塩
app: amine_hcl
level: ★★★
note: アニリンが塩になって水層へ移ります。酸性の物質と中性の物質はエーテル層に残ります。
:::

:::figure
src: aromatic-separation-aniline-salt.png
gen: name=アニリン plain
gen: name=アニリン塩酸塩 plain
between: kind=矢印 at=1 to=2 label=＋HCl
alt: 左にアニリン、右にアニリン塩酸塩の構造式を並べ、間を「＋HCl」の矢印でつないだ図。アミノ基 −NH₂ が −NH₃⁺ になり、そばに Cl⁻ がある
caption: アミノ基 −NH₂ が H⁺ を受け取って **−NH₃⁺** になり、Cl⁻ と組んだ塩になります。**イオンになったので水に溶け**、水層へ移ります。
:::

取り出した水層に NaOH 水溶液を加えると、アニリンが遊離します。そこにエーテルを加えて振れば、アニリンを**エーテル層へ戻して**取り出せます。

:::reaction
left: C₆H₅NH₃Cl ＋ NaOH
right: C₆H₅NH₂ ＋ NaCl ＋ H₂O
level: ★★★
note: アニリンが遊離して、エーテル層へ戻せるようになります。
:::

to: aniline
text: アニリンの塩基性と塩のでき方は、アニリンのページへ
:::

:::section
anchor: acid
title: 酸性の物質を強さの差で2段に分ける
lead: 先に NaHCO₃ でカルボン酸だけを、次に NaOH でフェノール類を水層へ移します。順番を逆にすると分けられません。
terms:
- 炭酸水素ナトリウム
- 水酸化ナトリウム
- 弱酸の遊離
codes:
- org.aroN.separation-order
- org.phenol.separation
- org.aroN.separation-recover
:::

カルボン酸とフェノール類はどちらも酸性ですが、**カルボン酸は炭酸より強く、フェノール類は炭酸より弱い**酸です。この差を使うと、2つを別々に水層へ移せます。

:::list
ordered: true
items:
- 炭酸水素ナトリウム水溶液を加えて振る。
　炭酸より強いカルボン酸だけが塩になって水層へ移る（CO₂ が出る）
- 残ったエーテル層に、水酸化ナトリウム水溶液を加えて振る。
　フェノール類が塩になって水層へ移る
- 最後までエーテル層に残ったものが、中性の物質。
:::

:::reaction
left: C₆H₅COOH ＋ NaHCO₃
right: C₆H₅COONa ＋ H₂O ＋ CO₂↑
gen: 安息香酸 ＋ 炭酸水素ナトリウム → 安息香酸ナトリウム ＋ 水 ＋ 二酸化炭素
app: neutralize_nahco3
level: ★★★
note: ①安息香酸は炭酸より強い酸なので、炭酸水素ナトリウムでも塩になります。
:::

:::reaction
left: C₆H₅OH ＋ NaOH
right: C₆H₅ONa ＋ H₂O
gen: フェノール ＋ 水酸化ナトリウム → ナトリウムフェノキシド ＋ 水
app: neutralize_naoh
level: ★★★
note: ②フェノールは炭酸より弱いので ①では動かず、NaOH を加えて初めて塩になります。
:::

水層へ移したものは、最後に**塩酸などの強い酸を加えて遊離させてから**取り出します。

:::reaction
left: C₆H₅COONa ＋ HCl
right: C₆H₅COOH ＋ NaCl
level: ★★★
note: 安息香酸が遊離します。ナトリウムフェノキシドも、塩酸か CO₂ で同じようにフェノールに戻せます。
:::

**「NaHCO₃ で水層へ移るのはカルボン酸だけ」は必ず覚えてください。**試薬の濃度や、振る回数は覚えなくて構いません。

:::mistake
wrong: 酸性の物質はどれも NaOH で水層へ移せるので、最初に NaOH を加えればよい。
right: NaOH はカルボン酸もフェノール類も両方塩にするので、先に使うと2つが同じ水層に入って分けられない。先に NaHCO₃ でカルボン酸だけを移す。
why: 「弱いほうの試薬から使う」という順番の理由が抜けると、手順を丸暗記しても入れ替えてしまいます。
:::

to: phenol
text: フェノールが炭酸より弱い酸であることは、フェノール類のページへ
:::

:::link
to: carboxylic-acid
text: カルボン酸が炭酸より強い酸であることは、カルボン酸のページへ
:::

安息香酸・フェノール・アニリン・ニトロベンゼンの4つを溶かしたエーテル溶液を、次の順に分けます。

:::table
caption: 4成分を分ける操作
source: 上の原理（塩にすると水層へ）と、酸・塩基の強さの順番（カルボン酸 ＞ 炭酸 ＞ フェノール、アニリンは塩基）から出る行。一問一答の知識項目 org.aroN.separation-order と同じ中身で、どの本の表も見ていない
head:
- 操作
- 水層へ移るもの
- エーテル層に残るもの
align: left | left | left
rows:
- ① **塩酸**を加える | **アニリン**（アニリン塩酸塩） | 安息香酸・フェノール・ニトロベンゼン
- ② **NaHCO₃ 水溶液**を加える | **安息香酸**（安息香酸ナトリウム） | フェノール・ニトロベンゼン
- ③ **NaOH 水溶液**を加える | **フェノール**（ナトリウムフェノキシド） | **ニトロベンゼン**
:::

:::figure
src: aromatic-separation-tree.png
svg: aromatic-separation-tree.svg
alt: 上から下へ3段に分かれる樹形図。左の縦の流れがエーテル層で、4成分から1つずつ減って最後にニトロベンゼンだけが残る。各段から右へ矢印が出て、塩酸でアニリン塩酸塩、炭酸水素ナトリウムで安息香酸ナトリウム、水酸化ナトリウムでナトリウムフェノキシドが水層へ移ることを示している
caption: **まっすぐ下がエーテル層、右へ出るのが水層**です。水層へ移した塩は、酸や塩基を加えて遊離させれば元の物質に戻せます。
:::

①の塩酸を最初に使うのは、アニリンだけを先に抜いておくためです。②と③の順番は入れ替えられませんが、①は②③の後にしても分けられます。

## 例題 —— 4成分を分けてみる

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: draft:reference-outline/aromatic.md の aromatic-separation の例題1（4成分の分離の表から作った問い。どの本の問題も見ていない）
prompt: 安息香酸・フェノール・アニリン・ニトロベンゼンを溶かしたエーテル溶液がある。この4つを分けるための操作を、順に答えよ。
answer: ① 塩酸を加えて振ると、**アニリン**が塩になって水層へ移る（NaOH で遊離させて回収）。② 残ったエーテル層に **NaHCO₃ 水溶液**を加えると、**安息香酸**が水層へ移る（塩酸で遊離）。③ さらに **NaOH 水溶液**を加えると、**フェノール**が水層へ移る（塩酸か CO₂ で遊離）。④ 最後にエーテル層に残るのが**ニトロベンゼン**。
:::

:::exercise
source: draft:reference-outline/aromatic.md の aromatic-separation の例題2（NaHCO₃ と NaOH の順番の理由から作った問い）
prompt: 上の操作の②と③の順番を入れ替えると、どうなるか。
answer: NaOH は**安息香酸もフェノールも両方**塩にしてしまうので、2つが同じ水層に入って分けられなくなります。酸の強さの差を使うには、**弱い塩基の NaHCO₃ から先に**使います。
:::
