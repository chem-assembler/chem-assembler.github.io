酸化数は、原子が酸化されたか還元されたかを数で表したものです。酸化剤・還元剤の判定と、半反応式の e⁻ の数を決めるときに使います。

:::link
to: redox-basics
text: 酸化数が減った原子を含む物質が酸化剤、増えた原子を含む物質が還元剤（「酸化と還元」）
:::

:::section

- 酸化数
:::

「単体の状態を基準（酸化数0）に、原子が失った電子 e⁻ の数」を酸化数といいます。

## 単原子イオンの場合

単原子イオンの酸化数は、**イオンの電荷と一致します**。

:::reaction
left: Na
right: Na⁺ ＋ e⁻
level: ★★★
note: 単体の Na（酸化数 0）の Na 原子は、電子を1個失って Na⁺（酸化数 ＋1）になりました。
:::

:::reaction
left: Cl₂ ＋ 2e⁻
right: 2Cl⁻
level: ★★★
note: 単体の Cl₂（酸化数 0）の Cl 原子は、電子を1個受け取って Cl⁻（酸化数 −1）になりました。「−1 個失った」と考えるので −1 です。
:::

## 多原子イオン・化合物の場合

多原子イオンや化合物は、「**すべての原子が単原子イオンに電離したと（仮想的に）考えたときの電荷**」を酸化数とします。そのため、**多原子イオンの各原子の酸化数の合計は、イオンの電荷と一致します**（化合物なら合計は 0）。

硫酸イオン SO₄²⁻ なら、S⁶⁺ ＋ 4O²⁻ に電離したと考えます。

　−2（イオンの電荷）＝ 1×(＋6) ＋ 4×(−2)（各原子の酸化数の合計）

したがって S の酸化数は ＋6 です。

- O | −2 | H₂O₂ など過酸化物の中では −1

:::list
ordered: true
items:
- 電離できるものは、まず電離する。
　Cu(NO₃)₂ → Cu²⁺ ＋ 2NO₃⁻
- 単原子イオンの酸化数は、電荷と一致させる。
　Cu²⁺ の Cu は ＋2
- 多原子イオンはさらに単原子イオンに（仮想的に）分け、酸化数がわかる原子から決める。
　NO₃⁻ → N○○ ＋ 3O²⁻ として、O は −2
- イオン全体の電荷を合わせて、残りの原子の酸化数を決める。
　−1 ＝ (N の酸化数) ＋ 3×(−2) より、N は ＋5
:::

:::mistake
wrong: 化合物の中の O は、いつでも酸化数 −2 である
right: 過酸化水素 H₂O₂ のような**過酸化物の中の O は −1** です。
why: 表で O より上にある H（＋1）が先に決まるためです。H₂O₂ は H が2個で ＋2、全体は 0 なので、O 2個で −2、つまり O 1個あたり −1 になります。同じ理由で、NaH の H は、表で上にある Na（＋1）が先に決まるので −1 になります。
:::

:::section
anchor: electronegativity
title: 電気陰性度から決める —— なぜ H は ＋1、O は −2 なのか
lead: 共有電子対は、少しでも強く引きつけている原子がすべてもっていると判定します。
terms:
- 電気陰性度
- 共有電子対
:::

電気陰性度は「共有結合した原子が共有電子対を引きつける力の強さ」です。**酸化数を決めるときは、共有電子対は少しでも強く引きつけている原子がすべてもっている**と判定します。

主な元素の電気陰性度の順は次のとおりです。

　F（4.0）＞ O（3.4）＞ Cl（3.2）＞ N（3.0）＞ C（2.6）など ＞ H（2.2）＞ ふつうの金属 ＞ アルカリ土類金属・アルカリ金属

:::figure
src: water-electron-pull.png
svg: water-electron-pull.svg
alt: 水分子の電子式の図。O と2つの H を結ぶ共有電子対の点が、どちらも O 側に寄せて描かれ、O と4組の電子をまとめて破線で囲んである。O に酸化数 −2、2つの H にそれぞれ ＋1 と書かれている
caption: 共有電子対を O のものとして数えると、O は電子を2個多くもった形（−2）、H は自分の電子をとられた形（＋1）になります。
:::

## 水 H₂O の場合

O の電気陰性度は 3.4、H は 2.2 なので、O−H の共有電子対は O 側に偏ります。O は両側の H から1個ずつ、合計2個の e⁻ をとったと考えるので**酸化数 −2**（O²⁻ と同じ状態）、H は自分の e⁻ をとられたので**酸化数 ＋1**（H⁺ と同じ状態）です。

## 単体の酸化数が 0 である理由

単体は同じ元素どうし（電気陰性度が等しい）が結合しているので、共有電子対は2つの原子のど真ん中に位置し、それぞれの原子がもっている e⁻ の数は変わりません。そのため**単体の原子の酸化数は 0** です。

## 例外が起こる理由

H は非金属元素の中で電気陰性度が事実上最小なので、他の非金属と結合すると e⁻ をとられて ＋1 になります。一方、H は金属より電気陰性度が大きいので、NaH のように**金属と結合すると e⁻ を1個とって −1** になります。

過酸化水素 H−O−O−H では、O−H の共有電子対は O 側に偏りますが、O−O の共有電子対は同じ元素どうしなのでど真ん中です。O は H から1個しか e⁻ をとっていないので**酸化数 −1** になります。

優先順位の表は丸暗記でも使えますが、**電気陰性度の大小から導けるようにしておくと、表に無い化合物にも対応できます**。

:::section
anchor: max
title: 最高酸化数
lead: 典型元素の最高酸化数は、価電子の数（族番号の一の位）と一致します。
terms:
- 最高酸化数
:::

酸化数は「原子が失った電子の数」なので、価電子をすべて失った状態がいちばん大きい酸化数になります。**典型元素の最高酸化数は、価電子の数（族番号の一の位）と一致します**。

## 具体例 —— 硫黄 S（16族）

S は16族なので価電子は6個あり、すべてを他の原子にとられた状態が ＋6（最高酸化数）です。

:::section
anchor: organic
title: 有機化合物の中の炭素の酸化数
lead: 有機化合物の炭素は、原子ごとに酸化数が違います。結合ごとに電気陰性度で e⁻ の行き先を決めます。
terms:
- 有機化合物の酸化数
:::

有機化合物は電離しないので、優先順位の表ではなく、**結合1本ごとに電気陰性度で共有電子対の行き先を決めて**数えます。電気陰性度は H（2.2）＜ C（2.6）＜ O（3.4）です。

:::list
items:
- C−H の共有電子対は C 側に偏っており、C が e⁻ を1個得る（−1）
- C−C の共有電子対はど真ん中に位置し、e⁻ のやりとりはない（0）
- C−O の共有電子対は O 側に偏っており、C が e⁻ を1個失う（＋1）。C=O なら2個失う（＋2）
:::

## 具体例 —— 酢酸 CH₃−COOH

メチル基の C は、3個の H から合計3個の e⁻ をとっているので**酸化数 −3**です。カルボキシ基の C は、C=O で2個、C−O で1個、合わせて3個の e⁻ を O にとられているので**酸化数 ＋3**です。

:::figure
src: acetic-acid-oxidation-number.png
svg: acetic-acid-oxidation-number.svg
alt: 酢酸の構造式の図。左のメチル基の炭素では3本の C−H の矢印がどれも C を向き、右のカルボキシ基の炭素では C=O と C−O の矢印が O を向いている。C−C には矢印がない。左の C に −3、右の C に ＋3 と書かれている
caption: 矢印は共有電子対が寄るほうを指しています。C に向いた矢印1本が −1、C から出た矢印1本が ＋1 で、数えた本数がそのまま酸化数です。
:::

## アルコールの酸化との関係

エタノール CH₃CH₂OH の −OH が付いた C は −1、アセトアルデヒド CH₃CHO の −CHO の C は ＋1、酢酸 CH₃COOH の −COOH の C は ＋3 です。アルコールを酸化すると、**−OH が付いた炭素の酸化数が2ずつ増えていきます**。

answer: **(1) ＋6　(2) ＋6　(3) −1　(4) ＋5　(5) −1** です。(1) S⁶⁺ ＋ 4O²⁻ と分けて −2 ＝ (S) ＋ 4×(−2) より ＋6。(2) まず Na⁺ ＋ H⁺ ＋ SO₄²⁻ に電離するので、S は (1) と同じ SO₄²⁻ の中の S で ＋6。(3) Na⁺ ＋ H⁻ に電離するので H は −1（金属と結合した H）。(4) H⁺ ＋ ClO₃⁻ に電離し、ClO₃⁻ → Cl⁵⁺ ＋ 3O²⁻ と分けて ＋5。(5) 2H⁺ ＋ 2O⁻ と分けて −1（過酸化物の O）。
:::
