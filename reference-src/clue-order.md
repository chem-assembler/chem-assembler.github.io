構造決定の問題は、条件に合う構造を当てにいくのではなく、**候補を減らしていく消去法**で解きます。分子式が決まれば、考えられる構造は有限個に限られます。条件を1つ使うたびに、その中から合わないものを外していきます。

:::section
anchor: order
title: 使う順番は「分類 → 数 → 物性」
lead: 官能基や液性で大きく削り、分子式で枠を切り、沸点や見た目で最後の1つに決めます。
terms:
- 構造決定
- 分類
- 物性
:::

条件は次の3段に分けて、上から順に使います。

:::table
caption: 手がかりの3段

head:
- 段
- 見るもの
- 条件の例
- 効き方
align: left | left | left | left
rows:
- **① 分類** | 官能基・液性・検出反応 | Na を加えると H₂ が発生した（−OH）／銀鏡反応を示した（−CHO）／NaHCO₃ 水溶液で CO₂ が発生した（−COOH） | **いちばん大きく削る**
- **② 数** | 分子式・分子量・不飽和度 | 分子式 C₄H₁₀O なら候補は7通り／不飽和度1なら C=C か環が1つ | 候補の枠を決める
- **③ 物性** | 沸点・融点・見た目・におい | 沸点34℃の液体（ジエチルエーテル） | **最後の1手・検算**
:::

**「分類 → 数 → 物性」の3語は覚えておきましょう。**問題文に書かれた順ではなく、この順に並べ替えてから使うと、書き出す候補が少なくて済みます。

:::section
anchor: reorder
title: 同じ条件でも、置く順で途中の候補数が変わる
lead: 最後に残る構造は順番によらず同じです。変わるのは、途中で書き出す候補の数です。
:::

問題文に、使わなくても答えが決まる条件が残ることがあります。**余った条件は、答えを確かめるために置かれている**と読んで構いません。

:::section
anchor: when-ea
title: 元素分析の結果はいつ使うか
lead: 問題文の先頭にあっても、先に使わなければいけないわけではありません。他の条件で決まったあとの検算に回せます。
:::

構造決定の問題は、元素分析の質量から始まることが多くあります。ただし、ほかの条件（分子量・Na との反応・酸化の結果など）で骨格が決まることも多く、そのとき元素分析の結果は「決めた構造と合っているか」の確かめになります。

使う順番を入れ替えても、残る構造は同じです。決めた分子式から燃焼で出る CO₂ と H₂O の質量を逆に計算して、問題の値と合えば確かめになります。下の例題1で、実際に両方の順で通します。

:::section
anchor: dou
title: 数から当たりを付ける（1）不飽和度
lead: 分子式から不飽和度を出すと、C=C や環がいくつあるか、候補が何通りあるかが見えます。
terms:
- 不飽和度
:::

分子式 C~m~H~n~O~k~N~l~ の不飽和度は、次の式で出せます（O の数は式に入りません）。

:::callout
tone: memorize
text: 不飽和度 ＝ (2 × C の数 ＋ 2 ＋ N の数 − H の数) ÷ 2
:::

たとえば C₅H₁₀ なら (2×5 ＋ 2 − 10) ÷ 2 ＝ 1 です。不飽和度1は「C=C が1つ」か「環が1つ」を表すので、構造異性体はアルケン5通りとシクロアルカン5通りの計10通りになります。

:::table
caption: 分子式から不飽和度と候補を出す
source: 不飽和度の式に分子式を代入した計算と、構造異性体の数（手で数えた値。立体異性体は分けていない）
head:
- 分子式
- 不飽和度
- 考えられる構造
align: left | right | left
rows:
- C₄H₁₀O | 0 | 二重結合も環も無い。アルコール4通り・エーテル3通りの計7通り
- C₅H₁₀ | 1 | C=C が1つ（アルケン5通り）か、環が1つ（シクロアルカン5通り）
- C₆H₆ | 4 | ベンゼン環1つ（環1 ＋ C=C 3つ）で説明が付く
:::

:::section
anchor: nitrogen-rule
title: 数から当たりを付ける（2）窒素則
lead: C・H・O・N だけの化合物では、分子量が奇数なら窒素は奇数個、偶数なら偶数個です。
terms:
- 窒素則
:::

C・H・O・N だけからなる化合物では、**分子量の偶奇と窒素原子の数の偶奇が一致します**。これを窒素則といいます。

:::list
items:
- 分子量が**奇数** → 窒素原子は**奇数個**（ふつうは1個）
- 分子量が**偶数** → 窒素原子は**偶数個**（0個もふくむ）
:::

たとえば α-アミノ酸で分子量が146（偶数）なら、窒素は偶数個です。アミノ酸は −NH₂ を必ずもつので0個ではなく、**2個**と決まります。高校でよく扱うアミノ酸なら、リシン C₆H₁₄N₂O₂ です。窒素が1個のグリシン（75）やアラニン（89）は、分子量が奇数になっています。

窒素則が成り立つのは、次の2つが同じ条件だからです。分子量 ＝ 12×C ＋ 1×H ＋ 16×O ＋ 14×N で、12・16・14 はどれも偶数なので、分子量の偶奇は H の数の偶奇と同じです。また、不飽和度が整数になるには、H の数と N の数の偶奇がそろっている必要があります。

**窒素則は覚えておくと速い規則です。**毎回導くこともできますが、「奇数なら N は奇数個」と覚えてしまいましょう。ただし、塩素などのハロゲンを含む化合物には使えません。

:::link
to: amino-acid
text: アミノ酸の種類と分子量はアミノ酸のページへ
:::

:::section
anchor: ratio
title: 数から当たりを付ける（3）組成式
lead: 組成式から物質を当てにいけるのは例外的です。CHO ならブテン二酸、CH₂O は分子量を待ちます。
:::

組成式だけで物質を当てにいけるのは、ごく限られた場合です。

組成式が **CHO**（C : H : O ＝ 1 : 1 : 1）のときは、まずブテン二酸 C₄H₄O₄（マレイン酸・フマル酸）を疑います。**「CHO ならブテン二酸」は覚えておきましょう。**

組成式が **CH₂O** のときは、ホルムアルデヒド HCHO（30）・酢酸 CH₃COOH（60）・乳酸（90）・グルコース（180）のように多くの化合物が当てはまり、**組成式だけでは決まりません**。分子量の条件を待ちます。

:::link
to: carboxylic-acid
text: マレイン酸・フマル酸の性質はカルボン酸のページへ
:::

**IR の波数や NMR の ppm の数値は覚えなくて構いません。**信号の数と面積比が読めれば十分です。

:::section
anchor: range
title: 覚える範囲
lead: 3段の順番・窒素則・「CHO ならブテン二酸」は覚え、そのほかの組成式の型と機器の数値は覚えなくて構いません。
:::

**「分類 → 数 → 物性」の3語は覚えてください。**順番そのものは、例題を通して手順として身につけましょう。

**窒素則と「CHO ならブテン二酸」も覚えておきましょう。**どちらも条件1つで候補が一気に減ります。

これ以外の組成式から物質を当てる型は、**覚えなくても構いません**。分子量の条件を待てば決まります。

## 例題

:::exercise
source: 自作（qa:org.clue.order の考え方で、C₄H₁₀O の元素分析・分子量・Na との反応・酸化の4条件を組んだもの。数値は検算済み）
prompt: C・H・O からなる化合物 A 7.4 mg を完全燃焼させると、CO₂ 17.6 mg と H₂O 9.0 mg が生じた。A の分子量は 74 である。A にナトリウムを加えると水素が発生し、A を酸化するとケトンが得られた。A の構造式を示性式で書け。（H=1.0、C=12、O=16）
answer: 分類から使うと、Na で H₂ が発生 → −OH をもつアルコール。酸化してケトン → 第二級アルコール。数の段では、分子量74 で C・H・O のアルコールなら C₄H₁₀O（12×4 ＋ 1.0×10 ＋ 16 ＝ 74）。C₄H₁₀O のアルコール4通りのうち第二級は1つだけなので、A は **CH₃CH(OH)CH₂CH₃**（2-ブタノール）。最後に元素分析で確かめると、C 17.6×12/44 ＝ 4.8 mg、H 9.0×2.0/18 ＝ 1.0 mg、O 7.4 − 4.8 − 1.0 ＝ 1.6 mg で、C : H : O ＝ 0.40 : 1.0 : 0.10 ＝ 4 : 10 : 1。C₄H₁₀O と合います。元素分析から先に使っても、同じ答えに着きます。
:::

:::exercise
source: 自作（qa:org.clue.nitrogen-parity, org.clue.amino-acid-mw-parity の組み合わせ）
prompt: C・H・O・N からなる化合物の分子量が 89 であった。この化合物に含まれる窒素原子の数について言えることを答えよ。また、この化合物が α-アミノ酸であるとき、その名称を答えよ。
answer: 分子量が奇数なので、窒素原子は奇数個（ふつうは1個）です。分子量89 の α-アミノ酸は**アラニン** CH₃CH(NH₂)COOH です。
:::

:::exercise
source: 自作（不飽和度の式と、C₅H₁₀ の構造異性体の数え上げ）
prompt: 分子式 C₅H₁₀ の化合物の不飽和度を求め、考えられる構造の型と、構造異性体の数を答えよ。
answer: 不飽和度は (2×5 ＋ 2 − 10) ÷ 2 ＝ 1。C=C を1つもつ鎖式のアルケンが5通り、環を1つもつシクロアルカンが5通りで、構造異性体は計10通りです（2-ペンテンのシス−トランスを分けて数えるとアルケンは6通り）。ここで「臭素水を脱色した」という条件が加われば、アルケン側に絞れます。
:::
