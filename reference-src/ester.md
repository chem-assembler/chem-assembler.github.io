カルボン酸とアルコールから水がとれて縮合した化合物を**エステル**といい、そのときできる −COO− の結合を**エステル結合**といいます。

:::section
anchor: props
title: エステルの性質
lead: カルボン酸と同じ一般式をもち、果実のような芳香がある無極性の液体です。
terms:
- エステル
- エステル結合
- 一般式
- 構造異性体
:::

鎖式で不飽和結合をもたないエステルの一般式は **C~n~H~2n~O~2~** です。n = 3 を代入すると C₃H₆O₂ ＝ 酢酸メチル CH₃COOCH₃ の分子式が得られます。

カルボン酸も同じ一般式 C~n~H~2n~O~2~ をもつので、**同じ分子式のエステルとカルボン酸は互いに構造異性体**です。分子式 C~n~H~2n~O~2~ を見たら、カルボン酸とエステルの両方を候補に入れてください。

エステルは**果実のような芳香**をもつ液体です。実際に果実の香りの成分として含まれています。酢酸エチル CH₃COOC₂H₅ は無色の液体で、溶媒や香料に使われます。

エステルは無極性分子なので分子間力が弱く、**沸点が低い**です。同じ理由でほとんど水に溶けないと考えてよく、炭素数の少ないエステルだけがある程度水に溶けます。

カルボン酸は加水分解を起こしませんが、**エステルは加水分解してアルコールとカルボン酸にもどります**。この違いが構造決定の出発点になります。

## なぜカルボン酸とエステルの一般式が同じになるのか

どちらも**カルボニル化合物 C~n~H~2n~O に O 原子を1個入れた構造**をしています。入れる場所が違うだけです。

:::list
ordered: true
items:
- カルボニル基と H 原子の間に O 原子を入れる → **カルボン酸**になる。
　アルデヒド R−CHO の C と H の間に O が入って R−COOH
- カルボニル基と C 原子の間に O 原子を入れる → **エステル**になる。
　アルデヒド R−CHO の C と R の間に O が入って R′−COO−R
:::

どちらも C~n~H~2n~O に O が1個増えただけなので、一般式は C~n~H~2n~O~2~ になります。

別の数え方もできます。エステルは2つのアルキル基 −C~a~H~2a+1~ と −C~b~H~2b+1~ がエステル結合でつながった形なので、分子式は C~a+b+1~H~2(a+b+1)~O~2~ となり、n = a＋b＋1 と置けば C~n~H~2n~O~2~ になります。**この導出を覚える必要はありません。**一般式そのものは覚えてください。

:::section
anchor: naming
title: エステルの命名
lead: 「カルボン酸の名前」＋「アルコールから来たアルキル基の名前」をつなぐだけです。
terms:
- 酢酸エチル
- ギ酸メチル
:::

エステルの名称は「**（カルボン酸の名称）＋（カルボン酸の H 原子を置換したアルキル基の名称）**」です。カルボン酸の名前を慣用名で覚えているので、エステルの名前も慣用名でよいです。

:::list
ordered: true
items:
- エステル結合 −COO− の**左側（C=O のある側）**がカルボン酸から来た部分。その名前を前に置く。
　カルボン酸が酢酸なら「**酢酸**○○」、ギ酸なら「**ギ酸**○○」
- エステル結合の**右側（O から炭素へ伸びる側）**がアルコールから来た部分。そのアルキル基の名前を後ろに置く。
　メタノール由来なら「○○**メチル**」、エタノール由来なら「○○**エチル**」
:::

酢酸とエタノールからできるエステルなら、前が「酢酸」、後ろが「エチル」で、**酢酸エチル**になります。

:::figure
src: ester-naming.png
alt: ギ酸メチルと酢酸エチルの構造式。カルボン酸から来た部分が青、アルコールから来たアルキル基が緑で塗り分けられ、下にメタン酸メチル（ギ酸メチル）・エタン酸エチル（酢酸エチル）と書かれている
caption: **青がカルボン酸から来た部分、緑がアルコールから来た部分**です。名前も青・緑の順に読みます。
:::

**エステルの名前は、構造式を見て言えるようにしてください。**構造決定の答案では、名前ではなく構造式で答えることが多いので、逆向き（名前から構造式）も書けるようにしておくと安全です。

:::section
anchor: reaction
title: エステル化・加水分解・けん化
lead: 同じ反応を右へ進めるか左へ進めるか、そして左へ進めて止める方法。3本で1組です。
terms:
- エステル化
- 加水分解
- けん化
:::

カルボン酸 R−COOH とアルコール R′−OH の混合物に、触媒として少量の**濃硫酸**を加えて加熱すると、脱水縮合してエステルが生じます。これを**エステル化**といいます。

:::reaction
left: R−COOH ＋ R′−OH
over: 濃硫酸
under: 加熱
right: R−COO−R′ ＋ H₂O
level: ★★★
note: 触媒としてはたらくのは水素イオン H⁺ です。濃硫酸を使うのは、脱水作用で生じた水を取り除いて平衡を右へ寄せ、エステルの収率を上げるためです。
:::

:::figure
src: esterification.png
alt: カルボン酸とアルコールが脱水縮合してエステルと水になる反応の構造式。カルボン酸の OH とアルコールの H が橙色の枠で囲まれ、そこから矢印が右端の H₂O を指している
caption: とれるのは、**カルボン酸の −OH** と**アルコールの −H** です。向きを逆に覚えないでください。
:::

**「カルボン酸から OH、アルコールから H がとれる」は丸暗記してください。**反応の仕組みの上でそう決まっているもので、どちらの原子が水になったかを問う問題がよく登場します。

逆向きに進めると**加水分解**です。エステルに希硫酸などの酸を触媒として水を加えると、カルボン酸とアルコールにもどります。

:::reaction
left: R−COO−R′ ＋ H₂O
over: 希硫酸
right: R−COOH ＋ R′−OH
level: ★★★
note: エステル化とまったく同じ反応を左向きに進めたものなので、可逆反応です。だから完全にはもどりきりません。
:::

エステルに**水酸化ナトリウム水溶液**を加えて加熱すると、カルボン酸の塩とアルコールに分かれます。これを**けん化**といいます。

:::reaction
left: R−COO−R′ ＋ NaOH
over: 加熱
right: R−COONa ＋ R′−OH
level: ★★★
note: 生じたカルボン酸がその場で中和されて塩になるので、逆反応が起こりません。だから最後まで進みます。
:::

**「加水分解は可逆、けん化は最後まで進む」と覚えましょう。**同じ「エステルを切る」操作でも、酸を使うか塩基を使うかで結果が変わります。

## ギ酸エステルは還元性を示す

ギ酸エステル **HCOO−R** は、エステルでありながら**銀鏡反応を示します**。HCOO− の H−C=O の部分が、そのままホルミル基のかたちになっているためです。

**「還元性を示すのは、アルデヒドとギ酸とギ酸エステル」と覚えてください。**「エステルだから還元性は無い」として候補から外すと、構造決定で答えが出なくなります。分子式から異性体を書き出すときは、ギ酸エステルを最初から候補に入れてください。

:::section
anchor: structure
title: エステルの構造決定
lead: エステルはまず切る。切って出てきたアルコールとカルボン酸に、条件を当てていきます。
terms:
- 構造決定
- ヨードホルム反応
- 不斉炭素原子
:::

エステルの構造決定は、**加水分解して2つに切ってから、それぞれについての条件を読む**のが基本の形です。条件はほとんどがアルコール側に付きます。

:::list
ordered: true
items:
- 分子式の**酸素の数**を見る。エステル結合1つが O 原子を2個使うので、O が2個ならエステル結合は1つです。
　O が2個なら「エステルかカルボン酸」、O が4個なら「エステル結合は多くても2つ」
- **加水分解して2つに分ける。**炭素数の和は、もとの分子の炭素数と等しくなります。
　炭素数5なら「カルボン酸1＋アルコール4」「2＋3」「3＋2」「4＋1」の4通り
- 出てきた**アルコール側**の条件を当てる。酸化の行き先（1級か2級か3級か）・脱水生成物・ヨードホルム反応・不斉炭素原子の有無。
- 出てきた**カルボン酸側**の条件を当てる。銀鏡反応が陽性ならギ酸、炭素数1ならギ酸。
- 決まった2つをエステル結合でつなぎ直して、**構造式**を書く。
:::

**アルコールの性質と、アルキル基の書き出しができることが前提になります。**構造決定でつまずくときは、たいていエステルではなくアルコール側の知識が抜けています。

:::section
anchor: advanced
title: 2価のエステル・環状エステル・無機のエステル
advanced: true
lead: エステル結合が2つあるとき、同じ分子の中で結ばれたとき、そして相手が無機の酸のとき。
terms:
- ラクトン
- ニトログリセリン
:::

エステル結合1つが O 原子を2個使うので、**分子式の酸素の数から、エステル結合の数は多くてもその半分**と決まります。O が4個なら、エステル結合は多くても2つです。

2価以上のエステルを加水分解すると、**出てくるものの比は 1対1 とはかぎりません**。同じアルコールや同じ酸が2分子出てくることがあります。

鎖状の2価エステルは、**エステル結合の向きの組み合わせが3通り**あります。向きが違うと加水分解で出てくるものが変わるので、3通りとも書き出してから条件を当てます。

同じ分子の中にあるヒドロキシ基とカルボキシ基が脱水すると、環状のエステルができます。これを**ラクトン**といいます。ラクトンは加水分解しても分子が2つに分かれないので、**加水分解の前後で分子の数が変わりません**。

硝酸や硫酸などの無機の酸（オキソ酸）も、アルコールとエステルをつくります。グリセリンと硝酸のエステルが**ニトログリセリン**です。

**この節の内容を先に覚える必要はありません。**構造決定の問題文に「2価のエステル」「環状のエステル」と書いてあったときに、ここへ戻ってくれば十分です。

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: slides:有機の基本3-6「エステルの性質」s7「練習1」（解答は s8）
prompt: 次の化学反応式を書け。**(1) 酢酸とエタノールに少量の濃硫酸を加え加熱した　(2) ギ酸と2-プロパノールに少量の濃硫酸を加え加熱した**
answer: (1) CH₃COOH ＋ C₂H₅OH → CH₃COOC₂H₅ ＋ H₂O（酢酸エチル）　(2) HCOOH ＋ CH₃CH(OH)CH₃ → HCOOCH(CH₃)₂ ＋ H₂O（ギ酸イソプロピル）　どちらも**カルボン酸から −OH、アルコールから −H** がとれています。名前は「カルボン酸の名前＋アルキル基の名前」の順につなぎます。
:::

:::exercise
source: slides:有機の基本3-8「エステルの構造決定」s3「練習1」
prompt: 分子式が C₆H₁₂O₂ である化合物 A がある。A を加水分解すると B と C が生じた。C を酸化すると B が得られた。**化合物 A の構造式を書け。**
answer: A はエステルなので、加水分解するとカルボン酸 B とアルコール C に分かれます。「C を酸化すると B」ということは、C と B は炭素数が同じで、C は酸化されてカルボン酸になる**1級アルコール**です。炭素数の和が6で、2つが同数なので、どちらも炭素数3。つまり B はプロピオン酸 CH₃CH₂COOH、C は1-プロパノール CH₃CH₂CH₂OH です。よって A は**プロピオン酸プロピル CH₃CH₂COOCH₂CH₂CH₃** となります。2-プロパノールを酸化してもアセトン（ケトン）にしかならないので、C は1-プロパノールに決まります。
:::

:::exercise
source: slides:有機の基本3-8「エステルの構造決定」s4「練習2」
prompt: 分子式が C₅H₁₀O₂ である化合物 A、B がある。A は不斉炭素原子をもたないが、B は不斉炭素原子をもつ。A を加水分解すると C と D が、B を加水分解すると E と F がそれぞれ生じた。C に濃硫酸を加えて加熱すると沸点34℃の F の構造異性体が生じた。E にアンモニア性硝酸銀水溶液を加えて加熱すると X が析出した。F をヨウ素と水酸化ナトリウム水溶液とともに加熱すると Y の（ア）色沈殿が生じた。**A、B の構造式、X、Y の化学式、（ア）に当てはまる語句を答えよ。**
answer: 沸点34℃の物質はジエチルエーテル C₂H₅OC₂H₅ です。C を分子間脱水するとジエチルエーテルになるので、**C はエタノール C₂H₅OH**。F はジエチルエーテルの構造異性体なので分子式は C₄H₁₀O のアルコールで、さらにヨードホルム反応が陽性なので CH₃CH(OH)− をもち、**F は2-ブタノール CH₃CH(OH)C₂H₅** です。A は C₅H₁₀O₂ でアルコール側がエタノール（炭素数2）なので、カルボン酸 D は炭素数3のプロピオン酸。よって **A はプロピオン酸エチル CH₃CH₂COOC₂H₅**（不斉炭素原子なし）。B はアルコール側が2-ブタノール（炭素数4）なので、カルボン酸 E は炭素数1のギ酸 HCOOH で、銀鏡反応を示すことと合います。よって **B はギ酸 sec-ブチル HCOOCH(CH₃)C₂H₅**（O が付いた C に H・CH₃・C₂H₅ が付くので不斉炭素原子あり）。**X は Ag**、**Y は CHI₃**、（ア）は**黄**です。
:::
