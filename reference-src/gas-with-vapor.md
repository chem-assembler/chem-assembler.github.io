燃焼で水ができる反応や、水上置換で集めた気体の問題では、容器の中に水蒸気が混ざります。このページでは、水蒸気を含む混合気体の圧力を求める手順をまとめます。前提になるのは、蒸気圧のページの「液体の水があれば上の空間は飽和蒸気圧」「飽和蒸気圧は分圧の最大値」の2つと、混合気体のページの「全圧は分圧の和」です。

:::section
anchor: pascal-table
title: 同じ容器の反応は Pa で3行の表を書く
lead: 同じ容器の中では、どの気体も温度 T と体積 V が共通なので、分圧は物質量に比例します。反応による量の変化を、mol の代わりに Pa で書けます。
:::

反応の量的関係は、ふつう物質量（mol）で「反応前・変化量・反応後」の3行の表に書きます。同じ容器の中の気体なら、PV ＝ nRT の T と V が共通なので、**分圧 P と物質量 n が比例します**。そこで、mol を求めずに**分圧（Pa）のまま3行の表を書けます**。変化量の比は、反応式の係数の比です。

:::link
to: stoichiometry
text: 3行の表（反応前・変化量・反応後）と「係数の比 ＝ mol の比」はこちら
:::

具体例で、300K で容器 A（3.0L）に 3.0×10⁵Pa の O₂、容器 B（6.0L）に 1.2×10⁵Pa の H₂ を入れ、コックを開いて完全に燃焼させ、再び 300K にした場合を考えます。コックを開くと体積は 9L になり、O₂ は 3L → 9L で分圧 1/3倍の 1.0×10⁵Pa、H₂ は 6L → 9L で分圧 2/3倍の 0.8×10⁵Pa です。

:::

H₂ がすべて反応し、O₂ が 0.6×10⁵Pa 残ります。H₂O の 0.8×10⁵Pa は、**生じた水がすべて気体だと仮定したときの分圧**です。本当にすべて気体かどうかは、次の節の手順で確かめます。

:::section
anchor: compare
title: 仮の分圧を飽和蒸気圧と比べる
lead: すべて気体と仮定した水の分圧が飽和蒸気圧を超えていれば、超えた分は液体になり、水蒸気の分圧は飽和蒸気圧に等しくなります。
:::

水蒸気を含む問題は、次の順に解きます。

:::list
ordered: true
items:
- 水がすべて気体だと仮定して、水蒸気の分圧（仮の分圧）を求める。
- 仮の分圧を、その温度の飽和蒸気圧と比べる。
- 仮の分圧 ＞ 飽和蒸気圧 なら、超えた分は液体になり、水蒸気の分圧は飽和蒸気圧に等しい。
- 仮の分圧 ≦ 飽和蒸気圧 なら、水はすべて気体で、水蒸気の分圧は仮の分圧のまま。
- ほかの気体の分圧と足して、全圧を求める。
:::

上の具体例では、300K の水の飽和蒸気圧が 3.6×10³Pa ＝ 0.036×10⁵Pa です。仮の分圧 0.8×10⁵Pa ＞ 0.036×10⁵Pa なので、水の大部分は液体になり、水蒸気の分圧は 0.036×10⁵Pa です。全圧は O₂ の分圧と足して 0.60×10⁵ ＋ 0.036×10⁵ ＝ 0.636×10⁵ ≒ **6.4×10⁴Pa** です。

液体として存在する水の割合も、同じ考え方で求められます。水の物質量は（同じ容器・同じ温度なら）分圧に比例するので、**（仮の分圧 − 飽和蒸気圧）÷ 仮の分圧** が液体の割合です。上の具体例なら (0.800 − 0.036)/0.800 ≒ 96% です。

:::mistake
wrong: 生じた水の分圧は、3行の表で求めた 0.8×10⁵Pa である
right: 3行の表の 0.8×10⁵Pa は「すべて気体と仮定した」値です。飽和蒸気圧（0.036×10⁵Pa）を超えているので、実際の水蒸気の分圧は 0.036×10⁵Pa です。
why: 3行の表を書いた時点で答えが出たと思い、飽和蒸気圧と比べる段を飛ばしてしまうためです。水ができる反応では、表のあとに必ず比べる段を入れましょう。
:::

:::section
anchor: water-displacement
title: 水上置換で集めた気体
lead: 水上置換で集めた気体には、飽和蒸気圧の水蒸気が混ざっています。集めた気体の分圧は、大気圧から水の飽和蒸気圧を引いた値です。
terms:
- 水上置換
:::

水上置換では、気体を水の上に集めるので、容器の中には液体の水と接した空間ができます。「液体の水があれば、上の空間は飽和蒸気圧」なので、集めた気体は**飽和蒸気圧の水蒸気との混合気体**です。

容器の中の水面を外の水槽の水面にそろえると、容器の中の全圧が大気圧に等しくなります。したがって、集めた気体の分圧は次のとおりです。

（集めた気体の分圧）＝（大気圧）−（水の飽和蒸気圧）です。

具体例で、27℃（300K）・9.96×10⁴Pa のもとで、過酸化水素水に酸化マンガン(Ⅳ) を加えて発生した O₂ を水上置換で 166mL 集めた場合を考えます（水の飽和蒸気圧 3.6×10³Pa）。

:::list
ordered: true
items:
- 桁をそろえて O₂ の分圧を出す。9.96×10⁴ − 0.36×10⁴ ＝ 9.6×10⁴Pa。
- 準標準状態（300K・1.0×10⁵Pa・24.9L）を基準に、P と V の倍率を書く。
　P は 1.00×10⁵Pa → 0.96×10⁵Pa（比）、V は 24900mL → 166mL（比）。
- n ＝ 1mol × 96/100 × 166/24900 ≒ 6.4×10⁻³mol。
:::

**「液面を水槽の液面にそろえて、容器内の圧力を大気圧に等しくする」は、実験の手順としても問われます。**理由まで説明できるようにしておきましょう。

:::section
anchor: reverse
title: 逆向きの問題 —— 全圧から飽和蒸気圧を求める
lead: 実際の全圧が、すべて気体と仮定した全圧より小さければ、水の一部が液体になっています。全圧からほかの気体の分圧を引けば、飽和蒸気圧が求められます。
:::

問題文に「水滴が生じた」とあれば、それだけで水蒸気が飽和蒸気圧に達していると読めます。書かれていなくても、**すべて気体と仮定した全圧と、実際の全圧を比べる**と分かります。実際の全圧の方が小さければ、その差の分の水が液体になっています。

このとき、（水の飽和蒸気圧）＝（実際の全圧）−（水以外の気体の分圧）で求められます。この型は、下の例題の2問目で扱います。

:::section
anchor: range
title: 覚える範囲
lead: 「同じ容器なら Pa で3行」「すべて気体と仮定して飽和蒸気圧と比べる」「水上置換の気体の分圧 ＝ 大気圧 − 飽和蒸気圧」の3つを手順として身につけます。
:::

**必ず身につけるのは、「同じ容器の反応は Pa で3行の表を書く」「すべて気体と仮定した分圧を、飽和蒸気圧と比べる」の2つの手順です。**水上置換の「大気圧 − 飽和蒸気圧」は、「液体の水の上は飽和蒸気圧」と「全圧は分圧の和」から出てくるので、公式として別に覚えなくて構いません。

水の飽和蒸気圧の値は、問題文で与えられます。27℃（300K）で約 3.6×10³Pa（大気圧の 4% ほど）という大きさの感覚だけ持っておくと、比べる段で迷いません。

:::exercise
source: slides:気体の基本２「混合気体と水蒸気圧」s29〜35「練習３・練習４」（s34 の「3.6×10⁵Pa」は 3.6×10³Pa に直した）
prompt: 300K で、容器 A（1.0L）に 1.8×10⁵Pa の O₂、容器 B（2.0L）に 2.7×10⁵Pa の H₂ を入れ、コックを開いて 400K に保ったところ、全圧は 3.2×10⁵Pa（O₂ 0.8×10⁵Pa・H₂ 2.4×10⁵Pa）になった。この混合気体を完全に反応させた。水の飽和蒸気圧は 300K で 3.6×10³Pa、400K で 2.5×10⁵Pa、液体の水の体積は無視できるとして、有効数字2桁で答えよ。(1) 容器を 400K に保ったときの全圧。(2) 容器を 300K に保ったときの全圧。(3) (2) のとき、生じた水のうち液体として存在する割合〔%〕。
answer: (1) 2.4×10⁵Pa。400K で Pa の3行を書くと、2H₂ ＋ O₂ → 2H₂O で H₂ 2.4 − 1.6 ＝ 0.8、O₂ 0.8 − 0.8 ＝ 0、H₂O ＋1.6（×10⁵Pa）。仮の分圧 1.6×10⁵Pa ＜ 飽和蒸気圧 2.5×10⁵Pa なので水はすべて気体。全圧 0.8 ＋ 1.6 ＝ 2.4×10⁵Pa。(2) 6.4×10⁴Pa。400K → 300K で T が 3/4倍なので、すべて気体と仮定すると H₂ 0.6×10⁵Pa・H₂O 1.2×10⁵Pa。1.2×10⁵Pa ＞ 0.036×10⁵Pa なので水蒸気の分圧は飽和蒸気圧。全圧 0.6×10⁵ ＋ 0.036×10⁵ ＝ 0.636×10⁵ ≒ 6.4×10⁴Pa。(3) 97%。水の物質量は分圧に比例するので (1.200 − 0.036)/1.200 × 100 ≒ 97%。
:::
