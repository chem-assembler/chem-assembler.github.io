酸と塩基は、**価数**（1個が出す H⁺・OH⁻ の数）と**強弱**（水に溶けたときにどれだけ電離するか）の2つの軸で分類して覚えます。「硫酸はどんな酸か」と聞かれたら「**2価の強酸**」と答えられるようにしましょう。定義そのものは前のページで扱っています。

:::section
anchor: valence
title: 酸と塩基の価数
lead: 1個の酸が出す H⁺ の数が酸の価数、1個の塩基が出す OH⁻ の数が塩基の価数です。
terms:
- 価数
- 1価の酸
- 2価の酸
:::

「**1個の酸が出す H⁺ の数**」を**酸の価数**、「**1個の塩基が出す OH⁻ の数**」を**塩基の価数**といいます。

H⁺ と OH⁻ は同じ数（mol）どうしで反応して H₂O になります。具体例として、H⁺ と OH⁻ 2個ずつで H₂O を2個つくる場合を考えると、**1価の酸なら2個必要**ですが、**2価の酸なら1個で足ります**。

:::figure
src: acid-base-strength-valence.png
alt: 塩基の OH⁻ と酸の H⁺ が結びついて H₂O ができる模式図。左は1価の酸2個がそれぞれ H⁺ を1個ずつ出す場合、右は2価の酸1個が H⁺ を2個出す場合
caption: **2個の H⁺ を出すのに、1価の酸なら2個、2価の酸なら1個**。価数は「1個が出す H⁺（OH⁻）の数」です。
:::

価数は、電離の式を書いてイオンに分ければ判断できます。

:::reaction
left: H₂SO₄
right: 2H⁺ ＋ SO₄²⁻
level: ★★★
note: H⁺ が2個出るので、硫酸は2価の酸です。陰イオン SO₄²⁻ の電荷の数と価数が一致します。
:::

よく登場する酸・塩基は、**暗記すべきイオンに H⁺ か OH⁻ がくっついてできています**。そのイオンの価数（電荷の数）が、そのまま酸・塩基の価数になります。

:::section
anchor: strength
title: 酸と塩基の強弱と電離度
lead: 水に溶けてすべて電離するのが強酸・強塩基、一部だけが電離するのが弱酸・弱塩基です。電離している割合を電離度 α といいます。
terms:
- 強酸
- 弱酸
- 強塩基
- 弱塩基
- 電離度
:::

水に溶けたとき、**すべて電離**して H⁺（OH⁻）をすべて放出するものを**強酸（強塩基）**、**一部だけが電離**して H⁺（OH⁻）をほとんど放出しないものを**弱酸（弱塩基）**といいます。

:::figure
src: acid-base-strength-ionization.png
alt: 強酸は5個すべてが H⁺ と陰イオンに分かれ、弱酸は5個のうち1個だけが分かれている模式図
caption: **強酸はすべて電離、弱酸は一部が電離**。弱酸の水溶液には、電離していない分子がたくさん残っています。
:::

「**酸・塩基のうち電離している割合（全体を1とする）**」を**電離度**といい、**α** で表します。

:::list
items:
- 電離度 α ＝（電離した酸・塩基の mol/L）÷（溶かした酸・塩基の mol/L）
- 強酸・強塩基は **α ＝ 1**
- 弱酸・弱塩基は **α ＜ 1**（**0.01 くらい**）
:::

具体例として、0.20 mol/L の酢酸の H⁺ 濃度が 0.0040 mol/L だったとすると、酢酸は1価なので電離した酢酸も 0.0040 mol/L で、α ＝ 0.0040 ÷ 0.20 ＝ **0.020** です。

**「弱酸・弱塩基の電離度は 0.01 くらい」は覚えておきましょう。**電離度は同じ物質でも濃度や温度で変わり、薄いほど大きくなります。滴定の「おおよその pH」を出すときは 0.01 をそのまま使います。

**強酸は3つ覚えます**。「**塩酸 HCl、硝酸 HNO₃、硫酸 H₂SO₄、その他は弱酸**」と言えるようにしてください。

**強塩基は、アルカリ金属と、Be・Mg を除くアルカリ土類金属の水酸化物**です。その他の金属の水酸化物は弱塩基ですが、**アンモニア NH₃ 以外の弱塩基はほぼ登場しません**。水酸化鉄(Ⅱ)・水酸化マグネシウムは覚えなくても困ることはほとんどありません。

表を読むときの注意を2つ挙げます。

:::list
items:
- 塩化水素 HCl は気体（純物質）で、その水溶液が塩酸（混合物）です
- 二酸化炭素 CO₂ は水に溶けると炭酸 H₂CO₃ になるので、2価の弱酸として扱います
:::

:::section
anchor: ionization
title: 電離の式
lead: 酸・塩基の化学式はイオンとセットで暗記し、電離の式が書けるようにします。弱酸・弱塩基の電離は可逆です。
terms:
- 電離の式
- カルボキシ基
:::

**表の酸・塩基は、電離の式まで書けるようにしてください。**式を書くと価数がそのまま見えます。

:::reaction
left: HNO₃
right: H⁺ ＋ NO₃⁻
level: ★★★
note: 1価の強酸。
:::

:::reaction
left: H₃PO₄
right: 3H⁺ ＋ PO₄³⁻
level: ★★★
note: 3価の弱酸。電離の式は価数を見るために、まとめて1本で書きます。
:::

:::reaction
left: H₂S
right: 2H⁺ ＋ S²⁻
level: ★★★
note: 2価の弱酸。
:::

:::reaction
left: H₂CO₃
right: 2H⁺ ＋ CO₃²⁻
level: ★★★
note: 2価の弱酸。CO₂ が水に溶けてできる酸です。
:::

:::reaction
left: (COOH)₂
right: 2H⁺ ＋ C₂O₄²⁻
level: ★★★
note: 2価の弱酸。シュウ酸は H₂C₂O₄ と書くこともあります。
:::

:::reaction
left: CH₃COOH
right: CH₃COO⁻ ＋ H⁺
level: ★★★
note: （可逆）1価の弱酸。一部しか電離しないので、ふつうは ⇄ で書きます。
:::

## 酢酸とシュウ酸の書き方

酢酸は4つの H 原子のうち、**カルボキシ基 −COOH の H 1個だけ**が電離します。分子式 C₂H₄O₂ ではこの特徴が表せないので、酢酸は**示性式 CH₃COOH** で書きます。シュウ酸も −COOH を2個もつので **(COOH)₂**（H₂C₂O₄ とも）と書きます。−COOH が弱酸の性質を示すためです。

:::link
to: carboxylic-acid
text: カルボキシ基と、カルボン酸が弱酸であることはカルボン酸のページへ
:::

:::section
anchor: concentration
title: H⁺ の濃度の求め方
lead: 強酸は（価数）×（濃度）、弱酸は（濃度）×（電離度）で H⁺ の濃度を出します。2つを使い分けます。
terms:
- 水素イオン濃度
:::

強酸・強塩基はすべて電離するので、電離の式の係数から次のように求めます。

:::list
items:
- 強酸：（価数）×（酸の mol/L）＝（H⁺ の mol/L）
- 強塩基：（価数）×（塩基の mol/L）＝（OH⁻ の mol/L）
:::

具体例として、0.12 mol/L の硫酸は2価の強酸なので、H⁺ の濃度は 2 × 0.12 ＝ **0.24 mol/L** です。

弱酸・弱塩基は一部しか電離しないので、電離度を掛けます。

:::list
items:
- 1価の弱酸：（酸の mol/L）×（電離度）＝（H⁺ の mol/L）
- 1価の弱塩基：（塩基の mol/L）×（電離度）＝（OH⁻ の mol/L）
:::

具体例として、電離度 0.025、0.10 mol/L の酢酸の H⁺ の濃度は 0.10 × 0.025 ＝ **2.5 × 10⁻³ mol/L** です。

:::callout
tone: caution
text: 「[H⁺] ＝（価数）×（濃度）×（電離度）」とまとめた公式を覚えれば、強酸にも弱酸にも使えます。ただしこれは、仕組みを考えずに数を当てはめてしまう「きはじ」型の公式なので、使わないほうがよいでしょう。強酸か弱酸かを先に判断して、上の2つの式を使い分けます。
:::

:::section
anchor: sulfuric-second
title: 硫酸の2段目の電離
advanced: true
lead: 硫酸の電離は、実際には H₂SO₄ → H⁺ ＋ HSO₄⁻ の1段目はほぼ完全ですが、HSO₄⁻ → H⁺ ＋ SO₄²⁻ の2段目は完全ではありません。
:::

高校の計算では、硫酸は「2価の強酸」としてすべて電離させて扱います。実際には、2段目の HSO₄⁻ の電離は1段目ほど進みません。濃い硫酸ほどこの差が目立ちます。

問題文に特に断りがなければ、**「硫酸は2価の強酸で、すべて電離する」として計算して問題ありません。**

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: slides:酸塩基の基本２ p.14「練習1」
prompt: 次の酸・塩基の化学式と、価数と強弱を「○価の（強酸・弱酸・強塩基・弱塩基）」の形で書け。硫酸／アンモニア／酢酸／水酸化カルシウム／硝酸／リン酸／シュウ酸
answer: 硫酸 **H₂SO₄**：2価の強酸／アンモニア **NH₃**：1価の弱塩基／酢酸 **CH₃COOH**：1価の弱酸／水酸化カルシウム **Ca(OH)₂**：2価の強塩基／硝酸 **HNO₃**：1価の強酸／リン酸 **H₃PO₄**：3価の弱酸／シュウ酸 **(COOH)₂**：2価の弱酸
:::

:::exercise
source: slides:酸塩基の基本２ p.15「練習2」
prompt: 0.12 mol/L の硫酸の H⁺ の濃度を有効数字2桁で求めよ。
answer: 硫酸は2価の強酸なのですべて電離し、H₂SO₄ → 2H⁺ ＋ SO₄²⁻ の係数から H₂SO₄ の2倍の H⁺ が生じます。2 × 0.12 mol/L ＝ **0.24 mol/L**
:::

:::exercise
source: slides:酸塩基の基本２ p.16「練習3」
prompt: 0.20 mol/L の酢酸の H⁺ の濃度は 0.0040 mol/L だった。この酢酸の電離度を有効数字2桁で求めよ。
answer: 酢酸は1価の酸なので、電離した CH₃COOH と生じた H⁺ は等しく、電離した酢酸は 0.0040 mol/L です。電離度 ＝ 0.0040 ÷ 0.20 ＝ 4.0 × 10⁻³ ÷ (2.0 × 10⁻¹) ＝ **2.0 × 10⁻²**
:::

:::exercise
source: slides:酸塩基の基本３ p.4「復習」
prompt: 0.10 mol/L のある強酸の H⁺ の濃度は 0.20 mol/L だった。この酸の価数を求めよ。
answer: 価数を x とすると、0.10 mol/L × x ＝ 0.20 mol/L より x ＝ 2。**2価**です。
:::
