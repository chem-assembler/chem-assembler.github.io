グルコースなどの単糖が**多数**つながった天然高分子を**多糖**といいます。代表は、植物が栄養としてたくわえる**デンプン**と、植物の体をつくる**セルロース**です。

:::section
anchor: definition
title: 多糖とは
lead: 多数のグルコースが脱水縮合してつながった高分子で、分子式は (C₆H₁₀O₅)~n~ と書けます。還元性も甘味もほとんどありません。
terms:
- 多糖
- 天然高分子
:::

グルコース C₆H₁₂O₆ が n 個つながるとき、つなぎ目ごとに水が1分子ずつとれます。n が非常に大きいので、繰り返し単位は C₆H₁₂O₆ − H₂O ＝ **C₆H₁₀O₅**、分子式は **(C₆H₁₀O₅)~n~** と書けます。

実際に代入すると、繰り返し単位 C₆H₁₀O₅ の式量は 72 ＋ 10 ＋ 80 ＝ **162** です。多糖の計算は、ほとんどこの162から始まります。

多糖は還元性も甘味もほとんど示しません。環が開ける末端は分子の端に1つあるだけで、分子全体から見るとごくわずかなためです。

**「多糖は (C₆H₁₀O₅)~n~、繰り返し単位の式量は162」は暗記してください。**

:::reaction
left: (C₆H₁₀O₅)ₙ ＋ nH₂O
over: 酸または酵素
right: nC₆H₁₂O₆
level: ★★★
note: 多糖を最後まで加水分解するとグルコースになります。デンプンでもセルロースでも同じ式です。
:::

:::section
anchor: starch
title: デンプン
lead: α-グルコースが縮合したものです。枝分かれの無いアミロースと、枝分かれの多いアミロペクチンからなります。
terms:
- デンプン
- アミロース
- アミロペクチン
:::

**デンプン**は、**α-グルコース**が多数縮合した多糖です。α形でつながると鎖が少しずつ曲がり、**らせん状**に巻きます。

デンプンは2種類の成分からなります。枝分かれの無いものを**アミロース**、枝分かれの多いものを**アミロペクチン**といいます。アミロースは温水に溶けやすく、アミロペクチンは溶けにくい成分です。

**アミロースとアミロペクチンの名前と、枝分かれの有無は暗記してください。**枝分かれの結合の位置（1位と6位）は覚えなくて構いません。

α-グルコース2分子がつながった形は、二糖のマルトースそのものです。デンプンはこの形がずっと続いたものと見られます。

:::section
anchor: iodine
title: ヨウ素デンプン反応
lead: デンプンの水溶液にヨウ素ヨウ化カリウム水溶液を加えると青紫色になります。加熱すると色が消え、冷やすと戻ります。
terms:
- ヨウ素デンプン反応
:::

デンプンの水溶液に**ヨウ素ヨウ化カリウム水溶液（ヨウ素液）**を加えると、**青紫色**になります。これを**ヨウ素デンプン反応**といいます。

色が出るのは、デンプンのらせんの中にヨウ素が入り込むためです。**加熱するとらせんがゆるんで色が消え、冷やすとまた青紫色に戻ります。**

**「デンプンは青紫色、加熱で消えて冷やすと戻る」は必ず暗記してください。**アミロースとアミロペクチンの色の違いは、余裕があれば覚える程度で構いません。呈色の仕組みは覚える必要はありません。

:::section
anchor: hydrolysis
title: デンプンの加水分解
lead: アミラーゼでデキストリンを経てマルトースまで、マルターゼでグルコースまで分解されます。
terms:
- アミラーゼ
- デキストリン
- マルターゼ
:::

デンプンは、酵素**アミラーゼ**のはたらきで、少し短くなった**デキストリン**を経て、二糖の**マルトース**まで分解されます。マルトースは酵素**マルターゼ**でグルコースになります。

:::reaction
left: 2(C₆H₁₀O₅)ₙ ＋ nH₂O
over: アミラーゼ
right: nC₁₂H₂₂O₁₁（マルトース）
level: ★★☆
note: デンプンを途中まで分解した形。二糖は単位2個ぶんなので、左辺に係数2が付きます。
:::

**「デンプン →（アミラーゼ）→ デキストリン → マルトース →（マルターゼ）→ グルコース」の順は暗記してください。**

:::section
anchor: glycogen
title: グリコーゲン
lead: 動物がたくわえる多糖で、アミロペクチンよりさらに枝分かれが多く、ヨウ素で赤褐色になります。
terms:
- グリコーゲン
:::

**グリコーゲン**は、動物の肝臓や筋肉にたくわえられる多糖です。デンプンと同じく α-グルコースからなり、**アミロペクチンよりさらに枝分かれが多い**ものです。ヨウ素液では**赤褐色**になります。

**グリコーゲンは「動物のデンプン」、ヨウ素で赤褐色、の2点だけ覚えておけば十分です。**

:::section
anchor: cellulose
title: セルロース
lead: β-グルコースが縮合したものです。まっすぐ伸びた鎖が束になり、丈夫な繊維になります。ヒトは消化できません。
terms:
- セルロース
- セロビオース
- セルラーゼ
:::

**セルロース**は、**β-グルコース**が多数縮合した多糖で、植物の細胞壁の主成分です。β形でつながると、鎖は**まっすぐ**伸びます。まっすぐな鎖どうしが水素結合で束になるので、**丈夫な繊維**になり、水にも溶けません。

セルロースは酵素**セルラーゼ**で二糖の**セロビオース**に、さらに**セロビアーゼ**でグルコースに分解されます。ヒトはセルラーゼをもたないので、セルロースを消化できません。

:::reaction
left: 2(C₆H₁₀O₅)ₙ ＋ nH₂O
over: セルラーゼ
right: nC₁₂H₂₂O₁₁（セロビオース）
level: ★★☆
note: デンプンをアミラーゼで分解する式と、形はまったく同じです。
:::

**「α形ならデンプン、β形ならセルロース」**と覚えましょう。この表の残りの行は、ほとんどこの1行から理由をつけて出せます。

:::section
anchor: cellulose-oh
title: セルロースの −OH は1単位に3個
lead: 繰り返し単位 C₆H₁₀O₅ には −OH が3個あるので、[C₆H₇O₂(OH)₃]~n~ と書けます。誘導体の計算はすべてここから始まります。
terms:
- ヒドロキシ基
:::

セルロースの繰り返し単位 C₆H₁₀O₅ には、**−OH が3個**残っています。−OH を外に出して書くと **[C₆H₇O₂(OH)₃]~n~** です。

一度数えて確かめます。C₆H₇O₂ に (OH)₃ を足すと、C は6、H は 7 ＋ 3 ＝ 10、O は 2 ＋ 3 ＝ 5 で、ちゃんと C₆H₁₀O₅ に戻ります。

**「セルロースは [C₆H₇O₂(OH)₃]~n~」と書けるようにしてください。**この3個の −OH をどう変えたかで、次の節の誘導体がすべて決まります。

:::section
anchor: nitrocellulose
title: ニトロセルロースとアセチルセルロース
lead: −OH を濃硝酸でエステルにするとニトロセルロース、無水酢酸でエステルにするとアセチルセルロースになります。
terms:
- トリニトロセルロース
- 硝酸エステル
- トリアセチルセルロース
:::

セルロースに**濃硝酸と濃硫酸の混合物**を作用させると、−OH が硝酸エステル −ONO₂ に変わります。3個とも変わったものが**トリニトロセルロース**で、**無煙火薬**の原料です。

:::reaction
left: [C₆H₇O₂(OH)₃]ₙ ＋ 3nHNO₃
over: 濃硫酸
right: [C₆H₇O₂(ONO₂)₃]ₙ ＋ 3nH₂O
level: ★★★
note: −OH の H と硝酸の OH から水がとれる**エステル化**です。−O−NO₂ と、炭素と窒素の間に酸素が1個はさまっています。
:::

:::mistake
wrong: ニトロセルロースは、ベンゼンのニトロ化と同じくニトロ化でできる
right: ニトロセルロースは**硝酸エステル**で、できる反応は**エステル化**です。
why: 名前に「ニトロ」と付いているためです。★ ニトロ化合物は C−NO₂、硝酸エステルは C−O−NO₂ で、**酸素が1個はさまるかどうか**で見分けます。ニトログリセリンも同じ硝酸エステルです。
:::

セルロースに**無水酢酸**を作用させると、−OH がアセチル化されて**トリアセチルセルロース**になります。

:::reaction
left: [C₆H₇O₂(OH)₃]ₙ ＋ 3n(CH₃CO)₂O
right: [C₆H₇O₂(OCOCH₃)₃]ₙ ＋ 3nCH₃COOH
level: ★★☆
note: 酢酸エステルができるアセチル化です。
:::

トリアセチルセルロースは溶媒に溶けにくいので、エステル結合を**一部だけ加水分解**してジアセチルセルロースに戻し、アセトンに溶かして紡ぎます。これが**アセテート繊維**です。

:::reaction
left: [C₆H₇O₂(OCOCH₃)₃]ₙ ＋ nH₂O
right: [C₆H₇O₂(OCOCH₃)₂(OH)]ₙ ＋ nCH₃COOH
level: ★★☆
note: 3個のうち1個だけ −OH に戻します。
:::

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: reference-outline/bio.md 第2部 polysaccharide の例題1（①ドラフトのために起こした計算問題）
prompt: セルロース 162 g のヒドロキシ基をすべて硝酸エステルにしたとき、得られるトリニトロセルロースの質量を求めよ。H ＝ 1、C ＝ 12、N ＝ 14、O ＝ 16 とする。
answer: 繰り返し単位 C₆H₁₀O₅ の式量は162なので、単位 1.00 mol 分。生成物の繰り返し単位 C₆H₇O₂(ONO₂)₃ の式量は **297** なので、**297 g** です。−OH 3個が −ONO₂ 3個に変わると、1単位あたり 3 × (62 − 17) ＝ 135 増える、と数えても出せます。
:::

:::exercise
source: reference-outline/bio.md 第2部 polysaccharide の例題2（①ドラフトのために起こした計算問題）
prompt: デンプン 81.0 g を完全に加水分解して得られるグルコースの質量を求めよ。H ＝ 1、C ＝ 12、O ＝ 16 とする。
answer: 81.0 ÷ 162 ＝ 0.500 mol 分の繰り返し単位。(C₆H₁₀O₅)~n~ ＋ nH₂O → nC₆H₁₂O₆ より、グルコースも 0.500 mol なので、180 × 0.500 ＝ **90.0 g** です。水が加わるぶん、質量が増えます。
:::

:::exercise
source: reference-outline/bio.md 第2部 polysaccharide の例題3（①ドラフトのために起こした記述問題）
prompt: デンプンとセルロースは、どちらも分子式 (C₆H₁₀O₅)~n~ で表される。この2つの構造上の違いと、それによって生じる性質の違いを書け。
answer: デンプンは **α-グルコース**が縮合してらせん状に巻き、セルロースは **β-グルコース**が縮合してまっすぐ伸び、束になります。そのためデンプンはヨウ素デンプン反応を示し、セルロースは丈夫な繊維になって呈色しません。ヒトはセルロースを分解する酵素をもたないので、セルロースを消化できません。
:::
