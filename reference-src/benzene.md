ベンゼン環をもつ炭化水素を**芳香族炭化水素**といいます。その出発点がベンゼン C₆H₆ で、芳香族の反応は、ほとんどすべてこの環の性質から決まります。

:::section
anchor: shape
title: ベンゼンのかたち
lead: 炭素6個が正六角形に並んだ平面分子で、結合角は120°。6個の C と6個の H はすべて同等です。
terms:
- ベンゼン
- ベンゼン環
- 芳香族炭化水素
:::

ベンゼン C₆H₆ は、**炭素原子6個が正六角形に並んだ平面分子**です。結合角はすべて **120°** で、6個の C 原子と6個の H 原子は、どれも同じ環境にあります。

:::section
anchor: bond
title: 結合はすべて同じ長さ
lead: 構造式は単結合と二重結合を交互に書きますが、実際の C−C 結合は6本とも同じ長さで、単結合と二重結合の中間です。
terms:
- 構造式（ケクレ式）
- 結合距離
:::

ベンゼンの構造式は、単結合と二重結合を1本おきに書きます。しかし実際に測ると、**6本の C−C 結合はすべて同じ長さ（約 0.140 nm）**で、単結合（約 0.154 nm）と二重結合（約 0.134 nm）の**中間**になっています。

:::section
anchor: substitution-first
title: だから付加ではなく置換が起こる
lead: 環がひとまとまりで安定なので、二重結合を切る付加反応は起こりにくく、H が入れ替わる置換反応が起こりやすくなります。
terms:
- 置換反応
- 付加反応
:::

二重結合をもつアルケンは、臭素水に加えるとすぐに付加反応が起こり、**臭素水の赤褐色が消えます**。ところが、ベンゼンに臭素水を加えても**色は消えません**。

これは、6本の結合が同等にならされて**環全体がひとつのまとまりとして安定になっている**ためです。付加反応をすると、このまとまりが壊れてしまいます。そのため、**環を壊さずに H だけを入れ替える置換反応**のほうが起こりやすくなります。

**「ベンゼンの反応は置換反応」と覚えましょう。**アルカンの「置換反応」、アルケンの「付加反応」と並べて覚えると整理しやすいです。

:::section
anchor: addition
title: それでも付加する2つの場合
lead: 水素（触媒・高温高圧）と、紫外線を当てた塩素。「起こりにくい」の中身は、条件の厳しさです。
terms:
- シクロヘキサン
- ヘキサクロロシクロヘキサン
:::

ベンゼンが付加反応を起こすのは、**条件を厳しくしたとき**だけです。高校で扱うのは次の2つです。

:::reaction
left: C₆H₆ ＋ 3H₂
over: Ni または Pt
under: 高温・高圧
right: C₆H₁₂
level: ★★★
note: シクロヘキサンになります。二重結合3本ぶんに一度に水素が付くので、H₂ の係数は 3 です。
:::

:::reaction
left: C₆H₆ ＋ 3Cl₂
over: 紫外線
right: C₆H₆Cl₆
level: ★★★
note: ヘキサクロロシクロヘキサンになります。
:::

同じ塩素でも、**鉄（または塩化鉄(III)）を触媒にすると置換反応**が起こって、クロロベンゼン C₆H₅Cl ができます。**「紫外線なら付加、鉄なら置換」**と対にして覚えてください。ここは取り違えがいちばん多いところです。

:::mistake
wrong: ベンゼンに塩素を反応させると、いつもクロロベンゼンができる。
right: 鉄を触媒にすると置換してクロロベンゼン C₆H₅Cl、紫外線を当てると付加してヘキサクロロシクロヘキサン C₆H₆Cl₆ ができる。
why: 試薬は同じ Cl₂ なので、条件（触媒か光か）を読まないと行き先を取り違えます。
:::

:::section
anchor: props
title: ベンゼンの性質と、どこから得るか
lead: 特有のにおいをもつ無色の液体。水に溶けにくく、多量のすすを出して燃えます。
terms:
- コールタール
- ナフサ
:::

ベンゼンは、**特有のにおいをもつ無色の揮発性の液体**です。水に溶けにくく、有機化合物をよく溶かします。**有毒で、引火しやすい**物質です。

ベンゼンは空気中で燃やすと、**多量のすすを出して燃えます**。分子に占める炭素の割合が大きく、酸素が足りなくなって炭素が燃え残るためです。

:::reaction
left: 2C₆H₆ ＋ 15O₂
right: 12CO₂ ＋ 6H₂O
level: ★★☆
note: 完全燃焼したときの式です。実際には酸素が足りず、すす（炭素）が残ります。
:::

ベンゼンは、石炭を乾留して得られる**コールタール**の分留や、石油の**ナフサ**の改質で得られます。**「コールタールとナフサ」の2語だけ覚えれば十分**で、装置や温度は覚えなくて構いません。

:::section
anchor: homolog
title: 芳香族炭化水素の一般式
lead: ベンゼン環1個にアルキル基が付いたものは C~n~H~2n−6~。n に炭素の数を入れれば分子式が出ます。
terms:
- 同族体
- 一般式
:::

ベンゼン環を1個もち、そこにアルキル基が付いた芳香族炭化水素の一般式は **C~n~H~2n−6~**（n≧6）です。n=6 を代入するとベンゼン C₆H₆、n=7 ならトルエン C₇H₈、n=8 ならキシレンやエチルベンゼン C₈H₁₀ が得られます。

アルカン C~n~H~2n+2~ と比べると H が8個少なくなっています。環を1つつくると H が2個、二重結合を1本つくると H が2個減るので、「環1つ＋二重結合3本」で 2＋6＝8個です。

prompt: 分子式 C₉H₁₂ の芳香族炭化水素は、一般式 C~n~H~2n−6~ の n がいくつにあたるか。
answer: n=9 です。2×9−6＝12 となり、H の数が合います。一般式に代入して合えば、「ベンゼン環1個＋アルキル基」の形だと当たりが付きます。
:::

:::exercise
source: draft:reference-outline/aromatic.md の benzene の例題2（アルケンの付加反応とベンゼンの置換反応の対比から作った問い）
prompt: ベンゼンと 2-ブテンに、それぞれ臭素水を加えた。見た目はどうなるか。
answer: 2-ブテンは付加反応が起こり、**臭素水の赤褐色が消えます**。ベンゼンは**変化しません**。構造式では二重結合を書くのに付加しない、というのがベンゼンの見分けどころです。
:::

answer: (1) C₆H₆ ＋ Cl₂ → C₆H₅Cl ＋ HCl（置換・クロロベンゼン）　(2) C₆H₆ ＋ 3Cl₂ → C₆H₆Cl₆（付加・ヘキサクロロシクロヘキサン）
