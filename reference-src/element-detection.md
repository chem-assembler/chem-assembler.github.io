有機化合物をつくる元素は、C・H・O のほかに N・S・Cl などに限られます。このページでは、試料にどの元素が入っているかを調べる操作を、元素ごとに見ていきます。

:::section
anchor: qualitative
title: 定性分析と定量分析
lead: 「何が入っているか」を調べるのが定性分析、「どれだけ入っているか」を調べるのが定量分析です。
terms:
- 定性分析
- 定量分析
:::

試料に何が含まれているか、何という物質なのかを調べる分析を**定性分析**といいます。これに対して、何 g・何 mol といった量を調べる分析を**定量分析**といいます。

このページは定性分析、次の「元素分析」のページが定量分析です。

たとえばアミノ酸のシステインは、C・H・O に加えて N と S を含みます。このページの操作を順に当てていくと、5元素のうち Cl 以外の4つで変化が見えます（O だけは確認の操作がありません。下の節で扱います）。

:::figure
src: element-detection-cysteine.png
gen: name=システイン plain
alt: システインの構造式。炭素3個の骨格に、アミノ基 −NH₂、カルボキシ基 −COOH、硫黄をふくむ −CH₂−SH が付いている
caption: システイン。C・H・O のほかに **N** と **S** を含むので、窒素と硫黄の確認で変化が見えます。
:::

調べる前に、試料は**純物質**にしておきます。混合物のままでは、どの物質の元素を見ているのかが決まらないためです。分けるには蒸留・再結晶・抽出（分液漏斗）・クロマトグラフィーを使います。

:::

:::section
anchor: list
title: 5元素の確認法の一覧
lead: 元素ごとに「操作 → 生成物 → 確認方法」が1組になっています。
terms:
- 石灰水
- 硫酸銅(II)無水物
- 炎色反応
- バイルシュタイン反応
- 酢酸鉛(II)
:::

:::table
caption: 成分元素の確認
source: slides:有機の基本1-3「元素の確認」s2「成分元素の確認（定性分析）」の表5行。生成物の列はスライドの「操作」列の文から分けたもの
head:
- 元素
- 操作
- 生成物
- 確認方法
align: left | left | left | left
rows:
- **炭素 C** | 完全燃焼させる | CO₂ | 石灰水に通じると**白濁**する
- **水素 H** | 完全燃焼させる | H₂O | 白色の硫酸銅(II)無水物が**青色**になる（塩化コバルト紙が青から**赤**に変わる）
- **窒素 N** | NaOH を加えて加熱する | NH₃ | 濃塩酸を近づけると**白煙**が生じる／湿った**赤色リトマス紙が青変**する
- **塩素 Cl** | 焼いた銅線につけて加熱する | CuCl₂ | **青緑色**の炎色反応が見られる（バイルシュタイン反応）
- **硫黄 S** | 金属 Na を加えて加熱・融解する | Na₂S | 水に溶かして酢酸鉛(II)水溶液を加えると**黒色沈殿**が生じる
:::

**この表の「操作」と「確認方法」は、5元素とも組にして必ず覚えてください。**反応そのものはどれも無機で習ったものなので、無機の知識と結び付けると覚える量が減ります。

:::section
anchor: carbon
title: 炭素の確認 —— 石灰水の白濁
lead: 完全燃焼で出た CO₂ を、石灰水との中和で見つけます。
terms:
- 完全燃焼
- 白濁
:::

炭素を含む有機化合物を完全燃焼させると、二酸化炭素が発生します。この気体を石灰水に通じると、炭酸カルシウムの白色沈殿が生じて白濁します。

:::reaction
left: Ca(OH)₂ ＋ CO₂
right: CaCO₃↓ ＋ H₂O
level: ★★★
note: 酸性酸化物の CO₂ と、塩基の Ca(OH)₂ の中和です。白濁の正体は CaCO₃ の沈殿です。
:::

:::reaction
left: CaCO₃ ＋ CO₂ ＋ H₂O
right: Ca(HCO₃)₂
level: ★★☆
note: CO₂ を通じ続けると、沈殿が炭酸水素カルシウムになって溶け、無色にもどります。
:::

確認に使うのは「**一度白濁したか**」です。通じ続けて透明にもどっても、CO₂ が出たことに変わりはありません。

:::section
anchor: hydrogen
title: 水素の確認 —— 硫酸銅(II)無水物の青変
lead: 完全燃焼で出た H₂O を、白色の無水物が水和して青くなる変化で見つけます。
terms:
- 硫酸銅(II)五水和物
- 塩化コバルト紙
:::

水素を含む有機化合物を完全燃焼させると、水が発生します。白色の硫酸銅(II)無水物は少量の水と反応して、青色の硫酸銅(II)五水和物になります。

:::reaction
left: CuSO₄ ＋ 5H₂O
right: CuSO₄・5H₂O
level: ★★★
note: 白色の無水物が、青色の五水和物になります。
:::

:::reaction
left: CuSO₄・5H₂O
over: 加熱
right: CuSO₄ ＋ 5H₂O
level: ★★☆
note: 逆向きの変化です。加熱すると水和水が抜けて白色にもどる、可逆な反応です。
:::

青色の塩化コバルト紙が赤色に変わることでも水を検出できます。高校化学ではあまり登場しないので、**塩化コバルト紙は覚えなくても構いません**。見て「水の検出だ」と分かれば十分です。

:::section
anchor: nitrogen
title: 窒素の確認 —— アンモニアの白煙
lead: NaOH と加熱して出た NH₃ を、塩酸との白煙かリトマス紙で見つけます。
terms:
- アンモニア
- 白煙
- 塩化アンモニウム
:::

窒素を含む有機化合物に水酸化ナトリウムを加えて加熱すると、有機化合物が分解されてアンモニアが発生します。濃塩酸をつけたガラス棒を近づけると、塩化アンモニウムの細かい結晶が白煙として見えます。

:::reaction
left: NH₃ ＋ HCl
right: NH₄Cl
level: ★★★
note: 塩基の NH₃ と酸の HCl の中和です。白煙は NH₄Cl の微粒子です。
:::

アンモニアは高校化学で扱う気体のうち、ただ1つの塩基性の気体です。そのため、湿らせた赤色リトマス紙を青く変えることでも確認できます。

この方法で NH₃ が出るのは、アミノ基 −NH₂ のような形で N が入っているときです。ニトロ基 −NO₂ の N ではアンモニアが発生しません。**この区別は覚える必要はありません。**

:::section
anchor: chlorine-sulfur
title: 塩素・硫黄の確認
lead: 塩素は銅線の炎色反応、硫黄は硫化鉛(II)の黒色沈殿で見つけます。
terms:
- バイルシュタイン反応
- 硫化ナトリウム
- 硫化鉛(II)
:::

塩素を含む有機化合物を、焼いた銅線につけて加熱すると、塩化銅(II)が生じて銅の**青緑色**の炎色反応が見られます。これを**バイルシュタイン反応**といいます。塩素の確認は無機化学では習わないので、**この組は丸暗記で構いません**。

:::reaction
left: 試料中の Cl ＋ Cu
over: 焼いた銅線・加熱
right: CuCl₂
level: ★★☆
note: CuCl₂ は炎の中で気化しやすいので、Cu の炎色反応が見えます。銅線そのものを炎に入れても、この色は出ません。
:::

:::mistake
wrong: 銅線の炎色反応で青緑色が見えたので、試料には塩素が入っている。
right: 青緑色が見えて分かるのは「ハロゲンが入っている」までです。臭素やヨウ素を含む化合物でも同じ色が出ます。
why: 高校の問題では試料がふつう塩素化合物なので Cl と答えて済みますが、選択肢に Br や I が並んでいる問題では、この1歩で外れます。
:::

硫黄を含む有機化合物に金属ナトリウムを加えて加熱・融解すると、硫化ナトリウムが生じます。これを水に溶かして酢酸鉛(II)水溶液を加えると、硫化鉛(II)の黒色沈殿が生じます。

:::reaction
left: Na₂S ＋ Pb(CH₃COO)₂
right: PbS↓ ＋ 2CH₃COONa
level: ★★☆
note: S²⁻ と Pb²⁺ の沈殿反応です。硫化物イオンは多くの金属イオンと黒色の沈殿をつくります。
:::

## 酸素だけは確認の操作が無い

酸素には、上の4元素のような確認の操作がありません。燃焼に使う O₂ からも CO₂ や H₂O の O が来るので、生成物を見ても試料に O があったかどうかは分からないためです。

★ 酸素は、次のページの元素分析で「**全体の質量から C と H を引いた残り**」として出します。

:::link
to: elemental-analysis
text: どれだけ入っているかを量る元素分析のページへ
:::

:::section
anchor: range
title: 覚える範囲
lead: 表の組は必ず、反応式は3本、ほかは読めれば十分です。
:::

**5元素の「操作」と「確認方法」の組は、必ず覚えてください。**

反応式は **Ca(OH)₂ ＋ CO₂**・**CuSO₄ ＋ 5H₂O**・**NH₃ ＋ HCl** の3本を書けるようにしましょう。どれも無機化学で一度書いた式です。

炭酸水素カルシウムができる逆向きの式、硫化鉛(II)の沈殿の式は、問題文に操作が書いてあれば読み取れる程度で構いません。塩化コバルト紙、ニトロ基では NH₃ が出ないことは**覚えなくても構いません**。

ただし「**青緑色の炎色反応はハロゲン全体で出る**」ことは覚えておきましょう。

:::exercise
source: slides:有機の基本1-3「元素の確認」s7「練習」(1)〜(5)（解答は s8）
prompt: 次の操作で存在が確認できる元素を、元素記号で答えよ。**(1) 完全燃焼して発生した気体を石灰水に通じると白濁した　(2) 完全燃焼して生じた液体を硫酸銅(II)無水物につけると青くなった　(3) 焼いた銅線の先につけて加熱すると青緑色の炎色反応を示した　(4) 金属ナトリウムと加熱・融解した生成物を水に溶かし、酢酸鉛(II)水溶液を加えると黒色沈殿を生じた　(5) 水酸化ナトリウムを加えて加熱し、発生した気体に濃塩酸をつけたガラス棒を近づけると白煙を生じた**
answer: (1) C　(2) H　(3) Cl（正確には「ハロゲン」まで）　(4) S　(5) N
:::

:::exercise
source: slides:有機の基本1-3「元素の確認」s9「練習」(1)〜(4)（解答は s10〜s13）
prompt: 次の変化を化学反応式で書け。**(1) 石灰水に二酸化炭素を吹き込むと白濁した　(2) (1) の液にさらに二酸化炭素を吹き込むと無色になった　(3) 硫酸銅(II)無水物に水を滴下すると青くなった　(4) 酢酸鉛(II)水溶液に硫化水素を吹き込むと黒色沈殿が生じた**
answer: (1) Ca(OH)₂ ＋ CO₂ → CaCO₃ ＋ H₂O　(2) CaCO₃ ＋ CO₂ ＋ H₂O → Ca(HCO₃)₂　(3) CuSO₄ ＋ 5H₂O → CuSO₄・5H₂O　(4) Pb(CH₃COO)₂ ＋ H₂S → PbS ＋ 2CH₃COOH　(4) は硫化水素が弱酸なので、生じるのは酢酸です。
:::
