酸化と還元は、**電子 e⁻ のやりとり**で説明します。酸化剤と還元剤がどちらの向きに e⁻ を渡すかさえ押さえれば、半反応式・酸化還元反応式・電池・電気分解はすべて同じ見方で読めます。

:::

:::section
anchor: definition
title: 酸化還元反応とは
lead: 還元剤が放出した電子 e⁻ を、酸化剤が受け取る反応です。
terms:
- 酸化還元反応
- 酸化剤
- 還元剤
codes:
- theo.redox.agent-def
:::

還元剤が放出した電子 e⁻ を酸化剤が受け取る反応を「酸化還元反応」といいます。

反応相手から**電子を受け取る物質**を「酸化剤」、反応相手に**電子を与える物質**を「還元剤」といいます。

## 具体例

過マンガン酸カリウム KMnO₄ と過酸化水素 H₂O₂ の反応では、それぞれ次のように e⁻ をやりとりしています。

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 酸化剤の反応式。**左辺に e⁻ がある**ので、MnO₄⁻ が e⁻ を受け取ったことがわかります。
:::

:::reaction
left: H₂O₂
right: O₂↑ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 還元剤の反応式。**右辺に e⁻ がある**ので、H₂O₂ が e⁻ を放出したことがわかります。「↑」は気体の発生を表します。
:::

このように、酸化剤・還元剤それぞれが e⁻ をどう受け渡すかを書いた式を「半反応式」といいます。**左辺に e⁻ があれば酸化剤、右辺に e⁻ があれば還元剤**です。

:::link
to: half-reaction
text: 半反応式の書き方と、覚えておく酸化剤・還元剤は「半反応式の書き方」で
:::

:::section
anchor: role
title: 酸化剤と還元剤の役割
lead: 酸化剤は相手を酸化し、自分は還元されます。還元剤はその逆です。
terms:
- 酸化
- 還元
codes:

:::

e⁻ を失うことを「酸化される」、e⁻ を受け取ることを「還元される」といいます。酸化剤は相手から e⁻ を奪うので、**相手を酸化し、自分は還元されます**。

:::figure
src: redox-basics-role-table.png
svg: redox-basics-role-table.svg
alt: 酸化剤と還元剤の役割の表。酸化剤は相手を酸化する・自分は還元される・電子を受け取る・酸化数は減る。還元剤は相手を還元する・自分は酸化される・電子を失う・酸化数は増える。右に、還元剤から酸化剤へ e⁻ が渡る矢印の図
caption: 酸化剤と還元剤の役割。**「相手を」と「自分は」で向きが逆になる**ところが混乱しやすいところです。
:::

:::

**この表は必ず暗記してください。**特に「酸化剤は自分は還元される」は、言葉だけで覚えると逆にしがちです。「酸化剤は e⁻ を受け取る」の1行から、残りの3行を導けるようにしておくとよいでしょう。

:::mistake
wrong: 酸化剤は酸化される物質である
right: 酸化剤は**相手を酸化し、自分は還元される**物質です。
why: 「酸化剤」という名前は「相手を酸化するはたらきをもつもの」という意味です。酸化剤は e⁻ を受け取るので、自分自身は還元されています。
:::

酸化と還元は、**必ず同時に起こります**。還元剤が放出した e⁻ は、どこかで酸化剤が受け取らなければならないためです。

:::section
anchor: oxidation-number-change
title: 酸化数の増減で見分ける
lead: 反応の前後で酸化数が変化した原子があれば、酸化還元反応です。
terms:
- 酸化数
codes:
- theo.redox.oxnum-judge
:::

「単体の状態を基準（酸化数0）に、原子が失った電子 e⁻ の数」を酸化数といいます。原子が e⁻ を失えば酸化数は増え、受け取れば減ります。

:::reaction
left: Na
right: Na⁺ ＋ e⁻
level: ★★★
note: Na の酸化数は 0 → ＋1。e⁻ を1個失ったので、Na は酸化されました（還元剤としてはたらいています）。
:::

:::reaction
left: Cl₂ ＋ 2e⁻
right: 2Cl⁻
level: ★★★
note: Cl の酸化数は 0 → −1。e⁻ を受け取ったので、Cl₂ は還元されました（酸化剤としてはたらいています）。
:::

**酸化数が減った原子を含む物質が酸化剤、増えた原子を含む物質が還元剤**です。

「反応によって酸化数の変化した原子がある」＝「酸化還元反応である」と覚えましょう。逆に、どの原子の酸化数も変わらない反応は、酸化還元反応ではありません。

## 具体例

中和反応 HCl ＋ NaOH → NaCl ＋ H₂O では、H は ＋1、Cl は −1、Na は ＋1、O は −2 のまま変わりません。そのため中和反応は酸化還元反応ではありません。

一方、亜鉛 Zn を硫酸銅(Ⅱ) CuSO₄ 水溶液に入れると、Zn の酸化数は 0 → ＋2、Cu の酸化数は ＋2 → 0 と変化します。これは酸化還元反応です。

:::reaction
left: Zn ＋ Cu²⁺
right: Zn²⁺ ＋ Cu
level: ★★★
note: Zn が還元剤（酸化数が増えた）、Cu²⁺ が酸化剤（酸化数が減った）です。
:::

:::mistake
wrong: 色が変わる反応は酸化還元反応である
right: 酸化還元反応かどうかは、**酸化数が変化した原子があるか**で決めます。
why: 例えば、黄色のクロム酸イオン CrO₄²⁻ の水溶液に酸を加えると、赤橙色の二クロム酸イオン Cr₂O₇²⁻ に変わります（2CrO₄²⁻ ＋ 2H⁺ ⇄ Cr₂O₇²⁻ ＋ H₂O）。色は変わりますが、Cr の酸化数はどちらも ＋6 で変わらないので、これは酸化還元反応ではありません。
:::

## 例題 —— 酸化数の増減で見分ける

:::exercise
source: slides:無機の基本１「無機の前に復習すべきこと」p.43（Zn と Cu²⁺ の反応）とp.33 の対応表から作った問い
prompt: 亜鉛 Zn の板を硫酸銅(Ⅱ) CuSO₄ 水溶液に入れると、亜鉛の表面に銅が析出した。**この反応で (1) 酸化された物質 (2) 還元された物質 (3) 酸化剤 (4) 還元剤 をそれぞれ答えよ。**
answer: **(1) Zn　(2) Cu²⁺（CuSO₄）　(3) Cu²⁺（CuSO₄）　(4) Zn** です。イオン反応式は Zn ＋ Cu²⁺ → Zn²⁺ ＋ Cu で、Zn の酸化数は 0 → ＋2 に増え（e⁻ を失った ＝ 酸化された ＝ 還元剤）、Cu の酸化数は ＋2 → 0 に減っています（e⁻ を受け取った ＝ 還元された ＝ 酸化剤）。**酸化された物質が還元剤、還元された物質が酸化剤**になります。
:::

:::section
anchor: oxygen-hydrogen
title: 酸素・水素のやりとりで見る酸化と還元
lead: 酸素を受け取る・水素を失う変化も酸化です。どちらも e⁻ のやりとりで説明できます。
terms:
- 酸素のやりとり
- 水素のやりとり
codes:
- theo.redox.o-h-definition
:::

酸化と還元は、もともと酸素や水素のやりとりで定義されていました。**物質が酸素を受け取る、または水素を失う変化が酸化**、**酸素を失う、または水素を受け取る変化が還元**です。

## 具体例

銅を空気中で加熱すると、銅は酸素を受け取って酸化銅(Ⅱ)になります。銅は酸化されています。

:::reaction
left: 2Cu ＋ O₂
over: 加熱
right: 2CuO
level: ★★☆
note: Cu の酸化数は 0 → ＋2。酸素を受け取る変化は、e⁻ で見ても酸化です。
:::

加熱した酸化銅(Ⅱ)に水素を通じると、酸化銅(Ⅱ)は酸素を失って銅に戻ります。酸化銅(Ⅱ)は還元され、水素は酸化されています。

:::reaction
left: CuO ＋ H₂
over: 加熱
right: Cu ＋ H₂O
level: ★★☆
note: Cu の酸化数は ＋2 → 0（還元）、H の酸化数は 0 → ＋1（酸化）。
:::

酸素や水素が関わらない反応（Zn と Cu²⁺ など）もあるので、**高校化学では e⁻ のやりとり（酸化数の増減）の定義で考えれば十分です**。酸素・水素での言い方は、「酸化」「還元」という言葉の由来として知っておけば問題ありません。
