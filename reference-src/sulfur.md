硫黄 S は16族の元素で、化合物の中で酸化数 −2 から +6 までの状態をとります。このページでは、単体（0）・硫化水素 H₂S（−2）・二酸化硫黄 SO₂ と亜硫酸（+4）を見ます。+6 の三酸化硫黄と硫酸は「硫酸」のページです。どの物質も、反応を**役割ごと**（酸・還元剤・酸化剤・沈殿）に分けて並べます。

斜方硫黄と単斜硫黄は小さい S₈ 分子の分子結晶なので、無極性溶媒の CS₂ に溶けます。ゴム状硫黄は巨大な鎖状分子なので CS₂ に溶けません。

**覚えるのは表の2点（常温で安定なのは斜方硫黄、ゴム状硫黄のつくり方）だけで十分です。**ほかの欄は理由から出せます。

硫黄を空気中で燃やすと、二酸化硫黄 SO₂ ができます（S ＋ O₂ → SO₂）。空気中の燃焼では S の酸化数は +4 で止まります。

H₂S は H₂O と同じ折れ線形の極性分子です。

## 硫化水素の製法 —— 弱酸の遊離

硫化鉄(Ⅱ) FeS に希硫酸を加えると H₂S が発生します。弱酸の H₂S が、強酸の H₂SO₄ によって追い出される反応です。

:::reaction
left: FeS ＋ H₂SO₄
right: FeSO₄ ＋ H₂S↑
level: ★★★
note: 「弱酸と塩基の塩 ＋ 強酸 → 強酸と塩基の塩 ＋ 弱酸」の型。FeS の S²⁻ が H⁺ を2個受け取って H₂S になり、残った Fe²⁺ と SO₄²⁻ が組んで FeSO₄ になります。
:::

## 【還元剤】単体の S になる

:::reaction
left: H₂S
right: S ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 強い2価の還元剤。S の酸化数が −2 → 0。「H₂S は S になる」ことを覚えて半反応式を書きます。
:::

H₂S の還元力は極めて強く、ふつうは還元剤としてはたらく SO₂ まで還元します（下の SO₂ の【酸化剤】で組み立てます）。

## 【沈殿】S²⁻ は多くの金属イオンと黒色沈殿をつくる

:::reaction
left: Cu²⁺ ＋ S²⁻
right: CuS↓
level: ★★★
note: 黒色沈殿。
:::

:::reaction
left: Pb²⁺ ＋ S²⁻
right: PbS↓
level: ★★★
note: 黒色沈殿。酢酸鉛(Ⅱ) Pb(CH₃COO)₂ をしみ込ませたろ紙に H₂S が触れると黒くなる（**H₂S の検出**）。
:::

硫化物の沈殿は多くが黒色です。**黒色でないものは ZnS（白）・CdS（黄）・SnS（褐）・MnS（淡赤）の4つだけ覚えましょう。**MnS は淡桃色と書く資料もあります。

硫化物が沈殿するかどうかは、金属のイオン化傾向と、水溶液の液性で決まります。

:::table
caption: 硫化物イオン S²⁻ で沈殿するか（イオン化傾向の順）

head:
- 金属イオンのもとの金属
- S²⁻ との沈殿
align: left | left
rows:
- Li・K・Ca・Na・Mg | 沈殿しない
- Al・Zn・Fe・Ni | 中性・塩基性で沈殿する（酸性では沈殿しない）。Al は硫化物ではなく Al(OH)₃ として沈む
- Sn・Pb・（H₂）・Cu・Hg・Ag | 酸性でも沈殿する（中性・塩基性ではもちろん沈殿する）
- Pt・Au | −
:::

イオン化傾向が小さい金属のイオンほど、S²⁻ と沈殿をつくりやすくなります。酸性の水溶液では H₂S の電離が抑えられて S²⁻ が少なくなるので、沈殿しやすいものだけが沈みます。Al³⁺ は硫化物 Al₂S₃ のままではいられず、水と反応（加水分解）して Al(OH)₃ として沈殿します（Al₂S₃ ＋ 6H₂O → 2Al(OH)₃ ＋ 3H₂S）。

## 【酸性酸化物】水に溶けて弱酸、塩基と中和

SO₂ は酸性酸化物で、水に溶けると S の酸化数が同じ +4 のオキソ酸、亜硫酸 H₂SO₃ になります（酸化数は変わりません）。SO₂ ＋ H₂O → H₂SO₃ と H₂SO₃ の1段階目の電離をまとめた、次のイオン反応式の方がよく使われます。

:::reaction
left: SO₂ ＋ H₂O
right: H⁺ ＋ HSO₃⁻
level: ★★★
note: （可逆）SO₂ が水に溶けて弱酸性を示す反応。
:::

:::reaction
left: HSO₃⁻
arrow: ⇄
right: H⁺ ＋ SO₃²⁻
level: ★★★
note: 亜硫酸の2段階目の電離。
:::

実際には、水溶液中の SO₂ は H₂SO₃ にはならず SO₂ のまま存在していると考えられています（H₂SO₃ という分子は存在しない）。それでも H₂SO₃ があると仮定した方が、反応が理解しやすくなります。

:::reaction
left: SO₂ ＋ 2NaOH
right: Na₂SO₃ ＋ H₂O
level: ★★★
note: SO₂ が酸、NaOH が塩基の中和反応。H₂SO₃ ＋ 2NaOH → Na₂SO₃ ＋ 2H₂O の両辺から H₂O を1つずつ引くと、この式になります。
:::

**「オキソ酸の中和の式から H₂O を引く」**と、酸性酸化物と塩基の反応はどれも同じ手順で書けます。

## 【還元剤】SO₄²⁻ になる

SO₂ は2価の還元剤としてはたらき、S の酸化数が +4 → +6 になります。16族の S は、最高酸化数の +6 の状態が安定です（周囲に強い酸化剤が多いので、e⁻ を6個失った状態の方が安定になる）。

:::reaction
left: SO₂ ＋ 2H₂O
right: SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻
level: ★★★
note: SO₂ は基本的に還元剤としてはたらきます。
:::

:::reaction
left: H₂O₂ ＋ SO₂
right: H₂SO₄
level: ★★★
note: H₂O₂ が酸化剤、SO₂ が還元剤。H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O と足すと H⁺ と H₂O が打ち消し合います。
:::

亜硫酸ナトリウム Na₂SO₃ の SO₃²⁻ も、同じく +4 → +6 の2価の還元剤です。SO₂ の半反応式と実質的に同じものです。

:::reaction
left: SO₃²⁻ ＋ H₂O
right: SO₄²⁻ ＋ 2H⁺ ＋ 2e⁻
level: ★★★
note: 亜硫酸イオンが還元剤としてはたらくとき。
:::

//⚠ スライド s17・s44 はこの半反応式を ⇄ で書いている。ほかの半反応式と同じく → にそろえた（校正で判断）

## 【酸化剤】H₂S が相手のときだけ S になる

SO₂ は、極めて還元力の強い H₂S が相手のときだけ、4価の**酸化剤**としてはたらきます。S の酸化数が +4 → 0 になり、e⁻ を4個受け取ります。

:::reaction
left: SO₂ ＋ 4H⁺ ＋ 4e⁻
right: S ＋ 2H₂O
level: ★★★
note: SO₂ が酸化剤としてはたらくときの半反応式。
:::

caption: 「SO₂ は S になる」とだけ覚えておき、O を H₂O で、H を H⁺ で、電荷を e⁻ で合わせます。

:::reaction
left: 2H₂S ＋ SO₂
right: 3S ＋ 2H₂O
level: ★★★
note: SO₂ が酸化剤、H₂S が還元剤。H₂S → S ＋ 2H⁺ ＋ 2e⁻ を2倍して e⁻ を4個にそろえ、足したものです。
:::

「S 以外の部分」を見ると、左辺の H 4個と O 2個が右辺の 2H₂O になっています。**S がすべて単体の S になる**ことに着目すると、半反応式を組まなくても書けます。

answer: (1) SO₂ ＋ 4H⁺ ＋ 4e⁻ → S ＋ 2H₂O　(2) SO₂ ＋ 2H₂O → SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻　(3) H₂O₂ ＋ SO₂ → H₂SO₄　(4) SO₂ ＋ H₂O ⇄ H⁺ ＋ HSO₃⁻、HSO₃⁻ ⇄ H⁺ ＋ SO₃²⁻　(5) SO₃²⁻ ＋ H₂O → SO₄²⁻ ＋ 2H⁺ ＋ 2e⁻　すべて★★★です。(1) と (2) で、SO₂ が酸化剤なら S、還元剤なら SO₄²⁻ になることを確かめましょう。
