クロム Cr（6族）とマンガン Mn（7族）は遷移元素です。遷移元素は1つの元素がいくつもの酸化数をとり、**酸化数によってイオンや化合物の色が変わる**ものが多くあります。この2つはその代表で、**酸化数の大きい化合物は強い酸化剤**になります。

酸化数は、O を −2、K を ＋1 として計算します。KMnO₄ なら、Mn の酸化数を x として (＋1) ＋ x ＋ (−2)×4 ＝ 0 より x ＝ ＋7 です。K₂Cr₂O₇ なら (＋1)×2 ＋ 2x ＋ (−2)×7 ＝ 0 より x ＝ ＋6 です。

**MnO₄⁻ 赤紫 → Mn²⁺ ほぼ無色、Cr₂O₇²⁻ 橙赤 → Cr³⁺ 緑、の2つの色の変化は必ず覚えてください。**酸化還元滴定や、還元剤の検出の問題で「色が変わった」と書かれるのはこの2つです。

## 過マンガン酸カリウム KMnO₄【酸化剤】

過マンガン酸カリウムの固体は、黒っぽい紫色の結晶です。水に溶かすと MnO₄⁻ ができ、液は赤紫色になります。**硫酸で酸性にした水溶液**の中で、強い酸化剤としてはたらきます。

:::reaction
left: MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻
right: Mn²⁺ ＋ 4H₂O
level: ★★★
note: 酸性。赤紫色 → ほぼ無色。
:::

:::reaction
left: MnO₄⁻ ＋ 2H₂O ＋ 3e⁻
right: MnO₂ ＋ 4OH⁻
level: ★★☆
note: 中性・塩基性では Mn²⁺ まで行かず、黒褐色の MnO₂ が沈殿します。
:::

酸性にするのに**硫酸**を使うのは、塩酸では Cl⁻ が MnO₄⁻ に酸化されて Cl₂ になってしまい、硝酸ではそれ自身が酸化剤としてはたらいてしまうためです。**「KMnO₄ は硫酸酸性」と組にして覚えてください。**

鉄(Ⅱ)イオンとの反応では、MnO₄⁻ 1個が e⁻ を5個受け取るので、Fe²⁺ は5個要ります。

:::reaction
left: MnO₄⁻ ＋ 5Fe²⁺ ＋ 8H⁺
right: Mn²⁺ ＋ 5Fe³⁺ ＋ 4H₂O
level: ★★☆
note: 酸化剤の半反応式と Fe²⁺ → Fe³⁺ ＋ e⁻ を5倍して足したもの。
:::

## 酸化マンガン(Ⅳ) MnO₂【触媒】【酸化剤】

酸化マンガン(Ⅳ)（二酸化マンガン）は黒褐色の粉末で、水に溶けません。同じ MnO₂ でも、反応によって役割が違います。

過酸化水素水に加えると、自分は変化せずに分解を速める**触媒**としてはたらき、酸素が発生します。

:::reaction
left: 2H₂O₂
over: MnO₂（触媒）
right: 2H₂O ＋ O₂
level: ★★★
note: 酸素の実験室的製法。MnO₂ は反応の前後で変わりません。
:::

濃塩酸と加熱すると、**酸化剤**としてはたらいて Cl⁻ を Cl₂ に酸化し、自分は Mn²⁺ になります。

:::reaction
left: MnO₂ ＋ 4HCl
over: 加熱
right: MnCl₂ ＋ 2H₂O ＋ Cl₂
level: ★★★
note: 塩素の実験室的製法。MnO₂ ＋ 4H⁺ ＋ 2e⁻ → Mn²⁺ ＋ 2H₂O が酸化剤の半反応式です。
:::

**「H₂O₂ では触媒、濃塩酸では酸化剤」は必ず区別してください。**式の上では、MnO₂ が右辺に Mn²⁺ として出てくるかどうかで見分けられます。MnO₂ はマンガン乾電池の正極にも使われます。

:::link
to: chlorine
text: 塩素の製法と洗気瓶は塩素と塩化水素のページへ
:::

## 二クロム酸カリウム K₂Cr₂O₇【酸化剤】

二クロム酸カリウムは橙赤色の結晶です。硫酸酸性の水溶液の中で、強い酸化剤としてはたらきます。

:::reaction
left: Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻
right: 2Cr³⁺ ＋ 7H₂O
level: ★★★
note: 橙赤色 → 緑色。Cr が2個あるので e⁻ は 3×2 ＝ 6個です。
:::

## クロム酸イオンと二クロム酸イオンの平衡

黄色のクロム酸カリウム水溶液に酸を加えると橙赤色の二クロム酸イオンになり、塩基を加えると黄色にもどります。

:::reaction
left: 2CrO₄²⁻ ＋ 2H⁺
arrow: ⇄
right: Cr₂O₇²⁻ ＋ H₂O
level: ★★☆
note: 酸性では右、塩基性では左に片寄ります。
:::

:::mistake
wrong: クロム酸イオン（黄色）が二クロム酸イオン（橙赤色）に変わるのは、酸化還元反応である。
right: この変化は**酸化還元反応ではありません**。Cr の酸化数は CrO₄²⁻ でも Cr₂O₇²⁻ でも **＋6** のままです。
why: 色が変わると酸化数が変わったと思いがちですが、ここでは H⁺ の出入りで2個の CrO₄²⁻ が O を1個はずしてつながっただけです。色が「緑」に変わったときが、Cr が ＋3 に還元されたときです。
:::

クロム酸イオンは、Ag⁺・Pb²⁺・Ba²⁺ と沈殿をつくります。色が違うので、陽イオンの確認に使われます。

:::table

head:

- 沈殿
- 色

rows:
- Ag⁺ | Ag₂CrO₄ | **赤褐色**
- Pb²⁺ | PbCrO₄ | **黄色**
- Ba²⁺ | BaCrO₄ | **黄色**
:::

right: Ag₂CrO₄↓
level: ★★☆
:::

## 水酸化クロム(Ⅲ)（発展）

Cr³⁺ を含む水溶液に塩基を加えると、灰緑色の水酸化クロム(Ⅲ) が沈殿します。この沈殿は、水酸化アルミニウムと同じように酸にも過剰の強塩基にも溶ける**両性**を示します。

## 必ず覚えるもの（★★★）

:::list
items:
- MnO₄⁻ 赤紫 → Mn²⁺ ほぼ無色、Cr₂O₇²⁻ 橙赤 → Cr³⁺ 緑、CrO₄²⁻ 黄
- MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺ ＋ 4H₂O
- Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O
- KMnO₄・K₂Cr₂O₇ は硫酸酸性で使う
- 2H₂O₂ → 2H₂O ＋ O₂（MnO₂ 触媒）、MnO₂ ＋ 4HCl → MnCl₂ ＋ 2H₂O ＋ Cl₂
:::

半反応式は丸暗記もよいですが、「反応前後の物質（MnO₄⁻ → Mn²⁺、Cr₂O₇²⁻ → Cr³⁺）だけ覚え、O を H₂O で、H を H⁺ で、電荷を e⁻ で合わせる」手順で書けるようにしておきましょう。中性・塩基性での MnO₄⁻ の式、クロム酸塩の沈殿の式は、見て分かれば十分です。
