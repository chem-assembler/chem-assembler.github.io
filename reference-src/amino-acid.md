1つの分子の中に、**アミノ基 −NH₂** と**カルボキシ基 −COOH** を両方もつ化合物を**アミノ酸**といいます。タンパク質を加水分解すると得られるのが、このアミノ酸です。

:::section
anchor: general
title: α-アミノ酸の一般式
lead: −NH₂ と −COOH が同じ炭素原子に結合したアミノ酸を α-アミノ酸といいます。一般式は R−CH(NH₂)−COOH です。
terms:
- アミノ酸
- α-アミノ酸
- 側鎖
:::

−NH₂ と −COOH が**同じ炭素原子**に結合しているアミノ酸を**α-アミノ酸**といいます。タンパク質をつくるアミノ酸は、すべて α-アミノ酸です。

一般式は **R−CH(NH₂)−COOH** で、R の部分を**側鎖**といいます。R に何を入れるかで、アミノ酸の種類が決まります。

:::list
items:
- R に H を入れれば「H−CH(NH₂)−COOH」＝ **グリシン**
- R に CH₃ を入れれば「CH₃−CH(NH₂)−COOH」＝ **アラニン**
- R に ○○ を入れれば「○○−CH(NH₂)−COOH」＝ 別のアミノ酸
:::

**一般式 R−CH(NH₂)−COOH は書けるようにしてください。**グリシンとアラニンの2つは、構造式まで書けるようにしておきましょう。

caption: いちばん簡単なアミノ酸の**グリシン**。側鎖 R が H です。
:::

caption: **アラニン**。側鎖 R が CH₃ です。
:::

:::example

:::

:::section
anchor: sidechain
title: 側鎖による分類
lead: 側鎖に −COOH をもつものを酸性アミノ酸、−NH₂ をもつものを塩基性アミノ酸、どちらももたないものを中性アミノ酸といいます。
terms:
- 中性アミノ酸
- 酸性アミノ酸
- 塩基性アミノ酸
:::

α-アミノ酸は、どれも −NH₂ と −COOH を1個ずつもっています。そこに**側鎖にもう1個 −COOH があれば酸性アミノ酸**、**もう1個 −NH₂ があれば塩基性アミノ酸**、どちらも無ければ**中性アミノ酸**です。

:::table
caption: 代表的な α-アミノ酸
source: qa:org.bio.amino-acid-sidechain の分類と、compounds.json の各アミノ酸の構造から側鎖を読んで並べた
head:
- 名称
- 側鎖 R
- 分類
- 覚えどころ
align: left | left | left | left
rows:
- グリシン | −H | 中性 | 不斉炭素原子をもたない
- アラニン | −CH₃ | 中性 | いちばん簡単な不斉なアミノ酸
- システイン | −CH₂−SH | 中性 | **硫黄**をもつ
- フェニルアラニン | −CH₂−C₆H₅ | 中性 | **ベンゼン環**をもつ
- チロシン | −CH₂−C₆H₄−OH | 中性 | ベンゼン環とフェノール性の −OH をもつ
- グルタミン酸 | −(CH₂)₂−COOH | **酸性** | 側鎖に −COOH
- リシン | −(CH₂)₄−NH₂ | **塩基性** | 側鎖に −NH₂
:::

**この7つは、名前と側鎖の特徴（硫黄・ベンゼン環・余分な −COOH や −NH₂）まで暗記してください。**タンパク質の呈色反応でどれが陽性になるかに、そのままつながります。天然のタンパク質をつくるおよそ20種のアミノ酸を、すべて覚える必要はありません。

:::section
anchor: chirality
title: 不斉炭素原子
lead: α位の炭素には H・NH₂・COOH・R の4つが付くので、R が H でなければ不斉炭素原子になります。グリシンだけが例外です。
terms:
- 不斉炭素原子
- 鏡像異性体
:::

α-アミノ酸の α位の炭素には、**H・−NH₂・−COOH・R** の4つが結合しています。R が H 以外なら4つがすべて違うので、この炭素は**不斉炭素原子**になり、**鏡像異性体**が存在します。

グリシンは R が H なので、H が2個付くことになり、不斉炭素原子をもちません。**「α-アミノ酸のうち、不斉炭素原子をもたないのはグリシンだけ」**と覚えましょう。

天然のタンパク質をつくるアミノ酸は、鏡像異性体のうち L形とよばれる片方だけです。L形と D形の見分け方は覚えなくて構いません。

caption: 左の**アラニン**は α位の炭素に H・−NH₂・−COOH・−CH₃ の4つの違うものが付くので不斉炭素原子（囲み）。右の**グリシン**は H が2個なので、不斉炭素原子がありません。

:::section
anchor: zwitterion
title: 両性の化合物と双性イオン
lead: アミノ酸は酸とも塩基とも反応して塩をつくります。結晶中や水溶液中では、−COO⁻ と −NH₃⁺ を1分子にあわせもつ双性イオンになっています。
terms:
- 両性化合物
- 双性イオン
:::

アミノ酸の −NH₂ は塩基、−COOH は酸としてはたらきます。だからアミノ酸は、**塩酸とも水酸化ナトリウムとも反応して塩をつくります**。

具体例としてグリシンで書きます。塩酸とは −NH₂ が、水酸化ナトリウムとは −COOH が反応します。

:::reaction
left: H₂N−CH₂−COOH ＋ HCl
right: Cl⁻ H₃N⁺−CH₂−COOH
level: ★★☆
note: 塩基である −NH₂ が H⁺ を受け取り、グリシンの塩酸塩になります。
:::

:::reaction
left: H₂N−CH₂−COOH ＋ NaOH
right: H₂N−CH₂−COONa ＋ H₂O
level: ★★☆
note: 酸である −COOH が中和されて、グリシンのナトリウム塩になります。
:::

**「アミノ酸は酸とも塩基とも反応する」は暗記してください。**

さらに、1つの分子の中でも −COOH の H⁺ が −NH₂ に移ります。こうしてできた、**−COO⁻ と −NH₃⁺ をあわせもつイオン**を**双性イオン**といいます。アミノ酸は、結晶中でも中性付近の水溶液中でも、おもにこの形でいます。

グリシンの双性イオンは H₃N⁺−CH₂−COO⁻ です。全体では正と負が1つずつなので、電荷の合計は0になります。

:::figure
src: amino-acid-zwitterion.png
svg: amino-acid-zwitterion.svg
alt: 左にグリシンの中性の形 H2N-CH2-COOH を書き、その上に右端から左端へ向かう曲がった赤い矢印で H+ が移ることを示し、右向きの矢印の先に双性イオン H3N+-CH2-COO- を書いた図
caption: 外から酸や塩基を加えなくても、**同じ分子の中で** H⁺ が移ります。移ったあとも原子の数は変わりません。
:::

:::section
anchor: crystal
title: アミノ酸の結晶の性質
lead: 双性イオンどうしが静電気の力で引き合うので、分子量が同じくらいの有機化合物にくらべて融点が高く、水に溶けやすく、有機溶媒に溶けにくくなります。
terms:
- 双性イオン
:::

アミノ酸の結晶は、双性イオンの −COO⁻ と −NH₃⁺ が**静電気の力で引き合った、イオン結晶に近い**つくりになっています。

そのため、分子量が同じくらいの有機化合物にくらべて**融点が高く**（融点に達する前に分解するものが多い）、**水に溶けやすく、有機溶媒には溶けにくい**性質を示します。

**「アミノ酸は融点が高く、水に溶けやすい。双性イオンだから」**と、理由とセットで覚えましょう。

:::section
anchor: ph
title: pH で3つの形が入れかわる
lead: 酸性の水溶液中では陽イオン、塩基性の水溶液中では陰イオン、その間では双性イオンが多くなります。
terms:
- 陽イオン
- 陰イオン
- 電離平衡
:::

アミノ酸の水溶液に酸を加えて**酸性**にすると、−COO⁻ が H⁺ を受け取って**陽イオン**が多くなります。塩基を加えて**塩基性**にすると、−NH₃⁺ が H⁺ を失って**陰イオン**が多くなります。

:::reaction
left: R−CH(NH₃⁺)−COOH（陽イオン）
right: R−CH(NH₃⁺)−COO⁻（双性イオン） ＋ H⁺
level: ★★★
note: 1段目の電離。−COOH のほうが先に H⁺ を手放します。酸性にすると左へ寄ります。
:::

:::reaction
left: R−CH(NH₃⁺)−COO⁻（双性イオン）
right: R−CH(NH₂)−COO⁻（陰イオン） ＋ H⁺
level: ★★★
note: 2段目の電離。塩基性にすると右へ寄ります。この2本で、3つの形が1本につながります。
:::

**「H⁺ が多いところでは H⁺ を受け取り、少ないところでは手放す」**の1本で、どちらの形が増えるかはすべて決まります。

具体例としてアラニンで書くと、塩酸を十分に加えたときは CH₃−CH(NH₃⁺)−COOH（陽イオン）、水酸化ナトリウム水溶液を十分に加えたときは CH₃−CH(NH₂)−COO⁻（陰イオン）になります。

:::figure
src: amino-acid-three-forms.png
svg: amino-acid-three-forms.svg
alt: 左から陽イオン、双性イオン、陰イオンの3つの示性式を横一列に並べ、となりどうしを両向きの矢印で結んだ図。右へ行くほど H+ を放し、左へ行くほど H+ を受け取る。下には左が酸性側、右が塩基性側の pH の矢印と、等電点の目盛りがあり、いちばん下に電気泳動でどちらの電極へ動くかを書いてある
caption: 3つの形は1本につながっていて、**pH で左右にずれるだけ**です。図の左右と、電気泳動で動く向きがそのまま対応します。
:::

:::section
anchor: isoelectric
title: 等電点と電気泳動
lead: 陽イオン・双性イオン・陰イオンの電荷の合計が全体として0になる pH を等電点といいます。等電点では、電圧をかけてもアミノ酸はどちらの電極にも移動しません。
terms:
- 等電点
- 電気泳動
:::

水溶液の pH を変えていくと、ある pH で、陽イオン・双性イオン・陰イオンの**電荷の合計が全体として0**になります。この pH をそのアミノ酸の**等電点**といいます。等電点では、ほとんどが双性イオンになっています。

アミノ酸の水溶液に電圧をかけると、陽イオンは陰極へ、陰イオンは陽極へ移動します。これを**電気泳動**といいます。等電点では電荷の合計が0なので、**どちらの電極にも移動しません**。

:::table
caption: 水溶液の pH と、多くなる形・電気泳動での動き
source: qa:org.bio.zwitterion-ph・org.bio.isoelectric-point の記述から、pH と等電点の大小で3行に並べた
head:
- 水溶液の pH
- 多くなる形
- 電気泳動での動き
align: left | left | left
rows:
- 等電点より小さい（酸性側） | 陽イオン | **陰極**へ移動する
- 等電点と同じ | 双性イオン | 移動しない
- 等電点より大きい（塩基性側） | 陰イオン | **陽極**へ移動する
:::

**この表の3行の向きは暗記してください。**「自分の等電点より酸性側なら陽イオン」と覚えれば、残りの2行はその場で出ます。

等電点の値は、中性アミノ酸ではおよそ6、**酸性アミノ酸では小さく**（グルタミン酸は約3）、**塩基性アミノ酸では大きく**（リシンは約10）なります。側鎖の −COOH や −NH₂ のぶんだけ、酸性側か塩基性側へずれるためです。

**「酸性アミノ酸の等電点は小さい、塩基性アミノ酸の等電点は大きい」というずれ方だけは覚えてください。**個々のアミノ酸の等電点の数値は、覚える必要はありません。問題文に与えられます。

:::mistake
wrong: 等電点では、アミノ酸がすべて双性イオンになっている
right: 等電点は、陽イオン・双性イオン・陰イオンの**電荷の合計が全体として0になる pH** です。ほとんどが双性イオンですが、陽イオンと陰イオンもわずかに同じ量ずつあります。
why: 「双性イオンは電荷の合計が0」と「等電点では電荷の合計が0」を同じものとして覚えてしまうためです。★ 入試の記述では「電荷の合計（平均）が0になる pH」と書けば安全です。
:::

:::figure
src: amino-acid-electrophoresis.png
svg: amino-acid-electrophoresis.svg
alt: 電気泳動の装置の模式図。横長の容器の左端に陰極、右端に陽極を差し込み、上で電源につないである。容器の中央に置いたアミノ酸の水溶液から、左へ向かう矢印に陽イオン、右へ向かう矢印に陰イオンと書かれ、双性イオンは動かないと添えてある

:::

:::section
anchor: ninhydrin
title: アミノ酸の検出
lead: アミノ酸にニンヒドリン水溶液を加えて温めると、青紫色から赤紫色になります。
terms:
- ニンヒドリン反応
:::

アミノ酸の水溶液に**ニンヒドリン**の水溶液を加えて温めると、**青紫色〜赤紫色**になります。これを**ニンヒドリン反応**といい、アミノ基 −NH₂ を検出する反応です。

**「ニンヒドリン反応はアミノ酸の検出、色は青紫〜赤紫」は暗記してください。**ほかの呈色反応といっしょに、タンパク質のページで表にまとめています。

:::link

:::section
anchor: polyprotic
title: 酸性・塩基性アミノ酸の電離と、片方だけ反応させる手
advanced: true
lead: 酸性アミノ酸と塩基性アミノ酸は3段階に電離します。また、−COOH と −NH₂ のどちらか片方だけを反応させることもできます。
terms:
- 三段階の電離
:::

中性アミノ酸は、上の2本の式のとおり**2段階**に電離します。側鎖にも −COOH や −NH₂ をもつ酸性アミノ酸・塩基性アミノ酸は、それが1つ増えるので**3段階**に電離します。

たとえばグルタミン酸は、強い酸性では陽イオン、pH を上げていくと双性イオン、さらに側鎖の −COOH も H⁺ を失って陰イオン、最後に −NH₃⁺ も H⁺ を失って2価の陰イオンになります。等電点を電離定数から計算する問題は、式が与えられる前提で解ければ十分です。

アミノ酸の −COOH だけ、あるいは −NH₂ だけを反応させることもできます。塩化水素を触媒にしてエタノールと反応させると −COOH だけがエステルに、無水酢酸と反応させると −NH₂ だけがアセチル化されます。

:::reaction
left: H₂N−CH₂−COOH ＋ C₂H₅OH
over: 塩化水素
right: H₂N−CH₂−COOC₂H₅ ＋ H₂O
level: ★☆☆
note: −COOH がふさがるので、残った −NH₂ によって全体として塩基性の物質になります。
:::

:::reaction
left: H₂N−CH₂−COOH ＋ (CH₃CO)₂O
right: CH₃CO−NH−CH₂−COOH ＋ CH₃COOH
level: ★☆☆
note: −NH₂ がふさがるので、残った −COOH によって全体として酸性の物質になります。
:::

source: reference-outline/bio.md 第2部 amino-acid の例題2（①ドラフトのために起こした電気泳動の問題。等電点の数値は問題文で与える形）
prompt: グリシン（等電点 6.0）・グルタミン酸（等電点 3.2）・リシン（等電点 9.7）の混合水溶液を pH 6.0 に保って電気泳動した。それぞれ陽極・陰極のどちらに移動するか。移動しないものは「移動しない」と答えよ。
answer: グリシンは等電点なので**移動しない**。グルタミン酸は pH が等電点より大きいので陰イオンが多くなり**陽極**へ。リシンは pH が等電点より小さいので陽イオンが多くなり**陰極**へ移動します。
:::

:::exercise
source: reference-outline/bio.md 第2部 amino-acid の例題3（①ドラフトのために起こした記述問題）
prompt: アミノ酸の結晶が、分子量が同じくらいのほかの有機化合物にくらべて融点が高く、水に溶けやすいのはなぜか。
answer: 結晶中で**双性イオン**になっていて、正と負の電荷が静電気の力で引き合う、**イオン結晶に近いつくり**をしているためです。
:::
