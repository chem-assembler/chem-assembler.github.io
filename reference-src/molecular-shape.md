共有結合のページでは、原子どうしが電子を出し合って電子対をつくり、それを電子式や構造式で書き表しました。このページでは、その電子対が**空間の中でどう並ぶか**を考えます。並び方が分子の形を決め、形が決まると分子の極性（電荷の偏り）が決まります。

:::section
anchor: shapes
title: 覚えておく分子の形
lead: 直線形・折れ線形・三角錐形・正四面体形の4つの形と、それぞれの代表の分子を結びつけて覚えます。
terms:
- 直線形
- 折れ線形
- 三角錐形
- 正四面体形
- 結合角
:::

分子の立体的な形は、分子ごとに決まっています。隣り合う2つの共有結合がつくる角度を**結合角**といいます。まずは代表の分子の形を表で見ておきましょう。

:::table
caption: 代表的な分子の形
source: 教科書 化学基礎 2編2章の「分子の形」の表と PLUS 欄の結合角から、中心の原子のまわりの電子のまとまりの数の順に並べ直した
head:
- 分子
- 中心の原子のまわり
- 形
- 結合角
align: left | left | left | left
rows:
- H₂・HCl・N₂ | ——（原子が2個） | **直線形** | ——
- CO₂（O=C=O） | 二重結合 2組 | **直線形** | 180°
- H₂O | 共有電子対 2組 ＋ 非共有電子対 2組 | **折れ線形** | 104.5°
- NH₃ | 共有電子対 3組 ＋ 非共有電子対 1組 | **三角錐形** | 106.7°
- CH₄ | 共有電子対 4組 | **正四面体形** | 109.5°
:::

**「H₂O は折れ線、NH₃ は三角錐、CH₄ は正四面体、CO₂ は直線」の4つは必ず暗記してください。** 分子の極性や分子間力の問題は、すべてこの4つの形から始まります。結合角は、CH₄ の 109.5° だけ覚えておけば十分です。H₂O と NH₃ の値は「109.5° より少し狭く、H₂O のほうがさらに狭い」と言えれば困ることはほとんどありません。

原子が2個だけの分子（H₂・HCl・N₂・Cl₂ など）は、2点を結ぶと必ず直線になるので、形を考える必要はありません。

:::mistake
wrong: 水分子は構造式が H−O−H なので、3つの原子が一直線に並んだ直線形である
right: **水分子は折れ線形**（結合角 104.5°）です。構造式は原子のつながり方を平面に書いたもので、実際の形を表してはいません。
why: 構造式では非共有電子対を省略するので、O の上下にある2組の非共有電子対が見えなくなります。電子式に戻して数えると、O のまわりには4組の電子対があります。
:::

:::section
anchor: repulsion
title: 形が決まるしくみ —— 電子のまとまりの反発
lead: 電子対はどれも負の電荷をもつので、たがいに反発して、中心の原子のまわりでいちばん遠い位置に散ります。まとまりが2組なら直線、3組なら正三角形、4組なら正四面体の向きです。
terms:
- 電子対の反発
- 共有電子対
- 非共有電子対
:::

では、なぜ H₂O は折れ線で CH₄ は正四面体になるのかを見ていきましょう。鍵は、**電子対はどれも負の電荷をもっている**ことです。負どうしは反発するので、中心の原子のまわりにある電子対は、**たがいにいちばん遠くなる位置へ散ります**。

:::figure
src: methane-electron-pair.png
alt: メタンの電子式。炭素のまわりの4組の共有電子対が、負の電荷でたがいに反発するので正四面体になることを示した図
caption: 4組の電子対がたがいに反発して、いちばん遠い位置に散った結果が正四面体です。
:::

:::figure
src: methane-tetrahedron.png
alt: メタンの正四面体構造。中心の炭素から4本の結合が伸び、手前に出る結合を塗ったくさび、奥へ向かう結合を破線のくさびで描き、結合角109.5度を書き込んだ図
caption: 4組が散ると、正四面体の中心から4つの頂点へ向かう形になり、結合角は 109.5° です。
:::

形は、次の手順で決めます。**数えるのは「電子のまとまり」**で、共有電子対も非共有電子対も1組と数え、**二重結合・三重結合もまとめて1組**と数えます。

:::list
ordered: true
items:
- 中心の原子のまわりを電子式で書く。
　H₂O なら O のまわりに、H と共有する電子対 2組と、非共有電子対 2組
- 電子のまとまりを数える。二重結合・三重結合は1組と数える。
　CO₂ の C は O=C=O で、二重結合 2本 ＝ 2組
- まとまりの数で、散る向きを決める。
　2組なら直線（180°）、3組なら正三角形（120°）、4組なら正四面体（109.5°）
- 原子が付いている方向だけを見て、形の名前を付ける。非共有電子対は形の名前に数えない。
　4組のうち非共有電子対が1組なら三角錐形、2組なら折れ線形
:::

:::table
caption: 電子のまとまりの数と散る向き
source: 本文の手順の3段目を表にした。例は教科書 化学基礎 2編2章の分子と、有機のページ（アルカン・アルケン・アルキン・ベンゼン）で扱った分子
head:
- まとまりの数
- 散る向き
- 角度
- 例
align: left | left | left | left
rows:
- 2組 | 直線 | 180° | CO₂、エチン（アセチレン）の C
- 3組 | 正三角形（平面） | 120° | エテン（エチレン）の C、ベンゼンの C、ホルムアルデヒドの C
- 4組 | 正四面体 | 109.5° | CH₄、NH₃ の N、H₂O の O、ダイヤモンドの C
:::

「まとまりが○○組なら○○の向き」の3行は、**丸暗記でよいので覚えてしまいましょう**。有機化合物の形（アルカンの炭素は正四面体、C=C のまわりは平面で 120°、C≡C のまわりは直線）は、この表をそのまま当てはめただけです。

## 非共有電子対は場所を広く取る

NH₃ と H₂O は、CH₄ と同じく4組のまとまりをもっているので、電子対は正四面体の向きに散ります。ただし**非共有電子対は、共有電子対より空間を広く取ろうとする**ので、残りの共有電子対を押しのけ、結合角が 109.5° より少し狭くなります。非共有電子対が1組の NH₃ は 106.7°、2組の H₂O は 104.5° です。

「非共有電子対が多いほど結合角は狭い」ので、結合角の大きい順は **CH₄ ＞ NH₃ ＞ H₂O** です。この順は、数値を覚えていなくても理由から出せます。

電子対の反発で分子の形を説明するこの考え方は、VSEPR（原子価殻電子対反発）則と呼ばれます。名前を覚える必要はありません。

## 反発だけでは説明できない形（発展）

電子対の反発で説明できるのは「多くの分子」で、すべてではありません。テトラアンミン銅(Ⅱ)イオン [Cu(NH₃)₄]²⁺ がその例外で、配位子が4つあるのに正四面体ではなく**正方形**です。錯イオンの形は、反発から導くのではなく**イオンごとに覚えます**。

:::link
to: complex-ion
text: 錯イオンの形（直線・正方形・正四面体・正八面体）は、錯イオンのページへ
:::

:::section
anchor: polarity
title: 形から極性を決める
lead: 異なる原子の共有結合には電荷の偏り（結合の極性）があります。分子全体の極性は、結合の極性が形によって打ち消されるかどうかで決まります。
terms:
- 電気陰性度
- 結合の極性
- 極性分子
- 無極性分子
:::

結合している2つの原子は、あいだの共有電子対を自分の側へ引っぱり合っています。その引っぱる強さを原子ごとに数で表したのが**電気陰性度**です。フッ素 F が最大で、貴ガスを除くと周期表の右上の元素ほど大きくなります。

:::link
to: periodic-table
text: 電気陰性度が周期表の上でどう変わるかは、周期表のページへ
:::

電気陰性度の違う2つの原子が共有結合すると、共有電子対は電気陰性度の大きい原子の方へ引き寄せられ、そちらがわずかに負（δ−）、相手がわずかに正（δ＋）の電荷を帯びます。このような電荷の偏りを「**結合に極性がある**」といいます。同じ原子どうしの結合（H−H・Cl−Cl）には極性がありません。

分子全体として電荷の偏りをもつ分子を**極性分子**、もたない分子を**無極性分子**といいます。原子が2個の分子なら、結合の極性がそのまま分子の極性です（HCl は極性分子、H₂ は無極性分子）。原子が3個以上になると、**形**が効いてきます。

:::figure
src: methane-electron-dot.png
alt: メタンの電子式と、結合の極性δ+δ−を書き込んだ構造式。結合の極性が分子全体で打ち消されて無極性になることを示している
caption: C−H 結合1本ずつには極性がありますが、正四面体の4方向に同じ大きさで向いているので、分子全体では打ち消されます。
:::

CO₂ の C=O 結合には極性がありますが、直線形で2本が正反対を向いているので、**打ち消し合って無極性分子**になります。一方、H₂O の O−H 結合は折れ線形で向きがそろわないため**打ち消されずに極性分子**になります。NH₃（三角錐形）も同じ理由で極性分子です。

:::table
caption: 形と分子の極性
source: 本文の「代表的な分子の形」の表の分子に、四面体で付いている原子が同じか混ざるかの対比として CCl₄・CH₃Cl を足して、形ごとに打ち消されるかを並べた
head:
- 分子
- 形
- 結合の極性
- 分子の極性
align: left | left | left | left
rows:
- H₂・N₂・Cl₂ | 直線形 | なし | 無極性分子
- HCl・HF | 直線形 | あり | **極性分子**
- CO₂ | 直線形 | あり（正反対で打ち消し合う） | 無極性分子
- H₂O | 折れ線形 | あり（打ち消されない） | **極性分子**
- NH₃ | 三角錐形 | あり（打ち消されない） | **極性分子**
- CH₄・CCl₄ | 正四面体形 | あり（4方向で打ち消し合う） | 無極性分子
- CH₃Cl | 四面体形（1つだけ別の原子） | あり（打ち消されない） | **極性分子**
:::

**「中心の原子のまわりに同じ原子が対称に付いていれば無極性、非共有電子対があるか付いている原子が混ざれば極性」**と覚えておきましょう。この表の分子は、極性分子か無極性分子かを即答できるようにしてください。

:::callout
tone: caution
text: 同じ四面体の形でも、CH₄ や CCl₄ は無極性、CH₃Cl や CH₂Cl₂ は極性分子です。形だけでなく「4つとも同じ原子か」を必ず見ます。
:::

極性分子どうしは、δ＋ と δ− の部分で引き合います。この引き合いが沸点の高さや、水への溶けやすさの違いになって現れます。

:::link
to: intermolecular-force
text: 極性が沸点にどう効くかは、分子間力のページへ
:::

:::link
to: dissolution
text: 極性分子は水に溶けやすく、無極性分子は溶けにくいことは、溶解のしくみのページへ
:::

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: 本文の「代表的な分子の形」と「形と分子の極性」の2つの表の分子で組んだ自作の問い（スライドに練習なし）
prompt: 次の分子の形を答え、極性分子をすべて選べ。(1) H₂O　(2) CO₂　(3) NH₃　(4) CH₄　(5) HCl　(6) CCl₄
answer: (1) 折れ線形 (2) 直線形 (3) 三角錐形 (4) 正四面体形 (5) 直線形 (6) 正四面体形。極性分子は **(1) H₂O・(3) NH₃・(5) HCl**。CO₂ は直線で、CH₄・CCl₄ は正四面体で、結合の極性が打ち消されるので無極性分子です。
:::

:::exercise
source: 本文の「非共有電子対は場所を広く取る」の節の理由づけを問う自作の問い（スライドに練習なし）
prompt: CH₄・NH₃・H₂O を結合角の大きい順に並べ、そうなる理由を「電子対」という語を使って説明せよ。
answer: **CH₄ ＞ NH₃ ＞ H₂O**。3つとも中心の原子のまわりに電子対が4組あり、正四面体の向きに散る。非共有電子対は共有電子対より空間を広く取るので、非共有電子対が 0組の CH₄（109.5°）、1組の NH₃（106.7°）、2組の H₂O（104.5°）の順に結合角が狭くなる。
:::

:::exercise
source: 本文の「電子のまとまりの数と散る向き」の表を、有機の分子に当てはめる自作の問い（スライドに練習なし）
prompt: ホルムアルデヒド HCHO（構造式は H と H が C に単結合し、C と O が二重結合）の、C のまわりの形と H−C−H の結合角のおよその値を答えよ。
answer: C のまわりのまとまりは、C−H が2組と C=O（二重結合で1組）の計 **3組**。3組は正三角形の向きに散るので、**平面の三角形で、結合角はおよそ 120°**。
:::
