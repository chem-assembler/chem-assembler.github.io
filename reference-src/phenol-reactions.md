フェノール類は、−OH が付いたことで**ベンゼンよりも置換反応を起こしやすく**なっています。このページでは、フェノール類を見分ける反応、環で起こる置換反応、そしてフェノールのつくり方を見ていきます。

:::section
anchor: fecl3
title: 塩化鉄(III) で呈色する
lead: 塩化鉄(III) 水溶液を少し加えて青紫〜赤紫に色づけば、フェノール類だと判定できます。
terms:
- 塩化鉄(III)
- 呈色反応
:::

フェノール類を見分ける試薬が**塩化鉄(III) FeCl₃ 水溶液**です。少し加えるだけで、液が**青紫〜赤紫色**に色づきます。フェノールなら紫、サリチル酸なら赤紫です。

**「フェノール類は塩化鉄(III) で呈色する」は必ず覚えてください。**−OH が環に直接付いているかどうかの試験なので、アルコール（ベンジルアルコールも含む）は呈色しません。

:::figure
src: phenol-fecl3-test.png
svg: phenol-fecl3-test.svg
alt: 3本の試験管に塩化鉄(III) 水溶液を1滴ずつ加えた模式図。フェノールの試験管は紫、サリチル酸は赤紫になり、ベンジルアルコールの試験管は塩化鉄(III) の黄色のまま変わらない
caption: ベンジルアルコールもベンゼン環と −OH をもちますが、−OH は CH₂ を挟んで付いているので、性質はアルコールの仲間です。**呈色するかどうかは、環があるかではなく、−OH が環に直接付いているかで決まります。**
:::

:::section
anchor: substitution
title: ベンゼンより置換されやすい
lead: フェノールは触媒なしで臭素水と反応し、3か所に Br が入った白色沈殿ができます。
terms:
- 2,4,6-トリブロモフェノール
- ピクリン酸
:::

ベンゼンを臭素で置換するには鉄の触媒が要りました。ところがフェノールは、**臭素水を加えるだけで、触媒なしに**置換反応が起こり、しかも **3か所いっぺんに** Br が入ります。

:::reaction
left: C₆H₅OH ＋ 3Br₂
right: C₆H₂Br₃OH↓ ＋ 3HBr
gen: フェノール ＋ 3 臭素 → 2,4,6-トリブロモフェノール ＋ 3 臭化水素
app: substitution_cl
level: ★★★
note: 2,4,6-トリブロモフェノールの白色沈殿ができます。−OH から見て o・p・o の3か所に入ります。
:::

:::figure
src: phenol-reactions-tribromophenol.png
gen: name=2,4,6-トリブロモフェノール plain
alt: 2,4,6-トリブロモフェノールの構造式。ベンゼン環にヒドロキシ基が1個付き、その両隣と向かいの炭素に臭素原子が1個ずつ結合している
caption: **2,4,6-トリブロモフェノール**。−OH の両隣（o）と向かい（p）の3か所に Br が入っています。
:::

**「ベンゼンは触媒が要る、フェノールは要らない」と対にして覚えましょう。**

:::mistake
wrong: フェノールに臭素水を加えると、アルケンと同じように付加反応が起こって臭素水の色が消える。
right: フェノールでは置換反応が起こり、2,4,6-トリブロモフェノールの白色沈殿ができる。
why: どちらも臭素水を使うので混ざりやすいところです。アルケンは脱色（付加）、フェノールは白色沈殿（置換）と、見た目で区別します。
:::

フェノールを混酸でニトロ化すると、同じように3か所にニトロ基が入って**ピクリン酸（2,4,6-トリニトロフェノール）**の**黄色の結晶**ができます。

:::reaction
left: C₆H₅OH ＋ 3HNO₃
over: 濃硫酸
right: C₆H₂(NO₂)₃OH ＋ 3H₂O
gen: フェノール → ピクリン酸 ＋ 3 水
app: substitution_no2
level: ★★☆
note: ピクリン酸ができます。3か所が 2,4,6 になるのは、臭素化と同じ理由です。
:::

:::figure
src: phenol-reactions-picric-acid.png
gen: name=ピクリン酸 plain

caption: **ピクリン酸（2,4,6-トリニトロフェノール）**。臭素化と同じ3か所にニトロ基が入っています。
:::

:::section
anchor: methyl
title: メチル化するとエーテルになる
lead: −OH の H を CH₃ に置き換えるとアニソールになり、塩化鉄(III) で呈色しなくなります。
terms:
- アニソール
- メチル化
:::

フェノールの −OH の H を**メチル基 −CH₃ に置き換える**と、**アニソール（メトキシベンゼン）C₆H₅OCH₃** になります。−O− で炭素どうしがつながったので、これは**エーテル**です。

:::reaction
left: C₆H₅ONa ＋ CH₃I
right: C₆H₅OCH₃ ＋ NaI
level: ★☆☆
note: ナトリウムフェノキシドにヨウ化メチルを作用させるとアニソールができます。試薬の名前は覚えなくて構いません。
:::

アニソールには −OH が無いので、**塩化鉄(III) で呈色せず、ナトリウムとも反応しません**。また H が CH₃ に変わったぶん、**分子量が 14 大きく**なります。**この2点は構造決定の問題で使うので覚えておきましょう。**

:::link
to: ether
text: エーテルの性質（ナトリウムと反応しない）はエーテルのページへ
:::

:::section
anchor: cumene
title: フェノールのつくり方① クメン法
lead: ベンゼンとプロペンからクメンをつくり、酸化・分解すると、フェノールとアセトンが同時にできます。
terms:
- クメン法
- クメン
- クメンヒドロペルオキシド
- アセトン
:::

現在、工業的にフェノールをつくっているのは**クメン法**です。次の3段で進みます。

:::list
ordered: true
items:
- ベンゼンにプロペンを付加させて、クメン（イソプロピルベンゼン）をつくる。
- クメンを空気中の酸素で酸化して、クメンヒドロペルオキシドにする。
- 最後に希硫酸をはたらかせると、クメンヒドロペルオキシドが2つに割れて、フェノールとアセトンになる。
:::

:::reaction
left: C₆H₆ ＋ CH₂=CHCH₃
over: 触媒
right: C₆H₅CH(CH₃)₂
gen: ベンゼン ＋ プロペン → クメン
level: ★★☆
note: ①クメン（イソプロピルベンゼン）ができます。
:::

:::reaction
left: C₆H₅CH(CH₃)₂ ＋ O₂
right: C₆H₅C(CH₃)₂OOH
gen: クメン ＋ 酸素 → クメンヒドロペルオキシド
level: ★★☆
note: ②クメンヒドロペルオキシドができます。−O−O−H の部分をもつ化合物です。
:::

:::reaction
left: C₆H₅C(CH₃)₂OOH
over: 希硫酸
right: C₆H₅OH ＋ CH₃COCH₃
gen: クメンヒドロペルオキシド → フェノール ＋ アセトン
level: ★★★
note: ③フェノールとアセトンが同時にできます。
:::

**「クメン法ではフェノールとアセトンが同時にできる」は必ず覚えてください。**アセトンの製法としても問われます。中間体の名前（クメン・クメンヒドロペルオキシド）も書けるようにしておきましょう。

:::link
to: ketone
text: 同時にできるアセトンの性質はケトンのページへ
:::

:::section
anchor: old-routes
title: フェノールのつくり方② 昔の2つの方法
lead: ベンゼンスルホン酸ナトリウムのアルカリ融解と、クロロベンゼンの加水分解。どちらもナトリウムフェノキシドを経て、最後に酸で遊離させます。
terms:
- アルカリ融解
- ベンゼンスルホン酸ナトリウム
:::

クメン法より前に使われていた方法が2つあります。**どちらもいったんナトリウムフェノキシドをつくり、最後に酸を加えてフェノールを遊離させる**という同じ形をしています。

ベンゼンスルホン酸ナトリウムを、固体の水酸化ナトリウムと高温で融かし合わせる方法を**アルカリ融解**といいます。

:::reaction
left: C₆H₅SO₃Na ＋ 2NaOH
over: 融解
under: 高温
right: C₆H₅ONa ＋ Na₂SO₃ ＋ H₂O
level: ★★☆
note: スルホ基が −ONa に置き換わって、ナトリウムフェノキシドができます。
:::

クロロベンゼンを、水酸化ナトリウム水溶液と高温・高圧で反応させる方法もあります。

:::reaction
left: C₆H₅Cl ＋ 2NaOH
over: 高温・高圧
right: C₆H₅ONa ＋ NaCl ＋ H₂O
level: ★★☆
note: Cl が −ONa に置き換わって、ナトリウムフェノキシドができます。
:::

どちらの方法も、最後にナトリウムフェノキシドに酸を加えてフェノールを取り出します。

:::reaction
left: C₆H₅ONa ＋ HCl
right: C₆H₅OH ＋ NaCl
level: ★★★
note: 塩酸のほうが強い酸なので、フェノールが遊離します。CO₂ を吹き込んでも同じようにフェノールが遊離します。
:::

## 例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: draft:reference-outline/aromatic.md の phenol-reactions の例題1（フェノールの臭素化の反応式から作った問い。どの本の問題も見ていない）
prompt: フェノールの水溶液に臭素水を加えたときの反応式を書き、生成物の名称と見た目を答えよ。
answer: C₆H₅OH ＋ 3Br₂ → C₆H₂Br₃OH ＋ 3HBr です。**2,4,6-トリブロモフェノールの白色沈殿**ができます。アルケンのように脱色するのではなく、沈殿が出ます。
:::

:::exercise
source: draft:reference-outline/aromatic.md の phenol-reactions の例題2（クメン法とアルカリ融解の経路から作った問い）
prompt: ベンゼンからフェノールをつくる方法を2つ、途中で経由する物質とともに答えよ。
answer: (1) **クメン法**: ベンゼン →（プロペンを付加）→ クメン →（酸素で酸化）→ クメンヒドロペルオキシド →（希硫酸で分解）→ フェノール ＋ アセトン。(2) **アルカリ融解**: ベンゼン →（濃硫酸でスルホン化）→ ベンゼンスルホン酸 →（中和）→ ベンゼンスルホン酸ナトリウム →（NaOH と融解）→ ナトリウムフェノキシド →（酸）→ フェノール。クロロベンゼンを経る方法でも正解です。
:::

:::exercise
source: draft:reference-outline/aromatic.md の phenol-reactions の例題3を直した問い。⚠ 骨子の「加水分解するとフェノールが得られた」はアニソール（エーテル）には当てはまらないので、ナトリウムとの反応と呈色で絞る形にした
prompt: 分子式 C₇H₈O で、ベンゼン環を1個もつ化合物 X がある。X は塩化鉄(III) で呈色せず、金属ナトリウムとも反応しなかった。X の名称と示性式を答えよ。
answer: **アニソール（メトキシベンゼン）C₆H₅OCH₃** です。呈色しないのでフェノール類（クレゾール）ではなく、ナトリウムと反応しないので −OH をもつベンジルアルコールでもありません。残るのは −O− をもつエーテルです。
:::
