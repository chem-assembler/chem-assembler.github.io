酸と塩基の性質は、それぞれ**水素イオン H⁺** と**水酸化物イオン OH⁻** によるものです。「酸の本体は H⁺、塩基の本体は OH⁻」と覚えましょう。このページでは、何を酸・塩基とよぶかの決め方（定義）を2つ見ていきます。

:::section
anchor: properties
title: 酸と塩基の性質
lead: 酸は酸っぱく青色リトマス紙を赤くし、塩基は苦く赤色リトマス紙を青くします。酸と塩基が反応すると、互いの性質を打ち消し合います（中和）。
terms:
- 酸性
- 塩基性
- リトマス紙
:::

:::table
caption: 酸と塩基の性質
source: slides:酸塩基の基本１ p.4 の表の行をそのまま並べた
head:
- 酸（H⁺）の性質
- 塩基（OH⁻）の性質
align: left | left
rows:
- 酸っぱい味 | 苦い味
- 青色リトマス紙を赤に変える | 赤色リトマス紙を青に変える
- Fe・Mg・Zn などの金属と反応して水素を発生する | 触れるとぬるぬるする
:::

これらの性質は、酸では H⁺、塩基では OH⁻ がもたらしています。酸と塩基を反応させると、H⁺ と OH⁻ が結びついて H₂O になるので、互いの性質が打ち消されます。これを**中和**といいます。

:::

:::section
anchor: arrhenius
title: アレニウスの定義
lead: 水に溶けて H⁺ を生じる物質が酸、水に溶けて OH⁻ を生じる物質が塩基です。
terms:
- アレニウスの定義
- 酸
- 塩基
- 電離
:::

「**水に溶けて水素イオン H⁺ を生じる物質**」を**酸**、「**水に溶けて水酸化物イオン OH⁻ を生じる物質**」を**塩基**といいます。これを**アレニウスの定義**といいます。

構造で言い直すと、**酸は H⁺ と陰イオンがくっついた構造**、**塩基は OH⁻ と陽イオンがくっついた構造**をしています。水に溶けると、このくっつきが離れてイオンに分かれます（**電離**）。

:::reaction
left: HCl
right: H⁺ ＋ Cl⁻
level: ★★★
note: 塩化水素は H⁺ と陰イオン Cl⁻ がくっついた構造なので酸です。
:::

:::reaction
left: NaOH
right: Na⁺ ＋ OH⁻
level: ★★★
note: 水酸化ナトリウムは OH⁻ と陽イオン Na⁺ がくっついた構造なので塩基です。
:::

:::figure
src: acid-base-definition-arrhenius.png
svg: acid-base-definition-arrhenius.svg
alt: 酸は H⁺ と陰イオンがくっついたもの、塩基は陽イオンと OH⁻ がくっついたもので、どちらも水中で電離して2つのイオンに分かれることを示した模式図
caption: アレニウスの定義。**酸は「H⁺＋陰イオン」、塩基は「陽イオン＋OH⁻」**の組み合わせで、水中で電離して分かれます。
:::

アレニウスの定義では、水に溶けたときに H⁺ を出すか OH⁻ を出すかで決めるので、**物質ごとに酸か塩基かが決まっています**。

:::section
anchor: bronsted
title: ブレンステッド・ローリーの定義
lead: 反応相手に H⁺ を与える物質が酸、反応相手から H⁺ を受け取る物質が塩基です。
terms:
- ブレンステッド・ローリーの定義
- オキソニウムイオン
:::

「**反応相手に水素イオン H⁺ を与える物質**」を**酸**、「**反応相手から H⁺ を受け取る物質**」を**塩基**といいます。これを**ブレンステッド・ローリーの定義**といいます。アレニウスの定義を広げたものです。

具体例として、気体どうしの塩化水素とアンモニアの反応を見ます。

:::reaction
left: HCl ＋ NH₃
right: NH₄Cl
level: ★★★
note: 塩化アンモニウムの白煙が生じます。イオンに分けて書くと HCl ＋ NH₃ → NH₄⁺ ＋ Cl⁻ となり、HCl から NH₃ へ H⁺ が渡されていることがわかります。
:::

この反応で、H⁺ を与えた HCl が酸、H⁺ を受け取った NH₃ が塩基です。ブレンステッド・ローリーの定義を使うと、次の2つの点でアレニウスの定義より広く扱えます。

:::list
items:
- 水溶液の中だけでなく、気体や固体の反応でも酸・塩基を考えられる
- OH⁻ を放出しない物質（NH₃ など）も塩基として扱える
:::

「OH⁻ を放出すること」と「H⁺ を受け取ること」は、**酸が出す H⁺ を打ち消してなくす**という点で同じ意味をもちます。OH⁻ は H⁺ とすぐに反応して H₂O になるためです。

:::reaction
left: H⁺ ＋ OH⁻
right: H₂O
level: ★★★
note: 酸と塩基はすぐに反応します。この式がすべての中和の芯です。
:::

terms:
- オキソニウムイオン
:::

## 塩化水素の場合

アレニウスの定義では、塩化水素は水に溶けると電離して H⁺ を放出するから酸です（HCl → H⁺ ＋ Cl⁻）。HCl 単独で酸と判断しています。

ブレンステッド・ローリーの定義では、塩化水素は水と反応するとき、水に H⁺ を与えるから酸です。H⁺ を受け取った H₂O は**オキソニウムイオン H₃O⁺** になります。

:::reaction
left: HCl ＋ H₂O
right: H₃O⁺ ＋ Cl⁻
level: ★★★
note: HCl は H₂O に H⁺ を与えた（酸）。H₂O は HCl から H⁺ を受け取った（塩基）。
:::

HCl はどちらの定義でも酸になりますが、考え方が違います。ブレンステッド・ローリーの定義では、**酸と塩基は必ずセットで判断します**。

## アンモニアの場合

:::reaction
left: NH₃ ＋ H₂O
arrow: ⇄
right: NH₄⁺ ＋ OH⁻
level: ★★★
note: NH₃ は H₂O から H⁺ を受け取った（塩基）。H₂O は NH₃ に H⁺ を渡した（酸）。
:::

アンモニアは分子の中に OH を持っていないので、「水に溶けて OH⁻ を出す」というアレニウスの定義ではうまく説明できません。ブレンステッド・ローリーの定義なら「水から H⁺ を受け取るから塩基」と説明できます。

:::section
anchor: role
title: 酸か塩基かは反応相手によって変わる
lead: ブレンステッド・ローリーの定義では、同じ物質でも相手によって酸にも塩基にもなります。H₂O と HCO₃⁻ がその代表です。
:::

ブレンステッド・ローリーの定義は、2つの物質が反応したときの **H⁺ のやりとり**で決めるので、酸・塩基は物質の種類ではなく**反応における役割**です。

:::figure
src: acid-base-definition-amphoteric.png
alt: H₂O が NH₃ 相手には H⁺ を渡して酸、HCl 相手には H⁺ を受け取って塩基になること、HCO₃⁻ が OH⁻ 相手には酸、H⁺ 相手には塩基になることを、H⁺ の移動の矢印で示した図
caption: **H₂O は NH₃ 相手では酸、HCl 相手では塩基**。**HCO₃⁻ は OH⁻ 相手では酸、H⁺ 相手では塩基**としてはたらきます。
:::

:::reaction
left: HCO₃⁻ ＋ OH⁻
right: CO₃²⁻ ＋ H₂O
level: ★★☆
note: HCO₃⁻ が OH⁻ に H⁺ を渡しているので、HCO₃⁻ は酸です。
:::

:::reaction
left: HCO₃⁻ ＋ H⁺
right: H₂CO₃
level: ★★☆
note: HCO₃⁻ が H⁺ を受け取っているので、HCO₃⁻ は塩基です。
:::

## 水が左辺にある反応式の見分け方

H₂O が左辺にある反応式では、右辺を見るだけで H₂O のはたらきが決まります。

:::list
items:
- 右辺に **OH⁻** がある → H₂O は H⁺ を相手に渡して OH⁻ が残った ＝ **H₂O は酸**
- 右辺に **H₃O⁺** がある → H₂O は H⁺ を受け取った ＝ **H₂O は塩基**
:::

「**右辺に OH⁻ なら H₂O は酸、H₃O⁺ なら H₂O は塩基**」と覚えましょう。

## 例題 —— 酸か塩基かは反応相手によって変わる

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

:::exercise
source: slides:酸塩基の基本１ p.15「練習1」
prompt: 次の反応で、**H₂O** はブレンステッド・ローリーの定義の酸・塩基のどちらとしてはたらいているか。(1) HCl ＋ H₂O → H₃O⁺ ＋ Cl⁻　(2) CH₃COO⁻ ＋ H₂O → CH₃COOH ＋ OH⁻　(3) NH₃ ＋ H₂O → NH₄⁺ ＋ OH⁻　(4) CO₃²⁻ ＋ H₂O → HCO₃⁻ ＋ OH⁻
answer: (1) **塩基**（右辺に H₃O⁺ がある ＝ HCl から H⁺ を受け取った）　(2) **酸**（右辺に OH⁻ がある ＝ CH₃COO⁻ に H⁺ を渡した）　(3) **酸**（NH₃ に H⁺ を渡した）　(4) **酸**（CO₃²⁻ に H⁺ を渡した）
:::

:::exercise
source: slides:酸塩基の基本２ p.4「復習1」
prompt: 次の反応で、**左辺の最初の物質**はブレンステッド・ローリーの定義の酸・塩基のどちらとしてはたらいているか。(1) HSO₄⁻ ＋ H₂O → H₃O⁺ ＋ SO₄²⁻　(2) CH₃COO⁻ ＋ HCl → CH₃COOH ＋ Cl⁻　(3) NH₄⁺ ＋ H₂O → NH₃ ＋ H₃O⁺　(4) HCO₃⁻ ＋ OH⁻ → CO₃²⁻ ＋ H₂O
answer: (1) **酸**（H₂O に H⁺ を与えた）　(2) **塩基**（HCl から H⁺ を受け取った）　(3) **酸**（H₂O に H⁺ を与えた）　(4) **酸**（OH⁻ に H⁺ を与えた）
:::

:::section
anchor: which
title: 実際はどちらの定義を使うのか
lead: ふだんはアレニウスの定義を使い、ブレンステッド・ローリーの定義で判断するよう指示されたときだけ、そちらを使います。
:::

ふだん「酸」「塩基」という言葉を使うときに、どちらの定義かを意識する必要はありません。ある物質が「酸である」「塩基である」と言うときは、**アレニウスの定義**を使っています。

反応式を示して「ブレンステッド・ローリーの定義で酸・塩基を判断せよ」と**指示された問題でだけ**、H⁺ のやりとりを見て判断します。

:::mistake
wrong: H₂O は中性なので、酸でも塩基でもない
right: アレニウスの定義では H₂O は酸でも塩基でもありませんが、**ブレンステッド・ローリーの定義では、相手によって酸にも塩基にもなります**（NH₃ 相手では酸、HCl 相手では塩基）。
why: 2つの定義を1つの問いの中で混ぜてしまうためです。★ 「酸である」という物質の分類はアレニウス、「酸としてはたらいた」という反応の中の役割はブレンステッド・ローリー、と分けて読みます。
:::
