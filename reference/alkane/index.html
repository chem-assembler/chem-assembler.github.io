アルカン —— 単結合だけでできた炭化水素

正四面体がつながった形、炭素が増えると沸点と状態がどう動くか、たった1つの反応（置換反応）、そしてメタンの製法まで。アルカンについて引きに来ることを1ページにまとめました。

アルカンは、炭素どうしが単結合だけでつながっている炭化水素です。二重結合も三重結合も環も無いので、炭素に付ける手はぜんぶ水素で埋まって（＝ 飽和して）います。

どんな形をしているか

メタンの正四面体が繰り返しつながった形で、炭素どうしの単結合は自由に回転できます。

いちばん小さいアルカンであるメタン CH₄ は、炭素を中心にした正四面体の形をしています。炭素のまわりにある4組の電子対が、負の電荷でたがいに反発して、いちばん遠い位置に散るためで、結合角は 約109.5° になります。

電子対の反発で分子の形が決まるしくみ（VSEPR）をもう少し詳しく準備中

アルカンは、この正四面体が繰り返しつながった形です。炭素間の単結合は自由に回転できるので、同じ分子でも変形することができ見え方は一定ではありません。

アルカンの一般式は CnH2n+2

丸暗記もよいが、図形的に導けるようにしよう。

枝分かれの無い直鎖のアルカンは、いくつかのメチレン基 −CH₂− と、両端の水素2個でできています。C原子の数を n 個とすると、水素原子はメチレン基の部分に 2n 個、両端の2個あるので合計 2n+2 個になります。

どんな構造のアルカンも「鎖を伸ばす」、「枝分かれをつくる」、の2つの操作だけでつくることができますが、いずれの場合もメチレン基 −CH₂− を足しているので、アルカンの分子式（一般式）は必ず CnH2n+2になります。

この一般式の n に n=1 を代入すれば炭素数1のアルカンであるメタンの分子式 CH₄ が、n=3 を代入すれば炭素数3のアルカンであるプロパンの分子式 C₃H₈ が得られます。

一般式とは何か、同族体とはどういう仲間かを最初から準備中

主なアルカンと、常温での姿

炭素が増えるほど沸点が上がり、気体 → 液体 → 固体と姿が変わります。分かれ目は C₄／C₅ と C₁₇／C₁₈ です。

補足

アルカンの常温での状態

アルカンは無極性分子なので、分子どうしを引きつけているのは弱いファンデルワールス力だけです。ファンデルワールス力は分子量が大きくなるほど引きつけ合う力は強くなるので、蒸発しにくくなり、沸点が高くなります。だから C₁〜C₄ は気体、C₅〜C₁₇ は液体、C₁₈ 以上は固体です。液体と固体の境界についてはほとんど問われることはありませんが、ブタン C₄H₁₀ やペンタン C₅H₁₂ はよく登場するので気体と液体の境界はしっかりと覚えるようにしましょう。

分子間力そのものと、沸点との関係をまとめて見る準備中

枝分かれすると沸点が下がる（発展）

同じ分子式のアルカン同士で比較すると、枝分かれが多いほど沸点は低くなります。枝分かれすると分子の形が球に近づき、分子どうしが触れ合う面積が減って引きつけ合う力が弱くなるためです。

同じ炭素数でもアルコールの沸点がずっと高いのはなぜか準備中

ペンタン C₅H₁₂ の異性体3つを自分で書き出してみる（沸点が違うのはこの3つ）

無極性であることは、水への溶けかたにもそのまま出ます。アルカンは水に溶けにくく、水より密度が小さいので、水と混ぜると上に分かれます。

アルキル基 —— アルカンから水素を1つ取ったもの

枝の名前はここから来ます。語尾の -ane を -yl に変えるだけです。

アルカン CnH2n+2 から水素原子を1個取り去った原子団をアルキル基 −CnH2n+1 といいます。分子ではなく、分子の一部（パーツ）です。名前は、もとのアルカンの語尾 -ane を -yl（イル）に変えるだけです。

  • メタン CH₄ → メチル基 −CH₃
  • エタン C₂H₆ → エチル基 −C₂H₅
  • プロパン C₃H₈ → プロピル基 −C₃H₇（2種類）
  • ブタン C₄H₁₀ → ブチル基 −C₄H₉（4種類）
  • ペンタン C₅H₁₂ → ペンチル基 −C₅H₁₁（8種類）

炭素が3個以上になると、どの水素を取ったかで違う基になります。プロピル基が2種類あるのはそのためで、枝分かれしたアルカンの名前が何通りにもなる理由もここにあります。

アルカンの反応 —— 置換反応

アルカンが常温付近で起こす反応はこれ1つです。光を当てて、ハロゲンと水素を入れ替えます。

アルカンは常温では反応性が低いのですが、ハロゲンの単体と混ぜて光を当てると反応します。メタンと塩素なら、メタンの水素1個と塩素分子の塩素1個が入れ替わって、クロロメタンと塩化水素ができます。

★★★ 必ず覚える
CH₄ ＋ Cl₂光→CH₃Cl ＋ HCl

原子が入れ替わるので置換反応といいます。アルカンの反応は置換反応、と覚えてしまってかまいません。

このように、分子の中の原子（原子団）が他の原子（原子団）と置き換わる反応を置換反応、入ってきた原子（原子団）を置換基、できた物質をもとの分子の置換体といいます。

電子対はどう動いているのか（発展）

電子対がどう動いてこの入れ替わりが起きるのかは、別ページの「反応の道すじ（反応機構）」で巻矢印のアニメとして1段ずつ追えます。

条件を整えると、置換は1回では止まりません。メタン CH₄ には水素が4個あるので、4回まで続けて起こります。

  1. CH₃Cl クロロメタン（塩素1個）
  2. CH₂Cl₂ ジクロロメタン（2個）
  3. CHCl₃ トリクロロメタン（3個。クロロホルムのこと）
  4. CCl₄ テトラクロロメタン（4個）

置換体の名前は、入った塩素の数を表す接頭辞（ジ・トリ・テトラ）＋ クロロ ＋ もとのアルカンの名前です。係数は、塩素を1個入れるのに Cl₂ が1分子要ることから決まります。

★★★ 必ず覚える
CH₄ ＋ 3Cl₂光→CHCl₃ ＋ 3HCl

塩素を3個入れたいので Cl₂ が3分子、外れた水素3個は HCl になって出ていきます。

もう1つ、アルカンが起こす反応が燃焼です。高温ではアルカンは還元剤としてはたらき、多量の熱を出して燃えます。燃料に使われるのはこのためです。完全燃焼すれば、生成物は二酸化炭素と水だけになります。

★★★ 必ず覚える
CH₄ ＋ 2O₂完全燃焼→CO₂ ＋ 2H₂O

炭素は CO₂ へ、水素は H₂O へ。他のアルカンでも、係数を合わせるだけで同じ形の式になります。

メタン CH₄

いちばん小さいアルカン。無色無臭の気体で水に溶けにくく、実験室では酢酸ナトリウムと水酸化ナトリウムを加熱してつくります。

メタンは無色無臭の気体で、天然ガスの主成分です。C−H 結合には極性がありますが、正四面体なので分子全体では打ち消し合い、分子としては無極性になります。無極性だから水に溶けにくく水上置換で捕集します。

実験室では、酢酸ナトリウムと水酸化ナトリウムの混合物を加熱してつくります。どちらも固体なので、加熱が要ります。

★★☆ 余裕があれば
CH₃COONa ＋ NaOH加熱→CH₄↑ ＋ Na₂CO₃

固体どうしの反応なので加熱します。出てきたメタンは水上置換で集めます。

丸暗記でよい

この反応式は丸暗記でかまいません。係数はすべて 1 なので、反応物を暗記すればメタン CH₄ ができたあまりが炭酸ナトリウム Na₂CO₃ です。
