酸素・オゾン・過酸化水素

酸素を含む3つの物質のまとめ。O₂ の性質表と酸化剤としての反応、実験室的製法3通り、過酸化水素 H₂O₂ の「酸化剤にも還元剤にもなる」2つの顔、オゾン O₃ の性質と、酸性・塩基性での半反応式の書き分け、ヨウ化カリウムデンプン紙での検出を1枚にしました。

酸素 O₂・オゾン O₃・過酸化水素 H₂O₂ は、どれも酸化剤としてはたらく物質です。反応式は、それぞれの半反応式を先に書いてから、相手の半反応式と足して組み立てます。半反応式の書き方は「半反応式の書き方」のページで確かめてください。

酸素 —— 空気中で 4価の酸化剤

酸素 O₂ は無色・無臭で水に溶けにくい気体です。空気中では O 原子が安定な O²⁻ になる、4価の酸化剤としてはたらきます。

酸素 O₂ の性質
項目酸素 O₂理由・補足
色・におい無色・無臭−
分子量32−
水への溶解ほぼ溶けない無極性分子なので水に溶けにくい
捕集法水上置換水に溶けないので水上置換
水溶液の液性−水に溶けにくく、酸でも塩基でもない
酸化剤／還元剤酸化剤O は電気陰性度が F に次いで大きい

構造式は O=O で、2つの O 原子が二重結合で結びついた無極性分子です。

酸化剤としての反応

空気中の反応なので、H⁺ や H₂O を加えず、O 原子は安定な O²⁻ になると書きます。

★★★ 必ず覚える
O₂ ＋ 4e⁻→2O²⁻

空気中で O₂ が酸化剤としてはたらくときの半反応式。O 原子1個が e⁻ を2個受け取るので、O₂ 1分子では 4価です。

O₂ は金や白金を除くほとんどの金属を空気中で酸化し、表面に酸化物をつくります。生じる金属イオンの価数を覚えていれば、反応式が書けます。

★★★ 必ず覚える
2Cu ＋ O₂→2CuO

Cu が還元剤、O₂ が酸化剤。2Cu → 2Cu²⁺ ＋ 4e⁻ と O₂ ＋ 4e⁻ → 2O²⁻ を足したものです。高温では 4Cu ＋ O₂ → 2Cu₂O と反応します。

O₂ は高温で非金属元素の化合物の多くを酸化します。完全燃焼すると、各元素の最高酸化数の酸化物（CO₂・H₂O など）ができます。「完全燃焼で CO₂ と H₂O ができる」ことを覚えて係数を合わせるだけです。

★★★ 必ず覚える
CH₄ ＋ 2O₂→CO₂ ＋ 2H₂O

炭素は CO₂、水素は H₂O になります。

酸素の実験室的製法
★★★ 必ず覚える
2H₂O₂MnO₂（触媒）→2H₂O ＋ O₂↑

過酸化水素水に触媒として酸化マンガン(Ⅳ) MnO₂ を加えます。H₂O₂ は不安定なので、安定な H₂O になって O₂ を出します。

この反応は、酸化剤も還元剤も H₂O₂ という自己酸化還元反応です。H₂O₂ が酸化剤としてはたらく半反応式と、還元剤としてはたらく半反応式を足すと組み立てられます（下の「過酸化水素」の節）。反応速度の単元でもよく登場し、「H₂O₂ の係数は2だが1次反応」と覚えておきます。

★★☆ 余裕があれば
2KClO₃MnO₂（触媒）・加熱→2KCl ＋ 3O₂↑

塩素酸カリウム KClO₃ と酸化マンガン(Ⅳ)の混合物を加熱します。どちらも固体なので加熱が必要です。KClO₃ の Cl（+5）が安定な Cl⁻ になって O₂ を出す自己酸化還元反応です。

希硫酸や水酸化ナトリウム水溶液を電気分解しても、陽極から O₂ が出ます（陰極からは H₂）。

★★★ 必ず覚える
2H₂O→O₂↑ ＋ 4H⁺ ＋ 4e⁻

希硫酸（酸性）の電気分解の陽極。

★★★ 必ず覚える
4OH⁻→O₂↑ ＋ 2H₂O ＋ 4e⁻

水酸化ナトリウム水溶液（塩基性）の電気分解の陽極。

例題 —— 酸素

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

例題

次の化学反応式を書け。(1) 空気中で酸素が酸化剤としてはたらいた（e⁻ とイオンを含む反応式で）　(2) 空気中で酸素が銅を酸化した　(3) 空気中で酸素がナトリウムを酸化した　(4) メタンを完全燃焼した　(5) メタノール CH₃OH を完全燃焼した

解答を見る

(1) O₂ ＋ 4e⁻ → 2O²⁻　(2) 2Cu ＋ O₂ → 2CuO　(3) 4Na ＋ O₂ → 2Na₂O　(4) CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O　(5) 2CH₃OH ＋ 3O₂ → 2CO₂ ＋ 4H₂O　すべて★★★です。(3) は Na が1価の Na⁺ になることから Na₂O と決まります。

まとめ

  • 空気中の O₂ は O₂ ＋ 4e⁻ → 2O²⁻ の4価の酸化剤としてはたらき、金属を酸化物にし、炭素化合物を完全燃焼で CO₂ と H₂O にする。
  • 酸素は、過酸化水素水に MnO₂ を触媒として加えるか、KClO₃ と MnO₂ の混合物を加熱してつくり、どちらも自己酸化還元反応である。

過酸化水素 —— 酸化剤にも還元剤にもなる

H₂O₂ の O は酸化数 −1。ふつうは −2 になる酸化剤、KMnO₄ や K₂Cr₂O₇ のような極めて強い酸化剤が相手のときだけ 0 になる還元剤です。

過酸化水素 H₂O₂ は無色の液体で、ふつうは水溶液（過酸化水素水）として使います。約3%の水溶液はオキシドールとよばれ、消毒に使われます。傷口に塗ると泡が出るのは、H₂O₂ が分解して O₂ が発生するためです。

H₂O₂ の O 原子の酸化数は −1 です。H₂O₂ は不安定なので、安定な H₂O（O の酸化数 −2）になろうとする、比較的強い2価の酸化剤です。

★★★ 必ず覚える
H₂O₂ ＋ 2H⁺ ＋ 2e⁻→2H₂O

酸化剤としてはたらくとき（酸性条件）。O 原子2個が e⁻ を1個ずつ受け取って −1 → −2。

一方、過マンガン酸カリウム KMnO₄ や二クロム酸カリウム K₂Cr₂O₇ のように極めて酸化力の強い相手には還元剤としてはたらき、O₂（酸化数 0）になります。

★★★ 必ず覚える
H₂O₂→O₂↑ ＋ 2H⁺ ＋ 2e⁻

還元剤としてはたらくとき。「H₂O₂ は還元剤になると O₂ になる」と覚えれば、あとは手順どおりに書けます。

「酸化剤なら H₂O、還元剤なら O₂」の2本はどちらも必ず覚えてください。どちらではたらくかは相手で決まり、相手が KMnO₄・K₂Cr₂O₇ のような強い酸化剤のときに還元剤になります。

⚠ 勘違いしやすい

「強い酸化剤が相手なら還元剤」と覚えると、相手を広げすぎます。H₂O₂ が還元剤としてはたらく相手として登場するのは、ほぼ KMnO₄ と K₂Cr₂O₇ だけです。

過マンガン酸カリウム・二クロム酸カリウムの半反応式はこちら

二酸化硫黄 SO₂ が相手なら、H₂O₂ は酸化剤としてはたらき、硫酸ができます。

★★★ 必ず覚える
H₂O₂ ＋ SO₂→H₂SO₄

H₂O₂ が酸化剤、SO₂ が還元剤。H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O と SO₂ ＋ 2H₂O → SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻ を足すと、H⁺ と H₂O が打ち消し合います。

例題 —— 過酸化水素
例題

次の化学反応式を書け。(1) 過酸化水素水に酸化マンガン(Ⅳ)を加えた　(2) 塩素酸カリウムと酸化マンガン(Ⅳ)の混合物を加熱した　(3) 過酸化水素が酸化剤としてはたらいた（e⁻ とイオンを含む反応式で）　(4) 過酸化水素が還元剤としてはたらいた（e⁻ とイオンを含む反応式で）　(5) 過酸化水素水に二酸化硫黄を吹き込んだ

解答を見る

(1) 2H₂O₂ → 2H₂O ＋ O₂↑　(2) 2KClO₃ → 2KCl ＋ 3O₂↑　(3) H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O　(4) H₂O₂ → O₂↑ ＋ 2H⁺ ＋ 2e⁻　(5) H₂O₂ ＋ SO₂ → H₂SO₄　(2) だけ★★☆、ほかは★★★です。(1) は (3) と (4) を足したものです。

まとめ

  • 過酸化水素（O の酸化数 −1）はふつう H₂O になる2価の酸化剤で、KMnO₄ や K₂Cr₂O₇ のような極めて強い酸化剤が相手のときだけ O₂ になる還元剤としてはたらく。

オゾン —— O₂ より不安定で、酸化力が極めて強い

O₃ は淡青色・特異臭の気体で、O₂ の無声放電でできます。中・塩基性で使う半反応式は O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ です。

オゾン O₃ の性質
項目オゾン O₃理由・補足
色・におい淡青色・特異臭「オゾン臭」としか言えないにおい
分子量48−
水への溶解少し溶ける極性分子なので O₂ より水に溶けやすい
酸化剤／還元剤強い酸化剤O₂ より不安定（反応しやすい）で、殺菌・消毒・漂白に使われる

O₃ は折れ線形の極性分子で、構造式の中に配位結合を1つ含みます。O₂ と O₃ は同じ元素 O からなる単体どうしで、互いに同素体です。

酸素中で無声放電（音の出ない放電）を行うと、オゾンができます。紫外線を当てても同じ反応が起こります。O₃ は不安定で、O₂ との間を行き来する可逆反応です。

★★☆ 余裕があれば
3O₂無声放電⇄2O₃

O₃ は不安定で、O₂ との間で可逆反応が起こります。

酸化剤としての反応 —— 液性で書き分ける

O₃ は極めて強い2価の酸化剤です。3個の O 原子のうち1個だけが還元されて −2 になり、残り2個は O₂ のまま出ていきます。「O₃ は O₂ になる」と覚えると、半反応式は手順どおりに書けます。

★★☆ 余裕があれば
O₃ ＋ 2H⁺ ＋ 2e⁻→O₂↑ ＋ H₂O

酸性条件の半反応式。

中・塩基性の水溶液では、H⁺ は OH⁻ と結びついて H₂O として存在しています。そこで、酸性の式の両辺に H⁺ と同じ数だけ OH⁻ を足し、H⁺ と OH⁻ を H₂O にしてから、両辺に共通する H₂O を消します。

★★☆ 余裕があれば
O₃ ＋ H₂O ＋ 2e⁻→O₂↑ ＋ 2OH⁻

中・塩基性条件の半反応式。O₃ が実際に使われるのはこの条件なので、O₃ の半反応式はこちらを使います。

オゾンの半反応式を酸性から塩基性に書き換える

オゾンの検出 —— ヨウ化カリウムデンプン紙

O₃ が出ているかは、ヨウ化カリウムデンプン紙を水でぬらしてかざすと分かります。紙が青く染まれば、O₃ がある目印です。紙に含まれるヨウ化物イオン I⁻ が還元剤としてはたらいてヨウ素 I₂ ができ、I₂ がデンプンとヨウ素デンプン反応を起こして青〜青紫色になります。

★★☆ 余裕があれば
O₃ ＋ 2KI ＋ H₂O→I₂ ＋ 2KOH ＋ O₂↑

酸を加えていないので、中・塩基性条件の半反応式を使って組み立てます。O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ と 2I⁻ → I₂ ＋ 2e⁻ を足し、両辺に 2K⁺ を戻すと KOH ができます。

ヨウ化カリウムデンプン紙は、O₃ だけでなく Cl₂ など酸化剤一般の検出に使います。

例題 —— オゾン
例題

次の化学反応式を書け。(1) 空気中で無声放電した　(2) オゾンが酸性条件で酸化剤としてはたらいた（e⁻ とイオンを含む反応式で）　(3) オゾンが塩基性条件で酸化剤としてはたらいた（e⁻ とイオンを含む反応式で）　(4) オゾンが湿らせたヨウ化カリウムデンプン紙を青変させた

解答を見る

(1) 3O₂ ⇄ 2O₃　(2) O₃ ＋ 2H⁺ ＋ 2e⁻ → O₂↑ ＋ H₂O　(3) O₃ ＋ H₂O ＋ 2e⁻ → O₂↑ ＋ 2OH⁻　(4) O₃ ＋ 2KI ＋ H₂O → I₂ ＋ 2KOH ＋ O₂↑　4本とも★★☆です。(3) は (2) の両辺に OH⁻ を2個ずつ足して導けます。

まとめ

  • オゾン O₃ は淡青色・特異臭の気体で O₂ の同素体であり、酸素中の無声放電でつくられ、強い酸化剤として湿らせたヨウ化カリウムデンプン紙を青変させる。
  • O₃ は O₂ になる2価の酸化剤で、実際に使われる中・塩基性では O₃ ＋ H₂O ＋ 2e⁻ → O₂ ＋ 2OH⁻ の半反応式を使う。
