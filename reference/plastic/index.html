熱可塑性樹脂と熱硬化性樹脂

鎖状の樹脂は加熱するとやわらかくなり、網目の樹脂は加熱すると硬くなって二度とやわらかくなりません。

長い鎖が1本ずつ独立している鎖状構造の樹脂は、加熱するとやわらかくなり、冷やすと再び固まります。これを熱可塑性樹脂といいます。鎖どうしは分子間力で引き合っているだけなので、温めると鎖がずれ動けるようになるためです。

鎖と鎖が共有結合で橋かけされ、全体が1つの巨大な分子になった立体網目構造の樹脂は、加熱すると硬化し、再び加熱してもやわらかくなりません。これを熱硬化性樹脂といいます。鎖どうしが共有結合で固定されていて、温めてもずれ動けないためです。

「鎖状は熱可塑性、網目は熱硬化性」と覚えましょう。どの樹脂がどちらかは、この合言葉と、各節の「網目になるかどうか」で決まります。

例題

次のうち、熱硬化性樹脂をすべて選べ。ポリスチレン、メラミン樹脂、ポリエチレンテレフタラート、フェノール樹脂、アルキド樹脂、ポリ塩化ビニル

解答を見る

メラミン樹脂・フェノール樹脂・アルキド樹脂の3つです。見分け方は「立体網目構造かどうか」の一点で、ホルムアルデヒドと付加縮合するものと、グリセリンのような3価以上の単量体を使うものが網目になります。

まとめ

  • 鎖状構造の高分子からなる熱可塑性樹脂は加熱するとやわらかくなり冷やすと固まる。立体網目構造をもつ熱硬化性樹脂は加熱すると硬化し、再加熱しても軟化しない。

ポリエチレン

エチレンの付加重合でできます。つくり方で枝分かれの数が変わり、やわらかい低密度と、硬い高密度の2種類になります。

エチレンを付加重合させるとポリエチレンができます。

★★★ 必ず覚える
n CH₂=CH₂→［CH₂−CH₂］ₙ
▶ 大きな画面で開く

同じ式でも、つくり方で枝分かれの数が変わり、別の性質の材料になります。

高い圧力で重合させると、枝分かれの多い低密度ポリエチレンになります。触媒を使って低い圧力で重合させると、枝分かれの少ない高密度ポリエチレンになります。枝分かれが少ないと鎖がそろって並びやすく、結晶部分が多くなるので、硬く不透明になるためです。

性質やわらかく、透明に近い硬く、不透明

「高圧法は低密度、低圧法は高密度」と、高と低が入れ替わることに注意して覚えましょう。

ビニル化合物からできる樹脂

単量体はどれも CH₂=CH−X の形です。付加重合すると ［CH₂−CH(X)］ₙ になり、X の違いが性質の違いになります。

付加重合の単量体の多くは、エチレンの H を1個 X に置きかえた CH₂=CH−X の形をしています。重合体の式は、次の型で書けます。

  • 単量体 CH₂=CH−X が付加重合すると、重合体は ［CH₂−CH(X)］ₙ
    X が −CH₃ なら「ポリプロピレン」、−Cl なら「ポリ塩化ビニル」、−C₆H₅ なら「ポリスチレン」

ポリ酢酸ビニルとポリビニルアルコール

ビニルアルコールは単量体として使えないので、酢酸ビニルを重合させてからけん化して、ポリビニルアルコールをつくります。

酢酸ビニルを付加重合させるとポリ酢酸ビニルができます。

★★★ 必ず覚える
n CH₂=CH−OCOCH₃→［CH₂−CH(OCOCH₃)］ₙ
▶ 大きな画面で開く

X ＝ −OCOCH₃ のビニル化合物です。

ポリ酢酸ビニルを水酸化ナトリウム水溶液でけん化すると、エステル結合が切れて ポリビニルアルコール（PVA） になります。

★★★ 必ず覚える
［CH₂−CH(OCOCH₃)］ₙ ＋ n NaOH→［CH₂−CH(OH)］ₙ ＋ n CH₃COONa
▶ 大きな画面で開く

繰り返し単位ごとにエステル結合が1つあるので、NaOH も n 個要ります。酢酸ナトリウムが出ていき、−OH が残ります。

ポリビニルアルコールの単量体にあたるビニルアルコール CH₂=CH−OH は不安定で、すぐにアセトアルデヒド CH₃CHO に変わってしまいます。だから直接は重合させられず、酢酸ビニルで鎖をつくってから −OH に変える、という回り道をします。

「酢酸ビニル → ポリ酢酸ビニル → ポリビニルアルコール」の3段は、2つの反応式ごと書けるようにしましょう。

エステル結合を切るけん化のしくみ

まとめ

  • 酢酸ビニルの付加重合でポリ酢酸ビニルが得られ、これを水酸化ナトリウム水溶液でけん化するとポリビニルアルコールになる。ビニルアルコールは不安定で単量体として使えない。

ポリメタクリル酸メチルとテフロン

ポリメタクリル酸メチルは透明で有機ガラスに、テフロンは薬品や熱に強く摩擦が小さいので、フライパンの表面加工などに使われます。

メタクリル酸メチルを付加重合させると、ポリメタクリル酸メチル（PMMA）ができます。透明度が高いので、有機ガラスとして水槽や風防に使われます。

★★☆ 余裕があれば
n CH₂=C(CH₃)COOCH₃→［CH₂−C(CH₃)(COOCH₃)］ₙ
▶ 大きな画面で開く

1つの炭素に −CH₃ と −COOCH₃ の2つがぶら下がっています。側鎖がかさばって鎖が規則正しく並べず、光を散らす結晶部分ができにくいので透明になります。

テトラフルオロエチレン CF₂=CF₂ を付加重合させると、ポリテトラフルオロエチレン（テフロン）ができます。薬品にも熱にも強く、表面がすべりやすいので、フライパンの表面加工などに使われます。

★★☆ 余裕があれば
n CF₂=CF₂→［CF₂−CF₂］ₙ
▶ 大きな画面で開く

エチレンの H が4つとも F に置きかわった形です。C−F 結合がとても強いので、薬品に侵されにくくなります。

「PMMA は有機ガラス」「テフロンは F を含み、薬品・熱に強い」の2点で十分でしょう。

まとめ

  • メタクリル酸メチルの付加重合で得られるポリメタクリル酸メチルは透明性が高く有機ガラスとよばれる。テトラフルオロエチレンの付加重合で得られるテフロン（ポリテトラフルオロエチレン）は薬品・熱に強く摩擦が小さい。

ポリエチレンテレフタラート（PET）

テレフタル酸とエチレングリコールの縮合重合でできます。エステル結合でつながったポリエステルで、ペットボトルや繊維になります。

テレフタル酸とエチレングリコールを縮合重合させると、ポリエチレンテレフタラート（PET）ができます。単量体どうしはエステル結合でつながるので、ポリエステルの一種です。

★★★ 必ず覚える
n HOOC−C₆H₄−COOH ＋ n HO−CH₂CH₂−OH→［CO−C₆H₄−CO−O−CH₂CH₂−O］ₙ ＋ 2n H₂O
▶ 大きな画面で開く

鎖状の縮合重合体なので熱可塑性で、溶かして成形し直せます。ペットボトルの PET です。

テレフタル酸は、p-キシレンの2本のメチル基を酸化してつくります。

例題 —— 重合体の単量体
例題

次の重合体の単量体を、示性式で書け。(1) ［CH₂−CH(C₆H₅)］ₙ　(2) ［CH₂−CH(OCOCH₃)］ₙ　(3) ［CO−C₆H₄−CO−O−CH₂CH₂−O］ₙ

解答を見る

(1) スチレン CH₂=CHC₆H₅。(2) 酢酸ビニル CH₂=CHOCOCH₃。この2つは付加重合なので、繰り返し単位の C−C を C=C に戻すだけです。(3) テレフタル酸 HOOC−C₆H₄−COOH とエチレングリコール HOCH₂CH₂OH の2つ。縮合重合なので、エステル結合を切り、切り口に −OH と −H を補って戻します。

まとめ

  • テレフタル酸とエチレングリコールを縮合重合させてつくる高分子が、ポリエチレンテレフタラート（PET）。単量体どうしをつないでいるのはエステル結合。

橋かけで網目にする

鎖と鎖を共有結合でつなぐことを橋かけ（架橋）といいます。橋が十分にかかると、全体が1つの巨大な分子になります。

鎖と鎖のあいだを共有結合でつなぐことを橋かけ（架橋）といいます。橋かけが十分に進むと、樹脂全体が1つの巨大な分子になり、立体網目構造になります。

網目をつくるには、1つの単量体が3か所以上で結合できることが要ります。2か所だけなら、何個つながっても一本の鎖のままだからです。この「3か所以上」の実例が、次の節から出てくるフェノール・尿素・メラミン・グリセリンです。

ゴムに硫黄を加えて鎖どうしをつなぐ加硫も、同じ橋かけの操作です。

フェノール樹脂

フェノールとホルムアルデヒドが付加と縮合をくり返す付加縮合でつながり、立体網目構造の熱硬化性樹脂になります。

フェノールとホルムアルデヒドを、酸または塩基を触媒として加熱すると、付加と縮合をくり返す付加縮合が起こります。こうしてできる立体網目構造の樹脂がフェノール樹脂です。

まず1か所つながったところを見ます。ホルムアルデヒドが、フェノールのベンゼン環に −CH₂− の橋をかけ、水が1個とれます。

★★☆ 余裕があれば
2 C₆H₅OH ＋ HCHO→HO−C₆H₄−CH₂−C₆H₄−OH ＋ H₂O

この −CH₂− の橋が、ベンゼン環の残りの位置（−OH から見てオルト位とパラ位の3か所）にも次々にかかって網目になります。

フェノールは1分子で3か所（オルト位2つとパラ位1つ）に橋を受けられるので、網目になります。電気を通しにくく熱に強いので、電気部品や配線基板に使われます。

フェノール樹脂の構造式そのものは書けなくて構いません。「フェノール ＋ ホルムアルデヒド」「付加縮合」「熱硬化性」の3語の組み合わせで足ります。

ノボラックとレゾール発展

酸を触媒にすると、網目になる前の鎖状の中間体ノボラックができ、これに硬化剤を加えて加熱すると網目になります。塩基を触媒にすると、別の中間体レゾールができ、これは加熱するだけで網目になります。

名前を見て「フェノール樹脂の途中の段階の話だ」と分かれば十分でしょう。

フェノールの性質と、ベンゼン環のオルト位・パラ位で起こる置換

まとめ

  • フェノールとホルムアルデヒドを酸または塩基の触媒のもとで反応させると、付加と縮合をくり返す付加縮合が起こり、立体網目構造のフェノール樹脂ができる。

尿素樹脂・メラミン樹脂・アルキド樹脂

尿素樹脂とメラミン樹脂は、相手がどちらもホルムアルデヒドの付加縮合です。アルキド樹脂は無水フタル酸とグリセリンの縮合重合です。

尿素とホルムアルデヒドから尿素樹脂が、メラミンとホルムアルデヒドからメラミン樹脂ができます。どちらもフェノール樹脂と同じ付加縮合で、−NH₂ の H が −CH₂− の橋に置きかわりながら網目になります。

★☆☆ 参考
2 CO(NH₂)₂ ＋ HCHO→H₂N−CO−NH−CH₂−NH−CO−NH₂ ＋ H₂O

尿素2分子が −CH₂− の橋でつながったところです。尿素1分子には H を出せる −NH₂ が2つ（H は4個）あるので、橋が何か所にもかかって網目になります。

無水フタル酸とグリセリンを縮合重合させると、エステル結合でつながったアルキド樹脂ができます。グリセリンは −OH を3個もつので、鎖が枝分かれして網目になります。2価のアルコールどうしなら、PET のように鎖のままです。

4つの樹脂の名前と原料の組み合わせは必ず暗記してください。「ホルムアルデヒドを使う3つは付加縮合、アルキド樹脂だけはグリセリンで網目になる縮合重合」と分けると覚えやすくなります。構造式は書けなくて構いません。

よくある誤解

×縮合重合でできた樹脂は、どれも熱可塑性樹脂である

○縮合重合でも、3価以上の単量体（グリセリンなど）を使うと網目になり、熱硬化性樹脂になります。アルキド樹脂がその例です。

縮合重合の代表例が鎖状の PET やナイロン66 なので、「縮合重合＝鎖状」と結び付けてしまうためです。★ 網目になるかどうかは重合の型ではなく、単量体が何か所で結合できるかで決まります。

まとめ

  • 尿素とホルムアルデヒドから尿素樹脂、メラミンとホルムアルデヒドからメラミン樹脂、無水フタル酸とグリセリンからアルキド樹脂ができ、いずれも立体網目構造の熱硬化性樹脂である。

高吸水性樹脂

ポリアクリル酸ナトリウムを橋かけして網目にしたもので、自分の重さの数百倍の水を吸ってゲルになります。

アクリル酸ナトリウムを重合させたポリアクリル酸ナトリウムを、少しだけ橋かけして網目にしたものが高吸水性樹脂です。自分の重さの数百〜千倍の水を吸収してゲルになり、少し押しても水を放しません。紙おむつや、土の保水材に使われます。

★★☆ 余裕があれば
n CH₂=CH−COONa→［CH₂−CH(COONa)］ₙ

これを橋かけして網目にしたものが高吸水性樹脂です。

水を吸うと、−COONa が電離して網目に −COO⁻ が並びます。−COO⁻ どうしが反発して網目が広がり、網目の内側のイオンの濃度が外より高くなるので、水が浸透して入り込むためです。網目なので、鎖がばらばらに溶け出すこともありません。

「網目」「−COO⁻」「紙おむつ」の3語を押さえておけば十分でしょう。

まとめ

  • 高吸水性樹脂はアクリル酸ナトリウムの重合体を橋かけした網目構造をもち、自重の数百倍の水を吸収してゲルになる。

イオン交換樹脂

スチレンとジビニルベンゼンの共重合体に酸性や塩基性の基を付けた網目の樹脂で、溶液中のイオンを H⁺ や OH⁻ と交換します。

スチレンに少量のジビニルベンゼンを混ぜて共重合させると、ジビニルベンゼンが鎖どうしの橋になって網目ができます。このベンゼン環にスルホ基 −SO₃H を付けたものが陽イオン交換樹脂、トリメチルアンモニウム基 −N⁺(CH₃)₃ などの塩基性の基を付けたものが陰イオン交換樹脂です。

陽イオン交換樹脂に塩化ナトリウム水溶液を通すと、溶液中の Na⁺ が樹脂の H⁺ と入れかわり、流れ出てくる液は塩酸になります。樹脂の本体を R と書きます。

★★★ 必ず覚える
R−SO₃H ＋ Na⁺→R−SO₃Na ＋ H⁺

入っていった Na⁺ の代わりに、同じ電荷ぶんの H⁺ が出てきます。

★★☆ 余裕があれば
2 R−SO₃H ＋ Ca²⁺→(R−SO₃)₂Ca ＋ 2 H⁺

2価の陽イオンなら、樹脂の −SO₃H 2個ぶんと交換し、H⁺ が2個出てきます。

陰イオン交換樹脂は、溶液中の陰イオンを樹脂の OH⁻ と入れかえます。

★★☆ 余裕があれば
R−N(CH₃)₃OH ＋ Cl⁻→R−N(CH₃)₃Cl ＋ OH⁻

入っていった Cl⁻ の代わりに OH⁻ が出てきます。

使い終わった樹脂は、陽イオン交換樹脂なら濃い塩酸、陰イオン交換樹脂なら濃い水酸化ナトリウム水溶液を流すと、上の反応が逆に進んでもとに戻ります（再生）。

用途は次の3つです。

  • 純水の製造：陽イオン交換樹脂と陰イオン交換樹脂を続けて通すと、出てきた H⁺ と OH⁻ が中和して水になり、イオンをほとんど含まない水が得られます。
  • 硬水の軟化：Ca²⁺ や Mg²⁺ を樹脂に吸着させて取り除きます。家庭用の軟水器では、H⁺ の代わりに Na⁺ を付けた樹脂を使い、Ca²⁺ を Na⁺ と交換します。
  • アミノ酸の分離：pH によってアミノ酸の電荷が変わるので、樹脂への吸着のしやすさの違いで分けられます。

イオン交換樹脂は、構造（スチレン－ジビニルベンゼンに −SO₃H）と交換の反応式を書けるようにしましょう。計算問題は「入った陽イオンの電荷の合計 ＝ 出てきた H⁺ の物質量」の1本で解けます。

例題 —— イオン交換樹脂
例題

陽イオン交換樹脂（H⁺ 形）を十分に詰めた管に、0.050 mol/L の硝酸マグネシウム水溶液 20 mL を流した。管に残った液も純水で押し流し、出てきた液を全部集めて、濃度 0.080 mol/L の NaOH 水溶液で滴定した。中和点までに NaOH 水溶液は何 mL 要るか。

解答を見る

25 mL。Mg²⁺ は 0.050 × 20/1000 ＝ 1.0×10⁻³ mol 入ります。2価なので、出てくる H⁺ はその2倍の 2.0×10⁻³ mol です。0.080 mol/L の NaOH なら 2.0×10⁻³ ÷ 0.080 ＝ 0.025 L ＝ 25 mL になります。★ 「入った陽イオンの電荷の合計 ＝ 出てきた H⁺ の物質量」で考えます。

まとめ

  • スチレンとジビニルベンゼンの共重合体にスルホ基を導入したものが陽イオン交換樹脂で、溶液中の陽イオンを H⁺ と交換する。塩基性の基をもつ陰イオン交換樹脂は陰イオンを OH⁻ と交換する。

アセチレンを付加重合させると、単結合と二重結合が交互に並んだポリアセチレンができます。

「ポリアセチレンにヨウ素を加えると電気を通す」の1文で十分でしょう。

生分解性高分子とリサイクル

微生物に分解される高分子を生分解性高分子といい、代表はポリ乳酸です。使い終わった樹脂は、溶かして成形し直すか、分解して原料に戻します。

微生物のはたらきで、最終的に二酸化炭素と水にまで分解される高分子を生分解性高分子といいます。代表がポリ乳酸です。

★★☆ 余裕があれば
n CH₃CH(OH)COOH→［O−CH(CH₃)−CO］ₙ ＋ n H₂O

乳酸は1分子に −OH と −COOH をもつので、1種類だけで縮合重合できます。実際の製造では、乳酸2分子の環状エステル（ラクチド）をつくってから開環重合させます。

使い終わったプラスチックの行き先は、次の3つに分けられます。

使い終わったプラスチックの行き先
名前やること例
マテリアルリサイクル溶かして成形し直すPET ボトル → 繊維・シート
ケミカルリサイクル化学反応で分解して、原料や単量体に戻すPET → テレフタル酸 ＋ エチレングリコール
サーマルリサイクル燃やして熱エネルギーとして使うごみ発電

ケミカルリサイクルで PET を単量体に戻す反応は、縮合重合の逆 ＝ 加水分解です。また、熱硬化性樹脂は加熱してもやわらかくならないので、マテリアルリサイクルができません。

「マテリアルは形を変える、ケミカルは分子を変える」と覚えましょう。

まとめ

  • 微生物のはたらきで分解される高分子を生分解性高分子といい、ポリ乳酸が代表例である。使用済みプラスチックの再利用には、溶かして成形し直すマテリアルリサイクルと、分解して原料に戻すケミカルリサイクルがある。
