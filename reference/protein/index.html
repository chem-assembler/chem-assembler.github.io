タンパク質

タンパク質はアミノ酸がペプチド結合で多数つながった天然高分子です。ペプチド結合のでき方、一次〜四次構造、分類、熱や酸で立体構造がこわれる変性、そして4つの呈色反応を「何を検出しているか」で並べました。

多数のアミノ酸がつながってできた天然高分子をタンパク質といいます。筋肉・皮膚・毛・酵素・ヘモグロビンなど、生物の体のはたらきの多くをタンパク質が受け持っています。

ペプチド結合

一方のアミノ酸の −COOH と、もう一方のアミノ酸の −NH₂ から水1分子がとれてできる −CO−NH− の結合をペプチド結合といいます。

アミノ酸どうしが、一方の −COOH ともう一方の −NH₂ から水1分子がとれて縮合すると、−CO−NH− の結合ができます。アミノ酸どうしのこの結合をペプチド結合といい、できた化合物をペプチドといいます。

具体例として、グリシン2分子からはグリシルグリシンができます。

★★★ 必ず覚える
H₂N−CH₂−COOH ＋ H₂N−CH₂−COOH→H₂N−CH₂−CO−NH−CH₂−COOH ＋ H₂O

左のグリシンの −COOH の OH と、右のグリシンの −NH₂ の H から水がとれています。

アミノ酸2分子からできたものをジペプチド、3分子ならトリペプチド、多数ならポリペプチドといいます。タンパク質は、ポリペプチドが決まった形に折りたたまれたものです。

ペプチド結合は、カルボン酸とアミンからできるアミド結合と同じ結合です。アミノ酸どうしのときだけ、特にペプチド結合と呼びます。

「ペプチド結合は −CO−NH−、−COOH と −NH₂ から水がとれてできる」は必ず暗記してください。

タンパク質を塩酸と加熱するか酵素で加水分解すると、ペプチド結合が切れて α-アミノ酸の混合物になります。

★★☆ 余裕があれば
ポリペプチド ＋ 水塩酸または酵素→α-アミノ酸の混合物

ペプチド結合1個を切るごとに水が1分子要ります。

構成単位であるアミノ酸の性質（双性イオン・等電点）はアミノ酸のページへ

ナイロンも同じアミド結合でつながった高分子です（合成繊維のページへ）

ペプチドは何種類できるか

ペプチドには向きがあり、−NH₂ が残る端と −COOH が残る端を区別します。だから同じアミノ酸の組み合わせでも、並び順が違えば別の物質です。

ペプチドの鎖の、−NH₂ が残っている端をN末端、−COOH が残っている端をC末端といいます。両端が違うので、ペプチドには向きがあります。

具体例として、グリシン（Gly）とアラニン（Ala）を1分子ずつ使ったジペプチドは、Gly−Ala と Ala−Gly の2種類です。どちらのアミノ酸の −COOH を使うかで、別の物質になります。

  • 2種類のアミノ酸を1回ずつ使うジペプチドは「○○」種類 ＝ 2 × 1 ＝ 2種類
  • 3種類のアミノ酸を1回ずつ使うトリペプチドは「○○」種類 ＝ 3 × 2 × 1 ＝ 6種類
  • N 種類のアミノ酸を1回ずつ使うと、並べ方の数 N! ＝「○○」種類

「ペプチドには向きがあるので、逆順は別物として数える」と覚えましょう。不斉炭素原子による鏡像異性体まで数える問題は、そう指示があるときだけ考えれば構いません。

一次構造から四次構造まで

アミノ酸の並び順を一次構造、水素結合でできるらせんやひだ状の形を二次構造、分子全体の折りたたみを三次構造、複数の鎖の集まりを四次構造といいます。

タンパク質の形は、4つの段階に分けて考えます。

ポリペプチドのアミノ酸の並び順を一次構造といいます。どのタンパク質も、決まった一次構造をもっています。

ペプチド結合の C=O の O と、別のペプチド結合の N−H の H の間には水素結合ができます。この水素結合によって、鎖がらせん状に巻いた α-ヘリックスや、鎖が並んでひだ状になった β-シートができます。これを二次構造といいます。

二次構造をもった鎖が、さらに分子全体として立体的に折りたたまれた形を三次構造といいます。三次構造は、側鎖どうしのジスルフィド結合 −S−S−（システインの −SH どうしからできる）・イオン結合・水素結合などで保たれています。

三次構造をもった鎖（サブユニット）が、いくつか集まってできた形を四次構造といいます。ヘモグロビンは4本の鎖が集まった四次構造をもちます。

タンパク質の構造
段階何を指すかおもに何で保たれているか
一次構造アミノ酸の並び順ペプチド結合
二次構造α-ヘリックス・β-シートペプチド結合の C=O と N−H の間の水素結合
三次構造分子全体の折りたたみジスルフィド結合・イオン結合・水素結合など
四次構造サブユニットの集まりサブユニットどうしの弱い結びつき

この表の「段階」と「何を指すか」の2列は暗記してください。二次構造が水素結合、三次構造でジスルフィド結合が出てくる、の2点までは覚えておきましょう。四次構造をもつタンパク質の名前を覚える必要はありません。

タンパク質の分類

アミノ酸だけからなるものを単純タンパク質、糖や色素などもふくむものを複合タンパク質といいます。形からは球状タンパク質と繊維状タンパク質に分けます。

加水分解したときにアミノ酸だけが得られるものを単純タンパク質、アミノ酸のほかに糖・リン酸・色素・核酸などもふくむものを複合タンパク質といいます。

形で分けると、鎖が丸くまとまって水に溶けやすい球状タンパク質と、鎖が束になって水に溶けにくい繊維状タンパク質があります。

タンパク質の分類と例
分け方種類例
成分で単純タンパク質（アミノ酸だけ）アルブミン（卵白）・ケラチン（羊毛・毛・爪）・フィブロイン（絹）・コラーゲン（皮膚・骨）
成分で複合タンパク質（ほかの成分もふくむ）カゼイン（牛乳・リン酸をふくむ）・ヘモグロビン（血液・色素をふくむ）
形で球状タンパク質（水に溶けやすい）アルブミン・ヘモグロビン
形で繊維状タンパク質（水に溶けにくい）ケラチン・フィブロイン・コラーゲン

「単純／複合」「球状／繊維状」の4つの名前と意味は暗記してください。例として、絹はフィブロイン、羊毛はケラチンの2つは覚えておきましょう。それ以外のタンパク質がどれにあたるかの一覧は、覚える必要はありません。

球状タンパク質を水に溶かすと、分子1個がコロイド粒子の大きさになるので、コロイド溶液になります。多量の塩を加えると沈殿します（塩析）。

変性

熱・強い酸や塩基・重金属イオン・アルコールなどによって、タンパク質の立体構造がこわれることを変性といいます。ペプチド結合は切れないので、一次構造は変わりません。

タンパク質に熱を加えたり、強い酸や塩基、重金属イオン（Cu²⁺・Hg²⁺・Pb²⁺ など）、エタノールなどの有機溶媒を加えたりすると、二次構造以上を保っていた水素結合などが切れて、立体構造がこわれます。これを変性といいます。

具体例として、生卵を加熱すると白く固まり、冷やしても元に戻りません。卵白のアルブミンが熱で変性したためです。消毒用アルコールが細菌を殺すのも、細菌のタンパク質を変性させるためです。

「変性でこわれるのは立体構造。ペプチド結合は切れないので、一次構造は変わらない」と覚えましょう。変性したタンパク質は、ふつう元の形に戻りません。

よくある誤解

×変性すると、タンパク質のペプチド結合が切れてアミノ酸にばらばらになる

○変性で切れるのは、立体構造を保っていた水素結合などです。ペプチド結合は切れず、一次構造は変わりません。

「こわれる」を加水分解と同じものとして覚えてしまうためです。★ ペプチド結合を切るのは、酸や酵素による加水分解のほうです。

酵素が高温ではたらかなくなるのも変性のためです（酵素のページへ）

呈色反応

ビウレット反応はペプチド結合、キサントプロテイン反応はベンゼン環、硫黄の検出は硫黄、ニンヒドリン反応はアミノ基を検出します。

タンパク質やアミノ酸を検出する反応は4つあります。どれも「何を検出しているか」で使い分けます。

タンパク質・アミノ酸の呈色反応
名称試薬と操作色何を検出しているか
ビウレット反応NaOH 水溶液を加えて塩基性にし、少量の CuSO₄ 水溶液を加える赤紫色ペプチド結合2個以上（トリペプチド以上）
キサントプロテイン反応濃硝酸を加えて加熱し、冷やしてからアンモニア水で塩基性にする黄色 → 橙黄色側鎖のベンゼン環
硫黄の検出NaOH 水溶液を加えて加熱し、酢酸鉛(II) 水溶液を加える黒色沈殿（PbS）側鎖の硫黄
ニンヒドリン反応ニンヒドリン水溶液を加えて温める青紫色〜赤紫色アミノ基 −NH₂

この表は4行とも「試薬・色・何を検出しているか」まで暗記してください。反応の仕組みは覚える必要はありません。

キサントプロテイン反応の黄色は、側鎖のベンゼン環がニトロ化されたためです。ベンゼン環をもつアミノ酸の中でも、チロシンのように環に −OH が付いたものがよく反応します。

★★☆ 余裕があれば
側鎖のベンゼン環 ＋ HNO₃加熱→ニトロ化されたベンゼン環（黄色） ＋ H₂O

ベンゼンのニトロ化と同じ置換反応です。

硫黄の検出では、NaOH と加熱して側鎖の硫黄を硫化物イオン S²⁻ に変えてから、鉛(II)イオンで黒い沈殿にします。

★★★ 必ず覚える
S²⁻ ＋ Pb²⁺→PbS（黒色沈殿）

黒色沈殿が出れば、システインなど硫黄をもつアミノ酸をふくみます。

ビウレット反応は、Cu²⁺ が2個以上のペプチド結合の N 原子にはさまれて錯イオンをつくり、赤紫色になるものです。ペプチド結合を1個しかもたないジペプチドでは、はさむ相手が足りないので呈色しません。

ベンゼン環のニトロ化そのものは、ベンゼンの置換反応のページへ

ケルダール法（窒素の定量）発展

タンパク質中の窒素をアンモニアに変えて酸に吸収させ、残った酸を滴定することで、窒素の量からタンパク質の量を求めます。

食品にふくまれるタンパク質の量は、タンパク質中の窒素の量から求めることができます。この方法をケルダール法といいます。

手順は3段です。

  1. 試料を濃硫酸と加熱して分解し、窒素をアンモニウムイオン NH₄⁺ に変える。
  2. 濃い水酸化ナトリウム水溶液を加えて加熱し、出てきたアンモニア NH₃ を、量のわかっている硫酸に吸収させる。
  3. 余った硫酸を水酸化ナトリウム水溶液で滴定する（逆滴定）。
    硫酸がもともと出せた H⁺ の物質量 ＝ NH₃ の物質量 ＋ 滴定に使った NaOH の物質量

求めた NH₃ の物質量が、試料中の窒素原子の物質量です。タンパク質の窒素の質量の割合（およそ16%）が問題文に与えられれば、窒素の質量からタンパク質の質量が出ます。式の立て方は、中和滴定の物質量の関係そのものなので、公式として覚える必要はありません。

例題

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

例題

あるタンパク質の水溶液で (1) ビウレット反応 (2) キサントプロテイン反応 (3) 硫黄の検出 を行ったところ、(1) と (3) は陽性、(2) は陰性だった。このタンパク質についてわかることを書け。

解答を見る

(1) からペプチド結合を2個以上もつこと、(3) からシステインなど硫黄をもつアミノ酸をふくむことがわかります。(2) が陰性なので、チロシンのようなベンゼン環をもつアミノ酸はふくまないと考えられます。

例題

グリシン・アラニン・システインの3種類のアミノ酸を1分子ずつすべて使ってできるトリペプチドは何種類か。鏡像異性体は区別しないものとする。

解答を見る

3種類の並べ方なので 3 × 2 × 1 ＝ 6種類です。ペプチドには向き（N末端と C末端）があるので、逆順も別の物質として数えます。

例題

生卵を加熱すると白く固まり、冷やしても元に戻らない。この現象の名前と、そのときタンパク質の分子に何が起きているかを書け。

解答を見る

変性です。熱によって、立体構造を保っていた水素結合などが切れて、二次構造以上の立体構造がこわれます。ペプチド結合は切れないので一次構造は変わりませんが、ふつう元の形には戻りません。

例題

ビウレット反応は、トリペプチドでは陽性だが、ジペプチドでは陰性になる。その理由を書け。

解答を見る

ビウレット反応の赤紫色は、Cu²⁺ が2個以上のペプチド結合にはさまれてできる錯イオンの色だからです。ジペプチドはペプチド結合を1個しかもたないので、呈色しません。

例題：システイン をつくる

システインを組んで、側鎖に硫黄をもつことを手で確かめます。

▶ システインを組んでみる

側鎖の −SH が、三次構造のジスルフィド結合と、硫黄の検出の黒色沈殿の両方に関わります。
