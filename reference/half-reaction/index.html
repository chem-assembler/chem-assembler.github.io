半反応式の書き方と主な酸化剤・還元剤

半反応式は「反応前後の物質だけ暗記して、係数は手順で出す」。書き方その1（H₂O → H⁺ → e⁻）と その2（酸化数 → e⁻ → H⁺ → H₂O）、必ず覚える酸化剤9本・還元剤11本の半反応式。

酸化剤・還元剤それぞれが e⁻ をどう受け渡すかを書いたイオン反応式を「半反応式」といいます。酸化還元反応の反応式は、酸化剤と還元剤の半反応式を書いてから、2本を組み合わせてつくります。

左辺に e⁻ があれば酸化剤、右辺にあれば還元剤（「酸化と還元」）

暗記するものと、手順で出すもの

反応前後の物質の化学式は暗記、係数は手順で出します。

半反応式で暗記が必要なのは、反応前後の物質の化学式だけです。過マンガン酸イオン MnO₄⁻ が酸性で Mn²⁺ になる、ということは覚えるしかありません。

一方、H₂O・H⁺・e⁻ の係数は、手順どおりに進めれば必ず出ます。係数まで丸暗記してもよいですが、忘れたときに自分で組み立て直せるようにしておきましょう。

書き方その1 —— H₂O → H⁺ → e⁻

O を H₂O で、H を H⁺ で、電荷を e⁻ で合わせます。

過マンガン酸カリウム KMnO₄ の半反応式を、次の4段で書きます。

  1. 酸化剤・還元剤の反応前後の物質（暗記）を書く。
    MnO₄⁻ → Mn²⁺
  2. H₂O で両辺の O 原子の数を合わせる。
    左辺に O 原子が4個あるので、右辺に 4H₂O を加える：MnO₄⁻ → Mn²⁺ ＋ 4H₂O
  3. H⁺ で両辺の H 原子の数を合わせる。
    右辺に H 原子が8個あるので、左辺に 8H⁺ を加える：MnO₄⁻ ＋ 8H⁺ → Mn²⁺ ＋ 4H₂O
  4. e⁻ で両辺の電荷を合わせる。
    左辺の電荷は合計 ＋7、右辺は合計 ＋2 なので、左辺に 5e⁻ を加える
★★★ 必ず覚える
MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻→Mn²⁺ ＋ 4H₂O

完成。Mn の酸化数は ＋7 → ＋2 で5減っており、酸化数の変化と e⁻ の数が対応しています（Mn⁷⁺ ＋ 5e⁻ → Mn²⁺）。

書き方その2 —— 酸化数 → e⁻ → H⁺ → H₂O

先に酸化数の変化から e⁻ の数を決め、電荷を H⁺ で、O を H₂O で合わせます。

同じ KMnO₄ を、酸化数から書く手順です。

  1. 酸化剤・還元剤の反応前後の物質（暗記）を書く。
    MnO₄⁻ → Mn²⁺
  2. 酸化数が変化する原子の酸化数を書き、変化に合わせて e⁻ を加える。
    Mn は ＋7 から ＋2 へ変化しているので、左辺に 5e⁻ を加える：MnO₄⁻ ＋ 5e⁻ → Mn²⁺
  3. H⁺ で両辺の電荷を合わせる。
    左辺の電荷は合計 −6、右辺は ＋2 なので、左辺に 8H⁺ を加える：MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺
  4. H₂O で両辺の O 原子の数を合わせる。
    左辺に O 原子が4個あるので、右辺に 4H₂O を加える：MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻ → Mn²⁺ ＋ 4H₂O

その1とその2は、同じ式にたどり着きます。酸化数がすぐ決まる物質ならその2、酸化数がわかりにくい物質（有機化合物など）ならその1が速いでしょう。どちらか一方を確実に書けるようにしておけば十分です。

主な酸化剤の半反応式

9本。反応前後の物質は必ず暗記します。

次の9本は必ず暗記してください。表の物質名から、反応後の物質と半反応式が書けるようにしておきましょう。

★★★ 必ず覚える
MnO₄⁻ ＋ 8H⁺ ＋ 5e⁻→Mn²⁺ ＋ 4H₂O

過マンガン酸カリウム KMnO₄（硫酸酸性）。赤紫色の MnO₄⁻ が、淡赤色の Mn²⁺ になります（薄い水溶液ではほぼ無色に見えます）。

★★★ 必ず覚える
Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻→2Cr³⁺ ＋ 7H₂O

二クロム酸カリウム K₂Cr₂O₇（硫酸酸性）。赤橙色の Cr₂O₇²⁻ が、緑色の Cr³⁺ になります。

★★★ 必ず覚える
HNO₃ ＋ 3H⁺ ＋ 3e⁻→NO↑ ＋ 2H₂O

希硝酸 HNO₃。無色の NO が発生します。

★★★ 必ず覚える
HNO₃ ＋ H⁺ ＋ e⁻→NO₂↑ ＋ H₂O

濃硝酸 HNO₃。赤褐色の NO₂ が発生します。

★★★ 必ず覚える
H₂SO₄ ＋ 2H⁺ ＋ 2e⁻→SO₂↑ ＋ 2H₂O

熱濃硫酸 H₂SO₄。加熱した濃硫酸だけが酸化剤としてはたらきます。

★★★ 必ず覚える
H₂O₂ ＋ 2H⁺ ＋ 2e⁻→2H₂O

過酸化水素 H₂O₂（酸性）。

★★★ 必ず覚える
SO₂ ＋ 4H⁺ ＋ 4e⁻→S ＋ 2H₂O

二酸化硫黄 SO₂。H₂S のような強い還元剤が相手のときだけ酸化剤になります。

★★★ 必ず覚える
Cl₂ ＋ 2e⁻→2Cl⁻

ハロゲンの単体（Cl₂ など）。H⁺ も H₂O も出てこない、液性に関係ない式です。

★★★ 必ず覚える
I₂ ＋ 2e⁻→2I⁻

ヨウ素 I₂。ハロゲンの単体の中では弱い酸化剤です。

酸化力のある酸の、もう1つの書き方

希硝酸・濃硝酸・熱濃硫酸の3つを「酸化力のある酸」といいます。これらは陰イオン（NO₃⁻・SO₄²⁻）が酸化剤としてはたらくので、次のように書いてもかまいません。

酸化力のある酸の半反応式（陰イオンで書いた形）
酸半反応式
希硝酸NO₃⁻ ＋ 4H⁺ ＋ 3e⁻ → NO ＋ 2H₂O
濃硝酸NO₃⁻ ＋ 2H⁺ ＋ e⁻ → NO₂ ＋ H₂O
熱濃硫酸SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻ → SO₂ ＋ 2H₂O

HNO₃ の形の式の両辺に H⁺ を1個足して打ち消すと、NO₃⁻ の形の式になります。どちらで書いても、組み立てた全体の式は同じになります。

主な還元剤の半反応式

金属の単体を含めて11本。金属イオンの種類と電荷も暗記します。

次の還元剤も必ず暗記してください。

★★★ 必ず覚える
H₂C₂O₄→2CO₂↑ ＋ 2H⁺ ＋ 2e⁻

シュウ酸 H₂C₂O₄（(COOH)₂ とも書く）。

★★★ 必ず覚える
Fe²⁺→Fe³⁺ ＋ e⁻

硫酸鉄(Ⅱ) FeSO₄。

★★★ 必ず覚える
Sn²⁺→Sn⁴⁺ ＋ 2e⁻

塩化スズ(Ⅱ) SnCl₂。

★★★ 必ず覚える
H₂S→S ＋ 2H⁺ ＋ 2e⁻

硫化水素 H₂S。硫黄が析出して、水溶液が白く濁ります。

★★★ 必ず覚える
2I⁻→I₂ ＋ 2e⁻

ヨウ化カリウム KI。生じた I₂ で水溶液が褐色になります。

★★★ 必ず覚える
H₂O₂→O₂↑ ＋ 2H⁺ ＋ 2e⁻

過酸化水素 H₂O₂。KMnO₄ のような強い酸化剤が相手のときに還元剤になります。

★★★ 必ず覚える
SO₂ ＋ 2H₂O→SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻

二酸化硫黄 SO₂。

★★★ 必ず覚える
Na→Na⁺ ＋ e⁻

金属の単体（Na など）。金属の単体はすべて還元剤としてはたらきます。

★★★ 必ず覚える
Cu→Cu²⁺ ＋ 2e⁻

銅。Cu⁺ ではなく Cu²⁺ です。

★★★ 必ず覚える
Fe→Fe²⁺ ＋ 2e⁻

鉄。単体の鉄が溶けるときは Fe³⁺ ではなく Fe²⁺ です。

★★★ 必ず覚える
Zn→Zn²⁺ ＋ 2e⁻

亜鉛。

金属イオンの種類や電荷は暗記です。Cu は Cu⁺ ではなく Cu²⁺、単体の Fe は Fe³⁺ ではなく Fe²⁺ になります。

よくある誤解

×鉄 Fe が酸に溶けると Fe³⁺ になる

○単体の鉄が溶けるときは Fe²⁺ になります。Fe²⁺ → Fe³⁺ は、それとは別の還元剤の式です。

鉄のイオンには Fe²⁺ と Fe³⁺ の2種類があるので、どちらになるかは反応ごとに覚えるしかありません。単体 Fe → Fe²⁺（金属の単体の式）と、Fe²⁺ → Fe³⁺（硫酸鉄(Ⅱ)の式）は別の行として覚えましょう。

酸化剤にも還元剤にもなる物質

過酸化水素 H₂O₂ と二酸化硫黄 SO₂ は、酸化剤・還元剤どちらとしてもはたらきます。どちらになるかは相手で決まり、相手が強い酸化剤なら還元剤に、強い還元剤なら酸化剤になります。

2つの顔をもつ物質
物質酸化剤のとき（酸化数が減る）還元剤のとき（酸化数が増える）
H₂O₂O は −1 → −2（H₂O になる）O は −1 → 0（O₂ になる）
SO₂S は ＋4 → 0（S になる）S は ＋4 → ＋6（SO₄²⁻ になる）

H₂O₂ はふつうは酸化剤で、還元剤としてはたらくのは KMnO₄ などの強い酸化剤が相手のときに限られます。SO₂ はふつうは還元剤で、酸化剤としてはたらくのは H₂S が相手のときがほとんどです。

(1) Cr₂O₇²⁻ ＋ 14H⁺ ＋ 6e⁻ → 2Cr³⁺ ＋ 7H₂O　(2) H₂SO₄ ＋ 2H⁺ ＋ 2e⁻ → SO₂ ＋ 2H₂O　(3) H₂O₂ ＋ 2H⁺ ＋ 2e⁻ → 2H₂O です。(1) を書き方その1で書くと、Cr₂O₇²⁻ → 2Cr³⁺ のあと、O が7個なので右辺に 7H₂O、H が14個なので左辺に 14H⁺、電荷が左辺 ＋12・右辺 ＋6 なので左辺に 6e⁻ です。

例題

次の還元剤の半反応式を書け。(1) シュウ酸　(2) 二酸化硫黄　(3) 鉄

解答を見る

(1) H₂C₂O₄ → 2CO₂ ＋ 2H⁺ ＋ 2e⁻　(2) SO₂ ＋ 2H₂O → SO₄²⁻ ＋ 4H⁺ ＋ 2e⁻　(3) Fe → Fe²⁺ ＋ 2e⁻ です。(2) を書き方その1で書くと、SO₂ → SO₄²⁻ のあと、O が右辺に2個多いので左辺に 2H₂O、H が左辺に4個あるので右辺に 4H⁺、電荷が左辺 0・右辺 ＋2 なので右辺に 2e⁻ です。(3) は Fe³⁺ ではなく Fe²⁺ です。
