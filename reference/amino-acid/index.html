アミノ酸

アミノ酸は1つの分子の中にアミノ基とカルボキシ基、つまり塩基と酸を両方もちます。α-アミノ酸の一般式と側鎖による分類、不斉炭素原子、双性イオン、pH で入れかわる3つの形、等電点と電気泳動までを1枚にしました。

1つの分子の中に、アミノ基 −NH₂ とカルボキシ基 −COOH を両方もつ化合物をアミノ酸といいます。タンパク質を加水分解すると得られるのが、このアミノ酸です。

α-アミノ酸の一般式

−NH₂ と −COOH が同じ炭素原子に結合したアミノ酸を α-アミノ酸といいます。一般式は R−CH(NH₂)−COOH です。

−NH₂ と −COOH が同じ炭素原子に結合しているアミノ酸をα-アミノ酸といいます。タンパク質をつくるアミノ酸は、すべて α-アミノ酸です。

一般式は R−CH(NH₂)−COOH で、R の部分を側鎖といいます。R に何を入れるかで、アミノ酸の種類が決まります。

  • R に H を入れれば「H−CH(NH₂)−COOH」＝ グリシン
  • R に CH₃ を入れれば「CH₃−CH(NH₂)−COOH」＝ アラニン
  • R に ○○ を入れれば「○○−CH(NH₂)−COOH」＝ 別のアミノ酸

一般式 R−CH(NH₂)−COOH は書けるようにしてください。グリシンとアラニンの2つは、構造式まで書けるようにしておきましょう。

側鎖による分類

側鎖に −COOH をもつものを酸性アミノ酸、−NH₂ をもつものを塩基性アミノ酸、どちらももたないものを中性アミノ酸といいます。

α-アミノ酸は、どれも −NH₂ と −COOH を1個ずつもっています。そこに側鎖にもう1個 −COOH があれば酸性アミノ酸、もう1個 −NH₂ があれば塩基性アミノ酸、どちらも無ければ中性アミノ酸です。

この7つは、名前と側鎖の特徴（硫黄・ベンゼン環・余分な −COOH や −NH₂）まで暗記してください。タンパク質の呈色反応でどれが陽性になるかに、そのままつながります。天然のタンパク質をつくるおよそ20種のアミノ酸を、すべて覚える必要はありません。

不斉炭素原子

α位の炭素には H・NH₂・COOH・R の4つが付くので、R が H でなければ不斉炭素原子になります。グリシンだけが例外です。

α-アミノ酸の α位の炭素には、H・−NH₂・−COOH・R の4つが結合しています。R が H 以外なら4つがすべて違うので、この炭素は不斉炭素原子になり、鏡像異性体が存在します。

グリシンは R が H なので、H が2個付くことになり、不斉炭素原子をもちません。「α-アミノ酸のうち、不斉炭素原子をもたないのはグリシンだけ」と覚えましょう。

天然のタンパク質をつくるアミノ酸は、鏡像異性体のうち L形とよばれる片方だけです。L形と D形の見分け方は覚えなくて構いません。

不斉炭素原子と鏡像異性体そのものは立体異性体のページへ

両性の化合物と双性イオン

アミノ酸は酸とも塩基とも反応して塩をつくります。結晶中や水溶液中では、−COO⁻ と −NH₃⁺ を1分子にあわせもつ双性イオンになっています。

アミノ酸の −NH₂ は塩基、−COOH は酸としてはたらきます。だからアミノ酸は、塩酸とも水酸化ナトリウムとも反応して塩をつくります。

具体例としてグリシンで書きます。塩酸とは −NH₂ が、水酸化ナトリウムとは −COOH が反応します。

★★☆ 余裕があれば
H₂N−CH₂−COOH ＋ HCl→Cl⁻ H₃N⁺−CH₂−COOH

塩基である −NH₂ が H⁺ を受け取り、グリシンの塩酸塩になります。

★★☆ 余裕があれば
H₂N−CH₂−COOH ＋ NaOH→H₂N−CH₂−COONa ＋ H₂O

酸である −COOH が中和されて、グリシンのナトリウム塩になります。

「アミノ酸は酸とも塩基とも反応する」は暗記してください。

さらに、1つの分子の中でも −COOH の H⁺ が −NH₂ に移ります。こうしてできた、−COO⁻ と −NH₃⁺ をあわせもつイオンを双性イオンといいます。アミノ酸は、結晶中でも中性付近の水溶液中でも、おもにこの形でいます。

グリシンの双性イオンは H₃N⁺−CH₂−COO⁻ です。全体では正と負が1つずつなので、電荷の合計は0になります。

アミノ酸の結晶の性質

双性イオンどうしが静電気の力で引き合うので、分子量が同じくらいの有機化合物にくらべて融点が高く、水に溶けやすく、有機溶媒に溶けにくくなります。

アミノ酸の結晶は、双性イオンの −COO⁻ と −NH₃⁺ が静電気の力で引き合った、イオン結晶に近いつくりになっています。

そのため、分子量が同じくらいの有機化合物にくらべて融点が高く（融点に達する前に分解するものが多い）、水に溶けやすく、有機溶媒には溶けにくい性質を示します。

「アミノ酸は融点が高く、水に溶けやすい。双性イオンだから」と、理由とセットで覚えましょう。

pH で3つの形が入れかわる

酸性の水溶液中では陽イオン、塩基性の水溶液中では陰イオン、その間では双性イオンが多くなります。

アミノ酸の水溶液に酸を加えて酸性にすると、−COO⁻ が H⁺ を受け取って陽イオンが多くなります。塩基を加えて塩基性にすると、−NH₃⁺ が H⁺ を失って陰イオンが多くなります。

★★★ 必ず覚える
R−CH(NH₃⁺)−COOH（陽イオン）→R−CH(NH₃⁺)−COO⁻（双性イオン） ＋ H⁺

1段目の電離。−COOH のほうが先に H⁺ を手放します。酸性にすると左へ寄ります。

★★★ 必ず覚える
R−CH(NH₃⁺)−COO⁻（双性イオン）→R−CH(NH₂)−COO⁻（陰イオン） ＋ H⁺

2段目の電離。塩基性にすると右へ寄ります。この2本で、3つの形が1本につながります。

「H⁺ が多いところでは H⁺ を受け取り、少ないところでは手放す」の1本で、どちらの形が増えるかはすべて決まります。

具体例としてアラニンで書くと、塩酸を十分に加えたときは CH₃−CH(NH₃⁺)−COOH（陽イオン）、水酸化ナトリウム水溶液を十分に加えたときは CH₃−CH(NH₂)−COO⁻（陰イオン）になります。

等電点と電気泳動

陽イオン・双性イオン・陰イオンの電荷の合計が全体として0になる pH を等電点といいます。等電点では、電圧をかけてもアミノ酸はどちらの電極にも移動しません。

水溶液の pH を変えていくと、ある pH で、陽イオン・双性イオン・陰イオンの電荷の合計が全体として0になります。この pH をそのアミノ酸の等電点といいます。等電点では、ほとんどが双性イオンになっています。

アミノ酸の水溶液に電圧をかけると、陽イオンは陰極へ、陰イオンは陽極へ移動します。これを電気泳動といいます。等電点では電荷の合計が0なので、どちらの電極にも移動しません。

水溶液の pH と、多くなる形・電気泳動での動き
水溶液の pH多くなる形電気泳動での動き
等電点より小さい（酸性側）陽イオン陰極へ移動する
等電点と同じ双性イオン移動しない
等電点より大きい（塩基性側）陰イオン陽極へ移動する

この表の3行の向きは暗記してください。「自分の等電点より酸性側なら陽イオン」と覚えれば、残りの2行はその場で出ます。

等電点の値は、中性アミノ酸ではおよそ6、酸性アミノ酸では小さく（グルタミン酸は約3）、塩基性アミノ酸では大きく（リシンは約10）なります。側鎖の −COOH や −NH₂ のぶんだけ、酸性側か塩基性側へずれるためです。

「酸性アミノ酸の等電点は小さい、塩基性アミノ酸の等電点は大きい」というずれ方だけは覚えてください。個々のアミノ酸の等電点の数値は、覚える必要はありません。問題文に与えられます。

よくある誤解

×等電点では、アミノ酸がすべて双性イオンになっている

○等電点は、陽イオン・双性イオン・陰イオンの電荷の合計が全体として0になる pH です。ほとんどが双性イオンですが、陽イオンと陰イオンもわずかに同じ量ずつあります。

「双性イオンは電荷の合計が0」と「等電点では電荷の合計が0」を同じものとして覚えてしまうためです。★ 入試の記述では「電荷の合計（平均）が0になる pH」と書けば安全です。

アミノ酸の検出

ニンヒドリン水溶液を加えて温め、青紫〜赤紫色に変われば、アミノ酸がある目印です。

アミノ酸の水溶液にニンヒドリンの水溶液を加えて温めると、青紫色〜赤紫色になります。これをニンヒドリン反応といい、アミノ基 −NH₂ を検出する反応です。

「ニンヒドリン反応はアミノ酸の検出、色は青紫〜赤紫」は暗記してください。ほかの呈色反応といっしょに、タンパク質のページで表にまとめています。

ビウレット反応・キサントプロテイン反応など、呈色反応の表はタンパク質のページへ

酸性・塩基性アミノ酸の電離と、片方だけ反応させる手発展

酸性アミノ酸と塩基性アミノ酸は3段階に電離します。また、−COOH と −NH₂ のどちらか片方だけを反応させることもできます。

中性アミノ酸は、上の2本の式のとおり2段階に電離します。側鎖にも −COOH や −NH₂ をもつ酸性アミノ酸・塩基性アミノ酸は、それが1つ増えるので3段階に電離します。

たとえばグルタミン酸は、強い酸性では陽イオン、pH を上げていくと双性イオン、さらに側鎖の −COOH も H⁺ を失って陰イオン、最後に −NH₃⁺ も H⁺ を失って2価の陰イオンになります。等電点を電離定数から計算する問題は、式が与えられる前提で解ければ十分です。

アミノ酸の −COOH だけ、あるいは −NH₂ だけを反応させることもできます。塩化水素を触媒にしてエタノールと反応させると −COOH だけがエステルに、無水酢酸と反応させると −NH₂ だけがアセチル化されます。

★☆☆ 参考
H₂N−CH₂−COOH ＋ C₂H₅OH塩化水素→H₂N−CH₂−COOC₂H₅ ＋ H₂O

−COOH がふさがるので、残った −NH₂ によって全体として塩基性の物質になります。

★☆☆ 参考
H₂N−CH₂−COOH ＋ (CH₃CO)₂O→CH₃CO−NH−CH₂−COOH ＋ CH₃COOH

−NH₂ がふさがるので、残った −COOH によって全体として酸性の物質になります。

例題

アラニンの水溶液に (1) 塩酸を十分に加えたとき (2) 水酸化ナトリウム水溶液を十分に加えたとき、アラニンはおもにどのような形で存在するか。示性式で書け。

解答を見る

(1) CH₃−CH(NH₃⁺)−COOH（陽イオン）　(2) CH₃−CH(NH₂)−COO⁻（陰イオン）。(1) では −COO⁻ も H⁺ を受け取って −COOH に戻っています。

例題

グリシン（等電点 6.0）・グルタミン酸（等電点 3.2）・リシン（等電点 9.7）の混合水溶液を pH 6.0 に保って電気泳動した。それぞれ陽極・陰極のどちらに移動するか。移動しないものは「移動しない」と答えよ。

解答を見る

グリシンは等電点なので移動しない。グルタミン酸は pH が等電点より大きいので陰イオンが多くなり陽極へ。リシンは pH が等電点より小さいので陽イオンが多くなり陰極へ移動します。

例題

アミノ酸の結晶が、分子量が同じくらいのほかの有機化合物にくらべて融点が高く、水に溶けやすいのはなぜか。

解答を見る

結晶中で双性イオンになっていて、正と負の電荷が静電気の力で引き合う、イオン結晶に近いつくりをしているためです。
