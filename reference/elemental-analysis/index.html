元素分析 —— 燃やした質量から分子式まで

有機化合物を完全燃焼させ、生じた CO₂ と H₂O の質量から組成式・分子式を出すまでの手順。吸収管の順番の理由と、酸素の数を1にそろえて計算を軽くするコツまで1本で通します。

有機化合物をつくっている元素の、質量の割合（組成比）を求める手法を元素分析といいます。「どの元素が含まれているか」を調べる定性分析に対して、「どれだけ含まれているか」を調べる定量分析です。このページでは C・H・O だけからなる化合物を扱います。

どの元素が含まれているかを調べる操作は、元素の確認のページへ

装置 —— 燃やして、水と二酸化炭素を別々に受ける

試料を CuO で完全に酸化し、生じた H₂O を塩化カルシウム管、CO₂ をソーダ石灰管で吸収します。

乾燥した酸素を送りながら試料を加熱して燃焼させ、生じた気体を2本の吸収管に順に通します。

装置の各部の役目
位置もの役目
入口乾燥した O₂（または空気）燃焼に使う。湿っていると、その水まで1本目に吸収されてしまう
燃焼管試料 ＋ 酸化銅(II) CuO試料を完全に酸化する酸化剤。CO やすすを残さない
1本目塩化カルシウム管（CaCl₂）中性の乾燥剤なので H₂O だけを吸収する。増えた質量 ＝ H₂O の質量
2本目ソーダ石灰管（NaOH ＋ CaO）塩基性なので酸性の CO₂ を吸収する。増えた質量 ＝ CO₂ の質量

燃焼管に酸化銅(II) を入れておくのは、試料の炭素と水素を残らず CO₂ と H₂O に変えるためです。CuO は酸素を渡す側、つまり酸化剤として働きます。不完全燃焼で CO やすすが残ると、吸収管で量った質量が試料中の C の量と合わなくなるためです。

★★☆ 余裕があれば
試料（C・H・O からなる） ＋ O₂CuO・加熱→CO₂ ＋ H₂O

試料中の C は全部 CO₂ に、H は全部 H₂O になります。係数は試料の分子式によって変わるので、ここでは書いていません。

★★☆ 余裕があれば
C₂H₅OH ＋ 3O₂→2CO₂ ＋ 3H₂O
▶ 大きな画面で開く

エタノールの例です。右辺の O は、試料の O と燃焼に使った O₂ の O が混ざっています。だから O の質量だけは、吸収管の質量からは出せません。

吸収管の順番 —— 水が先、二酸化炭素が後

塩化カルシウム管を先、ソーダ石灰管を後につなぎます。逆にすると H₂O と CO₂ を別々に量れません。

「塩化カルシウム管が先、ソーダ石灰管が後」の順番は、理由ごと必ず覚えてください。理由まで書かせる問題がよく登場します。

塩化カルシウムは中性の乾燥剤なので、水だけを吸収します。一方、ソーダ石灰は NaOH と CaO を混ぜた塩基性の固体です。水も吸いますが、酸性の二酸化炭素もいっしょに取り込んでしまいます。

よくある誤解

×ソーダ石灰管を先につないでも、2本の質量の増え方から H₂O と CO₂ の質量はそれぞれ求められる。

○ソーダ石灰管を先につなぐと、H₂O と CO₂ が1本目で一緒に吸収されてしまい、2本目はほとんど増えません。合計しか分からないので、別々には求められません。

無機で習った気体の乾燥剤の組み合わせ（酸性の気体に塩基性の乾燥剤は使わない）と同じ理由です。

ソーダ石灰をつくるには、酸化カルシウムに濃い NaOH 水溶液をしみこませ、熱して乾かします。できあがりは白い粒です。作り方は覚えなくても構いません。「塩基性だから CO₂ も吸う」が言えれば十分です。

質量を元素ごとに割り振る

CO₂ の質量から C、H₂O の質量から H を出し、O は全体から引き算で出します。

試料の質量、吸収された H₂O の質量、CO₂ の質量から、元素ごとの質量を次のように出します。

各元素の質量の出し方（H=1.0、C=12、O=16）
求めるもの式わけ
C の質量CO₂ の質量 × 12/44CO₂ の分子量 44 のうち、C が占めるのは 12
H の質量H₂O の質量 × 2.0/18H₂O の分子量 18 のうち、H が占めるのは 2個ぶんの 2.0
O の質量試料の質量 −（C の質量 ＋ H の質量）酸素だけは引き算でしか出せない

H は 1.0/18 ではなく 2.0/18 です。水1分子には H が2個入っているためです。ここは計算でいちばん間違えやすいところです。

たとえば CO₂ が 17.6 mg なら、C の質量は 17.6 × 12/44 ＝ 4.8 mg です。H₂O が 7.20 mg なら、H の質量は 7.20 × 2.0/18 ＝ 0.80 mg です。

原子量は問題文に与えられるので、覚えるものではありません。

組成式にする —— 酸素の数を1にそろえる

質量を原子量で割って原子の数の比にし、O が1になるように全体を割ってから整数比にします。

化合物をつくる原子の数を、最も簡単な整数比で表した式を組成式といいます。手順は次の3段です。

  1. 元素ごとの質量を、それぞれの原子量で割る。これで「質量の比」が「原子の数の比」になる。
    C : H : O ＝ C の質量/12 : H の質量/1.0 : O の質量/16
  2. 比の全体を O の値で割り、O を1にそろえる。
    C : H : O ＝ ○○ : ○○ : 1
  3. 最も簡単な整数比に直し、組成式 CxHyOz を書く。

2段目の「O を1にそろえる」がこの計算のコツです。有機化合物をつくる C・H・O のうち、ふつういちばん数が少ないのは O で、組成式の O はたいてい1か2です。O を1にしておくと、残りの数が整数か、整数の半分になりやすく、整数比を見つけやすくなります。

逆に、そろえずに進めると「5.175 : 10.3 : 1.725」のような小数が並び、どれを基準に整数に直せばよいか分からなくなります。これを1.725で割れば 3 : 5.97 : 1 となり、すぐに 3 : 6 : 1 と読めます。

計算の途中は、式を「書き写すところ」と「計算するところ」に分けて書きましょう。書き写すだけの行を作っておくと、見直すときに間違えた行が見つけやすくなります。

例題 —— 組成式にする
例題

C・H・O だけからなる有機化合物 33 mg を完全燃焼させると、CO₂ 66 mg と H₂O 27 mg が生じた。この化合物の組成式を求めよ。（H=1.0、C=12、O=16）

解答を見る

C の質量 ＝ 66 × 12/44 ＝ 18 mg、H の質量 ＝ 27 × 2.0/18 ＝ 3.0 mg、O の質量 ＝ 33 − 18 − 3.0 ＝ 12 mg。C : H : O ＝ 18/12 : 3.0/1.0 : 12/16 ＝ 1.5 : 3.0 : 0.75。O を1にそろえる（全体に 4/3 をかける）と 2 : 4 : 1 なので、組成式は C₂H₄O です。

分子式にする —— 組成式の何倍か

分子式は組成式の整数倍です。分子量を組成式の式量で割って、倍率を出します。

組成式は「原子の数の比」を、分子式は「1分子中の原子の数」を表します。そのため分子式は組成式の整数倍になり、倍率は「分子量 ÷ 組成式の式量」で決まります。

たとえば組成式 CH₂O（式量30）で分子量が60なら、60 ÷ 30 ＝ 2 なので分子式は C₂H₄O₂ です。

組成式が CH₂O になる化合物
分子式分子量組成式の何倍か化合物の例
CH₂O301倍ホルムアルデヒド HCHO
C₂H₄O₂602倍酢酸 CH₃COOH
C₃H₆O₃903倍乳酸 CH₃CH(OH)COOH
C₆H₁₂O₆1806倍グルコース

組成式だけでは、どの化合物か決まりません。上の4つはどれも組成式が CH₂O です。分子式まで出すには、分子量が必要です。

酢酸・乳酸の性質はカルボン酸のページへ

分子量はどこから来るか

いちばん多いのは、問題文に分子量がそのまま与えられる場合です。与えられないときは、気体の状態方程式や、凝固点降下・沸点上昇・浸透圧の測定から求めます。

凝固点降下などから求めるときは、溶かした試料の質量をその物質量で割ります。電離する物質では溶液中の粒子の数が増えるので、その分を補正する必要があります。

質量分析発展

実際の研究では、分子量は質量分析（MS）という機器で直接測ります。仕組みは覚えなくて構いません。

例題 —— 分子式にする
例題

C・H・O だけからなる有機化合物 12.0 mg を完全燃焼させると、CO₂ 17.6 mg と H₂O 7.20 mg が生じた。この化合物の組成式を求めよ。また、分子量が 60 のとき、分子式を求めよ。（H=1.0、C=12、O=16）

解答を見る

C の質量 ＝ 17.6 × 12/44 ＝ 4.8 mg、H の質量 ＝ 7.20 × 2.0/18 ＝ 0.80 mg、O の質量 ＝ 12.0 − 4.8 − 0.80 ＝ 6.4 mg。3つとも小数第1位までそろえておくと、足して 12.0 に戻るかがすぐ確かめられます。C : H : O ＝ 4.8/12 : 0.80/1.0 : 6.4/16 ＝ 0.40 : 0.80 : 0.40。O を1にそろえると 1 : 2 : 1 なので、組成式は CH₂O（式量30）。60 ÷ 30 ＝ 2 より、分子式は C₂H₄O₂ です。

例題

C・H・O だけからなる分子量 116 の化合物がある。質量組成は炭素 62.1%、水素 10.3% であった。この化合物の分子式を求めよ。（H=1.0、C=12、O=16）

解答を見る

O は 100 − 62.1 − 10.3 ＝ 27.6%。C : H : O ＝ 62.1/12 : 10.3/1.0 : 27.6/16 ＝ 5.175 : 10.3 : 1.725。O を1にそろえる（1.725 で割る）と 3 : 5.97 : 1 ≒ 3 : 6 : 1 なので、組成式は C₃H₆O（式量58）。116 ÷ 58 ＝ 2 より、分子式は C₆H₁₂O₂ です。分子量が分かっているときは、116 × 0.621/12 ＝ 6.0 のように各元素の質量を先に出しても同じ答えになりますが、計算が重くなります。

例題

質量組成が炭素 64.3%、水素 7.1%、酸素 28.6% で、分子量が 112 の化合物の分子式を求めよ。（H=1.0、C=12、O=16）

解答を見る

C : H : O ＝ 64.3/12 : 7.1/1.0 : 28.6/16 ＝ 5.36 : 7.1 : 1.79。O を1にそろえる（1.79 で割る）と 3.0 : 4.0 : 1 なので、組成式は C₃H₄O（式量56）。112 ÷ 56 ＝ 2 より、分子式は C₆H₈O₂ です（食品の保存料に使うソルビン酸がこの分子式です）。

覚える範囲

装置の順番と理由は必ず覚え、計算は手順として身につけます。

吸収管の順番（塩化カルシウム管が先、ソーダ石灰管が後）と、その理由は必ず覚えてください。CuO が酸化剤であることも覚えておきましょう。

計算は暗記ではなく手順です。原子量は問題に与えられます。「H は 2.0/18」と「O は引き算」の2点だけは、手順の中で必ず意識してください。

ソーダ石灰の作り方、質量分析の仕組みは覚えなくても構いません。
