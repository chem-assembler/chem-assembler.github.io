エステル

カルボン酸とアルコールから水がとれて縮合した化合物をエステルといい、そのときできる −COO− の結合をエステル結合といいます。

エステルの性質

カルボン酸と同じ一般式をもち、果実のような芳香がある無極性の液体です。

鎖式で不飽和結合をもたないエステルの一般式は CnH2nO2 です。n = 3 を代入すると C₃H₆O₂ ＝ 酢酸メチル CH₃COOCH₃ の分子式が得られます。

カルボン酸も同じ一般式 CnH2nO2 をもつので、同じ分子式のエステルとカルボン酸は互いに構造異性体です。分子式 CnH2nO2 を見たら、カルボン酸とエステルの両方を候補に入れてください。

エステルは果実のような芳香をもつ液体です。実際に果実の香りの成分として含まれています。酢酸エチル CH₃COOC₂H₅ は無色の液体で、溶媒や香料に使われます。

エステルは無極性分子なので分子間力が弱く、沸点が低いです。同じ理由でほとんど水に溶けないと考えてよく、炭素数の少ないエステルだけがある程度水に溶けます。

カルボン酸は加水分解を起こしませんが、エステルは加水分解してアルコールとカルボン酸にもどります。この違いが構造決定の出発点になります。

なぜカルボン酸とエステルの一般式が同じになるのか

どちらもカルボニル化合物 CnH2nO に O 原子を1個入れた構造をしています。入れる場所が違うだけです。

  1. カルボニル基と H 原子の間に O 原子を入れる → カルボン酸になる。
    アルデヒド R−CHO の C と H の間に O が入って R−COOH
  2. カルボニル基と C 原子の間に O 原子を入れる → エステルになる。
    アルデヒド R−CHO の C と R の間に O が入って R′−COO−R

どちらも CnH2nO に O が1個増えただけなので、一般式は CnH2nO2 になります。

別の数え方もできます。エステルは2つのアルキル基 −CaH2a+1 と −CbH2b+1 がエステル結合でつながった形なので、分子式は Ca+b+1H2(a+b+1)O2 となり、n = a＋b＋1 と置けば CnH2nO2 になります。この導出を覚える必要はありません。一般式そのものは覚えてください。

エステルの命名

「カルボン酸の名前」＋「アルコールから来たアルキル基の名前」をつなぐだけです。

エステルの名称は「（カルボン酸の名称）＋（カルボン酸の H 原子を置換したアルキル基の名称）」です。カルボン酸の名前を慣用名で覚えているので、エステルの名前も慣用名でよいです。

  1. エステル結合 −COO− の左側（C=O のある側）がカルボン酸から来た部分。その名前を前に置く。
    カルボン酸が酢酸なら「酢酸○○」、ギ酸なら「ギ酸○○」
  2. エステル結合の右側（O から炭素へ伸びる側）がアルコールから来た部分。そのアルキル基の名前を後ろに置く。
    メタノール由来なら「○○メチル」、エタノール由来なら「○○エチル」

酢酸とエタノールからできるエステルなら、前が「酢酸」、後ろが「エチル」で、酢酸エチルになります。

エステルの名前は、構造式を見て言えるようにしてください。構造決定の答案では、名前ではなく構造式で答えることが多いので、逆向き（名前から構造式）も書けるようにしておくと安全です。

エステル化・加水分解・けん化

同じ反応を右へ進めるか左へ進めるか、そして左へ進めて止める方法。3本で1組です。

カルボン酸 R−COOH とアルコール R′−OH の混合物に、触媒として少量の濃硫酸を加えて加熱すると、脱水縮合してエステルが生じます。これをエステル化といいます。

★★★ 必ず覚える
R−COOH ＋ R′−OH濃硫酸→加熱R−COO−R′ ＋ H₂O

触媒としてはたらくのは水素イオン H⁺ です。濃硫酸を使うのは、脱水作用で生じた水を取り除いて平衡を右へ寄せ、エステルの収率を上げるためです。

「カルボン酸から OH、アルコールから H がとれる」は丸暗記してください。反応の仕組みの上でそう決まっているもので、どちらの原子が水になったかを問う問題がよく登場します。

逆向きに進めると加水分解です。エステルに希硫酸などの酸を触媒として水を加えると、カルボン酸とアルコールにもどります。

★★★ 必ず覚える
R−COO−R′ ＋ H₂O希硫酸→R−COOH ＋ R′−OH

エステル化とまったく同じ反応を左向きに進めたものなので、可逆反応です。だから完全にはもどりきりません。

エステルに水酸化ナトリウム水溶液を加えて加熱すると、カルボン酸の塩とアルコールに分かれます。これをけん化といいます。

★★★ 必ず覚える
R−COO−R′ ＋ NaOH加熱→R−COONa ＋ R′−OH

生じたカルボン酸がその場で中和されて塩になるので、逆反応が起こりません。だから最後まで進みます。

「加水分解は可逆、けん化は最後まで進む」と覚えましょう。同じ「エステルを切る」操作でも、酸を使うか塩基を使うかで結果が変わります。

エステル結合をつくる／切る3本の反応（3行）
反応の名前加えるものできるもの逆にもどるか
エステル化カルボン酸とアルコールに濃硫酸を加えて加熱エステル ＋ 水もどる（可逆）。濃硫酸が水を取り除いて右へ寄せる
加水分解エステルに水と希硫酸などの酸を加えるカルボン酸 ＋ アルコールもどる（可逆）。だから完全には切れない
けん化エステルに水酸化ナトリウム水溶液を加えて加熱カルボン酸のナトリウム塩 ＋ アルコールもどらない。塩になった時点で逆反応が起こらない
ギ酸エステルは還元性を示す

ギ酸エステル HCOO−R は、エステルでありながら銀鏡反応を示します。HCOO− の H−C=O の部分が、そのままホルミル基のかたちになっているためです。

「還元性を示すのは、アルデヒドとギ酸とギ酸エステル」と覚えてください。「エステルだから還元性は無い」として候補から外すと、構造決定で答えが出なくなります。分子式から異性体を書き出すときは、ギ酸エステルを最初から候補に入れてください。

エステルの構造決定

エステルはまず切る。切って出てきたアルコールとカルボン酸に、条件を当てていきます。

エステルの構造決定は、加水分解して2つに切ってから、それぞれについての条件を読むのが基本の形です。条件はほとんどがアルコール側に付きます。

  1. 分子式の酸素の数を見る。エステル結合1つが O 原子を2個使うので、O が2個ならエステル結合は1つです。
    O が2個なら「エステルかカルボン酸」、O が4個なら「エステル結合は多くても2つ」
  2. 加水分解して2つに分ける。炭素数の和は、もとの分子の炭素数と等しくなります。
    炭素数5なら「カルボン酸1＋アルコール4」「2＋3」「3＋2」「4＋1」の4通り
  3. 出てきたアルコール側の条件を当てる。酸化の行き先（1級か2級か3級か）・脱水生成物・ヨードホルム反応・不斉炭素原子の有無。
  4. 出てきたカルボン酸側の条件を当てる。銀鏡反応が陽性ならギ酸、炭素数1ならギ酸。
  5. 決まった2つをエステル結合でつなぎ直して、構造式を書く。

アルコールの性質と、アルキル基の書き出しができることが前提になります。構造決定でつまずくときは、たいていエステルではなくアルコール側の知識が抜けています。

2価のエステル・環状エステル・無機のエステル発展

エステル結合が2つあるとき、同じ分子の中で結ばれたとき、そして相手が無機の酸のとき。

エステル結合1つが O 原子を2個使うので、分子式の酸素の数から、エステル結合の数は多くてもその半分と決まります。O が4個なら、エステル結合は多くても2つです。

2価以上のエステルを加水分解すると、出てくるものの比は 1対1 とはかぎりません。同じアルコールや同じ酸が2分子出てくることがあります。

鎖状の2価エステルは、エステル結合の向きの組み合わせが3通りあります。向きが違うと加水分解で出てくるものが変わるので、3通りとも書き出してから条件を当てます。

同じ分子の中にあるヒドロキシ基とカルボキシ基が脱水すると、環状のエステルができます。これをラクトンといいます。ラクトンは加水分解しても分子が2つに分かれないので、加水分解の前後で分子の数が変わりません。

硝酸や硫酸などの無機の酸（オキソ酸）も、アルコールとエステルをつくります。グリセリンと硝酸のエステルがニトログリセリンです。

この節の内容を先に覚える必要はありません。構造決定の問題文に「2価のエステル」「環状のエステル」と書いてあったときに、ここへ戻ってくれば十分です。

紙に書いて解いてみてください。答え合わせは「解答を見る」から。

例題

次の化学反応式を書け。(1) 酢酸とエタノールに少量の濃硫酸を加え加熱した　(2) ギ酸と2-プロパノールに少量の濃硫酸を加え加熱した

解答を見る

(1) CH₃COOH ＋ C₂H₅OH → CH₃COOC₂H₅ ＋ H₂O（酢酸エチル）　(2) HCOOH ＋ CH₃CH(OH)CH₃ → HCOOCH(CH₃)₂ ＋ H₂O（ギ酸イソプロピル）　どちらもカルボン酸から −OH、アルコールから −H がとれています。名前は「カルボン酸の名前＋アルキル基の名前」の順につなぎます。

例題

分子式が C₆H₁₂O₂ である化合物 A がある。A を加水分解すると B と C が生じた。C を酸化すると B が得られた。化合物 A の構造式を書け。

解答を見る

A はエステルなので、加水分解するとカルボン酸 B とアルコール C に分かれます。「C を酸化すると B」ということは、C と B は炭素数が同じで、C は酸化されてカルボン酸になる1級アルコールです。炭素数の和が6で、2つが同数なので、どちらも炭素数3。つまり B はプロピオン酸 CH₃CH₂COOH、C は1-プロパノール CH₃CH₂CH₂OH です。よって A はプロピオン酸プロピル CH₃CH₂COOCH₂CH₂CH₃ となります。2-プロパノールを酸化してもアセトン（ケトン）にしかならないので、C は1-プロパノールに決まります。

例題

分子式が C₅H₁₀O₂ である化合物 A、B がある。A は不斉炭素原子をもたないが、B は不斉炭素原子をもつ。A を加水分解すると C と D が、B を加水分解すると E と F がそれぞれ生じた。C に濃硫酸を加えて加熱すると沸点34℃の F の構造異性体が生じた。E にアンモニア性硝酸銀水溶液を加えて加熱すると X が析出した。F をヨウ素と水酸化ナトリウム水溶液とともに加熱すると Y の（ア）色沈殿が生じた。A、B の構造式、X、Y の化学式、（ア）に当てはまる語句を答えよ。

解答を見る

沸点34℃の物質はジエチルエーテル C₂H₅OC₂H₅ です。C を分子間脱水するとジエチルエーテルになるので、C はエタノール C₂H₅OH。F はジエチルエーテルの構造異性体なので分子式は C₄H₁₀O のアルコールで、さらにヨードホルム反応が陽性なので CH₃CH(OH)− をもち、F は2-ブタノール CH₃CH(OH)C₂H₅ です。A は C₅H₁₀O₂ でアルコール側がエタノール（炭素数2）なので、カルボン酸 D は炭素数3のプロピオン酸。よって A はプロピオン酸エチル CH₃CH₂COOC₂H₅（不斉炭素原子なし）。B はアルコール側が2-ブタノール（炭素数4）なので、カルボン酸 E は炭素数1のギ酸 HCOOH で、銀鏡反応を示すことと合います。よって B はギ酸 sec-ブチル HCOOCH(CH₃)C₂H₅（O が付いた C に H・CH₃・C₂H₅ が付くので不斉炭素原子あり）。X は Ag、Y は CHI₃、（ア）は黄です。
