立体異性体 —— つながり方は同じで、形が違う

原子のつながり方は同じなのに、立体的な形が違うために別の分子になるのが立体異性体です。二重結合で生じるシス－トランス異性体、不斉炭素原子で生じる鏡像異性体、不斉炭素原子の見つけ方、鏡像異性体の性質、メソ体までを1枚にまとめました。

分子式が同じでも構造が違う化合物を異性体といいます。そのうち、原子のつながり方はまったく同じなのに、立体的な形が違うために別の分子になるものを立体異性体といいます。このページでは、立体異性体の2つの種類 —— シス－トランス異性体と鏡像異性体 —— を見ていきましょう。

つながり方が違う異性体（構造異性体）と、その書き出しの手順は「同じ分子式で、別の分子」に

立体異性体とは —— 構造異性体との違い

分子式が同じなら異性体。さらに示性式まで同じなら立体異性体です。

異性体は2つに分けられます。原子の結合の順序（つながり方）が違うものが構造異性体、結合の順序は同じで、立体的な構造が違うものが立体異性体です。

たとえば、酢酸 CH₃COOH とギ酸メチル HCOOCH₃ は、分子式がどちらも C₂H₄O₂ ですが、つながり方が違います。示性式を書くと別の式になるので、この2つは構造異性体です。

一方、シス-2-ブテンとトランス-2-ブテンは、示性式を書くとどちらも CH₃CH=CHCH₃ で、まったく同じ式になります。それでも、メチル基 −CH₃ が二重結合の同じ側にあるか逆側にあるかで、別の分子になります。これが立体異性体です。

異性体の分け方
種類何が違うか示性式例
構造異性体原子のつながり方違う酢酸とギ酸メチル／ブタンと 2-メチルプロパン
立体異性体（シス－トランス異性体）二重結合に対する置換基の配置同じシス-2-ブテンとトランス-2-ブテン
立体異性体（鏡像異性体）不斉炭素原子に対する置換基の配置同じ乳酸の1対

「分子式が同じなら異性体、示性式まで同じなら立体異性体」と覚えてしまいましょう。示性式は結合の順序を表しているので、示性式が同じなら、違いは立体の形にしかありません。

補足

シス－トランス異性体は幾何異性体、鏡像異性体は光学異性体ともよばれます。どちらも古い呼び名ですが、問題文に出てくることがあるので、同じものだと分かるようにしておいてください。

シス－トランス異性体 —— 二重結合が回らないから生じる

二重結合は回転できないので、置換基が同じ側のシス形と、逆側のトランス形が別の分子になります。

炭素間の二重結合 C=C は回転できません。そのため、二重結合に結合している置換基（ここでは −CH₃）の並び方が固定され、同じ側にあるシス形と、逆側にあるトランス形の2つの立体異性体が生じます。この2つを互いにシス－トランス異性体といいます。

単結合は自由に回転できるので、単結合のまわりでは同じことは起こりません。二重結合がなぜ回らないのかは、アルケンのページで説明しています。

二重結合が回転できない理由と、アルケンの性質・反応はアルケンのページに

シス－トランス異性体が生じる条件

シス－トランス異性体があるかどうかは、二重結合の両端の炭素を1個ずつ見るだけで決まります。

  1. 二重結合の左の炭素に付いている2つを見る。
    2つが違う原子・原子団なら次へ。同じもの（H が2個など）なら、シス－トランス異性体はありません。
  2. 二重結合の右の炭素に付いている2つを見る。
    こちらも2つが違えば、シス－トランス異性体があります。

「両端の炭素が、どちらも違うものを2つずつもつ」ことが条件です。片方でも同じものが2つ付いていたら、裏返すと重なってしまうので、立体異性体は生じません。

2-ペンテンCH₃CH=CHCH₂CH₃H と CH₃H と C₂H₅ある
1,2-ジクロロエテンCHCl=CHClH と ClH と Clある

プロペンCH₂=CHCH₃H と HH と CH₃ない

末端に二重結合がある（CH₂= で始まる）アルケンには、シス－トランス異性体はありません。端の炭素に H が2個付いているからです。これを知っておくと、書き出しのときにすばやく判定できます。

よくある誤解

×1-ブテンも、エチル基を上に描くか下に描くかで、シス形とトランス形の2つがある。

○1-ブテンの左端の炭素には H が2個付いているので、上下どちらに描いても裏返せば重なる同じ分子です。シス－トランス異性体はありません。

紙の上では2通りに描けてしまうので、別の分子に見えます。見るべきなのは描き方ではなく、「両端の炭素がそれぞれ違うものを2つもつか」です。

シス－トランス異性体は、融点や沸点などの性質が互いに違います。別の物質として区別できるので、マレイン酸（シス形）とフマル酸（トランス形）のように別の名前が付いているものもあります。この点が、次の節の鏡像異性体と大きく違うところです。

環にもシス－トランス異性体がある（環も回転できない）話はシクロアルカンのページに

鏡像異性体 —— 不斉炭素原子から生じる

4つの手すべてに違うものが付いた炭素が不斉炭素原子です。あると、右手と左手のように重ならない1対の鏡像異性体が生じます。

4つの結合の手に、すべて異なる原子または原子団が結合している炭素原子を不斉炭素原子といいます。不斉炭素原子をもつ化合物には、互いに鏡に映した像の関係にある鏡像異性体が1対（2種類）存在します。

鏡像異性体の関係は、右手と左手の関係と同じです。右手と左手は同じ形ですが、どう回しても重ね合わせることはできません。手袋の左右を逆にはめられないのはこのためです。鏡像異性体も、どのように回転させても互いに重ね合わせることができません。

例として乳酸 CH₃CH(OH)COOH を見てみましょう。中央の炭素には、−CH₃・−OH・−COOH・−H の4つが結合しています。4つとも違うので、この炭素は不斉炭素原子です。

くさび形の表し方では、塗りつぶした三角形は紙面の手前、破線（しましま）の三角形は紙面の奥に伸びている結合を表します。4つの結合は正四面体の頂点の向きに伸びているので、平面の構造式ではこの違いが見えません。鏡像異性体は、平面の構造式ではまったく同じ式になることに注意してください。

乳酸の2つの鏡像異性体は、D-乳酸・L-乳酸のように D・L の記号で区別されます。D形・L形の見分け方は覚えなくて構いません。「不斉炭素原子が1個あれば鏡像異性体が1対ある」が言えれば十分です。

不斉炭素原子の見つけ方

不斉炭素原子は「枝の付け根」を探します。付け根でも、同じものが2つ付いていれば不斉炭素原子ではありません。

構造式の中の不斉炭素原子は、次の手順で探します。

  1. 「枝の付け根」の炭素だけを候補にする。
    鎖の途中の −CH₂− や端の −CH₃ は、水素が2個以上付いているので不斉炭素原子ではありません。二重結合をつくっている炭素も、4つの手に4つの別々のものが付いていないので外します。
  2. 候補の炭素の4つの手に付いているものを書き出す。
    2-ブタノールの2番の炭素なら「H・OH・CH₃・C₂H₅」です。
  3. 4つがすべて違えば不斉炭素原子。1組でも同じなら不斉炭素原子ではない。
    原子団が同じかどうかは、その炭素から先へたどって、最初に違いが出るところまで比べます。

具体例で見てみましょう。2-ブタノール CH₃CH(OH)CH₂CH₃ の2番の炭素には「H・OH・CH₃・C₂H₅」が付いていて、4つとも違うので不斉炭素原子です。ところが 3-ペンタノール CH₃CH₂CH(OH)CH₂CH₃ の3番の炭素は、同じ枝の付け根でも「H・OH・C₂H₅・C₂H₅」で、エチル基が2つ付いているので不斉炭素原子ではありません。

不斉炭素原子をもつアルキル基は、炭素4個から

アルキル基の付け根の炭素が不斉炭素原子になるには、付け根に H・メチル基・エチル基と、残りの手の4つの違うものが要ります。そのため、付け根が不斉炭素原子になれるいちばん小さいアルキル基は sec-ブチル基 −CH(CH₃)CH₂CH₃（炭素4個）です。

炭素3個のアルキル基（プロピル基・イソプロピル基）では、どちらも付け根に同じものが2つ付くので不斉になりません。「不斉炭素原子をもつ」と問題文にあったら、炭素4個以上の枝があると読めます。構造決定の問題では、これで炭素の割り振りが先に決まることがよくあります。sec-ブチル基が最小であることは覚えておきましょう。

環の中の炭素を調べるとき

環の中の炭素は、左右の手がどちらも環の一部なので、「枝の付け根を探す」だけでは判定できません。その炭素から環を左回りと右回りにたどり、最初に違いが出るところまで比べます。左右で違えば不斉炭素原子、同じなら不斉炭素原子ではありません。

たとえばメチルシクロヘキサンの、メチル基が付いた炭素から環を左右にたどると、どちらも −CH₂−CH₂−CH₂− と同じ並びが続くので、不斉炭素原子ではありません。1,2-ジメチルシクロプロパンでは、片側がすぐ −CH(CH₃)−、反対側が −CH₂− と最初の1個で違いが出るので、不斉炭素原子です。

鏡像異性体の性質 —— ほとんど同じで、旋光性と生理作用が違う

1対の鏡像異性体は、融点・沸点・密度・溶解度が同じです。違うのは、偏光面を回す向き（旋光性）と、生物に対するはたらきです。

1対の鏡像異性体は、融点・沸点・密度・溶解度などがすべて同じで、ふつうの化学反応での反応性も同じです。そのため、ふつうの方法では区別できません。

ただし、2つだけ違うところがあります。

  • 旋光性（偏光面を回転させる性質）の向きが逆。
    一方の鏡像異性体が偏光面を右に回すなら、もう一方は同じ角度だけ左に回します。鏡像異性体が「光学異性体」ともよばれるのは、この光学的な性質が違うためです。
  • 生物に対するはたらき（生理作用）が違う。
    味・におい・薬としての効き方が違うことがあります。生体内の酵素などのタンパク質は、一方の鏡像異性体のアミノ酸だけからできている不斉な相手なので、鏡像異性体を区別して認識するためです。
1対の鏡像異性体と、シス－トランス異性体の性質の比べ
性質1対の鏡像異性体シス－トランス異性体
融点・沸点・密度・溶解度同じ違う

よくある誤解

×1対の鏡像異性体は、物理的性質がすべて同じである。

○融点・沸点・密度・溶解度は同じですが、旋光性（偏光面を回す向き）が逆です。旋光性も物理的性質なので、「すべて同じ」は誤りです。

「鏡像異性体は性質がほとんど同じ」と覚えていると、「すべて」まで言い切ってしまいます。正誤問題でねらわれるのはこの一語です。

「融点・沸点は同じ、旋光性と生理作用が違う」の3点は必ず覚えてください。偏光面を回す角度の値や、D形・L形と右回り・左回りの対応を覚える必要はありません（D・L は立体の配置で決めた記号で、回す向きとは対応していません）。

旋光性が逆に転じることから名前が付いた「転化糖」は二糖類のページに

不斉炭素原子が2個あるとき —— メソ体発展

不斉炭素原子が n 個あると立体異性体は最大 2ⁿ 種類ですが、分子の中に対称性があると、それより少なくなります。

不斉炭素原子1個ごとに、置換基の配置は2通りあります。そのため、不斉炭素原子を n 個もつ化合物の立体異性体は、最大で 2ⁿ 種類になります。

ところが、複数の不斉炭素原子をもち、しかも分子の中に対称性があると、2ⁿ 種類のうちのいくつかが重なって、数が 2ⁿ より少なくなります。鏡に映した像と重なってしまう立体異性体が生じるためで、これをメソ体（メソ化合物）といいます。

例は酒石酸 HOOC−CH(OH)−CH(OH)−COOH です。2個の炭素がどちらも「H・OH・COOH・残りの半分」をもつので、不斉炭素原子は2個です。

不斉炭素原子2個なら 2² ＝ 4 種類のはずですが、そのうち2つは分子の中に対称面をもつ同じ分子（メソ体）なので、酒石酸の立体異性体は D形・L形・メソ体の3種類です。メソ体は自分自身の鏡像と重なるので、旋光性を示しません。

同じことは 2,3-ブタンジオール CH₃CH(OH)CH(OH)CH₃ や、環をもつ 1,2-ジメチルシクロプロパンでも起こり、どちらも立体異性体は3種類です。

メソ体まで覚える必要はありません。教科書では発展の扱いです。「不斉炭素原子が n 個なら最大 2ⁿ、左右対称なら減ることがある」とだけ知っておけば、入試の発展問題にも対応できます。

例題

次の文の空欄に適する語を入れよ。同じ分子式をもつが構造が異なる化合物を（ア）という。（ア）のうち、示性式が異なり原子の結合の順序が異なるものを（イ）といい、示性式が同じで分子の立体的な構造が異なるものを（ウ）という。（ウ）にはさらに、炭素間二重結合に対する置換基の配置の違いによって生じる（エ）と、不斉炭素原子に対する置換基の配置の違いによって生じる（オ）がある。

解答を見る

（ア）異性体、（イ）構造異性体、（ウ）立体異性体、（エ）シス－トランス異性体、（オ）鏡像異性体。分子式が同じものが異性体、さらに示性式も同じものが立体異性体です。

例題

次の化合物のうち、鏡像異性体をもつものをすべて選び、不斉炭素原子の数を答えよ。（ア）1-ブタノール CH₃CH₂CH₂CH₂OH　（イ）2-ブタノール CH₃CH(OH)CH₂CH₃　（ウ）2-メチル-2-プロパノール (CH₃)₃COH　（エ）3-ペンタノール CH₃CH₂CH(OH)CH₂CH₃　（オ）2,3-ブタンジオール CH₃CH(OH)CH(OH)CH₃

解答を見る

（イ）と（オ）です。（イ）は OH の付いた炭素に「H・OH・CH₃・C₂H₅」が付くので不斉炭素原子が1個。（オ）は中央の2個の炭素がどちらも「H・OH・CH₃・CH(OH)CH₃」をもつので2個。（ア）は枝の付け根がありません。（ウ）は付け根に CH₃ が3個、（エ）は付け根に C₂H₅ が2個付くので、不斉炭素原子ではありません。

例題

次のアルケンのうち、シス－トランス異性体が存在するものをすべて選べ。（ア）プロペン　（イ）2-ペンテン　（ウ）2-メチル-2-ブテン　（エ）1,2-ジクロロエテン　（オ）1,1-ジクロロエテン

解答を見る

（イ）と（エ）です。（イ）は左の炭素に「H と CH₃」、右の炭素に「H と C₂H₅」、（エ）は両方の炭素に「H と Cl」が付いていて、どちらも両端が違うものを2つずつもちます。（ア）と（オ）は端の炭素に同じもの（H が2個）が付き、（ウ）は片方の炭素に CH₃ が2個付くので、シス－トランス異性体はありません。
