# 設計メモ: イオン反応式を主にする／反応を2本に分ける

対象は錯イオン・両性水酸化物。2026-07-27 のユーザー指示にもとづく設計。
実装は本メモを正として進め、決まったことは DEVELOPMENT.md のチェックリストに反映する。

## 1. 何が問題か

現在 reactions.json にあるのは**まとめ版だけ**で、しかも1本に混ぜすぎている。

| 現在 | 問題 |
|---|---|
| `complex-cuoh2-nh3`: CuSO₄ ＋ NaOH ＋ NH₃ → [Cu(NH₃)₄](OH)₂ ＋ Na₂SO₄ | 反応物3つ。**NaOH と NH₃ を1本の式に混ぜるのは一般的でない**（実験手順としてはあり得るが、反応式としては書かない） |
| `amphoteric-aloh3-naoh`: AlCl₃ ＋ 4NaOH → Na[Al(OH)₄] ＋ 3NaCl | 分割版が無く、「少量で沈殿・過剰で再溶解」の2段が式として見えない |
| `amphoteric-znoh2-naoh`: 同上 | 同上 |

## 2. 目標の構成

### 銅(Ⅱ)イオン — NaOH 版と NH₃ 版を**別に**作り、相互に遷移できるようにする

**NaOH 版（1段階）**

```
Cu²⁺ ＋ 2OH⁻ → Cu(OH)₂↓（青白色）
```
過剰に加えても溶けない（Cu(OH)₂ は両性ではない）。ここが Al・Zn との対比になる。

**NH₃ 版（2段階）**

```
1段（少量）  Cu²⁺ ＋ 2NH₃ ＋ 2H₂O → Cu(OH)₂↓ ＋ 2NH₄⁺
2段（過剰）  Cu(OH)₂ ＋ 4NH₃ → [Cu(NH₃)₄]²⁺ ＋ 2OH⁻
```

1段目は「アンモニアが塩基として働く理由」を見せる必要があるので、**2本の足し合わせ**として提示する
（酸化還元モードの半反応式×倍率と同じ操作）。

```
  NH₃ ＋ H₂O → NH₄⁺ ＋ OH⁻      ×2   ← 弱塩基の電離。OH⁻ の出どころ
  Cu²⁺ ＋ 2OH⁻ → Cu(OH)₂↓            ← 沈殿の本体（NaOH 版と同じ式）
  ────────────────────────────
  Cu²⁺ ＋ 2NH₃ ＋ 2H₂O → Cu(OH)₂↓ ＋ 2NH₄⁺
```

**この形にする理由**: 沈殿そのものは `Cu²⁺ ＋ 2OH⁻ → Cu(OH)₂↓` で、OH⁻ がどこから来たかによらない。
イオン反応式を標準にすると **NaOH 版と NH₃ 版が文字どおり同じ式**になり、両者を行き来させる意味が立つ。
分子式で書くと `CuSO₄＋2NaOH→…` と `CuSO₄＋2NH₃＋2H₂O→…` になって同じ反応に見えない。

### 両性水酸化物 — 分割版とまとめ版の**両方**を持つ

```
分割  Al³⁺ ＋ 3OH⁻ → Al(OH)₃↓        Al(OH)₃ ＋ OH⁻ → [Al(OH)₄]⁻
まとめ Al³⁺ ＋ 4OH⁻ → [Al(OH)₄]⁻
Zn:   Zn²⁺ ＋ 2OH⁻ → Zn(OH)₂↓        Zn(OH)₂ ＋ 2OH⁻ → [Zn(OH)₄]²⁻   ／ まとめ 4OH⁻
```

「少量なら沈殿・過剰なら溶ける」は**2本に分けて初めて式として見える**。まとめ版は
「結局いくつ OH⁻ が要るか」を答える形として残し、分割版とリンクする。

## 3. 必要になる仕組み（4つ）

### (a) イオン反応式を主にできるようにする

いまは分子式が主で、イオン反応式は `netIon`（クリア後に出る従の表示）。
ステージに `primary: "ionic"` を持たせ、**反応式パネルの項そのものをイオン種にする**。

- 係数パズルの判定は `checkStageCoeffs` がそのまま使える（`compareSides` は原子だけでなく
  **電荷も保存を見ている**ため、イオン式でも正しく判定できる）
- 分子式の併記は残す（入試では分子式を書かせることもあるため）。主従が入れ替わるだけ
- 影響範囲: `buildEquationUI` / `renderTally` / 数合わせビュー（項の分解が既に `partsOf` 経由なので、
  イオン種はそれ自身に分解される＝そのまま動く見込み）

### (b) 沈殿を反応物として投入できるようにする

2段目はどれも **沈殿から始まる**（Cu(OH)₂・Al(OH)₃・Zn(OH)₂）。
いまは反応物を投入すると必ず電離するので、`SOLID_SPECIES` の種は電離させず
**沈殿として底に置く**投入経路を足す（`dissociateMolecule` で分岐し、mode を "sink" にする）。

**副産物**: いま `playable: false` の `complex-agcl-nh3`（AgCl ＋ 2NH₃ →[Ag(NH₃)₂]Cl。
ハロゲン化銀の識別）も同時に遊べるようになる。

### (c) NH₃ ＋ H₂O → NH₄⁺ ＋ OH⁻ の表現

DEVELOPMENT.md の M4 で「溶媒の水を要する」として残していた宿題。ここで回収する。

- ルール案: `{ find: ["NH3"], solvent: "H2O", make: ["NH4+", "OH-"], kind: "ionize" }`
- ビーカーでは、溶媒層から薄い H₂O の粒を1個わかせて NH₃ とくっつけ、NH₄⁺ と OH⁻ に分ける
  （水が「無限にある背景」ではなく、反応に参加した1個だけが見える）
- 原子の保存検査（監査・テスト）は、わかせた H₂O を投入分に加えて数える必要がある。
  **`solvent` で消費した数を記録する**カウンタを足す

### (d) 反応どうしのリンク

データに関係を持たせ、インデックスとステージ画面から行き来できるようにする。

```jsonc
"steps":     ["id1", "id2"],   // まとめ版 → 分割版（この2本に分けて書ける）
"combined":  "id",             // 分割版 → まとめ版
"variantOf": "id"              // NaOH 版 ⇄ NH₃ 版（同じ沈殿を別の試薬で）
```
