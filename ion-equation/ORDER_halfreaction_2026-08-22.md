## 0. ユーザーの言葉（原文・これが仕様の正）

> **酸化還元反応の反応式を作る練習（反応前後の化学式を与え、H+、e- などを入力させる）**
>
> **やり方が大きく2通りあるので対応したい**
>
> **半反応式は H2O H+ e- の順に決定するのが簡単だが、本質的には
> 酸化数の変化を調べ e- (H2O H+) の順に決定する方が本質的である**
>
> **また、酸化数の決定練習**
>
> **酸化数の決定についてはイオンに分けて考えることを徹底させたい。
> 仮想的に単原子イオンに分解させてもよい**

## 1. 発注は2本立て

| | 中身 |
|---|---|
| **練習X: 半反応式を組む** | 反応前後の化学式（例: MnO₄⁻ → Mn²⁺）を与え、**H₂O・H⁺・e⁻ を人に入れさせる** |
| **練習Y: 酸化数を決める** | ⚠ **イオンに分けて考えることを徹底させる**。仮想的に単原子イオンへ分解してよい |

★ **2本は独立ではない。** 練習X の**手順B が練習Y を要求する**（酸化数の変化を先に調べるため）。
**Y が先に立っていないと X の手順B は成り立たない**ので、**Y → X の順に作ること。**

## 2. ⚠ 練習X は「2通りの手順」を両方通すのが要件

**片方だけ作って終わりにしないこと。** ユーザーが明示的に「大きく2通りあるので対応したい」と言っている。

| | 手順 | 性格 |
|---|---|---|
| **A（作業として簡単）** | **H₂O → H⁺ → e⁻** | O の数を H₂O で合わせ → H の数を H⁺ で合わせ → **電荷の差**を e⁻ で合わせる |
| **B（本質的）** | **酸化数の変化を調べる → e⁻ → （H₂O → H⁺）** | 先に「何個の電子が動いたか」を酸化数から決め、あとから O・H を辻褄合わせする |

⚠ **B は「A を並べ替えたもの」ではない。** A は**最後まで電子の意味が出てこない**（電荷の帳尻としてしか現れない）。
B は**最初に電子が主役**になり、H₂O・H⁺ が後始末になる。**画面の段の並びも、説明の文言も変わる。**

⚠ **どちらを選ばせるか（選択式か・段階的に A → B へ進ませるか）は決まっていない。設計で提案すること。**

### ★ 着地（2026-08-28）—— 選択式にし、クリア後にもう一方へ誘う

`halfreaction.html` の上に手順の札を2つ置き、**同じ式のまま切り替えられる**ようにした。
段の見出しも説明の1行も、札を押すとそのまま入れ替わる。

```
手順A：H₂O → H⁺ → e⁻          電子は最後。O と H を合わせ、残った電荷の差を e⁻ で埋める。
  ① O の数を H₂O で合わせる   ② H の数を H⁺ で合わせる   ③ 電荷の差を e⁻ で埋める
手順B：酸化数 → e⁻ → H₂O → H⁺   電子が先。酸化数が動いたぶんが e⁻ の数で、O と H はあとから辻褄を合わせる。
  ① 酸化数の変化から e⁻ の数を決める   ② O の数を H₂O で合わせる   ③ H の数を H⁺ で合わせる
                                        ＋ 締めに「電荷は 左 +2 ／ 右 +2 —— 合っている」の1行
```

★ **B が「A の並べ替え」でないことは、画面では*電荷の役どころ*に出る**（§2 の指摘の実体）:

| | 電荷 | e⁻ |
|---|---|---|
| **A** | **答えを決める材料**（③の見出しそのもの） | 最後に出てくる帳尻 |
| **B** | **最後の答え合わせ**（段ではなく締めの1行） | 最初に決まる主役。以後**動かさない** |

**選択式を採った理由**（段階制・別ステージを採らなかった理由）:

1. 2通りが**同じ式に至る別の道**であることは、**同じ式で切り替えられて初めて見える**。
   段階制だと違う式で比べることになり、「A で組んだ式」と「B で組んだ式」が同じものだと分からない
2. 段階制は **B に着かない人が出る** ＝「大きく2通りあるので対応したい」が実質半分になる
3. 段階のよさ（順に通す）は、**クリアしたら「同じ式を手順B で組む →」を出す**ことで
   選択式の中に入れられる。実際そう作った
4. 実装上も、両手順は同じ採点部品を**段の並びだけ変えて**使うので、切り替えは状態のリセットで済む

⚠ **切り替えると入力は捨てる。** 残すと B に切り替えた瞬間に完成していて、
手順B の芯（先に e⁻ を決める）を一度も通らない。回帰テストがこれを見張る。

### ★ 手順B の1段目 —— 練習Y と重ならないように、酸化数は「印で与える」

手順B の1段目に出るのはこの1行だけ:

```
Mn の酸化数  ［+7］ → ［+2］   変わった原子は 1 個      この数の出し方 →（oxidation.html?sp=MnO4-）
```

- ⚠ **酸化数そのものは問わない。** それは練習Y の仕事で、ここで問うと**同じ練習を2回**やらせる
  （しかも2種ぶん）。**印（灰色）で与え**、出し方を知りたい人はリンクで練習Y へ送る
- ⚠ **1個あたりの幅（3）も、掛け算の答え（6）も出さない。** それを出すのがこの段の問い。
  Cr₂O₇²⁻ → 2Cr³⁺ が「3 × 2 個 ＝ 6」になるところが、この段のいちばんの山
- ★ **問うのは「e⁻ を何個・どちらの辺に」の2つだけ。** 辺は酸化数の向きから決まる
  （上がった原子は電子を出す ＝ 右辺／下がったなら左辺）ので、**外すと辺の理由を言い返す**
- ⚠ **採点の文に e⁻ の数を書かない**（「1個あたり動いた幅 × 変わった原子の数」とだけ言う）。
  回帰テストが「外したときの文に答えの数が含まれない」ことを見張る

★ **練習Y との重なりは「部品の共有」だけ**（`oxKnownOf` は使わず、`oxChangeOfHalf` と
`fmtOxNum` を借りるだけ）。**問うている中身は重なっていない** ——
Y は「1つの物質の中で酸化数をいくつに決めるか」、X-B は「2つの物質を突き合わせて、
動いた幅と原子の数から電子を何個にするか」。

## 3. 練習Y の芯 ——「イオンに分けて考えることを徹底」

ユーザーの狙いは **K₂Cr₂O₇ の Cr をいきなり考えさせない**ことにある（推測ではなく原文の「徹底させたい」から読める）。

```
K₂Cr₂O₇  →  2K⁺  ＋  Cr₂O₇²⁻     ← ここで切る（イオンに分ける）
                     Cr₂O₇²⁻ の中で  O は −2、合計が −2  →  Cr は +6
```

- ⚠ **「仮想的に単原子イオンに分解させてもよい」** ＝ Cr₂O₇²⁻ をさらに 2Cr⁶⁺ ＋ 7O²⁻ と見なす道を許してよい、という許可。
  **これは実在の電離ではない**ので、**そう断ったうえで**使うこと（`qa/KNOWLEDGE_CAVEATS.md` の型）。
- ⚠ **「分けなくても答えは出る」道を残すと徹底にならない。** 段として分けるか、分けないと次へ進めない作りにするかは設計で決めること。

### ★ 着地（2026-08-26）—— 段を分け、分けないと次へ進めない作りにした

`oxidation.html` の3段。**段1が正解になるまで段2は `hidden`**（＝分けるのを飛ばせない）。
ただし何が待っているかは「まだ開かない」段として先に見せる（行き先の分からない足止めにしない）。

```
段1 イオンに分ける      K₂Cr₂O₇ → [2] K⁺ ＋ [1] Cr₂O₇²⁻   ← 個数だけを問う。⚠ これは実在の電離
段2 イオンの中で決める   2K⁺   : K [+1]（印・単原子イオンなので電荷そのもの）
                       Cr₂O₇²⁻: Cr [ □ ] ×2 ・ O [−2]（印・規則）
                       検算 (□)×2 ＋ (−2)×7 ＝ ?　めざす合計 −2
段3（任意）仮想の分解    Cr₂O₇²⁻ → 2Cr⁶⁺ ＋ 7O²⁻ ＋ 断り文
```

⚠ **ただし K₂Cr₂O₇ そのものは、式のままでも解ける**（K も O も規則で決まるので未知は Cr だけ。
2x − 14 = 0 → x = +6）。**「分けないと解けない」のは別の式**で、そちらは実在する（§4 の実測）。
だから K₂Cr₂O₇ の回では嘘の理由をつけず、こう言う:

> この式のままでも数は出せる。それでも分けるのは、**分けないと解けない式がすぐ来る**から
> （CuSO₄ は Cu も S も決まらない）。分ける手を先に体に入れておく。

### ★ §7-4 の着地 —— 仮想分解の断り文（`OX_VIRTUAL_CAVEAT`）

段3を開いたときにだけ、式と対で出る。**この文が消えたら回帰テストが赤くなる。**

> ⚠ これは実際に起きている電離ではない。Cr₂O₇²⁻ の Cr と O は共有結合でつながっていて、
> 水の中でばらばらになることはない。酸化数は「結びついている電子を、引きつける力の強いほうの原子が
> **全部取ったことにする**」と決めて数えた値で、その約束をそのまま絵にしたのがこの姿。
> **数えるための道具であって、水の中の本当のすがたではない。**

⚠ **段1と段3を同じ画面で取り違えさせない**のが要点。段1は本当に起きる電離なので、
そちらは正解時に「これは本当に起きる電離」と明言する。
