📝 遊び方と操作方法:

  • 原子の配置：元素（C, O等）を選択し、キャンバス上の半透明プレビューの箇所をクリックして確定配置します。複数の原子と隣接できる位置では、プレビューに表示された結合がすべて作られます（環を閉じられます。不要な結合は右クリックで削除）。環の原子に2本目の側鎖を付けると、1本目と対称（±30°）に自動で振り分けられます（オレンジの点線が移動先）。
  • 原子・結合の削除：
    • 原子または結合線を「右クリック」します（PCで最もすばやく消去できます）。
    • または、現在選択中の元素と「同じ元素を重ねてクリック」します。
    • または、ツールバーの「消しゴム（Erase）」を選択して、原子や結合線をクリック（タップ）します。
    • タッチ操作：結合線を長押し（約0.5秒）またはすばやく2回タップしても削除できます。
  • 結合を繋ぐ・次数変更：
    • 「結合を描く（Draw Bond）」を選択し、原子から隣の原子へドラッグして繋ぎます。
    • 既存の結合線をシングルクリックすると、次数がトグル（単結合➔二重結合➔三重結合）で変わります。
    • 結合線を軸方向にドラッグすると結合を伸縮できます（グリッド単位）。スペースが足りないときは伸ばして空間を作ってから枝を付けます。環につながる結合を伸ばすと環ごと移動します（環の内部の結合は伸縮不可）。
  • 不斉炭素原子の指定：
    • 「不斉炭素原子マークモード」をONにして、不斉炭素原子（4つとも違う原子・原子団が結合した炭素原子）をクリックして * を付けます。
  • 分子を丸ごと動かす：Shift を押しながら原子をドラッグすると、その原子がつながっている分子全体が形を変えずに移動します。名称呼び出しや反応で分子が2つ以上あるとき、位置関係を整えるのに使います（反応の実行に場所が足りないときは、これで離してから実行します）。他の分子と重なる位置には置けません。くっつける操作ではないので、近づけても自動では結合しません。
  • 元に戻す / やり直し：Ctrl+Z で元に戻す、Ctrl+Y（または Ctrl+Shift+Z）でやり直しできます。
  • キャンバスの移動・拡大縮小：分子が画面からはみ出したときは、動かして見ます。
    • PC（マウス）：右ボタンでドラッグすると移動します。ホイールを回しても移動します。拡大・縮小はCtrl を押しながらホイール（カーソルの位置を中心に拡大します）。
    • タッチパッド：2本指のスクロールで移動、2本指をつまむ・広げる（ピンチ）で拡大・縮小します。
    • タッチ操作：2本指のドラッグで移動、ピンチで拡大・縮小します。
    • 迷ったら 🔍 全体表示（キャンバス上部）で元の見え方に戻せます。
  • 硫黄（S）についての注意：本アプリのSは6価（スルホ基 -SO₃H 用）として扱います。H₂Sやチオールなど2価のS化合物は正しく表現できません。

フィッシャー投影は紙面内で90°回すと鏡像（別の分子）になってしまいます。そこで90°ボタンは 「回してから左右の枝を入れ替える」までを1操作で行い、同じ分子を保ちます。 180°回転と、軸を1本固定して残り3本を回す操作は、そのままで同じ分子のままです。 どのボタンも、押した結果の図から立体を読み直して、分子が変わっていないことを確認しています。

📖 R・S ってなに？（読み物）

① R・S は「不斉炭素原子まわりの並び方」の呼び名
不斉炭素原子のまわりには、鏡像の関係にある2通りの並び方があります。そのどちらなのかを言い分けるための記号が R と S です。つながり方（どの原子とどの原子が結合しているか）はまったく同じで、違うのは立体的な並び方だけ。化合物名の頭に付いて、名前の一部になります。

② 決め方の骨組み
1. 不斉炭素原子に付いた4つの置換基に優先順位（1位〜4位）を付ける
2. いちばん低い4位を、自分から見て奥に置く
3. 残り3つを 1位 → 2位 → 3位 の順にたどる
4. その回り方が時計回りなら R、反時計回りなら S

③ 優先順位の付け方
・中心に直接つながっている原子の原子番号が大きいほうが上位（Br > Cl > S > O > N > C > H）
・水素は原子番号がいちばん小さいので、中心に H が付いていればそれが必ず4位
・直接つながる原子が同じ（同点）なら、1つ外側の原子へ進んで比べる。違いが出たところで順位が決まる
・二重結合は「その相手の原子が2個つながっている」とみなして数える
※実際の規則（CIP 則）にはさらに細かい取り決めがあります。ここでは考え方の骨組みだけを示しています。

④ このアプリは R・S を判定しません
優先順位の決定は例外や場合分けが多く、機械的に正しく解くには大がかりな実装が要ります。このアプリは R か S かを名乗る代わりに、重ね合わせられるかどうかを図の操作で確かめる方針をとっています。記号を覚えていなくても、「🪞 鏡像と並べる」→「並びを揃える」で重ならないことを見れば、同じ分子か鏡像異性体かは判断できます。「🔎 枝を辿って比べる」は、③の「同点なら1つ外側へ進む」と同じ辿り方で、どこで違いが出るかを示します（順位は付けません）。

⑤ D・L は R・S とは別の規約
糖やアミノ酸で使う D・L は、グリセルアルデヒドを基準にした慣用の分類です。フィッシャー投影に描いて、糖ならいちばん下の不斉炭素原子の -OH、アミノ酸なら-COOH の隣（α炭素）の -NH₂ が右にあれば D、左にあれば L と決めます。基準の分子と見比べるだけで、優先順位は使いません。
一方 R・S は、②③の優先順位から決めます。両者はまったく別の規約なので、D だから R、L だから S と決まるわけではありません（D・L が同じでも R・S が食い違う組み合わせがあります）。混同しやすいところなので、どちらの規約の話かを必ず区別してください。

⑥ 図で確かめる
②の「4位を奥に置く」は、この画面で実際にできます。上のタブ「🧊 3Dで回す」で「回転軸」に置換基を選び、「軸の向き: 奥」を押すと、その結合が視線の方向を向いた姿勢になり（ニューマン投影に近い見え方）、残り3つがどちら回りに並んでいるかを読み取れます。

くさび図では縦（上・下）が紙面の奥です。奥に置きたい置換基を縦へ動かすには「↻ 残り3つを回す」を使います（並べ替えても分子は変わりません）。
