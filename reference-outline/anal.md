## `element-detection` 元素の確認

**前書き（案）**
`id: element-detection` / `unit: anal` / `unitLabel: 元素の確認・元素分析` / `group: 元素の確認（定性）`
`title: 元素の確認`
`summary: C・H・N・Cl・S が入っているかを調べる操作と、そのとき見える変化のまとめ。検出反応はどれも無機で習った中和・水和・弱塩基の遊離・沈殿の使い回しなので、反応式ごと並べて見比べられます。`
`source: slides:有機の基本1-3「元素の確認」s2〜s13 ／ qa:org.anal.qualitative-def, org.anal.detect-*`
`why:` 「操作 → 変化」の対応だけを覚えると、反応式を書かせる出題で止まる。**無機の再利用**だと分かる並べ方にした。

**スコープ**: ★ 5元素の検出操作・生成物・見える変化・反応式を詳しく。定性／定量の言葉の区別もここ。
⛔ 量・組成式・分子式（→ `elemental-analysis`）。⛔ 官能基の検出（銀鏡・ヨードホルム等）は各物質ページ。
⛔ 分離・精製の操作は一言だけ（→ 芳香族の分離のページ・未着手）。

**概要**: 操作と結果を元素ごとに言え、実験操作の文から含まれる元素を当てられる。
検出反応の式が書ける。どれも既習の型（中和・水和・弱塩基の遊離・沈殿）だと分かる。

**引き受ける知識項目**: `org.anal.qualitative-def` `org.anal.detect-c` `org.anal.detect-h`
`org.anal.detect-n` `org.anal.detect-cl` `org.anal.detect-s`

### 節の並び

**1. 定性分析と定量分析**
「何が入っているか」を調べるのが**定性分析**、「どれだけ入っているか」を調べるのが**定量分析**。
この単元は前半が定性、次のページが定量。
★ 調べる前に**純物質にしておく**（混合物のままでは何を調べているのか決まらない）。
分けるには蒸留・再結晶・抽出（分液ろうと）・クロマトグラフィーを使う ＝ **一言＋リンクだけ**。

**2. 5元素の確認法（一覧）** —— **表: 元素 / 操作 / 生成物 / 確認方法**（`source: slides:1-3 s2`）

| 元素 | 操作 | 生成物 | 確認方法 |
|---|---|---|---|
| 炭素 C | 完全燃焼させる | CO₂ | 石灰水に通じると**白濁**する |
| 水素 H | 完全燃焼させる | H₂O | 白色の硫酸銅(II)無水物が**青色**になる／塩化コバルト紙が青から**淡赤色**に変わる |
| 窒素 N | NaOH を加えて加熱する | NH₃ | 湿った**赤色リトマス紙が青変**／濃塩酸を近づけると**白煙** |
| 塩素 Cl | 焼いた銅線につけて加熱する | CuCl₂ | **青緑色**の炎色反応（バイルシュタイン反応） |
| 硫黄 S | 金属 Na を加えて加熱・融解する | Na₂S | 水に溶かして酢酸鉛(II)水溶液を加えると**黒色沈殿** |

⚠ **青緑色の炎色反応は Br・I でも出る**ので、この操作で分かるのは「**ハロゲンが入っている**」まで。
★ Cl と言い切れるのは、他の条件が揃っているときだけ。

**3. 炭素の確認** —— 完全燃焼で CO₂。検出は無機で習った中和。

```
:::reaction
left: Ca(OH)₂ ＋ CO₂
right: CaCO₃↓ ＋ H₂O
level: ★★★
note: 酸性酸化物 CO₂ と塩基 Ca(OH)₂ の中和。白濁の正体は CaCO₃ です。
:::

:::reaction
left: CaCO₃ ＋ CO₂ ＋ H₂O
right: Ca(HCO₃)₂
level: ★★☆
note: CO₂ を通じ続けると沈殿が溶けて無色に戻ります。⚠ 確認は「一度白濁したか」で見ます。
:::
```

**4. 水素の確認** —— 完全燃焼で H₂O。白色の無水物が水和して青くなる。

```
:::reaction
left: CuSO₄ ＋ 5H₂O
right: CuSO₄・5H₂O
level: ★★★
note: 白色の硫酸銅(II)無水物が青色の五水和物になります。加熱すると白色に戻る可逆反応です。
:::

:::reaction
left: CuSO₄・5H₂O
over: 加熱
right: CuSO₄ ＋ 5H₂O
level: ★★☆
note: 逆向き。水和水が抜けて白色に戻ります。
:::
```

**5. 窒素の確認** —— NaOH を加えて加熱すると分解して NH₃ が出る。検出は無機のまま。

```
:::reaction
left: NH₃ ＋ HCl
right: NH₄Cl
level: ★★★
note: 濃塩酸をつけたガラス棒を近づけると白煙（NH₄Cl の微粒子）。NH₃ は**唯一の塩基性の気体**なので、湿らせた赤色リトマス紙の青変でも確認できます。
:::
```

⚠ この操作が効くのは**アミノ基 −NH₂** で、**ニトロ基 −NO₂ には効かない**（1行）。
★ 参考（弱塩基の遊離の型）: **2NH₄Cl ＋ Ca(OH)₂ → CaCl₂ ＋ 2NH₃↑ ＋ 2H₂O**（★★☆）

**6. 塩素・硫黄の確認**

```
:::reaction
left: 試料中の Cl ＋ Cu
over: 焼いた銅線・加熱
right: CuCl₂
level: ★★☆
note: CuCl₂ は沸点が低く炎の中で気化するので、Cu の青緑色の炎色反応が見えます。単体の Cu や CuO は沸点が高く、炎に入れても炎色反応を示しません。これがバイルシュタイン反応です。
:::

:::reaction
left: Na₂S ＋ Pb(CH₃COO)₂
right: PbS↓ ＋ 2CH₃COONa
level: ★★☆
note: 試料に金属 Na を加えて加熱・融解すると Na₂S ができます。水に溶かして酢酸鉛(II)水溶液を加えると PbS の黒色沈殿。S²⁻ は多くの金属イオンと黒色沈殿をつくります。
:::
```

**7. 覚える範囲の線引き**
★ 表の「操作と確認方法」は5元素とも組で必ず覚える。
反応式は **Ca(OH)₂＋CO₂／CuSO₄＋5H₂O／NH₃＋HCl の3本**を書けるようにする。
⚠ CuCl₂ の沸点の数値・PbS が酸性でも沈殿すること・塩化コバルト紙は**覚えなくてよい**（読めれば十分）。
★ ただし「**ハロゲンなら Br・I でも青緑になる**」は覚える（そのまま Cl と答えると外れる）。

**8. 例題1** `source: slides:1-3 s7→s8` —— 次の操作で確認できる元素を元素記号で答えよ。
① 完全燃焼して発生した気体を石灰水に通じると白濁した → **C**
② 完全燃焼して生じた液体を硫酸銅(II)無水物につけると青くなった → **H**
③ 焼いた銅線の先につけて加熱すると青緑色の炎色反応を示した → **Cl（またはハロゲン）**
④ 金属 Na と加熱した生成物を水に溶かし、酢酸鉛(II)水溶液を加えると黒色沈殿を生じた → **S**
⑤ NaOH を加えて加熱し、発生した気体に濃塩酸をつけたガラス棒を近づけると白煙を生じた → **N**

**9. 例題2** `source: slides:1-3 s9→s13` —— 次の反応式を書け。
① 石灰水に CO₂ を吹き込むと白濁した → **Ca(OH)₂ ＋ CO₂ → CaCO₃ ＋ H₂O**
② ①の溶液にさらに CO₂ を吹き込むと無色になった → **CaCO₃ ＋ CO₂ ＋ H₂O → Ca(HCO₃)₂**
③ 硫酸銅(II)無水物に水を滴下すると青くなった → **CuSO₄ ＋ 5H₂O → CuSO₄・5H₂O**
④ 酢酸鉛(II)水溶液に硫化水素を吹き込んだ → **Pb(CH₃COO)₂ ＋ H₂S → PbS↓ ＋ 2CH₃COOH**

**10. 例題3**（★ 短い1問。分類の手がかりとしての使い方に橋を架ける）
> ある有機化合物を完全燃焼させると CO₂ と H₂O を生じ、NaOH を加えて加熱すると NH₃ が発生した。
> この化合物に**必ず含まれている**元素をすべて答えよ。
**答: C・H・N。**⚠ **O は分からない**（燃焼の O₂ からも H₂O・CO₂ ができるため）。
★ **O だけは「確認」では出てこない ＝ 引き算で出すしかない**、が次のページへの橋。

`to: clue-order`（検出の結果は「分類」の手がかりとして最初に使う）

**⚠ まだ無いページ**: `elemental-analysis` `clue-order`

## `elemental-analysis` 元素分析 —— 燃やした質量から分子式まで

**前書き（案）**
`id: elemental-analysis` / `group: 元素分析（定量）` / `title: 元素分析`
`summary: 有機化合物を完全燃焼させ、生じた CO₂ と H₂O の質量から組成式と分子式を出すまでの手順。装置の順番の理由と、計算を軽くする並べ方まで1本で通します。`
`source: slides:有機の基本1-4「元素分析」s2〜s13 ／ qa:org.anal.*`
`why:` 構造決定でいちばん多い出だし。装置（暗記）と計算（手順）が別物なので、**装置 → 質量 → 組成式 → 分子式**の一本道にして、途中で止まる場所をなくした。

**スコープ**: ★ 装置とその順番の理由、質量 → 組成式 → 分子式の手順、分子量の出どころ。
⛔ どの元素が入っているかの確認（→ `element-detection`）。
⛔ **出した分子式をいつ使うか**（→ `clue-order`）。⛔ 不飽和度の定義（→ `hydrocarbon-classes`）。

**概要**: 装置の各部の役目と順番の理由が言え、CO₂・H₂O の質量から C・H・O の質量を出し、
組成式・分子式まで自力で通せる。★ 計算を軽くする並べ方（酸素を1個にそろえる）まで身につく。

**引き受ける知識項目**: `org.anal.quantitative-def` `org.anal.apparatus-absorb` `org.anal.apparatus-order`
`org.anal.apparatus-oxidant` `org.anal.mass-c` `org.anal.mass-h` `org.anal.mass-o`
`org.anal.composition-formula` `org.anal.molecular-formula` `org.anal.mw-from-solution`

### 節の並び

**1. 元素分析とは** —— 構成元素の**割合（組成比）**を求める定量分析。定性と対にして1段落。

**2. 装置** —— **乾燥した酸素（または空気）を送りながら**試料を燃やし、**酸化銅(II) CuO** で完全に酸化してから、
生じた H₂O・CO₂ を順に吸収管で受ける。**図: 装置図（必須）**

| 位置 | もの | 役目 |
|---|---|---|
| 入口 | 乾燥した O₂（または空気） | ⚠ 湿った気体を送ると 1本目の質量が増えてしまう |
| 燃焼管 | 試料 ＋ **酸化銅(II) CuO** | 試料を**完全に酸化**する酸化剤（CO やすすを残さない） |
| 1本目 | **塩化カルシウム管**（CaCl₂・**中性**の乾燥剤） | **H₂O だけ**を吸収。増加量 ＝ H₂O の質量 |
| 2本目 | **ソーダ石灰管**（NaOH ＋ CaO・**強塩基性**） | CO₂ を吸収。増加量 ＝ CO₂ の質量 |

```
:::reaction
left: C~x~H~y~O~z~ ＋ O₂
over: CuO・加熱
right: xCO₂ ＋ (y/2)H₂O
level: ★★☆
note: CuO は試料を完全燃焼させるための酸化剤です。不完全燃焼で CO やすすが残ると、量った質量が合いません。
:::

:::reaction
left: C₂H₅OH ＋ 3O₂
right: 2CO₂ ＋ 3H₂O
level: ★★☆
note: 具体例。C は全部 CO₂ に、H は全部 H₂O になります。⚠ O₂ 側にも酸素があるので、**O の質量だけは燃焼の式からは出せません**。
:::
```

★ ソーダ石灰は、酸化カルシウムを濃い水酸化ナトリウム水溶液に浸して加熱乾燥した**白色粒状の固体**。

**3. 吸収管の順番** —— **塩化カルシウム管（H₂O）が先、ソーダ石灰管（CO₂）が後。**
★ **逆にすると**、ソーダ石灰は塩基性なので **H₂O と CO₂ を両方吸ってしまい、別々に量れない**
（1本目だけが増えて、H₂O と CO₂ の内訳が分からなくなる）。
★ 合言葉「**水が先、二酸化炭素が後**」。⚠ **理由まで書かせる出題があるので、理由ごと覚える。**

**4. 質量を割り振る** —— 試料の質量を a、H₂O の質量を b、CO₂ の質量を c とする。

| 求めるもの | 式 | 由来 |
|---|---|---|
| H の質量 m_H | **b × 2.0/18** | H₂O 18 の中の H は**2個で 2.0** |
| C の質量 m_C | **c × 12/44** | CO₂ 44 の中の C は 12 |
| O の質量 m_O | **a −（m_C ＋ m_H）** | 引き算でしか出せない |

⚠ **H は 1/18 ではなく 2/18**（水1分子に H は2個）。ここが最頻のつまずき。
★ 原子量は覚えるものではなく、**問題に与えられる与件**。

**5. 組成式にする** —— 質量を原子量で割って原子の数の比にし、最も簡単な整数比にする。
　　C : H : O ＝ **m_C/12 : m_H/1.0 : m_O/16 ＝ x : y : z** → 組成式 C_xH_yO_z
★★ **本人のコツ: 最小の数で割らず、O が1個になるようにそろえる**（組成式の O はたいてい1か2）。
⚠ **わざと悪い手順を見せる**: 5.175 : 10.3 : 1.725 のまま整数に直そうとすると、どこを基準にすればよいか分からない。
★ もう1行: 「**書き写すところ**」と「**計算するところ**」を分けると計算量が減る。

**6. 分子式にする** —— **分子式は組成式の整数倍**。倍率 ＝ 分子量 ÷ 組成式の式量。

| 分子式 | 分子量 | CH₂O（式量30）の |
|---|---:|---|
| CH₂O | 30 | 1倍 |
| C₂H₄O₂ | 60 | 2倍（酢酸 CH₃COOH） |
| C₃H₆O₃ | 90 | 3倍（乳酸） |
| C₆H₁₂O₆ | 180 | 6倍（グルコース） |

★ 組成式は「原子の**数の比**」、分子式は「1分子中の原子の**数**」。

**7. 分子量はどこから来るか**

| 出どころ | 中身 |
|---|---|
| 問題文が与える | いちばん多い |
| 気体の状態方程式 | 気体・蒸気にできるとき |
| **凝固点降下・沸点上昇・浸透圧** | 溶かした試料の質量 ÷ 物質量。⚠ **電離する物質は粒子数が増えるので補正が要る** |
| 質量分析（MS） | 実験室ではこれが主流（★ 発展） |

★ この節は `advanced: true` でよい（最後の2行だけ）。

**8. 例題1（★ 最初から最後まで通す）** `source: slides:1-4 s3〜s5`
> C・H・O のみからなる有機化合物 **12.0 mg** を完全燃焼させると、CO₂ **17.6 mg**、H₂O **7.20 mg** を生じた。
> 組成式を求めよ。また分子量が **60** のとき分子式を求めよ。（H=1.0、C=12、O=16）

1. m_C ＝ 17.6 × 12/44 ＝ **4.8 mg**
2. m_H ＝ 7.20 × 2.0/18 ＝ **0.80 mg**
3. m_O ＝ 12.0 − 4.8 − 0.80 ＝ **6.4 mg**
4. 原子量で割る … 4.8/12 ＝ 0.40／0.80/1.0 ＝ 0.80／6.4/16 ＝ 0.40
5. **O を1にそろえる**（0.40 で割る）… C : H : O ＝ 1 : 2 : 1 → 組成式 **CH₂O**（式量30）
6. 60 ÷ 30 ＝ 2 → 分子式 **C₂H₄O₂**（酢酸 CH₃COOH）

**9. 例題2** `source: slides:1-4 s7→s9`
> C・H・O のみからなる有機化合物 **33 mg** を完全燃焼させると、CO₂ **66 mg**、H₂O **27 mg** を生じた。組成式を求めよ。

★ **別解（解答側に添える）**: 分子量に質量割合を掛けてから原子量で割ると、組成式を経ずに
116×0.621/12 ＝ 6.00／116×0.103/1.0 ＝ 11.9／116×0.276/16 ＝ 2.00 → **C₆H₁₂O₂**。
⚠ 分子量が分かっているときしか使えず、計算も重い。

## `clue-order` 手がかりを使う順番 —— 分類 → 数 → 物性

**前書き（案）**
`id: clue-order` / `unit: clue` / `unitLabel: 手がかりから物質に当たりを付ける` / `group: 手がかりを使う順番`
`title: 手がかりを使う順番`
`summary: 構造決定で与えられた条件を、どの順に使うか。分類 → 数 → 物性の順に使い、候補を削る条件と検算にしかならない条件を見分けます。数から絞る型（窒素則・組成式・不飽和度）と機器分析もここ。`
`source: qa:org.clue.*, org.anal.ir-carbonyl, org.anal.equivalent-h ／ stages:構造決定 ／ slides:有機の基本3-8「エステルの構造決定」s2〜s4`
`why:` 個々の知識ではなく**与件の使い方**が主題。与件には候補を削るものと検算にしかならないものがあり、この見分けが付くと解く順番が変わる。

**スコープ**: ★ ①使う順（分類 → 数 → 物性）②与件の2種類（削る／検算）③数から絞る型。
⛔ 検出反応の原理（→ 各物質のページ）。⛔ 物性から名指しする型（→ `clue-properties`）。
⛔ 不飽和度の定義と導き方（→ `hydrocarbon-classes`。式だけ引いて使ってみせる）。
⛔ 入試問題の文言は載せない（条件だけを使う）。

**概要**: 条件を**削る順に並べ替えてから**解き始められる。分子量の偶奇から窒素の数が言える。
組成式が出たとき「当てにいってよい型」と「分子量を待つ型」を見分けられる。
使わなくても解ける与件があることが分かる。

**引き受ける知識項目**: `org.clue.order` `org.clue.nitrogen-parity` `org.clue.amino-acid-mw-parity`
`org.clue.cho-ratio` `org.clue.ch2o-ratio` ／（発展）`org.anal.ir-carbonyl` `org.anal.equivalent-h`

### 節の並び

**1. 構造決定は消去法** —— 当てにいくのではなく候補を減らす。分子式が決まれば候補は有限個。

**2. 使う順番（★ この並びが主題）**

| 段 | 見るもの | 例 | 効き |
|---|---|---|---|
| ① 分類 | 官能基・液性・検出反応 | Na で H₂ が出た＝−OH／銀鏡反応＝アルデヒド／水溶液が酸性＝−COOH／炭酸水素ナトリウムで CO₂＝カルボン酸 | **いちばん大きく削る** |
| ② 数 | 分子式・分子量・不飽和度 | C₄H₁₀O なら候補は7通り／不飽和度1なら C=C か環 | 枠を切る |
| ③ 物性 | 沸点・融点・見た目・におい | 沸点34℃＝ジエチルエーテル | **最後の1手・検算** |

★ 「分類 → 数 → 物性」の3語を「」でくくって合言葉に。
⚠ **組成式から物質を当てにいくのは例外的**（→ 節8）。

**3. 同じ条件でも、置く順で残り方が変わる** —— ★ 最後に残る候補は順番によらず同じ。変わるのは途中の数。

| 順 | 1つめ | 残り | 2つめ | 残り |
|---|---|---:|---|---:|
| A | Na で H₂ が出た（−OH） | 4 | 酸化してケトン（2級） | 1 |
| B | 酸化してケトン（2級） | 1 | Na で H₂ が出た | 1 |

（C₄H₁₀O の7通りから。★ 大きく削る条件を先に置くほど、書き出す量が減る）

**4. 与件は2種類ある** —— **候補を削るもの**と、**検算にしかならないもの**。

| 与件 | はたらき | ひとこと |
|---|---|---|
| ナトリウムを加えると水素が発生した | **削る** | アルコール・フェノール類に限定 |
| 銀鏡反応を示した | **削る** | アルデヒドに限定 |
| 炭酸水素ナトリウム水溶液で気体が発生した | **削る** | カルボン酸に限定 |
| 分子量が与えられた | **削る** | 組成式の倍率が決まる |
| 不斉炭素原子をもつ | **削る** | 枝の付き方を限定 |
| **元素分析の結果** | **多くは検算** | 他の条件で骨格が決まることが多い |
| 沸点・融点の数値 | **名指し／検算** | 1つに決めるか、決まった構造を確かめるか |
| 「油状の液体である」 | **検算** | すでに絞れているものの確認になりやすい |

⚠ 余っている与件は読み落としではない。**確かめさせるために置かれていることがある。**

**5. 元素分析はいつ使うか** —— ★ 問題文の先頭にあっても、**先に使わなければいけないわけではない**。
他の条件で骨格が決まることが多く、そのときは元素分析は検算に回る。
⚠⚠ **これは別の解き方ではなく、同じ条件を使う順を変えているだけ**（残る候補はどちらでも同じ）。
★ 決めた構造から逆に燃焼の質量を計算して合わせれば、そのまま確かめになる。

**6. 数から当たりを付ける（1）不飽和度** —— 式は `hydrocarbon-classes` が持つが、**1回使ってみせる**。
　　不飽和度 ＝ (2C ＋ 2 ＋ N − H) / 2
- C₅H₁₀ … (10＋2−10)/2 ＝ **1** → C=C か環が1つ。異性体は **10通り**（アルケン5・シクロアルカン5）
- C₄H₁₀O … **0** → 二重結合も環も無い。異性体は **7通り**（アルコール4・エーテル3）
- C₆H₆ … **4** → ベンゼン環1つ（環1＋C=C 3）で説明が付く
★ **数が分かると「何通りの中から選ぶのか」が見える**のが、この段の効き。

**7. 数から当たりを付ける（2）窒素則** —— C・H・O・N だけの化合物では、
**分子量の偶奇と窒素の数の偶奇が一致する。**
理由（1〜2行）: 分子量 ＝ 12C ＋ H ＋ 16O ＋ 14N で 12C・16O・14N はどれも偶数 → 分子量の偶奇 ＝ H の偶奇。
さらに不飽和度が整数になることから H と N の偶奇が一致する。
- 分子量が**奇数** → 窒素は**奇数個**（ふつう1個）
- 分子量が**偶数** → 窒素は**偶数個**（0個をふくむ）
★ 使ってみせる: **α-アミノ酸で分子量146（偶数）→ N は2個 → リシン**。
窒素1個のふつうのα-アミノ酸は分子量が奇数（グリシン75・アラニン89）。

**8. 数から当たりを付ける（3）組成式** —— ★ 組成式から当てにいけるのは**例外的**。
- **CHO（1 : 1 : 1）→ まずブテン二酸 C₄H₄O₄**（マレイン酸・フマル酸）を疑う
- **CH₂O → 決まらない。分子量を待つ。**
  **図: ホルムアルデヒド HCHO（30）・酢酸 CH₃COOH（60）・乳酸 CH₃CH(OH)COOH（90）・
  グルコース C₆H₁₂O₆（180）の構造式4枚** —— どれも組成式 CH₂O。

**9.（発展・`advanced: true`）機器分析でわかること**

| 方法 | 分かること | 構造決定での使い方 |
|---|---|---|
| **質量分析（MS）** | 分子量 | ②段の「数」が直接手に入る |
| **赤外吸収（IR）** | 官能基の有無（C=O など） | ★ **不飽和度が残っているのに C=O が無ければ、環か C=C** |
| **¹H-NMR** | 水素の**種類の数**と**個数の比** | 信号の数＝化学的環境の異なる水素の種類。面積比＝水素の数の比 |

★ 具体例: 酢酸 CH₃COOH の ¹H-NMR は信号が**2本**、面積比 **1 : 3**（−COOH の1個と −CH₃ の3個）。
★ 置換位置にそのまま効く: 同じ置換基3つのベンゼン三置換体で、環の水素は
**1,2,3 が2種・1,2,4 が3種・1,3,5 が1種**。**図: 三置換体3枚。**

**10. 例題1（★ 最初から最後まで通す。順番の話がそのまま出る問題）**
`source: qa:org.clue.order ＋ compounds:2-ブタノール`
> C・H・O からなる化合物 A **7.4 mg** を完全燃焼させると、CO₂ **17.6 mg** と H₂O **9.0 mg** を生じた。
> A の分子量は **74** である。A にナトリウムを加えると水素が発生し、A を酸化するとケトンが得られた。
> A の構造式を書け。（H=1.0、C=12、O=16）

**解（★ 分類から使う）**
1. Na で水素が発生 → **−OH をもつ**（アルコール）
2. 酸化してケトン → **第二級アルコール**
3. 分子量74 → C₄H₁₀O（12×4 ＋ 1.0×10 ＋ 16 ＝ 74）。C₄H₁₀O のアルコール4通りのうち第二級は
   **2-ブタノール CH₃CH(OH)CH₂CH₃** だけ → **決まる**
4. **元素分析は最後に検算**: m_C ＝ 17.6×12/44 ＝ 4.8／m_H ＝ 9.0×2.0/18 ＝ 1.0／
   m_O ＝ 7.4 − 4.8 − 1.0 ＝ 1.6 → 4.8/12 : 1.0/1.0 : 1.6/16 ＝ 0.40 : 1.0 : 0.10 ＝ 4 : 10 : 1 → **C₄H₁₀O**（合う）
★ **元素分析を先にやっても同じ答えに着く。**違うのは、②〜③で済むところを①から通したかどうか。

**11. 例題2（数だけで絞る）**
> C・H・O・N からなる化合物の分子量が **89** であった。窒素原子の数について言えることを述べよ。
> また、この化合物がα-アミノ酸であるとき、名称を答えよ。
**答: 分子量が奇数なので窒素は奇数個（ふつう1個）。分子量89 のα-アミノ酸は アラニン CH₃CH(NH₂)COOH。**

**12. 例題3（不飽和度から場合分け）**
> 分子式 C₅H₁₀ の化合物の不飽和度を求め、考えられる構造の型を挙げよ。
**答: 不飽和度1。C=C を1つもつ鎖状（アルケン5種）か、環を1つもつ飽和（シクロアルカン5種）で、合わせて10通り。**
★ ここで「臭素水を脱色した」という1行が来れば、アルケン側の5種に絞れる。

**13. 覚える範囲の線引き**
★ 「分類 → 数 → 物性」の3語は覚える。順番そのものは手順として身につける。
**窒素則は覚えると速い**（導けるが毎回導くのは損）。**「CHO ならブテン二酸」は覚える。**

## `clue-properties` 見た目・におい・沸点から当たりを付ける

**前書き（案）**
`id: clue-properties` / `unit: clue` / `group: 沸点・融点／見た目・においから当たりを付ける`
`title: 見た目・におい・沸点から当たりを付ける`
`summary: 「淡黄色で水より重い油状の液体」のような問題文の書きぶりから物質を名指しするための対応表。沸点・融点で決まるもの、見た目・においで決まるもの、位置異性体を沸点で分ける型まで。`
`source: qa:org.clue.* ／ compounds:ニトロベンゼン・アニリン・ナフタレン・酢酸・ジエチルエーテル ／ slides:有機の基本3-8「エステルの構造決定」s4`
`why:` 物性の手がかりは削る力は弱いが**最後の1手**として強い。問題文の言い回しごと覚えると一瞬で決まるので、言い回しをそのまま左の列に置いた表にした。

**スコープ**: ★ 物性の与件から物質を名指しする対応。
⛔ なぜその沸点・融点になるかの説明（水素結合・分子間力は一言＋リンク）。
⛔ それぞれの物質の性質・製法・反応（→ 各物質のページ）。

**概要**: 問題文の書きぶりをそのまま物質名に変換できる。
物性の手がかりが最後の1手・検算向きだと分かり、どこまで覚えればよいかの線が引ける。

**引き受ける知識項目**: `org.clue.diethyl-ether-bp` `org.clue.acetic-mp` `org.clue.formaldehyde-gas`
`org.clue.amino-acid-mp` `org.clue.nitrobenzene-look` `org.clue.aniline-look`
`org.clue.naphthalene-sublime` `org.clue.ester-smell`

### 節の並び

**1. 物性の手がかりは最後に使う** —— 削る力は弱いが、残った候補を**1つに決める**ときに強い。検算にも使える。

**2. 沸点・融点・状態で名指しできるもの**

| 書きぶり | 物質 | ひとこと |
|---|---|---|
| 沸点 **34℃**、引火しやすい無色の液体 | **ジエチルエーテル** C₂H₅OC₂H₅ | 高校で名前の出る有機化合物では他に無い |
| 融点約 **17℃**（冬に凍る）、刺激臭の液体 | **酢酸** CH₃COOH | 純度の高いものを**氷酢酸**という |
| **常温で気体**のアルデヒド | **ホルムアルデヒド** HCHO | 気体のアルデヒドはこれだけ |
| 分子量のわりに**融点が非常に高く**、水に溶けるが有機溶媒に溶けない固体 | **アミノ酸** | 結晶中で双性イオンになっているため |

**3. 見た目・においで名指しできるもの**

| 書きぶり | 物質 | ひとこと |
|---|---|---|
| **淡黄色**で**水より重い**油状の液体、特有のにおい | **ニトロベンゼン** C₆H₅NO₂ | 水より重いのが決め手 |
| 無色の油状の液体で、空気中で**しだいに褐色**になる | **アニリン** C₆H₅NH₂ | 酸化されて色が付く |
| **昇華**する無色の**板状結晶**（防虫剤） | **ナフタレン** C₁₀H₈ | 昇華といえばこれ |
| **果実のような芳香**をもつ**中性**の液体 | **エステル** | ⚠ 物質名ではなく**分類**が決まる |

**4. 位置が違うだけの異性体も、沸点で分かれる** —— ★ 官能基の**位置**は分類でも数でも決まらないので、
物性が最後の決め手になることがある。

| 化合物 | 沸点 |
|---|---|
| **1-プロパノール** CH₃CH₂CH₂OH | **97℃** |
| **2-プロパノール** CH₃CH(OH)CH₃ | **82℃** |

★ どちらも C₃H₈O で、Na とも反応し、どちらもアルコール。**分類では分かれない。**
⚠ ただし「酸化するとケトン」と言われれば2-プロパノールに決まる ＝ **物性を使わずに済むならそちらが先**。

**5. なぜその物性になるか（一言ずつ）** —— ★ 1行＋リンクまで。展開しない。

```
:::reaction
left: 2C₂H₅OH
over: 濃硫酸・130〜140℃
right: C₂H₅OC₂H₅ ＋ H₂O
level: ★★★
note: 沸点34℃のジエチルエーテルはこうしてできます。⚠ エタノール（沸点78℃）より沸点がずっと低いのは、−OH が無く**分子どうしが水素結合をつくらない**ためです。
:::
```

アミノ酸の融点が高いのは**双性イオンどうしのイオン結合**のため／
エステルが中性なのは −COOH の H がアルキル基に置き換わっているため。

**6. 例題1** `source: qa:org.clue.diethyl-ether-bp ＋ compounds:ジエチルエーテル`
> 分子式 C₄H₁₀O の化合物 B は、ナトリウムを加えても変化がなく、沸点は 34℃ であった。B の構造式を書け。

1. Na と反応しない → **−OH をもたない** → 7通りのうち**エーテル3通り**
2. 沸点34℃ → **ジエチルエーテル**
3. **CH₃CH₂−O−CH₂CH₃**
★ `clue-order` の例題1と**同じ分子式 C₄H₁₀O** で、分かれ道だけが違う。2つ並べると通り方が見える。

**7. 例題2**
> 次の記述に当てはまる物質の名称を答えよ。
> ① 淡黄色で水より重い油状の液体である → **ニトロベンゼン**
> ② 無色の油状の液体で、空気中に置くとしだいに褐色になる → **アニリン**
> ③ 昇華しやすい無色の板状結晶で、防虫剤に使われる → **ナフタレン**
> ④ 冬に凍ることがある刺激臭の無色の液体である → **酢酸**

**8. 例題3（★ 物性を検算に使う）**
> ある化合物の構造を C₂H₅OC₂H₅ と決めた。この結論を、与えられた「沸点34℃」と「Na と反応しない」で確かめよ。
**答: −OH が無いので Na と反応しないことと合う。水素結合をつくらないので同じ分子式のアルコール（1-ブタノール 沸点117℃）より沸点が低く、34℃と合う。**
