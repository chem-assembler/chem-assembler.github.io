# 過去問の書き起こし

**方針の正は `video-scripts/POLICY_past_exams.md`。** ここは作業の置き場と手順だけ。

## 置き方

```
past-exams/
  <大学>-<年度>-<日程>-<大問>.md    例: osaka-2024-zenki-2.md
```

1問1ファイル。**書き起こした本人が、報告まで責任を持つ**（下の「報告」を参照）。

## 型の選び方（詳細は POLICY）

| | 大学の許諾 | 報告 | 有料可 |
|---|---|---|---|
| **型1 問題文を出さない** | 不要 | 不要 | **○** |
| **型2 問題文を出す（国立大）** | 不要（条件遵守） | **1か月以内・必須** | ○ |

- **無料の解説動画は 型2 でよい**（問題文が無いと解説しにくいため。2026-08-04 ユーザー判断）
- **有料コンテンツは 型1 と完全自作のみ**
- **共通テストは事前申請制**（通常8営業日）。**国立大の個別試験から始める**

## 書き起こすときの注意

- **元は書籍でよい**（『大学入試問題正解』など）。誤植が無く図も正確。
  **問題文の権利者は書籍ではなく大学**なので、大学の条件に従えばよい
- **⚠ 解答・解説は絶対に写さない。** ここだけが出版社の著作物で、はっきり駄目
- **図は自分で描き直す。** 構造式はアプリで描けば済む
- **出典は大学の指定書式に合わせる**（阪大は書式例まで指定している）
- **改題したら「改題」と明示する**
- **大学公表の解答以外を載せるなら「本学が公表したものでない」と明示する**

## 報告（型2で必須。忘れると条件を満たさない）

**公表から1か月以内**に、各大学の報告フォーム／申請書を出す。
出したら front matter の `reported` に日付を書く。
