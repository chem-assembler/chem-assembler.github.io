問1　化合物 B に炭酸水素ナトリウム水溶液を加えると<u>①気体が発生した</u>。化合物 B は，トルエンを過マンガン酸カリウムと反応させて得られる芳香族化合物と同じ物質であった。化合物 B の構造式を記せ。また，下線部①の気体の名称を記せ。

問2　化合物 C は不斉炭素原子をもち，その分子量は 90 である。化合物 C に炭酸水素ナトリウム水溶液を加えると<u>②気体が発生した</u>。15mg の化合物 C を完全燃焼させたところ，二酸化炭素 22mg と水 9.0mg が生成した。化合物 C の分子式と構造式を記せ。また，下線部②の気体の名称を記せ。

問3　化合物 D は，炭酸水素ナトリウムとは反応しないが，金属ナトリウムとは反応して<u>③気体を発生した</u>。化合物 D に塩基性条件下でヨウ素を作用させると黄色沈殿が生じた。化合物 D の構造式を記せ。また，下線部③の気体の名称を記せ。

問4　化合物 A の構造式を記せ。
